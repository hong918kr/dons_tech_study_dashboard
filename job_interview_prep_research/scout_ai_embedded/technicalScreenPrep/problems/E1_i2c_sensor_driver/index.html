E1 · I2C Temperature Sensor Driver (mock HAL)

IDE1
PriorityP0
Patternregister driver: RMW + poll with timeout + retry policy
Time30 min

파일: stub.c(여기서 풀기) · solution.c(정답) · 실행: ./run.sh E1 / ./run.sh E1 sol

0. 문제 한국어 소개 (먼저 읽기)

영어 문제(§1)를 읽기 전에 무엇을 만들라는 건지 먼저 잡기 위한 요약입니다. 실제 풀이와 테스트는 §1 영어 문제 기준입니다.

  • 한 줄 요약: 주어진 I2C HAL 함수만 써서 TMP102 비슷한 온도 센서 드라이버(초기화, 1회 측정 읽기, 경보 임계값 설정)를 재시도·타임아웃 규칙까지 맞춰 만든다.
  • 상황: MCU가 I2C 버스로 온도 센서 칩(주소 0x48)과 대화한다. 실제 하드웨어 대신 stub.c 아래쪽의 가짜 버스(레지스터 배열 + 오류 주입)가 HAL 뒤에 붙어 있다.
  • 배경 개념
    • 레지스터: 칩 안의 작은 번호 붙은 저장칸(0x00 TEMP, 0x01 CONFIG 등). 쓰기의 첫 바이트가 "몇 번 레지스터"인지(register pointer)이고, 읽기는 write {reg} 후 repeated START로 이어서 N바이트를 읽는다(i2c_write_read). 2바이트 레지스터는 MSB 먼저.
    • NACK: 칩이 바이트를 받았다는 응답(ACK)을 안 준 것. HAL이 -EIO로 알려주며, 일시적일 수 있어 재시도 대상이다. -ETIMEDOUT은 버스가 계속 busy로 묶인 상태.
    • WHO_AM_I: 항상 고정값(0xA1)을 돌려주는 ID 레지스터. 버스에 붙은 칩이 맞는 칩인지 확인용.
    • read-modify-write / one-shot: CONFIG를 읽어서 필요한 비트만 바꿔 다시 쓴다(나머지·reserved 비트 보존). OS 비트에 1을 쓰면 변환 1회 시작, 끝나면 STATUS의 DATA_READY가 켜진다(최대 30 ms).
  • 입력: TmpDev *d(addr, cfg = CONFIG 사본, ready), addr, rate(0..3), 출력 포인터 out(0.01 °C), 경보값 high_c100, low_c100(0.01 °C). 시간은 millis()(ms, uint32_t, wrap), 대기는 delay_ms().
  • 출력: 세 함수 모두 0 또는 음수 errno(-EIO, -ETIMEDOUT, -ENODEV, -EINVAL, -ERANGE). tmp_read_c100은 *out에 0.01 °C 단위 온도, tmp_init은 d->cfg에 실제로 쓴 CONFIG 값을 저장.
  • 규칙
    • tmp_init: rate > 3이면 -EINVAL. WHO_AM_I가 0xA1이 아니면 -ENODEV(재시도 없음). CONFIG를 RMW해서 RATE = rate, SD = 1, 나머지 비트 유지, 쓴 값을 d->cfg에 캐시.
    • tmp_read_c100: 초기화 안 됐으면 -ENODEV. CONFIG에 cfg + OS 비트(OR)를 쓰기 → TMP_POLL_MS(5 ms)마다 STATUS 확인 → TMP_TIMEOUT_MS(100 ms) 지나면 -ETIMEDOUT(millis() wrap에도 정확해야 함) → TEMP 2바이트를 한 트랜잭션으로 읽고 tmp_raw_to_c100()(이미 제공)으로 변환.
    • tmp_set_alert: low < high 아니면 -EINVAL. 각 값을 TEMP 형식(12비트, 0.0625 °C/LSB, 왼쪽 정렬)으로 인코딩, 반올림은 0에서 먼 쪽(half away from zero). 12비트에 안 들어가면 -ERANGE. 둘 다 검사한 뒤에 쓰기 시작.
    • 재시도: 모든 버스 전송은 -EIO일 때만 최대 TMP_MAX_RETRIES(3)번 재시도(총 4회). 버스의 -ETIMEDOUT은 즉시 반환. malloc 없음.
  • 예제 풀어 읽기: 가짜 버스는 now = 1000 ms, CONFIG = 0x00, TEMP = 0x1900, 변환 30 ms. tmp_init(&d, 0x48, 2) → 0, CONFIG = 0x05(RATE=2, SD=1), 전송 3번(WHO_AM_I 읽기, CONFIG 읽기, CONFIG 쓰기). tmp_read_c100 → 0, t = 2500(25.00 °C), 전송 9번 = 쓰기 1 + STATUS 폴링 7 + TEMP 읽기 1, 끝난 시각 1030. 처음 CONFIG가 0x7A였다면 init 후 0x7D(POL, TM, reserved 비트 유지). tmp_set_alert(&d, 8000, 7500) → T_HIGH = 0x5000, T_LOW = 0x4B00.
  • 놓치기 쉬운 것: 음수 온도(0xE700 → -2500, 0xFFF0 → -6), rate = 4 → -EINVAL, NACK 1번이면 재시도 후 성공(전송 10번), NACK 3번까지는 성공·계속 NACK면 4번 시도 후 -EIO, bus busy면 전송 1번만 하고 -ETIMEDOUT, WHO_AM_I 틀리면 전송 1번·CONFIG 안 건드림·이후 read도 -ENODEV, DATA_READY가 안 오면 정확히 100 ms 후 타임아웃(5000 → 5100, 쓰기 1 + 폴링 21), 폴링 중 millis() wrap(0xFFFFFFF0에서 시작), 반올림(8010 → 0x5020, -1005 → 0xF5F0), low == high → -EINVAL, 13000(130 °C) → -ERANGE, 잘못된 입력이면 전송 0번. 테스트가 전송 횟수(F.xfers)를 정확히 센다.
  • 구현할 함수
    • tmp_init(d, addr, rate): 칩 확인 + CONFIG RMW + 사본 저장.
    • tmp_read_c100(d, out): one-shot 시작 → 폴링(타임아웃) → TEMP 읽고 변환.
    • tmp_set_alert(d, high_c100, low_c100): 검증 후 T_HIGH / T_LOW 인코딩해서 쓰기.

1. Problem

Write a small driver for a TMP102-like I2C temperature sensor. You only get the HAL below; it is implemented at the bottom of stub.c as a fake bus (a register array with fault injection), so do not touch hardware details, just call the HAL.

/* HAL (provided). Return 0, -EIO (NACK) or -ETIMEDOUT (bus stuck busy). */
int i2c_write(uint8_t addr7, const uint8_t *buf, size_t len);   /* S addr+W buf P            */
int i2c_write_read(uint8_t addr7, const uint8_t *wbuf, size_t wlen,
                   uint8_t *rbuf, size_t rlen);                  /* S addr+W wbuf Sr addr+R rbuf P */
uint32_t millis(void);          /* free-running ms counter, wraps at 2^32 */
void     delay_ms(uint32_t ms); /* busy wait */

typedef struct { uint8_t addr; uint8_t cfg; bool ready; } TmpDev;   /* cfg = shadow of CONFIG */

int tmp_init(TmpDev *d, uint8_t addr, uint8_t rate);
int tmp_read_c100(TmpDev *d, int16_t *out);                 /* 0.01 degC */
int tmp_set_alert(TmpDev *d, int16_t high_c100, int16_t low_c100);

Datasheet excerpt. Device address 0x48. The first byte of every write is the register pointer; a register read is write {reg} + repeated START + read N bytes. Multi-byte registers are MSB first.

RegNameSizeAccessDescription
0x00TEMP2 BRO12-bit two's complement, left-justified (bits 15..4), 0.0625 °C/LSB
0x01CONFIG1 BRWb7 OS one-shot (write 1 to start a conversion, self-clearing) · b6 reserved · b5 POL alert polarity · b4 TM thermostat mode · b3 reserved · b2:1 RATE (0=0.25 Hz, 1=1 Hz, 2=4 Hz, 3=8 Hz) · b0 SD shutdown
0x02T_LOW2 BRWsame format as TEMP
0x03T_HIGH2 BRWsame format as TEMP
0x04STATUS1 BROb0 DATA_READY: set when a conversion finishes, cleared by reading TEMP
0x0FWHO_AM_I1 BROalways 0xA1

Reserved bits must be written back with the value read. One conversion takes up to 30 ms. One-shot mode works while SD = 1.

Requirements:

  • tmp_init: read WHO_AM_I; if it is not 0xA1 return -ENODEV (no retry). Then read-modify-write CONFIG: set RATE = rate and SD = 1, keep every other bit. Cache the written value in d->cfg. rate > 3 → -EINVAL.
  • tmp_read_c100: write CONFIG = cfg | OS; poll STATUS every TMP_POLL_MS (5) until DATA_READY, or return -ETIMEDOUT once TMP_TIMEOUT_MS (100) has elapsed (must be correct when millis() wraps); then read TEMP as 2 bytes in one transaction and convert with the provided tmp_raw_to_c100() (same as T1-5). Not initialized → -ENODEV.
  • tmp_set_alert: require low < high (-EINVAL); encode each threshold to the TEMP format, rounding half away from zero; a value that does not fit 12 bits → -ERANGE. Validate both before writing anything.
  • Retry policy: every bus transfer is retried up to TMP_MAX_RETRIES (3) times on -EIO only (4 attempts total). -ETIMEDOUT from the bus is returned immediately.
  • Return 0 or a negative errno. No malloc, single-threaded.

Example

fake: now = 1000 ms, CONFIG = 0x00, TEMP = 0x1900, conversion = 30 ms

tmp_init(&d, 0x48, 2)   -> 0     CONFIG = 0x05 (RATE=2, SD=1), 3 transfers
tmp_read_c100(&d, &t)   -> 0     t = 2500 (25.00 degC)
                                 9 transfers: 1 write + 7 STATUS polls + 1 TEMP read, now = 1030

CONFIG = 0x7A before init -> after init CONFIG = 0x7D (POL, TM, reserved bits kept)
tmp_set_alert(&d, 8000, 7500) -> 0   T_HIGH = 0x5000, T_LOW = 0x4B00

Constraints

  • C11, single thread, no RTOS. millis() is a uint32_t that wraps.
  • The fake counts every transfer attempt (F.xfers), so retry counts are tested exactly.
  • Error codes come from <errno.h>: EIO, ETIMEDOUT, ENODEV, EINVAL, ERANGE.

Clarifying questions to ask (first 3 minutes)

  1. Is the address 7-bit (0x48) and does the HAL add the R/W bit?
  2. Does a register read need a repeated START, or is STOP + START acceptable on this part?
  3. Which errors are worth retrying? (NACK yes; wrong chip ID no; bus stuck — retry or recover?)
  4. How many retries, and should there be a delay between them?
  5. What is the max conversion time, and what timeout do you want? Is millis() 32-bit and wrapping?
  6. Must reserved CONFIG bits be preserved? Can I keep a shadow copy of CONFIG instead of re-reading it?

/*
 * E1  I2C Temperature Sensor Driver (mock HAL)
 *
 * Write a small driver for a TMP102-like I2C temperature sensor on top of the HAL below.
 * The HAL is implemented at the bottom of this file as a FAKE bus (register array +
 * fault injection). Do not edit the fake; only use the HAL functions.
 *
 *   int i2c_write(addr7, buf, len)                       START addr+W buf[0..len) STOP
 *   int i2c_write_read(addr7, wbuf, wlen, rbuf, rlen)    START addr+W wbuf Sr addr+R rbuf STOP
 *       -> 0 on success, -EIO on NACK, -ETIMEDOUT if the bus is stuck busy
 *   uint32_t millis(void)   free-running ms counter (wraps at 2^32)
 *   void delay_ms(ms)       busy-wait (advances the fake clock)
 *
 * Register map (device address 0x48, register pointer = first written byte):
 *   0x00 TEMP     2 B  RO  12-bit two's complement, left-justified, MSB first, 0.0625 degC/LSB
 *   0x01 CONFIG   1 B  RW  b7 OS (one-shot, self-clearing) | b6 reserved | b5 POL | b4 TM |
 *                          b3 reserved | b2:1 RATE | b0 SD (shutdown)
 *   0x02 T_LOW    2 B  RW  same format as TEMP
 *   0x03 T_HIGH   2 B  RW  same format as TEMP
 *   0x04 STATUS   1 B  RO  b0 DATA_READY (set when a conversion finishes, cleared by reading TEMP)
 *   0x0F WHO_AM_I 1 B  RO  always 0xA1
 *
 * Implement:
 *   tmp_init      check WHO_AM_I (-ENODEV if wrong, no retry); read-modify-write CONFIG:
 *                 set RATE = rate and SD = 1, keep every other bit; cache CONFIG in d->cfg.
 *                 rate > 3 -> -EINVAL.
 *   tmp_read_c100 one-shot: write CONFIG with OS=1, poll STATUS.DATA_READY every TMP_POLL_MS
 *                 until it is set or TMP_TIMEOUT_MS has elapsed (-ETIMEDOUT; wrap-safe),
 *                 then burst-read TEMP (2 bytes, one transaction) and convert to 0.01 degC.
 *   tmp_set_alert encode thresholds (0.01 degC -> register, round half away from zero),
 *                 require low < high (-EINVAL), each must fit 12 bits (-ERANGE).
 *   Retry policy: every bus transfer is retried up to TMP_MAX_RETRIES times on -EIO only.
 *                 -ETIMEDOUT from the bus is returned immediately. Return 0 or -errno.
 *
 * Build & run:  ./run.sh E1
 */

/* ---------------- device definitions (from the datasheet) ---------------- */
#define TMP_ADDR_DEFAULT  0x48u
#define REG_TEMP          0x00u
#define REG_CONFIG        0x01u
#define REG_T_LOW         0x02u
#define REG_T_HIGH        0x03u
#define REG_STATUS        0x04u
#define REG_WHO_AM_I      0x0Fu
#define WHO_AM_I_VAL      0xA1u

#define CFG_SD            (1u << 0)
#define CFG_RATE_SHIFT    1
#define CFG_RATE_MASK     (3u << CFG_RATE_SHIFT)
#define CFG_POL           (1u << 5)
#define CFG_OS            (1u << 7)
#define STATUS_DRDY       (1u << 0)

#define TMP_MAX_RETRIES   3      /* retries after the first attempt, -EIO only */
#define TMP_POLL_MS       5
#define TMP_TIMEOUT_MS    100

/* Provided helper (same as T1-5): two TEMP-format bytes -> 0.01 degC, half away from 0. */
static int16_t tmp_raw_to_c100(uint8_t msb, uint8_t lsb)
{
    int16_t s16 = (int16_t)(uint16_t)(((uint16_t)msb << 8) | (lsb & 0xF0u));
    int32_t num = (int32_t)(s16 / 16) * 625;
    return (int16_t)((num >= 0) ? (num + 50) / 100 : (num - 50) / 100);
}

/* =====================================================================
 * Test harness: fake I2C bus + fake clock (do not edit)
 * ===================================================================== */
static struct {
    uint16_t reg[16];        /* register file; 1-byte regs use the low byte */
    uint32_t now;            /* fake millis() */
    uint32_t xfers;          /* transfers attempted (1-based index of the last one) */
    uint32_t nack_at, nack_len;  /* transfers nack_at .. nack_at+nack_len-1 NACK */
    bool     busy;           /* bus stuck: every transfer -> -ETIMEDOUT */
    bool     drdy_never;     /* conversion never completes */
    uint32_t conv_ms;        /* conversion time */
    bool     conv_pending, drdy;
    uint32_t conv_start;
} F;

static size_t reg_width(uint8_t r) { return (r == REG_TEMP || r == REG_T_LOW || r == REG_T_HIGH) ? 2 : 1; }

static void fake_reset(uint32_t now, uint8_t config)
{
    memset(&F, 0, sizeof F);
    F.now = now;
    F.conv_ms = 30;
    F.reg[REG_CONFIG] = config;
    F.reg[REG_WHO_AM_I] = WHO_AM_I_VAL;
    F.reg[REG_TEMP] = 0x1900;            /* 25.0 degC */
}

static int fake_begin(uint8_t addr7)
{
    F.xfers++;
    if (F.busy) return -ETIMEDOUT;
    if (F.nack_len && F.xfers >= F.nack_at && F.xfers - F.nack_at < F.nack_len) return -EIO;
    if (addr7 != TMP_ADDR_DEFAULT) return -EIO;
    return 0;
}

uint32_t millis(void) { return F.now; }
void delay_ms(uint32_t ms) { F.now += ms; }

int i2c_write(uint8_t addr7, const uint8_t *buf, size_t len)
{
    int rc = fake_begin(addr7);
    if (rc) return rc;
    if (len < 1 || buf[0] > 0x0F) return -EIO;
    uint8_t r = buf[0];
    if (len == 1) return 0;                          /* pointer-only write */
    if (len - 1 != reg_width(r)) return -EIO;        /* device NACKs a wrong length */
    uint16_t v = (reg_width(r) == 2) ? (uint16_t)((buf[1] << 8) | buf[2]) : buf[1];
    if (r == REG_CONFIG) {
        if (v & CFG_OS) { F.conv_pending = true; F.conv_start = F.now; F.drdy = false; }
        F.reg[r] = (uint16_t)(v & ~CFG_OS);          /* OS self-clears */
    } else if (r == REG_T_LOW || r == REG_T_HIGH) {
        F.reg[r] = v;
    }                                                /* RO registers ignore writes */
    return 0;
}

int i2c_write_read(uint8_t addr7, const uint8_t *wbuf, size_t wlen, uint8_t *rbuf, size_t rlen)
{
    int rc = fake_begin(addr7);
    if (rc) return rc;
    if (wlen != 1 || wbuf[0] > 0x0F || rlen < 1 || rlen > reg_width(wbuf[0])) return -EIO;
    uint8_t r = wbuf[0];
    if (r == REG_STATUS) {
        if (F.conv_pending && !F.drdy_never && F.now - F.conv_start >= F.conv_ms) {
            F.conv_pending = false; F.drdy = true;
        }
        F.reg[REG_STATUS] = F.drdy ? STATUS_DRDY : 0;
    }
    uint16_t v = F.reg[r];
    if (reg_width(r) == 2) { rbuf[0] = (uint8_t)(v >> 8); if (rlen > 1) rbuf[1] = (uint8_t)v; }
    else rbuf[0] = (uint8_t)v;
    if (r == REG_TEMP) F.drdy = false;               /* reading TEMP clears DATA_READY */
    return 0;
}

int main(void)
{
    TmpDev d = {0};
    int16_t t = 0;

    /* 1. normal init + one-shot read (25.0 degC); count transfers and elapsed time */
    fake_reset(1000, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    CHECK(F.xfers == 3);                               /* WHO_AM_I, CONFIG read, CONFIG write */
    CHECK(F.reg[REG_CONFIG] == 0x05);                  /* RATE=2, SD=1 */
    F.xfers = 0;
    CHECK(tmp_read_c100(&d, &t) == 0 && t == 2500);
    CHECK(F.xfers == 9 && F.now == 1030);              /* 1 write + 7 STATUS polls + 1 TEMP */
    CHECK(F.reg[REG_CONFIG] == 0x05);                  /* OS bit self-cleared */

    /* 2. negative temperatures */
    F.reg[REG_TEMP] = 0xE700;                          /* -25.0 degC */
    CHECK(tmp_read_c100(&d, &t) == 0 && t == -2500);
    F.reg[REG_TEMP] = 0xFFF0;                          /* -0.0625 degC */
    CHECK(tmp_read_c100(&d, &t) == 0 && t == -6);

    /* 3. read-modify-write keeps POL, TM and reserved bits */
    fake_reset(0, 0x7A);                               /* POL|TM|res|res, RATE=1, SD=0 */
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    CHECK(F.reg[REG_CONFIG] == 0x7D && d.cfg == 0x7D);
    CHECK(tmp_init(&d, 0x48, 4) == -EINVAL);

    /* 4. NACK once -> retried, read still succeeds */
    fake_reset(0, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    F.xfers = 0; F.nack_at = 1; F.nack_len = 1;        /* the one-shot write NACKs once */
    CHECK(tmp_read_c100(&d, &t) == 0 && t == 2500);
    CHECK(F.xfers == 10);

    /* 5. NACK 3 times -> still OK (3 retries); NACK forever -> -EIO after 1 + 3 attempts */
    fake_reset(0, 0x00); F.nack_at = 1; F.nack_len = 3;
    CHECK(tmp_init(&d, 0x48, 2) == 0 && F.xfers == 6);
    fake_reset(0, 0x00); F.nack_at = 1; F.nack_len = 1000;
    CHECK(tmp_init(&d, 0x48, 2) == -EIO && F.xfers == 4);

    /* 6. bus stuck busy -> -ETIMEDOUT immediately, no retry */
    fake_reset(0, 0x00); F.busy = true;
    CHECK(tmp_init(&d, 0x48, 2) == -ETIMEDOUT && F.xfers == 1);

    /* 7. wrong WHO_AM_I -> -ENODEV, no retry, CONFIG untouched */
    fake_reset(0, 0x00); F.reg[REG_WHO_AM_I] = 0x75;
    CHECK(tmp_init(&d, 0x48, 2) == -ENODEV && F.xfers == 1);
    CHECK(tmp_read_c100(&d, &t) == -ENODEV);

    /* 8. DATA_READY never set -> -ETIMEDOUT after exactly TMP_TIMEOUT_MS */
    fake_reset(5000, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    F.drdy_never = true; F.xfers = 0;
    CHECK(tmp_read_c100(&d, &t) == -ETIMEDOUT);
    CHECK(F.now == 5100 && F.xfers == 22);             /* 1 write + 21 STATUS polls */

    /* 9. millis() wraps during the poll: must not time out early ... */
    fake_reset(0xFFFFFFF0u, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    F.reg[REG_TEMP] = 0x5000;                          /* 80.0 degC */
    CHECK(tmp_read_c100(&d, &t) == 0 && t == 8000);
    CHECK(F.now == 0x0000000Eu);                       /* 0xFFFFFFF0 + 30 */
    /* ... and must still time out after 100 ms across the wrap */
    fake_reset(0xFFFFFFC0u, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    F.drdy_never = true;
    CHECK(tmp_read_c100(&d, &t) == -ETIMEDOUT && F.now == 0x00000024u);

    /* 10. alert thresholds: encode, round-trip, validation */
    fake_reset(0, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    CHECK(tmp_set_alert(&d, 8000, 7500) == 0);
    CHECK(F.reg[REG_T_HIGH] == 0x5000 && F.reg[REG_T_LOW] == 0x4B00);
    CHECK(tmp_set_alert(&d, 8010, -1005) == 0);
    CHECK(F.reg[REG_T_HIGH] == 0x5020 && F.reg[REG_T_LOW] == 0xF5F0);
    CHECK(tmp_raw_to_c100(0x50, 0x20) == 8013 && tmp_raw_to_c100(0xF5, 0xF0) == -1006);
    F.xfers = 0;
    CHECK(tmp_set_alert(&d, 7500, 7500) == -EINVAL);   /* low must be < high */
    CHECK(tmp_set_alert(&d, 13000, 0) == -ERANGE);     /* 130 degC > 127.9375 */
    CHECK(F.xfers == 0);                               /* nothing written on bad input */

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

3. 힌트 (막힐 때 하나씩)

Hint 1 — 재시도는 함수 두 개에 가둔다

reg_read(d, reg, buf, n) / reg_write(d, buf, n) 헬퍼를 먼저 만듭니다. 안에서 for (attempt = 0; attempt <= 3; attempt++) 돌며 rc != -EIO면 바로 빠져나옵니다. 그러면 나머지 코드에는 재시도 로직이 한 줄도 없고, -ETIMEDOUT/-ENODEV는 자동으로 재시도 대상에서 빠집니다.

Hint 2 — RMW는 "내 필드만 지우고, 내 필드만 쓴다"

v &= ~(RATE_MASK | SD | OS); v |= (rate << 1) | SD; 순서입니다. OS도 지우는 이유: 읽은 값에 OS가 1로 보이는 칩도 있고, 그대로 쓰면 원치 않는 변환이 시작됩니다. 쓴 값은 d->cfg에 저장해 두면 읽기 때마다 CONFIG를 다시 읽지 않아도 됩니다(shadow register).

Hint 3 — 타임아웃은 "경과 시간"으로 비교

if ((uint32_t)(millis() - t0) >= TMP_TIMEOUT_MS). millis() > t0 + 100은 t0가 0xFFFFFFF0일 때 t0 + 100 = 0x54로 넘쳐서 첫 폴링에 바로 타임아웃이 납니다(테스트 9번).

4. 풀이

4.1 핵심 아이디어 — 버스 위에서 일어나는 일

레지스터 읽기 한 번은 I2C 프레임 하나입니다. 먼저 "쓰기"로 레지스터 포인터를 0x00에 맞추고, STOP 없이 repeated START(Sr)로 방향을 바꿔 2바이트를 읽습니다. 마지막 바이트에 마스터가 NACK을 보내야 슬레이브가 SDA를 놓습니다.

MSB와 LSB를 한 트랜잭션으로 읽어야 하는 이유: 따로 읽으면 그 사이에 변환이 끝나 MSB는 옛 값, LSB는 새 값인 "찢어진(torn)" 값이 나올 수 있습니다. 대부분 센서는 burst read 동안 출력 레지스터를 잠급니다.

/*
 * E1  I2C Temperature Sensor Driver (mock HAL)
 *
 * Write a small driver for a TMP102-like I2C temperature sensor on top of the HAL below.
 * The HAL is implemented at the bottom of this file as a FAKE bus (register array +
 * fault injection). Do not edit the fake; only use the HAL functions.
 *
 *   int i2c_write(addr7, buf, len)                       START addr+W buf[0..len) STOP
 *   int i2c_write_read(addr7, wbuf, wlen, rbuf, rlen)    START addr+W wbuf Sr addr+R rbuf STOP
 *       -> 0 on success, -EIO on NACK, -ETIMEDOUT if the bus is stuck busy
 *   uint32_t millis(void)   free-running ms counter (wraps at 2^32)
 *   void delay_ms(ms)       busy-wait (advances the fake clock)
 *
 * Register map (device address 0x48, register pointer = first written byte):
 *   0x00 TEMP     2 B  RO  12-bit two's complement, left-justified, MSB first, 0.0625 degC/LSB
 *   0x01 CONFIG   1 B  RW  b7 OS (one-shot, self-clearing) | b6 reserved | b5 POL | b4 TM |
 *                          b3 reserved | b2:1 RATE | b0 SD (shutdown)
 *   0x02 T_LOW    2 B  RW  same format as TEMP
 *   0x03 T_HIGH   2 B  RW  same format as TEMP
 *   0x04 STATUS   1 B  RO  b0 DATA_READY (set when a conversion finishes, cleared by reading TEMP)
 *   0x0F WHO_AM_I 1 B  RO  always 0xA1
 *
 * Implement:
 *   tmp_init      check WHO_AM_I (-ENODEV if wrong, no retry); read-modify-write CONFIG:
 *                 set RATE = rate and SD = 1, keep every other bit; cache CONFIG in d->cfg.
 *                 rate > 3 -> -EINVAL.
 *   tmp_read_c100 one-shot: write CONFIG with OS=1, poll STATUS.DATA_READY every TMP_POLL_MS
 *                 until it is set or TMP_TIMEOUT_MS has elapsed (-ETIMEDOUT; wrap-safe),
 *                 then burst-read TEMP (2 bytes, one transaction) and convert to 0.01 degC.
 *   tmp_set_alert encode thresholds (0.01 degC -> register, round half away from zero),
 *                 require low < high (-EINVAL), each must fit 12 bits (-ERANGE).
 *   Retry policy: every bus transfer is retried up to TMP_MAX_RETRIES times on -EIO only.
 *                 -ETIMEDOUT from the bus is returned immediately. Return 0 or -errno.
 *
 * Reference solution.  Build & run:  ./run.sh E1 sol
 */
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>
#include <errno.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

/* ---------------- HAL (provided) ---------------- */
int i2c_write(uint8_t addr7, const uint8_t *buf, size_t len);
int i2c_write_read(uint8_t addr7, const uint8_t *wbuf, size_t wlen, uint8_t *rbuf, size_t rlen);
uint32_t millis(void);
void delay_ms(uint32_t ms);

/* ---------------- device definitions (from the datasheet) ---------------- */
#define TMP_ADDR_DEFAULT  0x48u
#define REG_TEMP          0x00u
#define REG_CONFIG        0x01u
#define REG_T_LOW         0x02u
#define REG_T_HIGH        0x03u
#define REG_STATUS        0x04u
#define REG_WHO_AM_I      0x0Fu
#define WHO_AM_I_VAL      0xA1u

#define CFG_SD            (1u << 0)
#define CFG_RATE_SHIFT    1
#define CFG_RATE_MASK     (3u << CFG_RATE_SHIFT)
#define CFG_POL           (1u << 5)
#define CFG_OS            (1u << 7)
#define STATUS_DRDY       (1u << 0)

#define TMP_MAX_RETRIES   3      /* retries after the first attempt, -EIO only */
#define TMP_POLL_MS       5
#define TMP_TIMEOUT_MS    100

typedef struct {
    uint8_t addr;     /* 7-bit address */
    uint8_t cfg;      /* shadow copy of CONFIG (OS bit always 0 here) */
    bool    ready;    /* tmp_init succeeded */
} TmpDev;

/* Provided helper (same as T1-5): two TEMP-format bytes -> 0.01 degC, half away from 0. */
static int16_t tmp_raw_to_c100(uint8_t msb, uint8_t lsb)
{
    int16_t s16 = (int16_t)(uint16_t)(((uint16_t)msb << 8) | (lsb & 0xF0u));
    int32_t num = (int32_t)(s16 / 16) * 625;
    return (int16_t)((num >= 0) ? (num + 50) / 100 : (num - 50) / 100);
}

/* ---------------- driver: your code ---------------- */

/* One register read with the retry policy. */
static int reg_read(const TmpDev *d, uint8_t reg, uint8_t *buf, size_t n)
{
    int rc = -EIO;
    for (int attempt = 0; attempt <= TMP_MAX_RETRIES; attempt++) {
        rc = i2c_write_read(d->addr, &reg, 1, buf, n);
        if (rc != -EIO) break;              /* 0 or -ETIMEDOUT: do not retry */
    }
    return rc;
}

/* One register write: buf = { reg, data... }. Writes here are idempotent, so retry is safe. */
static int reg_write(const TmpDev *d, const uint8_t *buf, size_t n)
{
    int rc = -EIO;
    for (int attempt = 0; attempt <= TMP_MAX_RETRIES; attempt++) {
        rc = i2c_write(d->addr, buf, n);
        if (rc != -EIO) break;
    }
    return rc;
}

int tmp_init(TmpDev *d, uint8_t addr, uint8_t rate)
{
    if (d == NULL || rate > 3) return -EINVAL;
    d->addr = addr;
    d->ready = false;

    uint8_t v;
    int rc = reg_read(d, REG_WHO_AM_I, &v, 1);
    if (rc) return rc;
    if (v != WHO_AM_I_VAL) return -ENODEV;          /* wrong chip: retrying will not help */

    rc = reg_read(d, REG_CONFIG, &v, 1);             /* read ...   */
    if (rc) return rc;
    v &= (uint8_t)~(CFG_RATE_MASK | CFG_SD | CFG_OS);   /* ... modify: clear only our fields */
    v |= (uint8_t)((rate << CFG_RATE_SHIFT) | CFG_SD);
    uint8_t w[2] = { REG_CONFIG, v };
    rc = reg_write(d, w, sizeof w);                  /* ... write  */
    if (rc) return rc;

    d->cfg = v;
    d->ready = true;
    return 0;
}

int tmp_read_c100(TmpDev *d, int16_t *out)
{
    if (d == NULL || out == NULL) return -EINVAL;
    if (!d->ready) return -ENODEV;

    uint8_t w[2] = { REG_CONFIG, (uint8_t)(d->cfg | CFG_OS) };   /* start one conversion */
    int rc = reg_write(d, w, sizeof w);
    if (rc) return rc;

    uint32_t t0 = millis();
    for (;;) {
        uint8_t st;
        rc = reg_read(d, REG_STATUS, &st, 1);
        if (rc) return rc;
        if (st & STATUS_DRDY) break;
        if ((uint32_t)(millis() - t0) >= TMP_TIMEOUT_MS)   /* wrap-safe: compare elapsed */
            return -ETIMEDOUT;
        delay_ms(TMP_POLL_MS);
    }

    uint8_t b[2];
    rc = reg_read(d, REG_TEMP, b, 2);     /* MSB+LSB in ONE transaction: no tearing */
    if (rc) return rc;
    *out = tmp_raw_to_c100(b[0], b[1]);
    return 0;
}

/* 0.01 degC -> 12-bit counts (0.0625 degC), round half away from zero. */
static int encode_c100(int16_t c100, uint8_t *msb, uint8_t *lsb)
{
    int32_t num = (int32_t)c100 * 16;                        /* counts * 100 */
    int32_t counts = (num >= 0) ? (num + 50) / 100 : (num - 50) / 100;
    if (counts < -2048 || counts > 2047) return -ERANGE;
    uint16_t reg = (uint16_t)((uint32_t)counts << 4);       /* left-justify, no signed shift */
    *msb = (uint8_t)(reg >> 8);
    *lsb = (uint8_t)(reg & 0xFFu);
    return 0;
}

int tmp_set_alert(TmpDev *d, int16_t high_c100, int16_t low_c100)
{
    if (d == NULL) return -EINVAL;
    if (!d->ready) return -ENODEV;
    if (low_c100 >= high_c100) return -EINVAL;

    uint8_t hi[3] = { REG_T_HIGH, 0, 0 }, lo[3] = { REG_T_LOW, 0, 0 };
    if (encode_c100(high_c100, &hi[1], &hi[2]) || encode_c100(low_c100, &lo[1], &lo[2]))
        return -ERANGE;                                     /* validate both before writing */

    int rc = reg_write(d, hi, sizeof hi);
    if (rc) return rc;
    return reg_write(d, lo, sizeof lo);
}

/* =====================================================================
 * Test harness: fake I2C bus + fake clock (do not edit)
 * ===================================================================== */
static struct {
    uint16_t reg[16];        /* register file; 1-byte regs use the low byte */
    uint32_t now;            /* fake millis() */
    uint32_t xfers;          /* transfers attempted (1-based index of the last one) */
    uint32_t nack_at, nack_len;  /* transfers nack_at .. nack_at+nack_len-1 NACK */
    bool     busy;           /* bus stuck: every transfer -> -ETIMEDOUT */
    bool     drdy_never;     /* conversion never completes */
    uint32_t conv_ms;        /* conversion time */
    bool     conv_pending, drdy;
    uint32_t conv_start;
} F;

static size_t reg_width(uint8_t r) { return (r == REG_TEMP || r == REG_T_LOW || r == REG_T_HIGH) ? 2 : 1; }

static void fake_reset(uint32_t now, uint8_t config)
{
    memset(&F, 0, sizeof F);
    F.now = now;
    F.conv_ms = 30;
    F.reg[REG_CONFIG] = config;
    F.reg[REG_WHO_AM_I] = WHO_AM_I_VAL;
    F.reg[REG_TEMP] = 0x1900;            /* 25.0 degC */
}

static int fake_begin(uint8_t addr7)
{
    F.xfers++;
    if (F.busy) return -ETIMEDOUT;
    if (F.nack_len && F.xfers >= F.nack_at && F.xfers - F.nack_at < F.nack_len) return -EIO;
    if (addr7 != TMP_ADDR_DEFAULT) return -EIO;
    return 0;
}

uint32_t millis(void) { return F.now; }
void delay_ms(uint32_t ms) { F.now += ms; }

int i2c_write(uint8_t addr7, const uint8_t *buf, size_t len)
{
    int rc = fake_begin(addr7);
    if (rc) return rc;
    if (len < 1 || buf[0] > 0x0F) return -EIO;
    uint8_t r = buf[0];
    if (len == 1) return 0;                          /* pointer-only write */
    if (len - 1 != reg_width(r)) return -EIO;        /* device NACKs a wrong length */
    uint16_t v = (reg_width(r) == 2) ? (uint16_t)((buf[1] << 8) | buf[2]) : buf[1];
    if (r == REG_CONFIG) {
        if (v & CFG_OS) { F.conv_pending = true; F.conv_start = F.now; F.drdy = false; }
        F.reg[r] = (uint16_t)(v & ~CFG_OS);          /* OS self-clears */
    } else if (r == REG_T_LOW || r == REG_T_HIGH) {
        F.reg[r] = v;
    }                                                /* RO registers ignore writes */
    return 0;
}

int i2c_write_read(uint8_t addr7, const uint8_t *wbuf, size_t wlen, uint8_t *rbuf, size_t rlen)
{
    int rc = fake_begin(addr7);
    if (rc) return rc;
    if (wlen != 1 || wbuf[0] > 0x0F || rlen < 1 || rlen > reg_width(wbuf[0])) return -EIO;
    uint8_t r = wbuf[0];
    if (r == REG_STATUS) {
        if (F.conv_pending && !F.drdy_never && F.now - F.conv_start >= F.conv_ms) {
            F.conv_pending = false; F.drdy = true;
        }
        F.reg[REG_STATUS] = F.drdy ? STATUS_DRDY : 0;
    }
    uint16_t v = F.reg[r];
    if (reg_width(r) == 2) { rbuf[0] = (uint8_t)(v >> 8); if (rlen > 1) rbuf[1] = (uint8_t)v; }
    else rbuf[0] = (uint8_t)v;
    if (r == REG_TEMP) F.drdy = false;               /* reading TEMP clears DATA_READY */
    return 0;
}

int main(void)
{
    TmpDev d = {0};
    int16_t t = 0;

    /* 1. normal init + one-shot read (25.0 degC); count transfers and elapsed time */
    fake_reset(1000, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    CHECK(F.xfers == 3);                               /* WHO_AM_I, CONFIG read, CONFIG write */
    CHECK(F.reg[REG_CONFIG] == 0x05);                  /* RATE=2, SD=1 */
    F.xfers = 0;
    CHECK(tmp_read_c100(&d, &t) == 0 && t == 2500);
    CHECK(F.xfers == 9 && F.now == 1030);              /* 1 write + 7 STATUS polls + 1 TEMP */
    CHECK(F.reg[REG_CONFIG] == 0x05);                  /* OS bit self-cleared */

    F.reg[REG_TEMP] = 0xE700;                          /* -25.0 degC */
    CHECK(tmp_read_c100(&d, &t) == 0 && t == -2500);
    F.reg[REG_TEMP] = 0xFFF0;                          /* -0.0625 degC */

    CHECK(F.reg[REG_CONFIG] == 0x7D && d.cfg == 0x7D);

    fake_reset(0, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    F.xfers = 0; F.nack_at = 1; F.nack_len = 1;        /* the one-shot write NACKs once */
    CHECK(tmp_read_c100(&d, &t) == 0 && t == 2500);
    CHECK(F.xfers == 10);

    fake_reset(0, 0x00); F.nack_at = 1; F.nack_len = 3;

    fake_reset(5000, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    F.drdy_never = true; F.xfers = 0;
    CHECK(tmp_read_c100(&d, &t) == -ETIMEDOUT);
    CHECK(F.now == 5100 && F.xfers == 22);             /* 1 write + 21 STATUS polls */

    /* 9. millis() wraps during the poll: must not time out early ... */
    fake_reset(0xFFFFFFF0u, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    F.reg[REG_TEMP] = 0x5000;                          /* 80.0 degC */
    CHECK(tmp_read_c100(&d, &t) == 0 && t == 8000);
    CHECK(F.now == 0x0000000Eu);                       /* 0xFFFFFFF0 + 30 */
    /* ... and must still time out after 100 ms across the wrap */
    fake_reset(0xFFFFFFC0u, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    F.drdy_never = true;
    CHECK(tmp_read_c100(&d, &t) == -ETIMEDOUT && F.now == 0x00000024u);

    /* 10. alert thresholds: encode, round-trip, validation */
    fake_reset(0, 0x00);
    CHECK(tmp_init(&d, 0x48, 2) == 0);
    CHECK(tmp_set_alert(&d, 8000, 7500) == 0);
    CHECK(F.reg[REG_T_HIGH] == 0x5000 && F.reg[REG_T_LOW] == 0x4B00);
    CHECK(tmp_set_alert(&d, 8010, -1005) == 0);
    CHECK(F.reg[REG_T_HIGH] == 0x5020 && F.reg[REG_T_LOW] == 0xF5F0);
    CHECK(tmp_raw_to_c100(0x50, 0x20) == 8013 && tmp_raw_to_c100(0xF5, 0xF0) == -1006);
    F.xfers = 0;
    CHECK(tmp_set_alert(&d, 7500, 7500) == -EINVAL);   /* low must be < high */
    CHECK(tmp_set_alert(&d, 13000, 0) == -ERANGE);     /* 130 degC > 127.9375 */
    CHECK(F.xfers == 0);                               /* nothing written on bad input */

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

코드 읽는 포인트

  • 재시도는 reg_read / reg_write 두 곳에만 있습니다. 조건은 rc != -EIO면 탈출 — 그래서 -ETIMEDOUT, 성공(0)은 바로 나갑니다. -ENODEV는 버스 에러가 아니라 데이터 검사 결과라 헬퍼 밖에서 판단하고, 재시도하지 않습니다.
  • 쓰기 재시도가 안전한 이유: CONFIG/T_HIGH/T_LOW 쓰기는 멱등(idempotent) 입니다. FIFO push나 "읽으면 클리어" 레지스터처럼 부작용이 있는 접근은 무조건 재시도하면 안 됩니다(§6).
  • 폴링 루프는 "읽기 → 확인 → 타임아웃 검사 → delay" 순서입니다. 그래서 정확히 100 ms 지점에서 마지막으로 한 번 더 읽어 보고 포기합니다(STATUS 21번).
  • encode_c100에서 counts << 4를 (uint32_t)counts << 4로 합니다. 음수의 왼쪽 시프트는 C에서 UB라서 UBSan이 잡습니다.
  • tmp_set_alert은 두 값을 먼저 모두 검증한 뒤 씁니다. T_HIGH만 써지고 T_LOW에서 실패하면 하드웨어가 반쯤 바뀐 상태가 됩니다.

4.6 복잡도

  • 시간: 읽기 1회당 전송 2 + ⌈변환시간 / 5 ms⌉ + 1번(정상 9번), 최악 1 + 21번 + 재시도. CPU는 delay_ms 동안 바쁜 대기.
  • 메모리: O(1). 스택 버퍼 2–3바이트, 장치 상태는 TmpDev 3바이트.

5. 임베디드 관점으로 말할 것

  • Shadow register: d->cfg에 CONFIG를 들고 있으면 one-shot마다 RMW(전송 2번)가 아니라 쓰기 1번이면 됩니다. 단, 다른 코드가 같은 레지스터를 만지면 shadow가 틀어지므로 "이 드라이버만 CONFIG를 소유한다"를 전제로 말합니다.
  • 바쁜 대기 vs 인터럽트: 실제 보드에서는 delay_ms 폴링 대신 ALERT/DRDY 핀 인터럽트나 RTOS vTaskDelay로 CPU를 양보합니다. 30분 면접에서는 폴링으로 짜고 "실제라면 DRDY 인터럽트 + 세마포어"라고 한 줄 말하면 충분합니다 → E3.
  • Bus recovery (9 clocks): 슬레이브가 바이트 중간에 리셋 없이 멈추면 SDA를 0으로 잡고 있어 마스터가 START를 못 겁니다(HAL의 -ETIMEDOUT). 표준 복구는 SCL을 GPIO로 바꿔 최대 9번 토글(슬레이브가 남은 비트를 내보내고 NACK을 보게 함) → STOP 생성 → I2C 주변장치 재초기화입니다. 이것이 버스 timeout을 재시도하지 않고 위로 올리는 이유입니다: 재시도해도 안 풀리고, 복구는 버스 소유자(HAL 계층)의 일입니다.
  • Linux로 옮기면: 같은 칩은 struct i2c_driver(.probe, of_match_table의 compatible = "vendor,tmp-e1")로 등록하고, 레지스터 접근은 직접 i2c_smbus_* 대신 regmap(devm_regmap_init_i2c)을 씁니다. regmap은 regmap_update_bits()(= 이 문제의 RMW), 레지스터 캐시(= shadow), regmap_read_poll_timeout()(= DRDY 폴링)을 이미 제공합니다. 사용자 인터페이스는 단순 온도면 hwmon(temp1_input은 밀리도 단위, temp1_max/temp1_min이 T_HIGH/T_LOW), 샘플링·버퍼·트리거가 필요하면 IIO(in_temp_raw + in_temp_scale = 62.5)를 고릅니다. 실제 TMP102는 커널 drivers/hwmon/tmp102.c에 regmap + hwmon으로 들어 있습니다.
  • 에러 코드 관례: Linux I2C 컨트롤러는 주소 NACK을 보통 -ENXIO/-EREMOTEIO, arbitration lost를 -EAGAIN으로 돌려줍니다. 이 문제는 단순화해서 -EIO 하나로 둡니다.

6. Follow-up 질문과 답

Follow-up (English)답
Why not retry on -ETIMEDOUT too?버스가 SDA low로 붙어 있으면 같은 전송을 다시 해도 똑같이 실패합니다. 위 계층에서 bus recovery(9 clocks + STOP)를 한 다음에 재시도해야 의미가 있습니다.
Should there be a delay or backoff between retries?네, 실제로는 짧은 delay(예: 1 ms)를 둡니다. 슬레이브가 내부 처리(EEPROM 쓰기 등) 중이라 NACK하는 경우가 흔하기 때문입니다. 테스트 숫자를 단순하게 두려고 생략했습니다.
Is it always safe to retry a transfer?아닙니다. 읽으면 클리어되는 STATUS, FIFO pop/push처럼 부작용이 있는 레지스터는 "슬레이브는 받았지만 마지막 ACK만 깨진" 경우 두 번 실행됩니다. 멱등 접근만 자동 재시도합니다.
What if the timeout must be shorter than the poll interval?폴링 간격을 min(TMP_POLL_MS, timeout - elapsed)로 줄입니다. 또는 DRDY 핀 인터럽트를 쓰고 세마포어 대기에 타임아웃을 줍니다.
How would you make this non-blocking?상태 머신으로 바꿉니다: IDLE → START_SENT → POLLING → DONE/ERROR. tmp_poll()을 주기 태스크가 부르고, 끝나면 콜백이나 플래그로 알립니다.
Two tasks call tmp_read_c100 at once (RTOS)?버스와 TmpDev를 mutex로 보호합니다. 같은 I2C 버스의 다른 장치 드라이버와도 버스 락을 공유해야 하고, ISR에서는 이 함수를 부르면 안 됩니다(블로킹).
How would this look in Linux?i2c_driver + regmap + hwmon(또는 IIO). §5 참고.
How do you test this without hardware?지금처럼 HAL 뒤에 fake를 둡니다(link seam). NACK/stuck/WHO_AM_I/DRDY를 주입하고 전송 횟수와 시각을 검증합니다. 하드웨어에서는 로직 분석기로 프레임을 확인합니다.

7. 자주 하는 실수

  • CONFIG에 그냥 (rate << 1) | SD를 씀 → POL·TM·reserved 비트 소실 (테스트 3번)
  • 타임아웃을 millis() > t0 + TIMEOUT으로 비교 → 랩어라운드에서 즉시 타임아웃 (테스트 9번)
  • 재시도 횟수 off-by-one: "3번 재시도"는 총 4번 시도입니다 (테스트 5번: NACK 3번은 성공, 계속 NACK이면 전송 4번)
  • WHO_AM_I가 틀렸는데도 재시도하거나, -ETIMEDOUT까지 재시도함 (테스트 6, 7번)
  • TEMP를 1바이트씩 두 번 읽음 → torn read 위험 + 전송 횟수가 맞지 않음
  • 임계값 두 개 중 하나를 쓴 다음에 검증 실패를 발견함 → 반쯤 바뀐 하드웨어 상태 (테스트 10번: 잘못된 입력이면 전송 0번)
  • 음수 counts << 4 → UB. (uint32_t)로 바꾼 뒤 시프트하거나 * 16
