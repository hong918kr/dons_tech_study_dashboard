D · Debug Drills

IDD1–D8
PriorityP0
Patternfind the bug in 1 minute
Time15 min

파일: buggy.c(버그 8개 + 테스트) · fixed.c(정답) · 실행: ./run.sh D buggy / ./run.sh D fixed / 내 수정본 ./run.sh D my

1. Problem

The interviewer pastes a short firmware function and asks: "What is wrong with this code?" You get about one minute per snippet.

For each of the eight drills below:

  1. Read the intended behavior.
  2. Name the bug in one sentence, and say which input triggers it.
  3. Write the fixed line.
  4. Say how you would have caught it (compiler warning, sanitizer, a unit test, a scope trace).

All eight functions live in buggy.c, together with a test main() that exposes every bug without crashing or hanging. Your job is to make it print ALL PASS.

DrillFunctionTopic
D1avg()average of int16_t samples
D2timed_out()timeout on a 32-bit tick counter
D3push()ring buffer push
D4process_reverse()loop from the last element to the first
D5decode_temp12()12-bit two's-complement sensor register
D6task() + TEMP_IRQHandler()counter shared with an ISR
D7clear()zero a struct
D8deb_update()debounced overheat detection

Constraints

  • Change only the function bodies (and, for D6, the declaration of the shared variable).
  • Keep the lines marked TEST GUARD and the simulation helpers (irq_window, irq_disable, irq_enable) as they are; they only exist so the test cannot hang or write out of bounds.
  • The fixed file must pass with -Wall -Wextra -Werror -fsanitize=address,undefined.

Clarifying questions to ask

  1. What are the types and ranges of the inputs? (most of these bugs are about widths and signedness)
  2. Can this run in interrupt context, or be interrupted?
  3. Is the counter / timestamp free-running, i.e. does it wrap?
  4. What should happen on the empty case (n == 0, empty buffer)?

드릴마다 D1 avg ok / <-- BUG 한 줄이 찍히므로 어느 것이 남았는지 바로 보입니다. 컴파일 경고(D4, D7)도 읽어 보세요. 그것 자체가 힌트입니다.

buggy.c
/*
 * D  Debug Drills (D1-D8)
 *
 * Eight short firmware functions. Each one compiles and "looks right", but each has
 * exactly one classic embedded bug (D1 has two). For every drill:
 *   1. read the "Intended behavior" comment,
 *   2. say the bug out loud in under a minute,
 *   3. fix it with a one-line (or few-line) change.
 *
 * The test main() exposes every bug WITHOUT crashing or hanging:
 *   - D1 n == 0 runs in a forked child, so a divide-by-zero trap cannot kill the run.
 *   - D3 checks the head index BEFORE the next write, so no out-of-bounds store happens.
 *   - D4 has a TEST GUARD (iteration cap + index check) so the loop cannot run forever.
 *   - D6 simulates an interrupt deterministically through a test hook.
 *
 * Buggy version.  Build & run:  ./run.sh D buggy     (copy to my.c, fix, ./run.sh D my)
 */
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>
#include <unistd.h>
#include <sys/wait.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

/* ------------------------------------------------------------------------------------
 * D1  Average of n samples.
 * Intended: return the integer mean (truncated toward zero) of x[0..n-1].
 *           Inputs can be large (e.g. 8500 = 85.00 degC in 0.01 degC units).
 *           If n == 0, return AVG_INVALID instead of dividing.
 * ---------------------------------------------------------------------------------- */
#define AVG_INVALID INT16_MIN

int16_t avg(const int16_t *x, uint8_t n)
{
    int16_t sum = 0;
    for (uint8_t i = 0; i < n; i++) sum += x[i];
    return sum / n;
}

/* ------------------------------------------------------------------------------------
 * D2  Timeout check on a free-running 32-bit tick counter.
 * Intended: return true once at least `timeout` ticks have elapsed since `start`.
 *           The counter wraps from 0xFFFFFFFF to 0, and that must not matter.
 * ---------------------------------------------------------------------------------- */
bool timed_out(uint32_t now, uint32_t start, uint32_t timeout)
{
    return now > start + timeout;
}

/* ------------------------------------------------------------------------------------
 * D3  Ring buffer push (one slot kept empty, capacity RB_N - 1).
 * Intended: store v at head and advance head, wrapping to 0 after RB_N - 1.
 *           Return false (and store nothing) when the buffer is full.
 * ---------------------------------------------------------------------------------- */
#define RB_N 8
static int rb_buf[RB_N];
static unsigned rb_head, rb_tail;

bool push(int v)
{
    if ((rb_head + 1) % RB_N == rb_tail) return false;
    rb_buf[rb_head++] = v;
    return true;
}

bool pop(int *v)              /* correct; given for the test */
{
    if (rb_head == rb_tail) return false;
    *v = rb_buf[rb_tail];
    rb_tail = (rb_tail + 1) % RB_N;
    return true;
}

/* ------------------------------------------------------------------------------------
 * D4  Process an array from the last element to the first.
 * Intended: call process(x[i]) for i = n-1, n-2, ..., 0 exactly once each.
 *           n == 0 must do nothing.
 * ---------------------------------------------------------------------------------- */
static int16_t d4_seen[16];
static size_t d4_cnt;
static bool d4_bad_index;     /* set by the TEST GUARD when the loop goes wrong */
static void process(int16_t v) { if (d4_cnt < 16) d4_seen[d4_cnt] = v; d4_cnt++; }

void process_reverse(const int16_t *x, size_t n)
{
    size_t iters = 0;
    for (size_t i = n - 1; i >= 0; i--) {
        /* TEST GUARD (not part of the drill): stop before an out-of-range read / endless loop */
        if (i >= n || ++iters > 1000) { d4_bad_index = true; break; }
        process(x[i]);
    }
}

/* ------------------------------------------------------------------------------------
 * D5  Decode a 12-bit two's-complement temperature register (TMP102-style).
 * Intended: msb holds bits 11..4, the upper nibble of lsb holds bits 3..0.
 *           Return the signed raw count; 1 count = 0.0625 degC.
 *           e.g. 0x190 -> +400 (+25 degC), 0xE70 -> -400 (-25 degC).
 * ---------------------------------------------------------------------------------- */
int16_t decode_temp12(uint8_t msb, uint8_t lsb)
{
    int16_t raw = (msb << 4) | (lsb >> 4);       /* 12-bit two's complement */
    return raw;
}

/* ------------------------------------------------------------------------------------
 * D6  Overheat event counter shared between an ISR and the main loop.
 * Intended: TEMP_IRQHandler() counts events; task() reports every event exactly once.
 *           No event may be lost even if the IRQ fires at any instruction of task().
 *
 * Simulation: irq_window() marks the point where a real interrupt could land.
 * The test arms g_irq_fire_once so that exactly one IRQ fires at that point.
 * irq_disable()/irq_enable() model __disable_irq()/__enable_irq(): an IRQ raised
 * while disabled stays pending and runs when interrupts are enabled again.
 * ---------------------------------------------------------------------------------- */
static uint32_t overheat_count;                 /* incremented in ISR */
static uint32_t g_reported;
static bool g_irq_fire_once, g_irq_masked, g_irq_pending;

void TEMP_IRQHandler(void) { overheat_count++; }
static void report(uint32_t c) { g_reported += c; }
static void irq_window(void)
{
    if (!g_irq_fire_once) return;
    g_irq_fire_once = false;
    if (g_irq_masked) g_irq_pending = true; else TEMP_IRQHandler();
}
static inline void irq_disable(void) { g_irq_masked = true; }
static inline void irq_enable(void)
{
    g_irq_masked = false;
    if (g_irq_pending) { g_irq_pending = false; TEMP_IRQHandler(); }
}

void task(void)
{
    if (overheat_count > 0) {
        report(overheat_count);
        irq_window();                          /* an interrupt can land here */
        overheat_count = 0;
    }
}

/* ------------------------------------------------------------------------------------
 * D7  Reset one sample record to all zeros.
 * Intended: every field of *s becomes 0.
 * ---------------------------------------------------------------------------------- */
typedef struct { uint32_t t_ms; int16_t temp_c10; uint16_t flags; uint32_t seq; uint32_t crc; } Sample;

void clear(Sample *s) { memset(s, 0, sizeof(s)); }

/* ------------------------------------------------------------------------------------
 * D8  Debounced overheat detection.
 * Intended: enter OVERHEAT only after 3 CONSECUTIVE readings >= HIGH.
 *           Any reading below HIGH restarts the count.
 * ---------------------------------------------------------------------------------- */
#define HIGH 800
typedef enum { NORMAL, OVERHEAT } State;
typedef struct { uint8_t hot_cnt; State state; } Debounce;

void deb_update(Debounce *d, int16_t temp)
{
    if (temp >= HIGH) {
        if (++d->hot_cnt >= 3) d->state = OVERHEAT;
    }
}

/* ================================== tests ======================================== */
static int g_sec_fail;
static void begin(void) { g_sec_fail = g_fail; }
static void end(const char *name) { printf("%-28s %s\n", name, g_fail == g_sec_fail ? "ok" : "<-- BUG"); }

/* run avg(x, 0) in a child process: a divide-by-zero trap kills only the child */
static bool avg_n0_returns_invalid(void)
{
    fflush(stdout);
    pid_t pid = fork();
    if (pid == 0) {
        const int16_t x[1] = { 5 };
        _exit(avg(x, 0) == AVG_INVALID ? 0 : 1);
    }
    int st = 0;
    if (pid < 0 || waitpid(pid, &st, 0) != pid) return false;
    return WIFEXITED(st) && WEXITSTATUS(st) == 0;
}

int main(void)
{
    /* D1 */
    begin();
    const int16_t small[3] = { 10, 20, 30 };
    CHECK(avg(small, 3) == 20);                            /* normal */
    const int16_t big[8] = { 8500, 8500, 8500, 8500, 8500, 8500, 8500, 8500 };
    CHECK(avg(big, 8) == 8500);                            /* sum 68000 > INT16_MAX */
    CHECK(avg_n0_returns_invalid());                       /* n == 0 */
    end("D1 avg");

    /* D2 */
    begin();
    CHECK(timed_out(1000, 100, 500) == true);              /* normal, 900 elapsed */
    CHECK(timed_out(300, 100, 500) == false);              /* normal, 200 elapsed */
    CHECK(timed_out(600, 100, 500) == true);               /* exactly timeout */
    CHECK(timed_out(0xFFFFFF10u, 0xFFFFFF00u, 512) == false);  /* 16 elapsed, start+timeout wraps */
    CHECK(timed_out(0x00000150u, 0xFFFFFF00u, 512) == true);   /* 592 elapsed across the wrap */
    end("D2 timed_out");

    /* D3 */
    begin();
    int v = 0;
    rb_head = rb_tail = 0;
    for (int i = 0; i < 7; i++) CHECK(push(i));            /* capacity is RB_N - 1 = 7 */
    CHECK(push(99) == false);                              /* full */
    for (int i = 0; i < 7; i++) CHECK(pop(&v) && v == i);
    CHECK(push(100));                                      /* writes slot 7, head must wrap to 0 */
    CHECK(rb_head < RB_N);                                 /* checked BEFORE the next write */
    if (rb_head < RB_N) {
        CHECK(push(101));
        CHECK(pop(&v) && v == 100);
        CHECK(pop(&v) && v == 101);
    }
    end("D3 ring push");

    /* D4 */
    begin();
    const int16_t r[4] = { 1, 2, 3, 4 };
    d4_cnt = 0; d4_bad_index = false;
    process_reverse(r, 4);
    CHECK(!d4_bad_index && d4_cnt == 4);
    CHECK(d4_seen[0] == 4 && d4_seen[3] == 1);
    d4_cnt = 0; d4_bad_index = false;
    process_reverse(r, 0);                                 /* n == 0 */
    CHECK(!d4_bad_index && d4_cnt == 0);
    end("D4 reverse loop");

    /* D5 */
    begin();
    CHECK(decode_temp12(0x19, 0x00) == 400);               /* +25 degC */
    CHECK(decode_temp12(0x7F, 0xF0) == 2047);              /* max +127.9375 degC */
    CHECK(decode_temp12(0xE7, 0x00) == -400);              /* -25 degC */
    CHECK(decode_temp12(0xFF, 0xF0) == -1);                /* -0.0625 degC */
    CHECK(decode_temp12(0x80, 0x00) == -2048);             /* min -128 degC */
    end("D5 sign extension");

    /* D6 */
    begin();
    overheat_count = 0; g_reported = 0;
    task();
    CHECK(g_reported == 0);                                /* nothing to report */
    for (int i = 0; i < 3; i++) TEMP_IRQHandler();         /* 3 events */
    g_irq_fire_once = true;                                /* 4th event lands inside task() */
    task();
    task();                                                /* next loop iteration */
    CHECK(g_reported + overheat_count == 4);               /* no event lost */
    CHECK(g_reported == 4);
    end("D6 ISR counter race");

    /* D7 */
    begin();
    Sample s = { 123456u, -55, 0xBEEF, 77u, 0xDEADBEEFu };
    clear(&s);
    CHECK(s.t_ms == 0 && s.temp_c10 == 0 && s.flags == 0);
    CHECK(s.seq == 0 && s.crc == 0);
    end("D7 memset sizeof");

    /* D8 */
    begin();
    Debounce d = { 0, NORMAL };
    const int16_t steady[3] = { 900, 900, 900 };
    for (int i = 0; i < 3; i++) deb_update(&d, steady[i]);
    CHECK(d.state == OVERHEAT);                            /* normal: 3 in a row */
    Debounce e = { 0, NORMAL };
    const int16_t spiky[5] = { 900, 700, 900, 700, 900 };
    for (int i = 0; i < 5; i++) deb_update(&e, spiky[i]);
    CHECK(e.state == NORMAL);                              /* 3 isolated spikes are not overheat */
    Debounce f = { 0, NORMAL };
    const int16_t edge[4] = { 900, 900, 799, 900 };
    for (int i = 0; i < 4; i++) deb_update(&f, edge[i]);
    CHECK(f.state == NORMAL);                              /* 799 < HIGH breaks the run */
    end("D8 debounce reset");

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

3. 힌트 (막힐 때 하나씩)

Hint 1 — 어디부터 의심하나

임베디드 C 버그는 대부분 네 종류입니다. (1) 정수 폭/부호(overflow, unsigned, sign extension), (2) 경계(0개, 꽉 참, 마지막 인덱스, 랩어라운드), (3) 동시성(ISR과 공유하는 변수), (4) C 문법 함정(sizeof 포인터). 스니펫을 보면 먼저 "타입이 뭐지?"를 묻고, 다음에 "0이면? 최댓값이면?"을 넣어 보세요.

Hint 2 — 숫자를 하나 넣어 보기
  • D1: 8500을 8번 더하면? int16_t 최댓값은 32767입니다.
  • D2: start = 0xFFFFFF00, timeout = 512이면 start + timeout은?
  • D4: n = 0이면 n - 1은? size_t가 음수가 될 수 있나?
  • D5: −25 °C의 12-bit 값 0xE70을 int16_t에 그대로 넣으면?
Hint 3 — 도구가 알려 주는 것

./run.sh는 ASan/UBSan을 켭니다. D1은 UBSan이 division by zero를, D7은 clang이 -Wsizeof-pointer-memaccess를 바로 보여 줍니다. D4는 -Wtautological-unsigned-zero-compare(clang) / -Wtype-limits(gcc, -Wextra에 포함)가 잡습니다. 도구가 못 잡는 것은 D2, D3(인덱스 논리), D5, D6, D8입니다. 이건 테스트 입력으로만 드러납니다.

4. 풀이

4.1 핵심 아이디어

각 드릴에서 말할 순서는 항상 같습니다: ① 버그 한 문장 → ② 터지는 입력 → ③ 고친 한 줄 → ④ 어떻게 찾았을지. 30초 안에 ①②를 말하면 면접관은 이미 만족합니다. 아래는 드릴별 문제(English)와 답(펼치기)입니다.

D1 · Average

Intended behavior: return the integer mean of x[0..n-1]. Inputs can be large (8500 = 85.00 °C in 0.01 °C units). If n == 0, return AVG_INVALID instead of dividing.

int16_t avg(const int16_t *x, uint8_t n) {
    int16_t sum = 0;
    for (uint8_t i = 0; i < n; i++) sum += x[i];
    return sum / n;
}
💡 D1 답 펼치기

버그 2개

  1. 합계가 int16_t라 넘칩니다. 8500 × 8 = 68000 > 32767 → 68000 − 65536 = 2464가 되고, 평균은 8500이 아니라 308이 나옵니다.
  2. n == 0이면 0으로 나누기 → UB. Cortex-M에서는 DIV_0_TRP가 켜져 있으면 UsageFault, 꺼져 있으면 조용히 0이 나옵니다.

고친 코드

if (n == 0) return AVG_INVALID;
int32_t sum = 0;                       /* 255 * 32767 < 2^31 */
...
return (int16_t)(sum / n);

어떻게 찾나

  • UBSan 출력: buggy.c:42:16: runtime error: division by zero
  • 오버플로는 UBSan이 못 잡습니다. sum += x[i]는 int로 계산한 뒤 int16_t로 변환하는 것이라 UB가 아니라 implementation-defined이기 때문입니다. → "최대 입력 × 최대 개수" 테스트가 필요합니다. (-fsanitize=implicit-conversion을 켜면 clang이 잡아 줍니다.)
  • 설명할 때: "누산기는 입력보다 넓게 — n_max × max_value가 들어가는 폭"이라고 말합니다.

D2 · Timeout on a free-running tick counter

Intended behavior: return true once at least timeout ticks have elapsed since start. The counter wraps from 0xFFFFFFFF to 0, and that must not matter.

bool timed_out(uint32_t now, uint32_t start, uint32_t timeout) {
    return now > start + timeout;
}
💡 D2 답 펼치기

버그: start + timeout이 랩어라운드하면 비교가 깨집니다. start = 0xFFFFFF00, timeout = 512 → start + timeout = 0x100. 그러면 16 tick밖에 안 지난 now = 0xFFFFFF10도 0x100보다 크므로 즉시 타임아웃(반대로 deadline은 랩되지 않았는데 now가 먼저 0으로 넘어가면, 다음 한 바퀴(1 ms tick이면 약 49.7일) 동안 계속 false). 덤으로 >라서 정확히 timeout만큼 지난 순간을 놓칩니다(timed_out(600, 100, 500)이 false).

고친 한 줄

return (uint32_t)(now - start) >= timeout;

부호 없는 뺄셈은 mod 2^32로 정의되어 있어서, 경과 시간이 2^32보다 작기만 하면 랩어라운드와 무관하게 정확합니다. (uint32_t) 캐스트는 uint16_t 카운터처럼 int로 승격되는 타입에서 꼭 필요하므로 습관으로 붙입니다.

어떻게 찾나: 컴파일러·sanitizer 모두 조용합니다(unsigned 랩은 정의된 동작). 랩 직전 start를 넣는 테스트가 유일한 방법입니다. 실기에서는 49.7일(1 ms tick) 뒤에 터지는 "장기 구동 버그"로 나타납니다. 테스트 때는 tick 카운터 초기값을 0xFFFF0000 근처로 두면 몇 초 만에 재현됩니다.

D3 · Ring buffer push

Intended behavior: store v at head and advance head, wrapping to 0 after RB_N - 1. Return false (and store nothing) when the buffer is full. One slot is kept empty, so capacity is RB_N - 1.

#define RB_N 8
static int rb_buf[RB_N];
static unsigned rb_head, rb_tail;
bool push(int v) {
    if ((rb_head + 1) % RB_N == rb_tail) return false;
    rb_buf[rb_head++] = v;
    return true;
}
💡 D3 답 펼치기

버그: rb_head++에 모듈로가 없습니다. full 검사는 % RB_N을 하지만 rb_head 자체는 8, 9, …로 계속 커져서 rb_buf[8]부터 버퍼 밖에 씁니다. 처음 7개는 멀쩡하므로, pop으로 tail이 움직인 뒤 한 바퀴 돌 때 처음 터집니다. 테스트: push 7 → pop 7 → push(100) 하면 rb_head == 8.

고친 코드

rb_buf[rb_head] = v;
rb_head = (rb_head + 1) % RB_N;

RB_N이 2의 거듭제곱이면 & (RB_N - 1)도 됩니다. 이 방식은 "한 칸 비우기"라 용량이 RB_N − 1 = 7이라는 것도 말합니다(대안: count 변수, 또는 free-running 인덱스 + 마스크 → T2-1).

어떻게 찾나: 테스트가 고치지 않으면 다음 push가 rb_buf[8]에 쓰게 되는데, ASan은 이것을 global-buffer-overflow ... WRITE of size 4로 잡습니다. 여기 테스트는 그 쓰기를 하기 전에 rb_head < RB_N 불변식을 검사해서 FAIL로 멈춥니다. 실기에서는 rb_buf 바로 뒤에 놓인 변수(대개 rb_head/rb_tail 자체)가 깨져서 "가끔 데이터가 이상하다"로 나타납니다.

D4 · Reverse loop

Intended behavior: call process(x[i]) for i = n-1, n-2, …, 0, each exactly once. n == 0 must do nothing.

for (size_t i = n - 1; i >= 0; i--) process(x[i]);
💡 D4 답 펼치기

버그: size_t는 부호가 없어서 i >= 0은 항상 참입니다. i = 0에서 i-- 하면 SIZE_MAX가 되어 루프가 끝나지 않고 x[SIZE_MAX]를 읽습니다. n == 0이면 시작부터 i = SIZE_MAX입니다. (buggy.c의 TEST GUARD가 i >= n을 감지해서 멈추게 했을 뿐, 원래 코드는 무한 루프 + 잘못된 메모리 읽기입니다.)

고친 한 줄

for (size_t i = n; i-- > 0; ) process(x[i]);

조건을 검사한 다음에 감소하므로 본문에서는 n-1 … 0이 보이고, n == 0이면 한 번도 돌지 않습니다. int i로 바꾸는 방법도 있지만 n이 INT_MAX보다 크면 다시 틀리고 -Wsign-compare 경고가 납니다.

어떻게 찾나: 컴파일러가 이미 알려 줍니다.

warning: result of comparison of unsigned expression >= 0 is always true
         [-Wtautological-unsigned-zero-compare]        (clang)
warning: comparison of unsigned expression in '>= 0' is always true [-Wtype-limits]   (gcc -Wextra)

그래서 펌웨어 빌드는 -Wall -Wextra -Werror가 기본이라고 말합니다.

D5 · 12-bit sensor register

Intended behavior: a TMP102-style sensor returns a 12-bit two's-complement temperature: msb holds bits 11..4, the upper nibble of lsb holds bits 3..0. Return the signed raw count (1 count = 0.0625 °C). For example 0x190 → +400 (+25 °C), 0xE70 → -400 (−25 °C).

int16_t raw = (msb << 4) | (lsb >> 4);     /* 12-bit two's complement */
return raw;
💡 D5 답 펼치기

버그: 12-bit 값을 16-bit 변수에 넣으면서 부호 확장을 안 했습니다. bit 11(부호 비트)이 1이어도 bit 15..12는 0으로 채워져서, 음수 온도가 큰 양수가 됩니다. −25 °C(0xE70) → +3696 = 231.0 °C. 양수 온도는 정상이라 실온 테스트로는 절대 안 보입니다.

고친 코드 (둘 중 하나)

int16_t raw = (int16_t)((msb << 4) | (lsb >> 4));
if (raw & 0x800) raw -= 0x1000;                 /* sign-extend bit 11 */

int16_t raw = (int16_t)((msb << 8) | lsb) / 16; /* 16-bit로 놓고 나누기 */

두 번째 방법은 부호 비트를 bit 15에 맞춘 뒤 16으로 나눕니다. >> 4도 되지만 음수의 오른쪽 시프트는 implementation-defined라서, 면접에서는 / 16이나 첫 번째 방법을 쓰고 그 이유를 말합니다(lsb 하위 니블이 0이라 / 16은 정확히 나눠떨어짐).

확인 값 (fixed.c 테스트): 0x19,0x00 → 400, 0x7F,0xF0 → 2047, 0xE7,0x00 → −400, 0xFF,0xF0 → −1, 0x80,0x00 → −2048. 버그 버전은 뒤 세 개가 3696, 4095, 2048로 나옵니다.

어떻게 찾나: sanitizer는 못 잡습니다. 음수 경계값 테스트(−0.0625 °C = 0xFFF, 최소값 0x800)가 답입니다. 실기에서는 "겨울에 냉동 창고 테스트를 하니 과열 경보가 뜬다"로 나타납니다. 자세한 버전은 T1-5.

D6 · Counter shared with an ISR

Intended behavior: TEMP_IRQHandler() counts overheat events; task() (main loop) reports every event exactly once. No event may be lost, even if the IRQ fires at any instruction inside task().

static uint32_t overheat_count;                 /* incremented in ISR */
void TEMP_IRQHandler(void) { overheat_count++; }
void task(void) {
    if (overheat_count > 0) { report(overheat_count); overheat_count = 0; }
}

In buggy.c the line irq_window(); marks where the test makes one interrupt fire, and irq_disable() / irq_enable() model __disable_irq() / __enable_irq() (an IRQ raised while masked stays pending and runs on enable).

💡 D6 답 펼치기

버그 2개

  1. 읽기-지우기 경쟁(race): report(overheat_count)로 읽은 뒤 overheat_count = 0 사이에 ISR이 들어와 count++를 하면, 그 증가분을 0으로 덮어써서 이벤트를 잃습니다. 테스트: 이벤트 3개 → task가 3을 보고 → 그 사이 4번째 IRQ → 0으로 지움 → 보고된 합계 3, 남은 카운트 0.
  2. volatile 없음: 컴파일러는 이 변수가 ISR에서 바뀐다는 것을 모릅니다. -O2에서 while (overheat_count == 0) {} 같은 대기 루프는 한 번만 읽고 무한 루프가 될 수 있고, 읽기·쓰기가 합쳐지거나 재배치될 수 있습니다. 단, volatile은 "매번 메모리에 접근하라"일 뿐 원자성을 주지 않습니다. 1번은 volatile로 안 고쳐집니다.

고친 코드

static volatile uint32_t overheat_count;

void task(void) {
    __disable_irq();                 /* 짧은 critical section: 읽고 지우기만 */
    uint32_t c = overheat_count;
    overheat_count = 0;
    __enable_irq();
    if (c > 0) report(c);            /* 느린 작업은 인터럽트 켠 뒤에 */
}

대안: C11 atomic_exchange(&overheat_count, 0) (Cortex-M3 이상은 LDREX/STREX로 구현), 또는 "ISR은 produced만 증가, task는 consumed만 증가, 차이를 보고"하는 단일 작성자 카운터 2개(락 없이 안전). __disable_irq() 대신 PRIMASK를 저장·복원하면 이미 꺼진 상태에서 불려도 안전합니다.

어떻게 찾나: ASan/UBSan은 못 잡습니다(단일 스레드에서는 경쟁이 없음). 리뷰에서 "ISR과 공유하는 변수 = read-modify-write가 원자적인가?"를 체크리스트로 봅니다. 실기 재현은 IRQ 빈도를 올리고(예: 테스트 타이머로 10 kHz) 카운트 합계를 비교하거나, GPIO 토글 + 로직 분석기로 critical section 길이를 잽니다.

D7 · Zero a struct

Intended behavior: set every field of *s to 0.

typedef struct { uint32_t t_ms; int16_t temp_c10; uint16_t flags; uint32_t seq; uint32_t crc; } Sample;
void clear(Sample *s) { memset(s, 0, sizeof(s)); }
💡 D7 답 펼치기

버그: sizeof(s)는 포인터 크기(64-bit 호스트 8, Cortex-M 4)입니다. Sample은 16바이트라서 앞 8바이트(t_ms, temp_c10, flags)만 지워지고 seq, crc는 그대로 남습니다. Cortex-M에서는 4바이트만 지워집니다. 즉 플랫폼마다 다르게 틀립니다.

고친 한 줄

memset(s, 0, sizeof(*s));      /* 또는 *s = (Sample){0}; */

*s = (Sample){0};는 크기를 쓸 일이 없어서 더 안전합니다.

어떻게 찾나: clang은 기본 경고로 바로 알려 줍니다.

warning: 'memset' call operates on objects of type 'Sample' while the size is based
         on a different type 'Sample *' [-Wsizeof-pointer-memaccess]

같은 실수가 배열 파라미터에서도 납니다: void f(int a[16]) { sizeof(a) }도 포인터 크기입니다(배열이 함수 인자로 오면 포인터로 바뀜).

D8 · Debounce counter

Intended behavior: enter OVERHEAT only after 3 consecutive readings >= HIGH (800). Any reading below HIGH restarts the count.

if (temp >= HIGH) {
    if (++d->hot_cnt >= 3) d->state = OVERHEAT;
}
💡 D8 답 펼치기

버그: 온도가 내려가도 hot_cnt를 리셋하지 않습니다. 그래서 "연속 3회"가 아니라 "누적 3회"가 됩니다. 테스트: 900, 700, 900, 700, 900 → 떨어져 있는 스파이크 3개로 과열 판정. 900, 900, 799, 900도 마찬가지(799 < 800).

고친 한 줄

} else d->hot_cnt = 0;

추가로 ++hot_cnt는 uint8_t라 256번째에 0으로 돌아갑니다. 여기서는 상태가 이미 래치되어 무해하지만, 같은 카운터로 "N회 연속이면 알람 유지" 같은 판정을 하면 문제가 되므로 if (hot_cnt < 3) hot_cnt++;로 포화시키는 것이 좋습니다(fixed.c가 그렇게 함).

어떻게 찾나: 도구는 못 잡습니다. "끊어진 스파이크" 테스트 벡터를 넣어야 합니다. 이 패턴의 완전한 버전(히스테리시스 + 회복)은 T1-2, T2-7.

💡 정답 코드 펼치기 (드릴 다 해 본 다음에)
fixed.c
/*
 * D  Debug Drills (D1-D8)
 *
 * Eight short firmware functions. Each one compiles and "looks right", but each has
 * exactly one classic embedded bug (D1 has two). For every drill:
 *   1. read the "Intended behavior" comment,
 *   2. say the bug out loud in under a minute,
 *   3. fix it with a one-line (or few-line) change.
 *
 * The test main() exposes every bug WITHOUT crashing or hanging:
 *   - D1 n == 0 runs in a forked child, so a divide-by-zero trap cannot kill the run.
 *   - D3 checks the head index BEFORE the next write, so no out-of-bounds store happens.
 *   - D4 has a TEST GUARD (iteration cap + index check) so the loop cannot run forever.
 *   - D6 simulates an interrupt deterministically through a test hook.
 *
 * Fixed version (reference).  Build & run:  ./run.sh D fixed   -> ALL PASS
 */
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>
#include <unistd.h>
#include <sys/wait.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

/* ------------------------------------------------------------------------------------
 * D1  Average of n samples.
 * Intended: return the integer mean (truncated toward zero) of x[0..n-1].
 *           Inputs can be large (e.g. 8500 = 85.00 degC in 0.01 degC units).
 *           If n == 0, return AVG_INVALID instead of dividing.
 * ---------------------------------------------------------------------------------- */
#define AVG_INVALID INT16_MIN

int16_t avg(const int16_t *x, uint8_t n)
{
    if (n == 0) return AVG_INVALID;                  /* FIX: no divide by zero */
    int32_t sum = 0;                                  /* FIX: 255 * 32767 fits in int32 */
    for (uint8_t i = 0; i < n; i++) sum += x[i];
    return (int16_t)(sum / n);                        /* mean of int16 values fits in int16 */
}

/* ------------------------------------------------------------------------------------
 * D2  Timeout check on a free-running 32-bit tick counter.
 * Intended: return true once at least `timeout` ticks have elapsed since `start`.
 *           The counter wraps from 0xFFFFFFFF to 0, and that must not matter.
 * ---------------------------------------------------------------------------------- */
bool timed_out(uint32_t now, uint32_t start, uint32_t timeout)
{
    return (uint32_t)(now - start) >= timeout;       /* FIX: elapsed = modular difference */
}

/* ------------------------------------------------------------------------------------
 * D3  Ring buffer push (one slot kept empty, capacity RB_N - 1).
 * Intended: store v at head and advance head, wrapping to 0 after RB_N - 1.
 *           Return false (and store nothing) when the buffer is full.
 * ---------------------------------------------------------------------------------- */
#define RB_N 8
static int rb_buf[RB_N];
static unsigned rb_head, rb_tail;

bool push(int v)
{
    if ((rb_head + 1) % RB_N == rb_tail) return false;
    rb_buf[rb_head] = v;
    rb_head = (rb_head + 1) % RB_N;                   /* FIX: wrap the index */
    return true;
}

bool pop(int *v)              /* correct; given for the test */
{
    if (rb_head == rb_tail) return false;
    *v = rb_buf[rb_tail];
    rb_tail = (rb_tail + 1) % RB_N;
    return true;
}

/* ------------------------------------------------------------------------------------
 * D4  Process an array from the last element to the first.
 * Intended: call process(x[i]) for i = n-1, n-2, ..., 0 exactly once each.
 *           n == 0 must do nothing.
 * ---------------------------------------------------------------------------------- */
static int16_t d4_seen[16];
static size_t d4_cnt;
static bool d4_bad_index;     /* set by the TEST GUARD when the loop goes wrong */
static void process(int16_t v) { if (d4_cnt < 16) d4_seen[d4_cnt] = v; d4_cnt++; }

void process_reverse(const int16_t *x, size_t n)
{
    size_t iters = 0;
    for (size_t i = n; i-- > 0; ) {                   /* FIX: test first, then decrement */
        /* TEST GUARD (not part of the drill): stop before an out-of-range read / endless loop */
        if (i >= n || ++iters > 1000) { d4_bad_index = true; break; }
        process(x[i]);
    }
}

/* ------------------------------------------------------------------------------------
 * D5  Decode a 12-bit two's-complement temperature register (TMP102-style).
 * Intended: msb holds bits 11..4, the upper nibble of lsb holds bits 3..0.
 *           Return the signed raw count; 1 count = 0.0625 degC.
 *           e.g. 0x190 -> +400 (+25 degC), 0xE70 -> -400 (-25 degC).
 * ---------------------------------------------------------------------------------- */
int16_t decode_temp12(uint8_t msb, uint8_t lsb)
{
    int16_t raw = (int16_t)((msb << 4) | (lsb >> 4)); /* 0..4095 */
    if (raw & 0x800) raw -= 0x1000;                   /* FIX: sign-extend bit 11 */
    return raw;
}

/* ------------------------------------------------------------------------------------
 * D6  Overheat event counter shared between an ISR and the main loop.
 * Intended: TEMP_IRQHandler() counts events; task() reports every event exactly once.
 *           No event may be lost even if the IRQ fires at any instruction of task().
 *
 * Simulation: irq_window() marks the point where a real interrupt could land.
 * The test arms g_irq_fire_once so that exactly one IRQ fires at that point.
 * irq_disable()/irq_enable() model __disable_irq()/__enable_irq(): an IRQ raised
 * while disabled stays pending and runs when interrupts are enabled again.
 * ---------------------------------------------------------------------------------- */
static volatile uint32_t overheat_count;        /* FIX: volatile - changed by the ISR */
static uint32_t g_reported;
static bool g_irq_fire_once, g_irq_masked, g_irq_pending;

void TEMP_IRQHandler(void) { overheat_count++; }
static void report(uint32_t c) { g_reported += c; }
static void irq_window(void)
{
    if (!g_irq_fire_once) return;
    g_irq_fire_once = false;
    if (g_irq_masked) g_irq_pending = true; else TEMP_IRQHandler();
}
static inline void irq_disable(void) { g_irq_masked = true; }
static inline void irq_enable(void)
{
    g_irq_masked = false;
    if (g_irq_pending) { g_irq_pending = false; TEMP_IRQHandler(); }
}

void task(void)
{
    irq_disable();                             /* FIX: read + clear as one critical section */
    uint32_t c = overheat_count;
    irq_window();                              /* the IRQ stays pending while masked */
    overheat_count = 0;
    irq_enable();                              /* pending IRQ runs here -> count = 1 */
    if (c > 0) report(c);                      /* slow work outside the critical section */
}

/* ------------------------------------------------------------------------------------
 * D7  Reset one sample record to all zeros.
 * Intended: every field of *s becomes 0.
 * ---------------------------------------------------------------------------------- */
typedef struct { uint32_t t_ms; int16_t temp_c10; uint16_t flags; uint32_t seq; uint32_t crc; } Sample;

void clear(Sample *s) { memset(s, 0, sizeof(*s)); /* FIX: size of the struct, not the pointer */ }

/* ------------------------------------------------------------------------------------
 * D8  Debounced overheat detection.
 * Intended: enter OVERHEAT only after 3 CONSECUTIVE readings >= HIGH.
 *           Any reading below HIGH restarts the count.
 * ---------------------------------------------------------------------------------- */
#define HIGH 800
typedef enum { NORMAL, OVERHEAT } State;
typedef struct { uint8_t hot_cnt; State state; } Debounce;

void deb_update(Debounce *d, int16_t temp)
{
    if (temp >= HIGH) {
        if (d->hot_cnt < 3) d->hot_cnt++;             /* saturate: no uint8_t wrap */
        if (d->hot_cnt >= 3) d->state = OVERHEAT;
    } else {
        d->hot_cnt = 0;                               /* FIX: a cool reading restarts the count */
    }
}

/* ================================== tests ======================================== */
static int g_sec_fail;
static void begin(void) { g_sec_fail = g_fail; }
static void end(const char *name) { printf("%-28s %s\n", name, g_fail == g_sec_fail ? "ok" : "<-- BUG"); }

/* run avg(x, 0) in a child process: a divide-by-zero trap kills only the child */
static bool avg_n0_returns_invalid(void)
{
    fflush(stdout);
    pid_t pid = fork();
    if (pid == 0) {
        const int16_t x[1] = { 5 };
        _exit(avg(x, 0) == AVG_INVALID ? 0 : 1);
    }
    int st = 0;
    if (pid < 0 || waitpid(pid, &st, 0) != pid) return false;
    return WIFEXITED(st) && WEXITSTATUS(st) == 0;
}

int main(void)
{
    /* D1 */
    begin();
    const int16_t small[3] = { 10, 20, 30 };
    CHECK(avg(small, 3) == 20);                            /* normal */
    const int16_t big[8] = { 8500, 8500, 8500, 8500, 8500, 8500, 8500, 8500 };
    CHECK(avg(big, 8) == 8500);                            /* sum 68000 > INT16_MAX */
    CHECK(avg_n0_returns_invalid());                       /* n == 0 */
    end("D1 avg");

    /* D2 */
    begin();
    CHECK(timed_out(1000, 100, 500) == true);              /* normal, 900 elapsed */
    CHECK(timed_out(300, 100, 500) == false);              /* normal, 200 elapsed */
    CHECK(timed_out(600, 100, 500) == true);               /* exactly timeout */
    CHECK(timed_out(0xFFFFFF10u, 0xFFFFFF00u, 512) == false);  /* 16 elapsed, start+timeout wraps */
    CHECK(timed_out(0x00000150u, 0xFFFFFF00u, 512) == true);   /* 592 elapsed across the wrap */
    end("D2 timed_out");

    /* D3 */
    begin();
    int v = 0;
    rb_head = rb_tail = 0;
    for (int i = 0; i < 7; i++) CHECK(push(i));            /* capacity is RB_N - 1 = 7 */
    CHECK(push(99) == false);                              /* full */
    for (int i = 0; i < 7; i++) CHECK(pop(&v) && v == i);
    CHECK(push(100));                                      /* writes slot 7, head must wrap to 0 */
    CHECK(rb_head < RB_N);                                 /* checked BEFORE the next write */
    if (rb_head < RB_N) {
        CHECK(push(101));
        CHECK(pop(&v) && v == 100);
        CHECK(pop(&v) && v == 101);
    }
    end("D3 ring push");

    /* D4 */
    begin();
    const int16_t r[4] = { 1, 2, 3, 4 };
    d4_cnt = 0; d4_bad_index = false;
    process_reverse(r, 4);
    CHECK(!d4_bad_index && d4_cnt == 4);
    CHECK(d4_seen[0] == 4 && d4_seen[3] == 1);
    d4_cnt = 0; d4_bad_index = false;
    process_reverse(r, 0);                                 /* n == 0 */
    CHECK(!d4_bad_index && d4_cnt == 0);
    end("D4 reverse loop");

    /* D5 */
    begin();
    CHECK(decode_temp12(0x19, 0x00) == 400);               /* +25 degC */
    CHECK(decode_temp12(0x7F, 0xF0) == 2047);              /* max +127.9375 degC */
    CHECK(decode_temp12(0xE7, 0x00) == -400);              /* -25 degC */
    CHECK(decode_temp12(0xFF, 0xF0) == -1);                /* -0.0625 degC */
    CHECK(decode_temp12(0x80, 0x00) == -2048);             /* min -128 degC */
    end("D5 sign extension");

    /* D6 */
    begin();
    overheat_count = 0; g_reported = 0;
    task();
    CHECK(g_reported == 0);                                /* nothing to report */
    for (int i = 0; i < 3; i++) TEMP_IRQHandler();         /* 3 events */
    g_irq_fire_once = true;                                /* 4th event lands inside task() */
    task();
    task();                                                /* next loop iteration */
    CHECK(g_reported + overheat_count == 4);               /* no event lost */
    CHECK(g_reported == 4);
    end("D6 ISR counter race");

    /* D7 */
    begin();
    Sample s = { 123456u, -55, 0xBEEF, 77u, 0xDEADBEEFu };
    clear(&s);
    CHECK(s.t_ms == 0 && s.temp_c10 == 0 && s.flags == 0);
    CHECK(s.seq == 0 && s.crc == 0);
    end("D7 memset sizeof");

    /* D8 */
    begin();
    Debounce d = { 0, NORMAL };
    const int16_t steady[3] = { 900, 900, 900 };
    for (int i = 0; i < 3; i++) deb_update(&d, steady[i]);
    CHECK(d.state == OVERHEAT);                            /* normal: 3 in a row */
    Debounce e = { 0, NORMAL };
    const int16_t spiky[5] = { 900, 700, 900, 700, 900 };
    for (int i = 0; i < 5; i++) deb_update(&e, spiky[i]);
    CHECK(e.state == NORMAL);                              /* 3 isolated spikes are not overheat */
    Debounce f = { 0, NORMAL };
    const int16_t edge[4] = { 900, 900, 799, 900 };
    for (int i = 0; i < 4; i++) deb_update(&f, edge[i]);
    CHECK(f.state == NORMAL);                              /* 799 < HIGH breaks the run */
    end("D8 debounce reset");

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

코드 읽는 포인트

  • 모든 수정에 /* FIX: ... */ 주석이 붙어 있습니다. diff buggy.c fixed.c로 보면 드릴마다 1–5줄만 다릅니다.
  • D1의 n == 0 테스트는 fork()한 자식 프로세스에서 돌립니다. x86에서는 0으로 나누기가 SIGFPE로 프로세스를 죽이기 때문에, 버그 버전에서도 테스트 전체가 멈추지 않게 하려는 장치입니다. 문제 자체와는 무관합니다.
  • D6의 irq_window()는 fixed 버전에도 같은 자리에 남아 있습니다. 같은 타이밍에 IRQ가 와도 이제는 pending으로 기다렸다가 irq_enable()에서 실행된다는 것을 테스트가 보여 줍니다.

4.4 복잡도

드릴 자체는 복잡도 문제가 아닙니다. 고친 코드는 모두 원래와 같은 O(n) 또는 O(1)이고, 추가 메모리도 없습니다(D6의 critical section은 명령어 몇 개 길이).

5. 임베디드 관점으로 말할 것

  • 경고를 에러로: D4, D7은 -Wall -Wextra -Werror만으로 빌드가 막힙니다. "우리 펌웨어 빌드는 경고 0이 기본"이라고 말하면 좋습니다. 정적 분석(clang-tidy, cppcheck, MISRA 검사기)은 D1의 좁은 누산기, D5의 암시적 변환도 지적합니다.
  • 호스트에서 sanitizer로 먼저: 펌웨어 로직(D1, D3, D4)은 HAL과 분리해서 PC에서 ASan/UBSan으로 단위 테스트합니다. 타깃에서는 MPU로 스택/버퍼 경계를 막고, HardFault 핸들러에서 PC/LR을 로그로 남깁니다.
  • 도구가 못 잡는 것은 테스트 벡터로: D2(랩 직전 tick), D5(음수 온도), D8(끊어진 스파이크)는 경계값을 의도적으로 넣는 테스트로만 드러납니다. tick 카운터 초기값을 랩 직전으로 두는 것은 실제로 많이 쓰는 기법입니다.
  • ISR 공유 변수 규칙: volatile은 가시성, critical section/atomic은 원자성. 둘은 다른 문제라는 것을 구분해서 말하면 시니어로 보입니다. critical section은 짧게(읽고 지우기만), 느린 report()는 밖에서.
  • 고정폭 정수와 단위: int16_t의 0.01 °C 단위는 ±327 °C까지만 됩니다. 누산·곱셈 전에 "최대 입력 × 최대 개수"가 몇 비트인지 계산하는 습관이 D1을 막습니다.

6. Follow-up 질문과 답

Follow-up (English)답
Does volatile alone fix D6?아닙니다. volatile은 컴파일러가 접근을 생략·캐시하지 않게 할 뿐이고, 읽기→지우기 두 동작 사이의 끼어들기는 막지 못합니다. 원자성은 critical section이나 atomic_exchange가 줍니다.
Can you fix D6 without disabling interrupts?ISR은 produced++만, task는 consumed만 씁니다. 보고할 양은 produced - consumed(unsigned 뺄셈이라 랩도 안전). 각 변수의 작성자가 하나뿐이고 32-bit 정렬 읽기/쓰기는 Cortex-M에서 원자적이라 락이 필요 없습니다. 또는 LDREX/STREX 기반 atomic_exchange.
How long can the D2 timeout be?차이를 uint32_t로 보므로 2^32 − 1 tick까지. 1 ms tick이면 약 49.7일. 그보다 긴 타임아웃은 64-bit tick이나 별도 카운터가 필요합니다. 부호 있는 비교 (int32_t)(now - deadline) >= 0 방식은 절반(약 24.8일)까지입니다.
Why not just make the D1 accumulator int64_t?가능하지만 Cortex-M0에서는 64-bit 덧셈이 여러 명령어라 느립니다. 필요한 폭을 계산하면 uint8_t n × int16_t 최대 = 255 × 32767 < 2^23이라 int32_t로 충분합니다. 폭은 계산해서 고릅니다.
How would you find D3 on the target, without ASan?버퍼 뒤에 canary 값을 두고 주기적으로 검사, MPU로 버퍼 끝 다음 영역을 no-access로 설정, 또는 디버거의 data watchpoint(DWT)를 &rb_buf[RB_N]에 걸어 쓰는 순간 멈추게 합니다.
In D5, is (int16_t)(raw << 4) >> 4 a good fix?흔히 쓰지만 음수의 오른쪽 시프트는 implementation-defined이고, 범위를 넘는 값을 int16_t로 변환하는 것도 implementation-defined입니다. 실제 컴파일러(GCC/Clang/ARMCC)는 모두 산술 시프트라 동작은 하지만, 면접에서는 if (raw & 0x800) raw -= 0x1000;처럼 표준만으로 정의된 방법을 먼저 말합니다.

7. 자주 하는 실수

  • D6에서 volatile만 붙이고 끝냄 → 경쟁은 그대로. 테스트 g_reported == 4가 계속 FAIL
  • D6에서 report()까지 critical section 안에 넣음 → 동작은 맞지만 인터럽트 지연이 길어져 다른 IRQ(모터 제어 등)가 밀림
  • D4를 int i = n - 1; i >= 0으로 고침 → n이 size_t라 -Wsign-compare 경고, 큰 n에서 다시 틀림
  • D2를 now - start > timeout으로 고침 → 랩은 해결됐지만 경계(== timeout)에서 한 tick 늦음. 테스트 timed_out(600, 100, 500) FAIL
  • D3을 고치면서 full 검사 (rb_head + 1) % RB_N == rb_tail까지 바꿔 버림 → 그 줄은 원래 맞습니다
  • D1에서 오버플로만 고치고 n == 0을 잊음 (또는 반대) — 버그가 두 개라는 것을 먼저 말할 것
  • D7을 sizeof(Sample)로 고침 → 지금은 맞지만, 나중에 s의 타입이 바뀌면 다시 틀림. sizeof(*s)가 더 견고
