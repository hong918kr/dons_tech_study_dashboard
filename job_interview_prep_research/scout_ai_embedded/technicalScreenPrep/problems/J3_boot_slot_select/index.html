J3 · Pick a Boot Slot (A/B Images with Rollback)

IDJ3
PriorityP1
Patternheader validation + CRC + state machine with persisted counters
Time30 min

파일: stub.c(여기서 풀기) · solution.c(정답) · 실행: ./run.sh J3 / ./run.sh J3 sol

0. 문제 한국어 소개 (먼저 읽기)

영어 문제(§1)를 읽기 전에 무엇을 만들라는 건지 먼저 잡기 위한 요약입니다. 실제 풀이와 테스트는 §1 영어 문제 기준입니다.

  • 한 줄 요약: flash의 A/B 두 슬롯 중 어느 펌웨어로 부팅할지 고르는 bootloader 로직. 이미지 검사(A) + 슬롯 선택과 rollback(B) + 정상 확인(C).
  • 상황: 로봇이 OTA로 MCU 펌웨어를 받는다. 새 이미지는 항상 지금 안 돌고 있는 슬롯에 써지고 "시험 부팅"된다. 새 이미지가 끝내 "나 정상이야"를 알리지 않으면 옛 이미지로 되돌아가야 한다.
  • 배경 개념
    • A/B 슬롯: flash에 펌웨어 자리가 두 개(A = 0x08004000, B = 0x08024000). 하나가 망가져도 다른 하나로 부팅할 수 있게 하는 구조.
    • vector table: Cortex-M 이미지 맨 앞 두 word. word0 = 처음 쓸 스택 포인터(SP, RAM 안이어야 함), word1 = reset handler 주소(전원 켜면 처음 뛰는 코드). Thumb 모드라 주소의 bit 0이 1이어야 한다.
    • CRC-32: 이미지 바이트 전체로 계산한 32-bit 체크값. 한 비트만 바뀌어도 값이 달라져서 깨진 이미지를 잡는다. crc32()는 주어진다.
    • trial boot / rollback: 새 이미지(pending)로 시험 부팅할 때마다 attempts를 올리고, 앱이 boot_confirm()을 부르면 확정. 3번 시도해도 확정이 없으면 그 슬롯을 bad로 찍고 옛 슬롯으로 돌아간다.
  • 입력: 슬롯 바이트 배열(각 4096 bytes, 앞 16 bytes가 little-endian header: magic, version, image_size, crc32), 슬롯 base 주소, EEPROM에 저장되는 4-byte BootState(active, pending, attempts, bad_mask).
  • 출력: image_check()는 IMG_OK 또는 실패 이유 enum, 성공 시 *out에 version/size/SP/reset. boot_select()는 부팅할 슬롯 번호(0/1) 또는 -1(DFU 모드), 그리고 *st를 갱신.
  • 규칙
    • Part A: 검사 순서 고정 — magic → size → CRC → vector. header는 바이트를 직접 조립해서 읽는다(struct cast 금지).
      • size: slot_size < 16, image_size < 8, image_size > slot_size - 16이면 IMG_BAD_SIZE.
      • vector: SP가 [0x20000000, 0x20020000] 밖이거나 4-byte 정렬 아님, reset의 bit 0이 0, 또는 reset & ~1이 [image_base, image_base + image_size) 밖이면 IMG_BAD_VECTOR. image_base = slot_base + 16.
    • Part B: 먼저 깨진 record 정리(active > 1 → 0, pending이 0/1/NO_PENDING이 아니면 NO_PENDING). 슬롯은 bad_mask에 없고 image_check() == IMG_OK이면 usable.
      • pending이 있으면: 그 슬롯이 usable이 아니거나 attempts >= 3 → bad 표시, pending = NO_PENDING, attempts = 0 하고 일반 규칙으로. 아니면 attempts++ 하고 pending 슬롯 반환.
      • 일반 규칙: usable 중 version 가장 높은 슬롯(같으면 active 유지), active를 그 슬롯으로. usable이 없으면 -1.
    • Part C: boot_confirm() → active = pending, pending = NO_PENDING, attempts = 0. pending이 없으면 아무것도 안 함.
  • 예제 풀어 읽기: A = v1, B = v2 둘 다 정상 → boot_select = 1(B가 더 새것), active = 1. B image[300]의 한 비트를 뒤집으면 CRC가 0xEBD66D8D로 바뀌어 header의 0xB5EDD439와 달라짐 → IMG_BAD_CRC → A로 부팅(0). A = v2, B = v3가 pending이고 B가 확정을 안 하면: 부팅 1·2·3번째는 B(attempts 1→2→3), 4번째에 A로 rollback, bad_mask = 0x02, 이후 B는 다시 안 시도.
  • 놓치기 쉬운 것: erased flash(FF FF FF FF)와 big-endian으로 잘못 쓴 magic은 IMG_BAD_MAGIC; image_size가 0, 7, slot_size - 15, 0xFFFFFFFF면 거부하고 정확히 slot_size - 16(4080)은 통과; slot_size = 8도 거부; header 값과 무관하게 슬롯 밖은 절대 읽지 않기; SP가 RAM_END와 같으면 허용, 0x20020004나 정렬 안 된 0x2001FFFE는 거부; reset이 다른 슬롯(A로 링크된 이미지)이나 이미지 끝을 가리키면 거부; tie일 때 active 유지; boot_confirm() 두 번 불러도 안전; 쓰레기 record({7, 9, ...}) 정리.
  • 구현할 함수
    • Part A: rd32le(p), image_check(slot, slot_size, slot_base, out)
    • Part B: boot_select(st, slots, slot_size)
    • Part C: boot_confirm(st)

1. Problem

A fielded robot updates its MCU firmware over the air. The bootloader keeps two slots (A and B) in flash. A new image is always written into the slot that is not running, then booted on trial. If it never confirms that it is healthy, the bootloader must roll back to the old image.

Each slot is SLOT_SIZE (4096) bytes and starts with a 16-byte little-endian header, followed by the image. The image begins with a Cortex-M vector table.

off 0   magic       u32   0x544F4F42  (bytes 42 4F 4F 54 = "BOOT")
off 4   version     u32
off 8   image_size  u32   8 .. slot_size - 16
off 12  crc32       u32   CRC-32/IEEE over the image_size bytes after the header
off 16  image:  word0 = initial SP,  word1 = reset handler,  code ...

Slot base addresses: A = 0x08004000, B = 0x08024000, so image_base = slot_base + 16. RAM is [0x20000000, 0x20020000].

Part A — image_check(): validate one slot in this order and fill *out on success.

ReturnWhen
IMG_BAD_MAGICmagic is not 0x544F4F42 (erased flash FF FF FF FF lands here)
IMG_BAD_SIZEslot_size < 16, or image_size < 8 (no room for SP + reset), or image_size > slot_size - 16
IMG_BAD_CRCcrc32(image, image_size) differs from the header
IMG_BAD_VECTORSP outside RAM or not 4-byte aligned; reset handler without the Thumb bit (bit 0), or reset & ~1 outside [image_base, image_base + image_size)
IMG_OKall checks pass

Parse the header with explicit byte assembly — do not cast the byte array to a struct.

Part B — boot_select(): a 4-byte BootState record (in EEPROM) survives resets.

  • A slot is usable if it is not marked in bad_mask and image_check() == IMG_OK.
  • If pending is a slot (an update installed but not yet confirmed):
    • pending slot not usable, or attempts >= MAX_ATTEMPTS (3) → mark it bad, pending = NO_PENDING, attempts = 0, then fall through to the normal rule.
    • otherwise attempts++ and return the pending slot (trial boot).
  • Normal rule: return the usable slot with the highest version (tie → active) and set active to it. No usable slot → -1 (stay in the bootloader / DFU mode).
  • Sanitize a corrupt record first (active > 1 → 0, pending not 0/1/NO_PENDING → NO_PENDING).

Part C — boot_confirm(): the application calls it once it is healthy: active = pending, pending = NO_PENDING, attempts = 0. No-op if nothing is pending.

Example

slot A: version 1, size 512, crc 0x4AF3A0F3, SP 0x20020000, reset 0x08004051 -> IMG_OK
slot B: version 2, size 512, crc 0xB5EDD439, SP 0x20020000, reset 0x08024051 -> IMG_OK
state {active 0, pending none, attempts 0, bad 0x00}  -> boot_select = 1 (B is newer), active = 1

flip one bit at B image[300] -> crc32 = 0xEBD66D8D != 0xB5EDD439 -> IMG_BAD_CRC -> boot_select = 0

A = v2, B = v3 just installed, state {active 0, pending 1, attempts 0, bad 0x00}, B never confirms:
  boot 1 -> 1 (attempts 1)   boot 2 -> 1 (attempts 2)   boot 3 -> 1 (attempts 3)
  boot 4 -> 0, bad_mask = 0x02, pending none, attempts 0   (rollback; B is never tried again)

Constraints

  • No malloc. The slot buffers are plain uint8_t arrays (assume no alignment).
  • image_check must never read outside slot[0 .. slot_size), whatever the header says.
  • boot_select runs once per reset; every change to BootState is a persisted write.

Clarifying questions to ask (first 3 minutes)

  1. Endianness of the header? Does the CRC cover the header, or only the image? Which CRC-32 variant?
  2. Is the initial SP allowed to equal the end of RAM (full-descending stack starts at the top)?
  3. Must the reset handler be inside the image, or just inside the slot?
  4. When does attempts increase — before the jump, or after the app starts? Who clears it?
  5. If both slots are valid with the same version, which wins? If none is valid, what do we do?
  6. Can a pending image that was rolled back ever be retried (until a new image is written)?

/* given library: CRC-32/IEEE (reflected, poly 0xEDB88320, init/xorout 0xFFFFFFFF) */
uint32_t crc32(const uint8_t *p, size_t n)
{
    uint32_t c = 0xFFFFFFFFu;
    for (size_t i = 0; i < n; i++) {
        c ^= p[i];
        for (int b = 0; b < 8; b++) c = (c >> 1) ^ (0xEDB88320u & (0u - (c & 1u)));
    }
    return ~c;
}

/* ---------------- test helpers (not part of the answer) ---------------- */
static void wr32le(uint8_t *p, uint32_t v)
{
    p[0] = (uint8_t)v; p[1] = (uint8_t)(v >> 8); p[2] = (uint8_t)(v >> 16); p[3] = (uint8_t)(v >> 24);
}

/* Build a valid image for `slot_base`: SP = RAM_END, reset = image_base + 0x40 | 1. */
static void make_image(uint8_t *slot, uint32_t slot_base, uint32_t version, uint32_t size)
{
    memset(slot, 0xFF, SLOT_SIZE);                       /* erased flash */
    uint8_t *img = slot + HDR_SIZE;
    for (uint32_t i = 0; i < size; i++) img[i] = (uint8_t)(i * 7u + version);
    wr32le(img, RAM_END);
    wr32le(img + 4, (slot_base + HDR_SIZE + 0x40u) | 1u);
    wr32le(slot, IMG_MAGIC);
    wr32le(slot + 4, version);
    wr32le(slot + 8, size);
    wr32le(slot + 12, crc32(img, size));
}

static void reseal(uint8_t *slot, uint32_t size)          /* recompute CRC after editing */
{
    wr32le(slot + 12, crc32(slot + HDR_SIZE, size));
}

static uint8_t flash[2][SLOT_SIZE];

int main(void)
{
    const uint8_t *slots[2] = { flash[0], flash[1] };
    ImgInfo inf = {0};
    BootState st;

    /* 1. normal: A v1, B v2 both valid -> newer B; equal versions -> keep active */
    make_image(flash[0], SLOT_BASE[0], 1, 512);
    make_image(flash[1], SLOT_BASE[1], 2, 512);
    CHECK(image_check(flash[0], SLOT_SIZE, SLOT_BASE[0], &inf) == IMG_OK);
    CHECK(inf.version == 1 && inf.image_size == 512 && inf.sp == 0x20020000u && inf.reset == 0x08004051u);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_OK && inf.reset == 0x08024051u);
    st = (BootState){ 0, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.active == 1);
    make_image(flash[1], SLOT_BASE[1], 1, 512);
    st = (BootState){ 1, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1);       /* tie -> stay on active B */
    st = (BootState){ 0, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0);       /* tie -> stay on active A */

    /* 2. one flipped bit in the newer image -> BAD_CRC -> boot the older slot */
    make_image(flash[1], SLOT_BASE[1], 2, 512);
    flash[1][HDR_SIZE + 300] ^= 0x10;
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_CRC);
    st = (BootState){ 0, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0 && st.active == 0);

    /* 3. bad magic: erased slot, and a big-endian header written by mistake */
    memset(flash[1], 0xFF, SLOT_SIZE);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_MAGIC);
    make_image(flash[1], SLOT_BASE[1], 2, 512);
    flash[1][0] = 0x54; flash[1][1] = 0x4F; flash[1][2] = 0x4F; flash[1][3] = 0x42;
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_MAGIC);

    /* 4. size: 0, 7, slot_size-15 are rejected; exactly slot_size-16 is fine */
    make_image(flash[1], SLOT_BASE[1], 2, 512);
    wr32le(flash[1] + 8, 0);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_SIZE);
    wr32le(flash[1] + 8, 7);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_SIZE);
    wr32le(flash[1] + 8, SLOT_SIZE - HDR_SIZE + 1);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_SIZE);
    wr32le(flash[1] + 8, 0xFFFFFFFFu);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_SIZE);
    make_image(flash[1], SLOT_BASE[1], 2, SLOT_SIZE - HDR_SIZE);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_OK && inf.image_size == 4080);
    CHECK(image_check(flash[1], 8, SLOT_BASE[1], &inf) == IMG_BAD_SIZE);

    /* 5. vector table: no Thumb bit, image linked for slot A flashed into B, bad SP */
    make_image(flash[1], SLOT_BASE[1], 2, 512);
    wr32le(flash[1] + HDR_SIZE + 4, 0x08024050u); reseal(flash[1], 512);       /* bit0 clear */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_VECTOR);
    wr32le(flash[1] + HDR_SIZE + 4, 0x08004051u); reseal(flash[1], 512);       /* points into A */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_VECTOR);
    wr32le(flash[1] + HDR_SIZE + 4, 0x08024211u); reseal(flash[1], 512);       /* past image end */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_VECTOR);
    wr32le(flash[1] + HDR_SIZE + 4, 0x0802420Fu); reseal(flash[1], 512);       /* last halfword ok */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_OK);
    wr32le(flash[1] + HDR_SIZE, 0x20020004u); reseal(flash[1], 512);           /* SP above RAM */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_VECTOR);
    wr32le(flash[1] + HDR_SIZE, 0x2001FFFEu); reseal(flash[1], 512);           /* SP misaligned */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_VECTOR);
    st = (BootState){ 0, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0);

    /* 6. pending update B v3 crashes every time: 3 trials, then rollback to A, B marked bad */
    make_image(flash[0], SLOT_BASE[0], 2, 512);
    make_image(flash[1], SLOT_BASE[1], 3, 512);
    st = (BootState){ 0, 1, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 1);   /* no confirm = crash */
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 2);
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 3);
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0);
    CHECK(st.active == 0 && st.pending == NO_PENDING && st.attempts == 0 && st.bad_mask == 0x02);
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0);       /* newer but bad: stays on A */

    /* 7. pending update confirmed on the 2nd try -> B becomes active and stays */
    st = (BootState){ 0, 1, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 1);   /* crash */
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 2);
    boot_confirm(&st);
    CHECK(st.active == 1 && st.pending == NO_PENDING && st.attempts == 0 && st.bad_mask == 0);
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 0);
    boot_confirm(&st);                                    /* idempotent */
    CHECK(st.active == 1 && st.pending == NO_PENDING);

    /* 8. pending slot corrupt -> rolled back at once; both invalid -> -1 (DFU) */
    flash[1][HDR_SIZE + 100] ^= 0x01;
    st = (BootState){ 0, 1, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0 && st.bad_mask == 0x02 && st.pending == NO_PENDING);
    memset(flash[0], 0xFF, SLOT_SIZE);
    st = (BootState){ 1, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == -1);
    st = (BootState){ 7, 9, 0, 0 };                       /* garbage record + no image */
    CHECK(boot_select(&st, slots, SLOT_SIZE) == -1 && st.active <= 1 && st.pending == NO_PENDING);

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

3. 힌트 (막힐 때 하나씩)

Hint 1 — rd32le 하나로 헤더 전부를 읽는다

p[0] | p[1] << 8 | p[2] << 16 | p[3] << 24 (각각 uint32_t로 캐스트한 다음 shift). 이 함수 하나로 magic, version, size, crc, SP, reset 6개를 모두 읽습니다. uint8_t는 int로 승격되므로 p[3] << 24를 캐스트 없이 쓰면 0x80 이상에서 signed overflow(UB)가 납니다.

Hint 2 — 검사 순서가 곧 안전성

magic → size → CRC → vector 순서입니다. size를 먼저 확인해야 crc32(img, size)가 slot 밖을 읽지 않습니다. 헤더는 신뢰할 수 없는 입력이라 0xFFFFFFFF 같은 값이 그대로 들어올 수 있습니다(테스트 4). reset 범위는 entry - img_base < size 한 번의 unsigned 비교로 끝납니다. entry < img_base이면 뺄셈이 랩어라운드해서 큰 값이 되므로 자동으로 걸러집니다.

Hint 3 — attempts는 점프 "전에" 올린다

새 이미지가 부팅 중에 죽으면 다시 bootloader로 돌아올 때 코드가 아무것도 기록하지 못합니다. 그래서 점프하기 전에 attempts++를 저장해 두고, 앱이 건강하면 boot_confirm()으로 지웁니다. 다음 부팅에서 attempts >= 3이면 "세 번 시도했는데 한 번도 confirm 못 했다" → bad 표시, 롤백합니다.

4. 풀이

4.1 핵심 아이디어 — 플래시 지도부터 그리기

테스트 1번의 두 슬롯을 바이트 단위로 그리면 이렇습니다. 헤더 4필드는 CRC 범위 밖이고, vector table부터 이미지 끝까지가 CRC 범위입니다.

struct 캐스팅을 쓰지 않는 이유 (면접에서 꼭 말할 것):

  • 정렬(alignment): uint8_t 버퍼는 4바이트 정렬이 보장되지 않습니다. Cortex-M0, 또는 M3/M4의 LDRD/LDM에서 비정렬 접근은 HardFault입니다.
  • 엔디언: struct 캐스트는 CPU의 엔디언을 따릅니다. 바이트 조립은 파일 포맷의 엔디언을 코드에 명시하므로 호스트(PC 툴, 테스트)에서도 같은 결과입니다.
  • strict aliasing: uint8_t[]를 Header *로 읽는 것은 C 표준상 UB이고, -O2에서 컴파일러가 읽기 순서를 바꿀 수 있습니다. memcpy로 struct에 복사하는 방법은 합법이지만 엔디언과 padding 문제는 그대로 남습니다.
  • 대가는 거의 없습니다. GCC/Clang은 rd32le 패턴을 인식해서 little-endian 타깃에서는 LDR 한 개(또는 바이트 로드 4개)로 컴파일합니다.

4.2 부팅 상태 머신

BootState 4바이트가 상태 머신 전체입니다. pending이 있으면 TRIAL, 없으면 NORMAL입니다.

핵심은 "앱이 confirm을 못 했다" = "죽었다"로 해석한다는 점입니다. bootloader는 앱이 왜 죽었는지 알 필요가 없습니다. 크래시, 무한 루프(→ watchdog reset), 브라운아웃 모두 같은 경로(confirm 없이 리셋)로 들어옵니다.

solution.c
/*
 * J3  Pick a Boot Slot (A/B images with rollback)
 *
 * A bootloader keeps two firmware slots (A and B) in flash. Each slot starts with a
 * 16-byte little-endian header, followed by the image:
 *
 *   off 0  magic       u32  0x544F4F42 ("BOOT" in memory)
 *   off 4  version     u32
 *   off 8  image_size  u32  bytes of image after the header, 8 .. slot_size-16
 *   off 12 crc32       u32  CRC-32/IEEE over the image bytes (given: crc32())
 *   off 16 image ...   starts with a Cortex-M vector table:
 *                        word0 = initial SP, word1 = reset handler
 *
 * Part A - image_check(): validate one slot, in this order, and fill *out on IMG_OK.
 *   IMG_BAD_MAGIC  : magic mismatch (erased flash 0xFF.. also lands here)
 *   IMG_BAD_SIZE   : slot_size < 16, or image_size < 8 (no room for SP + reset),
 *                    or image_size > slot_size - 16
 *   IMG_BAD_CRC    : crc32(image, image_size) != header crc32
 *   IMG_BAD_VECTOR : SP not in [RAM_START, RAM_END] or not 4-byte aligned, or the reset
 *                    handler has no Thumb bit (bit0) or (addr & ~1) is outside
 *                    [image_base, image_base + image_size), image_base = slot_base + 16
 *   Parse with explicit byte assembly - do not cast the byte array to a struct.
 *
 * Part B - boot_select(): persisted BootState (small EEPROM record) decides the slot.
 *   - A slot is usable if it is not in bad_mask and image_check() == IMG_OK.
 *   - If pending != NO_PENDING (an update that was installed but not yet confirmed):
 *       * pending slot not usable          -> mark it bad, clear pending, attempts = 0
 *       * attempts >= MAX_ATTEMPTS         -> same (rollback)
 *       * otherwise attempts++ and return the pending slot (trial boot)
 *   - Otherwise return the usable slot with the highest version (tie -> active),
 *     and set active to it. No usable slot -> return -1 (stay in bootloader / DFU).
 *   - A corrupt record (active > 1, pending not 0/1/NO_PENDING) is sanitized first.
 * Part C - boot_confirm(): the app calls this once it is healthy:
 *   pending becomes active, pending = NO_PENDING, attempts = 0.
 *
 * Reference solution.  Build & run:  ./run.sh J3 sol
 */
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

#define SLOT_SIZE     4096u
#define HDR_SIZE      16u
#define IMG_MAGIC     0x544F4F42u          /* bytes 42 4F 4F 54 = "BOOT" */
#define RAM_START     0x20000000u
#define RAM_END       0x20020000u          /* 128 KiB; initial SP may equal RAM_END */
#define MAX_ATTEMPTS  3u
#define NO_PENDING    0xFFu

static const uint32_t SLOT_BASE[2] = { 0x08004000u, 0x08024000u };

typedef enum { IMG_OK, IMG_BAD_MAGIC, IMG_BAD_SIZE, IMG_BAD_CRC, IMG_BAD_VECTOR } ImgStatus;
typedef struct { uint32_t version, image_size, sp, reset; } ImgInfo;
typedef struct { uint8_t active; uint8_t pending; uint8_t attempts; uint8_t bad_mask; } BootState;

/* given library: CRC-32/IEEE (reflected, poly 0xEDB88320, init/xorout 0xFFFFFFFF) */
uint32_t crc32(const uint8_t *p, size_t n)
{
    uint32_t c = 0xFFFFFFFFu;
    for (size_t i = 0; i < n; i++) {
        c ^= p[i];
        for (int b = 0; b < 8; b++) c = (c >> 1) ^ (0xEDB88320u & (0u - (c & 1u)));
    }
    return ~c;
}

/* little-endian u32 from any byte address (no alignment needed) */
uint32_t rd32le(const uint8_t *p)
{
    return (uint32_t)p[0] | (uint32_t)p[1] << 8 | (uint32_t)p[2] << 16 | (uint32_t)p[3] << 24;
}

ImgStatus image_check(const uint8_t *slot, size_t slot_size, uint32_t slot_base, ImgInfo *out)
{
    if (slot_size < HDR_SIZE) return IMG_BAD_SIZE;
    if (rd32le(slot) != IMG_MAGIC) return IMG_BAD_MAGIC;

    uint32_t ver  = rd32le(slot + 4);
    uint32_t size = rd32le(slot + 8);
    uint32_t crc  = rd32le(slot + 12);
    if (size < 8u || size > slot_size - HDR_SIZE) return IMG_BAD_SIZE;  /* before touching image */

    const uint8_t *img = slot + HDR_SIZE;
    if (crc32(img, size) != crc) return IMG_BAD_CRC;

    uint32_t sp = rd32le(img), reset = rd32le(img + 4);
    uint32_t img_base = slot_base + HDR_SIZE;
    uint32_t entry = reset & ~1u;
    if (sp < RAM_START || sp > RAM_END || (sp & 3u) != 0) return IMG_BAD_VECTOR;
    if ((reset & 1u) == 0 || entry - img_base >= size) return IMG_BAD_VECTOR; /* one unsigned compare */

    if (out) *out = (ImgInfo){ ver, size, sp, reset };
    return IMG_OK;
}

int boot_select(BootState *st, const uint8_t *slots[2], size_t slot_size)
{
    ImgInfo info[2];
    bool ok[2];

    if (st->active > 1) st->active = 0;                         /* sanitize persisted record */
    if (st->pending > 1 && st->pending != NO_PENDING) st->pending = NO_PENDING;

    for (int i = 0; i < 2; i++)
        ok[i] = !(st->bad_mask & (1u << i)) &&
                image_check(slots[i], slot_size, SLOT_BASE[i], &info[i]) == IMG_OK;

    if (st->pending != NO_PENDING) {
        uint8_t p = st->pending;
        if (ok[p] && st->attempts < MAX_ATTEMPTS) {
            st->attempts++;                    /* persist BEFORE jumping: a crash still counts */
            return p;                          /* trial boot */
        }
        st->bad_mask |= (uint8_t)(1u << p);    /* rollback: never try this image again */
        ok[p] = false;
        st->pending = NO_PENDING;
        st->attempts = 0;
    }

    int pick;
    if (ok[0] && ok[1]) {
        if (info[0].version == info[1].version) pick = st->active;
        else pick = info[1].version > info[0].version ? 1 : 0;
    } else if (ok[0]) pick = 0;
    else if (ok[1])   pick = 1;
    else return -1;                            /* nothing bootable: stay in DFU */

    st->active = (uint8_t)pick;
    return pick;
}

void boot_confirm(BootState *st)
{
    if (st->pending == NO_PENDING) return;     /* already confirmed: no flash write */
    st->active = st->pending;
    st->pending = NO_PENDING;
    st->attempts = 0;
}

/* ---------------- test helpers (not part of the answer) ---------------- */
static void wr32le(uint8_t *p, uint32_t v)
{
    p[0] = (uint8_t)v; p[1] = (uint8_t)(v >> 8); p[2] = (uint8_t)(v >> 16); p[3] = (uint8_t)(v >> 24);
}

/* Build a valid image for `slot_base`: SP = RAM_END, reset = image_base + 0x40 | 1. */
static void make_image(uint8_t *slot, uint32_t slot_base, uint32_t version, uint32_t size)
{
    memset(slot, 0xFF, SLOT_SIZE);                       /* erased flash */
    uint8_t *img = slot + HDR_SIZE;
    for (uint32_t i = 0; i < size; i++) img[i] = (uint8_t)(i * 7u + version);
    wr32le(img, RAM_END);
    wr32le(img + 4, (slot_base + HDR_SIZE + 0x40u) | 1u);
    wr32le(slot, IMG_MAGIC);
    wr32le(slot + 4, version);
    wr32le(slot + 8, size);
    wr32le(slot + 12, crc32(img, size));
}

static void reseal(uint8_t *slot, uint32_t size)          /* recompute CRC after editing */
{
    wr32le(slot + 12, crc32(slot + HDR_SIZE, size));
}

static uint8_t flash[2][SLOT_SIZE];

int main(void)
{
    const uint8_t *slots[2] = { flash[0], flash[1] };
    ImgInfo inf = {0};
    BootState st;

    /* 1. normal: A v1, B v2 both valid -> newer B; equal versions -> keep active */
    make_image(flash[0], SLOT_BASE[0], 1, 512);
    make_image(flash[1], SLOT_BASE[1], 2, 512);
    CHECK(image_check(flash[0], SLOT_SIZE, SLOT_BASE[0], &inf) == IMG_OK);
    CHECK(inf.version == 1 && inf.image_size == 512 && inf.sp == 0x20020000u && inf.reset == 0x08004051u);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_OK && inf.reset == 0x08024051u);
    st = (BootState){ 0, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.active == 1);
    make_image(flash[1], SLOT_BASE[1], 1, 512);
    st = (BootState){ 1, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1);       /* tie -> stay on active B */
    st = (BootState){ 0, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0);       /* tie -> stay on active A */

    /* 2. one flipped bit in the newer image -> BAD_CRC -> boot the older slot */
    make_image(flash[1], SLOT_BASE[1], 2, 512);
    flash[1][HDR_SIZE + 300] ^= 0x10;
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_CRC);
    st = (BootState){ 0, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0 && st.active == 0);

    /* 3. bad magic: erased slot, and a big-endian header written by mistake */
    memset(flash[1], 0xFF, SLOT_SIZE);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_MAGIC);
    make_image(flash[1], SLOT_BASE[1], 2, 512);
    flash[1][0] = 0x54; flash[1][1] = 0x4F; flash[1][2] = 0x4F; flash[1][3] = 0x42;
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_MAGIC);

    /* 4. size: 0, 7, slot_size-15 are rejected; exactly slot_size-16 is fine */
    make_image(flash[1], SLOT_BASE[1], 2, 512);
    wr32le(flash[1] + 8, 0);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_SIZE);
    wr32le(flash[1] + 8, 7);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_SIZE);
    wr32le(flash[1] + 8, SLOT_SIZE - HDR_SIZE + 1);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_SIZE);
    wr32le(flash[1] + 8, 0xFFFFFFFFu);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_SIZE);
    make_image(flash[1], SLOT_BASE[1], 2, SLOT_SIZE - HDR_SIZE);
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_OK && inf.image_size == 4080);
    CHECK(image_check(flash[1], 8, SLOT_BASE[1], &inf) == IMG_BAD_SIZE);

    /* 5. vector table: no Thumb bit, image linked for slot A flashed into B, bad SP */
    make_image(flash[1], SLOT_BASE[1], 2, 512);
    wr32le(flash[1] + HDR_SIZE + 4, 0x08024050u); reseal(flash[1], 512);       /* bit0 clear */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_VECTOR);
    wr32le(flash[1] + HDR_SIZE + 4, 0x08004051u); reseal(flash[1], 512);       /* points into A */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_VECTOR);
    wr32le(flash[1] + HDR_SIZE + 4, 0x08024211u); reseal(flash[1], 512);       /* past image end */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_VECTOR);
    wr32le(flash[1] + HDR_SIZE + 4, 0x0802420Fu); reseal(flash[1], 512);       /* last halfword ok */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_OK);
    wr32le(flash[1] + HDR_SIZE, 0x20020004u); reseal(flash[1], 512);           /* SP above RAM */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_VECTOR);
    wr32le(flash[1] + HDR_SIZE, 0x2001FFFEu); reseal(flash[1], 512);           /* SP misaligned */
    CHECK(image_check(flash[1], SLOT_SIZE, SLOT_BASE[1], &inf) == IMG_BAD_VECTOR);
    st = (BootState){ 0, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0);

    /* 6. pending update B v3 crashes every time: 3 trials, then rollback to A, B marked bad */
    make_image(flash[0], SLOT_BASE[0], 2, 512);
    make_image(flash[1], SLOT_BASE[1], 3, 512);
    st = (BootState){ 0, 1, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 1);   /* no confirm = crash */
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 2);
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 3);
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0);
    CHECK(st.active == 0 && st.pending == NO_PENDING && st.attempts == 0 && st.bad_mask == 0x02);
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0);       /* newer but bad: stays on A */

    /* 7. pending update confirmed on the 2nd try -> B becomes active and stays */
    st = (BootState){ 0, 1, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 1);   /* crash */
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 2);
    boot_confirm(&st);
    CHECK(st.active == 1 && st.pending == NO_PENDING && st.attempts == 0 && st.bad_mask == 0);
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 1 && st.attempts == 0);
    boot_confirm(&st);                                    /* idempotent */
    CHECK(st.active == 1 && st.pending == NO_PENDING);

    /* 8. pending slot corrupt -> rolled back at once; both invalid -> -1 (DFU) */
    flash[1][HDR_SIZE + 100] ^= 0x01;
    st = (BootState){ 0, 1, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == 0 && st.bad_mask == 0x02 && st.pending == NO_PENDING);
    memset(flash[0], 0xFF, SLOT_SIZE);
    st = (BootState){ 1, NO_PENDING, 0, 0 };
    CHECK(boot_select(&st, slots, SLOT_SIZE) == -1);
    st = (BootState){ 7, 9, 0, 0 };                       /* garbage record + no image */
    CHECK(boot_select(&st, slots, SLOT_SIZE) == -1 && st.active <= 1 && st.pending == NO_PENDING);

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

코드 읽는 포인트

  • rd32le의 각 바이트는 (uint32_t)로 캐스트한 뒤 shift합니다. p[3] << 24를 그대로 쓰면 int shift라 슬롯 B crc의 0xB5 << 24에서 UB가 납니다(UBSan이 잡음).
  • entry - img_base >= size 한 줄이 "아래쪽 밖"과 "위쪽 밖"을 동시에 검사합니다. 랩어라운드 안전 시간 비교와 같은 트릭입니다.
  • attempts++는 return p 바로 전에 있습니다. 실제 펌웨어에서는 여기서 EEPROM/플래시 쓰기가 완료된 뒤 점프합니다.
  • 롤백한 뒤 ok[p] = false로 두고 NORMAL 규칙으로 fall through합니다. 덕분에 "A도 깨져 있으면 -1"이 따로 코드 없이 처리됩니다.
  • boot_confirm은 이미 confirm된 상태면 아무것도 쓰지 않습니다. 앱이 매 부팅마다 호출해도 EEPROM 수명을 깎지 않습니다.

4.5 복잡도

  • image_check: 시간 O(image_size) (CRC가 지배), 추가 메모리 O(1).
  • boot_select: 슬롯 2개 검사 → O(slot_size), 상태 4바이트. 테이블 없는 bitwise CRC는 바이트당 8회 루프라, 실제 MCU에서는 256-entry 테이블(1 KiB) 또는 하드웨어 CRC 주변장치(TM4C129x에는 CCM/CRC 모듈이 있음)를 씁니다.

5. 임베디드 관점으로 말할 것

  • 면접관 맥락: Jason은 Charles Machine Works에서 TM4C129x용 bootloader와 공통 소프트웨어 라이브러리를 개발했습니다. 현장에 나가 있는 로봇은 사람이 JTAG를 꽂아 줄 수 없으므로, OTA 업데이트가 실패해도 반드시 부팅 가능한 이미지가 하나는 남는 것이 bootloader의 존재 이유입니다. "A/B + trial boot + rollback"이 그 답이라고 말하면 됩니다.
  • 헤더는 신뢰할 수 없는 입력: 반쯤 쓰다 전원이 나간 슬롯, 지워진 슬롯(0xFF), 잘못된 슬롯 주소로 링크된 이미지가 모두 현실에서 일어납니다. 그래서 size를 CRC보다 먼저, vector table을 CRC 다음에 검사합니다. 테스트 5의 "A용 이미지를 B에 쓴 경우"는 position-dependent 링크 때문에 실제로 자주 나는 사고입니다.
  • VTOR 정렬 주의: 이 문제는 단순하게 헤더 16바이트 바로 뒤에 vector table을 두었지만, SCB->VTOR는 테이블 크기 이상의 2의 거듭제곱 정렬(최소 128 B, IRQ가 많은 TM4C129x는 1 KiB 정도)이 필요합니다. 실제로는 MCUboot처럼 헤더를 0x200까지 패딩하거나 trailer 방식(이미지 끝에 메타데이터)을 씁니다. 이 점을 짚으면 실무 경험이 드러납니다.
  • 주소 체계: 예제 주소는 STM32 스타일(0x0800_0000)입니다. TM4C129x는 플래시가 0x0000_0000부터 시작하고 TivaWare boot_loader는 APP_START_ADDRESS로 앱 위치를 정합니다. 로직은 동일합니다.
  • 상태 기록 = 플래시 쓰기: BootState가 바뀔 때마다 EEPROM/플래시에 씁니다. 그래서 바뀔 때만 쓰고(boot_confirm no-op), 레코드에 CRC나 시퀀스 번호를 붙여 두 벌로 번갈아 쓰면 쓰다가 전원이 나가도 안전합니다(→ Follow-up).
  • 관련 문제: 프레임 파싱 + CRC는 E2, 비트 조작은 T2-6.

6. Follow-up 질문과 답

Follow-up (English)답
What does the actual jump look like on Cortex-M?IRQ 끄기 → bootloader가 켠 SysTick/주변장치 정지, NVIC enable/pending 전부 클리어 → SCB->VTOR = image_base → DSB/ISB → MSP = word0 → word1로 branch. 아래 코드 참고. 앱의 reset handler는 .data/.bss를 다시 초기화하므로 bootloader의 전역 상태는 넘어가지 않습니다.
What if power is lost in the middle of writing the update?순서가 핵심입니다. ① 비활성 슬롯 지우기 → ② 이미지 본문 쓰기 → ③ 다시 읽어서 CRC 확인 → ④ 마지막에 헤더(magic) 쓰기 → ⑤ pending 설정. 어느 단계에서 끊겨도 magic이 없거나 CRC가 틀려서 그 슬롯은 무시되고, 실행 중이던 슬롯은 건드리지 않았으므로 그대로 부팅됩니다. BootState 자체도 두 벌 + 시퀀스 번호 + CRC로 기록합니다.
Is CRC enough? What about authenticity?CRC는 우연한 손상만 잡습니다. 공격자는 CRC를 다시 계산하면 그만입니다. 방산 로봇이면 SHA-256 해시 + ECDSA P-256(또는 Ed25519) 서명을 검증하고, 공개키는 bootloader(가능하면 OTP/ROM)에 둡니다. 서명 검증은 수십~수백 ms 걸리지만 부팅 때 한 번이면 됩니다. bootloader 자체는 쓰기 보호(flash protection)를 걸어 둡니다.
What is the watchdog's role in a trial boot?앱이 크래시가 아니라 멈춰 버리면(deadlock, 무한 루프) 리셋이 안 일어나서 롤백도 안 됩니다. 그래서 bootloader가 점프 전에 WDT를 켜고, 앱은 끌 수 없게 둡니다. 앱이 멈추면 WDT 리셋 → attempts가 쌓여 롤백됩니다. confirm은 "부팅 직후"가 아니라 센서·통신·제어 루프가 실제로 돌기 시작한 뒤에 해야 의미가 있습니다.
How do you stop an attacker from installing an old, vulnerable signed image?anti-rollback counter: 서명된 헤더에 security_version을 넣고, 단조 증가 카운터(OTP fuse 또는 보호된 플래시)보다 작으면 거부합니다. 카운터는 새 이미지가 confirm된 뒤에만 올립니다(trial 중에 올리면 롤백할 곳이 사라짐). 이 문제의 version은 선택용일 뿐 보안 장치가 아닙니다.
How does this map to embedded Linux?같은 패턴입니다. U-Boot의 bootcount/bootlimit/altbootcmd가 attempts/MAX_ATTEMPTS/rollback이고, 사용자 공간이 부팅 성공 후 bootcount를 0으로(=confirm) 만듭니다. rootfs A/B 파티션은 RAUC, SWUpdate, Mender가 관리하고, 업데이트 툴이 U-Boot env(BOOT_ORDER, BOOT_x_LEFT)를 바꿉니다. MCU 쪽 대응물은 MCUboot(swap/test/confirm)입니다.
The BootState record itself gets corrupted.이 코드처럼 범위를 벗어난 값은 안전한 기본값으로 바꿉니다. 더 나아가 레코드에 CRC를 붙이고 두 벌을 번갈아 쓰면(ping-pong), 깨진 쪽은 버리고 시퀀스 번호가 큰 유효한 쪽을 씁니다.

점프 코드 (Follow-up 1)

typedef void (*entry_fn)(void);

static void jump_to_image(uint32_t image_base)          /* already validated by image_check() */
{
    uint32_t sp    = *(const volatile uint32_t *)image_base;        /* real flash: aligned */
    uint32_t reset = *(const volatile uint32_t *)(image_base + 4);

    __disable_irq();
    SysTick->CTRL = 0;                                   /* stop bootloader timers */
    for (unsigned i = 0; i < 8; i++) {                   /* disable + clear every IRQ */
        NVIC->ICER[i] = 0xFFFFFFFFu;
        NVIC->ICPR[i] = 0xFFFFFFFFu;
    }
    SCB->VTOR = image_base;                              /* needs table-size alignment */
    __DSB(); __ISB();
    __set_MSP(sp);                                       /* after this, no locals on stack */
    ((entry_fn)reset)();                                 /* bit0 = 1 keeps Thumb state */
    for (;;) { }                                         /* never returns */
}

__set_MSP 뒤에는 기존 스택이 사라지므로 sp, reset이 레지스터에 남아 있어야 합니다. 그래서 실무에서는 마지막 두 줄을 짧은 inline asm(msr msp, r0; bx r1)으로 쓰기도 합니다. 앱 쪽 startup 코드가 __enable_irq()로 PRIMASK를 다시 풉니다.

7. 자주 하는 실수

  • rd32le에서 캐스트 없이 p[3] << 24 → 바이트가 0x80 이상이면 signed overflow(UB). 슬롯 B의 crc 바이트 39 D4 ED B5(p[3] = 0xB5)가 바로 그 경우입니다.
  • size 검사 전에 CRC 계산 → image_size = 0xFFFFFFFF에서 버퍼 밖 읽기(ASan이 잡음, 실제 MCU면 HardFault 또는 엉뚱한 메모리 CRC) → 테스트 4.
  • reset 범위를 entry >= img_base && entry <= img_base + size로 써서 끝 경계 포함 → 0x08024211 통과 → 테스트 5. 또 Thumb bit을 지우지 않고 범위를 비교해서 마지막 halfword 경계를 틀림.
  • attempts를 점프 후 앱에서 올림 → 앱이 그 코드까지 못 가고 죽으면 영원히 trial 반복(boot loop) → 테스트 6이 롤백하지 않음.
  • 롤백할 때 bad_mask를 안 세움 → 다음 부팅에서 NORMAL 규칙이 "B가 더 새롭다"며 깨진 B를 다시 고름 → 테스트 6의 5번째 부팅 실패.
  • 동점에서 active가 아니라 무조건 A(또는 B)를 고름 → 테스트 1 후반(active = 1 동점 → 1, active = 0 동점 → 0).
  • pending 슬롯이 이미 깨져 있는 경우를 처리하지 않아 trial로 깨진 이미지에 점프 → 테스트 8.
