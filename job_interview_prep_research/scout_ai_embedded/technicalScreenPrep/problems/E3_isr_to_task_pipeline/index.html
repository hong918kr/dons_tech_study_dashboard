E3 · Data-Ready ISR → Task Overheat Pipeline

IDE3
PriorityP1
PatternISR → SPSC ring → task + hysteresis + critical section
Time35 min

파일: stub.c(여기서 풀기) · solution.c(정답) · 실행: ./run.sh E3 / ./run.sh E3 sol

1. Problem

A temperature ADC raises a DATA-READY interrupt every 10 ms. Build the firmware pipeline from that interrupt to the cooling fan:

  • ISR TEMP_DRDY_IRQHandler() captures { millis(), ADC_DATA } and pushes it into an SPSC ring buffer. If the ring is full, it drops the new sample and increments g_overrun_count. Nothing else happens in the ISR.
  • Task temp_task_poll() runs from the main loop, whenever it gets CPU time. In this order it:
    1. reads and clears g_overrun_count with interrupts masked (irq_disable() / irq_enable()), and adds the value to g_task.overruns_total. Simulation rule: call SIM_PREEMPT() between the read and the clear. That is the point where a real IRQ could arrive, and the harness injects one there.
    2. drains the ring. For each sample: if a previous sample exists and t - last_t > STALE_MS (50 ms, wrap-safe), reset the detector streak; convert with adc_to_c10(); call det_update(). On EV_OVERHEAT call fan_set(true), on EV_RECOVERED call fan_set(false), and append {t_ms, c10, ev} to g_task.log (write at most LOG_CAP, always count n_log).
  • Conversion (TMP36-style sensor, 12-bit ADC, 3.3 V reference): use the low 12 bits only. mV = code * 3300 / 4096 (truncating), then c10 = mV - 500.
  • The ring has RB_SIZE = 8 slots (power of two, all usable) and free-running uint32_t C11 atomic head/tail. The ISR writes only head, the task writes only tail.
  • Already provided: the fake hardware (ADC_DATA, millis(), irq_disable/enable with a one-bit pending latch, fan_set), the hysteresis detector from T1-2 (on at >= 850 ×3, off at <= 800 ×3), temp_task_init(), and the harness. No malloc, no real threads. The tests call the ISR at scripted points.
#define RB_SIZE 8u
typedef struct { uint32_t t_ms; uint16_t code; } RawSample;
typedef struct {
    RawSample buf[RB_SIZE];
    _Atomic uint32_t head;           /* written only by the ISR (producer)  */
    _Atomic uint32_t tail;           /* written only by the task (consumer) */
} SampleRing;

extern SampleRing        g_ring;
extern volatile uint32_t g_overrun_count;   /* ISR ++, task read-and-clear */

int16_t adc_to_c10(uint16_t code);
bool    ring_push(SampleRing *r, RawSample s);     /* ISR side  */
bool    ring_pop (SampleRing *r, RawSample *out);  /* task side */
void    TEMP_DRDY_IRQHandler(void);
void    temp_task_poll(void);

Example

high = 850, low = 800, n_confirm = 3, one IRQ every 10 ms from t = 1000,
task polls after every 2 IRQs

c10 per IRQ : 820 840 852 860 870 880 | 830 790 780 770 760 760
t_ms        : 1000 ...                  1040 ...              1090
-> EV_OVERHEAT  at t = 1040 (c10 870): fan_set(true)
-> EV_RECOVERED at t = 1090 (c10 770): fan_set(false)

burst: 20 IRQs while the task is blocked -> 8 queued, g_overrun_count = 12;
       next poll: processed 8, overruns_total = 12, g_overrun_count = 0

Constraints

  • Single core. The ISR can preempt the task at any instruction unless it is masked. The task never preempts the ISR.
  • millis() is uint32_t and wraps (after about 49.7 days).
  • While masked, a second DRDY edge on the same line is merged into the first (hardware pending latch). Keep the masked section short.

Clarifying questions to ask (first 3 minutes)

  1. When the ring is full, drop the newest or overwrite the oldest? Must the loss be reported?
  2. What goes in the ISR, and what can wait for the task? Is there an RTOS, or a bare-metal super-loop?
  3. Is the timestamp taken at capture (ISR) or at processing (task)?
  4. Is it single-core? Can another, higher-priority ISR also touch the counter?
  5. What is the sample rate, and what is the worst-case task latency? (This sizes the ring.)
  6. What should happen after a gap in the data: keep the confirmation streak or restart it?

/*
 * E3  Data-Ready ISR -> Task Overheat Pipeline
 *
 * A temperature ADC raises a DATA-READY interrupt every 10 ms. The ISR must be tiny:
 * it captures (millis(), ADC_DATA) and pushes it into an SPSC ring buffer. A main-loop
 * task (temp_task_poll) drains the ring, converts ADC codes to 0.1 degC, runs a
 * hysteresis detector and switches the fan. Lost samples must be COUNTED, never silent.
 *
 * Definitions (agreed with the interviewer):
 *   - Ring: RB_SIZE (power of two) RawSample slots, all usable. head/tail are free-running
 *     uint32_t C11 atomics; ISR writes only head, task writes only tail.
 *     Full ring -> drop the NEW sample and increment g_overrun_count (ISR side).
 *   - adc_to_c10(code): use the low 12 bits only. mV = code * 3300 / 4096 (truncate),
 *     c10 = mV - 500   (TMP36-style: 500 mV at 0 degC, 10 mV/degC).
 *   - temp_task_poll(), in this order:
 *       1) read-and-clear g_overrun_count with IRQs masked (irq_disable/irq_enable),
 *          add it to g_task.overruns_total. Simulation rule: call SIM_PREEMPT() between
 *          the read and the clear -- it is where a real IRQ could arrive.
 *       2) pop every sample. If a previous sample exists and (t - last_t) > STALE_MS
 *          (wrap-safe), reset the detector streak first. Then det_update().
 *          EV_OVERHEAT -> fan_set(true), EV_RECOVERED -> fan_set(false), and log
 *          {sample t_ms, c10, event} (write at most LOG_CAP, always count n_log).
 *   - No malloc, no real threads: the harness calls the ISR at scripted points.
 *
 * Build & run:  ./run.sh E3
 */

#include <string.h>

#define RB_MASK   (RB_SIZE - 1u)
#define ADC_MASK  0x0FFFu            /* 12-bit converter; bits 15..12 are status junk */
#define VREF_MV   3300u

#define LOG_CAP   8u

uint32_t millis(void) { return g_now_ms; }

bool g_fan_on;
int  g_fan_calls;
void fan_set(bool on) { g_fan_on = on; g_fan_calls++; }

void TEMP_DRDY_IRQHandler(void);

/* Simulated NVIC: one pending latch per IRQ line. A second edge while pending is lost. */
static bool g_irq_masked, g_irq_pending;
static uint32_t g_irq_raised, g_irq_coalesced;
void irq_disable(void) { g_irq_masked = true; }
void irq_enable(void)
{
    g_irq_masked = false;
    if (g_irq_pending) { g_irq_pending = false; TEMP_DRDY_IRQHandler(); }  /* pended IRQ fires now */
}
static void raise_irq(void)
{
    g_irq_raised++;
    if (!g_irq_masked) { TEMP_DRDY_IRQHandler(); return; }
    if (g_irq_pending) g_irq_coalesced++;
    g_irq_pending = true;
}
/* harness: one scripted DRDY edge, then time advances by one period */
static void irq(uint16_t code) { ADC_DATA = code; raise_irq(); g_now_ms += PERIOD_MS; }

static int      g_preempt_irqs;      /* how many IRQs the harness injects at SIM_PREEMPT() */
static uint16_t g_preempt_code;
void SIM_PREEMPT(void) { while (g_preempt_irqs > 0) { g_preempt_irqs--; irq(g_preempt_code); } }

/* ================= provided: hysteresis detector (from T1-2) ================= */
typedef enum { EV_NONE, EV_OVERHEAT, EV_RECOVERED } Event;
typedef struct { int16_t high, low; uint8_t n_confirm, streak; bool overheated; } Detector;

void det_init(Detector *d, int16_t high, int16_t low, uint8_t n_confirm)
{
    *d = (Detector){ high, low, n_confirm, 0, false };
}
Event det_update(Detector *d, int16_t c10)
{
    bool toward = d->overheated ? (c10 <= d->low) : (c10 >= d->high);
    if (!toward) { d->streak = 0; return EV_NONE; }
    if (++d->streak < d->n_confirm) return EV_NONE;
    d->streak = 0;
    d->overheated = !d->overheated;
    return d->overheated ? EV_OVERHEAT : EV_RECOVERED;
}

/* ================= shared state ================= */
typedef struct { uint32_t t_ms; uint16_t code; } RawSample;
typedef struct {
    RawSample buf[RB_SIZE];
    _Atomic uint32_t head;           /* written only by the ISR (producer)  */
    _Atomic uint32_t tail;           /* written only by the task (consumer) */
} SampleRing;

typedef struct { uint32_t t_ms; int16_t c10; Event ev; } LogEntry;
typedef struct {
    Detector det;
    bool     has_last;
    uint32_t last_t_ms;              /* capture time of the last processed sample */

/* ================= tests ================= */
/* ADC codes -> c10 (computed with adc_to_c10) */
enum { C760 = 1564, C770 = 1577, C780 = 1589, C790 = 1602, C800 = 1614, C820 = 1639,
       C830 = 1651, C840 = 1664, C852 = 1679, C860 = 1689, C870 = 1701, C880 = 1713,
       C700 = 1490, C900 = 1738 };

static void reset(uint32_t t0)
{
    g_now_ms = t0;
    g_irq_masked = g_irq_pending = false;
    g_irq_raised = g_irq_coalesced = 0;
    g_preempt_irqs = 0;
    g_fan_on = false; g_fan_calls = 0;
    temp_task_init(850, 800, 3);            /* on at >= 85.0 C x3, off at <= 80.0 C x3 */
}
static uint32_t ring_count(void) { return atomic_load(&g_ring.head) - atomic_load(&g_ring.tail); }
/* every raised IRQ must be processed, still queued, counted as overrun, or coalesced */
static bool conserved(void)
{
    return g_irq_raised == g_task.processed + ring_count() + g_task.overruns_total
                           + g_overrun_count + g_irq_coalesced;
}

int main(void)
{
    /* 1. normal: ramp up -> fan on at sample 4 (t=1040), cool down -> fan off (t=1090).
          Task polls after every 2 IRQs, so events are reported with CAPTURE time. */
    reset(1000);
    const uint16_t up[] = { C820, C840, C852, C860, C870, C880 };
    for (int i = 0; i < 6; i++) {
        irq(up[i]);
        if (i % 2 == 1) temp_task_poll();
        if (i == 3) CHECK(!g_fan_on && g_fan_calls == 0);
    }
    CHECK(g_fan_on && g_fan_calls == 1 && g_task.n_log == 1);
    CHECK(g_task.log[0].ev == EV_OVERHEAT && g_task.log[0].t_ms == 1040 && g_task.log[0].c10 == 870);
    const uint16_t down[] = { C830, C790, C780, C770, C760, C760 };   /* 830 is in the band */
    for (int i = 0; i < 6; i++) { irq(down[i]); if (i % 2 == 1) temp_task_poll(); }
    CHECK(!g_fan_on && g_fan_calls == 2 && g_task.n_log == 2);
    CHECK(g_task.log[1].ev == EV_RECOVERED && g_task.log[1].t_ms == 1090 && g_task.log[1].c10 == 770);
    CHECK(g_task.processed == 12 && g_task.overruns_total == 0 && conserved());

    /* 2. conversion: endpoints, truncation below 0 C, status bits ignored */
    CHECK(adc_to_c10(0) == -500);
    CHECK(adc_to_c10(4095) == 2799);
    CHECK(adc_to_c10(620) == -1);
    CHECK(adc_to_c10(1676) == 850 && adc_to_c10(0xF000u | 1676u) == 850);

    /* 3. burst: 20 IRQs while the task is blocked, ring holds 8 -> 12 overruns, oldest kept */
    reset(0);
    for (int i = 0; i < 20; i++) irq(C800);
    CHECK(ring_count() == RB_SIZE && g_overrun_count == 12);
    temp_task_poll();
    CHECK(g_task.processed == 8 && g_task.overruns_total == 12 && g_overrun_count == 0);
    CHECK(ring_count() == 0 && g_task.last_t_ms == 70);    /* samples 0..70 ms survived */
    irq(C800); temp_task_poll();                            /* t = 200: pipeline still sane */
    CHECK(g_task.processed == 9 && g_task.last_t_ms == 200 && g_task.overruns_total == 12);
    CHECK(g_fan_calls == 0 && conserved());

    /* 4. race: an IRQ arrives between read and clear of g_overrun_count (ring is full) */
    reset(0);
    for (int i = 0; i < 10; i++) irq(C800);                 /* 8 queued, 2 overruns */
    g_preempt_irqs = 1; g_preempt_code = C800;
    temp_task_poll();
    CHECK(g_preempt_irqs == 0 && g_task.processed == 8 && conserved());
    temp_task_poll();                                       /* collects anything left over */
    CHECK(g_task.overruns_total == 3 && g_overrun_count == 0 && g_irq_raised == 11 && conserved());

    /* 5. spikes: never 3 hot samples in a row -> fan never touched */
    reset(0);
    const uint16_t sp[] = { C900, C700, C900, C700, C900, C900, C700 };
    for (int i = 0; i < 7; i++) { irq(sp[i]); temp_task_poll(); }
    CHECK(g_fan_calls == 0 && !g_fan_on && g_task.n_log == 0);

    /* 6. millis() wraps during confirmation: t = 4294967281, 4294967291, 5 -> event at t=5 */
    reset(UINT32_MAX - 14u);
    for (int i = 0; i < 3; i++) irq(C870);
    temp_task_poll();
    CHECK(g_fan_on && g_task.n_log == 1 && g_task.log[0].t_ms == 5);

    /* 7. stale gap: 0, 10, (gap 60 ms) 70, 80, 90 -> streak restarts at 70, event at 90 */
    reset(0);
    irq(C870); irq(C870);
    g_now_ms = 70;
    irq(C870); irq(C870); temp_task_poll();
    CHECK(!g_fan_on && g_fan_calls == 0);
    irq(C870); temp_task_poll();
    CHECK(g_fan_on && g_task.n_log == 1 && g_task.log[0].t_ms == 90);

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

3. 힌트 (막힐 때 하나씩)

Hint 1 — ISR에는 무엇만 넣나?

ISR은 "레지스터 읽기 + 시각 찍기 + push + 실패 시 카운트" 네 가지만 합니다. 변환, 비교, 로그, printf, 팬 제어는 모두 task에서 합니다. ISR을 짧게 만들어야 다른 인터럽트의 지연이 줄고, 재진입이나 락 문제도 생기지 않습니다. ADC_DATA를 읽는 동작이 DRDY 플래그를 지우는 경우가 많아서, 이 읽기는 ISR에서 꼭 한 번 해야 합니다.

Hint 2 — 링버퍼는 락이 필요 없다, 카운터는 필요하다

SPSC 링은 각 인덱스를 한쪽만 씁니다(head는 ISR, tail은 task). 그래서 "데이터 쓰기 → head 공개(release)"와 "head 읽기(acquire) → 데이터 읽기" 순서만 지키면 됩니다. 반면 g_overrun_count는 양쪽이 다 씁니다(ISR은 ++, task는 = 0). 그래서 n = cnt; cnt = 0; 사이에 ISR이 끼어들면 그 사이에 늘어난 값이 사라집니다. 이 두 줄을 irq_disable()과 irq_enable()로 감싸세요.

Hint 3 — 시간 비교는 뺄셈으로

stale 검사는 s.t_ms - last_t_ms > STALE_MS처럼 부호 없는 뺄셈 결과를 비교합니다. s.t_ms > last_t_ms + STALE_MS는 last_t_ms + 50이 먼저 랩되면 거짓 stale이 됩니다. 테스트 6번이 이 실수를 잡습니다.

4. 풀이

4.1 핵심 아이디어 — 그림으로 보기

일을 두 문맥으로 나누는 것이 핵심입니다. ISR(µs 단위, 절대 막히면 안 됨)은 캡처만 하고, task(ms 단위, 늦어도 됨)는 판단을 합니다. 둘 사이 데이터는 SPSC 링으로 넘기고, 손실은 카운터로 넘깁니다.

공유 상태가 두 종류이고 보호 방법도 다릅니다.

공유 상태누가 쓰나보호 방법이유
g_ring.headISR만_Atomic + release store쓰는 쪽이 하나라 락이 필요 없고, 순서만 보장하면 됨
g_ring.tailtask만_Atomic + release store위와 같음
g_ring.buf[]ISR이 쓰고 task가 읽음head/tail의 acquire/release 쌍데이터가 인덱스보다 먼저 보여야 함
g_overrun_countISR ++, task = 0volatile + critical section읽기-지우기 두 단계가 끊기면 안 됨

4.2 volatile vs atomic vs critical section

  • volatile: 컴파일러가 매번 메모리에서 다시 읽고 쓰게 합니다. 하드웨어 레지스터(ADC_DATA)나 ISR이 바꾸는 플래그에 필요합니다. 하지만 원자성도, 다른 변수와의 순서도 보장하지 않습니다. cnt++는 여전히 load-add-store 세 단계입니다.
  • C11 atomic + memory order: atomic_store_explicit(&head, h+1, memory_order_release)는 "이 store 전에 쓴 buf[] 내용이 먼저 보인다"를 보장하고, 소비자의 memory_order_acquire load와 짝을 이룹니다. 단일 코어 MCU에서는 사실상 컴파일러 재배치 방지이고, 멀티코어나 캐시가 있는 SoC에서는 DMB 같은 배리어로 바뀝니다. 자기 인덱스를 읽을 때는 relaxed로 충분합니다(자기만 씀).
  • critical section(irq_disable/enable, Cortex-M이면 __disable_irq()·PRIMASK 또는 BASEPRI): 여러 단계를 하나로 묶을 때 씁니다. 읽기-지우기(read-and-clear)가 대표 예입니다. 대안은 atomic_exchange(&cnt, 0)인데, Cortex-M3/M4에서는 LDREX/STREX로 구현됩니다. Cortex-M0에는 LDREX/STREX가 없어서 결국 마스킹을 씁니다.

마스킹을 해도 IRQ는 사라지지 않고 미뤄집니다(NVIC pending bit). 그래서 테스트 4에서 마스킹한 버전은 첫 poll이 2를 가져가고, enable 직후 실행된 ISR이 링이 꽉 차 있어 cnt = 1로 만들고, 두 번째 poll이 1을 더 가져가 overruns_total = 3이 됩니다. 마스킹하지 않은 버전은 3이 0으로 지워져 total이 2에서 멈춥니다. harness의 보존 법칙 raised == processed + ring + overruns_total + g_overrun_count + coalesced가 깨집니다(11 ≠ 10).

4.3 버스트와 overrun — 타임라인

  • drop-newest라서 살아남는 건 가장 오래된 0–70 ms 샘플 8개입니다. 그래서 drain 후 last_t_ms == 70입니다.
  • 다음 IRQ(#21, t=200)는 직전 처리 샘플(70)과 130 ms 떨어져 있어 stale 규칙으로 streak가 리셋됩니다. 데이터가 빠진 구간을 건너서 "연속 3회"를 이어 붙이면 안 되기 때문입니다.

💡 정답 코드 펼치기 (30분 풀어 본 다음에)
solution.c
/*
 * E3  Data-Ready ISR -> Task Overheat Pipeline
 *
 * A temperature ADC raises a DATA-READY interrupt every 10 ms. The ISR must be tiny:
 * it captures (millis(), ADC_DATA) and pushes it into an SPSC ring buffer. A main-loop
 * task (temp_task_poll) drains the ring, converts ADC codes to 0.1 degC, runs a
 * hysteresis detector and switches the fan. Lost samples must be COUNTED, never silent.
 *
 * Definitions (agreed with the interviewer):
 *   - Ring: RB_SIZE (power of two) RawSample slots, all usable. head/tail are free-running
 *     uint32_t C11 atomics; ISR writes only head, task writes only tail.
 *     Full ring -> drop the NEW sample and increment g_overrun_count (ISR side).
 *   - adc_to_c10(code): use the low 12 bits only. mV = code * 3300 / 4096 (truncate),
 *     c10 = mV - 500   (TMP36-style: 500 mV at 0 degC, 10 mV/degC).
 *   - temp_task_poll(), in this order:
 *       1) read-and-clear g_overrun_count with IRQs masked (irq_disable/irq_enable),
 *          add it to g_task.overruns_total. Simulation rule: call SIM_PREEMPT() between
 *          the read and the clear -- it is where a real IRQ could arrive.
 *       2) pop every sample. If a previous sample exists and (t - last_t) > STALE_MS
 *          (wrap-safe), reset the detector streak first. Then det_update().
 *          EV_OVERHEAT -> fan_set(true), EV_RECOVERED -> fan_set(false), and log
 *          {sample t_ms, c10, event} (write at most LOG_CAP, always count n_log).
 *   - No malloc, no real threads: the harness calls the ISR at scripted points.
 *
 * Reference solution.  Build & run:  ./run.sh E3 sol
 */
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>
#include <stdatomic.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

#define RB_SIZE   8u                 /* must be a power of two */
#define RB_MASK   (RB_SIZE - 1u)
#define ADC_MASK  0x0FFFu            /* 12-bit converter; bits 15..12 are status junk */
#define VREF_MV   3300u
#define ADC_FULL  4096u
#define STALE_MS  50u                /* a gap larger than this restarts confirmation */
#define LOG_CAP   8u
#define PERIOD_MS 10u                /* harness: DRDY period */

/* ================= provided: fake hardware + platform ================= */
volatile uint16_t ADC_DATA;          /* fake data register (reading it acks DRDY) */
volatile uint32_t g_now_ms;
uint32_t millis(void) { return g_now_ms; }

bool g_fan_on;
int  g_fan_calls;
void fan_set(bool on) { g_fan_on = on; g_fan_calls++; }

void TEMP_DRDY_IRQHandler(void);

/* Simulated NVIC: one pending latch per IRQ line. A second edge while pending is lost. */
static bool g_irq_masked, g_irq_pending;
static uint32_t g_irq_raised, g_irq_coalesced;
void irq_disable(void) { g_irq_masked = true; }
void irq_enable(void)
{
    g_irq_masked = false;
    if (g_irq_pending) { g_irq_pending = false; TEMP_DRDY_IRQHandler(); }  /* pended IRQ fires now */
}
static void raise_irq(void)
{
    g_irq_raised++;
    if (!g_irq_masked) { TEMP_DRDY_IRQHandler(); return; }
    if (g_irq_pending) g_irq_coalesced++;
    g_irq_pending = true;
}
/* harness: one scripted DRDY edge, then time advances by one period */
static void irq(uint16_t code) { ADC_DATA = code; raise_irq(); g_now_ms += PERIOD_MS; }

static int      g_preempt_irqs;      /* how many IRQs the harness injects at SIM_PREEMPT() */
static uint16_t g_preempt_code;
void SIM_PREEMPT(void) { while (g_preempt_irqs > 0) { g_preempt_irqs--; irq(g_preempt_code); } }

/* ================= provided: hysteresis detector (from T1-2) ================= */
typedef enum { EV_NONE, EV_OVERHEAT, EV_RECOVERED } Event;
typedef struct { int16_t high, low; uint8_t n_confirm, streak; bool overheated; } Detector;

void det_init(Detector *d, int16_t high, int16_t low, uint8_t n_confirm)
{
    *d = (Detector){ high, low, n_confirm, 0, false };
}
Event det_update(Detector *d, int16_t c10)
{
    bool toward = d->overheated ? (c10 <= d->low) : (c10 >= d->high);
    if (!toward) { d->streak = 0; return EV_NONE; }
    if (++d->streak < d->n_confirm) return EV_NONE;
    d->streak = 0;
    d->overheated = !d->overheated;
    return d->overheated ? EV_OVERHEAT : EV_RECOVERED;
}

/* ================= shared state ================= */
typedef struct { uint32_t t_ms; uint16_t code; } RawSample;
typedef struct {
    RawSample buf[RB_SIZE];
    _Atomic uint32_t head;           /* written only by the ISR (producer)  */
    _Atomic uint32_t tail;           /* written only by the task (consumer) */
} SampleRing;

typedef struct { uint32_t t_ms; int16_t c10; Event ev; } LogEntry;
typedef struct {
    Detector det;
    bool     has_last;
    uint32_t last_t_ms;              /* capture time of the last processed sample */
    uint32_t processed;
    uint32_t overruns_total;
    LogEntry log[LOG_CAP];
    uint32_t n_log;
} TempTask;

SampleRing        g_ring;
volatile uint32_t g_overrun_count;   /* ISR increments, task reads-and-clears */
TempTask          g_task;

void temp_task_init(int16_t high, int16_t low, uint8_t n_confirm)
{
    atomic_store(&g_ring.head, 0u);
    atomic_store(&g_ring.tail, 0u);
    g_overrun_count = 0;
    memset(&g_task, 0, sizeof g_task);
    det_init(&g_task.det, high, low, n_confirm);
}

/* ================= your code ================= */
int16_t adc_to_c10(uint16_t code)
{
    uint32_t mv = (uint32_t)(code & ADC_MASK) * VREF_MV / ADC_FULL;   /* 0..3299, fits easily */
    return (int16_t)((int32_t)mv - 500);
}

bool ring_push(SampleRing *r, RawSample s)            /* ISR side */
{
    uint32_t h = atomic_load_explicit(&r->head, memory_order_relaxed);   /* our own index */
    uint32_t t = atomic_load_explicit(&r->tail, memory_order_acquire);   /* slot really freed? */
    if (h - t == RB_SIZE) return false;                                  /* full: drop newest */
    r->buf[h & RB_MASK] = s;                                             /* 1) data ...        */
    atomic_store_explicit(&r->head, h + 1u, memory_order_release);       /* 2) ... then publish */
    return true;
}

bool ring_pop(SampleRing *r, RawSample *out)          /* task side */
{
    uint32_t t = atomic_load_explicit(&r->tail, memory_order_relaxed);
    uint32_t h = atomic_load_explicit(&r->head, memory_order_acquire);   /* pairs with push release */
    if (h == t) return false;
    *out = r->buf[t & RB_MASK];
    atomic_store_explicit(&r->tail, t + 1u, memory_order_release);       /* give the slot back */
    return true;
}

void TEMP_DRDY_IRQHandler(void)
{
    RawSample s = { millis(), ADC_DATA };   /* timestamp at capture; reading DR acks the IRQ */
    if (!ring_push(&g_ring, s)) g_overrun_count++;   /* only this ISR writes it while unmasked */
}

void temp_task_poll(void)
{
    /* 1) read-and-clear must be one indivisible step w.r.t. the ISR */
    irq_disable();
    uint32_t n = g_overrun_count;
    SIM_PREEMPT();                          /* an IRQ here only PENDS while masked */
    g_overrun_count = 0;
    irq_enable();                           /* pended IRQ runs here, after the clear */
    g_task.overruns_total += n;

    /* 2) drain: all heavy work happens here, not in the ISR */
    RawSample s;
    while (ring_pop(&g_ring, &s)) {
        TempTask *t = &g_task;
        if (t->has_last && s.t_ms - t->last_t_ms > STALE_MS)   /* wrap-safe gap check */
            t->det.streak = 0;
        t->has_last = true;
        t->last_t_ms = s.t_ms;
        t->processed++;

        int16_t c10 = adc_to_c10(s.code);
        Event ev = det_update(&t->det, c10);
        if (ev == EV_NONE) continue;
        fan_set(ev == EV_OVERHEAT);
        if (t->n_log < LOG_CAP) t->log[t->n_log] = (LogEntry){ s.t_ms, c10, ev };
        t->n_log++;
    }
}

/* ================= tests ================= */
/* ADC codes -> c10 (computed with adc_to_c10) */
enum { C760 = 1564, C770 = 1577, C780 = 1589, C790 = 1602, C800 = 1614, C820 = 1639,
       C830 = 1651, C840 = 1664, C852 = 1679, C860 = 1689, C870 = 1701, C880 = 1713,
       C700 = 1490, C900 = 1738 };

static void reset(uint32_t t0)
{
    g_now_ms = t0;
    g_irq_masked = g_irq_pending = false;
    g_irq_raised = g_irq_coalesced = 0;
    g_preempt_irqs = 0;
    g_fan_on = false; g_fan_calls = 0;
    temp_task_init(850, 800, 3);            /* on at >= 85.0 C x3, off at <= 80.0 C x3 */
}
static uint32_t ring_count(void) { return atomic_load(&g_ring.head) - atomic_load(&g_ring.tail); }
/* every raised IRQ must be processed, still queued, counted as overrun, or coalesced */
static bool conserved(void)
{
    return g_irq_raised == g_task.processed + ring_count() + g_task.overruns_total
                           + g_overrun_count + g_irq_coalesced;
}

int main(void)
{
    /* 1. normal: ramp up -> fan on at sample 4 (t=1040), cool down -> fan off (t=1090).
          Task polls after every 2 IRQs, so events are reported with CAPTURE time. */
    reset(1000);
    const uint16_t up[] = { C820, C840, C852, C860, C870, C880 };
    for (int i = 0; i < 6; i++) {
        irq(up[i]);
        if (i % 2 == 1) temp_task_poll();
        if (i == 3) CHECK(!g_fan_on && g_fan_calls == 0);
    }
    CHECK(g_fan_on && g_fan_calls == 1 && g_task.n_log == 1);
    CHECK(g_task.log[0].ev == EV_OVERHEAT && g_task.log[0].t_ms == 1040 && g_task.log[0].c10 == 870);
    const uint16_t down[] = { C830, C790, C780, C770, C760, C760 };   /* 830 is in the band */
    for (int i = 0; i < 6; i++) { irq(down[i]); if (i % 2 == 1) temp_task_poll(); }
    CHECK(!g_fan_on && g_fan_calls == 2 && g_task.n_log == 2);
    CHECK(g_task.log[1].ev == EV_RECOVERED && g_task.log[1].t_ms == 1090 && g_task.log[1].c10 == 770);
    CHECK(g_task.processed == 12 && g_task.overruns_total == 0 && conserved());

    /* 2. conversion: endpoints, truncation below 0 C, status bits ignored */
    CHECK(adc_to_c10(0) == -500);
    CHECK(adc_to_c10(4095) == 2799);
    CHECK(adc_to_c10(620) == -1);
    CHECK(adc_to_c10(1676) == 850 && adc_to_c10(0xF000u | 1676u) == 850);

    /* 3. burst: 20 IRQs while the task is blocked, ring holds 8 -> 12 overruns, oldest kept */
    reset(0);
    for (int i = 0; i < 20; i++) irq(C800);
    CHECK(ring_count() == RB_SIZE && g_overrun_count == 12);
    temp_task_poll();
    CHECK(g_task.processed == 8 && g_task.overruns_total == 12 && g_overrun_count == 0);
    CHECK(ring_count() == 0 && g_task.last_t_ms == 70);    /* samples 0..70 ms survived */
    irq(C800); temp_task_poll();                            /* t = 200: pipeline still sane */
    CHECK(g_task.processed == 9 && g_task.last_t_ms == 200 && g_task.overruns_total == 12);
    CHECK(g_fan_calls == 0 && conserved());

    /* 4. race: an IRQ arrives between read and clear of g_overrun_count (ring is full) */
    reset(0);
    for (int i = 0; i < 10; i++) irq(C800);                 /* 8 queued, 2 overruns */
    g_preempt_irqs = 1; g_preempt_code = C800;
    temp_task_poll();
    CHECK(g_preempt_irqs == 0 && g_task.processed == 8 && conserved());
    temp_task_poll();                                       /* collects anything left over */
    CHECK(g_task.overruns_total == 3 && g_overrun_count == 0 && g_irq_raised == 11 && conserved());

    /* 5. spikes: never 3 hot samples in a row -> fan never touched */
    reset(0);
    const uint16_t sp[] = { C900, C700, C900, C700, C900, C900, C700 };
    for (int i = 0; i < 7; i++) { irq(sp[i]); temp_task_poll(); }
    CHECK(g_fan_calls == 0 && !g_fan_on && g_task.n_log == 0);

    /* 6. millis() wraps during confirmation: t = 4294967281, 4294967291, 5 -> event at t=5 */
    reset(UINT32_MAX - 14u);
    for (int i = 0; i < 3; i++) irq(C870);
    temp_task_poll();
    CHECK(g_fan_on && g_task.n_log == 1 && g_task.log[0].t_ms == 5);

    /* 7. stale gap: 0, 10, (gap 60 ms) 70, 80, 90 -> streak restarts at 70, event at 90 */
    reset(0);
    irq(C870); irq(C870);
    g_now_ms = 70;
    irq(C870); irq(C870); temp_task_poll();
    CHECK(!g_fan_on && g_fan_calls == 0);
    irq(C870); temp_task_poll();
    CHECK(g_fan_on && g_task.n_log == 1 && g_task.log[0].t_ms == 90);

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

코드 읽는 포인트

  • ring_push: 자기 인덱스 head는 relaxed, 상대 인덱스 tail은 acquire로 읽습니다(task가 슬롯을 다 읽고 돌려줬는지 확인). 데이터를 쓴 다음에 head를 release로 공개합니다. ring_pop은 이를 거울처럼 뒤집은 형태입니다.
  • ISR은 ring_push 실패 시 g_overrun_count++만 합니다. 단일 코어에서 task는 ISR을 선점하지 못하므로 ISR 쪽 ++는 안전합니다. 같은 카운터를 더 높은 우선순위 ISR도 건드리면 그때는 ISR 쪽도 보호해야 합니다.
  • critical section 안에는 세 줄만 있습니다. 마스킹 시간이 샘플 주기(10 ms)를 넘으면 두 번째 DRDY가 pending bit에 합쳐져(g_irq_coalesced) 카운트조차 안 되는 손실이 생깁니다.
  • 변환, stale 검사, detector, 로그는 모두 마스킹 밖에서 합니다. 링은 lock-free이기 때문입니다.
  • 로그는 T1-1과 같은 if (n < CAP) write; n++; 패턴을 씁니다.

4.6 복잡도

  • ISR O(1): 명령어 수십 개. task poll O(k): k는 그동안 쌓인 샘플 수(≤ RB_SIZE).
  • 메모리 O(RB_SIZE): 정적 할당. 샘플 하나가 8바이트(패딩 포함)라 링은 64바이트입니다.

5. 임베디드 관점으로 말할 것

  • ISR vs task 분리 기준: ISR에는 "지금 안 하면 데이터가 사라지는 일"만 넣습니다(레지스터 읽기, 타임스탬프, 플래그 ack). "늦어도 되는 일"(변환, 필터, 판단, 로그, I/O)은 task로 보냅니다. ISR이 길면 다른 IRQ의 지연(jitter)이 늘고, 같은 IRQ의 다음 edge를 놓칩니다.
  • ISR 지연 예산: Cortex-M3/M4는 IRQ 진입에 약 12 cycle이 들고, 이 ISR 본문은 수십 cycle입니다. 64 MHz에서 1 µs 미만이고, 100 Hz면 CPU 점유율은 0.01% 미만입니다. 예산이 빡빡해지는 건 샘플레이트가 수십 kHz로 올라갈 때입니다. 그때는 DMA + half/full-transfer IRQ로 바꿔 IRQ 횟수 자체를 줄입니다.
  • 링 크기 정하기: N ≥ 샘플레이트 × 최악 task 지연 + 여유, 그리고 2의 거듭제곱으로 올림합니다. 100 Hz에 최악 지연 60 ms면 6개, 여유를 더해 8입니다. 테스트 3처럼 200 ms 막히는 경우(예: flash sector erase)가 정상 동작 범위라면 20개 → 32가 필요합니다. 크기는 "추측"이 아니라 측정한 최악 지연(GPIO 토글 + 로직 분석기, 또는 DWT cycle counter)으로 정합니다.
  • 손실은 세고, 보고한다: drop-newest + overrun_count는 "얼마나 잃었는지"를 알 수 있게 해 줍니다. 텔레메트리로 올리고, overrun이 0이 아니면 링 크기나 task 우선순위를 다시 봅니다. 과열 판단 쪽에서는 stale 규칙으로 빠진 구간을 넘어 streak를 이어 붙이지 않게 합니다.
  • 타임스탬프는 캡처 시점에서: task가 늦게 돌아도 이벤트 시각이 정확합니다. millis() 랩은 뺄셈 비교로 처리합니다.

6. Follow-up 질문과 답

Follow-up (English)답
Why not do the conversion and detection inside the ISR?계산 자체는 짧지만, ISR이 길어질수록 다른 IRQ 지연이 늘고 나중에 기능(로그, 통신)을 붙이기 어려워집니다. ISR은 캡처만 하고 판단은 task에서 하는 게 표준 구조입니다. 또 fan_set이 I2C 팬 컨트롤러라면 ISR에서는 아예 못 씁니다(블로킹).
Is volatile enough for the counter?아닙니다. volatile은 매번 메모리에 접근하게 할 뿐, n = cnt; cnt = 0;의 두 단계를 묶어 주지 않습니다. critical section이나 atomic_exchange가 필요합니다.
Replace the critical section with C11 atomics.n = atomic_exchange_explicit(&cnt, 0, memory_order_relaxed);, ISR은 atomic_fetch_add를 씁니다. M3/M4에서는 LDREX/STREX 루프라 IRQ를 막지 않습니다. M0처럼 LDREX가 없으면 컴파일러가 라이브러리 호출(내부적으로 마스킹)을 넣습니다.
Drop-newest or overwrite-oldest?과열 판단은 최신 값이 더 중요하므로 overwrite-oldest가 나을 수 있습니다. 다만 SPSC에서 생산자가 tail을 건드리게 되어 lock-free가 깨집니다. 시퀀스 번호를 붙이거나 마스킹이 필요합니다. 이 문제는 단순성과 "손실을 센다"를 우선해서 drop-newest를 택했습니다.
What if a higher-priority ISR also increments the counter?그러면 낮은 ISR의 cnt++도 선점될 수 있으니 ISR 쪽도 atomic 또는 BASEPRI 마스킹이 필요합니다. 아니면 카운터를 ISR별로 나눠서 각자 한 명만 쓰게 만듭니다(SPSC 원칙).
How do you size the ring and prove it?rate × worst-case latency + margin, 2의 거듭제곱으로 올림합니다. 최악 지연은 GPIO 토글 + 로직 분석기, 또는 링 high-water mark(최대 head - tail)를 기록해서 측정합니다.
Multi-core (e.g. ISR on M4, task on A-core)?acquire/release가 실제 DMB 배리어가 됩니다. 공유 메모리의 캐시 일관성(non-cacheable 영역 또는 clean/invalidate)과 head/tail을 서로 다른 캐시라인에 두는 것(false sharing 방지)까지 챙겨야 합니다.
How would you test this on real hardware?신호 발생기로 센서 전압을 램프시키고, 팬 GPIO와 DRDY를 로직 분석기로 같이 찍어 이벤트 지연을 측정합니다. task에 인위적 지연을 넣어 overrun 카운터가 기대값만큼 오르는지 봅니다(fault injection).

7. 자주 하는 실수

  • n = cnt; cnt = 0;을 마스킹 없이 씀 → 테스트 4 실패(overrun 1개 증발)
  • ring_push에서 head를 먼저 올리고 데이터를 씀 → 실제 HW에서는 task가 쓰레기 슬롯을 읽음(시뮬레이션에서는 안 보이지만 면접관은 봄)
  • ISR에서 변환이나 detector까지 다 돌리고, task를 비워 둠 → 동작은 해도 구조 질문에서 감점
  • 링이 꽉 찼을 때 조용히 버림(카운트 안 함), 또는 RB_SIZE - 1칸만 쓰는 구현인데 테스트는 8칸 기대 → 테스트 3 실패
  • stale 검사를 t > last + STALE_MS로 씀 → 랩 근처에서 거짓 stale → 테스트 6 실패
  • 타임스탬프를 task에서 millis()로 찍음 → 로그 시각이 1040이 아니라 1060 → 테스트 1 실패
  • critical section 안에서 drain/변환까지 다 함 → 마스킹 시간이 길어져 DRDY edge가 pending bit에 합쳐짐(세지도 못하는 손실)
  • 링 관련 연습은 T2-1, detector는 T1-2, 구간 계산은 T1-1
