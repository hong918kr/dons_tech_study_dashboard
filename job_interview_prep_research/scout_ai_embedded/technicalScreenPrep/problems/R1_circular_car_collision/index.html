0. 문제 한국어 소개 (먼저 읽기)

영어 문제(§1)를 읽기 전에 무엇을 만들라는 건지 먼저 잡기 위한 요약입니다. 실제 풀이와 테스트는 §1 영어 문제 기준입니다.

  • 한 줄 요약: 평면 위에서 각자 원을 그리며 달리는 자동차 두 대가 처음 부딪히는 시각(초) 을 구한다. 없으면 -1.
  • 상황: 각 차의 상태는 x, y(m), heading(진행 방향, rad, +x축이 0, 반시계가 +), speed(m/s), omega(회전 속도, rad/s, +는 왼쪽/반시계, −는 오른쪽/시계). speed와 omega가 일정하니 차는 원을 그린다(omega == 0이면 직선). 용어 표는 아래 §0-2.
  • 입력: 차 두 대(Car), t_max(이때까지 안 만나면 포기), Part A는 time step dt, Part B/C는 정밀도 tol.
  • 출력: 첫 충돌 시각(초). t_max 전에 충돌 없으면 -1, t = 0에 이미 붙어 있으면 0.
  • 규칙
    • 충돌 = 두 중심 거리 <= COLLIDE_DIST(1.0 m). 차마다 반지름 같은 크기는 없다.
    • Part A (Solution 1, 면접관 방식): 상태에서 다음 위치를 계산해 시간을 dt씩 진행. x += speed·dt·cos(heading), y += speed·dt·sin(heading), heading += omega·dt. 매 스텝 충돌 확인.
    • Part B (Solution 1 refined): 원호를 따라가는 정확한 스텝 + 충돌 시각을 이분법(bisection)으로 tol까지 좁히기.
    • Part C (Solution 2, Don 방식): 차를 원(중심 cx, cy, 반지름 r, omega, 시작 각 phase0)으로 바꿔서 시각 t의 위치를 바로 계산. omega == 0이면 원이 없으니 false.
    • 동적 할당 금지, <math.h> 사용 가능.
  • 예제 풀어 읽기: A = (4, 0), heading 90°, speed 2.0, omega +0.5 → 중심 (0, 0), 반지름 4인 원을 반시계로. B = (6, 3), heading 0°, speed 1.2, omega −0.4 → 중심 (6, 0), 반지름 3인 원을 시계로. Solution 1은 dt = 0.5면 12.50 s, dt = 0.01이면 12.82 s. refined와 Solution 2는 둘 다 12.822241 s.
  • 놓치기 쉬운 것: 거리가 정확히 1.0이면 충돌, 1.0001이면 아님; 평행하게 5 m 떨어진 직진 차는 -1; 시작부터 0.8 m면 0; 정면 직진 충돌(4.5 s); 빠른 차를 dt = 1로 돌리면 서로 뚫고 지나가서(tunneling) 놓침 → refined는 0.45 s를 찾아야 함; t_max = 10이면 -1; omega == 0은 원 변환 실패; 원 방식 위치가 refined 스텝 위치와 같아야 함.
  • 구현할 함수 (모범답안: Solution 1 → §4.1, Solution 2 → §4.2)
    • Part A: update_car(c, dt), did_collide(a, b), sim_collision_time(a, b, dt, t_max) (init_car는 주어짐)
    • Part B: update_car_exact(c, dt), find_collision_time(a, b, t_max, tol)
    • Part C: circle_from_car(c, out), circle_pos(k, t, x, y), circle_collision_time(a, b, t_max, tol) (circle_dist2는 주어짐)

한 스텝에서 일어나는 일 (Solution 1의 전부)

  1. 이번 스텝에 갈 거리: dist = speed × dt
  2. 그 거리를 heading 방향으로 나눠 더하기: x += dist × cos(heading), y += dist × sin(heading)
  3. heading 돌리기: heading += omega × dt
  4. t = k × dt에서 두 차 거리 확인 → COLLIDE_DIST 이하면 t 출력

cos·sin은 라디안을 받으므로 degree는 × π / 180으로 바꿉니다(DEG() 매크로).

1. Problem

Two cars drive on a flat 2D plane. Each car's state is:

  • x, y — position in meters
  • heading — direction of travel in radians (0 = +x axis, counter-clockwise positive)
  • speed — m/s along the heading
  • omega — rotational speed in rad/s (> 0 turns left / CCW, < 0 turns right / CW)

From these parameters you can always compute the car's next position. Speed and omega are constant, so each car drives on a circle (a straight line when omega == 0). The cars collide when their centers are within COLLIDE_DIST = 1.0 m.

Report the timestamp of the first collision (seconds), or -1 if there is none before t_max.

#define COLLIDE_DIST 1.0
typedef struct { double x, y, heading, speed, omega; } Car;

/* Part A - Solution 1: parameters -> next position, step time */
Car    init_car(double x, double y, double heading, double speed, double omega);
void   update_car(Car *c, double dt);
bool   did_collide(const Car *a, const Car *b);
double sim_collision_time(Car a, Car b, double dt, double t_max);

/* Part B - Solution 1 refined: exact step + exact timestamp */
void   update_car_exact(Car *c, double dt);
double find_collision_time(Car a, Car b, double t_max, double tol);

/* Part C - Solution 2: describe each path by its circle */
typedef struct { double cx, cy, r, omega, phase0; } CircleCar;
bool   circle_from_car(const Car *c, CircleCar *out);          /* false if omega == 0 */
void   circle_pos(const CircleCar *k, double t, double *x, double *y);
double circle_collision_time(const CircleCar *a, const CircleCar *b, double t_max, double tol);

Example

A: x=4, y=0, heading=90 deg, speed=2.0 m/s, omega=+0.5 rad/s   (turns left)
B: x=6, y=3, heading= 0 deg, speed=1.2 m/s, omega=-0.4 rad/s   (turns right)
COLLIDE_DIST = 1.0 m

Solution 1, dt = 0.5  : 12.50 s     (simple loop, Euler step)
Solution 1, dt = 0.01 : 12.82 s
Solution 1 refined    : 12.822241 s (exact step + bisection)
Solution 2 (circle)   : 12.822241 s (A: center (0,0) r=4,  B: center (6,0) r=3)

Constraints

  • dt > 0, t_max > 0, tol > 0. Return 0 if the cars already collide at t = 0.
  • Speeds and omegas are constant for the whole run.
  • No dynamic allocation. <math.h> is allowed.

Clarifying questions to ask (first 3 minutes)

  1. What counts as a collision — the centers within some distance? What distance? Does touching count?
  2. Units: seconds, meters, radians? Heading measured from which axis, which direction is positive?
  3. Are speed and rotational speed constant? Can omega be zero or negative?
  4. Output: the first collision time only? How precise — is a fixed time step OK?
  5. What if they never collide? Is there a time limit?
  6. "Do you want me to step the state forward in time, or is a closed-form circle description fine?" ← 이번 면접에서 갈린 지점. 먼저 물어보면 면접관이 원하는 쪽으로 바로 간다

    /* 5. exact step: a quarter lap ends at (0,4) heading pi */
    Car e = a;
    update_car_exact(&e, PI);                   /* quarter of the 4*pi s period */
    CHECK(NEAR(e.x, 0.0, 1e-9) && NEAR(e.y, 4.0, 1e-9) && NEAR(fabs(e.heading), PI, 1e-9));

    /* 6. exact timestamp */
    double t_b = find_collision_time(a, b, 60, 1e-9);
    printf("Solution 1 refined (exact+bisect): t = %.6f s\n", t_b);

    CHECK(NEAR(find_collision_time(h1, h2, 60, 1e-9), 4.5, 1e-6));

    Car f1 = init_car(0, 0, 0, 10, 0), f2 = init_car(10, 0.0, PI, 10, 0);
    CHECK(sim_collision_time(f1, f2, 1.0, 5) == -1.0);

    CHECK(find_collision_time(a, b, 10, 1e-9) == -1.0);

    /* 10. parameters -> circle */
    CircleCar ca, cb;
    CHECK(circle_from_car(&a, &ca) && circle_from_car(&b, &cb));
    CHECK(NEAR(ca.cx, 0, 1e-12) && NEAR(ca.cy, 0, 1e-12) && NEAR(ca.r, 4, 1e-12));
    CHECK(NEAR(cb.cx, 6, 1e-12) && NEAR(cb.cy, 0, 1e-12) && NEAR(cb.r, 3, 1e-12));
    CHECK(!circle_from_car(&h1, &ca));           /* omega == 0 has no circle */

    double cx, cy;

    update_car_exact(&a7, 7.3);

    double t_c = circle_collision_time(&ca, &cb, 60, 1e-9);
    printf("Solution 2 (circle, closed form):  t = %.6f s\n", t_c);
    CHECK(NEAR(t_c, 12.822241, 1e-6));

    if (g_fail == 0) printf("ALL PASS\n"); else printf("%d FAILED\n", g_fail);

}

3. 힌트 (막힐 때 하나씩)

Hint 1 — 면접관의 상태 그대로: "파라미터로 다음 위치 계산"

dt 동안 차는 지금 heading 방향으로 speed·dt만큼 가고, heading은 omega·dt만큼 돕니다.

c->x += c->speed * cos(c->heading) * dt;
c->y += c->speed * sin(c->heading) * dt;
c->heading += c->omega * dt;

반지름이나 원의 중심은 필요 없습니다. omega가 heading을 계속 돌리기 때문에 결과적으로 원을 그립니다.

Hint 2 — Don의 뼈대에서 바꿀 3곳
  1. update_car(Car, x, y) → update_car(Car *c, double dt): 다음 위치는 밖에서 넣는 게 아니라 안에서 계산. C는 값 전달이라 포인터가 필요
  2. while (1) → for (k = 0; k*dt <= t_max; k++): 안 만나면 끝나야 함
  3. 시간 t = k*dt를 들고 다니다가 충돌 시 반환
Hint 3 — 정확한 timestamp (Part B)와 원 공식 (Part C)
  • Part B: omega가 일정하면 dt가 커도 정확한 호 공식이 있습니다. r = speed/omega, th1 = th0 + omega·dt → x += r(sin th1 − sin th0), y += r(cos th0 − cos th1). 그다음 거친 스텝 dt = 0.5·COLLIDE_DIST/(|vA|+|vB|)로 가다가, 처음 충돌한 스텝 안에서 이분법
  • Part C: 원의 중심은 차의 왼쪽으로 speed/omega만큼: cx = x − (v/ω)·sin(heading), cy = y + (v/ω)·cos(heading). 그러면 pos(t) = center + r·(cos(φ0 + ωt), sin(φ0 + ωt))

4.1 모범답안 — Solution 1 (면접관 방식, main까지 전부)

CoderPad에 처음부터 이렇게 치면 됩니다. 상수 → struct → 3개 함수 → main 순서.

model1.c
/*
 * R1 model answer - Solution 1 (the interviewer's approach)
 *
 * Each car is described by exactly the parameters the interviewer gave:
 *   x, y      position on the plane (meters)
 *   heading   the direction the car is pointing (radians)
 *             0 = pointing along +x (right), PI/2 = +y (up), PI = -x, -PI/2 = -y
 *   speed     how far the car moves per second along its heading (m/s)
 *   omega     rotational speed: how fast the heading turns (rad/s)
 *             omega > 0 turns left (counter-clockwise), omega < 0 turns right
 *
 * We do not know the "next point" in advance - we COMPUTE it from these parameters.
 * Time advances in small steps of DT seconds. In one step:
 *   the car moves speed*DT meters along its current heading, then
 *   the heading turns by omega*DT radians.
 * Repeating this traces a circle of radius speed/omega without ever storing a radius.
 *
 * Build & run:  ./run.sh R1 model1
 */
#include <math.h>
#include <stdbool.h>
#include <stdio.h>

#define PI           3.14159265358979323846
#define DEG(d)       ((d) * PI / 180.0)   /* degrees -> radians (cos/sin take radians) */
#define COLLIDE_DIST 1.0                  /* m: centers this close = collision */
#define DT           0.01                 /* s: one simulation step (100 steps per second) */
#define T_MAX        60.0                 /* s: stop if no collision by then */

typedef struct {
    double x, y;      /* m */
    double heading;   /* rad, 0 = +x, counter-clockwise positive */
    double speed;     /* m/s along the heading */
    double omega;     /* rad/s, + = turn left, - = turn right */
} Car;

Car init_car(double x, double y, double heading, double speed, double omega)
{
    Car c = { x, y, heading, speed, omega };
    return c;
}

/* Parameters -> next position. Called once per time step. */
void update_car(Car *c, double dt)
{
    double dist = c->speed * dt;              /* meters travelled in this step */
    c->x += dist * cos(c->heading);           /* x part of the move */
    c->y += dist * sin(c->heading);           /* y part of the move */
    c->heading += c->omega * dt;              /* turn for the next step */
}

/* Collision = distance between centers <= COLLIDE_DIST (compare squares, no sqrt). */
bool did_collide(const Car *a, const Car *b)
{
    double dx = a->x - b->x;
    double dy = a->y - b->y;
    return dx * dx + dy * dy <= COLLIDE_DIST * COLLIDE_DIST;
}

int main(void)
{
    /*                x    y    heading   speed  omega            */
    Car a = init_car(4.0, 0.0, DEG(90),  2.0,  +0.5);   /* points up, turns left  */
    Car b = init_car(6.0, 3.0, DEG(0),   1.2,  -0.4);   /* points right, turns right */

    for (long k = 0; ; k++) {                 /* k = step number */
        double t = k * DT;                    /* current time (s); k*DT avoids += drift */
        if (t > T_MAX) {
            printf("no collision within %.0f s\n", T_MAX);
            return 0;
        }
        if (did_collide(&a, &b)) {
            printf("collision at t = %.2f s (step %ld)\n", t, k);
            printf("  A at (%.3f, %.3f)   B at (%.3f, %.3f)   distance %.3f m\n",
                   a.x, a.y, b.x, b.y, hypot(a.x - b.x, a.y - b.y));
            return 0;
        }
        update_car(&a, DT);                   /* both cars move to their next point */
        update_car(&b, DT);
    }
}

model2.c
/*
 * R1 model answer - Solution 2 (Don's first idea: describe each path by its circle)
 *
 * Same inputs as Solution 1 (x, y, heading, speed, omega). With constant speed and
 * omega the car stays on ONE circle, so we convert the parameters to that circle once:
 *   r       radius of the path            r = |speed / omega|        (meters)
 *   cx, cy  center of the path            to the LEFT of the car when omega > 0,
 *                                         to the RIGHT when omega < 0
 *   phase   angle of the car seen from the center (radians, 0 = +x, CCW positive)
 *   phase0  that angle at t = 0
 * The car goes around the center at the same rate its heading turns, so
 *   phase(t) = phase0 + omega * t
 *   x(t) = cx + r * cos(phase(t)),   y(t) = cy + r * sin(phase(t))
 * Position at ANY time comes straight from the formula - no stepping, no drift.
 * Limitation: omega == 0 (straight line) has no circle.
 *
 * Build & run:  ./run.sh R1 model2
 */
#include <math.h>
#include <stdbool.h>
#include <stdio.h>

#define PI           3.14159265358979323846
#define DEG(d)       ((d) * PI / 180.0)
#define COLLIDE_DIST 1.0                  /* m */
#define DT           0.01                 /* s: how often we check the distance */
#define T_MAX        60.0                 /* s */

typedef struct {
    double cx, cy;    /* center of the circle (m) */
    double r;         /* radius (m) */
    double omega;     /* rad/s, + = counter-clockwise around the center */
    double phase0;    /* angle from center to car at t = 0 (rad) */
} CircleCar;

/* Convert the interviewer's parameters to a circle. Returns false for a straight line. */
bool circle_from_params(double x, double y, double heading, double speed, double omega,
                        CircleCar *out)
{
    if (fabs(omega) < 1e-9) return false;     /* omega == 0: no circle */
    double rs = speed / omega;                /* signed radius: + center on the left */
    out->cx = x - rs * sin(heading);          /* left of heading = heading + 90 deg */
    out->cy = y + rs * cos(heading);
    out->r = fabs(rs);
    out->omega = omega;
    out->phase0 = atan2(y - out->cy, x - out->cx);
    return true;
}

/* Position at time t, straight from the formula. */
void position_at(const CircleCar *c, double t, double *x, double *y)
{
    double phase = c->phase0 + c->omega * t;
    *x = c->cx + c->r * cos(phase);
    *y = c->cy + c->r * sin(phase);
}

int main(void)
{
    CircleCar a, b;
    /*                    x    y    heading  speed  omega */
    circle_from_params(4.0, 0.0, DEG(90), 2.0, +0.5, &a);
    circle_from_params(6.0, 3.0, DEG(0),  1.2, -0.4, &b);
    printf("A: center (%.2f, %.2f) r = %.2f   B: center (%.2f, %.2f) r = %.2f\n",
           a.cx, a.cy, a.r, b.cx, b.cy, b.r);

    for (long k = 0; ; k++) {
        double t = k * DT;
        if (t > T_MAX) {
            printf("no collision within %.0f s\n", T_MAX);
            return 0;
        }
        double ax, ay, bx, by;
        position_at(&a, t, &ax, &ay);         /* jump straight to time t */
        position_at(&b, t, &bx, &by);
        double dx = ax - bx, dy = ay - by;
        if (dx * dx + dy * dy <= COLLIDE_DIST * COLLIDE_DIST) {
            printf("collision at t = %.2f s (step %ld)\n", t, k);
            printf("  A at (%.3f, %.3f)   B at (%.3f, %.3f)   distance %.3f m\n",
                   ax, ay, bx, by, hypot(dx, dy));
            return 0;
        }
    }
}

💡 정답 코드 펼치기 (35분 풀어 본 다음에)
solution.c
/*
 * R1  Circular Car Collision  (actual Scout AI screen question, 2026-10-26)  -- Reference solution
 *
 * Two cars drive on a 2D plane. The interviewer's state for each car:
 *     x, y      position (m)
 *     heading   direction of travel (rad, 0 = +x axis, counter-clockwise positive)
 *     speed     m/s along the heading
 *     omega     rotational speed (rad/s, > 0 turns left / CCW, < 0 turns right / CW)
 * From these parameters you can always compute the car's NEXT position.
 * Speed and omega are constant, so each car drives on a circle (a line if omega == 0).
 * The cars collide when their centers are within COLLIDE_DIST meters.
 * Report the timestamp (seconds) of the first collision, or -1 if none before t_max.
 *
 * Part A - Solution 1 (step the state):  update_car, did_collide, sim_collision_time
 * Part B - Solution 1 refined:           update_car_exact, find_collision_time
 * Part C - Solution 2 (circle radius):   circle_from_car, circle_pos, circle_collision_time
 *
 * Build & run:  ./run.sh R1 sol
 */
#include <math.h>
#include <stdbool.h>
#include <stdio.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)
#define NEAR(a, b, eps) (fabs((a) - (b)) <= (eps))

static const double PI = 3.14159265358979323846;
#define COLLIDE_DIST 1.0                       /* meters between centers = contact */

typedef struct {
    double x, y;      /* position (m) */
    double heading;   /* rad */
    double speed;     /* m/s */
    double omega;     /* rad/s */
} Car;

Car init_car(double x, double y, double heading, double speed, double omega)
{
    Car c = { x, y, heading, speed, omega };
    return c;
}

/* ---------------- Part A: Solution 1 - parameters -> next position ---------------- */

/* One time step: move along the current heading, then turn. */
void update_car(Car *c, double dt)
{
    c->x += c->speed * cos(c->heading) * dt;
    c->y += c->speed * sin(c->heading) * dt;
    c->heading += c->omega * dt;
}

bool did_collide(const Car *a, const Car *b)
{
    double dx = a->x - b->x, dy = a->y - b->y;
    return dx * dx + dy * dy <= COLLIDE_DIST * COLLIDE_DIST;   /* no sqrt */
}

/* The interview loop: check, step both cars, advance time. */
double sim_collision_time(Car a, Car b, double dt, double t_max)
{
    for (long k = 0; k * dt <= t_max; k++) {   /* t = k*dt: no accumulated += error */
        if (did_collide(&a, &b)) return k * dt;
        update_car(&a, dt);
        update_car(&b, dt);
    }
    return -1.0;
}

/* ---------------- Part B: Solution 1 refined ---------------- */

/* Same parameters, but integrate along the arc: exact for any dt. */
void update_car_exact(Car *c, double dt)
{
    double th0 = c->heading;
    double th1 = th0 + c->omega * dt;
    if (fabs(c->omega) < 1e-9) {               /* straight line */
        c->x += c->speed * cos(th0) * dt;
        c->y += c->speed * sin(th0) * dt;
    } else {
        double r = c->speed / c->omega;        /* signed turn radius, derived */
        c->x += r * (sin(th1) - sin(th0));
        c->y += r * (cos(th0) - cos(th1));
    }
    c->heading = remainder(th1, 2.0 * PI);     /* keep in [-pi, pi] */
}

/* Coarse steps that cannot jump through a contact, then bisection in the hit step. */
double find_collision_time(Car a, Car b, double t_max, double tol)
{
    if (did_collide(&a, &b)) return 0.0;
    double vmax = fabs(a.speed) + fabs(b.speed);   /* bound on closing speed */
    if (vmax == 0.0) return -1.0;
    double dt = 0.5 * COLLIDE_DIST / vmax;

    double t = 0.0;
    while (t < t_max) {
        double step = (t + dt > t_max) ? t_max - t : dt;
        Car a1 = a, b1 = b;
        update_car_exact(&a1, step);
        update_car_exact(&b1, step);
        if (did_collide(&a1, &b1)) {
            double lo = 0.0, hi = step;        /* no contact at lo, contact at hi */
            while (hi - lo > tol) {
                double mid = 0.5 * (lo + hi);
                Car a2 = a, b2 = b;
                update_car_exact(&a2, mid);
                update_car_exact(&b2, mid);
                if (did_collide(&a2, &b2)) hi = mid; else lo = mid;
            }
            return t + hi;
        }
        a = a1; b = b1; t += step;
    }
    return -1.0;
}

/* ---------------- Part C: Solution 2 - describe the path by its circle ---------------- */

typedef struct {
    double cx, cy;    /* circle center (m) */
    double r;         /* path radius (m), > 0 */
    double omega;     /* angular speed around the center (rad/s), sign = direction */
    double phase0;    /* angle of the car seen from the center at t = 0 (rad) */
} CircleCar;

/* Convert the interviewer's state to a circle. False for a straight line (omega == 0). */
bool circle_from_car(const Car *c, CircleCar *out)
{
    if (fabs(c->omega) < 1e-9) return false;
    double rs = c->speed / c->omega;           /* signed: + center on the left */
    out->cx = c->x - rs * sin(c->heading);
    out->cy = c->y + rs * cos(c->heading);
    out->r = fabs(rs);
    out->omega = c->omega;
    out->phase0 = atan2(c->y - out->cy, c->x - out->cx);
    return true;
}

/* Position at any time t directly - no stepping, no accumulated error. */
void circle_pos(const CircleCar *k, double t, double *x, double *y)
{
    double ph = k->phase0 + k->omega * t;
    *x = k->cx + k->r * cos(ph);
    *y = k->cy + k->r * sin(ph);
}

static double circle_dist2(const CircleCar *a, const CircleCar *b, double t)
{
    double ax, ay, bx, by;
    circle_pos(a, t, &ax, &ay);
    circle_pos(b, t, &bx, &by);
    return (ax - bx) * (ax - bx) + (ay - by) * (ay - by);
}

double circle_collision_time(const CircleCar *a, const CircleCar *b, double t_max, double tol)
{
    const double d2 = COLLIDE_DIST * COLLIDE_DIST;
    if (circle_dist2(a, b, 0.0) <= d2) return 0.0;
    double vmax = fabs(a->omega) * a->r + fabs(b->omega) * b->r;   /* linear speeds */
    double dt = 0.5 * COLLIDE_DIST / vmax;
    for (double t = 0.0; t < t_max; t += dt) {
        double t1 = (t + dt > t_max) ? t_max : t + dt;
        if (circle_dist2(a, b, t1) <= d2) {
            double lo = t, hi = t1;
            while (hi - lo > tol) {
                double mid = 0.5 * (lo + hi);
                if (circle_dist2(a, b, mid) <= d2) hi = mid; else lo = mid;
            }
            return hi;
        }
    }
    return -1.0;
}

int main(void)
{
    /* main example (interviewer-style parameters) */
    Car a = init_car(4, 0, PI / 2, 2.0, 0.5);    /* CCW, turn radius 4, center (0,0) */
    Car b = init_car(6, 3, 0, 1.2, -0.4);        /* CW,  turn radius 3, center (6,0) */

    /* ---- Part A: Solution 1 ---- */
    /* 1. one step from the parameters */
    Car s = a;
    update_car(&s, 0.5);
    CHECK(NEAR(s.x, 4.0, 1e-12) && NEAR(s.y, 1.0, 1e-12) && NEAR(s.heading, PI / 2 + 0.25, 1e-12));

    /* 2. contact rule: exactly COLLIDE_DIST counts, a hair more does not */
    Car p = init_car(0, 0, 0, 0, 0), q = init_car(1.0, 0, 0, 0, 0), r = init_car(1.0001, 0, 0, 0, 0);
    CHECK(did_collide(&p, &q));
    CHECK(!did_collide(&p, &r));

    /* 3. simulation loop on the main example */
    double t_s = sim_collision_time(a, b, 0.01, 60);
    printf("Solution 1 (step dt=0.01):        t = %.2f s\n", t_s);
    CHECK(NEAR(t_s, 12.82, 1e-9));
    CHECK(NEAR(sim_collision_time(a, b, 0.5, 60), 12.50, 1e-9));

    /* 4. never meet -> -1 (parallel lanes 5 m apart), already touching -> 0 */
    Car l1 = init_car(0, 0, 0, 1, 0), l2 = init_car(0, 5, 0, 1, 0);
    CHECK(sim_collision_time(l1, l2, 0.01, 60) == -1.0);
    Car o1 = init_car(0, 0, 0, 1, 0), o2 = init_car(0.8, 0, 0, 1, 0);
    CHECK(sim_collision_time(o1, o2, 0.01, 60) == 0.0);

    /* ---- Part B: Solution 1 refined ---- */
    /* 5. exact step: a quarter lap ends at (0,4) heading pi */
    Car e = a;
    update_car_exact(&e, PI);                   /* quarter of the 4*pi s period */
    CHECK(NEAR(e.x, 0.0, 1e-9) && NEAR(e.y, 4.0, 1e-9) && NEAR(fabs(e.heading), PI, 1e-9));

    /* 6. exact timestamp */
    double t_b = find_collision_time(a, b, 60, 1e-9);
    printf("Solution 1 refined (exact+bisect): t = %.6f s\n", t_b);
    CHECK(NEAR(t_b, 12.822241, 1e-6));

    /* 7. straight head-on: gap 10 - 2t = 1 -> 4.5 s */
    Car h1 = init_car(0, 0, 0, 1, 0), h2 = init_car(10, 0, PI, 1, 0);
    CHECK(NEAR(find_collision_time(h1, h2, 60, 1e-9), 4.5, 1e-6));

    /* 8. tunneling: fast cars, dt = 1 s loop jumps through each other */
    Car f1 = init_car(0, 0, 0, 10, 0), f2 = init_car(10, 0.0, PI, 10, 0);
    CHECK(sim_collision_time(f1, f2, 1.0, 5) == -1.0);
    CHECK(NEAR(find_collision_time(f1, f2, 5, 1e-9), 0.45, 1e-6));

    /* 9. t_max cut-off */
    CHECK(find_collision_time(a, b, 10, 1e-9) == -1.0);

    /* ---- Part C: Solution 2 ---- */
    /* 10. parameters -> circle */
    CircleCar ca, cb;
    CHECK(circle_from_car(&a, &ca) && circle_from_car(&b, &cb));
    CHECK(NEAR(ca.cx, 0, 1e-12) && NEAR(ca.cy, 0, 1e-12) && NEAR(ca.r, 4, 1e-12));
    CHECK(NEAR(cb.cx, 6, 1e-12) && NEAR(cb.cy, 0, 1e-12) && NEAR(cb.r, 3, 1e-12));
    CHECK(!circle_from_car(&h1, &ca));           /* omega == 0 has no circle */
    circle_from_car(&a, &ca);

    /* 11. same position as Solution 1 refined at any t */
    double cx, cy;
    Car a7 = a;
    update_car_exact(&a7, 7.3);
    circle_pos(&ca, 7.3, &cx, &cy);
    CHECK(NEAR(cx, a7.x, 1e-9) && NEAR(cy, a7.y, 1e-9));

    /* 12. same timestamp */
    double t_c = circle_collision_time(&ca, &cb, 60, 1e-9);
    printf("Solution 2 (circle, closed form):  t = %.6f s\n", t_c);
    CHECK(NEAR(t_c, 12.822241, 1e-6));

    if (g_fail == 0) printf("ALL PASS\n"); else printf("%d FAILED\n", g_fail);
    return g_fail != 0;
}

코드 읽는 포인트

  • sim_collision_time은 시간을 t += dt로 더하지 않고 k * dt로 만듭니다. 0.01을 1000번 더하면 부동소수점 오차가 쌓이기 때문입니다.
  • did_collide는 dx² + dy² <= D²로 제곱끼리 비교합니다(sqrt 없음).
  • 시뮬레이션 함수는 Car를 값으로 받습니다. 호출자의 상태를 바꾸지 않고, 복사본으로 "미리 가 보기"가 쉽습니다.
  • update_car_exact의 r = speed/omega는 계산해서 나온 값입니다. 파라미터는 여전히 면접관의 다섯 개뿐입니다.
  • circle_from_car는 ω = 0이면 false를 반환합니다. 직선은 원이 없기 때문에 Solution 2만으로는 처리할 수 없습니다.

4.9 복잡도

  • Solution 1 (dt 고정): O(t_max / dt). 정확도를 10배 올리려면 10배 느려짐
  • Solution 1 refined / Solution 2: 거친 스텝 O(t_max / dt_coarse) + 이분법 O(log(dt/tol)). 예제는 83스텝 + 28번
  • 메모리 O(1)

5. 임베디드 관점으로 말할 것

  • Solution 1 = 실제 펌웨어 루프: 타이머 ISR이나 RTOS 주기 태스크가 dt마다 update(state, inputs, dt)를 부릅니다. dt는 상수가 아니라 측정한 경과 시간을 씁니다(지터 대응). 면접관이 이 구조를 원한 이유로 보입니다.
  • 수치 오차 = 안전 문제: Euler 오차가 차 크기만큼 커지면 충돌 판정이 틀립니다. "dt를 줄인다 / 정확한 적분 / 오차만큼 안전 여유를 더한다" 중 무엇을 고를지 말할 수 있어야 합니다.
  • FPU 사정: Cortex-M4F/M7은 single precision FPU만 있는 경우가 많아 double이 느립니다. MCU에서는 float + sinf/cosf, 또는 고정소수점 + 룩업 테이블.
  • 실제 차량에서는 예측을 계속 갱신: 매 주기 센서로 상태를 다시 받고 "앞으로 T초 안에 충돌하나?"(time-to-collision)를 다시 계산합니다. 면접관 Jason은 반자율 경로 추종 경력이 있어 이 이야기를 반길 가능성이 큽니다 추정.

6. Follow-up 질문과 답

Follow-up (English)답
Why did you want a radius parameter? Do you need it?필요 없습니다. heading을 omega로 계속 돌리면 결과적으로 반지름 v/ω의 원이 됩니다. 반지름·중심 표현(Solution 2)은 ω가 일정할 때 임의 시각 위치를 바로 구하는 최적화이고, 직선이나 입력 변화에는 상태 진행(Solution 1)이 더 일반적입니다.
Your answer depends on dt. Why?Euler는 dt 동안 접선으로 직진하기 때문입니다. dt = 0.5 → 12.50, 0.01 → 12.82, 정확한 값 12.822241. 정확한 호 공식을 쓰거나 dt를 줄입니다.
How do you avoid missing a collision?한 스텝에 거리가 최대 (|vA|+|vB|)·dt 변하므로, 이를 충돌 거리의 절반 이하로 잡습니다. dt가 크면 빠른 차가 서로 뚫고 지나갑니다(테스트 8: dt = 1 → −1, 정답 0.45).
What if speed or steering change over time?Solution 1이 그대로 갑니다. 매 스텝 새 speed/omega를 넣으면 됩니다. Solution 2는 원이 바뀔 때마다 다시 계산해야 합니다.
Can you solve it in closed form?직선끼리는 상대 위치가 p + v·t라 2차 방정식(closest point of approach). 원끼리는 sin/cos가 섞여 일반적인 닫힌 해가 없어 수치적으로 근을 찾습니다.
What about N cars?매 스텝 모든 쌍 O(N²). 격자로 공간을 나눠 이웃 칸만 비교하면 평균 O(N).
How would you test it?손으로 답이 나오는 경우(정면 직선 충돌 4.5 s, 평행 = −1, 처음부터 겹침 = 0), 아주 작은 dt와 비교, 두 솔루션이 같은 답을 내는지, 빠른 차(tunneling).
In C++?아래 코드. struct Car에 update()·collides() 멤버, 결과는 std::optional<double>.

면접관이 C++로 시작했으므로, Solution 1을 C++로 쓰면 이렇습니다.

#include <cmath>
#include <optional>

constexpr double kCollideDist = 1.0;

struct Car {
    double x, y, heading, speed, omega;

    void update(double dt) {                 // parameters -> next position
        x += speed * std::cos(heading) * dt;
        y += speed * std::sin(heading) * dt;
        heading += omega * dt;
    }
    bool collides(const Car& o) const {
        double dx = x - o.x, dy = y - o.y;
        return dx * dx + dy * dy <= kCollideDist * kCollideDist;
    }
};

std::optional<double> first_collision(Car a, Car b, double dt, double t_max) {
    for (long k = 0; k * dt <= t_max; ++k) {
        if (a.collides(b)) return k * dt;
        a.update(dt);
        b.update(dt);
    }
    return std::nullopt;
}
