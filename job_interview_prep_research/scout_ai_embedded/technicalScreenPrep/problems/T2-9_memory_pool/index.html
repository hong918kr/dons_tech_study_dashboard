T2-9 · Fixed-Block Memory Pool

IDT2-9
PriorityP2
Patternintrusive free list (stack) + used bitmap
Time30 min

파일: stub.c(여기서 풀기) · solution.c(정답) · 실행: ./run.sh T2-9 / ./run.sh T2-9 sol

1. Problem

On the robot, the telemetry task allocates one block per sensor message, fills it, and hands it to the radio task, which frees it after transmission. malloc() is banned (fragmentation, non-deterministic timing), so implement a fixed-block memory pool:

  • Storage is static: NUM_BLOCKS (8) blocks of BLOCK_SIZE (32) bytes inside the Pool object.
  • pool_init(): put every block on the free list, block 0 first.
  • pool_alloc(): O(1). Return a free block, or NULL when the pool is exhausted.
  • pool_free(): O(1). Return the block to the pool. It must detect
    • POOL_ERR_FOREIGN — the pointer is not the start of a block in this pool,
    • POOL_ERR_DOUBLE — the block is already free.
    • pool_free(p, NULL) is a no-op returning POOL_OK (like free(NULL)).
  • pool_free_count(): number of free blocks.
  • The free list is intrusive: the next pointer lives inside the free block itself. A used-block bitmap is allowed for the double-free check.
#define BLOCK_SIZE 32u
#define NUM_BLOCKS 8u
enum { POOL_OK = 0, POOL_ERR_FOREIGN = -1, POOL_ERR_DOUBLE = -2 };

typedef union Block { union Block *next; uint8_t bytes[BLOCK_SIZE]; uint64_t align_; } Block;
typedef struct { Block blocks[NUM_BLOCKS]; Block *free_head; uint32_t used; uint32_t n_free; } Pool;

void     pool_init(Pool *p);
void    *pool_alloc(Pool *p);
int      pool_free(Pool *p, void *ptr);
uint32_t pool_free_count(const Pool *p);

Example

pool_init        free list: B0 B1 B2 B3 B4 B5 B6 B7   free = 8
alloc x3         returns B0, B1, B2                   free = 5, used = 0x07
free(B1)         -> POOL_OK                           free = 6, used = 0x05
alloc            returns B1 (last freed, LIFO)
free(B1) again   -> POOL_ERR_DOUBLE
free(B0 + 1)     -> POOL_ERR_FOREIGN (not a block start)

Constraints

  • NUM_BLOCKS <= 32 (one uint32_t bitmap), BLOCK_SIZE >= sizeof(void *) and a multiple of 8.
  • Single-threaded for the base version (see Follow-up for ISR / multi-task use).

Clarifying questions to ask (first 3 minutes)

  1. Fixed block size only, or several size classes?
  2. What should pool_free do on an invalid pointer — return an error, assert, or hard-fault?
  3. Will alloc/free be called from an ISR or from several tasks at once?
  4. Do blocks need a specific alignment (DMA buffers, uint64_t fields)?
  5. Is LIFO reuse fine, or do we want FIFO to spread wear / catch use-after-free?

 *
 * The telemetry task allocates one block per sensor message, fills it, and hands it to the
 * radio task, which frees it after transmission. malloc() is banned (fragmentation,
 * non-deterministic timing), so implement a fixed-block pool:
 *
 *   - Storage is static: NUM_BLOCKS blocks of BLOCK_SIZE bytes inside the Pool object.
 *   - pool_init()  : put every block on the free list (block 0 first).
 *   - pool_alloc() : O(1). Return a free block, or NULL when the pool is exhausted.
 *   - pool_free()  : O(1). Return the block to the pool. Must detect:
 *                      POOL_ERR_FOREIGN  pointer is not the start of a block in this pool
 *                      POOL_ERR_DOUBLE   block is already free
 *                    pool_free(p, NULL) is a no-op returning POOL_OK (like free(NULL)).
 *   - pool_free_count() : number of free blocks.
 *   - The free list is INTRUSIVE: the "next" pointer lives inside the free block itself.
 *     A used-block bitmap is allowed for the double-free check.
 *
 * Build & run:  ./run.sh T2-9

#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

#define BLOCK_SIZE 32u        /* bytes per block (>= sizeof(void *)) */
#define NUM_BLOCKS 8u         /* <= 32 so one uint32_t bitmap is enough */

enum { POOL_OK = 0, POOL_ERR_FOREIGN = -1, POOL_ERR_DOUBLE = -2 };

typedef union Block {
    union Block *next;                  /* valid only while the block is free */
    uint8_t      bytes[BLOCK_SIZE];     /* payload while the block is in use */
    uint64_t     align_;                /* force 8-byte alignment */
} Block;

typedef struct {
    Block    blocks[NUM_BLOCKS];
    Block   *free_head;
    uint32_t used;                      /* bit i set = block i is allocated */
    uint32_t n_free;
} Pool;

void pool_init(Pool *p)
{
    /* TODO: your code here */
    (void)p;
}

void *pool_alloc(Pool *p)
{
    /* TODO: your code here */
    (void)p;
    return NULL;
}

int pool_free(Pool *p, void *ptr)
{
    /* TODO: your code here */
    (void)p; (void)ptr;
    return POOL_OK;
}

uint32_t pool_free_count(const Pool *p)
{
    /* TODO: your code here */
    (void)p;
    return 0;
}

int main(void)
{
    static Pool pool;                    /* static: lives in .bss, not on the stack */
    void *blk[NUM_BLOCKS + 1];

    /* 1. basic: alloc 3, free the middle one, the next alloc reuses it (LIFO) */
    pool_init(&pool);
    CHECK(pool_free_count(&pool) == 8u);
    blk[0] = pool_alloc(&pool); blk[1] = pool_alloc(&pool); blk[2] = pool_alloc(&pool);
    CHECK(blk[0] != NULL && blk[1] != NULL && blk[2] != NULL);
    CHECK(blk[0] != blk[1] && blk[1] != blk[2] && blk[0] != blk[2]);
    CHECK(pool_free_count(&pool) == 5u);
    CHECK(pool_free(&pool, blk[1]) == POOL_OK);
    CHECK(pool_free_count(&pool) == 6u);
    CHECK(blk[1] != NULL && pool_alloc(&pool) == blk[1]);

    /* 2. exhaustion: exactly NUM_BLOCKS distinct blocks, then NULL */
    pool_init(&pool);
    for (uint32_t i = 0; i < NUM_BLOCKS; i++) blk[i] = pool_alloc(&pool);
    bool distinct = true;
    for (uint32_t i = 0; i < NUM_BLOCKS; i++)
        for (uint32_t j = i + 1u; j < NUM_BLOCKS; j++)
            if (blk[i] == NULL || blk[i] == blk[j]) distinct = false;
    CHECK(distinct);
    CHECK(pool_alloc(&pool) == NULL);
    CHECK(pool_free_count(&pool) == 0u);

    /* 3. payload writes do not corrupt the pool (use the whole block) */
    for (uint32_t i = 0; i < NUM_BLOCKS; i++)
        if (blk[i]) memset(blk[i], 0xA5, BLOCK_SIZE);
    for (uint32_t i = 0; i < NUM_BLOCKS; i++) CHECK(pool_free(&pool, blk[i]) == POOL_OK);
    CHECK(pool_free_count(&pool) == NUM_BLOCKS);
    uint32_t got = 0;
    while (pool_alloc(&pool) != NULL && got <= NUM_BLOCKS) got++;
    CHECK(got == NUM_BLOCKS);

    /* 4. double free is detected and does not corrupt the free list */
    pool_init(&pool);
    void *x = pool_alloc(&pool);
    CHECK(pool_free(&pool, x) == POOL_OK);
    CHECK(pool_free(&pool, x) == POOL_ERR_DOUBLE);
    CHECK(pool_free_count(&pool) == NUM_BLOCKS);

    /* 5. foreign and misaligned pointers are rejected; NULL is a no-op */
    int on_stack = 0;
    x = pool_alloc(&pool);
    CHECK(pool_free(&pool, &on_stack) == POOL_ERR_FOREIGN);
    CHECK(x != NULL && pool_free(&pool, (uint8_t *)x + 1) == POOL_ERR_FOREIGN);
    CHECK(pool_free(&pool, (uint8_t *)&pool.blocks[NUM_BLOCKS - 1u] + BLOCK_SIZE) == POOL_ERR_FOREIGN);
    CHECK(pool_free(&pool, NULL) == POOL_OK);
    CHECK(pool_free_count(&pool) == NUM_BLOCKS - 1u);

    /* 6. never-allocated block inside the pool counts as a double free */
    pool_init(&pool);
    CHECK(pool_free(&pool, &pool.blocks[3]) == POOL_ERR_DOUBLE);

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

3. 힌트 (막힐 때 하나씩)

Hint 1 — free list는 스택

빈 블록들을 단일 연결 리스트로 잇고 free_head만 들고 있으면, alloc은 pop(head = head->next), free는 push(b->next = head; head = b)라서 둘 다 O(1)입니다. 연결 리스트 노드를 따로 만들 필요 없이 빈 블록의 첫 8바이트를 next 포인터로 재사용합니다(intrusive). 그래서 Block이 union입니다.

Hint 2 — 이 포인터가 우리 블록인가?

offset = (uintptr_t)ptr - (uintptr_t)blocks를 구해서

  1. 0 <= offset < NUM_BLOCKS * BLOCK_SIZE 인지(범위),
  2. offset % sizeof(Block) == 0 인지(블록 시작점),
  3. i = offset / sizeof(Block).

포인터끼리 < 비교는 서로 다른 객체면 C에서 UB라서 정수(uintptr_t)로 바꿔 비교합니다.

Hint 3 — double free는 비트맵으로

free list를 훑어서 이미 있는지 보면 O(n)입니다. 대신 uint32_t used의 비트 i를 alloc 때 켜고 free 때 끕니다. free할 때 비트가 이미 0이면 double free입니다(→ T2-6의 비트 연산).

4. 풀이

4.1 핵심 아이디어 — 그림으로 보기

블록들은 메모리에 B0…B7 순서로 고정되어 있고, 빈 블록끼리만 next로 연결됩니다. alloc은 head에서 하나 떼어 내고, free는 돌려받은 블록을 head 앞에 붙입니다.

사용 중인 블록에는 next가 없습니다. 사용자가 32바이트 전체를 덮어쓰기 때문입니다. 그래서 free list는 빈 블록만 이어야 하고, 사용 중 블록의 상태는 비트맵 used가 기억합니다.

4.2 손으로 따라가기 (trace)

테스트 1·4·5번을 한 흐름으로 이어 붙였습니다. used는 비트 i = Bi.

solution.c
/*
 * T2-9  Fixed-Block Memory Pool for Sensor Messages
 *
 * The telemetry task allocates one block per sensor message, fills it, and hands it to the
 * radio task, which frees it after transmission. malloc() is banned (fragmentation,
 * non-deterministic timing), so implement a fixed-block pool:
 *
 *   - Storage is static: NUM_BLOCKS blocks of BLOCK_SIZE bytes inside the Pool object.
 *   - pool_init()  : put every block on the free list (block 0 first).
 *   - pool_alloc() : O(1). Return a free block, or NULL when the pool is exhausted.
 *   - pool_free()  : O(1). Return the block to the pool. Must detect:
 *                      POOL_ERR_FOREIGN  pointer is not the start of a block in this pool
 *                      POOL_ERR_DOUBLE   block is already free
 *                    pool_free(p, NULL) is a no-op returning POOL_OK (like free(NULL)).
 *   - pool_free_count() : number of free blocks.
 *   - The free list is INTRUSIVE: the "next" pointer lives inside the free block itself.
 *     A used-block bitmap is allowed for the double-free check.
 *
 * Reference solution.  Build & run:  ./run.sh T2-9 sol
 */
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

#define BLOCK_SIZE 32u        /* bytes per block (>= sizeof(void *)) */
#define NUM_BLOCKS 8u         /* <= 32 so one uint32_t bitmap is enough */

enum { POOL_OK = 0, POOL_ERR_FOREIGN = -1, POOL_ERR_DOUBLE = -2 };

typedef union Block {
    union Block *next;                  /* valid only while the block is free */
    uint8_t      bytes[BLOCK_SIZE];     /* payload while the block is in use */
    uint64_t     align_;                /* force 8-byte alignment */
} Block;

typedef struct {
    Block    blocks[NUM_BLOCKS];
    Block   *free_head;
    uint32_t used;                      /* bit i set = block i is allocated */
    uint32_t n_free;
} Pool;

void pool_init(Pool *p)
{
    for (uint32_t i = 0; i + 1u < NUM_BLOCKS; i++)
        p->blocks[i].next = &p->blocks[i + 1u];      /* 0 -> 1 -> ... -> N-1 */
    p->blocks[NUM_BLOCKS - 1u].next = NULL;
    p->free_head = &p->blocks[0];
    p->used = 0;
    p->n_free = NUM_BLOCKS;
}

void *pool_alloc(Pool *p)
{
    Block *b = p->free_head;
    if (b == NULL) return NULL;                     /* exhausted */
    p->free_head = b->next;                         /* pop */
    p->used |= 1u << (uint32_t)(b - p->blocks);
    p->n_free--;
    return b;
}

int pool_free(Pool *p, void *ptr)
{
    if (ptr == NULL) return POOL_OK;
    /* compare as integers: relational compare of unrelated pointers is UB */
    uintptr_t base = (uintptr_t)p->blocks, a = (uintptr_t)ptr;
    if (a < base || a >= base + sizeof p->blocks) return POOL_ERR_FOREIGN;
    if ((a - base) % sizeof(Block) != 0u)         return POOL_ERR_FOREIGN;   /* mid-block */
    uint32_t i = (uint32_t)((a - base) / sizeof(Block));
    uint32_t bit = 1u << i;
    if ((p->used & bit) == 0u) return POOL_ERR_DOUBLE;
    p->used &= ~bit;
    Block *b = &p->blocks[i];
    b->next = p->free_head;                         /* push (LIFO) */
    p->free_head = b;
    p->n_free++;
    return POOL_OK;
}

uint32_t pool_free_count(const Pool *p)
{
    return p->n_free;
}

int main(void)
{
    static Pool pool;                    /* static: lives in .bss, not on the stack */
    void *blk[NUM_BLOCKS + 1];

    /* 1. basic: alloc 3, free the middle one, the next alloc reuses it (LIFO) */
    pool_init(&pool);
    CHECK(pool_free_count(&pool) == 8u);
    blk[0] = pool_alloc(&pool); blk[1] = pool_alloc(&pool); blk[2] = pool_alloc(&pool);
    CHECK(blk[0] != NULL && blk[1] != NULL && blk[2] != NULL);
    CHECK(blk[0] != blk[1] && blk[1] != blk[2] && blk[0] != blk[2]);
    CHECK(pool_free_count(&pool) == 5u);
    CHECK(pool_free(&pool, blk[1]) == POOL_OK);
    CHECK(pool_free_count(&pool) == 6u);
    CHECK(blk[1] != NULL && pool_alloc(&pool) == blk[1]);

    /* 2. exhaustion: exactly NUM_BLOCKS distinct blocks, then NULL */
    pool_init(&pool);
    for (uint32_t i = 0; i < NUM_BLOCKS; i++) blk[i] = pool_alloc(&pool);
    bool distinct = true;
    for (uint32_t i = 0; i < NUM_BLOCKS; i++)
        for (uint32_t j = i + 1u; j < NUM_BLOCKS; j++)
            if (blk[i] == NULL || blk[i] == blk[j]) distinct = false;
    CHECK(distinct);
    CHECK(pool_alloc(&pool) == NULL);
    CHECK(pool_free_count(&pool) == 0u);

    /* 3. payload writes do not corrupt the pool (use the whole block) */
    for (uint32_t i = 0; i < NUM_BLOCKS; i++)
        if (blk[i]) memset(blk[i], 0xA5, BLOCK_SIZE);
    for (uint32_t i = 0; i < NUM_BLOCKS; i++) CHECK(pool_free(&pool, blk[i]) == POOL_OK);
    CHECK(pool_free_count(&pool) == NUM_BLOCKS);
    uint32_t got = 0;
    while (pool_alloc(&pool) != NULL && got <= NUM_BLOCKS) got++;
    CHECK(got == NUM_BLOCKS);

    /* 4. double free is detected and does not corrupt the free list */
    pool_init(&pool);
    void *x = pool_alloc(&pool);
    CHECK(pool_free(&pool, x) == POOL_OK);
    CHECK(pool_free(&pool, x) == POOL_ERR_DOUBLE);
    CHECK(pool_free_count(&pool) == NUM_BLOCKS);

    /* 5. foreign and misaligned pointers are rejected; NULL is a no-op */
    int on_stack = 0;
    x = pool_alloc(&pool);
    CHECK(pool_free(&pool, &on_stack) == POOL_ERR_FOREIGN);
    CHECK(x != NULL && pool_free(&pool, (uint8_t *)x + 1) == POOL_ERR_FOREIGN);
    CHECK(pool_free(&pool, (uint8_t *)&pool.blocks[NUM_BLOCKS - 1u] + BLOCK_SIZE) == POOL_ERR_FOREIGN);
    CHECK(pool_free(&pool, NULL) == POOL_OK);
    CHECK(pool_free_count(&pool) == NUM_BLOCKS - 1u);

    /* 6. never-allocated block inside the pool counts as a double free */
    pool_init(&pool);
    CHECK(pool_free(&pool, &pool.blocks[3]) == POOL_ERR_DOUBLE);

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;

코드 읽는 포인트

  • union Block에 uint64_t align_을 넣어 블록이 8바이트 정렬되게 했습니다. 사용자가 uint64_t 타임스탬프나 double을 넣어도 정렬 오류(Cortex-M의 unaligned fault)가 나지 않습니다. C11이면 _Alignas(8)도 됩니다.
  • b - p->blocks는 같은 배열 안 포인터 뺄셈이라 정의된 연산이고 결과가 블록 인덱스입니다.
  • double free를 검사하지 않고 push하면 같은 블록이 리스트에 두 번 들어가 순환 리스트가 생기고, 이후 alloc 두 번이 같은 블록을 돌려줍니다. 비트맵 검사가 이것을 막습니다(테스트 4번).
  • 테스트에서 Pool을 static으로 둔 이유: 256바이트 이상을 스택에 올리지 않기 위함입니다. 실제 펌웨어에서도 풀은 전역(.bss)에 둡니다.

4.4 복잡도

  • pool_alloc / pool_free / pool_free_count: O(1), 루프 없음 → 최악 실행 시간이 고정.
  • pool_init: O(NUM_BLOCKS), 부팅 때 한 번.
  • 메모리: 블록 256바이트 + 관리용 12~16바이트. 블록마다 헤더가 없습니다(intrusive).

5. 임베디드 관점으로 말할 것

  • 왜 malloc을 안 쓰나: 힙 단편화로 오래 돌수록 큰 할당이 실패할 수 있고, 실행 시간이 입력에 따라 달라 실시간 보장이 어렵습니다. MISRA C도 동적 할당을 금지합니다. 고정 블록 풀은 단편화가 원천적으로 없고 O(1)입니다.
  • ISR·멀티태스크: alloc/free의 "읽고-바꾸고-쓰기"는 원자적이지 않습니다. 짧은 critical section(인터럽트 off)으로 감싸거나, RTOS의 메모리 풀 API(FreeRTOS는 정적 할당 + 큐, Zephyr k_mem_slab)를 씁니다.
  • 디버깅 보조: free할 때 블록을 0xDD로 채우고(poison), alloc할 때 검사하면 use-after-free를 잡을 수 있습니다. 최저 여유 블록 수(high-water mark)를 기록하면 풀 크기를 정할 근거가 됩니다.
  • 소유권 이동: 텔레메트리 태스크가 alloc → 큐에 포인터만 넣음 → 라디오 태스크가 전송 후 free. 데이터 복사 없이 포인터만 넘기는 zero-copy 패턴입니다(→ T2-1).

6. Follow-up 질문과 답

Follow-up (English)답
Make it safe to call from an ISR and a task.alloc/free 본문을 primask = __get_PRIMASK(); __disable_irq(); … __set_PRIMASK(primask);로 감쌉니다. 몇 명령뿐이라 인터럽트 지연이 짧습니다. 락프리로 하려면 LDREX/STREX로 head를 CAS하되 ABA 문제를 태그 카운터로 막아야 합니다.

How do you detect use-after-free?free 시 블록을 poison 값으로 채우고 alloc 시 next 다음 바이트들이 여전히 poison인지 검사합니다. 또는 FIFO로 재사용해서 방금 해제한 블록이 바로 재사용되지 않게 합니다.
What if NUM_BLOCKS is 100?비트맵을 uint32_t used[(N + 31) / 32]로 늘리고 used[i >> 5] & (1u << (i & 31))로 접근합니다.
Can you avoid the bitmap entirely?블록 앞에 매직 값 헤더를 두거나(사용 중 0xA110C8ED, 빈 블록 0xF4EEF4EE) free list를 훑는 O(n) 검사를 디버그 빌드에서만 켭니다. 비트맵이 가장 싸고 확실합니다.

7. 자주 하는 실수

  • 빈 블록이 없을 때 free_head->next를 그대로 읽음 → NULL 역참조(테스트 2번)
  • next 포인터를 사용 중 블록에도 있다고 가정 → 사용자가 payload를 쓰면 리스트가 깨짐(테스트 3번)
  • double free 검사 없음 → 리스트에 같은 블록이 두 번 들어가 순환(테스트 4번)
  • 포인터 범위를 ptr < p->blocks 같은 포인터 비교로 검사 → 다른 객체 포인터면 UB. uintptr_t로 비교
  • 블록 경계(% sizeof(Block)) 검사를 빼서 B0 + 1 같은 내부 포인터를 받아들임(테스트 5번)
  • 1u << i 대신 1 << i → i = 31에서 부호 있는 오버플로(UB)
