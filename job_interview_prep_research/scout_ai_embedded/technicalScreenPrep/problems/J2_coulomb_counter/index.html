J2 · Battery State of Charge by Coulomb Counting

IDJ2
PriorityP1
Patternstreaming integration + exact accumulator + wrap-safe dt + clamp + hysteresis + table interpolation
Time30 min

파일: stub.c(여기서 풀기) · solution.c(정답) · 실행: ./run.sh J2 / ./run.sh J2 sol

1. Problem

A battery-powered robot measures pack current with a shunt resistor, a current-sense amplifier and a 12-bit ADC. A timer calls you with each ADC reading and a millisecond timestamp. Track the state of charge (SoC) by integrating current over time ("coulomb counting").

Part A — counting

  • Convert a reading to current: current_mA = ((int32_t)raw - 2048) * 10 / 1 (zero current at code 2048, 10 mA per count). Positive = discharge, negative = charging.
  • ADC codes 0 and 4095 are saturated (the sensor is at a rail): do not integrate, set s->fault, increment s->faults. The next good sample clears s->fault.
  • dt = (uint32_t)(now_ms - last_ms) must be wrap-safe. Every call updates last_ms. The current measured at now_ms is used for the whole interval (last, now].
  • If dt > MAX_GAP_MS (1000 ms), samples were lost: do not integrate that interval, increment s->gaps.
  • Accumulate charge in mA·ms in an int64_t so that small currents are never lost to rounding. Clamp the remaining charge to [0, capacity].
  • soc_permille() returns remaining * 1000 / capacity, rounded down (0..1000).

Part B — low-battery alert with hysteresis: the alert turns ON at <= 150 permille and turns OFF at >= 200 permille. Between them it keeps its previous state. soc_init and soc_rest_calibrate evaluate it too.

Part C — rest-voltage recalibration: when the pack has been at rest, its open-circuit voltage (OCV) tells you the SoC. Map millivolts to permille through the given 7-point table with integer linear interpolation (rounded down), clamped below the first and above the last point. soc_rest_calibrate() overwrites the counted charge with that value.

Example

10 mAh pack, start 1000 permille, t = 0
raw 2148 (= +1000 mA) every 100 ms until t = 3600
  -> 1000 mA * 3600 ms = 3,600,000 mA*ms = 1 mAh  -> 900 permille

1 mAh pack, raw 2049 (= +10 mA) every 10 ms, 18000 times (180 s)
  -> each step is only 100 mA*ms, but 18000 * 100 = 0.5 mAh -> 500 permille

ocv_to_permille(3650) = 150 + (50 * 250) / 100 = 275
ocv_to_permille(3000) = 0,  ocv_to_permille(4300) = 1000

Constraints

  • 1 <= capacity_mAh <= 1,000,000; soc_permille argument above 1000 is clamped to 1000.
  • Calls come from one context (a timer task); no locking needed in this version.
  • No malloc, no floating point.

Clarifying questions to ask (first 3 minutes)

  1. Which sign is discharge? Where is the zero-current code, and is it calibrated?
  2. Over an interval, do I use the new sample, the previous one, or the average (trapezoid)?
  3. What should happen after a long gap — integrate with the last current, or skip?
  4. What does a saturated ADC code mean here — a real overcurrent or a broken sensor?
  5. Should the alert use hysteresis, and what are the on/off levels? Is the boundary inclusive?
  6. When is it safe to trust the rest voltage (how long at rest, which temperature)?

{
    Soc s = {0};

    /* 1. normal discharge: 1000 mA for 3.6 s = 1 mAh = 10% of a 10 mAh pack */
    CHECK(current_mA(2148) == 1000 && current_mA(1948) == -1000 && current_mA(2048) == 0);
    soc_init(&s, 10, 1000, 0);
    CHECK(soc_permille(&s) == 1000 && !soc_low_alert(&s));
    for (uint32_t t = 100; t <= 3600; t += 100) soc_update(&s, 2148, t);
    CHECK(soc_permille(&s) == 900);
    CHECK(s.rem_mAms == 9 * MAMS_PER_MAH);
    soc_update(&s, 2048, 3700);                       /* zero current: no change */
    CHECK(soc_permille(&s) == 900 && s.gaps == 0 && s.faults == 0);

    /* 2. tiny current, many steps: 10 mA * 10 ms = 100 mA*ms per step.
     *    Dividing to mAh every step gives 0 each time; the accumulator must keep it. */
    soc_init(&s, 1, 1000, 0);
    for (uint32_t i = 1; i <= 18000; i++) soc_update(&s, 2049, i * 10);   /* 180 s */
    CHECK(soc_permille(&s) == 500);
    CHECK(s.rem_mAms == MAMS_PER_MAH / 2);

    /* 3. charging clamps at capacity (stored value, not just the display) */
    soc_init(&s, 10, 990, 0);
    soc_update(&s, 1688, 1000);                       /* -3600 mA for 1 s = +1 mAh */
    soc_update(&s, 1688, 2000);
    CHECK(soc_permille(&s) == 1000 && s.rem_mAms == s.cap_mAms);
    soc_update(&s, 2084, 3000);                       /* +360 mA for 1 s = -0.1 mAh */
    CHECK(soc_permille(&s) == 990);

    /* 4. deep discharge clamps at 0, then charging starts from 0 */
    soc_init(&s, 10, 50, 0);
    CHECK(soc_low_alert(&s));                         /* starts low -> alert on */
    soc_update(&s, 2408, 1000);                       /* 3600 mA for 1 s */
    soc_update(&s, 2408, 2000);
    CHECK(soc_permille(&s) == 0 && s.rem_mAms == 0);
    soc_update(&s, 2012, 3000);                       /* -360 mA for 1 s */
    CHECK(soc_permille(&s) == 10);

    /* 5. timer wrap: last = 2^32 - 500, now = 500 -> dt = 1000 */
    soc_init(&s, 10, 1000, 0xFFFFFE0Cu);
    soc_update(&s, 2084, 500u);
    CHECK(s.gaps == 0 && soc_permille(&s) == 990);

    /* 6. gap > MAX_GAP_MS: skip the interval, but resync last_ms */
    soc_init(&s, 10, 1000, 0);
    soc_update(&s, 2408, 1001);                       /* dt = 1001 -> gap */
    CHECK(s.gaps == 1 && soc_permille(&s) == 1000);
    soc_update(&s, 2408, 2001);                       /* dt = 1000 -> integrate */
    CHECK(s.gaps == 1 && soc_permille(&s) == 900);

    /* 7. saturated ADC codes are faults: no integration */
    soc_init(&s, 10, 1000, 0);
    soc_update(&s, 4095, 1000);
    CHECK(s.fault && s.faults == 1 && soc_permille(&s) == 1000);
    soc_update(&s, 0, 2000);
    CHECK(s.fault && s.faults == 2 && soc_permille(&s) == 1000);
    soc_update(&s, 2084, 3000);                       /* good sample clears the flag */
    CHECK(!s.fault && s.faults == 2 && soc_permille(&s) == 990);

    /* 8. hysteresis: 10 permille per 1 s step (360 mA on 10 mAh) */
    soc_init(&s, 10, 300, 0);
    uint32_t t = 0;
    int on_edges = 0, off_edges = 0;
    bool prev = soc_low_alert(&s);
    for (int i = 0; i < 25; i++) {
        uint16_t raw = (i < 16) ? 2084 : (i < 22) ? 2012 : 2084;  /* down, up, down */
        t += 1000;
        soc_update(&s, raw, t);
        bool now = soc_low_alert(&s);
        if (now && !prev) on_edges++;
        if (!now && prev) off_edges++;
        prev = now;
        if (t == 14000) CHECK(soc_permille(&s) == 160 && !now);
        if (t == 15000) CHECK(soc_permille(&s) == 150 && now);   /* ON at <= 150 */
        if (t == 16000) CHECK(soc_permille(&s) == 140 && now);
        if (t == 21000) CHECK(soc_permille(&s) == 190 && now);   /* still ON in band */
        if (t == 22000) CHECK(soc_permille(&s) == 200 && !now);  /* OFF at >= 200 */
        if (t == 25000) CHECK(soc_permille(&s) == 170 && !now);  /* no re-trigger */
    }
    CHECK(on_edges == 1 && off_edges == 1);

    /* 9. OCV table: clamps, exact points, interpolation (rounded down) */
    CHECK(ocv_to_permille(3000) == 0 && ocv_to_permille(4300) == 1000);
    CHECK(ocv_to_permille(3300) == 0 && ocv_to_permille(3700) == 400 && ocv_to_permille(4200) == 1000);
    CHECK(ocv_to_permille(3650) == 275);
    CHECK(ocv_to_permille(3900) == 725);
    CHECK(ocv_to_permille(3333) == 8);                /* 33 * 50 / 200 = 8.25 -> 8 */

    /* 10. rest calibration overwrites the counted charge and re-evaluates the alert */
    soc_init(&s, 10, 900, 0);
    soc_rest_calibrate(&s, 3650);
    CHECK(soc_permille(&s) == 275 && !soc_low_alert(&s));
    soc_rest_calibrate(&s, 3500);
    CHECK(soc_permille(&s) == 50 && soc_low_alert(&s));

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

3. 힌트 (막힐 때 하나씩)

Hint 1 — 단위를 mA·ms로 고정하면 나눗셈이 사라진다

I(mA) × dt(ms)는 항상 정수이고 정확합니다. 용량도 같은 단위로 저장하세요: cap_mAms = capacity_mAh × 3,600,000. 그러면 soc_update에는 곱셈·뺄셈·clamp만 남고, 나눗셈은 soc_permille()에서 읽을 때 한 번만 합니다. 매 step마다 mAh로 나누면 몫이 0이 되어 작은 전류가 통째로 사라집니다.

Hint 2 — soc_update의 순서
  1. dt = (uint32_t)(now - last); last = now; ← 어떤 경로로 빠져나가도 last는 갱신
  2. 포화 코드(0, 4095)면 fault = true; faults++; return;
  3. fault = false; 그리고 dt > MAX_GAP_MS면 gaps++; return;
  4. rem -= (int64_t)current_mA(raw) * dt; → [0, cap]로 clamp
  5. 히스테리시스 갱신
Hint 3 — 히스테리시스와 표 보간
  • 알람: if (!on && p <= 150) on = true; else if (on && p >= 200) on = false; — 상태별로 "반대편으로 가는 조건"만 봅니다(T1-2와 같은 패턴).
  • 보간: 먼저 양 끝 clamp, 그다음 OCV[i-1].mv < mv <= OCV[i].mv인 구간을 찾고 y0 + (mv - x0) * (y1 - y0) / (x1 - x0). 곱하고 나서 나눕니다. 순서를 바꾸면 250/100 = 2가 되어 오차가 큽니다.

4. 풀이

4.1 핵심 아이디어 — 그림으로 보기

Coulomb counting은 "전류를 시간에 대해 적분"하는 것, 즉 Q = Σ I·dt입니다. 문제의 대부분은 적분 자체보다 경계 조건(정밀도, 시간 wrap, 끊긴 샘플, 고장 센서, 범위 clamp)을 처리하는 데 있습니다.

먼저 정밀도. 1 mAh 팩에 10 mA가 10 ms마다 들어오면 한 step에 빠지는 양은 100 mA·ms = 0.0000278 mAh입니다. 남은 용량을 mAh 정수로 들고 매번 나누면 100 / 3,600,000 = 0이라 180초가 지나도 1000‰ 그대로입니다. mA·ms 누적기는 18000 step 뒤 정확히 1,800,000 mA·ms(= 0.5 mAh) → 500‰입니다.

"remainder를 들고 다닌다"는 말은 결국 이것입니다. 단위를 따로 mAh로 두고 싶다면 rem_mAh와 frac_mAms(0..3,599,999) 두 개를 들고, frac이 3,600,000을 넘을 때만 1 mAh를 넘겨주면 됩니다. 결과는 같고, 하나의 int64 mA·ms가 더 단순합니다.

#define ZERO_RAW         2048
#define MA_PER_COUNT_NUM 10
#define MA_PER_COUNT_DEN 1
#define MAX_GAP_MS       1000u
#define MAMS_PER_MAH     3600000LL   /* 1 mAh = 3600 s * 1000 ms */
#define LOW_ON_PERMILLE  150u
#define LOW_OFF_PERMILLE 200u

typedef struct {
    int64_t  cap_mAms;    /* capacity in mA*ms */
    int64_t  rem_mAms;    /* remaining charge in mA*ms, 0..cap_mAms */
    uint32_t last_ms;     /* time of the previous call */
    uint32_t gaps;        /* intervals skipped because dt > MAX_GAP_MS */
    uint32_t faults;      /* saturated ADC samples seen */
    bool     fault;       /* the most recent sample was saturated */
    bool     low_alert;
} Soc;

int32_t current_mA(uint16_t raw)
{
    return ((int32_t)raw - ZERO_RAW) * MA_PER_COUNT_NUM / MA_PER_COUNT_DEN;
}

uint16_t soc_permille(const Soc *s)
{
    if (s->cap_mAms <= 0) return 0;
    return (uint16_t)(s->rem_mAms * 1000 / s->cap_mAms);   /* < 2^63: see capacity limit */
}

static void update_alert(Soc *s)
{
    uint16_t p = soc_permille(s);
    if (!s->low_alert && p <= LOW_ON_PERMILLE)  s->low_alert = true;
    else if (s->low_alert && p >= LOW_OFF_PERMILLE) s->low_alert = false;
}

void soc_init(Soc *s, uint32_t capacity_mAh, uint16_t soc_pm, uint32_t now_ms)
{
    memset(s, 0, sizeof *s);
    if (soc_pm > 1000) soc_pm = 1000;
    s->cap_mAms = (int64_t)capacity_mAh * MAMS_PER_MAH;
    s->rem_mAms = s->cap_mAms * soc_pm / 1000;
    s->last_ms  = now_ms;
    update_alert(s);
}

void soc_update(Soc *s, uint16_t adc_raw, uint32_t now_ms)
{
    uint32_t dt = (uint32_t)(now_ms - s->last_ms);   /* wrap-safe */
    s->last_ms = now_ms;

    if (adc_raw == 0 || adc_raw >= ADC_MAX) {         /* rail = sensor fault */
        s->fault = true;
        s->faults++;
        return;
    }
    s->fault = false;
    if (dt > MAX_GAP_MS) { s->gaps++; return; }       /* don't guess across a hole */

    /* discharge (+) removes charge, charging (-) adds it; no division here */
    s->rem_mAms -= (int64_t)current_mA(adc_raw) * dt;
    if (s->rem_mAms < 0)           s->rem_mAms = 0;
    if (s->rem_mAms > s->cap_mAms) s->rem_mAms = s->cap_mAms;
    update_alert(s);
}

bool soc_low_alert(const Soc *s) { return s->low_alert; }

/* ---- Part C: open-circuit-voltage recalibration ---- */
typedef struct { uint16_t mv, pm; } OcvPoint;
static const OcvPoint OCV[] = {
    {3300, 0}, {3500, 50}, {3600, 150}, {3700, 400}, {3800, 600}, {4000, 850}, {4200, 1000},
};
#define OCV_N (sizeof OCV / sizeof OCV[0])

uint16_t ocv_to_permille(uint16_t mv)
{
    if (mv <= OCV[0].mv)         return OCV[0].pm;
    if (mv >= OCV[OCV_N - 1].mv) return OCV[OCV_N - 1].pm;
    size_t i = 1;
    while (OCV[i].mv < mv) i++;                       /* OCV[i-1].mv < mv <= OCV[i].mv */
    int32_t x0 = OCV[i - 1].mv, x1 = OCV[i].mv;
    int32_t y0 = OCV[i - 1].pm, y1 = OCV[i].pm;
    return (uint16_t)(y0 + ((int32_t)mv - x0) * (y1 - y0) / (x1 - x0));
}

void soc_rest_calibrate(Soc *s, uint16_t cell_mv)
{
    s->rem_mAms = s->cap_mAms * ocv_to_permille(cell_mv) / 1000;
    update_alert(s);
}

int main(void)
{
    Soc s = {0};

    /* 1. normal discharge: 1000 mA for 3.6 s = 1 mAh = 10% of a 10 mAh pack */
    CHECK(current_mA(2148) == 1000 && current_mA(1948) == -1000 && current_mA(2048) == 0);
    soc_init(&s, 10, 1000, 0);
    CHECK(soc_permille(&s) == 1000 && !soc_low_alert(&s));
    for (uint32_t t = 100; t <= 3600; t += 100) soc_update(&s, 2148, t);
    CHECK(soc_permille(&s) == 900);
    CHECK(s.rem_mAms == 9 * MAMS_PER_MAH);
    soc_update(&s, 2048, 3700);                       /* zero current: no change */
    CHECK(soc_permille(&s) == 900 && s.gaps == 0 && s.faults == 0);

    /* 2. tiny current, many steps: 10 mA * 10 ms = 100 mA*ms per step.
     *    Dividing to mAh every step gives 0 each time; the accumulator must keep it. */
    soc_init(&s, 1, 1000, 0);
    for (uint32_t i = 1; i <= 18000; i++) soc_update(&s, 2049, i * 10);   /* 180 s */
    CHECK(soc_permille(&s) == 500);
    CHECK(s.rem_mAms == MAMS_PER_MAH / 2);

    /* 3. charging clamps at capacity (stored value, not just the display) */
    soc_init(&s, 10, 990, 0);
    soc_update(&s, 1688, 1000);                       /* -3600 mA for 1 s = +1 mAh */
    soc_update(&s, 1688, 2000);
    CHECK(soc_permille(&s) == 1000 && s.rem_mAms == s.cap_mAms);
    soc_update(&s, 2084, 3000);                       /* +360 mA for 1 s = -0.1 mAh */
    CHECK(soc_permille(&s) == 990);

    /* 4. deep discharge clamps at 0, then charging starts from 0 */
    soc_init(&s, 10, 50, 0);
    CHECK(soc_low_alert(&s));                         /* starts low -> alert on */
    soc_update(&s, 2408, 1000);                       /* 3600 mA for 1 s */
    soc_update(&s, 2408, 2000);
    CHECK(soc_permille(&s) == 0 && s.rem_mAms == 0);
    soc_update(&s, 2012, 3000);                       /* -360 mA for 1 s */
    CHECK(soc_permille(&s) == 10);

    /* 5. timer wrap: last = 2^32 - 500, now = 500 -> dt = 1000 */
    soc_init(&s, 10, 1000, 0xFFFFFE0Cu);
    soc_update(&s, 2084, 500u);
    CHECK(s.gaps == 0 && soc_permille(&s) == 990);

    /* 6. gap > MAX_GAP_MS: skip the interval, but resync last_ms */
    soc_init(&s, 10, 1000, 0);
    soc_update(&s, 2408, 1001);                       /* dt = 1001 -> gap */
    CHECK(s.gaps == 1 && soc_permille(&s) == 1000);
    soc_update(&s, 2408, 2001);                       /* dt = 1000 -> integrate */
    CHECK(s.gaps == 1 && soc_permille(&s) == 900);

    /* 7. saturated ADC codes are faults: no integration */
    soc_init(&s, 10, 1000, 0);
    soc_update(&s, 4095, 1000);
    CHECK(s.fault && s.faults == 1 && soc_permille(&s) == 1000);
    soc_update(&s, 0, 2000);
    CHECK(s.fault && s.faults == 2 && soc_permille(&s) == 1000);
    soc_update(&s, 2084, 3000);                       /* good sample clears the flag */
    CHECK(!s.fault && s.faults == 2 && soc_permille(&s) == 990);

    /* 8. hysteresis: 10 permille per 1 s step (360 mA on 10 mAh) */
    soc_init(&s, 10, 300, 0);
    uint32_t t = 0;
    int on_edges = 0, off_edges = 0;
    bool prev = soc_low_alert(&s);
    for (int i = 0; i < 25; i++) {
        uint16_t raw = (i < 16) ? 2084 : (i < 22) ? 2012 : 2084;  /* down, up, down */
        t += 1000;
        soc_update(&s, raw, t);
        bool now = soc_low_alert(&s);
        if (now && !prev) on_edges++;
        if (!now && prev) off_edges++;
        prev = now;
        if (t == 14000) CHECK(soc_permille(&s) == 160 && !now);
        if (t == 15000) CHECK(soc_permille(&s) == 150 && now);   /* ON at <= 150 */
        if (t == 16000) CHECK(soc_permille(&s) == 140 && now);
        if (t == 21000) CHECK(soc_permille(&s) == 190 && now);   /* still ON in band */
        if (t == 22000) CHECK(soc_permille(&s) == 200 && !now);  /* OFF at >= 200 */
        if (t == 25000) CHECK(soc_permille(&s) == 170 && !now);  /* no re-trigger */
    }
    CHECK(on_edges == 1 && off_edges == 1);

    /* 9. OCV table: clamps, exact points, interpolation (rounded down) */
    CHECK(ocv_to_permille(3000) == 0 && ocv_to_permille(4300) == 1000);
    CHECK(ocv_to_permille(3300) == 0 && ocv_to_permille(3700) == 400 && ocv_to_permille(4200) == 1000);
    CHECK(ocv_to_permille(3650) == 275);
    CHECK(ocv_to_permille(3900) == 725);
    CHECK(ocv_to_permille(3333) == 8);                /* 33 * 50 / 200 = 8.25 -> 8 */

    /* 10. rest calibration overwrites the counted charge and re-evaluates the alert */
    soc_init(&s, 10, 900, 0);
    soc_rest_calibrate(&s, 3650);
    CHECK(soc_permille(&s) == 275 && !soc_low_alert(&s));
    soc_rest_calibrate(&s, 3500);
    CHECK(soc_permille(&s) == 50 && soc_low_alert(&s));

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

코드 읽는 포인트

  • (int64_t)current_mA(raw) * dt: 캐스트를 곱셈 전에 합니다. int32 × uint32는 uint32로 승격되어 음수 전류(충전)가 거대한 양수가 됩니다. 이 버그는 테스트 4의 충전 단계에서 바로 드러납니다.
  • last_ms = now_ms를 함수 맨 앞에서 갱신합니다. fault/gap으로 return해도 다음 dt가 "직전 호출부터"로 맞습니다. 이걸 빠뜨리면 gap 다음 샘플도 계속 gap이 됩니다.
  • update_alert() 하나를 init·update·calibrate 세 곳에서 부릅니다. 상태 머신을 한 곳에만 두는 게 버그를 줄입니다.
  • soc_permille에서 rem × 1000: 용량 상한 1,000,000 mAh → 3.6×10¹² mA·ms × 1000 = 3.6×10¹⁵ < 9.2×10¹⁸(INT64_MAX)이라 안전합니다.
  • OCV 보간은 int32_t로 계산합니다(uint16_t 차이를 빼면 음수가 될 수 있는 식을 피함). 표가 단조 증가라는 전제로 선형 탐색 7번이면 충분하고, 표가 크면 이분 탐색으로 바꿉니다 → T2-5.

4.6 복잡도

  • soc_update: O(1) — 곱셈 1번, 비교 몇 번. 나눗셈 없음.
  • ocv_to_permille: O(표 크기) = 7, 이분 탐색이면 O(log n).
  • 상태: 구조체 32바이트(int64 2개 + uint32 3개 + bool 2개 + 패딩).

5. 임베디드 관점으로 말할 것

  • 왜 이 문제인가: 면접관 Jason MacDonald는 Johnson Outdoors에서 RTOS 기반 트롤링 모터 제품에 "배터리 전류를 모니터링해서 SoC를 계산"하는 기능을 직접 구현했습니다. Scout도 배터리로 움직이는 로봇·드론을 만듭니다. 그래서 "전류 적분 + 경계 처리 + 보정"을 짧게 짜고 설명할 수 있으면 대화가 바로 그 경험으로 이어집니다. 끝나고 "트롤링 모터에서는 offset 보정을 어떻게 하셨나요?" 같은 질문을 던지기 좋습니다.
  • 정밀도는 단위 선택으로 해결: 부동소수점 없이 mA·ms 정수 누적기를 쓰면 매 step 오차가 0입니다. 오차는 센서(offset, gain) 쪽에서만 생깁니다.
  • 어디서 돌리나: ADC를 타이머 트리거 + DMA로 돌리고, DMA 완료 ISR(또는 그 ISR이 깨우는 태스크)에서 샘플 블록을 평균 내서 soc_update를 부릅니다. ISR에서는 64비트 곱셈 1번이라 Cortex-M에서도 짧지만, 알람 처리·로그·CAN 전송은 태스크로 넘깁니다. 다른 태스크가 rem_mAms(64비트)를 읽으면 찢어진 읽기가 생길 수 있으니 critical section이나 seqlock으로 보호합니다 → E3.
  • 센서를 믿지 않기: 포화 코드는 실제 과전류일 수도, 증폭기 고장일 수도 있습니다. 적분하지 않고 플래그를 세운 뒤 상위(BMS/안전 로직)가 판단하게 합니다 → T1-6.
  • gap은 추측하지 않기: 샘플이 끊긴 동안을 마지막 전류로 채우면 큰 오차가 생깁니다. 건너뛰고 세어 두면 나중에 진단할 수 있습니다.
  • 히스테리시스: 부하가 바뀔 때 전압·SoC가 흔들려서 알람이 깜빡이는 걸 막습니다. 저전압 컷오프도 같은 패턴입니다 → T1-2, T2-7.

6. Follow-up 질문과 답

Follow-up (English)답
Why does coulomb counting drift over time?적분이라 작은 offset 오차가 시간에 비례해서 쌓입니다. 예: zero 코드가 1 count(10 mA) 틀리면 하루에 240 mAh가 틀어집니다. 그 밖에 gain 오차(shunt 저항 온도계수), 자가방전(측정 안 되는 전류), 온도에 따른 실제 용량 변화, Peukert 효과(고전류일수록 꺼낼 수 있는 용량이 줄어듦), 노화로 인한 용량 감소가 있습니다.
How do you calibrate the current-sense offset?부하를 끊은 상태(MOSFET off, 또는 부팅 직후 모터 정지)에서 수백 샘플을 평균 내 zero_raw를 측정해 저장합니다. 온도별로 다르면 몇 점 테이블로 둡니다. 런타임에는 "전류가 거의 0인 구간"의 아주 작은 값을 deadband로 0 처리하기도 합니다(대신 자가방전을 놓침).
When do you trust OCV, and how do you combine it with counting?부하가 없고 일정 시간(수십 분) 쉬어서 전압이 이완된 뒤에만 OCV가 SoC를 잘 나타냅니다. 부하 중에는 IR drop 때문에 낮게 보입니다. 그래서 휴지 상태가 감지되면 OCV로 재보정(Part C)하고, 사용 중에는 counting을 씁니다. Li-ion은 중간 구간(3600~3800 mV)이 평평하지 않지만 LFP는 매우 평평해서 OCV 보정이 거의 끝점에서만 유효합니다.
Can you do better than resetting from OCV?Kalman filter(EKF)로 두 정보를 융합합니다. 상태 = SoC(+ RC 분극 전압), 예측 = coulomb counting, 측정 = 단자 전압과 배터리 등가회로 모델. 측정 신뢰도에 따라 가중치가 자동으로 정해져서 "갑자기 점프"하는 재보정 대신 부드럽게 보정됩니다. 다만 모델 파라미터 식별이 필요해서 MCU에서는 간단한 버전을 씁니다.
How big can the accumulator get? Could int32 work?최악 1 step: 20,470 mA × 1000 ms ≈ 2×10⁷ — int32에 들어갑니다. 하지만 누적값은 10 Ah 팩만 해도 3.6×10¹⁰ mA·ms라 int32(2.1×10⁹) 초과입니다. int64면 9.2×10¹⁸이라 충분하고, ×1000 연산까지 고려해 용량 상한(1,000 Ah)을 둡니다. int32만 쓰고 싶으면 mAh 정수 + mA·ms 나머지(0..3,599,999)로 쪼갭니다.
Rectangle or trapezoid integration?샘플 주기가 전류 변화보다 충분히 빠르면 사각형으로 충분합니다. PWM 모터 전류처럼 리플이 크면 ADC를 PWM에 동기화하거나 하드웨어 평균/필터를 쓰는 게 적분 방식보다 중요합니다. 사다리꼴은 이전 전류를 저장해야 해서 상태가 하나 늘어납니다.
Would you use a fuel-gauge IC instead?보통 그렇습니다. TI BQ 시리즈(예: BQ34Z100, BQ40Z50) 같은 fuel gauge는 coulomb counter, 온도 보상, 셀 모델(Impedance Track), 노화 학습, 보호를 하드웨어로 제공하고 I2C/SMBus로 SoC를 읽습니다. DIY는 부품비·전력을 아끼거나 특수 화학/팩 구조일 때 고려합니다. 어느 쪽이든 펌웨어는 I2C 드라이버, 고장 처리, 알람 정책을 맡습니다 → E1.
The pack is replaced or the robot reboots. What happens?RAM 상태가 사라지므로 부팅 시 OCV로 초기 SoC를 정하고(모터 정지 상태), 마지막 값과 학습한 용량은 플래시/EEPROM에 주기적으로(마모 고려) 저장합니다. 팩 교체는 ID 칩이나 전압 점프로 감지합니다.

7. 자주 하는 실수

  • 매 step I*dt/3600000으로 mAh에 나눠서 더함 → 작은 전류가 0으로 잘려 사라짐 → 테스트 2 실패(1000‰에 머묾)
  • int32 × uint32 곱셈을 캐스트 없이 함 → 충전 전류가 unsigned로 바뀌어 거대한 방전 → 테스트 3·4 실패
  • 표시값만 clamp하고 저장값은 그대로 → 테스트 3의 "충전 후 방전 990" 실패
  • now < last를 검사하거나 signed로 뺌 → 타이머 wrap에서 gap으로 오판 → 테스트 5 실패
  • gap/fault로 return하기 전에 last_ms를 갱신하지 않음 → 이후 샘플이 계속 gap → 테스트 6·7 실패
  • 알람을 p <= 150의 level로만 계산 → 160~190‰에서 깜빡임(히스테리시스 없음) → 테스트 8 실패
  • 보간에서 (y1-y0)/(x1-x0)를 먼저 나눔 → 250/100 = 2로 잘려서 3650 mV가 150 + 50×2 = 250이 됨(정답 275)
  • OCV 표 끝점 처리 누락 → 표 밖 인덱스 접근(배열 범위 초과)
