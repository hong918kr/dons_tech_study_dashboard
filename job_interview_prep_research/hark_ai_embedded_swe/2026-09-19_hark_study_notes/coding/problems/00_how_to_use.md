# 00. 코딩 연습 사용법 — 먼저 읽기

> **대상**: Hark 1차 tech session · **문제 5개** · [마스터 플랜 §4](../plan/P01_tech_session_master_plan.html)에서 고른 우선순위
> **원칙**: 해설을 먼저 읽지 않는다. 손으로 먼저 짜고, 막힌 뒤에 읽는다.

---

## 1. 폴더 구조

```
coding/
  problems/   문제만 있다. 답도 힌트 코드도 없다
  starters/   컴파일되는 뼈대 + 테스트. 구현부가 TODO로 비어 있다
  solutions/  모범답안 + 테스트. 전부 경고 0개로 통과함
  notes/      그림 중심 상세 해설. 원리부터 한 줄씩
  Makefile
```

## 2. 명령

터미널에서 `coding/` 안으로 들어간 뒤 쓴다.

| 명령 | 하는 일 |
|---|---|
| `make list` | 문제 목록 |
| `make run N=01` | 내가 채운 `starters/01_*.c` 빌드·실행 |
| `make sol N=01` | 모범답안 실행 (전부 통과하는 걸 확인) |
| `make all` | 모범답안 5개 전부 실행 |
| `make clean` | 빌드 산출물 삭제 |

구현 전에 `make run`을 하면 첫 assert에서 멈춘다. **정상이다.** 안내 문구가 같이 나온다.

## 3. 한 문제를 푸는 순서

1. `problems/NN_*.md`를 읽는다. 요구사항과 경계 조건을 종이에 적는다.
2. **먼저 손으로** 자료구조를 그린다. 인덱스가 어디를 가리키는지, 가득 찬 상태와 빈 상태를 어떻게 구분하는지.
3. `starters/NN_*.c`의 TODO를 채운다. 테스트는 건드리지 않는다.
4. `make run N=NN` — 통과할 때까지.
5. 통과하면 `make sol N=NN`으로 모범답안과 비교한다. 다르면 왜 다른지 본다.
6. `notes/NN_*.md`를 읽는다. 내가 놓친 관점(ISR 경합, 메모리 순서, 정렬)이 여기 있다.
7. 문제 파일 맨 아래 "스스로 점검할 질문"에 **소리 내어** 답한다. 이게 면접에서 나오는 부분이다.

## 4.1 레퍼런스 뱅크 (06~21) — 기초부터 쌓기

01~05가 면접 직전 드릴이라면, 06~21은 **기초부터 다시 쌓고 나중에 다시 펼쳐볼 교재**다. 각 레벨의 해설은 문제별이 아니라 **레벨 노트 한 편**에 모여 있다.

| 레벨 | 노트 | 문제 | 언제 |
|---|---|---|---|
| **L0 비트·정수** | [L0 노트](../drills/L0_bit_basics.html) | 06 비트 조작 · 07 popcount·반전 · 08 엔디언·정렬 · 09 포화 연산 | 워밍업 문제가 불안하면 |
| **L1 메모리·포인터** | [L1 노트](../drills/L1_memory_pointers.html) | 10 memcpy/memmove · 11 구조체 레이아웃 · 12 volatile·const · 13 함수 테이블 | 포인터·정렬 질문 대비 |
| **L2 임베디드 관용구** | [L2 노트](../drills/L2_embedded_idioms.html) | 14 디바운스 FSM · 15 고정소수점 필터 · 16 CRC-8 · 17 소프트 타이머 | 실무형 문제 대비 |
| **L3 임베디드 C++** | [L3 노트](../drills/L3_embedded_cpp.html) | 18 RAII 가드 · 19 static_vector · 20 레지스터 래퍼 · 21 object pool | JD의 "C and/or C++" 대비 |

L3는 C++이라 `make`가 자동으로 `c++ -std=c++17 -fno-exceptions -fno-rtti`로 빌드한다.

## 5. 면접에서의 규칙

- 짜기 전에 **설계를 한 문장으로 말한다.** "인덱스를 free-running으로 두고 마스킹으로 접근하겠습니다."
- **경계 조건을 먼저 말한다.** 가득 참, 빔, wrap, 동시 접근. 이것만으로 점수가 된다.
- 막히면 침묵하지 말고 **불변식을 소리 내어 다시 말한다.**
- 다 짜고 나면 **직접 테스트 케이스를 말한다.** "제가 확인할 건 세 가지입니다."
