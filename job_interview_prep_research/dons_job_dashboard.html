📘 job-research 스킬 사용법

JD 링크만 붙여넣으면 돼요. 스킬 이름을 따로 부르지 않아도 JD 링크를 보면 알아서 실행돼요.

1. 새 포지션 조사 (처음 한 번)

cd ~/workspace/dons_tech_study_dashboard/job_interview_prep_research
mkdir <company>_<title>          # 예: neros_tech_senior_firmware_engineer
cd <company>_<title>
claude

세션이 열리면 이렇게 입력하세요.

https://job-boards.greenhouse.io/<company>/jobs/<id>  조사해줘

더 확실하게 하려면 스킬을 직접 불러요: /job-research <JD 링크>

  • 진행 순서: 레쥬메 읽기 → JD 원문 수집 → 회사 조사 → 적합도 분석 → 예상 인터뷰 → md 작성 → HTML 렌더링
  • 결과물: <dir>_context.md (원본), <dir>_context.html (보기용), 현황판 한 줄 추가
  • LinkedIn 링크는 로그인 때문에 막힐 수 있어요. 회사 채용 페이지 링크나 JD 텍스트를 붙여넣어도 돼요.
  • 디렉토리를 안 만들었으면 상위 폴더에서 링크를 줘도 스킬이 알아서 만들어요.

2. 이후 업데이트 (같은 디렉토리에서 다시 claude)

있었던 일을 그냥 말하면, md가 갱신되고 HTML도 다시 만들어져요.

이렇게 말하면이렇게 반영돼요
오늘 지원했어상태 📨, 진행 로그 추가
리크루터 콜 했어. 레벨 Senior, 밴드 $180-220k, 다음은 C 폰스크린 45분[추정] → [확인됨], 프로세스 섹션 갱신
폰스크린에서 링버퍼 구현이랑 I2C 디버깅 질문 받았어인터뷰 노트 기록, 예상 질문에 "실제 출제됨 ✔"
떨어졌어 / 오퍼 받았어상태 변경, 회고와 교훈 정리
레쥬메 새로 올렸어새 PDF로 적합도 재평가

3. HTML로 보기

  • 현황판: open ~/workspace/dons_tech_study_dashboard/job_interview_prep_research/dons_job_dashboard.html
  • 포지션별: 현황판 표의 link 클릭, 또는 open <dir>/<dir>_context.html
  • HTML만 다시 만들기: Claude에게 html 다시 만들어줘라고 하거나 직접 실행해요.
python3 ~/.claude/skills/job-research/scripts/render_html.py
  • HTML은 md에서 자동 생성돼요. 내용은 md에서만 수정하고, HTML은 직접 고치지 마세요.
  • 체크박스는 클릭하면 이 브라우저에만 저장돼요. md에 반영하려면 Claude에게 "체크리스트 X 끝냈어"라고 말하세요.

4. 유용한 추가 요청

  • 컨텍스트 파일 보고 폰스크린 준비 체크리스트만 뽑아줘
  • 4.3 예상 질문으로 모의 인터뷰 해줘
  • 이 JD에 맞게 레쥬메 bullet 다시 써줘
  • 현황판 보여줘

💡 새 세션은 이전 대화를 기억하지 못해요. 대신 스킬이 먼저 _context.md를 읽기 때문에, 항상 해당 회사 디렉토리에서 claude를 실행하면 맥락이 이어져요.
