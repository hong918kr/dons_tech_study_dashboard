6. 노트북을 준다는 것의 의미#

  • 자동완성 · linter · 내 단축키 없음 → 연습도 기본 편집기 + 터미널 python3 file.py로 한다
  • 표준 라이브러리만 쓴다 (collections, struct, re, dataclasses). pytest가 없을 수 있으니 assert + if __name__ == "__main__": 테스트가 기본
  • Python 3.8~3.9일 수도 있음 → match 문, int | None 타입 문법은 피한다 (이 키트 코드는 3.9에서 확인)
  • 발표 자료는 PDF 하나로 만든다. 폰트 · 애니메이션 · 동영상에 기대지 않는다

7. 이번 키트가 이전 자료와 다른 점#

  • 이전 onsitePrep(P00/P01, N01~N11)은 "C/C++ + ring buffer + generic design" 예상 기준이었다. 이번 콜로 형식이 확정되어 이 키트로 대체한다
  • 코딩 언어가 C → Python으로 바뀌었다. C 지식은 "Python에서 이걸 C로 하면?" 후속 질문용으로만 남긴다
  • 공부하다 생긴 질문은 Q&A 로그에 하위 페이지로 붙인다
