4. "Design a test system for X" — 어느 직군이든 같은 6단계#

단계질문예 (Flight)
1. 무엇을 증명하나이 펌웨어가 지켜야 할 약속 3개루프 타이밍, failsafe, 모드 전환
2. 레벨 나누기unit은 개발자, 나머지는 어느 리그에서?SITL = 로직 대량, HITL = 타이밍·드라이버
3. 리그 블록도자극 → DUT → 관측, 시계, 전원센서 주입 MCU → FC → DShot 캡처
4. 숫자리그 수, 실행 시간, 판정 기준PR 10분 스모크, nightly 2시간, p99 지터 < 50µs [추정]
5. 실패 모드리그가 틀리면? flaky면?self-test, quarantine, flip-rate
6. 결과 흐름누가 어떻게 보나MR 코멘트, 대시보드, 릴리즈 게이트

시작 대사: "Let me start from what this firmware has to guarantee, then decide which of those each test level can actually prove, and only then draw the rig."
