### P1-01 · 슬라이스와 뒤집기

리스트 xs의 마지막 n개를 거꾸로 돌려주는 last_n_reversed(xs, n).

정답:

```python
def last_n_reversed(xs, n):
    return xs[-n:][::-1]
```

### P1-02 · dict로 개수 세기

공백으로 나눈 단어별 개수를 dict로 돌려주는 count_words(text). dict.get 사용.

정답:

```python
def count_words(text):
    counts = {}
    for w in text.split():
        counts[w] = counts.get(w, 0) + 1
    return counts
```

### P1-03 · enumerate

target이 처음 나오는 인덱스, 없으면 -1을 돌려주는 find_index(xs, target). range(len()) 쓰지 말 것.

정답:

```python
def find_index(xs, target):
    for i, x in enumerate(xs):
        if x == target:
            return i
    return -1
```

### P1-04 · zip과 dict

두 리스트를 key → value dict로 묶는 pair_up(keys, values).

정답:

```python
def pair_up(keys, values):
    return dict(zip(keys, values))
```

### P1-05 · list comprehension

짝수만 골라 제곱한 리스트를 돌려주는 even_squares(xs). 한 줄.

정답:

```python
def even_squares(xs):
    return [x * x for x in xs if x % 2 == 0]
```

### P1-06 · f-string hex 포맷

fmt_reg(0x40, 0x1F) → "0x0040: 0x1F" (주소 4자리, 값 2자리, 대문자).

정답:

```python
def fmt_reg(addr, val):
    return f"0x{addr:04X}: 0x{val:02X}"
```

### P1-07 · 문자열 split · strip

"key = value" 한 줄을 (key, value) 튜플로. 값 안의 = 는 보존. parse_kv(line).

정답:

```python
def parse_kv(line):
    key, _, value = line.partition("=")
    return key.strip(), value.strip()
```

### P1-08 · sorted + key

길이 오름차순, 같으면 알파벳순으로 정렬하는 sort_words(words).

정답:

```python
def sort_words(words):
    return sorted(words, key=lambda w: (len(w), w))
```

### P1-09 · while + divmod

양의 정수 n의 자릿수 합 digit_sum(n). divmod 사용.

정답:

```python
def digit_sum(n):
    total = 0
    while n:
        n, d = divmod(n, 10)
        total += d
    return total
```

### P1-10 · set 연산

두 리스트에 공통으로 있는 값을 중복 없이 정렬해서 common(a, b).

정답:

```python
def common(a, b):
    return sorted(set(a) & set(b))
```

### C1-01 · stdint 배열 합

uint8_t 버퍼의 합을 uint32_t로 돌려주는 sum_u8(buf, n).

정답:

```c
uint32_t sum_u8(const uint8_t *buf, size_t n)
{
    uint32_t sum = 0;
    for (size_t i = 0; i < n; i++)
        sum += buf[i];
    return sum;
}
```

### C1-02 · 포인터로 swap

두 int를 바꾸는 swap_int(a, b).

정답:

```c
void swap_int(int *a, int *b)
{
    int t = *a;
    *a = *b;
    *b = t;
}
```

### C1-03 · typedef struct

int16_t x, y를 가진 point_t와, 두 점 거리의 제곱을 int32_t로 돌려주는 dist2(a, b).

정답:

```c
typedef struct {
    int16_t x, y;
} point_t;

int32_t dist2(point_t a, point_t b)
{
    int32_t dx = (int32_t)a.x - b.x;
    int32_t dy = (int32_t)a.y - b.y;
    return dx * dx + dy * dy;
}
```

### C1-04 · 비트 set · clear · test

BIT(n) 매크로와 set_bit / clear_bit / test_bit (uint32_t *reg 대상).

정답:

```c
#define BIT(n) (1u << (n))

void set_bit(uint32_t *reg, unsigned n)   { *reg |= BIT(n); }
void clear_bit(uint32_t *reg, unsigned n) { *reg &= ~BIT(n); }
bool test_bit(uint32_t reg, unsigned n)   { return (reg & BIT(n)) != 0; }
```

### C1-05 · strlen 직접

정답:

```c
size_t my_strlen(const char *s)
{
    const char *p = s;
    while (*p)
        p++;
    return (size_t)(p - s);
}
```

### C1-06 · 배열 제자리 뒤집기

uint8_t 배열을 제자리에서 뒤집는 reverse_u8(a, n). n=0도 안전하게.

정답:

```c
void reverse_u8(uint8_t *a, size_t n)
{
    if (n < 2)
        return;
    for (size_t i = 0, j = n - 1; i < j; i++, j--) {
        uint8_t t = a[i];
        a[i] = a[j];
        a[j] = t;
    }
}
```

### C1-07 · enum + switch

ST_IDLE / ST_ARMED / ST_FLYING enum과 이름 문자열을 돌려주는 state_name(s). 모르는 값은 "?".

정답:

```c
typedef enum { ST_IDLE, ST_ARMED, ST_FLYING } state_t;

const char *state_name(state_t s)
{
    switch (s) {
    case ST_IDLE:   return "IDLE";
    case ST_ARMED:  return "ARMED";
    case ST_FLYING: return "FLYING";
    default:        return "?";
    }
}
```

### C1-08 · memcpy · memcmp · memset

src를 dst에 복사하고 같은지 확인해서 true, 그다음 src를 0으로 지우는 copy_wipe(dst, src, n).

정답:

```c
bool copy_wipe(uint8_t *dst, uint8_t *src, size_t n)
{
    memcpy(dst, src, n);
    bool same = memcmp(dst, src, n) == 0;
    memset(src, 0, n);
    return same;
}
```

### C1-09 · set bit 개수

v &= v - 1 트릭으로 1인 비트 수를 세는 popcount32(v).

정답:

```c
int popcount32(uint32_t v)
{
    int n = 0;
    while (v) {
        v &= v - 1;
        n++;
    }
    return n;
}
```

### C1-10 · 포인터 순회로 최댓값

int32_t 배열(n>0)의 최댓값 max_i32(a, n). 포인터로 끝까지 순회.

정답:

```c
int32_t max_i32(const int32_t *a, size_t n)
{
    const int32_t *end = a + n;
    int32_t m = *a++;
    for (; a < end; a++)
        if (*a > m)
            m = *a;
    return m;
}
```
