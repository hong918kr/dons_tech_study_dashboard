## Python 8

### 01 · Two Sum — dict 로 '값 → 인덱스' 기억하기 (LeetCode 1)

> nums 와 target 이 주어질 때 합이 target 인 두 인덱스 [i, j] (없으면 []). O(n). 테스트 함수 하나 + main 까지 직접.

- dict 기본 — `d[k] = v` 넣기 · `k in d` 있나(O(1)) · `d[k]` 꺼내기(없으면 KeyError) · `d.get(k, 기본값)` 안전하게 꺼내기
- 순서가 중요: '확인 → 저장'. 저장부터 하면 같은 원소를 두 번 쓴다 ([3], 6 → [0, 0] 버그)
- 복잡도: 시간 O(n), 메모리 O(n) (dict)

```python
def two_sum(nums, target):
    seen = {}                          # 값 → 인덱스
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:               # 짝이 이미 지나갔나?
            return [seen[need], i]
        seen[x] = i                    # 확인한 다음에 저장
    return []


def test_two_sum():
    assert two_sum([2, 7, 11, 15], 9) == [0, 1]
    assert two_sum([3, 3], 6) == [0, 1]       # 같은 값 두 개
    assert two_sum([3], 6) == []              # 자기 자신과 짝 금지


if __name__ == "__main__":
    test_two_sum()
    print("PASS")
```

### 02 · Two Sum 변형 — dict 로 개수 세기 (합이 target 인 쌍의 수)

> nums 에서 i < j 이고 nums[i] + nums[j] == target 인 쌍의 개수를 O(n) 으로. dict.get 으로 빈도를 센다.

- 01 은 dict 에 '인덱스'를, 이 문제는 '지금까지 본 횟수'를 넣는다 — dict 의 두 번째 단골 용도
- `count[x] = count.get(x, 0) + 1` 이 세기의 기본형 (collections.Counter 도 같은 일)
- 전부 짝을 비교하면 O(n²), dict 로 O(n)

```python
def count_pairs(nums, target):
    count = {}                         # 값 → 지금까지 나온 횟수
    pairs = 0
    for x in nums:
        pairs += count.get(target - x, 0)    # 앞에서 나온 짝의 수만큼
        count[x] = count.get(x, 0) + 1
    return pairs


def test_count_pairs():
    assert count_pairs([1, 5, 7, -1, 5], 6) == 3     # (1,5) (1,5) (7,-1)
    assert count_pairs([2, 2, 2], 4) == 3            # 세 개 중 두 개 고르기
    assert count_pairs([], 4) == 0


if __name__ == "__main__":
    test_count_pairs()
    print("PASS")
```

### 03 · Two pointer — 정렬된 배열의 두 수의 합 (LeetCode 167)

> 오름차순 nums 에서 합이 target 인 두 인덱스 [i, j] (없으면 []). 추가 메모리 O(1).

- 같은 문제의 세 가지 풀이 — dict: O(n) 시간 · O(n) 메모리 / 투 포인터: O(n) 시간 · **O(1) 메모리** / 원소마다 이진 탐색: O(n log n) · O(1)
- 정렬돼 있다는 조건이 있으면 투 포인터가 가장 좋다 (메모리 0, 캐시 친화적)
- 왜 맞나: 합이 작으면 왼쪽 값을 키울 수밖에 없고, 크면 오른쪽 값을 줄일 수밖에 없다 → 버리는 쌍 중에 답이 없다

```python
def pair_with_sum(nums, target):
    i, j = 0, len(nums) - 1
    while i < j:
        s = nums[i] + nums[j]
        if s == target:
            return [i, j]
        if s < target:
            i += 1
        else:
            j -= 1
    return []


def test_pair_with_sum():
    assert pair_with_sum([1, 3, 4, 6, 9], 10) == [0, 4]
    assert pair_with_sum([1, 2], 5) == []


if __name__ == "__main__":
    test_pair_with_sum()
    print("PASS")
```

### 04 · Two pointer (같은 방향) — 정렬된 배열의 중복 제거, 제자리 (LeetCode 26)

> 정렬된 리스트 nums 를 제자리에서 중복 없이 앞쪽에 모으고, 고유 원소 개수 k 를 돌려준다. 추가 메모리 O(1).

- 03 은 양 끝에서 좁혀 오는 투 포인터, 이건 slow(쓸 자리) · fast(읽는 자리)가 같은 방향으로 가는 투 포인터
- `list(set(nums))` 는 쉽지만 O(n) 메모리 + 순서 보장 안 됨 → 면접에선 제자리 O(1) 이 요구된다
- 같은 패턴: 0 을 뒤로 밀기, 특정 값 제거, C 에서 버퍼 압축

```python
def dedup(nums):
    if not nums:
        return 0
    slow = 0                           # 마지막으로 남긴 고유 값의 자리
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1


def test_dedup():
    a = [1, 1, 2, 3, 3, 3]
    assert dedup(a) == 3 and a[:3] == [1, 2, 3]
    assert dedup([]) == 0


if __name__ == "__main__":
    test_dedup()
    print("PASS")
```

### 05 · 이진 탐색 — left · right · mid (LeetCode 704)

> 오름차순 nums 에서 target 의 인덱스, 없으면 -1. left/right/mid 로 O(log n).

- 불변식: 답이 있다면 항상 nums[left..right] 안에 있다 → `while left <= right`
- mid 는 `(left + right) // 2` (Python 은 오버플로 없음, C 에선 `left + (right - left) / 2`)
- 흔한 버그: `left = mid` / `right = mid` 로 두면 무한 루프 → 반드시 mid ± 1
- 실무에선 `bisect.bisect_left(nums, target)` — 없을 때 '들어갈 자리'까지 준다

```python
def search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            left = mid + 1             # 답은 오른쪽 절반에
        else:
            right = mid - 1            # 답은 왼쪽 절반에
    return -1


def test_search():
    assert search([-1, 0, 3, 5, 9, 12], 9) == 4
    assert search([-1, 0, 3, 5, 9, 12], 2) == -1
    assert search([], 1) == -1


if __name__ == "__main__":
    test_search()
    print("PASS")
```

### 06 · BST — 삽입 · 검색 · 중위 순회

> Node(val) 로 이진 탐색 트리. insert(root, val) → root, contains(root, val) → bool, inorder(root) → 정렬된 리스트.

- 05 이진 탐색과 같은 생각 — 작으면 왼쪽, 크면 오른쪽. 균형이면 O(log n), 한쪽으로 치우치면 O(n)
- 중위 순회(왼쪽 → 나 → 오른쪽) 결과는 항상 정렬돼 있다 → 테스트에서 이걸로 트리 전체를 검증

```python
class Node:
    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None


def insert(root, val):
    if root is None:
        return Node(val)
    if val < root.val:
        root.left = insert(root.left, val)
    elif val > root.val:
        root.right = insert(root.right, val)
    return root


def contains(root, val):
    while root:
        if val == root.val:
            return True
        root = root.left if val < root.val else root.right
    return False


def inorder(root):
    return inorder(root.left) + [root.val] + inorder(root.right) if root else []


def test_bst():
    root = None
    for v in [5, 3, 8, 1, 4, 3]:
        root = insert(root, v)
    assert inorder(root) == [1, 3, 4, 5, 8]          # 정렬 + 중복 무시
    assert contains(root, 4) and not contains(root, 7)


if __name__ == "__main__":
    test_bst()
    print("PASS")
```

### 07 · Ring buffer — head · tail · count

> RingBuffer(capacity): push(x) → bool (가득 차면 False), pop() → 가장 오래된 값 (비었으면 IndexError), peek(), len(), is_full().

- head = 다음에 쓸 칸, tail = 다음에 읽을 칸, count = 들어 있는 개수. head == tail 이 '빈 것'인지 '가득 찬 것'인지 count 가 구분해 준다
- 다른 방법 — count 없이 '한 칸 비우기' (용량 하나 손해), C 에서는 free-running index (C 문제 06)
- 테스트 포인트 — 정확히 가득 찼을 때, 한 바퀴 돈 뒤(wrap)의 순서, 빈 상태에서 pop

```python
class RingBuffer:
    def __init__(self, capacity):
        self.buf = [None] * capacity
        self.cap = capacity
        self.head = 0                  # 다음에 쓸 칸
        self.tail = 0                  # 다음에 읽을 칸
        self.count = 0

    def __len__(self):
        return self.count

    def is_full(self):
        return self.count == self.cap

    def push(self, x):
        if self.is_full():
            return False
        self.buf[self.head] = x
        self.head = (self.head + 1) % self.cap
        self.count += 1
        return True

    def peek(self):
        if self.count == 0:
            raise IndexError("empty")
        return self.buf[self.tail]

    def pop(self):
        x = self.peek()
        self.buf[self.tail] = None
        self.tail = (self.tail + 1) % self.cap
        self.count -= 1
        return x


def test_ring_buffer():
    r = RingBuffer(3)
    assert r.push(1) and r.push(2) and r.push(3) and not r.push(4) and r.is_full()
    assert r.pop() == 1 and r.push(4)                 # wrap: 4 는 index 0 으로
    assert [r.pop(), r.pop(), r.pop()] == [2, 3, 4] and len(r) == 0


def test_pop_empty_raises():
    try:
        RingBuffer(1).pop()
    except IndexError:
        return
    raise AssertionError("pop on empty must raise")


if __name__ == "__main__":
    test_ring_buffer()
    test_pop_empty_raises()
    print("PASS")
```

### 08 · 괄호 검사 — 스택 (LeetCode 20)

> '()[]{}' 로만 된 문자열이 올바르게 닫혔는지 True/False.

- 여는 괄호는 push, 닫는 괄호는 pop 해서 짝 확인. 끝나고 스택이 비어 있어야 한다
- dict 로 '닫는 → 여는' 짝을 표로 두면 if 문이 없어진다

```python
def is_valid(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
        else:
            stack.append(ch)
    return not stack


def test_is_valid():
    assert is_valid("{[()]}") and is_valid("")
    assert not is_valid("([)]") and not is_valid("(") and not is_valid("]")


if __name__ == "__main__":
    test_is_valid()
    print("PASS")
```

### 01 · 문자열 제자리 뒤집기

> void reverse_str(char *s) — 추가 메모리 없이 뒤집는다. NULL · 빈 문자열도 안전하게. 테스트 함수 + main 까지 직접.

- 양 끝 인덱스 i, j 를 swap 하며 가운데로. n < 2 면 할 일 없음 (n - 1 이 size_t 언더플로 나는 것도 막는다)
- 테스트 포인트 — 짝수 길이, 홀수 길이, 빈 문자열, NULL

```c
#include <assert.h>
#include <stdio.h>
#include <string.h>

void reverse_str(char *s)
{
    if (s == NULL)
        return;
    size_t n = strlen(s);
    if (n < 2)
        return;
    for (size_t i = 0, j = n - 1; i < j; i++, j--) {
        char t = s[i];
        s[i] = s[j];
        s[j] = t;
    }
}

static void test_reverse_str(void)
{
    char a[] = "neros", b[] = "";
    reverse_str(a);
    reverse_str(b);
    reverse_str(NULL);
    assert(strcmp(a, "soren") == 0 && strcmp(b, "") == 0);
}

int main(void)
{
    test_reverse_str();
    puts("PASS");
    return 0;
}
```

### 02 · 연결 리스트 — push_front · length · reverse

> node_t {int val; next}. push_front(head, node) → 새 head, list_len(head), reverse(head) → 새 head. malloc 없이 노드를 받아서.

- reverse = prev · curr · next 세 포인터: next 기억 → 화살표 뒤집기 → 한 칸 전진
- 테스트 포인트 — 빈 리스트(NULL), 노드 1개, 뒤집은 뒤 마지막 노드의 next 가 NULL 인지

```c
#include <assert.h>
#include <stddef.h>
#include <stdio.h>

typedef struct node {
    int val;
    struct node *next;
} node_t;

node_t *push_front(node_t *head, node_t *n)
{
    n->next = head;
    return n;
}

size_t list_len(const node_t *head)
{
    size_t n = 0;
    for (; head; head = head->next)
        n++;
    return n;
}

node_t *reverse(node_t *head)
{
    node_t *prev = NULL;
    while (head) {
        node_t *next = head->next;
        head->next = prev;
        prev = head;
        head = next;
    }
    return prev;
}

static void test_list(void)
{
    node_t a = {1, NULL}, b = {2, NULL};
    node_t *h = push_front(push_front(NULL, &a), &b);     /* 2 → 1 */
    assert(list_len(h) == 2 && h->val == 2);
    h = reverse(h);                                        /* 1 → 2 */
    assert(h == &a && a.next == &b && b.next == NULL);
    assert(reverse(NULL) == NULL);
}

int main(void)
{
    test_list();
    puts("PASS");
    return 0;
}
```

### 03 · strcpy 직접 구현 + 크기 제한 버전

> my_strcpy(dst, src) → dst. safe_copy(dst, cap, src) → 항상 '\0' 로 끝내고, 잘렸으면 false.

- strcpy 는 dst 크기를 모른다 → 버퍼 오버플로의 단골. 실무는 크기를 받는 버전
- 테스트 포인트 — 딱 맞는 길이(cap - 1 글자), 한 글자 넘침, cap == 0

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <string.h>

char *my_strcpy(char *dst, const char *src)
{
    char *d = dst;
    while ((*d++ = *src++) != '\0')
        ;
    return dst;
}

bool safe_copy(char *dst, size_t cap, const char *src)
{
    if (cap == 0)
        return false;
    size_t i = 0;
    for (; i + 1 < cap && src[i] != '\0'; i++)
        dst[i] = src[i];
    dst[i] = '\0';
    return src[i] == '\0';                       /* 원본을 끝까지 복사했나 */
}

static void test_copy(void)
{
    char buf[4];
    assert(strcmp(my_strcpy(buf, "arm"), "arm") == 0);
    assert(safe_copy(buf, sizeof buf, "abc") && strcmp(buf, "abc") == 0);    /* 딱 맞음 */
    assert(!safe_copy(buf, sizeof buf, "abcd") && strcmp(buf, "abc") == 0);  /* 잘림 */
}

int main(void)
{
    test_copy();
    puts("PASS");
    return 0;
}
```

### 04 · atoi 직접 구현

> int my_atoi(const char *s) — 앞 공백 무시, + / - 부호, 숫자가 아닌 글자에서 멈춤, int 범위를 넘으면 INT_MAX / INT_MIN.

- 순서: 공백 건너뛰기 → 부호 → 숫자 누적 (v * 10 + (c - '0'))
- 오버플로는 long long 으로 누적하며 매 자리 범위 검사 (int 로 누적하면 UB)

```c
#include <assert.h>
#include <limits.h>
#include <stdio.h>

int my_atoi(const char *s)
{
    while (*s == ' ' || *s == '\t')
        s++;
    int sign = 1;
    if (*s == '+' || *s == '-')
        sign = (*s++ == '-') ? -1 : 1;
    long long v = 0;
    while (*s >= '0' && *s <= '9') {
        v = v * 10 + (*s++ - '0');
        if (sign * v > INT_MAX)
            return INT_MAX;
        if (sign * v < INT_MIN)
            return INT_MIN;
    }
    return (int)(sign * v);
}

static void test_atoi(void)
{
    assert(my_atoi("  -17x") == -17 && my_atoi("abc") == 0);
    assert(my_atoi("99999999999") == INT_MAX && my_atoi("-2147483648") == INT_MIN);
}

int main(void)
{
    test_atoi();
    puts("PASS");
    return 0;
}
```

### 05 · Ring buffer — head · tail · count (아무 크기나 가능)

> rb_t {buf[RB_CAP], head, tail, count}. rb_push(rb, v) → bool (가득 차면 false), rb_pop(rb, &v) → bool (비었으면 false).

- count 가 full / empty 를 구분하므로 용량을 전부 쓴다. 인덱스는 `(i + 1) % RB_CAP` 로 감는다 → 크기가 2의 거듭제곱일 필요 없음
- 단점: push 와 pop 이 둘 다 count 를 고친다 → ISR 생산자 + main 소비자면 count 가 공유 변수가 되어 보호가 필요 (06 은 이 문제가 없다)
- 테스트 포인트 — 정확히 가득, 한 칸 넘침, 한 바퀴 돈 뒤의 순서

```c
#include <assert.h>
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>

#define RB_CAP 5u                                /* 아무 크기 */

typedef struct {
    uint8_t buf[RB_CAP];
    uint8_t head;                                /* 다음에 쓸 칸 */
    uint8_t tail;                                /* 다음에 읽을 칸 */
    uint8_t count;
} rb_t;

bool rb_push(rb_t *rb, uint8_t v)
{
    if (rb->count == RB_CAP)
        return false;
    rb->buf[rb->head] = v;
    rb->head = (uint8_t)((rb->head + 1) % RB_CAP);
    rb->count++;
    return true;
}

bool rb_pop(rb_t *rb, uint8_t *v)
{
    if (rb->count == 0)
        return false;
    *v = rb->buf[rb->tail];
    rb->tail = (uint8_t)((rb->tail + 1) % RB_CAP);
    rb->count--;
    return true;
}

static void test_rb(void)
{
    rb_t rb = {0};
    uint8_t v;
    for (uint8_t i = 0; i < RB_CAP; i++)
        assert(rb_push(&rb, i));
    assert(!rb_push(&rb, 99));                   /* 가득 */
    assert(rb_pop(&rb, &v) && v == 0);
    assert(rb_push(&rb, 5));                     /* wrap: index 0 에 들어감 */
    for (uint8_t i = 1; i <= 5; i++)
        assert(rb_pop(&rb, &v) && v == i);
    assert(!rb_pop(&rb, &v));                    /* 빔 */
}

int main(void)
{
    test_rb();
    puts("PASS");
    return 0;
}
```

### 06 · Ring buffer — free-running head/tail (2의 거듭제곱, count 없음)

> rb_t {buf[8], head, tail}. head/tail 은 마스크 없이 계속 증가, 접근할 때만 & (SIZE - 1). 개수 = head - tail.

- 05 와 비교: count 가 없어서 push 는 head 만, pop 은 tail 만 쓴다 → ISR 생산자 / main 소비자(SPSC)에서 lock 없이 쓸 수 있는 구조
- unsigned 뺄셈이라 head 가 2^32 를 넘어 0 으로 돌아도 head - tail 이 맞다 → 테스트는 UINT32_MAX 근처에서 시작
- % 대신 & 마스크 → 나눗셈 없음. 대신 크기가 반드시 2의 거듭제곱

```c
#include <assert.h>
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>

#define RB_SIZE 8u                               /* 2 의 거듭제곱 */
#define RB_MASK (RB_SIZE - 1u)

typedef struct {
    uint8_t  buf[RB_SIZE];
    uint32_t head, tail;
} rb_t;

bool rb_push(rb_t *rb, uint8_t v)
{
    if (rb->head - rb->tail == RB_SIZE)
        return false;
    rb->buf[rb->head & RB_MASK] = v;
    rb->head++;
    return true;
}

bool rb_pop(rb_t *rb, uint8_t *v)
{
    if (rb->head == rb->tail)
        return false;
    *v = rb->buf[rb->tail & RB_MASK];
    rb->tail++;
    return true;
}

static void test_rb_index_wrap(void)
{
    rb_t rb = {{0}, UINT32_MAX - 3, UINT32_MAX - 3};      /* 32비트 wrap 을 지나가게 */
    uint8_t v;
    for (uint8_t i = 0; i < RB_SIZE; i++)
        assert(rb_push(&rb, i));
    assert(!rb_push(&rb, 99) && rb.head - rb.tail == RB_SIZE);
    for (uint8_t i = 0; i < RB_SIZE; i++)
        assert(rb_pop(&rb, &v) && v == i);
    assert(!rb_pop(&rb, &v));
}

int main(void)
{
    test_rb_index_wrap();
    puts("PASS");
    return 0;
}
```
