입력 '1' (0x31), crc 시작값 0x00
  입력 0x31 를 XOR → crc = 0x31 (00110001)
    1단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0x62 (01100010)
    2단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0xC4 (11000100)
    3단계: 맨 위 비트 1 → 왼쪽 1칸 + ^0x07 → 0x8F (10001111)
    4단계: 맨 위 비트 1 → 왼쪽 1칸 + ^0x07 → 0x19 (00011001)
    5단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0x32 (00110010)
    6단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0x64 (01100100)
    7단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0xC8 (11001000)
    8단계: 맨 위 비트 1 → 왼쪽 1칸 + ^0x07 → 0x97 (10010111)
결과 0x97  ← 긴 나눗셈의 나머지와 같다
