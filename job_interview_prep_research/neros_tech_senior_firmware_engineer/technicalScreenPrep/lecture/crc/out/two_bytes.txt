[비트 방식] 입력 "12" = 0x31, 0x32
  입력 0x31 를 XOR → crc = 0x31 (00110001)
    1단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0x62 (01100010)
    2단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0xC4 (11000100)
    3단계: 맨 위 비트 1 → 왼쪽 1칸 + ^0x07 → 0x8F (10001111)
    4단계: 맨 위 비트 1 → 왼쪽 1칸 + ^0x07 → 0x19 (00011001)
    5단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0x32 (00110010)
    6단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0x64 (01100100)
    7단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0xC8 (11001000)
    8단계: 맨 위 비트 1 → 왼쪽 1칸 + ^0x07 → 0x97 (10010111)
  입력 0x32 를 XOR → crc = 0xA5 (10100101)
    1단계: 맨 위 비트 1 → 왼쪽 1칸 + ^0x07 → 0x4D (01001101)
    2단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0x9A (10011010)
    3단계: 맨 위 비트 1 → 왼쪽 1칸 + ^0x07 → 0x33 (00110011)
    4단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0x66 (01100110)
    5단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0xCC (11001100)
    6단계: 맨 위 비트 1 → 왼쪽 1칸 + ^0x07 → 0x9F (10011111)
    7단계: 맨 위 비트 1 → 왼쪽 1칸 + ^0x07 → 0x39 (00111001)
    8단계: 맨 위 비트 0 → 왼쪽 1칸만      → 0x72 (01110010)
결과 0x72

[테이블 방식] 바이트마다 표를 한 번씩
  1바이트: crc = T[0x00 ^ 0x31] = T[0x31] = 0x97
  2바이트: crc = T[0x97 ^ 0x32] = T[0xA5] = 0x72
결과 0x72  ← 비트 방식과 같다
