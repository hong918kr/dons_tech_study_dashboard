시작: crc = 0x00 ^ 입력 0x31 = 0x31  (00110001)
단계 1: 맨 위 비트 0 → <<1 만      → 0x62  (01100010)
단계 2: 맨 위 비트 0 → <<1 만      → 0xC4  (11000100)
단계 3: 맨 위 비트 1 → <<1 후 ^0x07 → 0x8F  (10001111)
단계 4: 맨 위 비트 1 → <<1 후 ^0x07 → 0x19  (00011001)
단계 5: 맨 위 비트 0 → <<1 만      → 0x32  (00110010)
단계 6: 맨 위 비트 0 → <<1 만      → 0x64  (01100100)
단계 7: 맨 위 비트 0 → <<1 만      → 0xC8  (11001000)
단계 8: 맨 위 비트 1 → <<1 후 ^0x07 → 0x97  (10010111)
결과: CRC8(0x31) = 0x97  = 테이블[0x31] (0x30~0x3F 줄의 2번째 칸)
