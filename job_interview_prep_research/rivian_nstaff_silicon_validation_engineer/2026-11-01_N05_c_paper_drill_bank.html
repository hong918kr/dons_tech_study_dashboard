1. 20분 종이 루틴 (모든 문제 공통 — 외우기)

분할 일소리 내서 할 말 (English)
0–2Clarify: 단위(bit/nibble/byte), 입력 형태(정수/배열/포인터+길이), 폭(32/64), 에러 처리, in-place 여부, 하드웨어 동작(W1C? FIFO?)"Before I start — is the input an integer or a byte buffer? What width? Should I handle errors or can I assume valid input?"
2–5예시 1개를 손으로 풀고, 접근 한 문장 + 복잡도"Let me do the example by hand first… so the idea is X, which is O(n)."
5–15코드: 시그니처 → 엣지 체크 → 본체. uint32_t/1u/volatile/timeout"I'll use fixed-width types and unsigned shifts to avoid UB."

18–20테스트 4개 + 확장 1개 먼저 제안"I'd test zero, all-ones, the max boundary, and a round-trip. If we want it faster I can do the O(log n) version."
