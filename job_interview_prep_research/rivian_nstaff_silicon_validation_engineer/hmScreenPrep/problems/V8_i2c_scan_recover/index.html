V8 · I2C Bus Scan + Stuck-Bus Recovery (bit-banged)

IDV8
PriorityP1
Patternopen-drain bit-bang + protocol state + timeout
Time30 min

파일: stub.c(여기서 풀기) · solution.c(정답) · 실행: ./run.sh V8 / ./run.sh V8 sol

1. Problem

On a new board, the SoC's I2C pins are muxed as GPIOs and you drive the bus by hand to see what is on it. Both lines are open-drain with pull-ups: you can only pull a line low or release it; a released line is high unless some device holds it low.

A bus model in the file simulates slaves that ACK their address, a slave that stretches the clock (holds SCL low during the ACK clock), and a slave that was stuck mid-byte by a reset: it holds SDA low and lets go only after it sees enough SCL falling edges to finish its byte.

Implement:

  1. i2c_bus_recover() — if SDA is already high, return 0 (no clocks). Otherwise pulse SCL (low, then release) at most 9 times, checking SDA after each pulse. Once SDA is high, generate a STOP and return the number of pulses used. Still low after 9 pulses → -EIO (no STOP). SCL that cannot go high → -ETIMEDOUT.
  2. i2c_probe(addr) — -EINVAL for reserved addresses (0x00–0x07, 0x78–0x7F, > 0x7F) with nothing on the bus; -EBUSY if SCL or SDA is low before START. Otherwise START, send (addr << 1) | 0 MSB first, read the ACK bit, STOP. Return 0 on ACK, -ENXIO on NACK.
  3. Clock stretching: every time you release SCL, wait until it is really high. If it stays low for I2C_STRETCH_TIMEOUT_US (200 µs), release both lines and return -ETIMEDOUT.
  4. i2c_scan(found, max) — probe 0x08..0x77 in order, write up to max ACKing addresses into found, return the total count. Any probe error other than -ENXIO aborts the scan and is returned.

Wait I2C_HALF_US (5 µs, 100 kHz) between line changes.

void gpio_scl_set(int release);   /* 0 = drive low, 1 = release */
void gpio_sda_set(int release);
int  gpio_scl_get(void);          /* real line level, 1 = high */
int  gpio_sda_get(void);
void delay_us(uint32_t us);

int i2c_bus_recover(void);                    /* pulses used (0..9) or -EIO / -ETIMEDOUT */
int i2c_probe(uint8_t addr);                  /* 0, -ENXIO, -EINVAL, -EBUSY, -ETIMEDOUT */
int i2c_scan(uint8_t *found, size_t max);     /* total found, or first hard error */

Example

devices at 0x1D, 0x48, 0x50
i2c_scan(found, 8)  -> 3, found = {0x1D, 0x48, 0x50}
                       112 probes (0x08..0x77), 112 START + 112 STOP, 110 us each = 12320 us

slave stuck holding SDA, releases after 5 more SCL falling edges
i2c_probe(0x48)     -> -EBUSY      (SDA low: no START possible)
i2c_bus_recover()   -> 5           (5 pulses + STOP, 65 us)
i2c_probe(0x48)     -> 0

SDA shorted to GND:            i2c_bus_recover() -> -EIO after exactly 9 pulses
slave stretches SCL 40 us:     i2c_probe(0x50) -> 0 in 150 us
slave never releases SCL:      i2c_probe(0x50) -> -ETIMEDOUT after 290 us

Constraints

  • No malloc, no interrupts: plain polling with delay_us.
  • Change SDA only while SCL is low, except for START (SDA falls while SCL high) and STOP (SDA rises while SCL high).
  • Never put a reserved address on the bus.

Clarifying questions to ask (first 3 minutes)

  1. Is this a 7-bit-only bus? Should the scan use a write probe (addr+W) or a read probe (some devices only answer reads)?
  2. What bus speed and what clock-stretching timeout do you want?
  3. If the bus is stuck before the scan, should i2c_scan recover automatically or report and stop?
  4. What should recovery return — pulse count, or just success/fail?
  5. Are there devices that must not be probed (e.g. ones that treat an empty write as a command)?

/* =====================================================================
 * Open-drain I2C bus model + slaves + fault injection (do not edit)
 * ===================================================================== */
#define MAX_DEV 4
#define FOREVER 0xFFFFFFFFu
enum { D_IDLE, D_ADDR, D_ACK, D_IGNORE };

typedef struct {
    uint8_t  addr;
    uint32_t stretch_us;          /* hold SCL low this long on the ACK clock (FOREVER = never let go) */
    int      st;
    uint8_t  bits, shift;
    bool     sda_low;             /* driving SDA low */
    bool     holding;             /* holding SCL low */
    uint32_t hold_until;
} Dev;

static struct {
    bool m_scl, m_sda;            /* master side: true = released */
    bool scl, sda;                /* last effective line levels */
    uint32_t now;                 /* microseconds */
    Dev dev[MAX_DEV]; int ndev;
    bool stuck; uint32_t stuck_left; bool stuck_dead;   /* stuck slave holding SDA low */
    bool sniff; uint8_t sniff_bits, sniff_shift;
    uint32_t starts, stops, m_falls, addr_bytes;
    uint8_t addr_min, addr_max;
} B;

static bool line_scl(void)
{
    if (!B.m_scl) return false;
    for (int i = 0; i < B.ndev; i++) if (B.dev[i].holding) return false;
    return true;
}

static bool line_sda(void)
{
    if (!B.m_sda || B.stuck) return false;
    for (int i = 0; i < B.ndev; i++) if (B.dev[i].sda_low) return false;
    return true;
}

static void ev_start(void)
{
    B.starts++;
    B.sniff = true; B.sniff_bits = 0; B.sniff_shift = 0;
    for (int i = 0; i < B.ndev; i++) { Dev *d = &B.dev[i]; d->st = D_ADDR; d->bits = 0; d->shift = 0; d->sda_low = false; }
}

static void ev_stop(void)
{
    B.stops++;
    B.sniff = false;
    for (int i = 0; i < B.ndev; i++) { B.dev[i].st = D_IDLE; B.dev[i].sda_low = false; }
}

static void ev_rise(bool sda)
{
    if (B.sniff && ++B.sniff_bits <= 8) {
        B.sniff_shift = (uint8_t)((B.sniff_shift << 1) | sda);
        if (B.sniff_bits == 8) {
            uint8_t a = B.sniff_shift >> 1;
            if (B.addr_bytes == 0 || a < B.addr_min) B.addr_min = a;
            if (B.addr_bytes == 0 || a > B.addr_max) B.addr_max = a;
            B.addr_bytes++;
        }
    }
    for (int i = 0; i < B.ndev; i++) {
        Dev *d = &B.dev[i];
        if (d->st == D_ADDR && d->bits < 8) { d->shift = (uint8_t)((d->shift << 1) | sda); d->bits++; }
    }
}

static void ev_fall(void)
{
    if (B.stuck && !B.stuck_dead && --B.stuck_left == 0) B.stuck = false;
    for (int i = 0; i < B.ndev; i++) {
        Dev *d = &B.dev[i];
        if (d->st == D_ADDR && d->bits == 8) {
            if ((d->shift >> 1) == d->addr && !(d->shift & 1u)) { d->st = D_ACK; d->sda_low = true; }
            else d->st = D_IGNORE;
        } else if (d->st == D_ACK) {
            d->st = D_IGNORE; d->sda_low = false;
        }
    }
}

static void bus_eval(void)
{
    bool scl = line_scl(), sda = line_sda();
    if (scl != B.scl) {
        if (scl) ev_rise(sda); else ev_fall();
    } else if (scl && sda != B.sda) {
        if (sda) ev_stop(); else ev_start();
    }
    B.scl = line_scl();
    B.sda = line_sda();
}

void gpio_scl_set(int release)
{
    bool r = release != 0;
    if (!r && B.m_scl) B.m_falls++;
    if (r && !B.m_scl) {                       /* master lets SCL go: stretching slaves grab it */
        for (int i = 0; i < B.ndev; i++) {
            Dev *d = &B.dev[i];
            if (d->st == D_ACK && d->stretch_us && !d->holding) {
                d->holding = true;
                d->hold_until = (d->stretch_us == FOREVER) ? FOREVER : B.now + d->stretch_us;
            }
        }
    }
    B.m_scl = r;
    bus_eval();
}

void gpio_sda_set(int release) { B.m_sda = release != 0; bus_eval(); }
int  gpio_scl_get(void) { return line_scl(); }
int  gpio_sda_get(void) { return line_sda(); }

void delay_us(uint32_t us)
{
    B.now += us;
    if (B.now > 10000000u) { printf("FAIL: bus time ran away (missing timeout?)\n"); exit(1); }
    for (int i = 0; i < B.ndev; i++) {
        Dev *d = &B.dev[i];
        if (d->holding && d->hold_until != FOREVER && B.now >= d->hold_until) d->holding = false;
    }
    bus_eval();
}

static void bus_reset(void)
{
    memset(&B, 0, sizeof B);
    B.m_scl = B.m_sda = true;
    B.scl = B.sda = true;
}

static void add_dev(uint8_t addr, uint32_t stretch_us)
{
    B.dev[B.ndev++] = (Dev){ .addr = addr, .stretch_us = stretch_us };
}

static void inject_stuck_sda(uint32_t falls_to_release)   /* FOREVER = shorted */
{
    B.stuck = true;
    B.stuck_left = falls_to_release;
    B.stuck_dead = (falls_to_release == FOREVER);
    B.sda = false;
}

static bool bus_idle(void) { return gpio_scl_get() && gpio_sda_get(); }

int main(void)
{
    uint8_t found[8];

    /* 1. scan finds exactly the populated addresses; reserved addresses never hit the bus */
    bus_reset();
    add_dev(0x1D, 0); add_dev(0x48, 0); add_dev(0x50, 0);
    memset(found, 0xEE, sizeof found);
    CHECK(i2c_scan(found, 8) == 3);
    CHECK(found[0] == 0x1D && found[1] == 0x48 && found[2] == 0x50 && found[3] == 0xEE);
    CHECK(B.addr_bytes == 112 && B.addr_min == 0x08 && B.addr_max == 0x77);
    CHECK(B.starts == 112 && B.stops == 112);              /* every probe ends with STOP */
    CHECK(bus_idle());

    /* 2. found[] smaller than the result: count is exact, nothing written past max */
    bus_reset();
    add_dev(0x1D, 0); add_dev(0x48, 0); add_dev(0x50, 0);
    memset(found, 0xEE, sizeof found);
    CHECK(i2c_scan(found, 2) == 3);
    CHECK(found[0] == 0x1D && found[1] == 0x48 && found[2] == 0xEE);

    /* 3. single probes: ACK, NACK, reserved address (no bus activity) */
    bus_reset();
    add_dev(0x48, 0);
    CHECK(i2c_probe(0x48) == 0);
    CHECK(i2c_probe(0x49) == -ENXIO);
    uint32_t s = B.starts;
    CHECK(i2c_probe(0x03) == -EINVAL && i2c_probe(0x78) == -EINVAL && i2c_probe(0x80) == -EINVAL);
    CHECK(B.starts == s && bus_idle());

    /* 4. slave stuck mid-byte releases SDA after 5 more clocks: recover, then the bus works */
    bus_reset();
    add_dev(0x48, 0);
    inject_stuck_sda(5);
    CHECK(i2c_probe(0x48) == -EBUSY && B.starts == 0);
    CHECK(i2c_bus_recover() == 5);
    CHECK(B.stops == 1 && bus_idle());
    CHECK(i2c_probe(0x48) == 0);
    CHECK(i2c_bus_recover() == 0);                          /* healthy bus: nothing to do */

    /* 5. worst recoverable case needs all 9 clocks */
    bus_reset();
    inject_stuck_sda(9);
    CHECK(i2c_bus_recover() == 9 && bus_idle());

    /* 6. SDA shorted low: give up after exactly 9 pulses, no STOP; scan refuses to start */
    bus_reset();
    add_dev(0x48, 0);
    inject_stuck_sda(FOREVER);
    CHECK(i2c_bus_recover() == -EIO);
    CHECK(B.m_falls == 9 && B.stops == 0);
    CHECK(i2c_scan(found, 8) == -EBUSY && B.starts == 0);

    /* 7. clock stretching: 40 us is waited out; a slave that never lets go times out */
    bus_reset();
    add_dev(0x50, 40);
    uint32_t t0 = B.now;
    CHECK(i2c_probe(0x50) == 0);
    CHECK(B.now - t0 >= 40 + 9 * 2 * I2C_HALF_US);         /* really waited for SCL */
    CHECK(B.stops == 1 && bus_idle());
    bus_reset();
    add_dev(0x50, FOREVER);
    t0 = B.now;
    CHECK(i2c_probe(0x50) == -ETIMEDOUT);
    CHECK(B.now - t0 >= I2C_STRETCH_TIMEOUT_US && B.now - t0 < I2C_STRETCH_TIMEOUT_US + 200);
    CHECK(B.m_scl && B.m_sda);                              /* master released both lines */

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

3. 힌트 (막힐 때 하나씩)

Hint 1 — "SCL을 놓는다" = 놓고 기다린다

open-drain에서 gpio_scl_set(1)은 "high로 만든다"가 아니라 "놓는다"입니다. 슬레이브가 잡고 있으면 여전히 low입니다. 그래서 헬퍼 하나를 먼저 만드세요.

scl_high(): gpio_scl_set(1) → while (!gpio_scl_get()) 동안 delay_us(1), 누적 200 µs면 -ETIMEDOUT. probe와 recover의 모든 SCL 상승은 이 헬퍼로 합니다.

Hint 2 — 한 비트 = "SCL low에서 SDA 세팅 → SCL high에서 샘플" 
START : SDA low, delay, SCL low
bit   : SDA = b, delay, scl_high(), delay, SCL low        (x 8, MSB first)
ACK   : SDA release, delay, scl_high(), ack = !SDA, delay, SCL low
STOP  : SDA low, delay, scl_high(), delay, SDA release, delay

ACK는 SCL이 high일 때 읽습니다. 슬레이브가 ACK을 SDA low로 표현하므로 ack = (gpio_sda_get() == 0).

Hint 3 — 복구 루프의 종료 조건 두 개

while (SDA low) { if (n == 9) return -EIO; pulse; n++; } 그리고 루프를 빠져나오면 STOP. 반드시 펄스 후에 SDA를 확인해야 정확히 필요한 만큼만 클록을 줍니다. STOP은 SCL low → SDA low → SCL high → SDA high 순서 — SDA를 먼저 low로 만들어야 "SCL high 중 SDA 상승" 엣지를 만들 수 있습니다.

4. 풀이

4.1 핵심 아이디어 — 파형으로 보기

I2C의 규칙은 딱 두 줄입니다: 데이터는 SCL low일 때 바꾸고 SCL high일 때 읽는다, 그리고 SCL high 중 SDA가 바뀌는 것은 START/STOP 신호다. probe 한 번은 START + 주소 바이트 8비트 + ACK 1클록 + STOP입니다.

ACK/NACK의 전기적 의미가 핵심입니다. ACK은 누군가 능동적으로 SDA를 끌어내린 것이고, NACK은 아무도 안 잡아서 pull-up이 high로 만든 것입니다. 그래서 장치가 없거나, 전원이 꺼졌거나, 주소가 틀리면 모두 NACK입니다 — 스캔이 동작하는 원리입니다.

4.2 stuck bus와 9클록 복구

슬레이브가 읽기 바이트를 보내는 도중 마스터만 리셋되면, 슬레이브는 아직 바이트의 남은 비트를 내보내는 중이라 0인 비트에서 SDA를 잡고 있습니다. 마스터는 SDA가 low라 START를 못 겁니다(-EBUSY). SCL을 더 주면 슬레이브가 남은 비트를 다 내보내고, ACK 슬롯에서 마스터가 SDA를 놓아 둔 상태(=NACK)를 보고 전송을 끝냅니다.

/*
 * V8  I2C Bus Scan + Stuck-Bus Recovery on a Bit-Banged Controller (Reference solution)
 *
 * Board bring-up: the SoC's I2C pins are muxed as GPIOs and you drive the bus by hand.
 * Both lines are open-drain with pull-ups:
 *   gpio_scl_set(0) / gpio_sda_set(0)   drive the line LOW
 *   gpio_scl_set(1) / gpio_sda_set(1)   RELEASE the line (it goes high unless someone holds it low)
 *   gpio_scl_get() / gpio_sda_get()     read the real line level (1 = high)
 *   delay_us(us)                        busy-wait; advances the fake clock
 * The bus model at the bottom simulates slaves that ACK their address, a slave that
 * stretches the clock (holds SCL low during the ACK clock), and a slave stuck mid-byte
 * holding SDA low that lets go after it sees enough SCL falling edges.
 *
 * Implement:
 *   i2c_bus_recover()  If SDA is already high: return 0 (no clocks). Otherwise pulse SCL
 *                      (low, then release/high) at most 9 times, checking SDA after each pulse;
 *                      once SDA is high, generate a STOP (SCL low, SDA low, SCL high, SDA high)
 *                      and return the number of pulses used. Still low after 9 pulses -> -EIO
 *                      (no STOP). SCL that cannot go high -> -ETIMEDOUT.
 *   i2c_probe(addr)    -EINVAL for reserved addresses (0x00-0x07, 0x78-0x7F, > 0x7F), nothing on
 *                      the bus. -EBUSY if SCL or SDA is low before START. Otherwise:
 *                      START, send (addr << 1) | 0 MSB first, read the ACK bit, STOP.
 *                      0 on ACK, -ENXIO on NACK.
 *                      Every time you release SCL, wait until it is really high (clock stretching);
 *                      if it stays low for I2C_STRETCH_TIMEOUT_US -> release both lines, -ETIMEDOUT.
 *   i2c_scan(found, max) probe 0x08..0x77 in order; write up to max ACKing addresses into found,
 *                      return the total count. If a probe fails with anything other than
 *                      -ENXIO, stop and return that error.
 *   Timing: I2C_HALF_US between line changes (100 kHz).
 *
 * Build & run:  ./run.sh V8 sol
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>
#include <errno.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

/* ---------------- GPIO HAL (provided, implemented by the bus model below) ---------------- */
void gpio_scl_set(int release);
void gpio_sda_set(int release);
int  gpio_scl_get(void);
int  gpio_sda_get(void);
void delay_us(uint32_t us);

#define I2C_HALF_US             5u
#define I2C_STRETCH_TIMEOUT_US  200u
#define I2C_RECOVER_MAX_PULSES  9

/* ---------------- your code ---------------- */

/* release SCL and wait for it to really go high (clock stretching) */
static int scl_high(void)
{
    gpio_scl_set(1);
    uint32_t waited = 0;
    while (!gpio_scl_get()) {
        if (waited >= I2C_STRETCH_TIMEOUT_US) return -ETIMEDOUT;
        delay_us(1);
        waited++;
    }
    return 0;
}

int i2c_bus_recover(void)
{
    if (gpio_sda_get()) return 0;
    int n = 0;
    while (!gpio_sda_get()) {
        if (n == I2C_RECOVER_MAX_PULSES) return -EIO;    /* still stuck: give up, no STOP */
        gpio_scl_set(0);
        delay_us(I2C_HALF_US);
        if (scl_high()) return -ETIMEDOUT;
        delay_us(I2C_HALF_US);
        n++;
    }
    /* STOP: SDA rises while SCL is high */
    gpio_scl_set(0);
    gpio_sda_set(0);
    delay_us(I2C_HALF_US);
    if (scl_high()) return -ETIMEDOUT;
    delay_us(I2C_HALF_US);
    gpio_sda_set(1);
    delay_us(I2C_HALF_US);
    return n;
}

static bool addr_reserved(uint8_t a) { return a < 0x08u || a > 0x77u; }

static int abort_timeout(void)
{
    gpio_sda_set(1);
    gpio_scl_set(1);
    return -ETIMEDOUT;
}

int i2c_probe(uint8_t addr)
{
    if (addr_reserved(addr)) return -EINVAL;
    if (!gpio_scl_get() || !gpio_sda_get()) return -EBUSY;

    /* START: SDA falls while SCL is high */
    gpio_sda_set(0);
    delay_us(I2C_HALF_US);
    gpio_scl_set(0);

    uint8_t byte = (uint8_t)(addr << 1);                  /* R/W = 0 (write) */
    for (int i = 7; i >= 0; i--) {
        gpio_sda_set((byte >> i) & 1u);                   /* change SDA only while SCL is low */
        delay_us(I2C_HALF_US);
        if (scl_high()) return abort_timeout();
        delay_us(I2C_HALF_US);
        gpio_scl_set(0);
    }

    /* ACK clock: release SDA, slave pulls it low to ACK */
    gpio_sda_set(1);
    delay_us(I2C_HALF_US);
    if (scl_high()) return abort_timeout();
    bool ack = !gpio_sda_get();                           /* sample while SCL is high */
    delay_us(I2C_HALF_US);
    gpio_scl_set(0);

    /* STOP */
    gpio_sda_set(0);
    delay_us(I2C_HALF_US);
    if (scl_high()) return abort_timeout();
    delay_us(I2C_HALF_US);
    gpio_sda_set(1);
    delay_us(I2C_HALF_US);
    return ack ? 0 : -ENXIO;
}

int i2c_scan(uint8_t *found, size_t max)
{
    int cnt = 0;
    for (uint8_t a = 0x08; a <= 0x77; a++) {
        int rc = i2c_probe(a);
        if (rc == -ENXIO) continue;
        if (rc) return rc;
        if ((size_t)cnt < max) found[cnt] = a;
        cnt++;
    }
    return cnt;
}

/* =====================================================================
 * Open-drain I2C bus model + slaves + fault injection (do not edit)
 * ===================================================================== */
#define MAX_DEV 4
#define FOREVER 0xFFFFFFFFu
enum { D_IDLE, D_ADDR, D_ACK, D_IGNORE };

typedef struct {
    uint8_t  addr;
    uint32_t stretch_us;          /* hold SCL low this long on the ACK clock (FOREVER = never let go) */
    int      st;
    uint8_t  bits, shift;
    bool     sda_low;             /* driving SDA low */
    bool     holding;             /* holding SCL low */
    uint32_t hold_until;
} Dev;

static struct {
    bool m_scl, m_sda;            /* master side: true = released */
    bool scl, sda;                /* last effective line levels */
    uint32_t now;                 /* microseconds */
    Dev dev[MAX_DEV]; int ndev;
    bool stuck; uint32_t stuck_left; bool stuck_dead;   /* stuck slave holding SDA low */
    bool sniff; uint8_t sniff_bits, sniff_shift;
    uint32_t starts, stops, m_falls, addr_bytes;
    uint8_t addr_min, addr_max;
} B;

static bool line_scl(void)
{
    if (!B.m_scl) return false;
    for (int i = 0; i < B.ndev; i++) if (B.dev[i].holding) return false;
    return true;
}

static bool line_sda(void)
{
    if (!B.m_sda || B.stuck) return false;
    for (int i = 0; i < B.ndev; i++) if (B.dev[i].sda_low) return false;
    return true;
}

static void ev_start(void)
{
    B.starts++;
    B.sniff = true; B.sniff_bits = 0; B.sniff_shift = 0;
    for (int i = 0; i < B.ndev; i++) { Dev *d = &B.dev[i]; d->st = D_ADDR; d->bits = 0; d->shift = 0; d->sda_low = false; }
}

static void ev_stop(void)
{
    B.stops++;
    B.sniff = false;
    for (int i = 0; i < B.ndev; i++) { B.dev[i].st = D_IDLE; B.dev[i].sda_low = false; }
}

static void ev_rise(bool sda)
{
    if (B.sniff && ++B.sniff_bits <= 8) {
        B.sniff_shift = (uint8_t)((B.sniff_shift << 1) | sda);
        if (B.sniff_bits == 8) {
            uint8_t a = B.sniff_shift >> 1;
            if (B.addr_bytes == 0 || a < B.addr_min) B.addr_min = a;
            if (B.addr_bytes == 0 || a > B.addr_max) B.addr_max = a;
            B.addr_bytes++;
        }
    }
    for (int i = 0; i < B.ndev; i++) {
        Dev *d = &B.dev[i];
        if (d->st == D_ADDR && d->bits < 8) { d->shift = (uint8_t)((d->shift << 1) | sda); d->bits++; }
    }
}

static void ev_fall(void)
{
    if (B.stuck && !B.stuck_dead && --B.stuck_left == 0) B.stuck = false;
    for (int i = 0; i < B.ndev; i++) {
        Dev *d = &B.dev[i];
        if (d->st == D_ADDR && d->bits == 8) {
            if ((d->shift >> 1) == d->addr && !(d->shift & 1u)) { d->st = D_ACK; d->sda_low = true; }
            else d->st = D_IGNORE;
        } else if (d->st == D_ACK) {
            d->st = D_IGNORE; d->sda_low = false;
        }
    }
}

static void bus_eval(void)
{
    bool scl = line_scl(), sda = line_sda();
    if (scl != B.scl) {
        if (scl) ev_rise(sda); else ev_fall();
    } else if (scl && sda != B.sda) {
        if (sda) ev_stop(); else ev_start();
    }
    B.scl = line_scl();
    B.sda = line_sda();
}

void gpio_scl_set(int release)
{
    bool r = release != 0;
    if (!r && B.m_scl) B.m_falls++;
    if (r && !B.m_scl) {                       /* master lets SCL go: stretching slaves grab it */
        for (int i = 0; i < B.ndev; i++) {
            Dev *d = &B.dev[i];
            if (d->st == D_ACK && d->stretch_us && !d->holding) {
                d->holding = true;
                d->hold_until = (d->stretch_us == FOREVER) ? FOREVER : B.now + d->stretch_us;
            }
        }
    }
    B.m_scl = r;
    bus_eval();
}

void gpio_sda_set(int release) { B.m_sda = release != 0; bus_eval(); }
int  gpio_scl_get(void) { return line_scl(); }
int  gpio_sda_get(void) { return line_sda(); }

void delay_us(uint32_t us)
{
    B.now += us;
    if (B.now > 10000000u) { printf("FAIL: bus time ran away (missing timeout?)\n"); exit(1); }
    for (int i = 0; i < B.ndev; i++) {
        Dev *d = &B.dev[i];
        if (d->holding && d->hold_until != FOREVER && B.now >= d->hold_until) d->holding = false;
    }
    bus_eval();
}

static void bus_reset(void)
{
    memset(&B, 0, sizeof B);
    B.m_scl = B.m_sda = true;
    B.scl = B.sda = true;
}

static void add_dev(uint8_t addr, uint32_t stretch_us)
{
    B.dev[B.ndev++] = (Dev){ .addr = addr, .stretch_us = stretch_us };
}

static void inject_stuck_sda(uint32_t falls_to_release)   /* FOREVER = shorted */
{
    B.stuck = true;
    B.stuck_left = falls_to_release;
    B.stuck_dead = (falls_to_release == FOREVER);
    B.sda = false;
}

static bool bus_idle(void) { return gpio_scl_get() && gpio_sda_get(); }

int main(void)
{
    uint8_t found[8];

    /* 1. scan finds exactly the populated addresses; reserved addresses never hit the bus */
    bus_reset();
    add_dev(0x1D, 0); add_dev(0x48, 0); add_dev(0x50, 0);
    memset(found, 0xEE, sizeof found);
    CHECK(i2c_scan(found, 8) == 3);
    CHECK(found[0] == 0x1D && found[1] == 0x48 && found[2] == 0x50 && found[3] == 0xEE);
    CHECK(B.addr_bytes == 112 && B.addr_min == 0x08 && B.addr_max == 0x77);
    CHECK(B.starts == 112 && B.stops == 112);              /* every probe ends with STOP */
    CHECK(bus_idle());

    /* 2. found[] smaller than the result: count is exact, nothing written past max */
    bus_reset();
    add_dev(0x1D, 0); add_dev(0x48, 0); add_dev(0x50, 0);
    memset(found, 0xEE, sizeof found);
    CHECK(i2c_scan(found, 2) == 3);
    CHECK(found[0] == 0x1D && found[1] == 0x48 && found[2] == 0xEE);

    /* 3. single probes: ACK, NACK, reserved address (no bus activity) */
    bus_reset();
    add_dev(0x48, 0);
    CHECK(i2c_probe(0x48) == 0);
    CHECK(i2c_probe(0x49) == -ENXIO);
    uint32_t s = B.starts;
    CHECK(i2c_probe(0x03) == -EINVAL && i2c_probe(0x78) == -EINVAL && i2c_probe(0x80) == -EINVAL);
    CHECK(B.starts == s && bus_idle());

    /* 4. slave stuck mid-byte releases SDA after 5 more clocks: recover, then the bus works */
    bus_reset();
    add_dev(0x48, 0);
    inject_stuck_sda(5);
    CHECK(i2c_probe(0x48) == -EBUSY && B.starts == 0);
    CHECK(i2c_bus_recover() == 5);
    CHECK(B.stops == 1 && bus_idle());
    CHECK(i2c_probe(0x48) == 0);
    CHECK(i2c_bus_recover() == 0);                          /* healthy bus: nothing to do */

    /* 5. worst recoverable case needs all 9 clocks */
    bus_reset();
    inject_stuck_sda(9);
    CHECK(i2c_bus_recover() == 9 && bus_idle());

    /* 6. SDA shorted low: give up after exactly 9 pulses, no STOP; scan refuses to start */
    bus_reset();
    add_dev(0x48, 0);
    inject_stuck_sda(FOREVER);
    CHECK(i2c_bus_recover() == -EIO);
    CHECK(B.m_falls == 9 && B.stops == 0);
    CHECK(i2c_scan(found, 8) == -EBUSY && B.starts == 0);

    /* 7. clock stretching: 40 us is waited out; a slave that never lets go times out */
    bus_reset();
    add_dev(0x50, 40);
    uint32_t t0 = B.now;
    CHECK(i2c_probe(0x50) == 0);
    CHECK(B.now - t0 >= 40 + 9 * 2 * I2C_HALF_US);         /* really waited for SCL */
    CHECK(B.stops == 1 && bus_idle());
    bus_reset();
    add_dev(0x50, FOREVER);
    t0 = B.now;
    CHECK(i2c_probe(0x50) == -ETIMEDOUT);
    CHECK(B.now - t0 >= I2C_STRETCH_TIMEOUT_US && B.now - t0 < I2C_STRETCH_TIMEOUT_US + 200);
    CHECK(B.m_scl && B.m_sda);                              /* master released both lines */

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

코드 읽는 포인트

  • scl_high() 하나가 clock stretching 전체입니다. 이게 없으면 마스터가 슬레이브보다 먼저 다음 비트로 넘어가서 버스가 깨집니다(테스트 7번: STOP이 안 나감).
  • i2c_probe는 NACK이어도 STOP을 보냅니다. STOP 없이 다음 START를 걸면 repeated START가 되어 슬레이브 상태가 꼬일 수 있습니다.
  • 주소 검사(-EINVAL)와 idle 검사(-EBUSY)가 START보다 먼저입니다 → 잘못된 호출은 버스에 흔적이 없음(테스트 3, 4, 6번 starts == 0).
  • i2c_bus_recover의 9번 제한은 n == 9 체크를 펄스 전에 해서 정확히 9번에서 멈춥니다(테스트 6번 m_falls == 9).
  • 스캔의 반환/버퍼 규칙은 T1-1과 같습니다: 쓸 수 있는 만큼 쓰고 전체 개수를 반환.

4.5 복잡도

  • probe 1회: 9클록 + START/STOP = 반 주기 22개 = 110 µs(100 kHz). 스캔: 112 × 110 µs ≈ 12.3 ms.
  • recover: 최대 9 × 10 µs + STOP 15 µs = 105 µs (stretching 없을 때).
  • 메모리 O(1).

5. 임베디드 관점으로 말할 것

  • 왜 bit-bang인가: 실제 SoC에는 I2C 컨트롤러 IP가 있지만, 복구는 컨트롤러가 못 하는 경우가 많습니다(SDA low면 START 자체가 안 걸림). 그래서 드라이버는 pinmux를 GPIO로 바꿔서 9클록을 주고 다시 I2C 기능으로 돌립니다. Linux의 i2c_generic_scl_recovery() / recovery-gpios(scl-gpios, sda-gpios) DT 속성이 바로 이것입니다.
  • open-drain과 pull-up: 상승 시간은 R_pullup × C_bus로 정해집니다. 100 kHz 표준 모드는 rise time ≤ 1000 ns, 400 kHz는 ≤ 300 ns. 풀업이 너무 크면 엣지가 느려 고속에서 비트가 틀리고, 너무 작으면 3 mA sink 한도를 넘습니다.
  • 스캔이 SoC validation에서 하는 일: 보드에 실장된 장치(PMIC, 센서, EEPROM, 카메라 serializer)가 기대한 주소에서 응답하는지 = 보드 enumeration, 그리고 pinmux·pad 설정·전원 시퀀스·레벨 시프터가 맞는지를 한 번에 확인합니다. 기대 목록과 diff해서 리포트합니다.
  • probe의 위험: 일부 장치는 빈 write에도 반응합니다(예: 일부 EEPROM이 write pointer를 바꿈). Linux i2cdetect가 주소 범위마다 quick-write/read-byte를 골라 쓰는 이유입니다.
  • 관련: 레지스터 접근 계층과 sanity test는 V2, 테스트 결과 집계는 V5.

5.1 면접관(HW 출신 Sr Manager)이 파고들 포인트

  • "로직 분석기로 어떻게 디버그하나?" — SCL/SDA 두 채널을 최소 4–10배 오버샘플(100 kHz면 1–2 MS/s 이상)로 잡고 I2C 디코더를 켭니다. NACK인지, 주소가 틀렸는지(7비트 vs 8비트 표기 혼동), stretching이 얼마나 긴지, STOP이 있는지 바로 보입니다. 엣지가 둥글면 아날로그 채널/오실로스코프로 rise time을 봅니다. "First I put a logic analyzer on SCL and SDA: the decoder tells me ACK versus NACK and the address, and a scope tells me whether the rise time is within spec."
  • "스캔에서 장치 하나가 안 보이면 원인 순서는?" — 전원/리셋 핀 → pinmux/pad(open-drain 설정, 내부 pull-up) → 주소 strap 핀 → 레벨 시프터/버스 스위치 enable → 장치 고장. 스캔은 이 중 "응답이 없다"는 것만 알려주므로 측정으로 좁힙니다. "A missing device in the scan is a symptom; I walk power, reset, pinmux, address straps, then the level shifter before blaming the part."
  • "Silicon에서 이 테스트를 어떻게 쓸 건가?" — bring-up 첫날 보드 enumeration, 그리고 PVT(전압·온도) 코너에서 반복 스캔해서 마진이 없는 버스(엣지가 느린 버스)를 찾습니다. SLT에서는 기대 장치 목록과 diff해서 pass/fail. "The same scan runs at every PVT corner; a device that disappears only at low voltage and hot points to a marginal pull-up or rise time."
  • "복구가 실패하면?" — 9클록 후에도 SDA가 low면 소프트웨어로는 못 고칩니다: 슬레이브 전원/리셋 라인 토글, 버스 스위치로 구간 분리, 그래도 안 되면 보드 short. 그래서 -EIO를 위로 올려서 보고합니다. "If nine clocks don't free SDA, it's not a protocol hang anymore — I power-cycle or reset that device, or isolate the segment with the bus mux."

6. Follow-up 질문과 답

Follow-up (English)답
Why exactly 9 clocks?슬레이브가 멈출 수 있는 최악의 위치는 바이트의 첫 비트입니다. 남은 것은 데이터 8비트 + ACK 슬롯 1개 = 9클록. ACK 슬롯에서 마스터가 SDA를 놓아 두면 슬레이브는 NACK으로 보고 전송을 끝내고 SDA를 놓습니다.
What do ACK and NACK mean electrically?ACK = 수신 측이 9번째 클록 동안 SDA를 능동적으로 low로 잡음. NACK = 아무도 안 잡아서 pull-up이 high로 둠. 그래서 "장치 없음"과 "장치가 거부함"은 전기적으로 구별이 안 됩니다.
How do you size the pull-up resistor?하한: R_min = (VDD − V_OL) / I_OL (예: 3.3 V, 0.4 V, 3 mA → 약 1 kΩ). 상한: R_max = t_r / (0.8473 × C_bus) (100 kHz, t_r 1000 ns, 200 pF → 약 5.9 kΩ). 그 사이에서 속도·소비 전류를 보고 고릅니다.
What is a repeated START and when do you need it?STOP 없이 START를 다시 거는 것(Sr). 레지스터 읽기에서 "레지스터 포인터 쓰기 → Sr → 읽기"를 버스 소유권을 놓지 않고 이어서 하려고 씁니다(멀티 마스터에서 중간에 다른 마스터가 끼어들지 못함).
How does 10-bit addressing work?첫 바이트가 11110 A9 A8 R/W, 두 번째 바이트가 A7..A0. 0x78–0x7B가 예약된 이유입니다. 스캔에서 이 범위를 건너뛰는 이유이기도 합니다.
I2C vs I3C?I3C는 push-pull(최대 12.5 MHz SDR), 동적 주소 할당(ENTDAA)으로 스캔 대신 열거, in-band interrupt(IBI)로 별도 IRQ 선 불필요, I2C 장치와 같은 버스에서 공존 가능. 센서가 많은 카메라/IMU 시스템에서 점점 많이 씁니다.
Why does an SoC validation test do a bus scan at all?보드 enumeration(실장된 장치가 기대 주소에서 응답) + pinmux/pad/전원 시퀀스 검증을 한 번에. 기대 장치 목록과 diff해서 리포트하고, PVT 코너마다 반복해서 마진을 봅니다.
What about a slave holding SCL low forever?9클록 복구는 SDA stuck용이고, SCL stuck은 마스터가 클록을 줄 수 없어서 못 고칩니다. 타임아웃(SMBus는 25–35 ms)으로 감지하고 장치 리셋/전원 차단으로 처리합니다. 이 문제의 -ETIMEDOUT이 그 감지 부분입니다.

7. 자주 하는 실수

  • gpio_scl_set(1) 후 바로 다음 단계로 감 → clock stretching 무시, STOP이 안 나감 (테스트 7번)
  • stretching 대기에 타임아웃이 없음 → 영원히 매달림 (테스트 7번 forever, 모델이 강제 종료)
  • SCL high일 때 SDA를 바꿈 → 의도치 않은 START/STOP이 생겨 슬레이브가 리셋됨
  • NACK이면 STOP을 생략함 → starts == stops 불일치 (테스트 1번)
  • 예약 주소(0x00–0x07, 0x78–0x7F)까지 스캔 → general call(0x00)로 모든 장치가 반응할 수 있음 (테스트 1번 주소 범위)
  • 복구에서 SDA 확인 전에 9번을 무조건 다 줌 → 반환 값(필요한 펄스 수)이 틀림 (테스트 4번 = 5)
  • 복구 후 STOP을 안 만듦 → 슬레이브 상태 머신이 "전송 중"으로 남을 수 있음 (테스트 4번 stops == 1)
  • 버스가 막혔는데 그냥 START를 시도 → -EBUSY 대신 엉뚱한 NACK (테스트 4, 6번)
