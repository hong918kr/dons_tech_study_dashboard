0. 문제 한국어로 먼저 보기

영어 원문(§1)을 읽기 전에 무슨 상황이고 뭘 만들어야 하는지만 빠르게 잡는 요약입니다. 풀이 힌트는 없습니다.

한 줄 요약: NPU가 계산한 int8 GEMM 결과를 검증하기 위해 C golden model, 결과를 비교하는 comparator, 차이를 버그 종류로 분류하는 diagnose, 그리고 seeded stimulus generator를 짭니다.

상황

  • 사내 AI accelerator SoC의 NPU를 검증합니다. quantized fully-connected(또는 1×1 conv) layer가 NPU에서 int8 GEMM으로 돌아갑니다.
  • golden model은 compiler 팀이 sign-off 하는 기준이고, TFLite/gemmlowp와 같은 수식이어야 합니다.
  • 행렬 A[M][K], B[K][N], C[M][N]은 모두 row-major int8입니다. weight(B)는 symmetric(zero point 0)입니다.
  • 핵심 용어
    • zero point(a_zp, out_zp): int8 값에서 "실제 0"에 해당하는 정수. 입력은 A - a_zp로 빼서 쓰고, 출력은 결과에 out_zp를 더함
    • accumulator(acc): bias[n] + Σ_k (A[m][k] - a_zp) * B[k][n], int32로 누적
    • requant: int32 acc를 실수 scale(mult / 2^31 / 2^shift)로 줄여 int8로 되돌리는 단계. SRDHM(곱한 뒤 상위 32 bit를 반올림) → RDBPOT(2^e로 나누며 반올림) 순서이고, 정확한 수식은 §1 코드 블록에 있음
    • per-channel / per-tensor: mult/shift를 출력 column n마다 따로 쓰면 per-channel(c = n), 하나만 쓰면 per-tensor(c = 0)
    • relu: 켜면 하한 act_min = out_zp, 끄면 -128. 상한은 항상 127
    • bit-exact: golden과 HW 출력이 한 비트도 다르지 않아야 pass
  • 테스트에는 NPU behavioural model npu_gemm(..., bug)이 들어 있습니다. 한 tile에 출력 column 8개(NPU_TILE = 8)를 계산하고, 버그 4개를 넣을 수 있습니다.
    • BUG_TRUNC_ROUND: 반올림 대신 floor
    • BUG_ACC16: accumulator가 16 bit에서 wrap
    • BUG_NO_BIAS_CH: channel 5의 bias 누락
    • BUG_TILE_EDGE: 마지막 partial tile에서 k = K-1 항이 빠짐
  • 내 comparator와 diagnose가 이 4개를 모두 잡아내고 맞는 종류로 분류해야 합니다.

diagnose 판정 순서 (위에서부터 처음 맞는 것)

  1. mismatch 없음 → DIAG_PASS
  2. N % tile != 0이고, 틀린 column이 전부 >= tile * floor(N / tile)(= 마지막 partial tile 안) → DIAG_TILE_EDGE
  3. mismatch가 전부 한 column에 있음 → DIAG_ONE_CHANNEL
  4. max_abs == 1 → DIAG_ROUNDING
  5. 그 밖 → DIAG_CORRUPTION

gen_tensor 규칙

  • LCG: s = s * 1664525 + 1013904223 (mod 2^32), 원소마다 한 step.
  • (s >> 8) % 8 == 0이면 원소 = CORNER[(s >> 4) & 3], CORNER = { -128, 127, 0, zp }.
  • 아니면 원소 = (int8_t)(s >> 24).

예시를 말로 풀면

  • 2×3 A와 3×2 B, bias = [10, -20], a_zp = 1, out_zp = -1, per-tensor mult = 0x40000000(0.5), shift = 1 → scale은 0.5 × 2^-1 = 0.25입니다.
    • 예: acc[0][0] = 10 + (11-1)*1 + (21-1)*2 + (31-1)*3 = 150. 전체 acc = [[150, 90], [378, 494]].
    • 150 * 0.25 = 37.5 → 반올림해서 38, 여기에 out_zp = -1을 더해 37. 전체 C = [[37, 22], [94, 123]].
    • relu를 켜고 out_zp = -100으로 바꾸면 하한이 -100이 되고 C = [[-62, -77], [-5, 24]].
  • M=6, K=32, N=12 layer를 NPU model과 bit-exact로 비교하면 (N=12, tile=8이라 column 8–11이 마지막 partial tile):
    • BUG_NONE: mismatch 0 → PASS
    • BUG_TRUNC_ROUND: 37개, 최대 차이 1 → ROUNDING (CMP_TOL1로 보면 0개)
    • BUG_ACC16: 27개, 최대 차이 86 → CORRUPTION (정확히 |acc| > 32767인 27개)
    • BUG_NO_BIAS_CH: 6개, 전부 column 5 → ONE_CHANNEL
    • BUG_TILE_EDGE: 16개, 첫 mismatch (0, 8) → TILE_EDGE

지켜야 할 조건

  • M, N <= 32(CMP_MAX_N), K <= 64, 0 <= shift <= 31. 음수 int32_t의 right shift는 arithmetic이라고 가정 (gcc/clang).
  • golden model은 위 수식과 bit-exact여야 함. tie(딱 .5)를 어느 쪽으로 반올림하는지까지 똑같아야 함.
  • malloc 금지.

1. Problem

You validate the NPU of an in-house AI accelerator SoC. A quantized fully-connected (or 1×1 conv) layer runs on the NPU as an int8 GEMM. Write:

  1. the C golden model that the compiler team signs off on (same math as TFLite/gemmlowp),
  2. a comparator that reports how the NPU output differs from golden,
  3. a diagnose step that turns the report into a likely bug class, and
  4. a seeded stimulus generator with corner values.

Math (the spec from the compiler team). A[M][K], B[K][N], C[M][N] are row-major int8; weights are symmetric (zero point 0).

acc[m][n] = bias[n] + sum_k (A[m][k] - a_zp) * B[k][n]          int32 accumulate
C[m][n]   = clamp(requant(acc, mult[c], shift[c]) + out_zp, act_min, 127)
            c = n (per-channel) or 0 (per-tensor);  act_min = relu ? out_zp : -128

requant(x, mult, shift) = RDBPOT(SRDHM(x, mult), shift)
  SRDHM(a, b):  if a == b == INT32_MIN return INT32_MAX
                p = (int64)a * b;  nudge = p >= 0 ? 1<<30 : 1 - (1<<30)
                return (int32)((p + nudge) / 2^31)            C division, truncates toward 0
  RDBPOT(x, e): mask = (1<<e) - 1;  rem = x & mask;  thr = (mask >> 1) + (x < 0)
                return (x >> e) + (rem > thr)                 arithmetic shift, 0 <= e <= 31
real scale = mult / 2^31 / 2^shift,  mult in [2^30, 2^31)

  • cmp_tensors: CMP_BITEXACT (default) fails on any difference; CMP_TOL1 accepts |diff| <= 1. Report mismatches (outside tolerance), max_abs and hist (|d| == 0, == 1, > 1) over all elements, the first mismatch in row-major order (-1, -1 if none), and per-column mismatch counts col_bad[n].
  • diagnose, rules in this order: no mismatch → PASS; N % tile != 0 and every bad column is >= tile * floor(N / tile) → TILE_EDGE; all mismatches in one column → ONE_CHANNEL; max_abs == 1 → ROUNDING; else → CORRUPTION.
  • gen_tensor: LCG s = s * 1664525 + 1013904223 (mod 2^32), one step per element. If (s >> 8) % 8 == 0 the element is CORNER[(s >> 4) & 3] with CORNER = { -128, 127, 0, zp }, else (int8_t)(s >> 24).
  • No malloc. N <= CMP_MAX_N (32), K <= 64.

The tests include a provided NPU behavioural model npu_gemm(..., bug) that computes 8 output columns per tile (NPU_TILE = 8) and can inject four bugs: BUG_TRUNC_ROUND (floor instead of round), BUG_ACC16 (accumulator wraps at 16 bits), BUG_NO_BIAS_CH (bias of channel 5 dropped) and BUG_TILE_EDGE (the last, partial tile drops k = K-1). Your comparator and diagnose must catch and classify each.

Constraints

  • M, N <= 32, K <= 64, 0 <= shift <= 31. Right shift of a negative int32_t is arithmetic (gcc/clang).
  • The golden model must be bit-exact with the formulas above, including how ties round.

Clarifying questions to ask (first 3 minutes)

  1. Is the golden reference TFLite/gemmlowp-style fixed point, or float scale + round? (They differ in ties.)
  2. Per-tensor or per-channel quantization? Symmetric weights? Where is the zero point applied?
  3. Is the accumulator 32-bit on the HW? Is bias added before or after accumulation, in int32?
  4. Is bit-exact the pass criterion, or is ±1 LSB acceptable for some layers?
  5. What tile sizes does the NPU use, and which layer shapes do not divide evenly?
  6. How do I get the HW output — DMA to DDR and read back, or a debug port?

/* Stands in for the RTL / FPGA image. Computes tile by tile, NPU_TILE output columns at a time. */

typedef enum { BUG_NONE, BUG_TRUNC_ROUND, BUG_ACC16, BUG_NO_BIAS_CH, BUG_TILE_EDGE } NpuBug;
#define NPU_BUG_CH 5          /* channel whose bias is dropped for BUG_NO_BIAS_CH */

static int32_t hw_requant(int32_t x, int32_t mult, int shift, bool trunc)
{
    int64_t p = (int64_t)x * mult;
    if (trunc) {                                  /* bug: floor instead of round, both steps */
        int32_t hi = (int32_t)(p >> 31);
        return hi >> shift;
    }
    int64_t nudge = p >= 0 ? (1LL << 30) : (1 - (1LL << 30));
    int32_t hi = (int32_t)((p + nudge) / (1LL << 31));
    int32_t mask = (int32_t)((1u << shift) - 1u);
    return (hi >> shift) + ((hi & mask) > (mask >> 1) + (hi < 0));
}

static void npu_gemm(const int8_t *A, const int8_t *B, const int32_t *bias, int M, int K, int N,
                     const QParams *q, int8_t *C, NpuBug bug)
{
    int32_t lo = q->relu ? q->out_zp : -128;
    for (int n0 = 0; n0 < N; n0 += NPU_TILE) {
        int w = (N - n0 < NPU_TILE) ? N - n0 : NPU_TILE;
        int kmax = (bug == BUG_TILE_EDGE && w < NPU_TILE) ? K - 1 : K;   /* remainder-path bug */
        for (int m = 0; m < M; m++)
            for (int j = 0; j < w; j++) {
                int n = n0 + j;
                int32_t acc = (bug == BUG_NO_BIAS_CH && n == NPU_BUG_CH) ? 0 : bias[n];
                for (int k = 0; k < kmax; k++) {
                    acc += ((int32_t)A[m * K + k] - q->a_zp) * (int32_t)B[k * N + n];
                    if (bug == BUG_ACC16) acc = (int16_t)(uint16_t)(uint32_t)acc;  /* 16-bit wrap */
                }

3. 힌트 (막힐 때 하나씩)

Hint 1 — 공식을 "그대로" 옮기는 것이 golden model

srdhm/rdbpot은 위 의사코드를 한 줄씩 옮기면 됩니다. "더 깔끔한" 반올림(llround, (x + half) >> e)으로 바꾸면 음수 tie에서 1 LSB 차이가 나고, 그 순간 golden이 아닙니다. 64비트 곱((int64_t)a * b)을 잊으면 overflow(UB)입니다.

Hint 2 — 비교기는 "얼마나·어디서"를 같이 센다

원소마다 d = |hw - gold|를 구해 hist[d==0 ? 0 : d==1 ? 1 : 2]++, max_abs 갱신, d > tol이면 mismatches++, col_bad[n]++, 첫 번째면 (m, n) 저장. 이 네 가지 요약이 곧 버그의 지문(signature)입니다.

Hint 3 — 진단 규칙은 "공간 패턴 → 크기" 순서

먼저 어디서 틀렸나(마지막 partial tile 열에만? 한 열에만?)를 보고, 그다음 얼마나 틀렸나(최대 1이면 반올림)를 봅니다. 순서가 바뀌면 bias 누락(최대 3)이나 tile 버그가 엉뚱하게 분류됩니다. tile 경계 = tile * (N / tile).

4. 풀이

4.1 핵심 아이디어 — 양자화 데이터 경로

비트 폭을 먼저 말할 수 있어야 합니다. A − a_zp는 9비트(최대 ±255), 곱은 17비트(|p| <= 255 × 128 = 32 640), K = 32개를 더하면 17 + 5 = 22비트. 그래서 16비트 누산기(BUG_ACC16)는 틀리고, 32비트면 K가 2^15까지 안전합니다.

4.2 Tile 경계 버그 — 실패 위치가 원인을 말한다

이 그림에서 두 가지를 말합니다.

  • 위치가 원인을 가리킵니다. 실패가 열 ≥ 8에만 있으면 "remainder/partial tile 경로" 버그입니다. N = 16처럼 tile 배수인 shape만 테스트하면 이 버그는 영원히 안 보입니다 → stimulus에 N % TILE != 0인 shape을 반드시 넣습니다.
  • 값이 작으면 버그가 숨습니다. 행 2, 3은 같은 버그를 겪었지만 빠진 항(2·B, 1·B)이 scale ≈ 1/1000 아래로 사라졌습니다. 그래서 corner 값(−128, 127)을 섞는 stimulus가 필요합니다.

 * V11  AI Accelerator Validation: INT8 GEMM Golden Model + Bit-Exact Compare
 *
 * The NPU computes a quantized fully-connected / 1x1-conv layer as an int8 GEMM.
 * You write the C golden model the compiler team signs off on, a comparator that
 * characterises mismatches, and a seeded stimulus generator.
 *
 *   acc[m][n] = bias[n] + sum_k (A[m][k] - a_zp) * B[k][n]        int32 accumulate
 *   C[m][n]   = clamp(requant(acc, mult[c], shift[c]) + out_zp, act_min, act_max)
 *               c = n (per-channel) or 0 (per-tensor); relu -> act_min = out_zp
 *   A[M][K], B[K][N], C[M][N] row-major int8; weights symmetric (zero point 0).
 *
 *   requant(x, mult, shift) = RDBPOT(SRDHM(x, mult), shift)   (TFLite / gemmlowp)
 *     SRDHM(a, b): high 32 bits of 2*a*b, rounded with this exact nudge (note: a
 *                  negative tie rounds toward 0, e.g. -1.5 -> -1; bit-exact = formula-exact):
 *         if a == b == INT32_MIN return INT32_MAX;
 *         p = (int64)a * b;  nudge = p >= 0 ? 1<<30 : 1 - (1<<30);
 *         return (int32)((p + nudge) / 2^31);          (C division, truncates to 0)
 *     RDBPOT(x, e): x / 2^e rounded half away from zero, 0 <= e <= 31:
 *         mask = (1<<e) - 1; rem = x & mask; thr = (mask >> 1) + (x < 0);
 *         return (x >> e) + (rem > thr);               (arithmetic shift)
 *   real scale = mult / 2^31 / 2^shift,  mult in [2^30, 2^31)

int32_t srdhm(int32_t a, int32_t b)
{
    if (a == INT32_MIN && b == INT32_MIN) return INT32_MAX;
    int64_t p = (int64_t)a * b;
    int64_t nudge = p >= 0 ? (1LL << 30) : (1 - (1LL << 30));
    return (int32_t)((p + nudge) / (1LL << 31));
}

int32_t rdbpot(int32_t x, int e)
{
    int32_t mask = (int32_t)((1u << e) - 1u);
    int32_t rem = x & mask;
    int32_t thr = (mask >> 1) + (x < 0);
    return (x >> e) + (rem > thr);               /* >> on negative: arithmetic (gcc/clang) */
}

int8_t requant_i8(int32_t acc, int32_t mult, int shift, int32_t out_zp,
                  int32_t act_min, int32_t act_max)
{
    int32_t v = rdbpot(srdhm(acc, mult), shift) + out_zp;
    if (v < act_min) v = act_min;
    if (v > act_max) v = act_max;
    return (int8_t)v;
}

void gemm_ref(const int8_t *A, const int8_t *B, const int32_t *bias, int M, int K, int N,
              const QParams *q, int8_t *C, int32_t *acc_out)
{
    int32_t act_min = q->relu ? q->out_zp : -128;
    for (int m = 0; m < M; m++)
        for (int n = 0; n < N; n++) {
            int32_t acc = bias ? bias[n] : 0;
            for (int k = 0; k < K; k++)
                acc += ((int32_t)A[m * K + k] - q->a_zp) * (int32_t)B[k * N + n];
            int c = q->per_channel ? n : 0;
            C[m * N + n] = requant_i8(acc, q->mult[c], q->shift[c], q->out_zp, act_min, 127);
            if (acc_out) acc_out[m * N + n] = acc;
        }
}

void cmp_tensors(const int8_t *gold, const int8_t *hw, int M, int N, CmpMode mode, CmpReport *r)
{
    memset(r, 0, sizeof *r);
    r->first_m = r->first_n = -1;
    int32_t tol = (mode == CMP_TOL1) ? 1 : 0;
    for (int m = 0; m < M; m++)
        for (int n = 0; n < N; n++) {
            int32_t d = (int32_t)hw[m * N + n] - (int32_t)gold[m * N + n];
            if (d < 0) d = -d;
            r->hist[d == 0 ? 0 : d == 1 ? 1 : 2]++;
            if (d > r->max_abs) r->max_abs = d;
            if (d > tol) {
                if (r->mismatches == 0) { r->first_m = m; r->first_n = n; }
                r->mismatches++;
                r->col_bad[n]++;
            }
        }
}

Diag diagnose(const CmpReport *r, int N, int tile)
{
    if (r->mismatches == 0) return DIAG_PASS;
    int lo = N, hi = -1;
    for (int n = 0; n < N; n++)
        if (r->col_bad[n]) { if (n < lo) lo = n; hi = n; }
    int edge = (N / tile) * tile;                 /* first column of the partial tile */
    if (N % tile != 0 && lo >= edge) return DIAG_TILE_EDGE;
    if (lo == hi) return DIAG_ONE_CHANNEL;
    if (r->max_abs == 1) return DIAG_ROUNDING;
    return DIAG_CORRUPTION;
}

/*
 * LCG: s = s * 1664525 + 1013904223 (mod 2^32), one step per element.
 * If (s >> 8) % 8 == 0 the element is a corner value CORNER[(s >> 4) & 3]
 * with CORNER = { -128, 127, 0, zp }; otherwise it is (int8_t)(s >> 24).
 */
void gen_tensor(int8_t *t, size_t n, uint32_t seed, int8_t zp)
{
    const int8_t corner[4] = { -128, 127, 0, zp };
    uint32_t s = seed;
    for (size_t i = 0; i < n; i++) {
        s = s * 1664525u + 1013904223u;
        t[i] = ((s >> 8) % 8u == 0) ? corner[(s >> 4) & 3u] : (int8_t)(uint8_t)(s >> 24);
    }
}

/* ============ provided: NPU behavioural model with injectable bugs (do not edit) ============ */
/* Stands in for the RTL / FPGA image. Computes tile by tile, NPU_TILE output columns at a time. */

typedef enum { BUG_NONE, BUG_TRUNC_ROUND, BUG_ACC16, BUG_NO_BIAS_CH, BUG_TILE_EDGE } NpuBug;
#define NPU_BUG_CH 5          /* channel whose bias is dropped for BUG_NO_BIAS_CH */

static int32_t hw_requant(int32_t x, int32_t mult, int shift, bool trunc)
{
    int64_t p = (int64_t)x * mult;
    if (trunc) {                                  /* bug: floor instead of round, both steps */
        int32_t hi = (int32_t)(p >> 31);
        return hi >> shift;
    }
    int64_t nudge = p >= 0 ? (1LL << 30) : (1 - (1LL << 30));
    int32_t hi = (int32_t)((p + nudge) / (1LL << 31));
    int32_t mask = (int32_t)((1u << shift) - 1u);
    return (hi >> shift) + ((hi & mask) > (mask >> 1) + (hi < 0));
}

static void npu_gemm(const int8_t *A, const int8_t *B, const int32_t *bias, int M, int K, int N,
                     const QParams *q, int8_t *C, NpuBug bug)
{
    int32_t lo = q->relu ? q->out_zp : -128;
    for (int n0 = 0; n0 < N; n0 += NPU_TILE) {
        int w = (N - n0 < NPU_TILE) ? N - n0 : NPU_TILE;
        int kmax = (bug == BUG_TILE_EDGE && w < NPU_TILE) ? K - 1 : K;   /* remainder-path bug */
        for (int m = 0; m < M; m++)
            for (int j = 0; j < w; j++) {
                int n = n0 + j;
                int32_t acc = (bug == BUG_NO_BIAS_CH && n == NPU_BUG_CH) ? 0 : bias[n];
                for (int k = 0; k < kmax; k++) {
                    acc += ((int32_t)A[m * K + k] - q->a_zp) * (int32_t)B[k * N + n];
                    if (bug == BUG_ACC16) acc = (int16_t)(uint16_t)(uint32_t)acc;  /* 16-bit wrap */
                }
                int c = q->per_channel ? n : 0;
                int32_t v = hw_requant(acc, q->mult[c], q->shift[c], bug == BUG_TRUNC_ROUND) + q->out_zp;
                C[m * N + n] = (int8_t)(v < lo ? lo : v > 127 ? 127 : v);
            }
    }
}

    CHECK(srdhm(INT32_MIN, INT32_MIN) == INT32_MAX);     /* the one overflow case */

    CHECK(srdhm(3, 1 << 30) == 2);                       /* 1.5 rounds away from 0 */

    CHECK(rdbpot(4, 1) == 2 && rdbpot(-7, 2) == -2);     /* -1.75 -> -2 */

    CHECK(requant_i8(-1000, 0x60000000, 4, 10, 10, 127) == 10);    /* relu clamp */

    const int8_t B2[3 * 2] = { 1, -1,

                               3, 4 };
    const int32_t bias2[2] = { 10, -20 };
    const int32_t m1[1] = { 0x40000000 };     /* 0.5 */
    const int8_t  s1[1] = { 1 };              /* * 2^-1 -> scale 0.25 */
    QParams q2 = { 1, -1, m1, s1, false, false };
    int8_t C2[4]; int32_t acc2[4];

    CHECK(C2[0] == 37 && C2[1] == 22 && C2[2] == 94 && C2[3] == 123);
    q2.relu = true; q2.out_zp = -100;
    gemm_ref(A2, B2, bias2, 2, 3, 2, &q2, C2, NULL);
    CHECK(C2[0] == -62 && C2[1] == -77 && C2[2] == -5 && C2[3] == 24);

    /* 3. stimulus generator: deterministic, hits every corner value */
    int8_t g[64], g2[64];
    gen_tensor(g, 64, 1u, 5);
    gen_tensor(g2, 64, 1u, 5);
    CHECK(memcmp(g, g2, 64) == 0);
    CHECK(g[0] == 60 && g[1] == 94 && g[2] == -127 && g[3] == -76);
    int seen[4] = { 0 };
    for (int i = 0; i < 64; i++) {

        if (g[i] == 5) seen[3]++;

    int32_t bias[N], acc[M * N], mult[N];

        mult[n] = 0x40000000 + n * 0x02000000;   /* 0.5 .. 0.84 */
        shift[n] = 9;                            /* scale ~ 1/1000 .. 1/600 */
    }
    QParams q = { 3, -4, mult, shift, true, false };
    gemm_ref(A, B, bias, M, K, N, &q, gold, acc);
    CHECK(gold[0] == 12 && gold[1] == 50 && gold[11] == -3 && gold[M * N - 1] == -71);

    /* 5a. bug-free NPU is bit-exact */
    npu_gemm(A, B, bias, M, K, N, &q, hw, BUG_NONE);
    cmp_tensors(gold, hw, M, N, CMP_BITEXACT, &r);

    /* 5b. truncation instead of rounding: only +-1, fails bit-exact, passes tolerance */
    npu_gemm(A, B, bias, M, K, N, &q, hw, BUG_TRUNC_ROUND);
    cmp_tensors(gold, hw, M, N, CMP_BITEXACT, &r);

    CHECK(r.first_m == 0 && r.first_n == 0);
    CHECK(diagnose(&r, N, NPU_TILE) == DIAG_ROUNDING);
    cmp_tensors(gold, hw, M, N, CMP_TOL1, &r);
    CHECK(r.mismatches == 0);

    npu_gemm(A, B, bias, M, K, N, &q, hw, BUG_ACC16);

    CHECK(diagnose(&r, N, NPU_TILE) == DIAG_CORRUPTION);
    int big = 0, bad_small = 0;
    for (int i = 0; i < M * N; i++) {
        bool wide = acc[i] > INT16_MAX || acc[i] < INT16_MIN;
        if (wide) big++;
        if (gold[i] != hw[i] && !wide) bad_small++;
    }
    CHECK(big == 27 && bad_small == 0);        /* every failure is a wide accumulator */

    /* 5d. bias dropped on channel 5: one bad column, every row */
    npu_gemm(A, B, bias, M, K, N, &q, hw, BUG_NO_BIAS_CH);
    cmp_tensors(gold, hw, M, N, CMP_BITEXACT, &r);
    CHECK(r.mismatches == 6 && r.max_abs == 3 && r.col_bad[NPU_BUG_CH] == 6 && r.first_m == 0 && r.first_n == 5);
    CHECK(diagnose(&r, N, NPU_TILE) == DIAG_ONE_CHANNEL);

    /* 5e. last partial tile drops k = K-1: failures confined to columns >= 8 */
    npu_gemm(A, B, bias, M, K, N, &q, hw, BUG_TILE_EDGE);
    cmp_tensors(gold, hw, M, N, CMP_BITEXACT, &r);
    uint32_t below = 0;
    for (int n = 0; n < 8; n++) below += r.col_bad[n];

    CHECK(diagnose(&r, N, NPU_TILE) == DIAG_TILE_EDGE);
    CHECK(diagnose(&r, 16, NPU_TILE) != DIAG_TILE_EDGE);   /* N % 8 == 0: no partial tile */

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

코드 읽는 포인트

  • srdhm의 음수 tie: srdhm(-3, 1<<30)은 −1.5인데 결과는 −1(양수 1.5는 2). nudge가 1 − 2^30이고 C 나눗셈이 0 쪽으로 자르기 때문입니다. 반면 rdbpot(-5, 1)은 −3(0에서 먼 쪽). 이 비대칭까지 똑같아야 bit-exact입니다. 테스트 1번이 이것을 고정합니다.
  • gemm_ref는 acc_out으로 int32 누산값을 내보냅니다. 비교기는 출력만 보지만, 진단할 때는 중간값이 필요합니다(테스트 5c: 실패 27개가 정확히 |acc| > 32767인 원소와 일치 → 누산기 폭 버그 확정).
  • cmp_tensors의 hist·max_abs는 tolerance와 무관하게 전체 원소 기준입니다. TOL1 모드에서도 "±1이 37개 있었다"는 정보가 남아야 회귀를 추적할 수 있습니다.
  • diagnose는 휴리스틱입니다. 확정이 아니라 어디를 먼저 볼지 알려 주는 용도이고, 리포트에 first (m, n)과 col_bad를 그대로 남겨 RTL 엔지니어가 파형에서 그 좌표를 찾게 합니다.
  • gen_tensor는 (int8_t)(uint8_t)(s >> 24)로 변환합니다. 범위 밖 값을 signed로 바로 바꾸는 것은 implementation-defined라 두 단계로 씁니다.

4.5 복잡도

  • gemm_ref: 시간 O(M·K·N), 추가 메모리 O(1). 비교·진단: O(M·N) + O(N).
  • 실제 층(예: 4096×4096)은 C 모델이 초 단위라 괜찮지만, 시뮬레이터 위의 RTL은 그 층 하나에 몇 시간입니다. 그래서 RTL 시뮬레이션에는 작은 shape + 경계 shape를, FPGA/에뮬레이터·실리콘에는 실제 네트워크 층을 씁니다.

5. 임베디드 관점으로 말할 것

  • 검증 루프: (1) seed로 A/B/bias 생성 → (2) DMA로 DDR/SRAM에 올리고 NPU 디스크립터 실행 → (3) 결과를 읽어 golden과 비교 → (4) 실패하면 seed·shape·첫 좌표·col_bad를 로그. seed만 있으면 실패를 재현할 수 있다는 것이 핵심입니다.
  • bare-metal에서: golden은 같은 SoC의 CPU(A-core)에서 돌려도 되고, 미리 계산한 기대값을 이미지에 넣어도 됩니다. 캐시가 있으면 NPU가 쓴 버퍼를 읽기 전에 cache invalidate(DMA coherency) 해야 하고, 이것을 빠뜨린 "가짜 mismatch"가 첫 실리콘에서 가장 흔합니다 → V3.
  • 성능 측정은 같은 하네스로: 같은 층을 돌리며 사이클 카운터로 latency, 2·M·K·N / time으로 실효 TOPS, 피크 대비 MAC utilization을 계산합니다 → V4.
  • 커버리지: shape(정확히 나눠지는/안 나눠지는 M, N, K), per-tensor/per-channel, relu on/off, zero point 극값, 포화가 일어나는 scale을 축으로 cross coverage를 잡습니다 → V5.

5.1 면접관(HW 출신 Sr Manager)이 파고들 포인트

  • "Golden model이 맞다는 건 어떻게 아나?" — 컴파일러 팀의 레퍼런스(TFLite 커널 등)와 같은 입력으로 교차 비교하고, 손으로 계산 가능한 작은 케이스(테스트 2번), 경계값(INT32_MIN·tie) 단위 테스트로 고정합니다. golden과 HW가 다르면 세 번째 구현(예: Python/NumPy)으로 누가 틀렸는지 판정합니다. "I don't trust a golden model until it matches the framework reference on real layers and passes hand-computed corner cases, including tie rounding."
  • "FPGA/HAPS에서 통과했는데 실리콘에서 실패하면?" — 같은 seed·shape로 재현 → 실패 위치 패턴(tile, 채널, 특정 SRAM bank 주소)을 봅니다. 패턴이 데이터 무관하고 주파수·전압에 따라 변하면 타이밍/전원 문제라 shmoo로 넘기고(V7), 항상 같은 좌표면 기능 버그나 메모리 결함입니다(V1). "If the failing coordinates move with voltage and frequency it's margin; if they're stable and data-dependent it's logic — that split decides who gets the bug."
  • "테스트가 몇 개면 충분한가? 시간은?" — 무작위만으로는 tile 경계·포화 같은 희귀 경로가 안 나옵니다. directed(경계 shape, corner 값) + random(seed sweep) + 실제 네트워크 층의 3단 구성으로 하고, RTL 시뮬레이션은 작은 shape, 에뮬레이터는 층 단위, 실리콘은 전체 네트워크를 돌립니다. "Directed corners for the rare paths, seeded random for breadth, and real network layers for realism — each on the platform fast enough to run it."
  • "±1 허용하면 안 되나?" — 최종 정확도엔 영향이 거의 없어도, ±1 차이는 HW와 컴파일러 모델이 다르다는 신호라 다음 층에서 누적되고, 무엇보다 진짜 버그를 가립니다(TRUNC 버그는 TOL1에서 0개). 기본은 bit-exact, 허용은 명시적 waiver로만. "Bit-exact is the default because a tolerance hides real bugs — the truncation bug here passes a ±1 check completely."

6. Follow-up 질문과 답

Follow-up (English)답
Why does bit-exact matter?컴파일러 팀은 golden model로 양자화 정확도를 검증하고 배포합니다. HW가 1 LSB라도 다르면 그 검증이 무효가 되고, 층을 지나며 차이가 누적됩니다. 또 bit-exact여야 diff 0이 아닌 모든 것을 버그 후보로 볼 수 있습니다.
How do you generate stimuli?세 종류: random(seed 기반 LCG/PRBS, 재현 가능), directed corner(−128/127/0/zp, 포화 scale, K 최대, N % TILE != 0), 실제 네트워크 층(실제 가중치·활성값 분포). 실패 시 seed와 shape만 로그하면 재현됩니다.
How do you compute TOPS and MAC utilization?TOPS = 2 × MAC 수 × 클럭(1 MAC = 곱+덧셈 2 ops). 예: 1 600 sparse TOPS는 2:4 sparsity 기준이라 dense로는 800 TOPS, 2 GHz면 800e12 / (2 × 2e9) = 20만 MAC. 실효 utilization = 측정 ops/s ÷ 피크; 작은 층·partial tile·DMA 대기에서 크게 떨어집니다.
Memory-bound vs compute-bound?roofline: 산술 강도 = ops / DRAM bytes. GEMM 6×32×12는 4 608 ops / 648 B ≈ 7 ops/B. batch 1 FC(1×4096×4096)는 약 2 ops/B라 거의 항상 memory bound. 기계 균형점(피크 TOPS ÷ DRAM BW, 예: 800 TOPS / 200 GB/s = 4 000 ops/B)보다 낮으면 BW가 상한입니다.
How do you validate DMA + SRAM tiling?tile 크기와 맞지 않는 shape, SRAM bank 경계를 넘는 버퍼, double buffering(ping-pong) 전환 시점을 directed로 넣고, 출력 비교 외에 guard 영역(버퍼 앞뒤 canary)이 안 덮였는지 확인합니다.
How do you choose accumulator width?8 + 8 + 1(zp) + log2(K) 비트가 필요합니다. K = 4 096이면 17 + 12 = 29비트 → 32비트 누산기면 충분, 16비트면 곱 두 개(65 280)만 더해도 넘칩니다(테스트 5c).
What about sparsity?2:4 구조적 sparsity는 4개 중 2개 0인 가중치를 압축하고 metadata로 위치를 기록해 MAC을 건너뜁니다. 검증은 압축/메타데이터 경로를 따로 directed로 넣고, 결과는 dense golden과 bit-exact 비교합니다.
What is a power virus test?MAC 배열을 최대로 토글시키는 패턴(교대 비트, 최대 utilization 층)으로 최대 전류·di/dt를 만들어 전원망(IR drop)과 열을 검증합니다. 같은 하네스로 돌리고 비교까지 해서 "전원 스트레스 중에도 bit-exact"를 확인합니다.
Pre-silicon: FPGA/HAPS vs emulator?RTL 시뮬레이션 ~Hz–kHz(가시성 최고), 에뮬레이터(Palladium/Veloce) ~1 MHz(가시성 좋음, 비쌈), FPGA 프로토타입(HAPS) ~10–100 MHz(SW 개발·긴 테스트, 디버그 가시성 낮음). 같은 bare-metal 테스트를 세 곳에서 그대로 돌리도록 HAL을 분리해 두는 것이 핵심입니다.

7. 자주 하는 실수

  • SRDHM을 llround((double)a * b / 2^31)(tie는 0에서 먼 쪽)로 단순화 → 음수 tie에서 1 차이 (테스트 1번 srdhm(-3, 1<<30) == -1). RDBPOT를 (x + half) >> e로 쓰면 반대로 rdbpot(-5, 1)이 −2가 되어 틀립니다
  • a * b를 32비트로 곱함 → overflow UB, UBSan이 잡음
  • zero point를 B 쪽이나 출력 뒤에 적용, 또는 a_zp를 빼지 않음 → 테스트 2번 acc 불일치
  • relu에서 act_min = 0으로 둠 → out_zp가 0이 아니면 틀림 (테스트 2번 relu, out_zp = −100)
  • per-channel인데 mult[0]만 씀 → 열마다 scale이 달라 대부분 불일치
  • 비교기가 TOL1 모드에서 hist·max_abs까지 버림 → ±1 경향 추적 불가
  • 진단 순서를 "크기 먼저"로 둠 → TILE 버그 중 |d| = 1인 원소가 많은 경우 ROUNDING으로 오분류
  • tile 배수 shape(N = 16)만 테스트 → partial tile 버그를 영원히 못 봄
