IDV5
PriorityP1
Patterntable-driven registry + filter + wrap-safe timing + bounded snprintf report

0. 문제 한국어로 먼저 보기

영어 원문(§1)을 읽기 전에 무슨 상황이고 뭘 만들어야 하는지만 빠르게 잡는 요약입니다. 풀이 힌트는 없습니다.

한 줄 요약: SoC 검증 펌웨어의 테스트 표를 돌리는 test runner(tf_run)와, 결과를 UART 로그용 텍스트로 찍는 결과/coverage 리포트(tf_report)를 짭니다.

상황

  • 검증 펌웨어 안에 테스트 케이스 표(TestCase 배열)가 고정으로 들어 있습니다. 테스트마다 검사하는 block(예: PCIE, DDR)과 검증하는 requirement(req_id, 예: REQ-PCIE-001)가 붙어 있습니다.
  • 같은 이미지가 FPGA 프로토타입과 실리콘 양쪽에서 돕니다(Platform: PLAT_FPGA / PLAT_SILICON).
  • 호스트 쪽 Python 스크립트가 UART 로그를 파싱해서 결과 DB와 coverage 리포트를 만듭니다. 그래서 출력 형식이 정해져 있습니다.
  • 시간은 HAL 함수 tf_now_ms()로 잽니다. uint32_t ms 카운터라 wrap(0xFFFFFFFF 다음 0) 됩니다. stub 아래쪽 harness가 가짜 clock과 가짜 테스트 함수를 제공합니다.
  • 용어
    • 테스트 함수 fn(ctx): 0이면 pass, 음수 errno면 fail
    • timeout_ms: 0이면 제한 없음
    • TF_SKIP_ON_FPGA: FPGA에서는 돌리지 않는 테스트
    • TF_DESTRUCTIVE: 되돌릴 수 없는 테스트(예: OTP burn). allow_destructive가 켜져야만 돌림
    • coverage: requirement 중 몇 개가 PASS한 테스트로 검증됐는지의 비율

구현할 것

함수하는 일규칙
tf_run(tests, n, cfg, res, res_cap)표의 테스트를 골라서 돌리고 결과를 res에 기록selected = block_filter == NULL이거나 block이 filter와 같음. 선택 안 된 테스트는 기록도 안 함
선택된 개수 > res_cap → 아무것도 안 돌리고 -ENOSPC
결과는 표 순서대로, 결과 개수 반환
tf_report(res, nres, reqs, nreq, buf, cap)결과를 정해진 텍스트 형식으로 buf에 씀최대 cap 바이트, cap > 0이면 항상 NUL 종료
snprintf처럼 필요했던 전체 길이(NUL 제외) 반환
cap == 0이면 buf가 NULL일 수 있음. 모든 줄은 \n으로 끝남
tf_status_name(s)상태 이름 문자열 ("PASS" 등)이미 제공됨

tf_run이 선택된 테스트마다 정하는 상태

  1. SKIP: plat == PLAT_FPGA이고 TF_SKIP_ON_FPGA가 붙었거나, TF_DESTRUCTIVE인데 allow_destructive가 false. 이때 fn은 호출 안 함, rc = 0, ms = 0.
  2. 그 밖에는 실행: start = tf_now_ms() → rc = fn(cfg->ctx) → ms = tf_now_ms() - start (wrap 돼도 맞아야 함).
  3. timeout_ms != 0이고 ms > timeout_ms → TIMEOUT (rc는 그대로 둠).
  4. 아니면 rc == 0 → PASS, 그 외 → FAIL.

tf_report 출력 순서

  • RESULT,<id>,<status>,<rc>,<ms>: 결과마다 한 줄, 순서대로
  • SUMMARY,total=..,pass=..,fail=..,skip=..,timeout=..: 한 줄
  • COVERAGE,<block>,<covered>/<total>,<pct>%: block마다 한 줄, reqs에 처음 나온 순서
  • COVERAGE,ALL,<covered>/<total>,<pct>%: 한 줄
  • UNCOVERED,<req_id>: covered 안 된 requirement마다 한 줄, reqs 순서
  • requirement가 covered = 같은 req_id를 가진 결과 중 PASS가 하나라도 있음
  • pct = covered * 100 / total 내림, total == 0이면 0

예시를 말로 풀면

  • FPGA, filter 없음, destructive 금지로 6개 테스트를 돌립니다. clock은 0xFFFFFFF8에서 시작해서 도는 중에 wrap 됩니다. 그래도 ms는 12, 3, 40, 600처럼 정확해야 합니다.
    • PCIE-LINK-001: 12 ms, rc 0 → PASS
    • PCIE-LINK-002: rc -5 → FAIL
    • PCIE-GEN4-003: SKIP_ON_FPGA인데 FPGA → SKIP (0,0)
    • DDR-TRAIN-001: 40 ms, timeout 40 → 40 > 40이 아니라서 PASS
    • DDR-STRESS-002: 600 ms > 500 → TIMEOUT, rc 0은 그대로 찍힘
    • OTP-BURN-001: DESTRUCTIVE인데 금지 → SKIP
  • 그래서 tf_run은 6을 반환하고 SUMMARY는 pass 2, fail 1, skip 2, timeout 1입니다.
  • Coverage: requirement 7개 중 PASS로 덮인 건 REQ-PCIE-001, REQ-DDR-001 2개뿐입니다.
    • PCIE 1/3 = 33%, DDR 1/2 = 50%, OTP 0/1, ISP 0/1 (ISP는 테스트가 아예 없음)
    • ALL 2/7 = 200/7 = 28.57… → 내림해서 28%
  • 나머지 5개 requirement가 UNCOVERED 줄로 나옵니다. 전체 텍스트 길이는 451바이트라서 tf_report가 451을 반환합니다.

지켜야 할 조건

  • C11, single core, OS 없음. tf_now_ms()는 uint32_t이고 wrap 됨.
  • 표의 문자열은 static, NUL 종료. 테스트와 requirement는 수백 개 정도 (O(n·m) 매칭이면 충분).
  • 이 버전에서는 테스트 함수가 스스로 리턴함(진짜 hang 없음). timeout은 리턴한 뒤에 판정.
  • malloc 금지.

1. Problem

The SoC validation firmware has a static table of test cases. Each test is tagged with the block it exercises and the requirement it verifies. The same image runs on the FPGA prototype and on silicon. A host-side Python script parses the UART log and feeds a results database and a coverage report.

uint32_t tf_now_ms(void);                        /* HAL: free-running ms clock, wraps */

typedef enum { PLAT_FPGA = 0, PLAT_SILICON = 1 } Platform;
#define TF_SKIP_ON_FPGA  (1u << 0)
#define TF_DESTRUCTIVE   (1u << 1)

typedef struct {
    const char *id;  const char *block;  const char *req_id;
    int (*fn)(void *ctx);   /* 0 = pass, negative errno = fail */
    uint32_t timeout_ms;    /* 0 = no limit */
    uint32_t flags;
} TestCase;
typedef struct { const char *req_id; const char *block; } Requirement;
typedef struct { Platform plat; const char *block_filter; bool allow_destructive; void *ctx; } RunCfg;
typedef enum { ST_PASS = 0, ST_FAIL, ST_SKIP, ST_TIMEOUT } Status;
typedef struct { const TestCase *tc; Status st; int rc; uint32_t ms; } TestResult;
const char *tf_status_name(Status s);            /* provided: "PASS" ... */

int    tf_run(const TestCase *tests, size_t n, const RunCfg *cfg, TestResult *res, size_t res_cap);
size_t tf_report(const TestResult *res, size_t nres, const Requirement *reqs, size_t nreq,
                 char *buf, size_t cap);

tf_run

  • A test is selected if cfg->block_filter == NULL or its block equals the filter. Unselected tests are not recorded at all.
  • If the number of selected tests is larger than res_cap, run nothing and return -ENOSPC.
  • A selected test is SKIP (rc = 0, ms = 0, fn not called) if plat == PLAT_FPGA && (flags & TF_SKIP_ON_FPGA), or if (flags & TF_DESTRUCTIVE) && !allow_destructive.
  • Otherwise: start = tf_now_ms(); rc = fn(cfg->ctx); ms = tf_now_ms() - start; (wrap-safe). If timeout_ms != 0 && ms > timeout_ms → TIMEOUT (keep rc), else rc == 0 → PASS, otherwise FAIL.
  • Results are in table order. Return the number of results.

tf_report writes text into buf (at most cap bytes, always NUL-terminated when cap > 0) and returns the full length it needed, excluding the NUL, like snprintf. buf may be NULL when cap == 0. Every line ends with \n:

RESULT,<id>,<status>,<rc>,<ms>                  one per result, in order
SUMMARY,total=<n>,pass=<p>,fail=<f>,skip=<s>,timeout=<t>
COVERAGE,<block>,<covered>/<total>,<pct>%       one per block, in first-appearance order of reqs
COVERAGE,ALL,<covered>/<total>,<pct>%
UNCOVERED,<req_id>                              one per uncovered requirement, in reqs order

A requirement is covered if at least one result with the same req_id has status PASS. pct = covered * 100 / total rounded down (0 when total == 0). No malloc.

Constraints

  • C11, single core, no OS. tf_now_ms() is uint32_t and wraps.
  • Strings in the table are static and NUL-terminated. Up to a few hundred tests and requirements (O(n·m) matching is fine).
  • The test function returns by itself in this version (no real hang). The timeout is detected after it returns.

Clarifying questions to ask (first 3 minutes)

  1. If a test hangs forever, is post-hoc timing enough, or do you expect a watchdog to recover?
  2. Is a test that passes but takes longer than its timeout a PASS or a TIMEOUT?
  3. Should filtered-out tests appear in the report as SKIP, or not at all?
  4. Does a requirement need all of its tests to pass, or at least one?
  5. What if the report does not fit in the buffer — truncate, or stream line by line to the UART?
  6. Is the log format fixed by an existing host parser? Any escaping needed (commas in ids)?

/*
 * V5  Bare-metal Test Framework: registry, timeouts and coverage report
 *
 * The validation firmware has a static table of test cases. Each test is tagged with the
 * SoC block it exercises and the requirement it verifies. The same image runs on the FPGA
 * prototype and on silicon. A host-side Python script parses the UART log.
 *
 * Implement:
 *   tf_run(tests, n, cfg, res, res_cap)
 *     - select tests whose block equals cfg->block_filter (NULL = all blocks); others are
 *       not recorded at all.
 *     - a selected test is SKIP (rc 0, ms 0, fn not called) if
 *         (cfg->plat == PLAT_FPGA && flags & TF_SKIP_ON_FPGA) or
 *         (flags & TF_DESTRUCTIVE && !cfg->allow_destructive)
 *     - otherwise: start = tf_now_ms(); rc = fn(cfg->ctx); ms = tf_now_ms() - start (wrap-safe)
 *         ms > timeout_ms (timeout_ms != 0)  -> TIMEOUT (rc kept)
 *         else rc == 0 -> PASS, rc != 0 -> FAIL

 *     would have been written (like snprintf), so the caller can retry with a bigger buffer:

 *       COVERAGE,<block>,<covered>/<total>,<pct>%      per block, first-appearance order in reqs
 *       COVERAGE,ALL,<covered>/<total>,<pct>%
 *       UNCOVERED,<req_id>                             in reqs order
 *     A requirement is covered if at least one result with the same req_id is PASS.
 *     pct = covered * 100 / total, rounded down (0 if total == 0). Every line ends with '\n'.
 *   No malloc.
 *
 * Build & run:  ./run.sh V5

/* =====================================================================
 * Test harness: fake ms clock + fake tests (do not edit)
 * ===================================================================== */
static uint32_t g_now;
static uint32_t g_calls;
uint32_t tf_now_ms(void) { return g_now; }
static void busy_ms(uint32_t ms) { g_now += ms; }

static int t_link_ok(void *ctx)   { (void)ctx; g_calls++; busy_ms(12);  return 0; }
static int t_link_eio(void *ctx)  { (void)ctx; g_calls++; busy_ms(3);   return -EIO; }
static int t_ddr_train(void *ctx) { (void)ctx; g_calls++; busy_ms(40);  return 0; }   /* == timeout */
static int t_ddr_hang(void *ctx)  { (void)ctx; g_calls++; busy_ms(600); return 0; }   /* > timeout */

static const TestCase TESTS[] = {
    { "PCIE-LINK-001",  "PCIE", "REQ-PCIE-001", t_link_ok,   100, 0 },
    { "PCIE-LINK-002",  "PCIE", "REQ-PCIE-002", t_link_eio,  100, 0 },
    { "PCIE-GEN4-003",  "PCIE", "REQ-PCIE-003", t_link_ok,   100, TF_SKIP_ON_FPGA },
    { "DDR-TRAIN-001",  "DDR",  "REQ-DDR-001",  t_ddr_train,  40, 0 },
    { "DDR-STRESS-002", "DDR",  "REQ-DDR-002",  t_ddr_hang,  500, 0 },
    { "OTP-BURN-001",   "OTP",  "REQ-OTP-001",  t_link_ok,   100, TF_DESTRUCTIVE },
};

int main(void)
{

    char buf[1024];
    int k;

    /* 1. full suite on FPGA (clock wraps during the run): mixed statuses + exact report */
    g_now = 0xFFFFFFF8u; g_calls = 0;

    CHECK(g_calls == 4);                                   /* 2 skipped tests not called */

    CHECK(k == 6 && res[3].st == ST_PASS && res[3].ms == 40);         /* ms == timeout is OK */
    CHECK(k == 6 && res[4].st == ST_TIMEOUT && res[4].ms == 600);

    CHECK(k == 6 && g_calls == 6);
    CHECK(k == 6 && res[2].st == ST_PASS && res[5].st == ST_PASS);

    CHECK(strstr(buf, "SUMMARY,total=6,pass=4,fail=1,skip=0,timeout=1\n") != NULL);
    CHECK(strstr(buf, "COVERAGE,PCIE,2/3,66%\n") != NULL);
    CHECK(strstr(buf, "COVERAGE,ALL,4/7,57%\n") != NULL);
    CHECK(strstr(buf, "UNCOVERED,REQ-OTP-001") == NULL);

    /* 3. block filter: only DDR tests are recorded; other blocks show as uncovered */

    RunCfg ddr = { PLAT_FPGA, "DDR", false, NULL };
    k = tf_run(TESTS, NT, &ddr, res, 8);
    CHECK(k == 2 && g_calls == 2);
    CHECK(k == 2 && strcmp(res[0].tc->id, "DDR-TRAIN-001") == 0 && res[1].st == ST_TIMEOUT);
    tf_report(res, k > 0 ? (size_t)k : 0, REQS, NR, buf, sizeof buf);
    CHECK(strstr(buf, "SUMMARY,total=2,pass=1,fail=0,skip=0,timeout=1\n") != NULL);
    CHECK(strstr(buf, "COVERAGE,PCIE,0/3,0%\n") != NULL);
    CHECK(strstr(buf, "COVERAGE,ALL,1/7,14%\n") != NULL);

    /* 4. result buffer too small: nothing runs */
    g_calls = 0;
    CHECK(tf_run(TESTS, NT, &fpga, res, 5) == -ENOSPC && g_calls == 0);
    CHECK(tf_run(TESTS, NT, &ddr, res, 2) == 2);           /* exactly enough after filtering */

    /* 5. report buffer too small: truncated, NUL-terminated, returns the needed length */
    g_now = 0;
    k = tf_run(TESTS, NT, &fpga, res, 8);
    char small[40];
    memset(small, 'X', sizeof small);
    len = tf_report(res, k > 0 ? (size_t)k : 0, REQS, NR, small, sizeof small);
    CHECK(len == strlen(EXPECT_FPGA));
    CHECK(small[sizeof small - 1] == '\0');
    CHECK(strncmp(small, EXPECT_FPGA, sizeof small - 1) == 0);
    CHECK(tf_report(res, k > 0 ? (size_t)k : 0, REQS, NR, NULL, 0) == strlen(EXPECT_FPGA));

    /* 6. empty run: no results, every requirement uncovered, no divide-by-zero */
    len = tf_report(res, 0, NULL, 0, buf, sizeof buf);
    CHECK(strcmp(buf, "SUMMARY,total=0,pass=0,fail=0,skip=0,timeout=0\nCOVERAGE,ALL,0/0,0%\n") == 0);
    CHECK(len == strlen(buf));

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

3. 힌트 (막힐 때 하나씩)

Hint 1 — 판정 순서를 먼저 고정

선택(filter) → SKIP 조건 → 실행 → TIMEOUT → PASS/FAIL 순서입니다. TIMEOUT 검사가 rc 검사보다 먼저여야 "늦게 끝났지만 rc = 0"인 테스트(DDR-STRESS-002)가 PASS로 잡히지 않습니다. 경계는 ms > timeout_ms라서 정확히 40 ms인 DDR-TRAIN-001은 PASS입니다.

Hint 2 — snprintf 누적 헬퍼 하나

put(buf, cap, &len, fmt, ...)를 만듭니다. 안에서 len < cap이면 buf + len, 남은 공간 cap - len으로 vsnprintf를 부르고, 아니면 vsnprintf(NULL, 0, ...)로 길이만 셉니다. 그리고 반환값을 항상 len에 더합니다. 그러면 잘려도 마지막에 len이 필요한 전체 길이가 되고, vsnprintf가 NUL을 붙여 줍니다.

Hint 3 — 블록별 커버리지를 malloc 없이

블록 목록을 따로 만들지 않아도 됩니다. reqs[i]의 block이 reqs[0..i-1]에 처음 나오는 것일 때만, j >= i를 다시 훑어서 같은 block의 total/covered를 셉니다. O(m²)이지만 m은 수백 개라 문제없습니다.

4. 풀이

4.1 핵심 아이디어 — 파이프라인

타깃 쪽은 "테이블 → 고르기 → 돌리기 → 결과 배열 → 텍스트" 다섯 단계이고, 그 텍스트를 호스트 Python이 받아 DB와 traceability 도구로 넘깁니다. 펌웨어는 판정과 한 줄 기록까지만 책임지고, 집계·이력·그래프는 호스트가 합니다.

4.2 커버리지 매트릭스

커버리지가 "테스트를 돌렸는가"가 아니라 "PASS 증거가 있는가" 라는 점이 핵심입니다. SKIP, FAIL, TIMEOUT은 모두 증거가 아닙니다. 그래서 같은 테이블이라도 FPGA에서는 2/7, 실리콘에서는 4/7이 나옵니다. 필터를 걸면 다른 블록의 requirement는 이번 실행 기준으로 uncovered로 나옵니다(테스트 3번: PCIE 0/3) — 리포트는 "이 실행"의 증거만 말합니다.

💡 정답 코드 펼치기 (30분 풀어 본 다음에)
solution.c
/*
 * V5  Bare-metal Test Framework: registry, timeouts and coverage report
 * Reference solution.
 *
 * The validation firmware has a static table of test cases. Each test is tagged with the
 * SoC block it exercises and the requirement it verifies. The same image runs on the FPGA
 * prototype and on silicon. A host-side Python script parses the UART log.
 *
 * Implement:
 *   tf_run(tests, n, cfg, res, res_cap)
 *     - select tests whose block equals cfg->block_filter (NULL = all blocks); others are
 *       not recorded at all.
 *     - a selected test is SKIP (rc 0, ms 0, fn not called) if
 *         (cfg->plat == PLAT_FPGA && flags & TF_SKIP_ON_FPGA) or
 *         (flags & TF_DESTRUCTIVE && !cfg->allow_destructive)
 *     - otherwise: start = tf_now_ms(); rc = fn(cfg->ctx); ms = tf_now_ms() - start (wrap-safe)
 *         ms > timeout_ms (timeout_ms != 0)  -> TIMEOUT (rc kept)
 *         else rc == 0 -> PASS, rc != 0 -> FAIL
 *     - results in table order; returns the number of results.
 *       If res_cap is smaller than the number of selected tests, run NOTHING and return -ENOSPC.
 *   tf_report(res, nres, reqs, nreq, buf, cap)
 *     Writes (bounded, always NUL-terminated if cap > 0) and returns the FULL length that
 *     would have been written (like snprintf), so the caller can retry with a bigger buffer:
 *       RESULT,<id>,<status>,<rc>,<ms>                 one line per result, in order
 *       SUMMARY,total=<n>,pass=<p>,fail=<f>,skip=<s>,timeout=<t>
 *       COVERAGE,<block>,<covered>/<total>,<pct>%      per block, first-appearance order in reqs
 *       COVERAGE,ALL,<covered>/<total>,<pct>%
 *       UNCOVERED,<req_id>                             in reqs order
 *     A requirement is covered if at least one result with the same req_id is PASS.
 *     pct = covered * 100 / total, rounded down (0 if total == 0). Every line ends with '\n'.
 *   No malloc.
 *
 * Build & run:  ./run.sh V5 sol
 */
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>
#include <stdarg.h>
#include <errno.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

/* ---------------- framework types (provided) ---------------- */
uint32_t tf_now_ms(void);                       /* HAL: free-running ms clock, wraps */

typedef enum { PLAT_FPGA = 0, PLAT_SILICON = 1 } Platform;
#define TF_SKIP_ON_FPGA  (1u << 0)              /* needs real PHY / clocks / analog */
#define TF_DESTRUCTIVE   (1u << 1)              /* burns fuses, resets the board, ... */

typedef struct {
    const char *id;          /* "PCIE-LINK-001" */
    const char *block;       /* "PCIE" */
    const char *req_id;      /* "REQ-PCIE-001" */
    int (*fn)(void *ctx);    /* 0 = pass, negative errno = fail */
    uint32_t timeout_ms;     /* 0 = no limit */
    uint32_t flags;
} TestCase;

typedef struct { const char *req_id; const char *block; } Requirement;

typedef struct {
    Platform    plat;
    const char *block_filter;    /* NULL = all blocks */
    bool        allow_destructive;
    void       *ctx;             /* passed to every test */
} RunCfg;

typedef enum { ST_PASS = 0, ST_FAIL, ST_SKIP, ST_TIMEOUT } Status;
const char *tf_status_name(Status s)      /* provided */
{
    static const char *const name[] = { "PASS", "FAIL", "SKIP", "TIMEOUT" };
    return name[s];
}

typedef struct { const TestCase *tc; Status st; int rc; uint32_t ms; } TestResult;

/* ---------------- framework: your code ---------------- */

static bool selected(const TestCase *t, const RunCfg *cfg)
{
    return cfg->block_filter == NULL || strcmp(t->block, cfg->block_filter) == 0;
}

int tf_run(const TestCase *tests, size_t n, const RunCfg *cfg, TestResult *res, size_t res_cap)
{
    size_t need = 0;
    for (size_t i = 0; i < n; i++) if (selected(&tests[i], cfg)) need++;
    if (need > res_cap) return -ENOSPC;          /* never half-run a suite */

    size_t k = 0;
    for (size_t i = 0; i < n; i++) {
        const TestCase *t = &tests[i];
        if (!selected(t, cfg)) continue;
        TestResult *r = &res[k++];
        *r = (TestResult){ t, ST_SKIP, 0, 0 };

        if ((cfg->plat == PLAT_FPGA && (t->flags & TF_SKIP_ON_FPGA)) ||
            ((t->flags & TF_DESTRUCTIVE) && !cfg->allow_destructive))
            continue;

        uint32_t start = tf_now_ms();
        r->rc = t->fn(cfg->ctx);
        r->ms = tf_now_ms() - start;             /* wrap-safe elapsed */
        if (t->timeout_ms != 0 && r->ms > t->timeout_ms) r->st = ST_TIMEOUT;
        else r->st = (r->rc == 0) ? ST_PASS : ST_FAIL;
    }
    return (int)k;
}

/* snprintf-style append: writes what fits, always counts the full length */
static void put(char *buf, size_t cap, size_t *len, const char *fmt, ...)
{
    va_list ap;
    va_start(ap, fmt);
    char *dst = (*len < cap) ? buf + *len : NULL;
    size_t room = (*len < cap) ? cap - *len : 0;
    int w = vsnprintf(dst, room, fmt, ap);
    va_end(ap);
    if (w > 0) *len += (size_t)w;
}

static bool req_covered(const char *req, const TestResult *res, size_t nres)
{
    for (size_t i = 0; i < nres; i++)
        if (res[i].st == ST_PASS && strcmp(res[i].tc->req_id, req) == 0) return true;
    return false;
}

static unsigned pct(size_t c, size_t t) { return t ? (unsigned)(c * 100u / t) : 0u; }

size_t tf_report(const TestResult *res, size_t nres, const Requirement *reqs, size_t nreq,
                 char *buf, size_t cap)
{
    size_t len = 0;
    size_t cnt[4] = { 0 };
    if (cap > 0) buf[0] = '\0';

    for (size_t i = 0; i < nres; i++) {
        const TestResult *r = &res[i];
        cnt[r->st]++;
        put(buf, cap, &len, "RESULT,%s,%s,%d,%lu\n",
            r->tc->id, tf_status_name(r->st), r->rc, (unsigned long)r->ms);
    }
    put(buf, cap, &len, "SUMMARY,total=%zu,pass=%zu,fail=%zu,skip=%zu,timeout=%zu\n",
        nres, cnt[ST_PASS], cnt[ST_FAIL], cnt[ST_SKIP], cnt[ST_TIMEOUT]);

    size_t all_cov = 0;
    for (size_t i = 0; i < nreq; i++) {
        bool first = true;                       /* first appearance of this block? */
        for (size_t j = 0; j < i; j++)
            if (strcmp(reqs[j].block, reqs[i].block) == 0) { first = false; break; }
        if (req_covered(reqs[i].req_id, res, nres)) all_cov++;
        if (!first) continue;

        size_t tot = 0, cov = 0;
        for (size_t j = i; j < nreq; j++) {
            if (strcmp(reqs[j].block, reqs[i].block) != 0) continue;
            tot++;
            if (req_covered(reqs[j].req_id, res, nres)) cov++;
        }
        put(buf, cap, &len, "COVERAGE,%s,%zu/%zu,%u%%\n", reqs[i].block, cov, tot, pct(cov, tot));
    }
    put(buf, cap, &len, "COVERAGE,ALL,%zu/%zu,%u%%\n", all_cov, nreq, pct(all_cov, nreq));

    for (size_t i = 0; i < nreq; i++)
        if (!req_covered(reqs[i].req_id, res, nres))
            put(buf, cap, &len, "UNCOVERED,%s\n", reqs[i].req_id);
    return len;
}

/* =====================================================================
 * Test harness: fake ms clock + fake tests (do not edit)
 * ===================================================================== */
static uint32_t g_now;

static void busy_ms(uint32_t ms) { g_now += ms; }

static int t_link_ok(void *ctx)   { (void)ctx; g_calls++; busy_ms(12);  return 0; }
static int t_link_eio(void *ctx)  { (void)ctx; g_calls++; busy_ms(3);   return -EIO; }
static int t_ddr_train(void *ctx) { (void)ctx; g_calls++; busy_ms(40);  return 0; }   /* == timeout */
static int t_ddr_hang(void *ctx)  { (void)ctx; g_calls++; busy_ms(600); return 0; }   /* > timeout */

static const TestCase TESTS[] = {
    { "PCIE-LINK-001",  "PCIE", "REQ-PCIE-001", t_link_ok,   100, 0 },
    { "PCIE-LINK-002",  "PCIE", "REQ-PCIE-002", t_link_eio,  100, 0 },

코드 읽는 포인트

  • tf_run은 먼저 선택된 개수를 세고 -ENOSPC를 판단한 다음에 실행합니다. 결과 슬롯이 모자라서 중간에 멈추면 destructive 테스트가 "돌았지만 기록이 없는" 상태가 되기 때문입니다.
  • *r = (TestResult){ t, ST_SKIP, 0, 0 };로 먼저 SKIP 기본값을 채우고, 실행할 때만 덮어씁니다. 그래서 SKIP 경로는 continue 한 줄입니다.
  • r->ms = tf_now_ms() - start; — unsigned 뺄셈이라 wrap에서도 12가 나옵니다(테스트 1번 첫 줄).
  • put()은 *len < cap일 때만 실제 포인터를 넘기고, 아니면 vsnprintf(NULL, 0, ...)로 길이만 셉니다. buf + len이 버퍼 밖을 가리키는 포인터 연산 자체를 피합니다.
  • %zu, %lu + (unsigned long) 캐스트: uint32_t를 %u로 찍는 것은 대부분 맞지만 이식성 있게 쓰려면 캐스트하거나 PRIu32를 씁니다.
  • 첫 줄 if (cap > 0) buf[0] = '\0'; — 결과가 0줄이어도(실제로는 SUMMARY가 항상 있지만) 빈 문자열을 보장합니다.

4.5 복잡도

  • tf_run: O(n) + 테스트 실행 시간. strcmp 필터 비용은 블록 이름 길이만큼.
  • tf_report: 커버리지 판정이 requirement마다 결과 전체를 훑으므로 O(m·r + m²) (m = requirement 수, r = 결과 수). 수백 개면 수만 번 strcmp라 무시할 만합니다. 커지면 테스트 테이블에 requirement 인덱스를 미리 넣어 O(r + m)으로 줄입니다.
  • 메모리: O(1) + 호출자 버퍼.

5. 임베디드 관점으로 말할 것

  • 테이블 기반 등록: 실제로는 __attribute__((section(".testcases"))) + 링커 스크립트로 각 파일의 테스트를 한 섹션에 모읍니다(Zephyr ztest, U-Boot U_BOOT_CMD와 같은 방식). 등록 함수 호출이 없어서 테스트를 추가할 때 중앙 파일을 고치지 않아도 됩니다.
  • 같은 이미지, 다른 플랫폼: 플랫폼은 런타임에 SoC ID 레지스터나 FPGA 빌드 ID 레지스터를 읽어 정합니다. SKIP_ON_FPGA처럼 테스트가 스스로 이유를 밝히는 플래그가 있어야 "FPGA에서 0%인 이유"를 리포트로 설명할 수 있습니다.
  • 기계가 읽는 로그: RESULT,... 한 줄 고정 형식은 사람이 읽는 printf와 섞여도 호스트가 startswith("RESULT,")로 걸러낼 수 있습니다. 필드 추가는 뒤에만 붙여서 기존 파서를 깨지 않습니다.
  • UART에 바로 흘리기: 버퍼가 작으면 tf_report를 버퍼 대신 putc 콜백으로 바꿔 한 줄씩 내보냅니다. 버퍼 버전은 결과를 공유 메모리에 남겨 JTAG으로 읽어 가는 경우에 씁니다.
  • 벤치 결과도 같은 형식으로: V4의 min/p50/p99를 PERF,<id>,... 줄로 같이 내면 같은 파서와 DB를 씁니다.

5.1 면접관(HW 출신 Sr Manager)이 파고들 포인트

  • "테스트가 멈추면(hang) 어떻게 되나?" — 이 버전은 사후 측정이라 진짜 hang은 못 잡습니다. 실제로는 테스트마다 HW watchdog을 timeout_ms로 다시 설정하고, 리셋 후 부트 코드가 리셋 원인 레지스터 + no-init RAM에 남긴 "현재 테스트 id" 를 보고 그 테스트를 TIMEOUT으로 기록한 뒤 다음 테스트부터 이어 갑니다. "Before each test I arm the watchdog and write the test id to no-init RAM; after a watchdog reset the runner reads it back, logs that test as TIMEOUT and resumes with the next one."
  • "FPGA와 실리콘에서 같은 테스트를 어떻게 유지하나?" — 하나의 소스, 플랫폼 플래그와 런타임 감지, 그리고 FPGA에서 SKIP된 항목은 실리콘 체크리스트에 자동으로 넘어갑니다. "One test source for both; anything skipped on FPGA is automatically tracked as open until silicon passes it, so coverage gaps are visible from day one."
  • "커버리지 100%면 다 된 건가?" — 이건 requirement(기능) 커버리지입니다. 테스트 코드가 HW 레지스터/기능의 어디를 건드렸는지는 별개이고, RTL 쪽 functional coverage(covergroup)와 매핑하거나, 레지스터 접근 로그로 보완합니다. "This is requirement coverage; it says every requirement has passing evidence, not that every register field or corner was exercised."
  • "결과가 PVT/SLT로 어떻게 이어지나?" — 같은 RESULT 줄에 보드 ID, 전압, 온도, 주파수를 붙여 DB에 쌓고, PVT 코너별 pass rate로 보고, 안정된 테스트 일부는 production SLT 리스트로 승격합니다(runtime 예산 안에서). "The same result lines carry board, voltage, temperature and frequency, so the PVT report and the SLT test list are just queries on that database."
  • "테스트 자체가 맞는지는 어떻게 아나?" — 실패해야 하는 상황을 주입해 실제로 FAIL이 나는지 봅니다(fault injection, 잘못된 기대값, 링크 강제 down). "Every new test is checked once with an injected fault so we know it can actually fail."

6. Follow-up 질문과 답

Follow-up (English)답
How does the host-side Python orchestrate this?보드 팜의 각 보드에 대해 전원 제어(PDU/릴레이) → 이미지 로드(JTAG/OpenOCD, 또는 UART 부트로더) → UART 로그 수집 → RESULT, 줄 파싱 → DB 기록 순서입니다. 타임아웃 없는 부팅·멈춤은 호스트 쪽 타이머로 감지해 전원 재인가합니다. pytest를 쓰면 보드 하나를 fixture로 두고 펌웨어 테스트 id를 parametrize합니다.
Functional coverage vs code coverage?이 리포트는 requirement(기능) 커버리지입니다. code coverage는 펌웨어 코드의 줄/분기 실행률(gcov, bare-metal이면 카운터를 RAM에 모아 덤프)이고, HW 관점에서는 RTL functional coverage(covergroup)와 레지스터 필드 접근 커버리지가 또 따로 있습니다. 셋 다 "얼마나 검증했나"의 다른 축입니다.
How do you keep requirement traceability?requirement id(Jira/Polarion/DOORS)를 테스트 테이블에 문자열로 박고, 호스트가 결과를 그 id에 연결해 올립니다. 테스트 없는 requirement(REQ-ISP-001)와 requirement 없는 테스트 둘 다 리포트에 경고로 냅니다.
What is your retry / flaky policy?첫 실패에 자동 재시도는 하되 결과는 FAIL→PASS(flaky)로 따로 기록하고 숨기지 않습니다. flaky 비율이 기준을 넘으면 테스트나 HW 마진(→ V7) 이슈로 티켓을 엽니다. destructive 테스트는 재시도 금지.
How do you keep tests runnable both pre- and post-silicon?HAL 아래만 플랫폼별로 바꾸고 테스트는 공통입니다. FPGA(HAPS)에서는 클록이 느리므로 timeout을 플랫폼 배율로 늘리고, 없는 블록(아날로그 PHY, 실제 DDR PHY)은 SKIP_ON_FPGA로 표시합니다. 같은 테스트가 RTL 시뮬레이션에서도 돌면 더 좋습니다.
What about a test that truly hangs?테스트별 watchdog + no-init RAM에 현재 테스트 id 기록 + 리셋 후 재개(§5.1). 멀티코어면 다른 코어가 감시하고, 호스트도 UART 무응답 타이머로 이중 감시합니다.
What if the report does not fit?tf_report는 snprintf처럼 필요한 길이를 돌려주므로 다시 할당하거나, 줄 단위로 UART에 흘리는 콜백 버전으로 바꿉니다. 절대로 넘쳐 쓰지 않는 것이 우선입니다.
Why not count SKIP as covered?SKIP은 "검증하지 않았음"입니다. FPGA에서 SKIP된 requirement는 실리콘에서 PASS가 나올 때까지 open으로 남아야 테이프아웃/샘플 출하 판단에 빈칸이 보입니다.

7. 자주 하는 실수

  • TIMEOUT보다 rc를 먼저 판정 → 늦게 끝난 테스트가 PASS (테스트 1번 DDR-STRESS-002)
  • >=로 타임아웃 비교 → 정확히 40 ms인 DDR-TRAIN-001이 TIMEOUT (테스트 1번)
  • SKIP 테스트의 fn을 호출함 → destructive 테스트가 실제로 실행됨 (g_calls 검사)
  • 필터에서 빠진 테스트도 SKIP으로 기록 → total이 6이 됨 (테스트 3번)
  • snprintf 반환값만큼 포인터를 움직이고 남은 크기를 다시 계산하지 않음 → 잘리는 순간 버퍼 오버런 (테스트 5번, ASan이 잡음)
  • 잘렸을 때 실제로 쓴 길이를 반환 → 호출자가 필요한 크기를 모름
  • covered * 100 / total에서 total == 0 처리 누락 → 0으로 나누기 (테스트 6번)
  • requirement가 FAIL/SKIP 테스트만 있어도 covered로 셈
