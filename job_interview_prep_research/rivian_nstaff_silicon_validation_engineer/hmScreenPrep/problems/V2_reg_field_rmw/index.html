0. 문제 한국어로 먼저 보기

영어 원문(§1)을 읽기 전에 무슨 상황이고 뭘 만들어야 하는지만 빠르게 잡는 요약입니다. 풀이 힌트는 없습니다.

한 줄 요약: FPGA에 새로 올라온 IP 블록의 레지스터를 안전하게 다루는 헬퍼 함수와, 레지스터가 스펙대로 동작하는지 확인하는 레지스터 sanity 테스트를 짭니다.

상황

  • SIF라는 센서 인터페이스 블록이 FPGA 프로토타입에 막 올라왔습니다. 드라이버를 쓰기 전에 RTL이 레지스터 스펙과 맞는지부터 확인해야 합니다.
  • 블록에는 32-bit MMIO 함수 reg_read(off) / reg_write(off, val)로만 접근합니다. 파일 아래쪽 HW model이 실제 블록을 흉내 냅니다.
  • 비트마다 성질이 다릅니다.
    • RW: 쓰고 읽을 수 있음
    • RO: 써도 안 바뀜. reserved 비트도 여기에 포함되며 항상 0으로 읽힘
    • W1C(write-1-to-clear): HW가 1로 세우고, SW가 1을 쓰면 0으로 지워짐
    • SC(self-clearing) SOFT_RST: 1을 쓰면 블록 전체가 리셋됨
    • FIFO 레지스터는 읽기만 해도 데이터가 빠져나감
  • HW model은 버그(stuck bit, 틀린 reset 값, 쓰기가 되는 RO 비트)를 일부러 넣을 수 있습니다.

구현할 것

함수하는 일규칙
field_mask(msb, lsb)msb..lsb 비트만 1인 마스크field_mask(31,0) = 0xFFFFFFFF, UB shift 금지
field_get(reg, msb, lsb)레지스터 값에서 필드 값 꺼내기
field_prep(val, msb, lsb)필드 값을 제자리로 shift
field_write(rd, msb, lsb, val)필드 하나만 read-modify-writemsb>31 또는 lsb>msb → -EINVAL, val이 필드에 안 들어가면 → -ERANGE. 에러면 버스 접근 0회. 필드 밖 비트는 읽은 값 그대로 쓰되 W1C·SC 비트는 0으로 씀
reg_sanity_test(tbl, n, log, log_cap)표에 있는 레지스터를 하나씩 검사REG_F_SKIP 항목은 건너뜀. 불일치 총 개수 반환, 앞의 log_cap개만 log에 기록

reg_sanity_test가 레지스터마다 하는 4단계

  1. RESET 확인: 읽은 값이 표의 reset과 같아야 함. 이 값을 orig라고 부름.
  2. RO 확인: RW 비트에는 orig, RO 비트에는 ~orig(뒤집은 값), W1C/SC 비트에는 0을 써서 → 다시 읽었을 때 orig 그대로여야 함 (RO가 진짜 안 바뀌는지).
  3. RW 확인 (rw_mask가 0이 아닐 때만): 패턴 0x55555555, 0xAAAAAAAA, 그리고 RW 비트마다 bit 0부터 walking-1. 쓴 RW 비트가 그대로 읽혀야 함.
  4. 원상 복구: orig를 다시 씀 (W1C/SC 비트는 0으로).
  • 불일치 종류: 1단계 실패는 MM_RESET. 그 밖에는 틀린 비트에 RW 비트가 끼어 있으면 MM_RW, 아니면 MM_RO.

예시를 말로 풀면

  • IRQ 레지스터에 pending 비트 3개(0x7, W1C)가 서 있는 상태에서 IRQ_EN 필드에 5를 씁니다.
    • 순진하게 RMW하면 읽은 0x7을 그대로 다시 써서 pending 인터럽트 3개가 지워집니다 (틀림).
    • 올바른 field_write는 W1C 비트를 0으로 써서 pending을 살려 둡니다.
  • 버그 2개(SCRATCH bit 13 stuck-at-0, THRESH reset 값 틀림)를 넣고 log_cap=2로 돌리면 불일치는 3개입니다. 반환값은 3이고 log에는 앞의 2개만 남습니다.

지켜야 할 조건

  • malloc 금지. -fsanitize=undefined에서 깨끗해야 함.
  • 테스트가 SOFT_RST에 1을 쓰면 안 되고, FIFO를 읽으면 안 되고, 끝나면 모든 레지스터를 처음 상태로 돌려놔야 함.

1. Problem

A new IP block (SIF, a sensor-interface block) has just come up on the FPGA prototype. Before anyone writes a driver, you write the register access layer and a register-sanity test that checks the RTL against the register spec.

The block is reached only through 32-bit MMIO accessors reg_read(off) / reg_write(off, val). A HW model in the file emulates it: RW bits, RO bits, W1C (write-1-to-clear) status bits set by hardware, a self-clearing SOFT_RST bit (writing 1 resets the whole block), reserved bits that always read 0, and a FIFO register whose read pops data. The model can also inject HW bugs (stuck bits, wrong reset value, writable RO bit).

Implement:

  1. field_mask / field_get / field_prep for a field msb..lsb. field_mask(31, 0) must return 0xFFFFFFFF with no undefined shift.
  2. field_write(rd, msb, lsb, val) — read-modify-write one field.
    • -EINVAL if msb > 31 or lsb > msb; -ERANGE if val does not fit. On error, no bus access.
    • Bits outside the field are written back as read, except W1C and self-clearing bits, which must be written as 0.
  3. reg_sanity_test(tbl, n, log, log_cap) — walk the description table (skip REG_F_SKIP entries). Per register:
    1. RESET: read; must equal reset. Call the value read orig.
    2. RO: write orig on RW bits and ~orig on RO bits (not RW, not W1C, not SC — includes reserved); W1C/SC bits as 0. Read-back must equal orig.
    3. RW (if rw_mask != 0): patterns 0x55555555, 0xAAAAAAAA, then walking-1 over every RW bit from bit 0 up. Write (p & rw) | (orig & RO bits); read-back must equal (p & rw) | (orig & ~rw).
    4. Restore: write orig with W1C/SC bits cleared.

Each failed check is one mismatch: MM_RESET for step 1, otherwise MM_RW if the difference touches an RW bit, else MM_RO. Log the first log_cap mismatches (log may be NULL when log_cap == 0) and return the total count.

Example

IRQ = 0x00000007 (HW latched 3 pending interrupts), field_write(IRQ, 18, 16, 5)
  naive RMW writes 0x00050007 -> W1C clears pending -> IRQ = 0x00050000   (wrong)
  field_write writes 0x00050000                    -> IRQ = 0x00050007   (right)

HW bugs injected: SCRATCH bit 13 stuck-at-0, THRESH reset reads 0x08000180
  reg_sanity_test(..., log, 2) = 3
  log[0] = { 0x10, MM_RESET, wrote 0,          expect 0x08000100, got 0x08000180 }
  log[1] = { 0x14, MM_RW,    wrote 0xAAAAAAAA, expect 0xAAAAAAAA, got 0xAAAA8AAA }
  (3rd mismatch, walking-1 bit 13, is counted but not logged)

Constraints

  • No malloc. 32-bit registers, word-aligned offsets. Must be clean under -fsanitize=undefined.
  • The test must not write 1 to SOFT_RST, must not read FIFO, and must leave every register as it found it.

Clarifying questions to ask (first 3 minutes)

  1. Is the description table the source of truth (generated from IP-XACT / SystemRDL), or do I hard-code the map?
  2. Which bits have side effects on write (self-clearing, W1C, "go" bits) or on read (read-to-clear, FIFO pop)?
  3. Can I assume the block is just out of reset when the test starts (no HW status already latched)?
  4. Is writing 1s into reserved bits allowed on this IP, or must reserved bits always be written as 0?
  5. On mismatch, should I stop or keep going and report everything? How big is the log?

 *
 * A new IP block ("SIF", a sensor-interface block) has just come up on FPGA / first silicon.
 * Its registers are reached through reg_read(off) / reg_write(off, val) (32-bit MMIO).
 * The HW model at the bottom emulates the block: RW bits, RO bits, W1C status bits,
 * a self-clearing SOFT_RST bit, reserved bits that read 0, and a FIFO register whose
 * read pops data (side effect). It can also inject HW bugs.
 *
 * Implement:
 *   field_mask(msb, lsb)        mask with bits msb..lsb set (0 <= lsb <= msb <= 31).
 *                               Must be correct for msb=31, lsb=0 (no UB shift by 32).
 *   field_get(reg, msb, lsb)    extract the field, right-aligned.
 *   field_prep(val, msb, lsb)   place val into the field (val truncated to the field width).
 *   field_write(rd, msb, lsb, v) read-modify-write one field of register rd->off:
 *        - -EINVAL if msb > 31 or lsb > msb; -ERANGE if v does not fit the field.
 *          On error, do not touch the register.
 *        - Bits outside the field are written back as read, EXCEPT W1C bits and
 *          self-clearing bits, which must be written as 0 (writing back a 1 that was

 *        - Bits inside the field are written as given (so writing 1 to a W1C field clears it).
 *   reg_sanity_test(tbl, n, log, log_cap)

 *        1. RESET : read; must equal rd->reset.             (orig = value read)
 *        2. RO    : write orig on RW bits, ~orig on "RO" bits (= not RW, not W1C, not SC),
 *                   0 on W1C/SC bits; read back must equal orig.
 *        3. RW    : for each pattern p in { 0x55555555, 0xAAAAAAAA, then walking-1 over every

/* =====================================================================
 * HW model of the SIF block + fault injection (do not edit)
 * ===================================================================== */
#define NREG 7
static struct {
    uint32_t val[NREG];
    uint32_t reset_bug[NREG];     /* XOR applied to the reset value (wrong reset) */
    uint32_t stuck0[NREG], stuck1[NREG];
    uint32_t ro_leak[NREG];       /* RO bits that are wrongly writable */
    uint32_t writes, bad_access, soft_resets, fifo_pops;
} H;

static uint32_t hw_rw(size_t i)  { return SIF_REGS[i].rw_mask; }
static uint32_t hw_w1c(size_t i) { return SIF_REGS[i].w1c_mask; }

static uint32_t hw_fix(size_t i, uint32_t v) { return (v | H.stuck1[i]) & ~H.stuck0[i]; }

static void hw_block_reset(void)
{
    for (size_t i = 0; i < NREG; i++) H.val[i] = hw_fix(i, SIF_REGS[i].reset ^ H.reset_bug[i]);
}

static void hw_power_on(void)                 /* clears faults too */
{
    memset(&H, 0, sizeof H);
    hw_block_reset();
}

static void hw_raise(uint32_t off, uint32_t bits) { H.val[off / 4] |= bits; }   /* HW sets status */

static int hw_index(uint32_t off)
{
    if ((off & 3u) || off / 4 >= NREG) { H.bad_access++; return -1; }
    return (int)(off / 4);
}

uint32_t reg_read(uint32_t off)
{
    int i = hw_index(off);
    if (i < 0) return 0xDEADBEEFu;
    if (off == SIF_FIFO) H.fifo_pops++;          /* read side effect */
    return H.val[i];
}

void reg_write(uint32_t off, uint32_t val)
{
    int i = hw_index(off);
    if (i < 0) return;
    H.writes++;
    if (off == SIF_CTRL && (val & 0x80000000u)) { H.soft_resets++; hw_block_reset(); return; }
    uint32_t rw = hw_rw((size_t)i) | H.ro_leak[i];
    uint32_t nv = (H.val[i] & ~rw) | (val & rw);
    nv &= ~(val & hw_w1c((size_t)i));             /* W1C */
    H.val[i] = hw_fix((size_t)i, nv);             /* reserved bits never stored */
}

static bool regs_at_reset(void)
{
    for (size_t i = 0; i < NREG; i++)
        if (H.val[i] != hw_fix(i, SIF_REGS[i].reset ^ H.reset_bug[i])) return false;
    return true;
}

int main(void)
{
    const RegDesc *CTRL = &SIF_REGS[1], *IRQ = &SIF_REGS[2];
    Mismatch log[4];

    /* 1. field helpers, including the full-width and single-bit edges */
    CHECK(field_mask(15, 8) == 0x0000FF00u);
    CHECK(field_mask(0, 0) == 0x00000001u);
    CHECK(field_mask(31, 31) == 0x80000000u);
    CHECK(field_mask(31, 0) == 0xFFFFFFFFu);
    CHECK(field_get(0x0000AB0Fu, 15, 8) == 0xABu);
    CHECK(field_get(0x0000AB0Fu, 3, 1) == 0x7u);
    CHECK(field_get(0xDEADBEEFu, 31, 0) == 0xDEADBEEFu);
    CHECK(field_prep(0x3u, 3, 1) == 0x6u);
    CHECK(field_prep(0x1FFu, 15, 8) == 0xFF00u);          /* truncated to the field */

    /* 2. field_write: normal RMW keeps the other fields */
    hw_power_on();
    CHECK(field_write(CTRL, 0, 0, 1) == 0);               /* EN = 1 */
    CHECK(field_write(CTRL, 3, 1, 5) == 0);               /* MODE = 5 */
    CHECK(field_write(CTRL, 15, 8, 0x10) == 0);           /* DIV = 0x10 */
    CHECK(reg_read(SIF_CTRL) == 0x0000100Bu);
    CHECK(H.soft_resets == 0);

    /* 3. W1C pitfall: HW has pending bits set; changing IRQ_EN must not clear them */
    hw_power_on();
    hw_raise(SIF_IRQ, 0x7u);
    CHECK(field_write(IRQ, 18, 16, 0x5) == 0);
    CHECK(reg_read(SIF_IRQ) == 0x00050007u);              /* naive RMW gives 0x00050000 */
    CHECK(field_write(IRQ, 1, 1, 1) == 0);                /* ack only pending bit 1 */
    CHECK(reg_read(SIF_IRQ) == 0x00050005u);

    /* 4. bad arguments: error code and NO bus write */
    hw_power_on();
    CHECK(field_write(CTRL, 7, 8, 0) == -EINVAL);
    CHECK(field_write(CTRL, 32, 0, 0) == -EINVAL);
    CHECK(field_write(CTRL, 3, 1, 8) == -ERANGE);         /* 3-bit field max 7 */
    CHECK(H.writes == 0 && reg_read(SIF_CTRL) == 0x00000400u);
    CHECK(field_write(&SIF_REGS[5], 31, 0, 0xFFFFFFFFu) == 0 && reg_read(SIF_SCRATCH) == 0xFFFFFFFFu);

    /* 5. sanity test on good HW: 0 mismatches, no side effects, everything restored */
    hw_power_on();
    CHECK(reg_sanity_test(SIF_REGS, N_SIF_REGS, log, 4) == 0);
    CHECK(H.soft_resets == 0);                            /* SOFT_RST never written as 1 */
    CHECK(H.fifo_pops == 0);                              /* FIFO register skipped */
    CHECK(H.bad_access == 0);
    CHECK(regs_at_reset());

    /* 6. injected bugs: SCRATCH bit 13 stuck-at-0, THRESH reset value wrong (bit 7) */
    hw_power_on();
    H.stuck0[SIF_SCRATCH / 4] = 1u << 13;
    H.reset_bug[SIF_THRESH / 4] = 0x80u;
    hw_block_reset();
    memset(log, 0, sizeof log);
    CHECK(reg_sanity_test(SIF_REGS, N_SIF_REGS, log, 2) == 3);   /* total, even if log is small */
    CHECK(log[0].off == SIF_THRESH && log[0].kind == MM_RESET &&
          log[0].expect == 0x08000100u && log[0].got == 0x08000180u);
    CHECK(log[1].off == SIF_SCRATCH && log[1].kind == MM_RW &&
          log[1].wrote == 0xAAAAAAAAu && log[1].got == 0xAAAA8AAAu);
    CHECK(log[2].off == 0 && log[2].kind == 0);           /* nothing written past log_cap */
    CHECK(reg_sanity_test(SIF_REGS, N_SIF_REGS, NULL, 0) == 3);
    CHECK(regs_at_reset());

    /* 7. RO bit wrongly writable (ID bit 0): one MM_RO mismatch, ID restored */
    hw_power_on();
    H.ro_leak[SIF_ID / 4] = 1u;
    CHECK(reg_sanity_test(SIF_REGS, N_SIF_REGS, log, 4) == 1);
    CHECK(log[0].off == SIF_ID && log[0].kind == MM_RO &&
          log[0].wrote == 0xA5E2FEFDu && log[0].got == 0x5A1D0103u);
    CHECK(reg_read(SIF_ID) == 0x5A1D0102u);

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

3. 힌트 (막힐 때 하나씩)

Hint 1 — width 32에서 UB 없는 mask

((1u << (msb - lsb + 1)) - 1) << lsb는 (31, 0)에서 1u << 32가 되어 UB입니다(UBSan이 잡음, x86에서는 실제로 1u << 0처럼 동작해서 mask가 0이 됨). 시프트 양이 항상 31 이하가 되도록 두 번 나눠 자르세요: (~0u >> (31 - msb)) & (~0u << lsb).

Hint 2 — field_write에서 지워야 할 비트

읽은 값 cur를 그대로 다시 쓰면 W1C 비트에 읽힌 1이 그대로 써져서 pending 상태가 지워집니다. keep = cur & ~field_mask & ~(w1c_mask | sc_mask). 그리고 검증(-EINVAL, -ERANGE)은 읽기 전에 하세요. 잘못된 인자로 버스를 건드리면 안 됩니다.

Hint 3 — sanity test는 "write → read-back → 비교" 하나로

wr_check(rd, written, expected) 헬퍼 하나를 만들면 RO 단계와 RW 단계가 같은 코드가 됩니다. 차이 diff = got ^ expected가 RW 비트에 걸리면 MM_RW, 아니면 MM_RO. 로그는 T1-1과 같은 if (cnt < cap) log[cnt] = …; cnt++; 패턴입니다. RO 비트 집합은 ~(rw | w1c | sc) — W1C에 1을 쓰면 상태가 지워지고, SC에 1을 쓰면 블록이 리셋되기 때문에 빼야 합니다.

4. 풀이

4.1 핵심 아이디어 — 비트마다 "속성"이 다르다

레지스터는 32비트 정수 하나지만, 비트마다 쓰기 규칙이 다릅니다. 같은 값을 써도 RW 비트는 저장되고, RO·reserved는 무시되고, W1C는 1을 쓰면 지워지고, SC는 1을 쓰면 동작(리셋)이 일어납니다. 이 문제의 모든 함정은 "읽은 값을 그대로 다시 쓰면 안전하다"는 착각에서 나옵니다.

4.2 RMW 함정 — W1C 비트

반대로 pending을 일부러 지울 때는 그 비트만 1로 씁니다. field_write(IRQ, 1, 1, 1)은 쓰기 값 0x00050002 → 결과 0x00050005(bit 1만 클리어). 이게 W1C가 존재하는 이유입니다: 여러 status 비트 중 처리한 것만 원자적으로 지울 수 있습니다.

💡 정답 코드 펼치기 (25분 풀어 본 다음에)
solution.c
/*
 * V2  Register Access Layer + Register-Sanity Test (Reference solution)
 *
 * A new IP block ("SIF", a sensor-interface block) has just come up on FPGA / first silicon.
 * Its registers are reached through reg_read(off) / reg_write(off, val) (32-bit MMIO).
 * The HW model at the bottom emulates the block: RW bits, RO bits, W1C status bits,
 * a self-clearing SOFT_RST bit, reserved bits that read 0, and a FIFO register whose
 * read pops data (side effect). It can also inject HW bugs.
 *
 * Implement:
 *   field_mask(msb, lsb)        mask with bits msb..lsb set (0 <= lsb <= msb <= 31).
 *                               Must be correct for msb=31, lsb=0 (no UB shift by 32).
 *   field_get(reg, msb, lsb)    extract the field, right-aligned.
 *   field_prep(val, msb, lsb)   place val into the field (val truncated to the field width).
 *   field_write(rd, msb, lsb, v) read-modify-write one field of register rd->off:
 *        - -EINVAL if msb > 31 or lsb > msb; -ERANGE if v does not fit the field.
 *          On error, do not touch the register.
 *        - Bits outside the field are written back as read, EXCEPT W1C bits and
 *          self-clearing bits, which must be written as 0 (writing back a 1 that was
 *          read from a W1C bit would clear a pending status the driver never saw).
 *        - Bits inside the field are written as given (so writing 1 to a W1C field clears it).
 *   reg_sanity_test(tbl, n, log, log_cap)
 *        For every register in the description table (skip entries with REG_F_SKIP):
 *        1. RESET : read; must equal rd->reset.             (orig = value read)
 *        2. RO    : write orig on RW bits, ~orig on "RO" bits (= not RW, not W1C, not SC),
 *                   0 on W1C/SC bits; read back must equal orig.
 *        3. RW    : for each pattern p in { 0x55555555, 0xAAAAAAAA, then walking-1 over every
 *                   RW bit from bit 0 up }: write (p & rw) | (orig & RO bits); read back must
 *                   equal (p & rw) | (orig & ~rw).  (skip if rw_mask == 0)
 *        4. restore: write orig with W1C/SC bits cleared.
 *        Each failed check counts as one mismatch: kind MM_RW if the difference touches an
 *        RW bit, otherwise MM_RO (MM_RESET for step 1). Log the first log_cap mismatches
 *        into log (log may be NULL when log_cap == 0). Return the total mismatch count.
 *
 * Build & run:  ./run.sh V2 sol
 */
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>
#include <errno.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

/* ---------------- MMIO HAL (provided, implemented by the HW model below) ---------------- */
uint32_t reg_read(uint32_t off);
void     reg_write(uint32_t off, uint32_t val);

/* ---------------- register description (from the IP spec / IP-XACT) ---------------- */
#define REG_F_SKIP  0x1u          /* side-effect register: never touch in generic tests */

typedef struct {
    const char *name;
    uint32_t off;
    uint32_t reset;               /* documented reset value */
    uint32_t rw_mask;             /* read-write bits */
    uint32_t w1c_mask;            /* write-1-to-clear status bits (HW sets them) */
    uint32_t sc_mask;             /* self-clearing / write-action bits (read as 0) */
    uint32_t flags;
} RegDesc;

#define SIF_ID       0x00u
#define SIF_CTRL     0x04u        /* [0] EN  [3:1] MODE  [15:8] DIV  [31] SOFT_RST (SC) */
#define SIF_IRQ      0x08u        /* [2:0] pending (W1C)  [8] BUSY (RO)  [18:16] IRQ_EN (RW) */
#define SIF_TIMEOUT  0x0Cu        /* [23:0] */
#define SIF_THRESH   0x10u        /* [11:0] LO  [27:16] HI */
#define SIF_SCRATCH  0x14u
#define SIF_FIFO     0x18u        /* RO, read pops one entry */

static const RegDesc SIF_REGS[] = {
    { "ID",      SIF_ID,      0x5A1D0102u, 0x00000000u, 0x0u, 0x00000000u, 0 },
    { "CTRL",    SIF_CTRL,    0x00000400u, 0x0000FF0Fu, 0x0u, 0x80000000u, 0 },
    { "IRQ",     SIF_IRQ,     0x00000000u, 0x00070000u, 0x7u, 0x00000000u, 0 },
    { "TIMEOUT", SIF_TIMEOUT, 0x0000FFFFu, 0x00FFFFFFu, 0x0u, 0x00000000u, 0 },
    { "THRESH",  SIF_THRESH,  0x08000100u, 0x0FFF0FFFu, 0x0u, 0x00000000u, 0 },
    { "SCRATCH", SIF_SCRATCH, 0x00000000u, 0xFFFFFFFFu, 0x0u, 0x00000000u, 0 },
    { "FIFO",    SIF_FIFO,    0x00000000u, 0x00000000u, 0x0u, 0x00000000u, REG_F_SKIP },
};
#define N_SIF_REGS (sizeof SIF_REGS / sizeof SIF_REGS[0])

typedef enum { MM_RESET = 1, MM_RO = 2, MM_RW = 3 } MmKind;
typedef struct {
    uint32_t off;
    MmKind   kind;
    uint32_t wrote;               /* value written before the read-back (0 for MM_RESET) */
    uint32_t expect, got;
} Mismatch;

/* ---------------- your code ---------------- */

uint32_t field_mask(unsigned msb, unsigned lsb)
{
    /* two shifts of at most 31 each: no UB at width 32 */
    return (0xFFFFFFFFu >> (31u - msb)) & (0xFFFFFFFFu << lsb);
}

uint32_t field_get(uint32_t reg, unsigned msb, unsigned lsb)
{
    return (reg & field_mask(msb, lsb)) >> lsb;
}

uint32_t field_prep(uint32_t val, unsigned msb, unsigned lsb)
{
    return (val << lsb) & field_mask(msb, lsb);
}

int field_write(const RegDesc *rd, unsigned msb, unsigned lsb, uint32_t val)
{
    if (msb > 31u || lsb > msb) return -EINVAL;
    uint32_t m = field_mask(msb, lsb);
    if (val > (m >> lsb)) return -ERANGE;

    uint32_t cur = reg_read(rd->off);
    uint32_t keep = cur & ~m & ~(rd->w1c_mask | rd->sc_mask);   /* never echo W1C/SC 1s */
    reg_write(rd->off, keep | field_prep(val, msb, lsb));
    return 0;
}

static size_t g_nmm;              /* mismatch counter for the current test run */

static void log_mm(Mismatch *log, size_t cap, uint32_t off, MmKind k,
                   uint32_t wrote, uint32_t expect, uint32_t got)
{
    if (g_nmm < cap) log[g_nmm] = (Mismatch){ off, k, wrote, expect, got };
    g_nmm++;
}

/* write, read back, compare; classify by which bits differ */
static void wr_check(const RegDesc *rd, uint32_t w, uint32_t expect, Mismatch *log, size_t cap)
{
    reg_write(rd->off, w);
    uint32_t got = reg_read(rd->off);
    uint32_t diff = got ^ expect;
    if (diff) log_mm(log, cap, rd->off, (diff & rd->rw_mask) ? MM_RW : MM_RO, w, expect, got);
}

size_t reg_sanity_test(const RegDesc *tbl, size_t n, Mismatch *log, size_t log_cap)
{
    g_nmm = 0;
    for (size_t i = 0; i < n; i++) {
        const RegDesc *rd = &tbl[i];
        if (rd->flags & REG_F_SKIP) continue;            /* FIFO pop, read-to-clear, ... */
        uint32_t rw = rd->rw_mask;
        uint32_t ro = ~(rw | rd->w1c_mask | rd->sc_mask); /* includes reserved bits */

        /* 1. reset value */
        uint32_t orig = reg_read(rd->off);
        if (orig != rd->reset) log_mm(log, log_cap, rd->off, MM_RESET, 0, rd->reset, orig);

        /* 2. RO bits must ignore writes */
        wr_check(rd, (orig & rw) | (~orig & ro), orig, log, log_cap);

        /* 3. RW bits: checkerboards, then walking-1 */
        if (rw) {
            static const uint32_t pats[] = { 0x55555555u, 0xAAAAAAAAu };
            for (size_t k = 0; k < 2; k++)
                wr_check(rd, (pats[k] & rw) | (orig & ro), (pats[k] & rw) | (orig & ~rw), log, log_cap);
            for (unsigned b = 0; b < 32; b++) {
                uint32_t p = 1u << b;
                if (!(rw & p)) continue;
                wr_check(rd, p | (orig & ro), p | (orig & ~rw), log, log_cap);
            }
        }

        /* 4. restore */
        reg_write(rd->off, orig & ~(rd->w1c_mask | rd->sc_mask));
    }
    return g_nmm;
}

/* =====================================================================
 * HW model of the SIF block + fault injection (do not edit)
 * ===================================================================== */
#define NREG 7
static struct {
    uint32_t val[NREG];
    uint32_t reset_bug[NREG];     /* XOR applied to the reset value (wrong reset) */
    uint32_t stuck0[NREG], stuck1[NREG];
    uint32_t ro_leak[NREG];       /* RO bits that are wrongly writable */
    uint32_t writes, bad_access, soft_resets, fifo_pops;
} H;

static uint32_t hw_rw(size_t i)  { return SIF_REGS[i].rw_mask; }
static uint32_t hw_w1c(size_t i) { return SIF_REGS[i].w1c_mask; }

static uint32_t hw_fix(size_t i, uint32_t v) { return (v | H.stuck1[i]) & ~H.stuck0[i]; }

static void hw_block_reset(void)
{
    for (size_t i = 0; i < NREG; i++) H.val[i] = hw_fix(i, SIF_REGS[i].reset ^ H.reset_bug[i]);
}

static void hw_power_on(void)                 /* clears faults too */
{
    memset(&H, 0, sizeof H);
    hw_block_reset();
}

static void hw_raise(uint32_t off, uint32_t bits) { H.val[off / 4] |= bits; }   /* HW sets status */

static int hw_index(uint32_t off)
{
    if ((off & 3u) || off / 4 >= NREG) { H.bad_access++; return -1; }
    return (int)(off / 4);
}

uint32_t reg_read(uint32_t off)
{
    int i = hw_index(off);
    if (i < 0) return 0xDEADBEEFu;
    if (off == SIF_FIFO) H.fifo_pops++;          /* read side effect */
    return H.val[i];
}

void reg_write(uint32_t off, uint32_t val)
{
    int i = hw_index(off);
    if (i < 0) return;
    H.writes++;
    if (off == SIF_CTRL && (val & 0x80000000u)) { H.soft_resets++; hw_block_reset(); return; }
    uint32_t rw = hw_rw((size_t)i) | H.ro_leak[i];
    uint32_t nv = (H.val[i] & ~rw) | (val & rw);
    nv &= ~(val & hw_w1c((size_t)i));             /* W1C */
    H.val[i] = hw_fix((size_t)i, nv);             /* reserved bits never stored */
}

static bool regs_at_reset(void)
{
    for (size_t i = 0; i < NREG; i++)
        if (H.val[i] != hw_fix(i, SIF_REGS[i].reset ^ H.reset_bug[i])) return false;
    return true;
}

int main(void)
{
    const RegDesc *CTRL = &SIF_REGS[1], *IRQ = &SIF_REGS[2];
    Mismatch log[4];

    /* 1. field helpers, including the full-width and single-bit edges */
    CHECK(field_mask(15, 8) == 0x0000FF00u);
    CHECK(field_mask(0, 0) == 0x00000001u);
    CHECK(field_mask(31, 31) == 0x80000000u);
    CHECK(field_mask(31, 0) == 0xFFFFFFFFu);
    CHECK(field_get(0x0000AB0Fu, 15, 8) == 0xABu);
    CHECK(field_get(0x0000AB0Fu, 3, 1) == 0x7u);
    CHECK(field_get(0xDEADBEEFu, 31, 0) == 0xDEADBEEFu);
    CHECK(field_prep(0x3u, 3, 1) == 0x6u);
    CHECK(field_prep(0x1FFu, 15, 8) == 0xFF00u);          /* truncated to the field */

    /* 2. field_write: normal RMW keeps the other fields */
    hw_power_on();
    CHECK(field_write(CTRL, 0, 0, 1) == 0);               /* EN = 1 */
    CHECK(field_write(CTRL, 3, 1, 5) == 0);               /* MODE = 5 */
    CHECK(field_write(CTRL, 15, 8, 0x10) == 0);           /* DIV = 0x10 */
    CHECK(reg_read(SIF_CTRL) == 0x0000100Bu);
    CHECK(H.soft_resets == 0);

    /* 3. W1C pitfall: HW has pending bits set; changing IRQ_EN must not clear them */
    hw_power_on();
    hw_raise(SIF_IRQ, 0x7u);
    CHECK(field_write(IRQ, 18, 16, 0x5) == 0);
    CHECK(reg_read(SIF_IRQ) == 0x00050007u);              /* naive RMW gives 0x00050000 */
    CHECK(field_write(IRQ, 1, 1, 1) == 0);                /* ack only pending bit 1 */
    CHECK(reg_read(SIF_IRQ) == 0x00050005u);

    /* 4. bad arguments: error code and NO bus write */
    hw_power_on();
    CHECK(field_write(CTRL, 7, 8, 0) == -EINVAL);
    CHECK(field_write(CTRL, 32, 0, 0) == -EINVAL);
    CHECK(field_write(CTRL, 3, 1, 8) == -ERANGE);         /* 3-bit field max 7 */
    CHECK(H.writes == 0 && reg_read(SIF_CTRL) == 0x00000400u);
    CHECK(field_write(&SIF_REGS[5], 31, 0, 0xFFFFFFFFu) == 0 && reg_read(SIF_SCRATCH) == 0xFFFFFFFFu);

    /* 5. sanity test on good HW: 0 mismatches, no side effects, everything restored */
    hw_power_on();
    CHECK(reg_sanity_test(SIF_REGS, N_SIF_REGS, log, 4) == 0);
    CHECK(H.soft_resets == 0);                            /* SOFT_RST never written as 1 */
    CHECK(H.fifo_pops == 0);                              /* FIFO register skipped */
    CHECK(H.bad_access == 0);
    CHECK(regs_at_reset());

    /* 6. injected bugs: SCRATCH bit 13 stuck-at-0, THRESH reset value wrong (bit 7) */
    hw_power_on();
    H.stuck0[SIF_SCRATCH / 4] = 1u << 13;
    H.reset_bug[SIF_THRESH / 4] = 0x80u;
    hw_block_reset();
    memset(log, 0, sizeof log);
    CHECK(reg_sanity_test(SIF_REGS, N_SIF_REGS, log, 2) == 3);   /* total, even if log is small */
    CHECK(log[0].off == SIF_THRESH && log[0].kind == MM_RESET &&
          log[0].expect == 0x08000100u && log[0].got == 0x08000180u);
    CHECK(log[1].off == SIF_SCRATCH && log[1].kind == MM_RW &&
          log[1].wrote == 0xAAAAAAAAu && log[1].got == 0xAAAA8AAAu);
    CHECK(log[2].off == 0 && log[2].kind == 0);           /* nothing written past log_cap */
    CHECK(reg_sanity_test(SIF_REGS, N_SIF_REGS, NULL, 0) == 3);
    CHECK(regs_at_reset());

    /* 7. RO bit wrongly writable (ID bit 0): one MM_RO mismatch, ID restored */
    hw_power_on();
    H.ro_leak[SIF_ID / 4] = 1u;
    CHECK(reg_sanity_test(SIF_REGS, N_SIF_REGS, log, 4) == 1);
    CHECK(log[0].off == SIF_ID && log[0].kind == MM_RO &&
          log[0].wrote == 0xA5E2FEFDu && log[0].got == 0x5A1D0103u);
    CHECK(reg_read(SIF_ID) == 0x5A1D0102u);

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

코드 읽는 포인트

  • field_write는 검증 → 읽기 → keep | prep → 쓰기 순서입니다. keep에서 w1c_mask | sc_mask를 지우는 한 줄이 이 문제의 핵심입니다.
  • wr_check() 하나로 RO 단계와 RW 단계를 처리합니다. 기대값 공식만 다릅니다: RO 단계는 orig, RW 단계는 (p & rw) | (orig & ~rw).
  • RW 패턴을 쓸 때 RO 비트에는 orig를 씁니다. 0을 쓰면 RO 버그(쓰기 누수)가 RW 단계에서도 중복으로 잡힙니다.
  • log_mm은 cap과 관계없이 카운터를 올립니다 → 반환값은 항상 전체 개수(T1-1과 같은 규칙).
  • 정답은 카운터를 파일 static(g_nmm)으로 두었지만, 실제 코드라면 컨텍스트 구조체로 넘기는 게 재진입에 안전합니다.

4.5 복잡도

  • 시간: 레지스터당 3 + 2 + popcount(rw) 번 MMIO 쓰기/읽기 → O(레지스터 수 × 32). SIF 전체에서 쓰기 117번.
  • 메모리: O(1) + 호출자 로그 버퍼.

5. 임베디드 관점으로 말할 것

  • volatile과 접근 폭: 실제 reg_read는 *(volatile uint32_t *)(BASE + off)입니다. volatile이 없으면 컴파일러가 read-back을 지우거나 합칩니다. 또 32비트 레지스터는 반드시 32비트 load/store로 접근해야 합니다(일부 IP는 byte 접근에 bus error 또는 엉뚱한 lane 쓰기).
  • posted write와 read-back: AXI/APB 브리지는 쓰기를 버퍼링(posted)할 수 있습니다. "쓰기 → 바로 다른 장치 동작" 순서가 중요하면 같은 장치에서 한 번 읽어서 flush하거나 dsb/wmb()를 씁니다. 이 테스트의 write → read-back 쌍은 자연스럽게 순서를 보장합니다(같은 장치, 같은 주소).
  • 테이블 기반 테스트: 레지스터 맵은 사람이 손으로 옮기면 틀립니다. IP-XACT/SystemRDL에서 RegDesc 테이블을 생성하면 RTL과 SW가 같은 소스를 봅니다. 이 테스트는 블록마다 처음 켜는 날 가장 먼저 돌리는 "smoke test"입니다.
  • RW 비트도 부작용이 있다: walking-1 중에 CTRL.EN = 1이 써지면 실제 블록은 동작을 시작할 수 있습니다. 실무 테이블에는 "test에서 쓰지 말 것" 비트 마스크를 따로 둡니다(이 문제의 sc_mask를 일반화한 것).
  • 관련 문제: 메모리 쪽 같은 아이디어(패턴 + walking bit)는 V1, 결과를 보고서로 묶는 것은 V5.

5.1 면접관(HW 출신 Sr Manager)이 파고들 포인트

  • "FPGA와 first silicon에서 뭐가 달라지나?" — FPGA에서는 레지스터가 대부분 맞지만 클록/리셋 도메인이 다릅니다. Silicon에서는 블록 클록·리셋·power domain을 먼저 켜야 하고, 안 켜면 read가 bus error나 0xDEADBEEF로 옵니다. 그래서 첫 체크는 ID 레지스터입니다. "On first silicon I read the ID register of every block first — that proves clock, reset, power and the bus path before I trust any other result."
  • "테스트 자체가 맞는지 어떻게 아나?" — 일부러 버그를 넣은 모델(stuck bit, 틀린 reset, RO 누수)로 테스트를 테스트합니다. 잡아야 할 버그를 못 잡으면 테스트가 틀린 것입니다(테스트 6, 7번). "I validate the test against a fault-injected model: if it can't catch a stuck bit I planted, it won't catch a real one."
  • "레지스터가 수천 개면?" — 테이블은 SystemRDL/IP-XACT에서 자동 생성, side-effect 레지스터는 속성으로 자동 skip, 결과는 블록별 pass/fail + 커버리지(검사한 비트 / 전체 RW 비트)로 리포트합니다. "The map is generated from the same IP-XACT the RTL team uses, so coverage is measurable: bits checked versus bits defined."
  • "Reset 값이 틀리면 RTL 버그인가 스펙 버그인가?" — 둘 다 가능합니다. 실패 로그에 offset, 기대값, 실제값을 남겨서 RTL/아키텍처 팀과 바로 대조합니다. Silicon에서는 OTP/fuse가 reset 값을 덮는 경우도 확인합니다. "A reset mismatch goes to triage with expected, actual, and the spec revision — sometimes the RTL is right and the document is stale."

6. Follow-up 질문과 답

Follow-up (English)답
Why volatile, and is it enough for MMIO ordering?volatile은 컴파일러가 접근을 없애거나 순서를 바꾸지 못하게 할 뿐, CPU/버스의 재배열이나 posted write는 막지 못합니다. ARM에서는 Device 메모리 속성 + 필요 시 dsb, Linux에서는 writel()(barrier 포함) / writel_relaxed()를 구분해서 씁니다.
Why can a posted write bite you, and how do you flush it?쓰기가 인터커넥트 버퍼에 머문 상태에서 CPU가 다음 일을 진행합니다. 예: 인터럽트 클리어 후 바로 리턴하면 같은 IRQ가 다시 들어옵니다. 같은 장치 레지스터를 한 번 읽으면 앞선 쓰기가 끝났음이 보장됩니다.
Why is read-modify-write racy?(1) HW가 읽기와 쓰기 사이에 status 비트를 바꾸면 그 변화가 덮입니다 → W1C/SET/CLR 레지스터가 존재하는 이유. (2) 두 코어/ISR이 같은 레지스터를 RMW하면 한쪽 변경이 사라집니다 → spinlock + IRQ off, 또는 SET/CLR alias 레지스터.
How would you generate these tests from IP-XACT / SystemRDL?peakrdl 같은 도구로 RDL을 C 헤더 + RegDesc 테이블로 변환합니다. 속성(sw=r/rw, onwrite=woclr, singlepulse, rclr)이 그대로 rw/w1c/sc/skip 마스크가 됩니다. UVM uvm_reg_hw_reset_seq / uvm_reg_bit_bash_seq와 같은 아이디어를 bare-metal C로 옮긴 것입니다.
Which registers must a generic test skip?읽기 부작용(read-to-clear status, FIFO pop, 카운터 latch), 쓰기 부작용(doorbell, "go"/start 비트, soft reset, PLL/clock 설정 — 잘못 쓰면 버스가 죽음), 보안/lock 비트(한 번 쓰면 리셋 전까지 고정).
Bitfield structs vs masks?struct { uint32_t en:1; ... }는 비트 순서·패딩·접근 폭이 구현 정의라 컴파일러마다 다르고, 필드 하나 쓰는데 byte store가 나올 수 있습니다. MMIO에는 mask/shift(Linux FIELD_GET/FIELD_PREP, GENMASK)가 이식성과 접근 폭 모두 안전합니다.
How do you test W1C and self-clearing bits then?일반 bit-bash가 아니라 블록별 directed test로 합니다: HW 이벤트를 만들어 status를 세우고 → 1을 써서 지워지는지, 0을 써서 유지되는지 확인. SC 비트는 1을 쓴 뒤 0으로 돌아오는지 + 동작이 일어났는지(레지스터가 reset 값으로 돌아왔는지) 확인합니다.

7. 자주 하는 실수

  • ((1u << width) - 1) << lsb → width 32에서 UB (테스트 1번, UBSan이 잡음)
  • RMW에서 W1C 비트를 마스크하지 않음 → pending 인터럽트 소실 (테스트 3번)
  • 인자 검증 전에 레지스터를 먼저 읽음/씀 → 잘못된 호출이 버스 접근을 만듦 (테스트 4번 H.writes == 0)
  • RO 단계에서 ~orig를 SC 비트에도 씀 → SOFT_RST가 블록을 리셋, 테스트가 자기 자신을 망침 (테스트 5번)
  • FIFO 같은 side-effect 레지스터를 "reset 값 확인"한다고 읽음 (테스트 5번 fifo_pops == 0)
  • 기대값을 reset 기준으로 계산 → reset 버그 하나가 수십 건으로 번짐 (테스트 6번은 정확히 3건이어야 함)
  • 로그가 꽉 차면 카운트도 멈춤 → 전체 개수 반환 규칙 위반 (테스트 6번)
  • 테스트 후 원래 값 복원을 잊음 → 다음 테스트가 오염됨
