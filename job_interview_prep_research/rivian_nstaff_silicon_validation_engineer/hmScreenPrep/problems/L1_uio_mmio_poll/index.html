IDL1
PriorityP0
Patternmmap page-align + volatile MMIO + monotonic-deadline poll + UIO IRQ handshake
Time30 min

파일: stub.c(여기서 풀기) · solution.c(정답) · 실행: ./run.sh L1 / ./run.sh L1 sol

0. 문제 한국어로 먼저 보기

영어 원문(§1)을 읽기 전에 무슨 상황이고 뭘 만들어야 하는지만 빠르게 잡는 요약입니다. 풀이 힌트는 없습니다.

한 줄 요약: Zynq UltraScale+ PetaLinux에서 userspace validation 툴이 PL IP 블록의 레지스터를 /dev/mem mmap으로 읽고 쓰고, 인터럽트를 UIO(/dev/uioN)로 기다리는 작은 라이브러리를 짭니다.

상황

  • PL에 올린 IP 블록 pgen이 PS의 M_AXI_HPM0_FPD 포트 뒤, 물리 주소 0xA001_0000에 있습니다. 커널 드라이버는 없습니다.
  • 레지스터 접근은 /dev/mem을 열고 물리 주소 구간을 mmap()해서 합니다. 인터럽트는 device tree에서 generic-uio로 묶인 /dev/uio0 fd로 받습니다.
  • UIO 규칙
    • fd에 4바이트 값 1을 write → 인터럽트 다시 켜기(unmask)
    • 인터럽트가 오면 fd가 readable → 4바이트 read = 지금까지의 인터럽트 총 횟수
  • pgen 레지스터: CTRL(0x00, b0 START) · STATUS(0x04, b0 BUSY, b1 DONE, b15:8 RESULT) · ID(0x08, 0xC0DE0101) · SCRATCH(0x0C)
  • 하드웨어 없이 macOS에서 테스트합니다. /dev/mem 대신 sparse temp 파일을 쓰고(물리 주소 P = 파일 offset P), 같은 파일을 mmap한 thread가 PL IP 역할을 합니다. UIO는 socketpair(양방향 pipe)로 흉내 냅니다.

예시를 말로 풀면

  • regmap_open(0xA001_0000, 0x1000) → ID 읽으면 0xC0DE0101. SCRATCH에 0xDEADBEEF를 쓰면 device 쪽에서 그 값이 보이고, device가 바꾼 값도 다음 read에서 바로 보입니다.
  • regmap_open(0xA001_0F00, 0x200)(페이지 중간에서 시작): 4 KiB 페이지면 0xA001_0000부터 2페이지(0x2000) 를 mmap하고 base = map + 0xF00. offset 0x100 = 물리 0xA001_1000(페이지 경계)도 맞게 읽혀야 합니다.
  • 같은 map에서 reg_rd32(0x200)은 mmap 범위 안이지만 len 밖이므로 0xFFFFFFFF, reg_wr32(0x200, …)는 아무것도 안 씁니다.
  • CTRL.START를 쓰면 IP thread가 20 ms 뒤 STATUS.DONE과 RESULT = 0x5A를 세웁니다 → reg_poll(STATUS, DONE, DONE, 2000)은 0. 절대 안 서는 비트를 50 ms 기다리면 -ETIMEDOUT.
  • UIO: 마지막으로 본 횟수 1, 이번에 읽은 횟수 4 → 반환 2(두 개 놓침), *count = 4. 마지막 0xFFFFFFFF → 새 1은 wrap이라 반환 1.

지켜야 할 조건

  • C11 + POSIX, malloc 금지. 함수는 errno를 남기지 말고 -errno를 반환.
  • 레지스터 접근은 반드시 한 번의 32-bit volatile load/store.
  • 테스트는 thread와 socketpair를 쓰지만 타이밍은 넉넉하게(수십 ms ~ 2 s) 잡혀 있습니다.

1. Problem

You are writing the low-level layer of a userspace validation tool on a Zynq UltraScale+ MPSoC running PetaLinux. A PL IP block (pgen) sits behind M_AXI_HPM0_FPD at physical address 0xA001_0000; there is no kernel driver for it. The tool reaches the registers by mmap()ing /dev/mem, and receives the IP's interrupt through a UIO device (/dev/uio0, bound with compatible = "generic-uio").

UIO semantics: writing a 4-byte 1 to the fd re-enables (unmasks) the interrupt; when the interrupt fires, the fd becomes readable and a 4-byte read() returns the total interrupt count.

#define REG_BAD 0xFFFFFFFFu

struct regmap {
    int               fd;        /* -1 when closed */
    void             *map;       /* page-aligned mmap() result, NULL when closed */
    size_t            map_len;   /* bytes mapped, multiple of the page size */
    volatile uint8_t *base;      /* register offset 0 (= map + in-page offset) */
    size_t            len;       /* register window in bytes */
    uint64_t          phys;      /* physical address of offset 0 */
};

int      regmap_open(struct regmap *m, const char *path, uint64_t phys, size_t len);
void     regmap_close(struct regmap *m);
uint32_t reg_rd32(const struct regmap *m, uint32_t off);
void     reg_wr32(const struct regmap *m, uint32_t off, uint32_t val);
int      reg_poll(const struct regmap *m, uint32_t off, uint32_t mask, uint32_t want,
                  unsigned timeout_ms);
int      uio_wait_irq(int fd, unsigned timeout_ms, uint32_t *count);

Requirements:

  • regmap_open: m or path NULL, len == 0, phys or len not 4-byte aligned, or phys + len overflowing → -EINVAL. Open with O_RDWR | O_SYNC, mmap() the page-aligned window that covers [phys, phys + len) (page size from sysconf(_SC_PAGESIZE)), and set base to the register at phys. Return 0 or -errno. On any failure leave m closed (fd = -1, map = NULL, base = NULL) and leak nothing.
  • regmap_close: unmap and close; safe on a closed regmap and when called twice.
  • reg_rd32 / reg_wr32: one 32-bit volatile access at base + off. Contract: off must be 4-byte aligned and off + 4 <= len. A bad offset (or a closed / NULL map) does no bus access: read returns REG_BAD, write is dropped.
  • reg_poll: wait until (reg & mask) == want, using a CLOCK_MONOTONIC deadline. Return 0 or -ETIMEDOUT. The register must be read at least once after the deadline before giving up. Bad offset, or want has bits outside mask → -EINVAL.
  • uio_wait_irq: write a 4-byte 1, poll() for POLLIN up to timeout_ms, read the 4-byte count. *count is in/out: in = the last count the caller saw, out = the new count. Return the number of missed interrupts (new - last - 1, so 0 means exactly one new interrupt), -ETIMEDOUT, -EIO (short read/write, EOF, or the count did not advance), -EINVAL (count NULL), or -errno from write/poll/read. Retry on EINTR.

The harness runs on macOS/Linux without hardware: "/dev/mem" is a sparse temp file (physical address P = file offset P), a thread maps the same pages and plays the PL IP, and UIO is a socketpair() whose device end reads your unmask word and writes counts.

Example

regmap_open(&m, devmem, 0xA0010000, 0x1000)       -> 0, base == map, map_len = 1 page
reg_rd32(&m, 0x08)                                -> 0xC0DE0101       (ID)

regmap_open(&m, devmem, 0xA0010F00, 0x200)        -> 0   (4 KiB pages)
  page_base = 0xA0010000, base = map + 0xF00, map_len = 0x2000
  reg_rd32(&m, 0x100)  -> value at phys 0xA0011000 (crosses the page boundary)
  reg_rd32(&m, 0x200)  -> 0xFFFFFFFF  (mapped slack, but off + 4 > len)
  reg_rd32(&m, 0x102)  -> 0xFFFFFFFF  (misaligned)

reg_wr32(CTRL, START); reg_poll(STATUS, DONE, DONE, 2000) -> 0 after ~20 ms, RESULT = 0x5A
reg_poll(STATUS, DONE, DONE, 50)  on a bit that never sets -> -ETIMEDOUT after >= 50 ms

last = 1; device count = 4  -> uio_wait_irq(...) = 2, last = 4      (two missed)
last = 0xFFFFFFFF; count 1  -> 1                                     (wrap-safe)
last = 4; count 4           -> -EIO                                  (count did not advance)
nothing fires in 50 ms      -> -ETIMEDOUT, last unchanged

Constraints

  • C11 + POSIX (open, mmap, poll, clock_gettime). No malloc. Return -errno, never -1.
  • Every register access is exactly one 32-bit volatile load or store.
  • off_t must be 64-bit (_FILE_OFFSET_BITS=64 on 32-bit ARM), checked by a _Static_assert.

Clarifying questions to ask (first 3 minutes)

  1. Is the IP's address range 4 KiB-aligned in the Vivado address editor, or can the tool be asked to map an arbitrary sub-range?
  2. Does the AXI-Lite slave accept only 32-bit accesses? Any read-to-clear or FIFO registers (so a stray read is harmful)?
  3. Is the interrupt level or edge, and who clears the source — the tool via a W1C status register?
  4. Is CONFIG_STRICT_DEVMEM / CONFIG_IO_STRICT_DEVMEM set on this image, and does a kernel driver already claim this range?
  5. Can more than one process open the UIO device? (decides how much a count jump means)
  6. What should happen if the PL is not programmed or its clock is off — fail fast, or is a hang acceptable on a bring-up board?

/* PL IP "pgen" register map (offsets from 0xA001_0000) */
#define PL_BASE      0xA0010000ull
#define REG_CTRL     0x00u     /* b0 START (self-clearing)          */
#define REG_STATUS   0x04u     /* b0 BUSY | b1 DONE | b15:8 RESULT  */
#define REG_ID       0x08u     /* reads PGEN_ID                     */
#define REG_SCRATCH  0x0Cu
#define CTRL_START   (1u << 0)
#define ST_BUSY      (1u << 0)
#define ST_DONE      (1u << 1)
#define PGEN_ID      0xC0DE0101u
#define DEV_SPAN     0x10000u  /* harness maps 64 KiB of "PL" (multiple of 4K and 16K pages) */

static volatile uint32_t *dev;  /* the device's own view of the same file pages */
static inline uint32_t dget(uint32_t off) { return dev[off / 4]; }
static inline void dset(uint32_t off, uint32_t v) { dev[off / 4] = v; }

static int64_t test_ms(void)
{
    struct timespec t;
    clock_gettime(CLOCK_MONOTONIC, &t);
    return (int64_t)t.tv_sec * 1000 + t.tv_nsec / 1000000;

static void sleep_ms(int ms)
{
    struct timespec t = { ms / 1000, (long)(ms % 1000) * 1000000L };
    nanosleep(&t, NULL);
}

/* PL IP model: wait for START, stay BUSY 20 ms, then DONE with RESULT = 0x5A. */
static atomic_int ip_quit, ip_starts;
static void *pl_ip_thread(void *arg)
{
    (void)arg;
    for (int t = 0; t < 2000 && !atomic_load(&ip_quit); t++) {
        if (dget(REG_CTRL) & CTRL_START) {
            atomic_fetch_add(&ip_starts, 1);
            dset(REG_CTRL, 0);                     /* START self-clears */
            dset(REG_STATUS, ST_BUSY);
            sleep_ms(20);
            dset(REG_STATUS, ST_DONE | (0x5Au << 8));
            return NULL;
        }
        sleep_ms(1);
    }
    return NULL;
}

/* UIO model: fires only after the IRQ is unmasked (like a masked level IRQ). */
typedef struct { int fd; uint32_t fire; int unmask_seen; } UioDev;
static void *uio_dev_thread(void *arg)
{
    UioDev *u = arg;
    struct pollfd p = { .fd = u->fd, .events = POLLIN, .revents = 0 };
    uint32_t v = 0;
    if (poll(&p, 1, 3000) == 1 && read(u->fd, &v, 4) == 4 && v == 1) {
        u->unmask_seen = 1;
        sleep_ms(20);
        (void)!write(u->fd, &u->fire, 4);          /* "IRQ": kernel bumps the count */
    }
    return NULL;
}

/* device end: read back what the tool wrote; returns words read (expects exactly one 1) */
static int drain_unmask(int dfd, uint32_t *last)
{
    int k = 0;
    uint32_t v;
    struct pollfd p = { .fd = dfd, .events = POLLIN, .revents = 0 };
    while (poll(&p, 1, 0) == 1 && (p.revents & POLLIN) && read(dfd, &v, 4) == 4) { *last = v; k++; }
    return k;
}
static void fire(int dfd, uint32_t c) { (void)!write(dfd, &c, 4); }

    dset(0x1100, 0x5A5A5A5Au);                           /* phys 0xA0011100 = first byte past the window */
    CHECK(regmap_open(&m, path, PL_BASE + 0xF00, 0x200) == 0);
    CHECK((uintptr_t)m.base - (uintptr_t)m.map == 0xF00);
    CHECK(m.map_len == (0xF00 + 0x200 + pg - 1) / pg * pg);   /* 0x2000 on 4K pages */
    CHECK(reg_rd32(&m, 0x100) == 0x600DCAFEu);
    reg_wr32(&m, 0x1FC, 0xA1B2C3D4u);                    /* last valid register */
    CHECK(dget(0x10FC) == 0xA1B2C3D4u);

    /* 3. bounds contract: off + 4 > len or misaligned -> no access */
    CHECK(reg_rd32(&m, 0x200) == REG_BAD);               /* mapped slack, but outside len */
    reg_wr32(&m, 0x200, 0);
    CHECK(dget(0x1100) == 0x5A5A5A5Au);                  /* write was dropped */
    CHECK(reg_rd32(&m, 0x102) == REG_BAD);
    reg_wr32(&m, 0xFFFFFFFCu, 0);                        /* off + 4 wraps in 32 bits */
    CHECK(reg_rd32(NULL, 0) == REG_BAD);
    regmap_close(&m);
    CHECK(reg_rd32(&m, 0x100) == REG_BAD);               /* closed map */

    CHECK(regmap_open(&m, path, PL_BASE, 0) == -EINVAL);
    CHECK(m.fd == -1 && m.map == NULL);
    CHECK(regmap_open(&m, path, PL_BASE + 2, 0x100) == -EINVAL);

    CHECK(m.fd == -1 && m.map == NULL && m.base == NULL);

3. 힌트 (막힐 때 하나씩)

Hint 1 — mmap offset은 페이지 배수여야 함

mmap()의 offset은 페이지 크기의 배수여야 합니다(아니면 EINVAL). 그래서 page_base = phys & ~(pg - 1)부터 매핑하고, delta = phys - page_base만큼 base를 밀어 줍니다. 길이는 len이 아니라 delta + len을 페이지 단위로 올림합니다. 끝을 빼먹으면 페이지 경계를 넘는 레지스터가 잘립니다.

Hint 2 — poll 루프에서 "시간 먼저, 읽기 나중"

루프마다 먼저 시간을 보고(late = now >= deadline), 그다음 레지스터를 읽고, 맞으면 0, 아니고 late였으면 -ETIMEDOUT. 이렇게 하면 마지막 read가 항상 deadline 뒤에 일어납니다. 반대 순서면 스케줄러가 툴을 오래 재운 경우 "실제로는 DONE인데 timeout"이 나옵니다.

Hint 3 — UIO count는 unsigned 차이로

delta = new - last를 uint32_t로 계산하면 2^32 wrap에서도 맞습니다. delta == 1이면 정상(반환 0), delta > 1이면 delta - 1개를 놓친 것, delta == 0이면 이상한 상태(-EIO). unmask write는 poll 전에 합니다. 테스트 7번의 device thread는 unmask를 받아야만 인터럽트를 냅니다.

4. 풀이

4.1 핵심 아이디어 — 페이지 정렬된 창 + 안쪽 offset

/dev/mem의 파일 offset이 곧 물리 주소입니다. mmap은 페이지 단위로만 되므로 "원하는 구간을 덮는 가장 작은 페이지 묶음"을 매핑하고, 그 안에서 레지스터 0번 위치를 기억합니다.

  • munmap()에는 base가 아니라 map(페이지 정렬된 원래 주소) 과 map_len을 넘깁니다. 그래서 구조체에 둘 다 둡니다.
  • 경계 검사는 map_len이 아니라 len 기준입니다. slack 영역은 다른 IP의 레지스터일 수 있습니다.

4.2 UIO 인터럽트 핸드셰이크

  • ①을 ②보다 먼저: unmask 없이 poll하면 영원히(또는 timeout까지) 기다립니다. 테스트 7번 device thread가 이 순서를 확인합니다.
  • ⑥은 호출자 책임: uio_wait_irq()가 돌아온 뒤 IP의 W1C status를 지우고 다음 호출에서 unmask합니다.
  • count는 장치 전체 누적값입니다. 차이로 놓친 횟수를 계산합니다.

/*
 * L1  Userspace Register Access on Zynq PetaLinux (/dev/mem + UIO)
 * Reference solution.
 *
 * A validation tool on Zynq UltraScale+ (PetaLinux) drives a PL IP block from userspace.
 * The IP sits behind M_AXI_HPM0_FPD at physical 0xA001_0000. Registers are reached by
 * mmap()ing /dev/mem; the IP's interrupt is exposed by the generic-uio driver as /dev/uioN.
 *
 * Implement:
 *   regmap_open   validate args (m/path NULL, len 0, phys or len not 4-byte aligned,
 *                 phys + len overflows -> -EINVAL). open(path, O_RDWR | O_SYNC), mmap the
 *                 page-aligned window that covers [phys, phys + len) (page = sysconf(_SC_PAGESIZE)),
 *                 set base = map + (phys - page_base). Return 0 or -errno.
 *                 On ANY failure the regmap is left closed (fd = -1, map = NULL, base = NULL).
 *   regmap_close  munmap + close; safe on a closed regmap and when called twice.
 *   reg_rd32 / reg_wr32
 *                 32-bit volatile access at base + off. Contract: off must be 4-byte aligned
 *                 and off + 4 <= len. A bad offset does NO bus access: read returns REG_BAD
 *                 (0xFFFFFFFF, like an aborted PCIe read), write is dropped.
 *   reg_poll      wait until (reg & mask) == want. CLOCK_MONOTONIC deadline; the register is
 *                 always read once more after the deadline. 0 or -ETIMEDOUT.
 *                 Bad offset, or want has bits outside mask -> -EINVAL.
 *   uio_wait_irq  UIO handshake: write a 4-byte 1 (re-enable the IRQ), poll() for POLLIN,
 *                 read the 4-byte interrupt count.
 *                 *count is IN/OUT: in = last count the caller saw, out = new count.
 *                 Returns the number of MISSED interrupts (0 = exactly one new IRQ),
 *                 -ETIMEDOUT, -EIO (short read/write, EOF, or count did not advance),
 *                 -EINVAL (count NULL), or -errno from write/poll/read.
 *
 * Harness (no hardware, works on macOS): "/dev/mem" is a sparse temp file, so physical
 * address P is file offset P. A helper thread maps the same file pages and plays the PL IP.
 * UIO is a socketpair: the device end reads the 1 we write and writes 4-byte counts.

static void regmap_reset(struct regmap *m)
{
    m->fd = -1; m->map = NULL; m->map_len = 0; m->base = NULL; m->len = 0; m->phys = 0;
}

int regmap_open(struct regmap *m, const char *path, uint64_t phys, size_t len)
{
    if (m == NULL) return -EINVAL;
    regmap_reset(m);                               /* closed on every failure path */
    if (path == NULL || len == 0 || (phys & 3u) != 0 || (len & 3u) != 0)
        return -EINVAL;
    if ((uint64_t)len > UINT64_MAX - phys) return -EINVAL;   /* phys + len wraps */

    long pg = sysconf(_SC_PAGESIZE);
    if (pg <= 0) return -EINVAL;
    uint64_t pmask = (uint64_t)pg - 1;
    uint64_t page_base = phys & ~pmask;
    uint64_t delta = phys - page_base;             /* in-page offset of register 0 */
    if ((uint64_t)len > SIZE_MAX - delta - pmask) return -EINVAL;
    size_t map_len = (size_t)((delta + len + pmask) & ~pmask);
    if (page_base > (uint64_t)INT64_MAX) return -EOVERFLOW;  /* off_t is signed */

    int fd = open(path, O_RDWR | O_SYNC | O_CLOEXEC);
    if (fd < 0) return -errno;
    void *p = mmap(NULL, map_len, PROT_READ | PROT_WRITE, MAP_SHARED, fd, (off_t)page_base);
    if (p == MAP_FAILED) {
        int e = errno;
        close(fd);
        return -e;
    }
    m->fd = fd;
    m->map = p;
    m->map_len = map_len;
    m->base = (volatile uint8_t *)p + delta;
    m->len = len;
    m->phys = phys;
    return 0;
}

void regmap_close(struct regmap *m)
{
    if (m == NULL) return;
    if (m->map != NULL) munmap(m->map, m->map_len);
    if (m->fd >= 0) close(m->fd);
    regmap_reset(m);                               /* second close is a no-op */
}

static bool reg_ok(const struct regmap *m, uint32_t off)
{
    return m != NULL && m->base != NULL && (off & 3u) == 0 && (size_t)off + 4u <= m->len;
}

uint32_t reg_rd32(const struct regmap *m, uint32_t off)
{
    if (!reg_ok(m, off)) return REG_BAD;           /* no bus access */
    return *(volatile uint32_t *)(m->base + off);  /* exactly one 32-bit load */
}

void reg_wr32(const struct regmap *m, uint32_t off, uint32_t val)
{
    if (!reg_ok(m, off)) return;                   /* dropped */
    *(volatile uint32_t *)(m->base + off) = val;   /* exactly one 32-bit store */
}

static int64_t mono_ns(void)
{
    struct timespec t;
    clock_gettime(CLOCK_MONOTONIC, &t);            /* never jumps with NTP / date */
    return (int64_t)t.tv_sec * 1000000000 + t.tv_nsec;
}

int reg_poll(const struct regmap *m, uint32_t off, uint32_t mask, uint32_t want,
             unsigned timeout_ms)
{
    if (!reg_ok(m, off) || (want & ~mask) != 0) return -EINVAL;   /* could never match */
    const int64_t deadline = mono_ns() + (int64_t)timeout_ms * 1000000;
    const struct timespec nap = { 0, 20 * 1000 };  /* 20 us between reads */
    for (;;) {
        bool late = mono_ns() >= deadline;         /* sample time BEFORE the read */
        if ((reg_rd32(m, off) & mask) == want) return 0;
        if (late) return -ETIMEDOUT;               /* last read happened after the deadline */
        nanosleep(&nap, NULL);
    }
}

int uio_wait_irq(int fd, unsigned timeout_ms, uint32_t *count)
{
    if (count == NULL) return -EINVAL;

    uint32_t one = 1;                              /* irqcontrol: 1 = enable (unmask) */
    ssize_t w;
    do { w = write(fd, &one, sizeof one); } while (w < 0 && errno == EINTR);
    if (w < 0) return -errno;
    if (w != (ssize_t)sizeof one) return -EIO;

    const int64_t deadline = mono_ns() + (int64_t)timeout_ms * 1000000;
    struct pollfd p = { .fd = fd, .events = POLLIN, .revents = 0 };
    for (;;) {
        int64_t left = deadline - mono_ns();
        int ms = left <= 0 ? 0
               : left / 1000000 >= INT_MAX ? INT_MAX
               : (int)((left + 999999) / 1000000);
        int r = poll(&p, 1, ms);
        if (r > 0) break;
        if (r == 0) return -ETIMEDOUT;
        if (errno != EINTR) return -errno;         /* EINTR: retry with the time left */
    }
    if ((p.revents & POLLIN) == 0) return -EIO;    /* POLLERR / POLLHUP / POLLNVAL only */

    uint32_t c;
    ssize_t n;
    do { n = read(fd, &c, sizeof c); } while (n < 0 && errno == EINTR);
    if (n < 0) return -errno;
    if (n != (ssize_t)sizeof c) return -EIO;       /* EOF or short read */

    uint32_t delta = c - *count;                   /* wrap-safe */
    *count = c;
    if (delta == 0) return -EIO;                   /* woke up but count did not move */
    return delta - 1 > (uint32_t)INT_MAX ? INT_MAX : (int)(delta - 1);
}

/* PL IP model: wait for START, stay BUSY 20 ms, then DONE with RESULT = 0x5A. */
static atomic_int ip_quit, ip_starts;
static void *pl_ip_thread(void *arg)
{
    (void)arg;
    for (int t = 0; t < 2000 && !atomic_load(&ip_quit); t++) {
        if (dget(REG_CTRL) & CTRL_START) {
            atomic_fetch_add(&ip_starts, 1);
            dset(REG_CTRL, 0);                     /* START self-clears */
            dset(REG_STATUS, ST_BUSY);
            sleep_ms(20);
            dset(REG_STATUS, ST_DONE | (0x5Au << 8));
            return NULL;
        }
        sleep_ms(1);
    }
    return NULL;
}

/* UIO model: fires only after the IRQ is unmasked (like a masked level IRQ). */
typedef struct { int fd; uint32_t fire; int unmask_seen; } UioDev;
static void *uio_dev_thread(void *arg)
{
    UioDev *u = arg;
    struct pollfd p = { .fd = u->fd, .events = POLLIN, .revents = 0 };
    uint32_t v = 0;
    if (poll(&p, 1, 3000) == 1 && read(u->fd, &v, 4) == 4 && v == 1) {
        u->unmask_seen = 1;
        sleep_ms(20);
        (void)!write(u->fd, &u->fire, 4);          /* "IRQ": kernel bumps the count */

    return NULL;
}

/* device end: read back what the tool wrote; returns words read (expects exactly one 1) */
static int drain_unmask(int dfd, uint32_t *last)
{
    int k = 0;
    uint32_t v;
    struct pollfd p = { .fd = dfd, .events = POLLIN, .revents = 0 };
    while (poll(&p, 1, 0) == 1 && (p.revents & POLLIN) && read(dfd, &v, 4) == 4) { *last = v; k++; }
    return k;
}
static void fire(int dfd, uint32_t c) { (void)!write(dfd, &c, 4); }

    snprintf(path, sizeof path, "%s/l1_devmem_XXXXXX", tmp && *tmp ? tmp : "/tmp");
    int hfd = mkstemp(path);
    if (hfd < 0 || ftruncate(hfd, (off_t)(PL_BASE + DEV_SPAN)) != 0) {
        printf("harness: cannot create sparse /dev/mem file\n");
        return 2;
    }
    void *dv = mmap(NULL, DEV_SPAN, PROT_READ | PROT_WRITE, MAP_SHARED, hfd, (off_t)PL_BASE);
    if (dv == MAP_FAILED) { printf("harness: mmap failed\n"); unlink(path); return 2; }
    dev = dv;
    const size_t pg = (size_t)sysconf(_SC_PAGESIZE);
    dset(REG_ID, PGEN_ID);

    /* 1. aligned window: map fields, ID read, write reaches the device, device write is seen */
    struct regmap m = {0};
    CHECK(regmap_open(&m, path, PL_BASE, 0x1000) == 0);
    CHECK(m.fd >= 0 && m.map != NULL && m.len == 0x1000 && m.phys == PL_BASE);
    CHECK((uintptr_t)m.map % pg == 0 && m.map_len == (0x1000 + pg - 1) / pg * pg);
    CHECK((uintptr_t)m.base == (uintptr_t)m.map);
    CHECK(reg_rd32(&m, REG_ID) == PGEN_ID);
    reg_wr32(&m, REG_SCRATCH, 0xDEADBEEFu);
    CHECK(dget(REG_SCRATCH) == 0xDEADBEEFu);
    dset(REG_SCRATCH, 0x12345678u);                      /* HW changes it behind our back */
    CHECK(reg_rd32(&m, REG_SCRATCH) == 0x12345678u);
    int oldfd = m.fd;
    regmap_close(&m);
    CHECK(m.fd == -1 && m.map == NULL && m.base == NULL);
    CHECK(oldfd > 2 && fcntl(oldfd, F_GETFD) == -1 && errno == EBADF);   /* really closed */
    regmap_close(&m);                                    /* double close is safe */

    /* 2. unaligned phys 0xA0010F00, len 0x200: in-page offset 0xF00, window spans a 4K page boundary */
    dset(0x1000, 0x600DCAFEu);                           /* phys 0xA0011000 = window off 0x100 */
    dset(0x1100, 0x5A5A5A5Au);                           /* phys 0xA0011100 = first byte past the window */
    CHECK(regmap_open(&m, path, PL_BASE + 0xF00, 0x200) == 0);
    CHECK((uintptr_t)m.base - (uintptr_t)m.map == 0xF00);
    CHECK(m.map_len == (0xF00 + 0x200 + pg - 1) / pg * pg);   /* 0x2000 on 4K pages */
    CHECK(reg_rd32(&m, 0x100) == 0x600DCAFEu);
    reg_wr32(&m, 0x1FC, 0xA1B2C3D4u);                    /* last valid register */
    CHECK(dget(0x10FC) == 0xA1B2C3D4u);

    /* 3. bounds contract: off + 4 > len or misaligned -> no access */
    CHECK(reg_rd32(&m, 0x200) == REG_BAD);               /* mapped slack, but outside len */
    reg_wr32(&m, 0x200, 0);
    CHECK(dget(0x1100) == 0x5A5A5A5Au);                  /* write was dropped */
    CHECK(reg_rd32(&m, 0x102) == REG_BAD);
    reg_wr32(&m, 0xFFFFFFFCu, 0);                        /* off + 4 wraps in 32 bits */
    CHECK(reg_rd32(NULL, 0) == REG_BAD);
    regmap_close(&m);
    CHECK(reg_rd32(&m, 0x100) == REG_BAD);               /* closed map */

    /* 4. argument validation; on failure the regmap is left closed */
    CHECK(regmap_open(&m, path, PL_BASE, 0) == -EINVAL);
    CHECK(m.fd == -1 && m.map == NULL);
    CHECK(regmap_open(&m, path, PL_BASE + 2, 0x100) == -EINVAL);
    CHECK(regmap_open(&m, path, PL_BASE, 6) == -EINVAL);
    CHECK(regmap_open(&m, path, UINT64_MAX - 3, 8) == -EINVAL);
    CHECK(regmap_open(&m, NULL, PL_BASE, 0x100) == -EINVAL);
    CHECK(regmap_open(NULL, path, PL_BASE, 0x100) == -EINVAL);
    CHECK(regmap_open(&m, "/nonexistent/l1/devmem", PL_BASE, 0x100) == -ENOENT);
    CHECK(m.fd == -1 && m.map == NULL && m.base == NULL);
    regmap_close(&m);

    /* 5. reg_poll */
    CHECK(regmap_open(&m, path, PL_BASE, 0x1000) == 0);
    dset(REG_STATUS, 0); dset(REG_CTRL, 0);
    CHECK(reg_poll(&m, REG_STATUS, ST_BUSY, 0, 0) == 0);              /* already true, timeout 0 */
    int64_t t0 = test_ms();
    CHECK(reg_poll(&m, REG_STATUS, ST_DONE, ST_DONE, 50) == -ETIMEDOUT);
    int64_t dt = test_ms() - t0;
    CHECK(dt >= 45 && dt < 1500);
    CHECK(reg_poll(&m, REG_STATUS, ST_DONE, ST_DONE | ST_BUSY, 10) == -EINVAL);  /* want outside mask */
    CHECK(reg_poll(&m, 0x1000, 1, 1, 10) == -EINVAL);                   /* off out of range */
    pthread_t th;
    atomic_store(&ip_quit, 0); atomic_store(&ip_starts, 0);
    pthread_create(&th, NULL, pl_ip_thread, NULL);
    reg_wr32(&m, REG_CTRL, CTRL_START);
    t0 = test_ms();
    CHECK(reg_poll(&m, REG_STATUS, ST_DONE, ST_DONE, 2000) == 0);
    dt = test_ms() - t0;
    atomic_store(&ip_quit, 1);
    pthread_join(th, NULL);
    CHECK(atomic_load(&ip_starts) == 1 && dt >= 15 && dt < 1500);
    CHECK(((reg_rd32(&m, REG_STATUS) >> 8) & 0xFFu) == 0x5Au);
    regmap_close(&m);

    /* 6. uio_wait_irq: unmask word, count, missed interrupts, wrap, stale count */
    int sv[2];
    CHECK(socketpair(AF_UNIX, SOCK_STREAM, 0, sv) == 0);
    int ufd = sv[0], dfd = sv[1];
    uint32_t last = 0, got = 0;
    fire(dfd, 1);
    CHECK(uio_wait_irq(ufd, 1000, &last) == 0 && last == 1);
    CHECK(drain_unmask(dfd, &got) == 1 && got == 1);     /* exactly one 4-byte 1 */
    fire(dfd, 4);
    CHECK(uio_wait_irq(ufd, 1000, &last) == 2 && last == 4);   /* 1 -> 4: two missed */
    drain_unmask(dfd, &got);
    last = 0xFFFFFFFFu; fire(dfd, 1);
    CHECK(uio_wait_irq(ufd, 1000, &last) == 1 && last == 1);   /* wraps: 0xFFFFFFFF -> 0 -> 1 */
    drain_unmask(dfd, &got);
    last = 4; fire(dfd, 4);
    CHECK(uio_wait_irq(ufd, 1000, &last) == -EIO);       /* count did not advance */
    drain_unmask(dfd, &got);
    CHECK(uio_wait_irq(ufd, 100, NULL) == -EINVAL);

    /* 7. timeout, then a device that fires only after unmask (order matters) */
    last = 4; got = 0;
    t0 = test_ms();
    CHECK(uio_wait_irq(ufd, 50, &last) == -ETIMEDOUT && last == 4);
    dt = test_ms() - t0;
    CHECK(dt >= 45 && dt < 1500);
    CHECK(drain_unmask(dfd, &got) == 1 && got == 1);     /* still unmasked before waiting */
    UioDev ud = { dfd, 5, 0 };
    pthread_create(&th, NULL, uio_dev_thread, &ud);
    t0 = test_ms();
    int r = uio_wait_irq(ufd, 2000, &last);
    dt = test_ms() - t0;
    close(ufd);                                          /* lets the device thread exit if stuck */
    pthread_join(th, NULL);
    CHECK(r == 0 && last == 5 && ud.unmask_seen == 1 && dt >= 15);

    /* 8. errors from the fd itself */
    CHECK(uio_wait_irq(ufd, 10, &last) == -EBADF);       /* closed fd */
    CHECK(socketpair(AF_UNIX, SOCK_STREAM, 0, sv) == 0);
    close(sv[1]);                                        /* device side gone */
    CHECK(uio_wait_irq(sv[0], 10, &last) == -EPIPE);
    close(sv[0]);
    close(dfd);

    munmap(dv, DEV_SPAN);
    close(hfd);
    unlink(path);
    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

코드 읽는 포인트

  • regmap_open은 맨 처음 regmap_reset(m)으로 닫힌 상태를 만들어 둡니다. 이후 어느 경로로 실패해도 fd = -1이 보장되고, mmap 실패 시에는 errno를 먼저 저장한 뒤 close(fd)합니다(close가 errno를 덮어쓸 수 있음).
  • overflow 검사 두 개: len > UINT64_MAX - phys(물리 주소 wrap), len > SIZE_MAX - delta - pmask(올림 계산 wrap). page_base > INT64_MAX는 signed off_t에 안 들어가므로 -EOVERFLOW.
  • reg_ok의 (size_t)off + 4u <= m->len: off + 4를 uint32_t로 계산하면 0xFFFFFFFC + 4 = 0이 되어 검사를 통과합니다.
  • 접근은 *(volatile uint32_t *)(m->base + off) 한 줄. base가 volatile uint8_t *이고 off가 4의 배수라 정렬이 맞습니다.
  • reg_poll은 20 µs nanosleep으로 CPU를 양보합니다. bring-up 툴에서는 충분하고, µs 단위 지연 측정이 필요하면 sleep 없이 spin합니다.
  • uio_wait_irq는 남은 시간을 매번 다시 계산해 EINTR 뒤에도 전체 timeout을 지킵니다. POLLIN 없이 POLLHUP/POLLERR만 오면 -EIO.

4.5 복잡도

  • regmap_open/close: syscall 2–3개, O(1). reg_rd32/wr32: 버스 접근 1회.
  • reg_poll: 읽기 횟수 ≈ timeout / (20 µs + syscall 시간). 50 ms면 수백~수천 번. 메모리 O(1).
  • uio_wait_irq: syscall 3개(write, poll, read), 기다리는 동안 CPU 0.

5. 임베디드 관점으로 말할 것

  • PS ↔ PL 경로: ZynqMP에서 PS가 PL 레지스터를 읽는 길은 M_AXI_HPM0_FPD(0xA000_0000 – 0xAFFF_FFFF, 256 MB), HPM1_FPD(0xB000_0000 –), HPM0_LPD(0x8000_0000 –)입니다. Zynq-7000은 M_AXI_GP0(0x4000_0000 – 0x7FFF_FFFF)라서 Vivado 기본 주소가 0x43C0_0000입니다. 주소는 Vivado Address Editor → XSA → PetaLinux가 만든 pl.dtsi에 그대로 들어갑니다.
  • O_SYNC와 memory type: arm64 커널의 /dev/mem mmap은 RAM이 아닌 주소(PL 레지스터)를 항상 Device memory(Device-nGnRnE, uncached) 로 매핑합니다. O_SYNC가 실제로 차이를 내는 곳은 RAM(예: PL DMA와 공유하는 reserved DDR) 쪽으로, 이때 cached 대신 Normal-NC(write-combine)가 됩니다. 그래도 항상 O_SYNC를 붙이는 게 이식성 있는 습관입니다(x86 등은 이걸로 UC를 결정).
  • 왜 volatile이고 memcpy가 아닌가: 컴파일러는 일반 포인터 read를 루프 밖으로 빼거나 합치거나 없앱니다(-O2에서 poll 무한 루프). memcpy는 크기·정렬에 따라 바이트 단위, 64/128-bit(ldp q), 비정렬 접근을 씁니다. AXI-Lite slave는 32-bit 접근만 받고, Device memory에 비정렬 접근을 하면 alignment fault(SIGBUS) 입니다. glibc memset은 DC ZVA를 써서 Device memory에서 바로 fault 납니다. read-to-clear / FIFO 레지스터는 한 번 더 읽는 것 자체가 버그입니다.
  • volatile은 순서 보장이 아님: 같은 장치에 대한 Device memory 접근끼리는 순서가 지켜지지만, "DDR 버퍼 쓰기 → PL 도어벨 레지스터"처럼 Normal memory와 섞이면 __sync_synchronize()(arm64 dmb ish) 또는 dsb st가 필요합니다 → V3의 dma_wmb()와 같은 이야기.
  • device tree + generic-uio: PetaLinux system-user.dtsi에서 IP 노드를 덮어씁니다.
&pgen_0 {                                  /* node generated in pl.dtsi */
    compatible = "generic-uio";
    interrupt-parent = <&gic>;
    interrupts = <0 89 4>;                 /* pl_ps_irq0[0] = SPI 89, level-high */
};
/ { chosen { bootargs = "earlycon console=ttyPS0,115200 clk_ignore_unused uio_pdrv_genirq.of_id=generic-uio"; }; };

uio_pdrv_genirq는 기본으로 아무 compatible에도 안 붙기 때문에 of_id=generic-uio 모듈 파라미터가 필요합니다. 확인은 /sys/class/uio/uio0/name, maps/map0/addr, maps/map0/size. UIO fd 자체를 mmap하면(offset = map 번호 × page size) /dev/mem 없이도 레지스터에 접근됩니다.

5.1 면접관 Iris Lee(SW·시스템 출신 Principal)가 파고들 포인트

  • "Why /dev/mem here, and when would you stop using it?" → bring-up 첫날과 레지스터 peek/poke에는 /dev/mem이 가장 빠릅니다. 인터럽트가 필요해지면 UIO, DMA·전원 관리·여러 프로세스 공유가 필요해지면 커널 드라이버로 옮깁니다. 이 regmap 층을 두면 위의 테스트 코드는 그대로입니다. "I start with /dev/mem for day-one peek and poke, move to UIO once I need interrupts, and only write a kernel driver when DMA, power management or sharing make userspace the wrong place — the test code above the regmap layer does not change."
  • "Your tool read 0xA000_0000 and the board hung. Walk me through it." → bitstream 로드 여부(fpga_manager state), PL 클럭(clk_disable_unused), PL reset, Address Editor와 DT 주소 불일치 순으로 봅니다. JTAG(XSDB)로 같은 주소를 읽어 CPU/인터커넥트 문제와 IP 문제를 나눕니다. "First I check the bitstream is loaded and the PL clock was not gated by clk_disable_unused, then I read the same address over JTAG to split an interconnect problem from an IP problem."
  • "How do you know you didn't miss an interrupt?" → UIO count는 누적값이라 차이로 압니다. 다만 uio_pdrv_genirq는 IRQ마다 mask하므로, 정상 흐름에서는 1씩만 늘어납니다. 1보다 크게 뛰면 timeout 뒤에 늦게 온 IRQ, 다른 프로세스가 unmask, 또는 mask를 안 하는 UIO 드라이버입니다. 검증에서는 IP 쪽 이벤트 카운터 레지스터와 UIO count를 비교하는 게 확실합니다. "The count is cumulative, so a jump larger than one is a missed event; I cross-check it against an event counter register in the IP, which is the ground truth."
  • "Would the same code work for a PCIe-attached accelerator?" → 레지스터는 /sys/bus/pci/devices/<BDF>/resource0을 mmap하면 같은 regmap으로 됩니다(offset 0 = BAR 시작). 인터럽트는 UIO 대신 VFIO(MSI-X → eventfd, IOMMU 격리)를 씁니다. 링크가 끊기면 read가 0xFFFFFFFF로 오는데, 그래서 REG_BAD를 같은 값으로 골랐습니다. "Same regmap over the BAR's resource0 file, VFIO with eventfds instead of UIO for MSI-X, and an all-ones read is my cue that the link dropped."
  • "Is polling every 20 µs OK? What about timing accuracy?" → bring-up 툴에서는 CPU 사용량보다 단순함이 중요합니다. 지연을 µs 단위로 재려면 sleep 없이 spin, SCHED_FIFO + mlockall + isolcpus, 또는 IP 안의 타임스탬프 카운터를 씁니다. CLOCK_MONOTONIC이라 NTP/date에 안 흔들립니다. "For bring-up a 20 µs poll is fine; for latency measurements I spin on an isolated SCHED_FIFO core, or better, read a timestamp counter inside the IP."

6. Follow-up 질문과 답

Follow-up (English)답
What does O_SYNC actually change on arm64?PL 레지스터 같은 non-RAM 주소는 O_SYNC가 없어도 Device memory(uncached)로 매핑됩니다. RAM 주소일 때만 차이가 나서 cached 대신 Normal-NC(write-combine)가 됩니다. PL DMA와 공유하는 reserved DDR을 볼 때 중요합니다.
Why not memcpy a block of registers into a struct?접근 폭과 횟수를 제어할 수 없습니다. 64/128-bit나 바이트 접근, 비정렬 접근이 나와서 AXI-Lite가 SLVERR를 주거나 Device memory alignment fault가 납니다. read-to-clear 레지스터는 부작용도 생깁니다. 레지스터마다 32-bit volatile 접근 1회가 원칙입니다.
This tool must also run on a Zynq-7000. What breaks?32-bit ARM이라 off_t가 기본 32-bit입니다. 0xA000_0000 같은 주소는 signed 32-bit에 안 들어가서 mmap이 실패합니다(-D_FILE_OFFSET_BITS=64 필요, 그래서 _Static_assert). 주소도 GP0의 0x43C0_0000 대역으로 바뀌고 페이지는 4 KiB입니다.
How do you read a 64-bit counter over a 32-bit AXI-Lite bus?hi → lo → hi를 읽어 두 hi가 같으면 확정, 다르면 다시 읽습니다. IP가 lo를 읽을 때 hi를 latch하는 설계면 그 순서를 지킵니다. 64-bit 단일 접근은 인터커넥트가 두 번으로 쪼갤 수 있어 원자적이지 않습니다.
mmap of /dev/mem returns EPERM. Why?CONFIG_STRICT_DEVMEM이 RAM 영역을 막았거나, CONFIG_IO_STRICT_DEVMEM에서 이미 드라이버(UIO 포함)가 그 영역을 request_mem_region으로 잡은 경우입니다. root가 아니면 open 단계에서 이미 EACCES/EPERM입니다. 해결은 UIO fd를 mmap하거나 커널 설정 변경입니다.
How would you map registers through the UIO fd instead?mmap(NULL, size, RW, MAP_SHARED, uio_fd, N * page_size)로 mapN을 엽니다. 크기·주소는 /sys/class/uio/uio0/maps/mapN/{size,addr,offset}에서 읽고, 페이지 안 offset은 offset 파일 값만큼 더합니다. 이 문제의 delta와 같은 개념입니다.
Why poll() and not a blocking read()?blocking read는 timeout이 없어 IRQ가 안 오면 툴이 영원히 멈춥니다. poll()은 timeout과 여러 fd(예: 종료 신호용 eventfd, 원격 제어 socket)를 함께 기다릴 수 있습니다. 실제 UIO read는 count가 바뀔 때까지 막히므로 poll로 readable을 확인한 뒤 읽습니다.
Could the count "not advance" on real UIO?정상이라면 아닙니다. UIO read는 이 fd가 마지막으로 본 값과 다를 때만 돌아옵니다. 그래서 delta == 0은 fd 혼동이나 툴 버그를 뜻하는 방어 코드로 -EIO를 줍니다.
How would you measure interrupt latency with this setup?IP가 IRQ를 올린 순간의 타임스탬프 레지스터와, poll()이 깨어난 직후 같은 타임베이스(예: PL의 free-running counter)를 읽어 차이를 냅니다. 수천 번 반복해 min/median/p99/max 히스토그램을 그립니다 → V4. PREEMPT_RT와 CPU 격리가 꼬리 지연을 줄입니다.
The IP gets reset in the middle of a test. What does your tool see?AXI-Lite 레지스터가 reset 값으로 돌아갑니다(ID는 그대로, SCRATCH는 0). PL 전체가 재프로그램되면 접근 자체가 hang/SError 위험입니다. 그래서 긴 테스트는 단계마다 SCRATCH 패턴 쓰고 읽기로 IP가 살아 있는지 확인합니다 → V2.

7. 자주 하는 실수

  • mmap()의 offset에 phys를 그대로 넣음 → 페이지 배수가 아니면 EINVAL (테스트 2번)
  • page_base로 매핑하고 delta를 안 더함 → 페이지 시작 레지스터를 읽음 (테스트 2번 base - map == 0xF00)
  • 매핑 길이를 round_up(len)으로만 계산 → 페이지 경계 뒤 레지스터가 잘려서 SIGBUS/SIGSEGV (테스트 2번 0x1FC)
  • munmap(base, len) → 페이지 정렬이 안 된 주소라 실패, 매핑이 새어 나감
  • 경계 검사를 map_len 기준으로 하거나 off + 4를 uint32_t로 계산 → slack 접근, wrap 통과 (테스트 3번)
  • volatile 없는 포인터로 poll → -O2에서 read가 루프 밖으로 나가 무한 루프
  • timeout을 루프 횟수나 time()/CLOCK_REALTIME으로 셈 → NTP가 시계를 당기면 timeout이 틀어짐
  • mmap 실패 시 close(fd)를 안 하거나, close 뒤에 errno를 읽음 → fd 누수, 엉뚱한 에러 코드
  • UIO에 1바이트나 8바이트로 read/write → 실제 UIO는 EINVAL. unmask write를 빼먹음 → 두 번째 IRQ가 안 옴 (테스트 7번)
  • -1을 반환하고 errno에 맡김 → 이 API는 -errno 규약 (테스트 4·8번 -ENOENT, -EBADF, -EPIPE)
