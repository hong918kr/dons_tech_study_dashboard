0. 문제 한국어로 먼저 보기

영어 원문(§1)을 읽기 전에 무슨 상황이고 뭘 만들어야 하는지만 빠르게 잡는 요약입니다. 풀이 힌트는 없습니다.

한 줄 요약: 카메라 SoC의 CSI-2 receiver가 캡처한 바이트 스트림을 받아서 패킷 헤더 ECC와 payload CRC를 검사하고, VC별로 frame/line 구조가 맞는지 세는 스트림 checker를 짭니다.

상황

  • 카메라 SoC의 CSI-2 receiver(CSI-2 v1.x, D-PHY 위)를 validation 중입니다. 자동 테스트가 캡처할 때마다 이 checker를 호출합니다.
  • receiver의 debug capture가 캡처 한 번 분량의 merged byte stream을 줍니다.
    • lane merging은 이미 끝났고 LP/SoT/EoT도 제거됨 → 버퍼에 패킷이 빈틈없이 연달아 들어 있음
  • 용어
    • VC(virtual channel, 0–3): 한 링크에 여러 스트림을 섞어 보내는 채널 번호
    • DT(data type): 패킷 종류. WC(word count): long packet의 payload 바이트 수
    • short packet: 헤더 4바이트만 있음. long packet: 헤더 + payload + CRC
    • ECC: 헤더 24비트에 대한 6-bit Hamming 코드. 1비트 오류는 고칠 수 있고, 그보다 많으면 고칠 수 없음
  • 테스트 파일에 TPG(test pattern generator: tpg_short, tpg_long, tpg_frame)가 들어 있습니다. ECC/CRC가 올바른 스트림을 만드는 독립적인 CSI-2 TX model이며, 수정하지 말고 사용합니다.

패킷 구조

Byte내용
0DI = VC[7:6] | DT[5:0]
1WC[7:0] — 16-bit WC, little endian. short packet이면 이 16비트가 data 필드
2WC[15:8]
3ECC — D[23:0] = byte0 | byte1<<8 | byte2<<16에 대한 P5..P0, bit 7:6은 0
  • DT 0x00–0x0F = short packet: 0x00 FS(frame start), 0x01 FE(frame end, data = frame 번호), 0x02 LS(line start), 0x03 LE(line end, data = line 번호)
  • DT >= 0x10 = long packet: 헤더 + WC바이트 payload + 16-bit CRC(LSB 먼저). 여기서 쓰는 DT: 0x1E YUV422 8-bit(16 bpp), 0x2A RAW8, 0x2B RAW10, 0x2C RAW12
  • ECC 각 패리티 비트 P0..P5는 §1 표에 나열된 data 비트들의 XOR
  • CRC-16은 payload에만 계산: 다항식 x^16 + x^12 + x^5 + 1, init 0xFFFF, LSB 먼저 처리(reflected 0x8408), final XOR 없음

csi2_check_stream 규칙 (VC마다 따로, 다른 VC와 독립)

  1. frame 구조: FS → long packet height개 → FE
  2. good line: DT가 cfg.dt, WC가 csi2_expected_wc(cfg.dt, cfg.width), CRC 일치 — 셋 다 맞아야 함
  3. frame ok: FE가 왔을 때 good line이 정확히 height개, FE 번호 = FS 번호, frame 안에서 실패한 게 없음
  4. FS가 또 옴(frame이 열린 상태): missing_fe, 이전 frame은 bad로 닫고 새 frame 시작
  5. frame 없이 long packet이나 FE가 옴: no_fs_pkts
  6. frame 번호: 새 FS 번호와 이전 FS 번호가 둘 다 0이 아니면 새 번호는 prev + 1이어야 함(0xFFFF 다음은 1). 아니면 frame_num_err (frame이 빠졌다는 뜻이고, 현재 frame 자체는 bad로 안 침)
  7. payload 건너뛰기: WC가 틀렸어도 항상 헤더의 WC로 건너뜀
  8. sync 잃음: 고칠 수 없는 헤더, 또는 패킷이 len을 넘어감 → 멈추고 -1, stop_off = 그 패킷 시작 위치. 아니면 0, stop_off = len. 멈춘 시점에 열려 있는 frame은 모두 missing_fe + frames_bad
  9. LS/LE와 기타 short packet은 받아들이되 이번 버전에선 무시
  10. cfg.dt == 0인 VC로 온 패킷 → unexpected_vc

  • VC0 설정: RAW10, width 8, height 3. RAW10은 픽셀당 10비트라 한 줄 WC = 8×10/8 = 10바이트.
  • 스트림: FS(1) L L L FE(1) FS(2) L L L FE(2) — 패킷 10개.
    • frame 하나 = FS 4 + 줄 3개 × (헤더 4 + payload 10 + CRC 2) + FE 4 = 56바이트, 두 frame이면 112바이트

    • FS(1) 헤더 00 01 00 1A: VC0, DT 0x00(FS), data = 1, ECC 0x1A
    • line 헤더 2B 0A 00 2E: VC0, DT 0x2B(RAW10), WC = 10, ECC 0x2E

  • 그대로 검사하면 → 반환 0, stop_off 112, frames_ok 2, lines_ok 6, ecc_corrected 0.
  • 두 번째 line 헤더의 WC bit 3을 뒤집음(2B 0A → 2B 02): byte1의 bit 3은 D11. syndrome 0x25가 D11 열과 같으므로 1비트 오류 → 고쳐짐. ecc_corrected 1, frames_ok는 여전히 2.

1. Problem

You are validating the CSI-2 receiver (CSI-2 v1.x over D-PHY) of a camera SoC. The receiver's debug capture gives you the merged byte stream of one capture window: lane merging is done and LP/SoT/EoT are stripped, so packets sit back to back in a buffer. Write the checker that the automated test calls after every capture.

Packet format. Every packet starts with a 4-byte header:

ByteFieldNotes
0DI = VC[7:6] | DT[5:0]virtual channel 0–3, data type
1WC[7:0]16-bit word count, little endian. For a short packet this is the 16-bit data field
2WC[15:8]
3ECC6-bit Hamming code P5..P0 over D[23:0] = byte0 | byte1<<8 | byte2<<16; bits 7:6 are 0

  • DT >= 0x10 = long packet: header + WC payload bytes + 16-bit CRC (LSB first). Data types used here: 0x1E YUV422 8-bit (16 bpp), 0x2A RAW8, 0x2B RAW10, 0x2C RAW12.
  • ECC parity equations (XOR of the listed data bits):
P0 = D0 D1 D2 D4 D5 D7 D10 D11 D13 D16 D20 D21 D22 D23
P1 = D0 D1 D3 D4 D6 D8 D10 D12 D14 D17 D20 D21 D22 D23
P2 = D0 D2 D3 D5 D6 D9 D11 D12 D15 D18 D20 D21 D22
P3 = D1 D2 D3 D7 D8 D9 D13 D14 D15 D19 D20 D21 D23
P4 = D4 D5 D6 D7 D8 D9 D16 D17 D18 D19 D20 D22 D23
P5 = D10 D11 D12 D13 D14 D15 D16 D17 D18 D19 D21 D22 D23

Rules for csi2_check_stream (per VC, independent of the other VCs):

  • A frame is FS → height long packets → FE. A long packet is a good line only if its DT is cfg.dt, its WC is csi2_expected_wc(cfg.dt, cfg.width) and its CRC matches. A frame is ok only if FE arrives with exactly height good lines, the FE number equals the FS number and nothing failed inside it.
  • FS while a frame is open → missing_fe, close the old frame as bad, start the new one. A long packet or FE with no open frame → no_fs_pkts.
  • Frame numbers: when both the new and the previous FS number are non-zero, the new one must be prev + 1 (0xFFFF wraps to 1), else frame_num_err (a dropped frame; the current frame itself is not marked bad).
  • Always use the header's WC to skip the payload, even when the WC is wrong.
  • An uncorrectable header or a packet that runs past len means we lost sync: stop, return -1, stop_off = start of that packet. Otherwise return 0, stop_off = len. At the stop point every open frame counts as missing_fe + frames_bad.
  • LS/LE and other short packets are accepted and ignored in this version. A packet on a VC with cfg.dt == 0 → unexpected_vc.
  • No malloc. Never read past buf[len-1].

The test file includes a test pattern generator (tpg_short, tpg_long, tpg_frame): an independent CSI-2 TX model that builds streams with correct ECC and CRC. Use it, do not edit it.

  • Known answers: csi2_crc16("123456789") = 0x6F91; csi2_expected_wc(RAW10, 1920) = 2400.

static const uint8_t TPG_COL[24] = {   /* H-matrix column (P5..P0) for each data bit D0..D23 */
    0x07, 0x0B, 0x0D, 0x0E, 0x13, 0x15, 0x16, 0x19, 0x1A, 0x1C, 0x23, 0x25,
    0x26, 0x29, 0x2A, 0x2C, 0x31, 0x32, 0x34, 0x38, 0x1F, 0x2F, 0x37, 0x3B
};

static size_t tpg_hdr(uint8_t *b, size_t off, uint8_t vc, uint8_t dt, uint16_t wc)
{
    uint32_t d = (uint32_t)(vc << 6 | dt) | (uint32_t)wc << 8;
    uint8_t e = 0;
    for (int i = 0; i < 24; i++) if (d >> i & 1u) e ^= TPG_COL[i];
    b[off] = (uint8_t)d; b[off + 1] = (uint8_t)(d >> 8); b[off + 2] = (uint8_t)(d >> 16); b[off + 3] = e;
    return off + 4;
}

static uint16_t tpg_crc(const uint8_t *p, size_t n)        /* bit-serial, like the RTL */
{
    uint16_t c = 0xFFFF;
    for (size_t i = 0; i < n; i++)
        for (int k = 0; k < 8; k++) {
            unsigned in = (p[i] >> k & 1u) ^ (c & 1u);
            c >>= 1;
            if (in) c ^= 0x8408;
        }
    return c;
}

static size_t tpg_short(uint8_t *b, size_t off, uint8_t vc, uint8_t dt, uint16_t data)
{
    return tpg_hdr(b, off, vc, dt, data);
}

static size_t tpg_long(uint8_t *b, size_t off, uint8_t vc, uint8_t dt, uint16_t wc, uint8_t seed)
{
    off = tpg_hdr(b, off, vc, dt, wc);
    for (uint16_t i = 0; i < wc; i++) b[off + i] = (uint8_t)(seed + i * 7u);
    uint16_t c = tpg_crc(&b[off], wc);
    off += wc;
    b[off] = (uint8_t)c; b[off + 1] = (uint8_t)(c >> 8);
    return off + 2;
}

/* FS(fn), `lines` long packets, FE(fn) on one VC */
static size_t tpg_frame(uint8_t *b, size_t off, uint8_t vc, uint8_t dt, uint16_t fn,
                        uint16_t wc, int lines)
{
    off = tpg_short(b, off, vc, CSI2_DT_FS, fn);
    for (int l = 0; l < lines; l++) off = tpg_long(b, off, vc, dt, wc, (uint8_t)(fn * 16 + l));
    return tpg_short(b, off, vc, CSI2_DT_FE, fn);
}

static int run(const uint8_t *b, size_t len, const Csi2VcCfg *cfg, Csi2Report *r)
{
    memset(r, 0, sizeof *r);
    return csi2_check_stream(b, len, cfg, r);
}

int main(void)
{
    static uint8_t b[512];
    Csi2Report r;
    Csi2Hdr h;
    /* VC0: RAW10, 8 px/line (WC = 10), 3 lines/frame. Other VCs unused. */
    const Csi2VcCfg cfg[CSI2_NUM_VC] = { { CSI2_DT_RAW10, 8, 3 }, { 0, 0, 0 }, { 0, 0, 0 }, { 0, 0, 0 } };
    size_t n, n1;

    /* 1. building blocks: ECC, CRC, word count */
    CHECK(csi2_ecc(0x000000) == 0x00);
    CHECK(csi2_ecc(0x000A2B) == 0x2E);               /* VC0 RAW10 WC=10 */
    CHECK(csi2_ecc(0x000100) == 0x1A);               /* FS, frame number 1 */
    CHECK(csi2_ecc(0x09602B) == 0x1D);        /* RAW10 WC=2400 (0x0960) */
    CHECK(csi2_crc16((const uint8_t *)"123456789", 9) == 0x6F91);
    const uint8_t spec1[24] = { 0xFF,0x00,0x00,0x02,0xB9,0xDC,0xF3,0x72,0xBB,0xD4,0xB8,0x5A,
                                0xC8,0x75,0xC2,0x7C,0x81,0xF8,0x05,0xDF,0xFF,0x00,0x00,0x01 };
    const uint8_t spec2[24] = { 0xFF,0x00,0x00,0x00,0x1E,0xF0,0x1E,0xC7,0x4F,0x82,0x78,0xC5,
                                0x82,0xE0,0x8C,0x70,0xD2,0x3C,0x78,0xE9,0xFF,0x00,0x00,0x01 };
    CHECK(csi2_crc16(spec1, 24) == 0x00F0);
    CHECK(csi2_crc16(spec2, 24) == 0xE569);
    CHECK(csi2_expected_wc(CSI2_DT_RAW10, 1920) == 2400);
    CHECK(csi2_expected_wc(CSI2_DT_RAW12, 1920) == 2880);
    CHECK(csi2_expected_wc(CSI2_DT_YUV422_8, 1920) == 3840);
    CHECK(csi2_expected_wc(CSI2_DT_RAW10, 1918) == 0);   /* 19180 bits: not byte aligned */
    CHECK(csi2_expected_wc(0x30, 1920) == 0);            /* user-defined DT: unknown */

    /* 2. header decode: clean, every single-bit flip corrected, every 2-bit flip detected */
    uint8_t hdr[4] = { 0x6B, 0x0A, 0x00, 0x00 };          /* VC1 RAW10 WC=10 */
    hdr[3] = csi2_ecc(0x000A6B);
    CHECK(csi2_header_decode(hdr, &h) == HDR_OK && h.vc == 1 && h.dt == 0x2B && h.wc == 10);
    int fixed = 0, caught = 0;
    for (int i = 0; i < 30; i++) {                        /* 24 data + 6 ECC bits */
        uint8_t t[4]; memcpy(t, hdr, 4);
        t[i / 8] ^= (uint8_t)(1u << (i % 8));
        memset(&h, 0, sizeof h);
        if (csi2_header_decode(t, &h) == HDR_CORRECTED && h.vc == 1 && h.dt == 0x2B && h.wc == 10)
            fixed++;
        for (int j = i + 1; j < 30; j++) {
            uint8_t u[4]; memcpy(u, t, 4);
            u[j / 8] ^= (uint8_t)(1u << (j % 8));
            if (csi2_header_decode(u, &h) == HDR_UNCORRECTABLE) caught++;
        }
    }
    CHECK(fixed == 30);
    CHECK(caught == 435);                                  /* C(30,2) */

    /* 3. clean stream: 2 frames x 3 lines, 112 bytes */
    n = tpg_frame(b, 0, 0, CSI2_DT_RAW10, 1, 10, 3);
    n1 = n;
    n = tpg_frame(b, n, 0, CSI2_DT_RAW10, 2, 10, 3);
    CHECK(n1 == 56 && n == 112);
    CHECK(run(b, n, cfg, &r) == 0 && r.stop_off == 112);
    CHECK(r.vc[0].frames_ok == 2 && r.vc[0].frames_bad == 0 && r.vc[0].lines_ok == 6);
    CHECK(r.packets == 10 && r.ecc_corrected == 0 && r.vc[0].frame_num_err == 0);

    /* 4. single-bit error in a line header (WC bit 3: 10 -> 2) is corrected, sync kept */
    b[20 + 1] ^= 0x08;                                     /* frame 1, line 2 header at 20 */
    CHECK(run(b, n, cfg, &r) == 0 && r.stop_off == 112);
    CHECK(r.ecc_corrected == 1 && r.vc[0].frames_ok == 2 && r.vc[0].lines_ok == 6);
    b[20 + 1] ^= 0x08;

    /* 5. 2-bit error in frame 2, line 1 header (offset 60): parse stops there */
    b[60 + 0] ^= 0x01; b[60 + 2] ^= 0x10;
    CHECK(run(b, n, cfg, &r) == -1 && r.stop_off == 60);
    CHECK(r.ecc_uncorrectable == 1 && r.vc[0].frames_ok == 1);
    CHECK(r.vc[0].missing_fe == 1 && r.vc[0].frames_bad == 1);   /* frame 2 left open */
    b[60 + 0] ^= 0x01; b[60 + 2] ^= 0x10;

    /* 6. payload CRC error: one payload byte of frame 1 line 1 flipped */
    b[4 + 4 + 5] ^= 0x40;
    CHECK(run(b, n, cfg, &r) == 0);
    CHECK(r.vc[0].crc_err == 1 && r.vc[0].lines_ok == 5);
    CHECK(r.vc[0].frames_ok == 1 && r.vc[0].frames_bad == 1 && r.vc[0].line_count_err == 1);
    b[4 + 4 + 5] ^= 0x40;

    /* 7. short frame: frame 2 has only 2 lines */
    n = tpg_frame(b, 0, 0, CSI2_DT_RAW10, 1, 10, 3);
    n = tpg_frame(b, n, 0, CSI2_DT_RAW10, 2, 10, 2);
    CHECK(n == 96 && run(b, n, cfg, &r) == 0);
    CHECK(r.vc[0].frames_ok == 1 && r.vc[0].frames_bad == 1 && r.vc[0].line_count_err == 1);
    CHECK(r.vc[0].lines_ok == 5 && r.vc[0].crc_err == 0);

    /* 8. missing FE on frame 1, then frame number jumps 2 -> 4 (frame 3 dropped) */
    n = tpg_frame(b, 0, 0, CSI2_DT_RAW10, 1, 10, 3) - 4;   /* cut off FE(1) */
    n = tpg_frame(b, n, 0, CSI2_DT_RAW10, 2, 10, 3);
    n = tpg_frame(b, n, 0, CSI2_DT_RAW10, 4, 10, 3);
    CHECK(n == 164 && run(b, n, cfg, &r) == 0);
    CHECK(r.vc[0].missing_fe == 1 && r.vc[0].frame_num_err == 1);
    CHECK(r.vc[0].frames_ok == 2 && r.vc[0].frames_bad == 1 && r.vc[0].lines_ok == 9);

    /* 9. WC mismatch (12 instead of 10, valid ECC and CRC): flagged, parse continues */
    n = tpg_short(b, 0, 0, CSI2_DT_FS, 1);
    n = tpg_long(b, n, 0, CSI2_DT_RAW10, 10, 0x11);
    n = tpg_long(b, n, 0, CSI2_DT_RAW10, 12, 0x22);
    n = tpg_long(b, n, 0, CSI2_DT_RAW10, 10, 0x33);
    n = tpg_short(b, n, 0, CSI2_DT_FE, 1);
    CHECK(n == 58 && run(b, n, cfg, &r) == 0 && r.stop_off == 58);
    CHECK(r.vc[0].wc_err == 1 && r.vc[0].crc_err == 0 && r.vc[0].lines_ok == 2);
    CHECK(r.vc[0].frames_bad == 1 && r.vc[0].line_count_err == 1);

    /* 10. two VCs interleaved: VC0 RAW10 8x2, VC1 YUV422 4x2 (WC 8, frame 7), + stray VC2 */
    const Csi2VcCfg cfg2[CSI2_NUM_VC] = { { CSI2_DT_RAW10, 8, 2 }, { CSI2_DT_YUV422_8, 4, 2 },
                                          { 0, 0, 0 }, { 0, 0, 0 } };
    n = tpg_short(b, 0, 0, CSI2_DT_FS, 1);
    n = tpg_short(b, n, 1, CSI2_DT_FS, 7);
    n = tpg_long(b, n, 0, CSI2_DT_RAW10, 10, 0xA0);
    n = tpg_long(b, n, 1, CSI2_DT_YUV422_8, 8, 0xB0);
    n = tpg_short(b, n, 2, CSI2_DT_LS, 1);                   /* VC2 not configured */
    n = tpg_long(b, n, 0, CSI2_DT_RAW10, 10, 0xA1);
    n = tpg_long(b, n, 1, CSI2_DT_YUV422_8, 8, 0xB1);
    n = tpg_short(b, n, 0, CSI2_DT_FE, 1);
    n = tpg_short(b, n, 1, CSI2_DT_FE, 7);
    CHECK(n == 80 && run(b, n, cfg2, &r) == 0);
    CHECK(r.vc[0].frames_ok == 1 && r.vc[0].lines_ok == 2 && r.vc[0].frames_bad == 0);
    CHECK(r.vc[1].frames_ok == 1 && r.vc[1].lines_ok == 2 && r.vc[1].frames_bad == 0);
    CHECK(r.unexpected_vc == 1 && r.packets == 9);

    /* 11. truncated long packet at the end of the buffer: stop, no over-read */
    n = tpg_frame(b, 0, 0, CSI2_DT_RAW10, 1, 10, 3);
    CHECK(run(b, 30, cfg, &r) == -1 && r.stop_off == 20);   /* line 2 needs 16 B, 10 left */
    CHECK(r.vc[0].lines_ok == 1 && r.vc[0].missing_fe == 1);

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

3. 힌트 (막힐 때 하나씩)

Hint 1 — ECC는 선형 코드: 비트 하나의 ECC가 곧 H 행렬의 열

csi2_ecc()는 각 Pi에 대해 "마스크 AND 후 parity"입니다(P0 마스크 = 0xF12CB7 …). 선형이므로 신드롬 = 받은 ECC ^ 다시 계산한 ECC가 데이터 비트 i 하나만 틀렸을 때 csi2_ecc(1u << i)와 같습니다. 24개 열을 돌며 같은 값을 찾으면 그 비트를 뒤집습니다.

Hint 2 — 신드롬의 무게(popcount)로 분류
  • 0 → 정상
  • 비트 1개(무게 1) → ECC 바이트 자체가 틀림. 데이터는 그대로 두고 CORRECTED
  • 데이터 열과 일치(D0–D19은 무게 3, D20–D23은 무게 5) → 그 비트 정정
  • 그 외(무게 2, 4, 6 등 짝수) → 2비트 이상 오류, UNCORRECTABLE

모든 열의 무게가 홀수라서 2비트 오류는 항상 짝수 무게가 되어 정정 열과 헷갈리지 않습니다. 이것이 SEC-DED입니다.

Hint 3 — 상태는 VC별로, 패킷 길이는 헤더 WC로

r->vc[h.vc]에 in_frame / lines / frame_num / frame_bad를 둡니다. 한 VC의 FE가 다른 VC 프레임을 닫으면 안 됩니다. 루프는 off += 4 + (long ? wc + 2 : 0); WC가 틀렸어도(테스트 9번) 그 WC로 건너뛰어야 다음 헤더에 맞습니다. 그래서 헤더 ECC 정정이 동기 유지의 전부입니다.

4. 풀이

4.1 핵심 아이디어 — 패킷 구조

수신기 관점에서 중요한 비대칭이 있습니다.

  • 헤더가 깨지면 스트림 전체가 깨집니다. WC가 틀리면 다음 헤더 위치를 잘못 계산해 이후 모든 패킷이 쓰레기가 됩니다. 그래서 헤더에는 정정 가능한 ECC(SEC-DED)를 둡니다.
  • payload가 깨지면 그 줄 하나만 버리면 됩니다. 그래서 CRC(검출 전용)로 충분합니다.

solution.c
/*
 * V9  MIPI CSI-2 Receiver Stream Checker
 *
 * A CSI-2 (v1.x, D-PHY) receiver hands you the merged byte stream of one capture
 * (lane merging and LP/SoT/EoT already removed): packets back to back.
 *
 *   Packet header (4 bytes, sent first to last):
 *     byte0  DI   = VC[7:6] | DT[5:0]
 *     byte1  WC[7:0]     \  16-bit word count, little endian
 *     byte2  WC[15:8]    /  (for a short packet this is the 16-bit data field)
 *     byte3  ECC  = 6-bit Hamming code P5..P0 over D[23:0] = byte0 | byte1<<8 | byte2<<16
 *                   (bits 7:6 are 0 in v1.x)
 *   DT 0x00..0x0F -> short packet (header only):  0x00 FS, 0x01 FE (data = frame number),
 *                                                 0x02 LS, 0x03 LE (data = line number)
 *   DT >= 0x10    -> long packet: header + WC payload bytes + 16-bit CRC (LSB first)
 *                    0x1E YUV422 8-bit (16 bpp), 0x2A RAW8, 0x2B RAW10, 0x2C RAW12
 *
 *   ECC parity equations (XOR of the listed data bits):
 *     P0 = D0 D1 D2 D4 D5 D7 D10 D11 D13 D16 D20 D21 D22 D23
 *     P1 = D0 D1 D3 D4 D6 D8 D10 D12 D14 D17 D20 D21 D22 D23
 *     P2 = D0 D2 D3 D5 D6 D9 D11 D12 D15 D18 D20 D21 D22
 *     P3 = D1 D2 D3 D7 D8 D9 D13 D14 D15 D19 D20 D21 D23
 *     P4 = D4 D5 D6 D7 D8 D9 D16 D17 D18 D19 D20 D22 D23
 *     P5 = D10 D11 D12 D13 D14 D15 D16 D17 D18 D19 D21 D22 D23
 *   CRC-16: poly x^16+x^12+x^5+1, init 0xFFFF, bits processed LSB first (reflected,
 *           0x8408), no final XOR, computed over the payload only.
 *
 * Implement:
 *   csi2_ecc            6-bit ECC of a 24-bit header.
 *   csi2_header_decode  check the ECC; correct a single-bit error (data or ECC bit),
 *                       report a 2-bit error as uncorrectable. Fill *h unless uncorrectable.
 *   csi2_crc16          payload CRC.
 *   csi2_expected_wc    bytes per line for (dt, width); 0 if unknown DT or not byte aligned.
 *   csi2_check_stream   per-VC state machine: FS -> `height` long lines -> FE.
 *                       Count everything in Csi2Report (see field comments). An
 *                       uncorrectable header or a packet running past `len` stops the
 *                       parse (we lost sync): return -1 with stop_off = start of that
 *                       packet. Otherwise return 0 with stop_off = len. At the stop point
 *                       every frame still open counts as missing FE (and a bad frame).
 *   No malloc. Never read past buf[len-1].
 *
 * Reference solution.  Build & run:  ./run.sh V9 sol
 */
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

#define CSI2_DT_FS        0x00u
#define CSI2_DT_FE        0x01u
#define CSI2_DT_LS        0x02u
#define CSI2_DT_LE        0x03u
#define CSI2_DT_YUV422_8  0x1Eu
#define CSI2_DT_RAW8      0x2Au
#define CSI2_DT_RAW10     0x2Bu
#define CSI2_DT_RAW12     0x2Cu
#define CSI2_NUM_VC       4
#define CSI2_HDR_LEN      4u
#define CSI2_CRC_LEN      2u

typedef struct { uint8_t vc, dt; uint16_t wc; } Csi2Hdr;   /* wc = data field for short pkts */

enum { HDR_OK = 0, HDR_CORRECTED = 1, HDR_UNCORRECTABLE = -1 };

typedef struct {
    uint8_t  dt;       /* expected long-packet DT; 0 = this VC is not configured */
    uint16_t width;    /* pixels per line */
    uint16_t height;   /* lines per frame */
} Csi2VcCfg;

typedef struct {
    /* counters */
    uint32_t frames_ok;      /* FE seen, exactly `height` good lines, no error inside */
    uint32_t frames_bad;     /* any other frame that ended (FE, FS-without-FE, or stop) */
    uint32_t lines_ok;       /* long packets with right DT, WC and CRC inside a frame */
    uint32_t crc_err;        /* payload CRC mismatch */
    uint32_t wc_err;         /* WC != csi2_expected_wc(cfg.dt, cfg.width) */
    uint32_t dt_err;         /* long packet DT != cfg.dt */
    uint32_t no_fs_pkts;     /* long packet or FE received while no frame is open */
    uint32_t missing_fe;     /* FS while a frame is open, or frame still open at stop */
    uint32_t line_count_err; /* FE arrived with good lines != height */
    uint32_t frame_num_err;  /* FS number not prev+1 (both non-zero), or FE number != FS number */
    /* receiver state (zero-initialised by the caller) */
    bool     in_frame, frame_bad, have_prev;
    uint16_t frame_num, prev_num, lines;
} Csi2VcStats;

typedef struct {
    Csi2VcStats vc[CSI2_NUM_VC];
    uint32_t packets;           /* headers accepted (OK or corrected) */
    uint32_t ecc_corrected;
    uint32_t ecc_uncorrectable;
    uint32_t unexpected_vc;     /* packet on a VC whose cfg.dt == 0 */
    size_t   stop_off;
} Csi2Report;

static const uint32_t ECC_MASK[6] = {          /* data bits feeding P0..P5 */
    0xF12CB7u, 0xF2555Bu, 0x749A6Du, 0xB8E38Eu, 0xDF03F0u, 0xEFFC00u
};

static unsigned parity24(uint32_t x)
{
    x ^= x >> 16; x ^= x >> 8; x ^= x >> 4; x ^= x >> 2; x ^= x >> 1;
    return x & 1u;
}

uint8_t csi2_ecc(uint32_t d24)
{
    uint8_t e = 0;
    for (unsigned i = 0; i < 6; i++)
        e |= (uint8_t)(parity24(d24 & ECC_MASK[i]) << i);
    return e;
}

int csi2_header_decode(const uint8_t raw[4], Csi2Hdr *h)
{
    uint32_t d = (uint32_t)raw[0] | (uint32_t)raw[1] << 8 | (uint32_t)raw[2] << 16;
    uint8_t syn = (uint8_t)((raw[3] ^ csi2_ecc(d)) & 0x3Fu);
    int st = HDR_OK;

    if (syn != 0) {
        if ((syn & (syn - 1)) == 0) {
            st = HDR_CORRECTED;                 /* one ECC bit flipped: data is fine */
        } else {
            int bit = -1;
            for (int i = 0; i < 24; i++)        /* column i of H = ecc of a lone bit i */
                if (csi2_ecc(1u << i) == syn) { bit = i; break; }
            if (bit < 0)
                return HDR_UNCORRECTABLE;        /* even-weight syndrome: >= 2 errors */
            d ^= 1u << bit;
            st = HDR_CORRECTED;
        }
    }
    h->vc = (uint8_t)((d >> 6) & 3u);
    h->dt = (uint8_t)(d & 0x3Fu);
    h->wc = (uint16_t)(d >> 8);
    return st;
}

uint16_t csi2_crc16(const uint8_t *p, size_t n)
{
    uint16_t crc = 0xFFFFu;
    for (size_t i = 0; i < n; i++) {
        crc ^= p[i];
        for (int b = 0; b < 8; b++)
            crc = (crc & 1u) ? (uint16_t)((crc >> 1) ^ 0x8408u) : (uint16_t)(crc >> 1);
    }
    return crc;
}

uint16_t csi2_expected_wc(uint8_t dt, uint16_t width)
{
    uint32_t bpp;
    switch (dt) {
    case CSI2_DT_RAW8:     bpp = 8;  break;
    case CSI2_DT_RAW10:    bpp = 10; break;
    case CSI2_DT_RAW12:    bpp = 12; break;
    case CSI2_DT_YUV422_8: bpp = 16; break;
    default: return 0;
    }
    uint32_t bits = (uint32_t)width * bpp;
    if (bits % 8u != 0 || bits / 8u > 0xFFFFu)
        return 0;
    return (uint16_t)(bits / 8u);
}

static void close_frame(Csi2VcStats *s, bool good)
{
    if (good) s->frames_ok++; else s->frames_bad++;
    s->in_frame = false;
}

static void on_packet(Csi2VcStats *s, const Csi2VcCfg *c, const Csi2Hdr *h, const uint8_t *payload)
{
    if (h->dt == CSI2_DT_FS) {
        if (s->in_frame) {                       /* previous frame never got its FE */
            s->missing_fe++;
            close_frame(s, false);
        }
        uint16_t fn = h->wc;
        if (fn != 0 && s->have_prev && s->prev_num != 0) {
            uint16_t want = (s->prev_num == 0xFFFFu) ? 1u : (uint16_t)(s->prev_num + 1u);
            if (fn != want) s->frame_num_err++;  /* dropped frame upstream */
        }
        s->prev_num = fn; s->have_prev = true;
        s->frame_num = fn; s->lines = 0;
        s->in_frame = true; s->frame_bad = false;
    } else if (h->dt == CSI2_DT_FE) {
        if (!s->in_frame) { s->no_fs_pkts++; return; }
        if (h->wc != s->frame_num) { s->frame_num_err++; s->frame_bad = true; }
        if (s->lines != c->height) { s->line_count_err++; s->frame_bad = true; }
        close_frame(s, !s->frame_bad);
    } else if (h->dt >= 0x10u) {                 /* long packet */
        if (!s->in_frame) { s->no_fs_pkts++; return; }
        bool ok = true;
        if (h->dt != c->dt) { s->dt_err++; ok = false; }
        if (h->wc != csi2_expected_wc(c->dt, c->width)) { s->wc_err++; ok = false; }
        uint16_t rx = (uint16_t)(payload[h->wc] | payload[h->wc + 1u] << 8);
        if (rx != csi2_crc16(payload, h->wc)) { s->crc_err++; ok = false; }
        if (ok) { s->lines++; s->lines_ok++; } else s->frame_bad = true;
    }
    /* LS/LE and generic short packets: accepted, not checked in this version */
}

int csi2_check_stream(const uint8_t *buf, size_t len, const Csi2VcCfg cfg[CSI2_NUM_VC],
                      Csi2Report *r)
{
    size_t off = 0;
    int rc = 0;

    while (off < len) {
        if (len - off < CSI2_HDR_LEN) { rc = -1; break; }          /* truncated header */
        Csi2Hdr h;
        int st = csi2_header_decode(&buf[off], &h);
        if (st == HDR_UNCORRECTABLE) { r->ecc_uncorrectable++; rc = -1; break; }
        size_t plen = (h.dt >= 0x10u) ? (size_t)h.wc + CSI2_CRC_LEN : 0;
        if (len - off - CSI2_HDR_LEN < plen) { rc = -1; break; }   /* runs past buffer */
        if (st == HDR_CORRECTED) r->ecc_corrected++;
        r->packets++;
        if (cfg[h.vc].dt == 0) r->unexpected_vc++;
        else on_packet(&r->vc[h.vc], &cfg[h.vc], &h, &buf[off + CSI2_HDR_LEN]);
        off += CSI2_HDR_LEN + plen;
    }
    r->stop_off = off;
    for (int v = 0; v < CSI2_NUM_VC; v++)
        if (r->vc[v].in_frame) { r->vc[v].missing_fe++; close_frame(&r->vc[v], false); }
    return rc;
}

static const uint8_t TPG_COL[24] = {   /* H-matrix column (P5..P0) for each data bit D0..D23 */
    0x07, 0x0B, 0x0D, 0x0E, 0x13, 0x15, 0x16, 0x19, 0x1A, 0x1C, 0x23, 0x25,
    0x26, 0x29, 0x2A, 0x2C, 0x31, 0x32, 0x34, 0x38, 0x1F, 0x2F, 0x37, 0x3B
};

static size_t tpg_hdr(uint8_t *b, size_t off, uint8_t vc, uint8_t dt, uint16_t wc)
{
    uint32_t d = (uint32_t)(vc << 6 | dt) | (uint32_t)wc << 8;
    uint8_t e = 0;
    for (int i = 0; i < 24; i++) if (d >> i & 1u) e ^= TPG_COL[i];
    b[off] = (uint8_t)d; b[off + 1] = (uint8_t)(d >> 8); b[off + 2] = (uint8_t)(d >> 16); b[off + 3] = e;
    return off + 4;
}

static uint16_t tpg_crc(const uint8_t *p, size_t n)        /* bit-serial, like the RTL */
{
    uint16_t c = 0xFFFF;
    for (size_t i = 0; i < n; i++)
        for (int k = 0; k < 8; k++) {
            unsigned in = (p[i] >> k & 1u) ^ (c & 1u);
            c >>= 1;
            if (in) c ^= 0x8408;
        }
    return c;
}

static size_t tpg_short(uint8_t *b, size_t off, uint8_t vc, uint8_t dt, uint16_t data)
{
    return tpg_hdr(b, off, vc, dt, data);
}

static size_t tpg_long(uint8_t *b, size_t off, uint8_t vc, uint8_t dt, uint16_t wc, uint8_t seed)
{
    off = tpg_hdr(b, off, vc, dt, wc);
    for (uint16_t i = 0; i < wc; i++) b[off + i] = (uint8_t)(seed + i * 7u);
    uint16_t c = tpg_crc(&b[off], wc);
    off += wc;
    b[off] = (uint8_t)c; b[off + 1] = (uint8_t)(c >> 8);
    return off + 2;
}

/* FS(fn), `lines` long packets, FE(fn) on one VC */
static size_t tpg_frame(uint8_t *b, size_t off, uint8_t vc, uint8_t dt, uint16_t fn,
                        uint16_t wc, int lines)
{
    off = tpg_short(b, off, vc, CSI2_DT_FS, fn);
    for (int l = 0; l < lines; l++) off = tpg_long(b, off, vc, dt, wc, (uint8_t)(fn * 16 + l));
    return tpg_short(b, off, vc, CSI2_DT_FE, fn);
}

static int run(const uint8_t *b, size_t len, const Csi2VcCfg *cfg, Csi2Report *r)
{
    memset(r, 0, sizeof *r);
    return csi2_check_stream(b, len, cfg, r);
}

코드 읽는 포인트

  • csi2_header_decode는 1비트 신드롬(ECC 비트 오류) 을 먼저 처리합니다. 이걸 빠뜨리면 ECC 바이트만 깨진 정상 헤더를 UNCORRECTABLE로 버립니다(테스트 2번에서 6개 실패).
  • 정정 후 vc/dt/wc를 정정된 d에서 뽑습니다. VC 비트가 깨진 경우 정정하지 않으면 다른 VC의 상태 머신을 망가뜨립니다.
  • 길이 검사는 len - off - 4 < plen 형태로 뺄셈만 씁니다. off + 4 + plen > len은 size_t 오버플로 여지가 있고, 이 순서여야 payload를 읽기 전에 멈춥니다(테스트 11번, ASan이 지켜봄).
  • ecc_corrected++는 패킷이 버퍼 안에 다 들어온 것을 확인한 뒤에 합니다. 잘린 패킷은 "받은 패킷"으로 세지 않습니다.
  • 프레임 종료 처리(close_frame)를 FE, FS 재진입, 스트림 끝 세 곳이 공유합니다. 열린 프레임을 끝에서 닫지 않으면 테스트 5·11번이 실패합니다.

4.5 복잡도

  • 시간 O(len): 헤더당 ECC 계산이 상수(정정 시 최대 24열 탐색), payload 바이트마다 CRC 8 step.
  • 메모리 O(1): VC 4개분 상태. 실제 HW에서는 CRC를 바이트 테이블(512 B)이나 lane당 병렬 CRC로 계산합니다.

5. 임베디드 관점으로 말할 것

  • 이 체커가 실제로 어디서 도나: 수신기 IP는 보통 HW로 ECC/CRC를 검사하고 에러를 인터럽트 + 카운터 레지스터(ECC 1-bit corrected, ECC 2-bit, CRC error, frame sync error, WC error)로 냅니다. 검증 SW의 일은 (1) 이 카운터를 읽고 (2) 디버그 캡처 버퍼를 SW 체커로 독립 재검증해서 HW 카운터와 SW 카운터가 일치하는지 보는 것입니다. 둘이 다르면 수신기 RTL 버그나 카운터 버그입니다.
  • TPG가 핵심 자극원: 센서 내장 TPG(color bar, walking 1s, PRBS)나 FPGA 패턴 소스로 기대값을 아는 데이터를 넣어야 bit-exact 비교가 됩니다. 실제 카메라 이미지로는 "보기에 괜찮다"만 알 수 있습니다.
  • 오류 주입: FPGA 송신기에서 헤더 1비트/2비트, payload 1비트, WC, FE 누락, VC 인터리브를 주입하는 시나리오 표를 만들고, 각 시나리오의 기대 카운터 값을 이 문제처럼 숫자로 고정합니다 → V5의 테스트 러너에 그대로 들어갑니다.
  • 처리량 계산: 1920×1080 RAW12 30 fps = 1920·1080·12·30 = 746.5 Mb/s payload. 패킷 오버헤드는 줄당 6 B/2880 B ≈ 0.2%, 블랭킹·LP 전환까지 약 10–20% 여유를 두면 D-PHY 2 lane × 1 Gb/s면 충분합니다. 4K60 RAW12(≈ 6 Gb/s)는 4 lane × 2.0–2.5 Gb/s가 필요합니다.
  • 프레임 타임스탬프와 FS 간격 검증은 V12와 이어집니다.

5.1 면접관(HW 출신 Sr Manager)이 파고들 포인트

  • "First silicon에서 카메라 없이 수신기를 어떻게 검증하나?" — FPGA(Zynq + D-PHY 송신 보드)를 패턴 소스로 쓰거나, SoC에 CSI-2 TX가 있으면 TX→RX 루프백, 또는 PHY 레벨 내부 루프백/PPI 패턴으로 시작합니다. 센서는 TPG 모드부터 켭니다. "I'd bring the receiver up with a known pattern source first — an FPGA CSI-2 transmitter or the sensor's own test pattern — so every byte is predictable and I can compare bit-exactly."
  • "당신 체커가 맞다는 걸 어떻게 아나?" — CRC는 공개 check 값과 스펙 예제, ECC는 30개 1비트 / 435개 2비트 전수 검사, 그리고 TPG를 다른 방식(열 테이블, bit-serial)으로 구현해 교차 검증합니다. HW 카운터와 SW 카운터의 일치도 서로를 검증합니다. "I check the checker: published CRC vectors, an exhaustive single- and double-bit sweep of the ECC, and an independently written generator."
  • "ECC corrected 카운트가 조금씩 올라가면?" — 링크 마진 문제입니다. D-PHY HS 데이터 레이트·deskew·termination·온도/전압을 바꿔 가며 에러율을 그리는 shmoo로 이어집니다 → V7. 1-bit corrected는 기능상 통과지만 PVT에서 늘어나는지 봐야 합니다. "Corrected errors are a margin signal, not a pass — I'd shmoo data rate against voltage and temperature and watch the corrected-error rate."
  • "Baidu에서 FPGA로 카메라 데이터를 처리했는데, 멀티 카메라는?" — VC(최대 4, v2.0은 16)나 DT로 여러 센서를 한 링크에 묶고(aggregator/SerDes, 예: GMSL/FPD-Link 디시리얼라이저), 수신기는 VC별로 다른 버퍼/ISP 채널로 라우팅합니다. 테스트 10번이 그 최소 형태입니다. "With a deserializer aggregating several cameras, each camera gets its own VC, so the checker must keep state per VC exactly like this."

6. Follow-up 질문과 답

Follow-up (English)답
D-PHY vs C-PHY?D-PHY: clock lane + 1–4 data lanes(차동쌍), HS 구간에 클럭 별도 전송, lane당 ~2.5 Gb/s(v2.x 4.5). C-PHY: 3선 trio에 3상 신호, 클럭 내장(embedded clock), 7심볼에 16비트(≈ 2.28 bit/symbol)라 같은 선 수에 더 높은 처리량. 패킷 계층(CSI-2)은 거의 같지만 C-PHY는 헤더 구조가 다르고 ECC 대신 CRC를 씁니다.
Explain lanes and HS / LP modes.LP(저속, single-ended, ~10 Mb/s)는 제어·line/frame 사이 휴지용, HS(고속 차동)는 데이터 burst. burst는 LP-11 → LP-01 → LP-00 → HS-0 → SoT 동기 바이트(0xB8)로 시작해 EoT 후 LP-11로 돌아옵니다. 이 문제의 버퍼는 SoT/EoT를 뺀 HS payload입니다.
How does lane merging work?송신기가 바이트를 lane에 round-robin으로 분배합니다(byte 0 → lane 0, byte 1 → lane 1 …). 수신기는 lane별 SoT로 정렬(deskew)한 뒤 다시 섞습니다. 패킷 길이가 lane 수의 배수가 아니면 lane마다 끝나는 시점이 다르고, lane 간 skew가 크면 merge가 틀어져 헤더 ECC 오류로 나타납니다.
How is RAW10 packed?4픽셀 → 5바이트: 바이트 0–3은 각 픽셀의 상위 8비트[9:2], 바이트 4는 네 픽셀의 하위 2비트(P0이 bit 1:0). 그래서 RAW10 폭은 4의 배수여야 WC가 정수입니다(1918 → 0). RAW12는 2픽셀 → 3바이트.
How does an ISP consume this?일반적 순서: BLC(black level) → 렌즈 셰이딩/결함 화소 보정 → demosaic(Bayer → RGB) → AWB 게인 → CCM(색 보정 행렬) → gamma/tone map → NR·sharpen → YUV 변환 → 인코더/NN. 각 블록은 레지스터로 bypass가 가능해서 검증 때 한 블록씩 켜며 golden 모델과 비교합니다.
What test pattern generators would you use?센서 TPG(color bar, 고정 값, walking 1s), 수신기/ISP 내부 TPG(수신기 이후 경로만 분리 검증), FPGA 패턴 소스(오류 주입 가능). 패턴은 PRBS나 카운터처럼 수신 측에서 재생성 가능한 것이 좋습니다 → V6.
How do you validate a receiver without a camera?FPGA CSI-2 TX(예: Zynq + D-PHY 보드)로 정상/오류 스트림 재생, SoC TX→RX 루프백, PHY 내부 루프백. 시나리오별 HW 에러 카운터와 SW 재검증 결과를 비교합니다.
Throughput: 1080p30 RAW12 vs lane rate?1920×1080×12×30 = 746.5 Mb/s. 블랭킹 포함 약 0.85–0.9 Gb/s → 1 lane 1.5 Gb/s 또는 2 lane 1 Gb/s. 8b/10b 같은 라인 코딩이 D-PHY에는 없어 lane rate가 그대로 비트율입니다.
What would you add next?LS/LE 줄 번호 연속성, FS 간 시간 간격(프레임 레이트·jitter), 에러 후 resync(다음 유효 헤더 탐색 대신 다음 SoT까지 버림), v2.0 VC 확장(VCX)과 ECC 26비트.
