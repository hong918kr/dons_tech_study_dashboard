V4 · Benchmark Harness: Latency / Throughput Stats from a 32-bit Cycle Counter

IDV4
PriorityP0
Patternwrap-safe delta + overhead calibration + nearest-rank percentile + overflow-safe integer math
Time30 min

파일: stub.c(여기서 풀기) · solution.c(정답) · 실행: ./run.sh V4 / ./run.sh V4 sol

0. 문제 한국어로 먼저 보기

영어 원문(§1)을 읽기 전에 무슨 상황이고 뭘 만들어야 하는지만 빠르게 잡는 요약입니다. 풀이 힌트는 없습니다.

한 줄 요약: 32-bit cycle counter 하나만으로 블록 성능을 재는 micro-benchmark 라이브러리(측정 overhead 보정, 반복 측정, 통계, MB/s 환산)를 짭니다.

상황

  • validation 팀이 새 SoC의 블록(CPU memcpy, DMA copy, NPU kernel)을 characterize(성능 특성 측정)할 때 쓰는 라이브러리입니다.
  • 쓸 수 있는 타이머는 read_cycles() 하나뿐입니다. free-running 32-bit cycle counter라서 2^32에서 wrap(0으로 되돌아감)됩니다.
  • counter를 읽는 것 자체에도 몇 cycle이 듭니다 (measurement overhead).
  • HAL은 stub.c 아래쪽의 fake입니다. 테스트는 counter를 0xFFFFFFFF 근처에서 시작시키거나, 특정 read에 추가 비용을 넣거나(인터럽트 흉내), 측정 대상 op의 호출마다 걸리는 시간을 지정할 수 있습니다.
  • 상수: CPU_HZ = 1.5 GHz, CPU_MHZ = 1500, BENCH_CAL_K = 8.
  • nearest-rank percentile: 정렬한 뒤 rank = ceil(p * n / 100)번째 값(sorted[rank - 1])을 그 percentile로 씀.

구현할 것

함수하는 일규칙
bench_calibrate(k)빈 측정의 비용t0 = read; t1 = read; t1 - t0을 k번 해서 최솟값. k == 0 → 0
bench_run(op, ctx, iters, warmup, samples, overhead_out)op를 반복 측정아래 3단계. 0 반환. op == NULL 또는 samples == NULL && iters > 0이면 -EINVAL
bench_stats(samples, n, outlier_x, st)샘플 통계 → BenchStatsmin, max, mean(64-bit 누적, 내림), p50·p99(nearest rank), outliers = p50 * outlier_x보다 엄격히 큰 샘플 수. samples는 호출자 버퍼라 제자리 정렬 허용. malloc 금지. n == 0 또는 NULL 포인터 → -EINVAL, *st는 건드리지 않음
bench_mbps(bytes_per_op, cycles_per_op, cpu_mhz)처리량(MB/s) 계산1 MB = 10^6 bytes. bytes * cpu_mhz / cycles를 내림. 어떤 입력에서도 64-bit overflow 없이. UINT64_MAX에서 saturate. cycles_per_op == 0 → 0

bench_run의 3단계

  1. overhead = bench_calibrate(BENCH_CAL_K). overhead_out이 NULL이 아니면 거기에 저장.
  2. op(ctx)를 warmup번 호출 (측정 안 함).
  3. iters번 반복: t0 = read; op(ctx); t1 = read; → samples[i] = (t1 - t0) - overhead. wrap-safe하게, 0 아래로는 clamp.

예시를 말로 풀면

  • read 비용 20 cycle, op는 정확히 1000 cycle: bench_run(op, ctx, 16, 4, ...) → ovh = 20, op 호출은 warmup 4 + 측정 16 = 20번, 샘플은 전부 1000 (측정값 1020에서 overhead 20을 뺌). 통계도 min = max = mean = p50 = p99 = 1000, 1000 > 2000인 샘플이 없으니 outliers = 0.
  • counter가 0 - 1100에서 시작 (wrap 발생): iteration 2에서 t0 = 0xFFFFFF9C(wrap 100 cycle 전), t1 = 0x000000DC(wrap 후 220). 실제 경과는 100 + 220 = 0x140 = 320, overhead를 빼면 300.
  • 샘플 100개 (1000 × 95, 1500 × 3, 5000 × 2, outlier_x = 2):
    • mean = (95000 + 4500 + 10000) / 100 = 1095
    • p50: rank = 50 → 정렬 후 50번째 = 1000. p99: rank = 99 → 99번째 = 5000
    • outlier 기준은 1000 × 2 = 2000 초과 → 5000 두 개 → outliers 2
  • bench_mbps
    • (4096, 2048, 1500) → 4096 × 1500 / 2048 = 3000 (4 KiB 복사에 2048 cycle, 1.5 GHz)
    • (1000, 3, 1000) → 333333.33을 내림해서 333333
    • (1ull << 54, 1000000, 1500) → 결과는 27021597764222지만, bytes * mhz를 그대로 곱하면 64-bit를 넘어감

지켜야 할 조건

  • C11, single thread. 인터럽트가 측정을 방해할 수 있음 (fake는 read 추가 비용으로 흉내 냄).
  • bench_stats의 n은 1 <= n <= 4096. O(n²) insertion sort 허용 (더 큰 n이면 뭘 쓸지 말할 것).
  • 실제 측정 구간은 항상 counter 한 주기(2^32 cycle ≈ 1.5 GHz에서 2.86 s)보다 짧음.

1. Problem

You are writing the micro-benchmark library the validation team uses to characterize blocks on a new SoC (CPU memcpy, DMA copies, NPU kernels). The only timer is a free-running 32-bit cycle counter read_cycles() that wraps at 2^32. Reading the counter costs a few cycles itself. The HAL is a fake at the bottom of stub.c: the test can start the counter near 0xFFFFFFFF, inject extra cost on individual reads, and script the duration of each call to the operation under test.

uint32_t read_cycles(void);                 /* HAL: free-running, wraps at 2^32 */
typedef void (*bench_op_fn)(void *ctx);     /* operation under test */
#define CPU_HZ      1500000000u             /* 1.5 GHz */
#define CPU_MHZ     (CPU_HZ / 1000000u)
#define BENCH_CAL_K 8

typedef struct {
    uint32_t n;
    uint32_t min, max, mean;   /* cycles, overhead removed, mean rounded down */
    uint32_t p50, p99;         /* nearest-rank percentiles */
    uint32_t outliers;         /* samples > p50 * outlier_x */
} BenchStats;

uint32_t bench_calibrate(uint32_t k);
int      bench_run(bench_op_fn op, void *ctx, uint32_t iters, uint32_t warmup,
                   uint32_t *samples, uint32_t *overhead_out);
int      bench_stats(uint32_t *samples, uint32_t n, uint32_t outlier_x, BenchStats *st);
uint64_t bench_mbps(uint64_t bytes_per_op, uint32_t cycles_per_op, uint32_t cpu_mhz);
  • bench_calibrate(k): the cost of an empty measurement (t0 = read; t1 = read; t1 - t0), taken as the minimum over k tries. k == 0 → 0.
  • bench_run: (1) overhead = bench_calibrate(BENCH_CAL_K), store it in *overhead_out if non-NULL; (2) call op(ctx) warmup times without measuring; (3) for each of iters iterations: t0 = read; op(ctx); t1 = read; and store samples[i] = (t1 - t0) - overhead, wrap-safe, clamped at 0. Return 0, or -EINVAL if op == NULL or samples == NULL && iters > 0.
  • bench_stats: min, max, mean (64-bit accumulator, floor), p50 and p99 by nearest rank: rank = ceil(p * n / 100), value = sorted[rank - 1]. outliers = number of samples strictly greater than p50 * outlier_x. You may sort samples in place (it is the caller's buffer). No malloc. n == 0 or NULL pointers → -EINVAL and *st is left untouched.
  • bench_mbps: throughput in MB/s (1 MB = 10^6 bytes) = bytes * cpu_mhz / cycles, rounded down, with no 64-bit overflow for any input. Saturate at UINT64_MAX. cycles_per_op == 0 → 0.

Example

read cost = 20 cycles, op takes exactly 1000 cycles
bench_run(op, ctx, 16, 4, smp, &ovh)  -> 0, ovh = 20, op called 20 times, smp[0..15] = 1000
bench_stats(smp, 16, 2, &st)          -> min = max = mean = p50 = p99 = 1000, outliers = 0

counter starts at 0 - 1100: iteration 2 sees t0 = 0xFFFFFF9C, t1 = 0x000000DC
                            raw = 0x140 = 320, sample = 320 - 20 = 300

100 samples: 95 x 1000, 3 x 1500, 2 x 5000 (any order), outlier_x = 2
  -> min 1000, max 5000, mean 1095, p50 1000, p99 5000, outliers 2

bench_mbps(4096, 2048, 1500)        -> 3000      (4 KiB copy in 2048 cycles at 1.5 GHz)
bench_mbps(1000, 3, 1000)           -> 333333    (333333.33 rounded down)
bench_mbps(1ull << 54, 1000000, 1500) -> 27021597764222   (bytes * mhz would overflow 64 bits)

Constraints

  • C11, single thread, interrupts may disturb a measurement (the fake injects this as extra read cost).
  • 1 <= n <= 4096 for bench_stats (O(n²) insertion sort is acceptable; say what you would use for larger n).
  • A real measured interval is always shorter than one counter period (2^32 cycles ≈ 2.86 s at 1.5 GHz).

Clarifying questions to ask (first 3 minutes)

  1. Is the counter 32 or 64 bit, and is it the core clock (PMU PMCCNTR) or a fixed-frequency timer (CNTVCT)? Does it keep counting under DVFS / WFI?
  2. How should I remove the measurement overhead — subtract a calibrated empty measurement? Min or mean of the calibration runs?
  3. Which percentile definition do you want: nearest rank or linear interpolation?
  4. Can I reorder the caller's sample buffer, or must I keep the original order (e.g. for a time-series plot)?
  5. Is MB 10^6 or 2^20 bytes? Round down or to nearest?
  6. Is the op measured one call per sample, or should I batch N calls per sample when the op is shorter than the overhead?

/* =====================================================================
 * Test harness: fake cycle counter + scripted operation (do not edit)
 * ===================================================================== */
static struct {
    uint32_t cyc;            /* counter value */
    uint32_t read_cost;      /* cycles a read_cycles() call costs (lands after the value is latched) */
    uint32_t extra[64];      /* extra cost injected on read #i (interrupt, cache miss) */
    uint32_t reads;
} F;

uint32_t read_cycles(void)
{
    uint32_t v = F.cyc;
    F.cyc += F.read_cost + (F.reads < 64 ? F.extra[F.reads] : 0);
    F.reads++;
    return v;
}

typedef struct { const uint32_t *dur; uint32_t n, calls; } Script;

static void fake_op(void *ctx)            /* advances the counter by the next scripted duration */
{
    Script *s = ctx;
    F.cyc += s->dur[s->calls % s->n];
    s->calls++;
}

static void fake_reset(uint32_t start)
{
    memset(&F, 0, sizeof F);
    F.cyc = start;
    F.read_cost = 20;
}

{

    uint32_t ovh = 0;

    CHECK(s1.calls == 20);

    Script s2 = { d2, 1, 0 };
    CHECK(bench_run(fake_op, &s2, 8, 0, smp, &ovh) == 0);
    CHECK(ovh == 20);
    CHECK(smp[1] == 300 && smp[2] == 300 && smp[3] == 300);
    CHECK(bench_stats(smp, 8, 2, &st) == 0);

3. 힌트 (막힐 때 하나씩)

Hint 1 — 랩어라운드는 뺄셈 한 번으로 끝

uint32_t raw = t1 - t0; 이면 됩니다. unsigned 뺄셈은 mod 2^32로 정의되어 있어서 t1이 wrap 후 작은 값이 되어도 결과가 맞습니다. if (t1 < t0) raw = (UINT32_MAX - t0) + t1 + 1; 같은 분기는 필요 없고, 64-bit나 signed로 바꿔서 빼면 오히려 틀립니다.

Hint 2 — 오버헤드는 왜 min인가

빈 측정의 진짜 비용은 고정값이고, 노이즈(인터럽트, 캐시 미스)는 항상 더하기만 합니다. 그래서 K번 중 최솟값이 진짜 값에 가장 가깝습니다. 평균을 쓰면 노이즈가 섞인 값만큼 모든 샘플을 과하게 빼게 됩니다(테스트 3번).

Hint 3 — MB/s 오버플로

bytes * mhz를 먼저 곱하면 bytes가 2^54 근처에서 64-bit를 넘습니다. bytes = q*cycles + r로 나눠서 q*mhz + (r*mhz)/cycles를 계산하면 정확한 floor 값이 나오고, r < cycles < 2^32라 r*mhz는 절대 넘치지 않습니다. q*mhz는 q > UINT64_MAX / mhz로 미리 검사해서 포화시킵니다.

4. 풀이

4.1 핵심 아이디어 — 분포를 보면 평균은 거짓말을 한다

벤치마크 결과는 숫자 하나가 아니라 분포입니다. 테스트 4번 데이터를 히스토그램으로 그리면, 평균(1095)은 실제 어떤 샘플과도 같지 않고 꼬리 2개에 끌려간 값입니다. 그래서 검증 리포트에는 min / p50 / p99 / max를 같이 적습니다.

  • min: 하드웨어가 낼 수 있는 최선(캐시 hit, 방해 없음). 회귀 비교에 가장 안정적입니다.
  • p50: 전형적인 값. 평균보다 꼬리에 덜 흔들립니다.
  • p99 / max: 실시간 시스템(카메라 프레임, 제어 루프)에서 deadline을 결정하는 값.
  • outlier 수: 인터럽트, refresh, TLB miss 같은 "가끔 생기는 일"이 몇 번 있었는지.

nearest rank 정의: rank = ceil(p·n/100). n = 4, 값 {10,20,30,40}이면 p50 = rank 2 = 20입니다(보간 정의면 25). 정의가 답을 바꾸므로 질문 3번을 먼저 합니다.

4.2 wrap-safe 측정과 오버헤드

fake에서 read_cycles()는 값을 먼저 잡고(latch) 그 뒤에 비용 20 cycle을 씁니다. 그래서 측정 하나는 raw = (t0 읽기 비용) + op이고, 빈 측정은 raw = t0 읽기 비용입니다. 빈 측정 값을 빼면 op 시간만 남습니다. 실제 코어에서도 같은 구조입니다: MRS PMCCNTR(또는 rdtsc) 자체와 그 앞뒤 파이프라인 효과가 항상 같이 잡힙니다.

4.4 정답 코드

💡 정답 코드 펼치기 (30분 풀어 본 다음에)
solution.c
/*
 * V4  Benchmark Harness: latency / throughput statistics from a 32-bit cycle counter
 * Reference solution.
 *
 * You are writing the micro-benchmark library used to characterize blocks on a new SoC
 * (memcpy, DMA, NPU kernels). The only timer is a free-running 32-bit cycle counter
 * read_cycles() that wraps at 2^32. The HAL is a FAKE at the bottom of this file.
 *
 *   uint32_t read_cycles(void)   free-running, wraps; reading it costs a few cycles itself
 *   typedef void (*bench_op_fn)(void *ctx)   the operation under test
 *
 * Implement:
 *   bench_calibrate(k)   overhead of an EMPTY measurement (t0 = read; t1 = read; t1 - t0),
 *                        taken as the MINIMUM over k tries. k == 0 -> 0.
 *   bench_run(op, ctx, iters, warmup, samples, overhead_out)
 *                        1) overhead = bench_calibrate(BENCH_CAL_K)
 *                        2) call op() `warmup` times, not measured
 *                        3) for i in [0, iters): t0 = read; op(ctx); t1 = read;
 *                           samples[i] = (t1 - t0) - overhead, wrap-safe, clamped at 0
 *                        returns 0, or -EINVAL if op == NULL or (samples == NULL && iters > 0).
 *   bench_stats(samples, n, outlier_x, st)
 *                        min, max, mean (64-bit accumulator, floor), p50, p99 by NEAREST RANK
 *                        (rank = ceil(p * n / 100), value = sorted[rank - 1]),
 *                        outliers = count of samples > p50 * outlier_x.
 *                        May sort `samples` in place (caller's buffer). No malloc.
 *                        n == 0 or NULL pointers -> -EINVAL and *st untouched.
 *   bench_mbps(bytes_per_op, cycles_per_op, cpu_mhz)
 *                        throughput in MB/s (1 MB = 10^6 bytes) = bytes * cpu_mhz / cycles,
 *                        rounded DOWN, no 64-bit overflow for any input; saturates at
 *                        UINT64_MAX; cycles_per_op == 0 -> 0.
 *
 * Build & run:  ./run.sh V4 sol
 */
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>
#include <errno.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

/* ---------------- HAL (provided) ---------------- */
uint32_t read_cycles(void);
typedef void (*bench_op_fn)(void *ctx);

#define CPU_HZ       1500000000u            /* 1.5 GHz core clock */
#define CPU_MHZ      (CPU_HZ / 1000000u)
#define BENCH_CAL_K  8                      /* empty measurements for calibration */
#define BENCH_MAX_N  4096                   /* max samples per run */

typedef struct {
    uint32_t n;
    uint32_t min, max, mean;    /* cycles, overhead already removed; mean rounded down */
    uint32_t p50, p99;          /* nearest-rank percentiles */
    uint32_t outliers;          /* samples > p50 * outlier_x */
} BenchStats;

/* ---------------- benchmark library: your code ---------------- */

uint32_t bench_calibrate(uint32_t k)
{
    uint32_t best = UINT32_MAX;
    if (k == 0) return 0;
    for (uint32_t i = 0; i < k; i++) {
        uint32_t t0 = read_cycles();
        uint32_t t1 = read_cycles();
        uint32_t d = t1 - t0;                 /* unsigned subtraction: wrap-safe */
        if (d < best) best = d;               /* min = least-disturbed measurement */
    }
    return best;
}

int bench_run(bench_op_fn op, void *ctx, uint32_t iters, uint32_t warmup,
              uint32_t *samples, uint32_t *overhead_out)
{
    if (op == NULL || (samples == NULL && iters > 0)) return -EINVAL;

    uint32_t ovh = bench_calibrate(BENCH_CAL_K);
    if (overhead_out) *overhead_out = ovh;

    for (uint32_t i = 0; i < warmup; i++) op(ctx);       /* caches, TLB, branch predictor */

    for (uint32_t i = 0; i < iters; i++) {
        uint32_t t0 = read_cycles();
        op(ctx);
        uint32_t t1 = read_cycles();
        uint32_t raw = t1 - t0;                           /* correct across one wrap */
        samples[i] = (raw > ovh) ? raw - ovh : 0;
    }
    return 0;
}

static void sort_u32(uint32_t *a, uint32_t n)             /* insertion sort, n <= BENCH_MAX_N */
{
    for (uint32_t i = 1; i < n; i++) {
        uint32_t v = a[i], j = i;
        while (j > 0 && a[j - 1] > v) { a[j] = a[j - 1]; j--; }
        a[j] = v;
    }
}

static uint32_t pct_nearest_rank(const uint32_t *sorted, uint32_t n, uint32_t p)
{
    uint64_t rank = ((uint64_t)p * n + 99u) / 100u;       /* ceil(p*n/100) */
    if (rank == 0) rank = 1;
    return sorted[rank - 1];
}

int bench_stats(uint32_t *samples, uint32_t n, uint32_t outlier_x, BenchStats *st)
{
    if (samples == NULL || st == NULL || n == 0) return -EINVAL;

    sort_u32(samples, n);

    uint64_t sum = 0;                                     /* 32-bit sum overflows fast */
    for (uint32_t i = 0; i < n; i++) sum += samples[i];

    BenchStats s;
    s.n    = n;
    s.min  = samples[0];
    s.max  = samples[n - 1];
    s.mean = (uint32_t)(sum / n);
    s.p50  = pct_nearest_rank(samples, n, 50);
    s.p99  = pct_nearest_rank(samples, n, 99);

    uint64_t lim = (uint64_t)s.p50 * outlier_x;           /* 64-bit: no overflow */
    s.outliers = 0;
    for (uint32_t i = 0; i < n; i++)
        if (samples[i] > lim) s.outliers++;

    *st = s;
    return 0;
}

uint64_t bench_mbps(uint64_t bytes_per_op, uint32_t cycles_per_op, uint32_t cpu_mhz)
{
    if (cycles_per_op == 0) return 0;
    /* bytes * mhz / cycles, split into quotient and remainder so nothing overflows:
     *   bytes = q*cycles + r  ->  result = q*mhz + (r*mhz)/cycles   (exact floor) */
    uint64_t q = bytes_per_op / cycles_per_op;
    uint64_t r = bytes_per_op % cycles_per_op;            /* r < 2^32 */
    if (cpu_mhz != 0 && q > UINT64_MAX / cpu_mhz) return UINT64_MAX;
    uint64_t hi = q * cpu_mhz;
    uint64_t lo = (r * cpu_mhz) / cycles_per_op;          /* r*mhz < 2^64 */
    if (hi > UINT64_MAX - lo) return UINT64_MAX;
    return hi + lo;
}

/* =====================================================================
 * Test harness: fake cycle counter + scripted operation (do not edit)
 * ===================================================================== */
static struct {
    uint32_t cyc;            /* counter value */
    uint32_t read_cost;      /* cycles a read_cycles() call costs (lands after the value is latched) */
    uint32_t extra[64];      /* extra cost injected on read #i (interrupt, cache miss) */
    uint32_t reads;
} F;

uint32_t read_cycles(void)
{
    uint32_t v = F.cyc;
    F.cyc += F.read_cost + (F.reads < 64 ? F.extra[F.reads] : 0);
    F.reads++;
    return v;
}

typedef struct { const uint32_t *dur; uint32_t n, calls; } Script;

static void fake_op(void *ctx)            /* advances the counter by the next scripted duration */
{
    Script *s = ctx;
    F.cyc += s->dur[s->calls % s->n];
    s->calls++;
}

static void fake_reset(uint32_t start)
{
    memset(&F, 0, sizeof F);
    F.cyc = start;
    F.read_cost = 20;
}

int main(void)
{
    static uint32_t smp[BENCH_MAX_N];
    BenchStats st;
    uint32_t ovh = 0;

    /* 1. constant 1000-cycle op: overhead 20 removed, warm-up calls not recorded */
    fake_reset(1000);
    const uint32_t d1[] = { 1000 };
    Script s1 = { d1, 1, 0 };
    CHECK(bench_run(fake_op, &s1, 16, 4, smp, &ovh) == 0);
    CHECK(ovh == 20);
    CHECK(s1.calls == 20);
    CHECK(smp[0] == 1000 && smp[15] == 1000);
    CHECK(bench_stats(smp, 16, 2, &st) == 0);
    CHECK(st.min == 1000 && st.max == 1000 && st.mean == 1000);
    CHECK(st.p50 == 1000 && st.p99 == 1000 && st.outliers == 0);

    /* 2. counter wraps inside iteration 2: t0 = 0xFFFFFF9C, t1 = 0x000000DC */
    fake_reset(0u - 1100u);
    const uint32_t d2[] = { 300 };
    Script s2 = { d2, 1, 0 };
    CHECK(bench_run(fake_op, &s2, 8, 0, smp, &ovh) == 0);
    CHECK(ovh == 20);
    CHECK(smp[1] == 300 && smp[2] == 300 && smp[3] == 300);
    CHECK(bench_stats(smp, 8, 2, &st) == 0);
    CHECK(st.max == 300 && st.min == 300);

    /* 3. calibration is the MIN of K empty reads, not the first or the mean */
    fake_reset(0);
    for (int i = 0; i < 14; i += 2) F.extra[i] = 15;     /* empty pairs 0..6 disturbed: 35 cycles */
    const uint32_t d3[] = { 500, 520, 480 };
    Script s3 = { d3, 3, 0 };
    CHECK(bench_run(fake_op, &s3, 6, 0, smp, &ovh) == 0);
    CHECK(ovh == 20);
    CHECK(smp[0] == 500 && smp[1] == 520 && smp[2] == 480 && smp[5] == 480);
    fake_reset(0);
    F.extra[0] = 15;
    CHECK(bench_calibrate(1) == 35);
    CHECK(bench_calibrate(0) == 0);

    /* 4. known distribution: 95 x 1000, 3 x 1500, 2 x 5000 (shuffled) -> nearest rank */
    uint32_t n = 0;
    for (int i = 0; i < 100; i++)
        smp[n++] = (i == 17 || i == 63) ? 5000 : (i == 5 || i == 40 || i == 88) ? 1500 : 1000;
    CHECK(bench_stats(smp, n, 2, &st) == 0);
    CHECK(st.min == 1000 && st.max == 5000);
    CHECK(st.mean == 1095);
    CHECK(st.p50 == 1000 && st.p99 == 5000);
    CHECK(st.outliers == 2);
    uint32_t four[] = { 40, 10, 30, 20 };                 /* nearest rank, not interpolation */
    CHECK(bench_stats(four, 4, 1, &st) == 0);
    CHECK(st.p50 == 20 && st.p99 == 40 && st.mean == 25 && st.outliers == 2);
    uint32_t big[] = { 0xF0000000u, 0xF0000000u, 0xF0000000u, 0xF0000000u };
    CHECK(bench_stats(big, 4, 0xFFFFFFFFu, &st) == 0);    /* 32-bit sum / p50*x would overflow */
    CHECK(st.mean == 0xF0000000u && st.outliers == 0);

    /* 5. zero-iteration / bad-argument guards */
    fake_reset(0);
    Script s5 = { d1, 1, 0 };
    CHECK(bench_run(fake_op, &s5, 0, 3, NULL, &ovh) == 0 && s5.calls == 3);
    CHECK(bench_run(NULL, &s5, 4, 0, smp, &ovh) == -EINVAL);
    CHECK(bench_run(fake_op, &s5, 4, 0, NULL, &ovh) == -EINVAL);
    st.n = 0xABCD;
    CHECK(bench_stats(smp, 0, 2, &st) == -EINVAL && st.n == 0xABCD);
    CHECK(bench_stats(NULL, 4, 2, &st) == -EINVAL);

    /* 6. throughput MB/s: integer math, floor, overflow-safe */
    CHECK(bench_mbps(4096, 2048, CPU_MHZ) == 3000);
    CHECK(bench_mbps(1000, 3, 1000) == 333333);            /* 333333.33 -> floor */
    CHECK(bench_mbps(1ull << 54, 1000000, CPU_MHZ) == 27021597764222ull);  /* bytes*mhz > 2^64 */
    CHECK(bench_mbps(UINT64_MAX, 1, 2) == UINT64_MAX);     /* saturate */
    CHECK(bench_mbps(4096, 0, CPU_MHZ) == 0);

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

코드 읽는 포인트

  • uint32_t raw = t1 - t0; 한 줄이 wrap 처리 전부입니다. 조건은 "실제 구간 < 2^32 cycles"뿐이고, 이건 Constraints에 있습니다.
  • samples[i] = (raw > ovh) ? raw - ovh : 0; — op가 거의 0 cycle이면 노이즈 때문에 raw < ovh가 될 수 있고, 그대로 빼면 unsigned underflow로 4 × 10^9 같은 값이 됩니다.
  • 측정 루프 안에는 read → op → read와 저장 한 번만 있습니다. 통계, printf, 분기는 루프 밖에서 합니다(measurement perturbation 최소화).
  • bench_stats는 결과를 지역 변수 s에 만든 다음 마지막에 *st = s로 한 번에 씁니다. 그래서 에러 경로에서는 *st가 바뀌지 않습니다.
  • pct_nearest_rank의 ((uint64_t)p * n + 99) / 100은 정수 ceil입니다. rank == 0 방어는 p = 0을 위한 것입니다.
  • (uint64_t)s.p50 * outlier_x — p50 = 0xF0000000, x = 0xFFFFFFFF 같은 값은 32-bit에서 넘칩니다(테스트 4번 마지막).

4.5 복잡도

  • bench_run: 시간 O(K + warmup + iters), 메모리 O(1) + 호출자 버퍼.
  • bench_stats: insertion sort O(n²) (n ≤ 4096이면 최악 ~8M 비교, 리포트 단계라 허용). n이 크면 heapsort O(n log n, 추가 메모리 0) 또는 고정 bin 히스토그램 O(n)으로 p50/p99를 근사합니다.
  • bench_mbps: O(1), 나눗셈 2번.

5. 임베디드 관점으로 말할 것

  • 카운터 선택: Cortex-A/R의 PMU cycle counter(PMCCNTR_EL0)는 코어 클록을 세므로 DVFS로 주파수가 바뀌면 "cycle"은 그대로인데 시간은 바뀝니다. Generic timer(CNTVCT_EL0)는 고정 주파수(예: 24–100 MHz)라 벽시계 시간에 맞지만 분해능이 낮습니다. 리포트에 둘 중 무엇인지, 측정 중 주파수를 고정했는지 적습니다.
  • 오버헤드 / 직렬화: out-of-order 코어에서는 ISB(Arm) 또는 lfence; rdtsc(x86)로 카운터 읽기를 op 앞뒤로 고정해야 op가 측정 구간 밖으로 새지 않습니다. 이 문제의 calibrate는 그 비용까지 함께 빼는 구조입니다.
  • warm-up: 첫 몇 번은 I-cache/D-cache miss, TLB miss, 분기 예측 학습, DDR page open 때문에 느립니다. warm-up을 버리거나, 반대로 cold 성능이 목적이면 매 iteration 전에 cache flush를 하고 그 사실을 명시합니다.
  • throughput은 정수로: bare-metal 검증 펌웨어는 FPU를 안 켜거나 printf %f가 없는 경우가 많습니다. MB/s를 정수 floor로 내고, 필요하면 ×1000한 milli-MB/s로 소수점을 보존합니다.
  • 결과는 host로: 샘플 원본 대신 min/p50/p99/max/outliers 한 줄(CSV)을 UART로 내보내고, 원본은 필요할 때만 덤프합니다 → 같은 형식의 결과 라인은 V5 참고.

5.1 면접관(HW 출신 Sr Manager)이 파고들 포인트

  • "How do you know your benchmark itself is right?" — 이론값을 아는 대상으로 먼저 검증합니다: NOP N개 루프(= N cycle), 알려진 DDR 대역폭, 또는 HW 성능 카운터/로직 분석기와 교차 확인. "I validate the harness first against something with a known answer, like a fixed NOP loop or a DMA with a known bus width and clock, before I trust it on a new block."
  • "FPGA/HAPS에서 잰 숫자와 실리콘 숫자가 다르다." — FPGA는 클록이 10–50 MHz라 절대값은 의미가 없고, cycle 수와 비율(op 대비 DDR latency) 만 비교합니다. 메모리 서브시스템은 FPGA에서 다른 IP(예: 대체 DDR 컨트롤러)를 쓰는 경우가 많아 그 차이를 리포트에 명시합니다. "On FPGA I compare cycle counts and ratios, not absolute time, and I flag any block that is modeled differently there, like the DDR controller."
  • "achieved vs theoretical" — 이론 대역폭(버스 폭 × 클록 × 채널)이나 이론 TOPS(MAC 수 × 2 × 클록)를 먼저 적고 utilization = achieved / theoretical로 말합니다. 낮으면 roofline으로 compute-bound인지 memory-bound인지 가릅니다. "I always report utilization against the theoretical peak, and use a roofline to say whether we are compute- or bandwidth-bound."
  • "PVT / 주파수 sweep과 어떻게 엮나" — 같은 벤치를 주파수·전압·온도 조합마다 돌리고 CSV로 모아 perf/W 곡선과 shmoo 형태로 그립니다 → V7. "The same benchmark runs at every frequency-voltage-temperature point and the host plots perf per watt; any point where results drift beyond run-to-run variance is a margin flag."
  • "run-to-run variance" — 같은 보드에서 여러 번, 여러 보드에서 반복해 p50의 분산을 봅니다. 차이가 그 분산보다 작으면 "개선/회귀"라고 말하지 않습니다. "A change only counts if it is larger than the run-to-run variance we measured on the same build."

Follow-up (English)답
Cycle counter vs a timer: which do you use and why?PMU PMCCNTR는 코어 cycle 단위로 분해능이 높지만 DVFS·WFI에 영향을 받고, 코어마다 따로입니다. CNTVCT는 고정 주파수·시스템 전체 공통이라 멀티코어/DMA 구간 측정에 맞지만 분해능이 낮습니다. 짧은 커널은 PMU, 긴 전송/여러 마스터 구간은 generic timer를 씁니다. 32-bit면 오버플로 IRQ로 상위 비트를 확장하거나 64-bit 카운터를 씁니다.
What about frequency scaling during the run?측정 중 DVFS governor를 끄고 주파수를 고정한 뒤, 그 주파수를 결과에 같이 기록합니다. cycle → 시간 변환은 측정 당시 실제 주파수(PLL 레지스터에서 읽은 값)로 합니다.
Why warm up? When would you NOT?캐시/TLB/분기 예측/DDR page 상태를 안정시켜 steady-state를 보려는 것입니다. 부팅 시간, 첫 프레임 latency처럼 cold 성능이 요구사항이면 반대로 매번 cache clean+invalidate, TLB flush 후 측정합니다.
How would you measure DMA bandwidth vs CPU memcpy?CPU memcpy는 read → memcpy → read로 됩니다. DMA는 시작 시각을 kick 직전, 끝을 완료 인터럽트/상태 비트로 잡고, 큰 전송(수 MB)으로 setup 비용을 희석합니다. 캐시 coherency(clean/invalidate) 비용을 포함할지 명시하고, 결과는 bench_mbps로 같은 단위로 비교합니다.
How do you report utilization, e.g. achieved vs theoretical TOPS?이론 TOPS = MAC 수 × 2 × 클록. achieved = 연산 수 / 측정 시간. utilization = achieved / 이론. roofline(산술 강도 = ops/byte 대 대역폭 한계)에 찍어서 메모리 병목인지 계산 병목인지 판단합니다.
How would you sweep compute / IO frequency and plot perf/W?주파수 테이블을 돌며 PLL 설정 → 안정화 대기 → 벤치 → 전력(PMIC/INA 센서) 측정을 반복하고 한 줄 CSV로 host에 보냅니다. host가 perf, power, perf/W를 그리고 knee point를 찾습니다.
Is a 2% improvement real?run-to-run variance를 먼저 잽니다(같은 빌드 N회, p50의 표준편차나 min-max 범위). 차이가 그보다 작으면 노이즈입니다. 엄밀하게는 두 분포에 Mann-Whitney 같은 비모수 검정을 씁니다(분포가 정규가 아니므로).
Does the measurement perturb what you measure?네. 카운터 읽기, 샘플 저장(캐시 라인 오염), printf가 영향을 줍니다. 루프 안에서는 저장만 하고, op가 오버헤드보다 짧으면 N번을 묶어 한 샘플로 재고 N으로 나눕니다. 인터럽트는 측정 구간 동안 마스킹하거나, 남기고 outlier로 셉니다.
Why insertion sort?n ≤ 4096이고 리포트 단계라 단순함이 우선입니다. 더 크면 heapsort(추가 메모리 0), 또는 정해진 bin의 히스토그램으로 O(n) 근사 percentile을 냅니다. 원래 순서(시계열)가 필요하면 복사본을 정렬합니다.

7. 자주 하는 실수

  • 64-bit나 signed로 바꿔서 t1 - t0 → wrap 구간에서 음수/거대한 값 (테스트 2번)
  • calibration에 평균이나 첫 값을 씀 → 모든 샘플이 과하게 빠짐 (테스트 3번)
  • raw - ovh를 그냥 빼서 unsigned underflow
  • 합계를 uint32_t로 누적 → 0xF0000000 × 4에서 넘침 (테스트 4번 마지막)
  • p99를 sorted[n * 99 / 100]으로 계산 → rank와 index를 섞은 off-by-one (n = 100이면 index 99 = rank 100 = max가 되어 버림). rank = ceil(p·n/100), index = rank − 1로 나눠 씁니다
  • n == 0에서 sum / n → 0으로 나누기 (테스트 5번)
  • bytes * mhz / cycles를 그대로 곱함 → 큰 값에서 64-bit 오버플로 (테스트 6번)
  • warm-up 호출을 아예 안 하거나, warm-up 결과도 samples에 저장
