V7 · Shmoo Sweep + Margin Analysis (PVT characterization)

IDV7
PriorityP0
Pattern2-D grid sweep + repeat voting + monotonic-edge scan
Time30 min

파일: stub.c(여기서 풀기) · solution.c(정답) · 실행: ./run.sh V7 / ./run.sh V7 sol

0. 문제 한국어로 먼저 보기

영어 원문(§1)을 읽기 전에 무슨 상황이고 뭘 만들어야 하는지만 빠르게 잡는 요약입니다. 풀이 힌트는 없습니다.

한 줄 요약: 첫 실리콘의 전압(V) × 주파수(F) 격자를 다 돌려서 pass/fail 지도(shmoo)를 만들고, 거기서 fmax / Vmin / margin / hole을 뽑고 ASCII로 그리는 characterization 툴을 짭니다.

상황

  • DUT(테스트 대상 칩)는 함수 하나만 줍니다: run_test(v_mv, f_mhz). core 전원 전압과 clock을 설정하고 functional pattern을 돌려서 pass/fail(true/false)을 돌려줍니다.
  • stub.c 아래쪽 숨은 모델(fake)이 이걸 흉내 냅니다. fake는 수정 금지.
    • 기본은 전압/주파수 wall: 전압이 높을수록 더 높은 F까지 pass
    • 선택적으로 hole(항상 fail하는 특정 점) 1개
    • 선택적으로 flaky 점 1개(그 점에 대한 호출이 2번째마다 fail)
  • 용어
    • shmoo: V × F 격자의 각 점에 pass/fail을 찍은 지도
    • 셀 값: CELL_PASS(돌린 횟수 전부 pass), CELL_FAIL(전부 fail), CELL_MARGINAL(섞임)
    • fmax: 어떤 전압에서 안정적으로 도는 최고 주파수
    • Vmin: 목표 주파수를 만족하는 최저 전압
    • margin: nominal 전압에서 fmax가 target보다 얼마나 여유 있는지
    • hole: 주변은 pass인데 그 점만 fail인 구멍
  • 격자 인덱스: map[vi * nf + fi], vi = 0이 v_lo, fi = 0이 f_lo.

구현할 것

함수하는 일규칙
shmoo_sweep(c, map, cap)격자 전 점(V v_lo..v_hi, F f_lo..f_hi)에서 테스트를 repeats번씩 돌려 셀 하나씩 기록전부 pass → CELL_PASS, 전부 fail → CELL_FAIL, 섞이면 CELL_MARGINAL
잘못된 격자(step 0, hi < lo, repeats == 0) → -EINVAL
cap < nv * nf → -ENOSPC
shmoo_fmax(c, map, vi)행 vi의 fmaxF 그리고 그 아래 모든 격자 주파수가 CELL_PASS인 가장 높은 F ("아래부터 끊김 없이 pass")
f_lo가 pass가 아니면 0
shmoo_vmin(c, map, target_mhz)fmax ≥ target_mhz인 가장 낮은 격자 전압그런 행이 없으면 0
shmoo_margin(c, map, nominal_mv, target_mhz, margin_mhz, margin_pct10)nominal 전압에서의 여유nominal_mv가 격자 전압이 아니면 -EINVAL
margin_mhz = fmax − target (음수 가능)
margin_pct10 = margin_mhz * 1000 / target (퍼센트 × 10, 0 쪽으로 버림)
shmoo_holes(c, map, out, cap)hole 목록hole = CELL_FAIL이면서 같은 행의 양쪽(낮은 F, 높은 F) 또는 같은 열의 양쪽(낮은 V, 높은 V)에 CELL_PASS가 있는 점
map 순서로 보고, 최대 cap개 쓰고 전체 개수 반환
shmoo_render(c, map, buf, cap)ASCII 그림가장 높은 전압부터 한 행에 한 줄: "%4u |" + F마다 한 글자(* pass, . fail, ? marginal) + '\n'
snprintf 규칙: cap 넘어 쓰지 않음, cap > 0이면 NUL 종료, 필요한 전체 길이 반환

예시를 말로 풀면

  • 격자: V 700..1000 step 50 (7행), F 200..1000 step 100 (9열), repeats = 3.
  • DUT는 f <= 2 * (v - 500)이면 pass (예: 900 mV → 800 MHz까지 pass). 여기에 (950 mV, 400 MHz) hole, (800 mV, 600 MHz) flaky가 있습니다.
  • 행별 fmax
    • 1000 mV: 전 칸 pass → 1000
    • 950 mV: 원래 900까지 pass지만 400에 hole이 있어 아래부터 끊김 없는 구간이 300에서 끊김 → 300
    • 900 / 850 mV: 800 / 700
    • 800 mV: 600이 flaky라 3번 중 섞여서 ?(marginal). marginal은 pass가 아니므로 fmax = 500
    • 750 / 700 mV: 500 / 400
  • shmoo_vmin(700): fmax ≥ 700인 가장 낮은 행 → 850 mV
  • shmoo_margin(900, 700): 900 mV의 fmax 800 − 700 = +100 MHz, pct10 = 100 × 1000 / 700 = 142 (14.2 %)
  • shmoo_holes: (950, 400) 하나뿐. 800/600의 ?는 CELL_FAIL이 아니라서 hole이 아님.
  • run_test 호출 수: 63점 × 3번 = 189 (정확히 이만큼이어야 함)

지켜야 할 조건

  • 격자는 수천 점까지. map은 호출자가 주며 점당 1바이트.
  • fake가 run_test 호출 수(F.calls)를 세므로 돌린 횟수가 정확히 검사됨.
  • flaky 점은 그 점에 대한 호출이 2번째마다 fail: 1번만 돌리면 멀쩡해 보이고, 3번 돌리면 드러남.
  • malloc 금지, 정수 연산만.

1. Problem

You are writing the characterization tool for first silicon. The DUT exposes one call, run_test(v_mv, f_mhz), which sets the core supply and clock, runs a functional pattern and returns pass/fail. It is implemented at the bottom of stub.c by a hidden model (a voltage/frequency wall, plus an optional deterministic hole and an optional flaky point). Do not edit the fake.

Build a shmoo tool on top of it:

  • shmoo_sweep: visit every grid point (V from v_lo to v_hi, F from f_lo to f_hi), run the test repeats times per point, and store one cell per point in map[vi * nf + fi] (vi = 0 is v_lo, fi = 0 is f_lo): CELL_PASS if all runs passed, CELL_FAIL if all failed, CELL_MARGINAL if mixed. Bad grid (a step of 0, hi < lo, repeats == 0) → -EINVAL; cap < nv * nf → -ENOSPC.
  • shmoo_fmax: for row vi, the highest F such that F and every lower grid frequency are CELL_PASS ("contiguous pass from the bottom"). 0 if f_lo does not pass.
  • shmoo_vmin: the lowest grid voltage whose fmax ≥ target_mhz; 0 if no row reaches it.
  • shmoo_margin: at nominal_mv (must be a grid voltage, else -EINVAL): margin_mhz = fmax − target (may be negative) and margin_pct10 = margin_mhz * 1000 / target (percent × 10, truncated toward zero).
  • shmoo_holes: a hole is a CELL_FAIL point with a CELL_PASS point on both sides of it in its row (lower F and higher F) or in its column (lower V and higher V). Report in map order; write at most cap, return the total.
  • shmoo_render: ASCII plot, highest voltage first, one line per row: "%4u |" + one char per F (* pass, . fail, ? marginal) + '\n'. snprintf rules: never write past cap, NUL-terminate when cap > 0, return the full length needed.
  • No malloc, integer math only.

Example

grid: V 700..1000 step 50 (7 rows), F 200..1000 step 100 (9 cols), repeats = 3
DUT : pass iff f <= 2 * (v - 500); hole at (950 mV, 400 MHz); flaky at (800 mV, 600 MHz)

shmoo_render ->                fmax per row
1000 |*********                1000
 950 |**.*****.                 300   <- hole at 400 cuts the contiguous run
 900 |*******..                 800
 850 |******...                 700
 800 |****?....                 500   <- marginal is not a pass
 750 |****.....                 500
 700 |***......                 400

shmoo_vmin(700)               = 850 mV
shmoo_margin(900, 700)        = +100 MHz, pct10 = 142   (14.2 %)
shmoo_holes                   = { (950, 400) }          (the '?' is not a hole)
run_test calls                = 63 points x 3 = 189

Constraints

  • Grid up to a few thousand points; map is caller-provided, one byte per point.
  • The fake counts run_test calls (F.calls), so the number of runs is tested exactly.
  • The flaky point fails on every 2nd call to that point: one run looks fine, three runs do not.

Clarifying questions to ask (first 3 minutes)

  1. How is fmax defined when a row is not monotonic — the highest passing F, or the top of the contiguous pass run from the bottom?
  2. How many repeats per point, and how should mixed results be reported?
  3. Does a marginal point count as pass for fmax/Vmin? (Here: no — be conservative.)
  4. Is margin measured in MHz, in %, or in mV (voltage margin at the target frequency)?
  5. What do you call a hole — row-wise only, or also column-wise?
  6. Is the full grid affordable in test time, or should I search for the wall?

/* ======================================================================
 * Test harness: fake DUT (do not edit)
 *   pass  <=>  f <= fmax(v) = (v - v0_mv) * mhz_per_10mv / 10
 *   hole  : (hole_v, hole_f) always fails (e.g. a supply resonance / PLL lock problem)
 *   flaky : (flaky_v, flaky_f) fails on every 2nd call to that point
 * ====================================================================== */
static struct {
    int32_t  v0_mv, mhz_per_10mv;
    uint16_t hole_v, hole_f;       /* 0 = no hole        */
    uint16_t flaky_v, flaky_f;     /* 0 = no flaky point */
    uint32_t flaky_calls;
    uint32_t calls;                /* total run_test() calls */
} F;

static void fake_reset(void)
{
    memset(&F, 0, sizeof F);
    F.v0_mv = 500; F.mhz_per_10mv = 20;            /* 2 MHz per mV above 500 mV */
}

bool run_test(uint16_t v_mv, uint16_t f_mhz)
{
    F.calls++;
    if (F.hole_v && v_mv == F.hole_v && f_mhz == F.hole_f) return false;
    if (F.flaky_v && v_mv == F.flaky_v && f_mhz == F.flaky_f && (++F.flaky_calls % 2) == 0)
        return false;
    int32_t fmax = ((int32_t)v_mv - F.v0_mv) * F.mhz_per_10mv / 10;
    return (int32_t)f_mhz <= fmax;
}

{

    static char txt[256];

    CHECK(shmoo_margin(&g, map, 900, 700, &mm, &mp) == 0 && mm == 100 && mp == 142);

        " 850 |******...\n"
        " 800 |*****....\n"
        " 750 |****.....\n"
        " 700 |***......\n";

    CHECK(shmoo_holes(&g, map, holes, 4) == 1 && holes[0].v_mv == 950 && holes[0].f_mhz == 400);
    CHECK(shmoo_fmax(&g, map, 5) == 300);
    CHECK(shmoo_margin(&g, map, 950, 700, &mm, &mp) == 0 && mm == -400 && mp == -571);
    CHECK(shmoo_vmin(&g, map, 700) == 850);                 /* other rows unaffected */

    CHECK(shmoo_render(&g1, map, txt, sizeof txt) == 16 && strcmp(txt, " 900 |*******..\n") == 0);

    /* 6. render into a tiny buffer: snprintf semantics */
    fake_reset();
    CHECK(shmoo_sweep(&g, map, sizeof map) == 0);
    char small[10]; memset(small, 'X', sizeof small);
    CHECK(shmoo_render(&g, map, small, sizeof small) == 112);
    CHECK(strcmp(small, "1000 |***") == 0);
    CHECK(shmoo_render(&g, map, NULL, 0) == 112);

    /* 7. hole + flaky together, R=3 (the plot in the README) */
    fake_reset(); F.hole_v = 950; F.hole_f = 400; F.flaky_v = 800; F.flaky_f = 600;
    CHECK(shmoo_sweep(&g3, map, sizeof map) == 0);
    const char *both =
        "1000 |*********\n"
        " 950 |**.*****.\n"
        " 900 |*******..\n"
        " 850 |******...\n"
        " 800 |****?....\n"
        " 750 |****.....\n"
        " 700 |***......\n";
    CHECK(shmoo_render(&g3, map, txt, sizeof txt) == 112 && strcmp(txt, both) == 0);
    CHECK(shmoo_vmin(&g3, map, 700) == 850);
    CHECK(shmoo_margin(&g3, map, 900, 700, &mm, &mp) == 0 && mm == 100 && mp == 142);

    printf(g_fail ? "%d FAILED\n" : "ALL PASS\n", g_fail);
    return g_fail != 0;
}

3. 힌트 (막힐 때 하나씩)

Hint 1 — repeat는 "통과 횟수"만 세면 된다

한 점에서 pass를 0부터 세고 repeats번 돌립니다. pass == repeats면 PASS, pass == 0이면 FAIL, 그 사이면 MARGINAL. 첫 실패에서 멈추면(early exit) 호출 횟수 테스트(189회)가 틀어지고, 무엇보다 "몇 번 중 몇 번 실패했나"라는 정보를 잃습니다.

Hint 2 — fmax는 아래에서부터 첫 non-PASS에서 멈춘다

for (fi = 0; fi < nf; fi++) { if (map[...] != CELL_PASS) break; fmax = F(fi); }. 위쪽에서 마지막 PASS를 찾으면 hole을 건너뛰어 버려서 950 mV 줄이 900 MHz로 나옵니다. 실리콘에서는 "그 주파수까지 모든 주파수가 안전해야" 쓸 수 있으므로 연속 구간이 맞습니다.

Hint 3 — render는 pos를 항상 증가, 쓰기만 조건부

if (pos + 1 < cap) buf[pos] = ch; pos++; 패턴을 모든 글자에 쓰면 버퍼가 작아도 안전하고, 반환값은 항상 전체 길이(112)입니다. 마지막에 cap > 0이면 buf[min(pos, cap-1)] = '\0'. 줄 머리는 snprintf(head, 8, "%4u |", v)로 만들면 됩니다.

4. 풀이

4.1 핵심 아이디어 — 그림으로 보기

Shmoo plot은 "어떤 전압·주파수 조합에서 칩이 동작하는가"를 한 장에 보여 줍니다. V가 올라가면 트랜지스터가 빨라져서 더 높은 F까지 통과하므로, 정상적인 칩은 오른쪽 위로 올라가는 계단(wall) 하나로 PASS/FAIL이 나뉩니다. 계단 모양이 깨진 곳(hole, ?)이 바로 validation 엔지니어가 찾아야 하는 버그 후보입니다.

세 가지 숫자의 의미:

  • fmax(V): 그 전압에서 쓸 수 있는 최고 클럭. 오른쪽으로 걸어가다 처음 막히는 곳 바로 앞.
  • Vmin(F): 그 클럭을 쓰기 위한 최저 전압. 아래에서 위로 올라가며 처음 fmax ≥ F가 되는 줄. 전력은 V²에 비례하므로 Vmin을 낮추는 것이 곧 전력 절감입니다.
  • margin: 정격(nominal) 전압에서 target 클럭보다 얼마나 여유가 있는가. 이 여유가 공정 편차·온도·노화·전원 노이즈를 버텨 줍니다.

4.2 PVT 코너에서 Vmin이 어떻게 움직이나

같은 sweep을 공정 코너(SS/TT/FF 칩) × 온도(cold/room/hot)마다 반복하면 아래 같은 그림이 나옵니다. 출하용 Vmin은 가장 나쁜 코너 + guardband로 정합니다.

4.3 손으로 따라가기 (trace)

sweep, 800 mV 줄, repeats = 3 (fake 모델 fmax(800) = 2 × (800 − 500) = 600):

Frun 1run 2run 3passcell
200 … 500PPP3PASS *
600 (flaky)P (call 1)F (call 2, 짝수)P (call 3)2MARGINAL ?
700 … 1000FFF0FAIL .

repeats = 1이었다면 600은 call 1(P) 한 번만 보고 PASS가 됩니다(테스트 3번 앞부분). 한 번 통과는 증거가 아닙니다.

fmax 스캔 (테스트 7 격자):

줄왼쪽부터 셀멈춘 곳fmax
950* * . …fi = 2 (400, hole)300
900*×7 .fi = 7 (900)800
850*×6 .fi = 6 (800)700
800*×4 ?fi = 4 (600, marginal)500

Vmin(700): 700 → 400 ✗, 750 → 500 ✗, 800 → 500 ✗, 850 → 700 ✓ → 850 mV.

margin (테스트 숫자 그대로):

nominaltargetfmaxmargin_mhzmargin_pct10 = m × 1000 / target
900700800+100100000 / 700 = 142.8 → 142 (14.2 %)
950 (hole 있음)700300−400−400000 / 700 = −571.4 → −571
9001100800−300−300000 / 1100 = −272.7 → −272
925–––격자에 없음 → -EINVAL

hole 판정 (950, 400): 같은 줄에 왼쪽 300 PASS, 오른쪽 500 PASS → hole. 열 방향으로도 900/400 PASS, 1000/400 PASS. 반면 800/600 ?는 FAIL이 아니므로 hole 목록에 들어가지 않고, wall 바깥 .들은 왼쪽(낮은 F)과 위쪽(높은 V)에만 PASS가 있고 반대편에는 없으므로 hole이 아닙니다.

render 길이: 줄당 "%4u |" 6자 + 9자 + \n = 16자, 7줄 = 112. 단일 줄 격자(900 mV만)는 " 900 |*******..\n" = 16.

4.4 정답 코드

💡 정답 코드 펼치기 (30분 풀어 본 다음에)
solution.c
/*
 * V7  Shmoo Sweep + Margin Analysis (PVT characterization)
 *
 * A mock DUT exposes one call:  bool run_test(uint16_t v_mv, uint16_t f_mhz)  -> pass/fail.
 * It is implemented at the bottom of this file by a hidden model (do not edit the fake):
 * a voltage/frequency wall, an optional deterministic "hole" and an optional flaky point.
 *
 * Implement:
 *   shmoo_sweep   Sweep every (V, F) point of the grid, run the test `repeats` times per point
 *                 and store one cell per point in map[vi * nf + fi] (vi = 0 is v_lo, fi = 0 is f_lo):
 *                 CELL_PASS (all runs passed), CELL_FAIL (all failed), CELL_MARGINAL (mixed).
 *                 Bad grid (step 0, hi < lo, repeats 0) -> -EINVAL; cap < nv * nf -> -ENOSPC.
 *   shmoo_fmax    For voltage row vi: the highest F such that F and EVERY lower grid frequency are
 *                 CELL_PASS ("contiguous pass from the bottom"). 0 if f_lo itself does not pass.
 *   shmoo_vmin    The lowest grid voltage whose fmax >= target_mhz. 0 if no row reaches it.
 *   shmoo_margin  At nominal_mv (must be a grid voltage, else -EINVAL):
 *                 margin_mhz = fmax - target_mhz (may be negative),
 *                 margin_pct10 = margin_mhz * 1000 / target_mhz (percent x10, truncated toward 0).
 *   shmoo_holes   A HOLE is a CELL_FAIL point that has a CELL_PASS point on both sides of it
 *                 in its row (lower F and higher F, same V) OR in its column (lower V and higher V,
 *                 same F). Report holes in map order; write at most cap, return the total.
 *   shmoo_render  ASCII plot, highest voltage first, one line per row: "%4u |" + one char per F
 *                 ('*' pass, '.' fail, '?' marginal) + '\n'. snprintf rules: never write past cap,
 *                 NUL-terminate when cap > 0, return the full length needed (without the NUL).
 *   No malloc. Integer math only.
 *
 * Reference solution.  Build & run:  ./run.sh V7 sol
 */
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>
#include <errno.h>

static int g_fail;
#define CHECK(c) do { if (!(c)) { printf("FAIL line %d: %s\n", __LINE__, #c); g_fail++; } } while (0)

/* ---------------- DUT interface (provided) ---------------- */
bool run_test(uint16_t v_mv, uint16_t f_mhz);   /* one functional test at (V, F): true = pass */

enum { CELL_FAIL = 0, CELL_PASS = 1, CELL_MARGINAL = 2 };

typedef struct {
    uint16_t v_lo_mv, v_hi_mv, v_step_mv;     /* voltage axis (rows)    */
    uint16_t f_lo_mhz, f_hi_mhz, f_step_mhz;  /* frequency axis (cols)  */
    uint8_t  repeats;                         /* runs per point          */
} ShmooCfg;

typedef struct { uint16_t v_mv, f_mhz; } ShmooPt;

/* Provided helpers: number of rows / columns, 0 if the axis is invalid. */
static size_t shmoo_nv(const ShmooCfg *c)
{
    if (c->v_step_mv == 0 || c->v_hi_mv < c->v_lo_mv) return 0;
    return (size_t)(c->v_hi_mv - c->v_lo_mv) / c->v_step_mv + 1;
}
static size_t shmoo_nf(const ShmooCfg *c)
{
    if (c->f_step_mhz == 0 || c->f_hi_mhz < c->f_lo_mhz) return 0;
    return (size_t)(c->f_hi_mhz - c->f_lo_mhz) / c->f_step_mhz + 1;
}
static uint16_t row_mv(const ShmooCfg *c, size_t vi)  { return (uint16_t)(c->v_lo_mv + vi * c->v_step_mv); }
static uint16_t col_mhz(const ShmooCfg *c, size_t fi) { return (uint16_t)(c->f_lo_mhz + fi * c->f_step_mhz); }

/* ---------------- your code ---------------- */

int shmoo_sweep(const ShmooCfg *c, uint8_t *map, size_t cap)
{
    if (c == NULL || c->repeats == 0) return -EINVAL;
    size_t nv = shmoo_nv(c), nf = shmoo_nf(c);
    if (nv == 0 || nf == 0) return -EINVAL;
    if (map == NULL || cap < nv * nf) return -ENOSPC;

    for (size_t vi = 0; vi < nv; vi++) {
        for (size_t fi = 0; fi < nf; fi++) {
            unsigned pass = 0;
            for (unsigned r = 0; r < c->repeats; r++)
                pass += run_test(row_mv(c, vi), col_mhz(c, fi)) ? 1u : 0u;
            map[vi * nf + fi] = (pass == c->repeats) ? CELL_PASS
                              : (pass == 0)          ? CELL_FAIL : CELL_MARGINAL;
        }
    }
    return 0;
}

uint16_t shmoo_fmax(const ShmooCfg *c, const uint8_t *map, size_t vi)
{
    size_t nf = shmoo_nf(c);
    if (vi >= shmoo_nv(c)) return 0;
    uint16_t fmax = 0;
    for (size_t fi = 0; fi < nf; fi++) {
        if (map[vi * nf + fi] != CELL_PASS) break;   /* first non-pass ends the run */
        fmax = col_mhz(c, fi);
    }
    return fmax;
}

uint16_t shmoo_vmin(const ShmooCfg *c, const uint8_t *map, uint16_t target_mhz)
{
    size_t nv = shmoo_nv(c);
    for (size_t vi = 0; vi < nv; vi++) {               /* lowest voltage first */
        uint16_t fm = shmoo_fmax(c, map, vi);
        if (fm != 0 && fm >= target_mhz) return row_mv(c, vi);
    }
    return 0;
}

int shmoo_margin(const ShmooCfg *c, const uint8_t *map, uint16_t nominal_mv, uint16_t target_mhz,
                 int32_t *margin_mhz, int32_t *margin_pct10)
{
    size_t nv = shmoo_nv(c);
    if (nv == 0 || target_mhz == 0 || nominal_mv < c->v_lo_mv ||
        (nominal_mv - c->v_lo_mv) % c->v_step_mv != 0)
        return -EINVAL;
    size_t vi = (size_t)(nominal_mv - c->v_lo_mv) / c->v_step_mv;
    if (vi >= nv) return -EINVAL;

    int32_t m = (int32_t)shmoo_fmax(c, map, vi) - (int32_t)target_mhz;
    *margin_mhz = m;
    *margin_pct10 = m * 1000 / (int32_t)target_mhz;    /* C division truncates toward 0 */
    return 0;
}

size_t shmoo_holes(const ShmooCfg *c, const uint8_t *map, ShmooPt *out, size_t cap)
{
    size_t nv = shmoo_nv(c), nf = shmoo_nf(c), cnt = 0;
    for (size_t vi = 0; vi < nv; vi++) {
        for (size_t fi = 0; fi < nf; fi++) {
            if (map[vi * nf + fi] != CELL_FAIL) continue;
            bool lo_f = false, hi_f = false, lo_v = false, hi_v = false;
            for (size_t k = 0; k < fi; k++)      lo_f |= map[vi * nf + k] == CELL_PASS;
            for (size_t k = fi + 1; k < nf; k++) hi_f |= map[vi * nf + k] == CELL_PASS;
            for (size_t k = 0; k < vi; k++)      lo_v |= map[k * nf + fi] == CELL_PASS;
            for (size_t k = vi + 1; k < nv; k++) hi_v |= map[k * nf + fi] == CELL_PASS;
            if ((lo_f && hi_f) || (lo_v && hi_v)) {
                if (cnt < cap) out[cnt] = (ShmooPt){ row_mv(c, vi), col_mhz(c, fi) };
                cnt++;
            }
        }
    }
    return cnt;
}

int shmoo_render(const ShmooCfg *c, const uint8_t *map, char *buf, size_t cap)
{
    size_t nv = shmoo_nv(c), nf = shmoo_nf(c), pos = 0;
    static const char glyph[3] = { '.', '*', '?' };

    for (size_t r = 0; r < nv; r++) {
        size_t vi = nv - 1 - r;                         /* highest voltage on top */
        char head[8];
        int hn = snprintf(head, sizeof head, "%4u |", (unsigned)row_mv(c, vi));
        for (int k = 0; k < hn; k++, pos++)
            if (pos + 1 < cap) buf[pos] = head[k];
        for (size_t fi = 0; fi < nf; fi++, pos++) {
            uint8_t cell = map[vi * nf + fi];
            if (pos + 1 < cap) buf[pos] = cell <= CELL_MARGINAL ? glyph[cell] : '#';
        }
        if (pos + 1 < cap) buf[pos] = '\n';
        pos++;
    }
    if (cap > 0) buf[pos < cap ? pos : cap - 1] = '\0';
    return (int)pos;
}

/* ======================================================================
 * Test harness: fake DUT (do not edit)
 *   pass  <=>  f <= fmax(v) = (v - v0_mv) * mhz_per_10mv / 10
 *   hole  : (hole_v, hole_f) always fails (e.g. a supply resonance / PLL lock problem)
 *   flaky : (flaky_v, flaky_f) fails on every 2nd call to that point
 * ====================================================================== */
static struct {
    int32_t  v0_mv, mhz_per_10mv;
    uint16_t hole_v, hole_f;       /* 0 = no hole        */
    uint16_t flaky_v, flaky_f;     /* 0 = no flaky point */
    uint32_t flaky_calls;
    uint32_t calls;                /* total run_test() calls */
} F;

static void fake_reset(void)
{
    memset(&F, 0, sizeof F);
    F.v0_mv = 500; F.mhz_per_10mv = 20;            /* 2 MHz per mV above 500 mV */
}

bool run_test(uint16_t v_mv, uint16_t f_mhz)
{
    F.calls++;
    if (F.hole_v && v_mv == F.hole_v && f_mhz == F.hole_f) return false;
    if (F.flaky_v && v_mv == F.flaky_v && f_mhz == F.flaky_f && (++F.flaky_calls % 2) == 0)
        return false;
    int32_t fmax = ((int32_t)v_mv - F.v0_mv) * F.mhz_per_10mv / 10;
    return (int32_t)f_mhz <= fmax;
}

int main(void)
{
    static uint8_t map[64];
    static char txt[256];
    ShmooPt holes[4];
    int32_t mm = 0, mp = 0;
    const ShmooCfg g = { 700, 1000, 50,  200, 1000, 100,  1 };   /* 7 rows x 9 cols */

    /* 1. clean wall: fmax per row, Vmin, margin, plot */
    fake_reset();

    CHECK(F.calls == 63);
    CHECK(shmoo_fmax(&g, map, 0) == 400 && shmoo_fmax(&g, map, 4) == 800 && shmoo_fmax(&g, map, 6) == 1000);
    CHECK(shmoo_vmin(&g, map, 700) == 850);
    CHECK(shmoo_margin(&g, map, 900, 700, &mm, &mp) == 0 && mm == 100 && mp == 142);
    CHECK(shmoo_holes(&g, map, holes, 4) == 0);
    const char *clean =
        "1000 |*********\n"
        " 950 |********.\n"
        " 900 |*******..\n"
        " 850 |******...\n"
        " 800 |*****....\n"
        " 750 |****.....\n"
        " 700 |***......\n";
    CHECK(shmoo_render(&g, map, txt, sizeof txt) == 112 && strcmp(txt, clean) == 0);

    /* 2. hole at (950 mV, 400 MHz): reported, and fmax at 950 collapses to 300 */
    fake_reset(); F.hole_v = 950; F.hole_f = 400;
    CHECK(shmoo_sweep(&g, map, sizeof map) == 0);
    CHECK(shmoo_holes(&g, map, holes, 4) == 1 && holes[0].v_mv == 950 && holes[0].f_mhz == 400);
    CHECK(shmoo_fmax(&g, map, 5) == 300);
    CHECK(shmoo_margin(&g, map, 950, 700, &mm, &mp) == 0 && mm == -400 && mp == -571);
    CHECK(shmoo_vmin(&g, map, 700) == 850);                 /* other rows unaffected */

    /* 3. flaky point (800 mV, 600 MHz): R=1 misses it, R=3 marks it MARGINAL */
    fake_reset(); F.flaky_v = 800; F.flaky_f = 600;
    CHECK(shmoo_sweep(&g, map, sizeof map) == 0);

    CHECK(shmoo_holes(&g3, map, holes, 4) == 0);            /* marginal is not a hole */
    CHECK(shmoo_render(&g3, map, txt, sizeof txt) == 112 && strstr(txt, " 800 |****?....\n") != NULL);

    CHECK(shmoo_vmin(&g, map, 1100) == 0);
    CHECK(shmoo_margin(&g, map, 900, 1100, &mm, &mp) == 0 && mm == -300 && mp == -272);
    CHECK(shmoo_margin(&g, map, 925, 700, &mm, &mp) == -EINVAL);
    CHECK(shmoo_margin(&g, map, 1050, 700, &mm, &mp) == -EINVAL);
    ShmooCfg bad = g; bad.f_step_mhz = 0;
    CHECK(shmoo_sweep(&bad, map, sizeof map) == -EINVAL);
    bad = g; bad.repeats = 0;
    CHECK(shmoo_sweep(&bad, map, sizeof map) == -EINVAL);
    CHECK(shmoo_sweep(&g, map, 62) == -ENOSPC);

    fake_reset();

    CHECK(shmoo_render(&g1, map, txt, sizeof txt) == 16 && strcmp(txt, " 900 |*******..\n") == 0);

    fake_reset();
    CHECK(shmoo_sweep(&g, map, sizeof map) == 0);

    CHECK(shmoo_render(&g, map, small, sizeof small) == 112);
    CHECK(strcmp(small, "1000 |***") == 0);
    CHECK(shmoo_render(&g, map, NULL, 0) == 112);

    CHECK(shmoo_vmin(&g3, map, 700) == 850);
    CHECK(shmoo_margin(&g3, map, 900, 700, &mm, &mp) == 0 && mm == 100 && mp == 142);

코드 읽는 포인트

  • map[vi * nf + fi] 행 우선(row-major) 1차원 배열입니다. 2차원 VLA를 피하고, 호출자가 크기를 검증받은 버퍼 하나만 넘기면 됩니다. -ENOSPC 검사가 sweep 전에 있어서 DUT를 한 번도 건드리지 않습니다.
  • shmoo_vmin은 shmoo_fmax를 재사용합니다. "Vmin은 fmax 곡선의 역함수"라는 관계를 코드가 그대로 말해 줍니다.
  • margin_pct10은 정수 나눗셈입니다. C99부터 음수 나눗셈은 0 쪽으로 잘리므로 −571.4 → −571. 반올림을 원하면 면접관에게 먼저 물어봅니다.
  • shmoo_holes는 셀마다 줄·열을 다시 훑는 O(nv·nf·(nv+nf))입니다. 격자가 수천 점이면 충분합니다. 더 크면 줄마다 "첫 PASS / 마지막 PASS" 위치를 미리 구해 O(nv·nf)로 줄입니다.
  • shmoo_render는 snprintf와 같은 계약(필요 길이 반환)이라 호출자가 render(…, NULL, 0)로 크기를 먼저 알아낼 수 있습니다.

4.5 복잡도

  • sweep: run_test 호출 nv × nf × R회(예제 189회). 실제 시간은 점마다 전원 settle + 패턴 실행이라 이 숫자가 곧 테스트 비용입니다.
  • fmax/vmin: O(nv·nf). holes: O(nv·nf·(nv+nf)). render: O(nv·nf). 추가 메모리 O(1).

5. 임베디드 관점으로 말할 것

  • SK hynix에서 직접 한 일과 연결: "At SK hynix I built shmoo testing: sweep voltage against a timing parameter, repeat each point, and look for holes, not just the edge." 숫자 하나(margin)보다 그림의 모양이 디버그 정보라는 점을 강조합니다.
  • run_test 한 번에 실제로 일어나는 일: PMIC(I2C/PMBus)로 VDD 설정 → settle 대기(수 ms) 및 ADC로 실제 전압 readback → PLL 재설정 후 lock 확인 → 테스트 패턴(메모리 테스트, NPU 커널, CRC 체크) 실행 → 결과 판정. 설정값이 아니라 측정값을 기록해야 IR drop을 반영합니다.
  • 안전 순서: 전압은 올릴 때 "V 먼저, F 나중", 내릴 때 "F 먼저, V 나중"입니다. 낮은 V에서 높은 F를 걸면 타이밍 위반으로 hang이 날 수 있으므로, fail 후에는 watchdog/리셋으로 DUT를 복구하고 다음 점으로 갑니다.
  • flaky를 버리지 않는다: MARGINAL은 wall 근처 노이즈일 수도 있지만, wall 안쪽의 ?는 race condition, 전원 노이즈 민감 회로, 특정 데이터 패턴 의존 버그일 가능성이 큽니다. 위치·횟수·패턴을 로그로 남깁니다.

5.1 면접관(HW 출신 Sr Manager)이 파고들 포인트

  • "A full grid is too slow for production. What would you do?" — wall은 줄마다 단조(monotonic)라고 가정하고 이분 탐색(줄당 log₂ nf 회)이나, 이전 줄의 fmax에서 시작해 한두 칸만 보는 edge tracking을 씁니다. 단, 이렇게 하면 hole을 못 봅니다 → 특성 평가(char) 단계는 full grid, 양산(SLT)은 빠른 탐색으로 나눕니다. "Full grid for characterization to find holes, then a binary search on the wall per voltage for production, because the edge is monotonic once the design is clean."
  • "How do you know your test itself is correct?" — 알려진 모델(지금 fake처럼 wall·hole·flaky를 심은 DUT)에 돌려서 정확히 찾아내는지 먼저 검증합니다. 실리콘에서는 정격 조건 PASS 확인, 강제로 fail시키는 조건(아주 낮은 V) 확인, 같은 칩을 두 번 돌려 재현성 확인. "I validate the tool against a fake DUT with planted holes and flaky points before trusting it on silicon."
  • "FPGA vs first silicon?" — FPGA/HAPS에서는 전압·주파수를 바꿀 수 없어서 shmoo 자체는 의미가 없고, 도구의 흐름(제어, 로그, 리포트)만 미리 검증합니다. 실제 margin은 실리콘에서만 나옵니다. "On FPGA I can only validate the flow; the V/F physics only exists on silicon."
  • "How do results feed PVT and SLT?" — 코너 칩(SS/TT/FF) × 온도(thermal forcer로 −40/25/125 °C)마다 Vmin/fmax를 모아 최악 코너 + guardband로 출하 조건과 binning 기준을 정하고, SLT에는 그 기준 근처 몇 점만 넣습니다. "Characterization data across corners sets the guardband and the bins; SLT then checks only a few points near that edge."
  • "Why repeats? Isn't the chip deterministic?" — 디지털 로직도 wall 근처에서는 전원 노이즈·온도·데이터 패턴에 따라 결과가 흔들립니다. 1번 PASS로는 확신할 수 없고, R번 중 1번이라도 실패하면 그 점은 쓸 수 없습니다. "Near the edge, a single pass proves nothing; any failure out of R runs makes the point unusable."

6. Follow-up 질문과 답

Follow-up (English)답
What does PVT stand for, and what are the corners?Process · Voltage · Temperature. 공정 코너는 NMOS/PMOS 속도 조합: SS(둘 다 느림), FF(둘 다 빠름), TT(typical), SF/FS(한쪽만 빠름 — 레벨 시프터·SRAM 읽기/쓰기 마진에 특히 중요). 전압은 nominal ±5–10 %, 온도는 −40 °C ~ 125 °C(차량용 AEC-Q100 Grade 1).
Isn't hot always the worst case?아닙니다. temperature inversion: 온도가 오르면 캐리어 이동도는 떨어지지만(느려짐) 문턱 전압 Vth도 떨어집니다(빨라짐). 공급 전압이 Vth에 가까운 저전압·첨단 공정(FinFET, 7/5 nm)에서는 Vth 효과가 이겨서 cold가 더 느립니다. 그래서 저전압 Vmin은 cold에서, 누설·발열 관련 문제는 hot에서 봅니다. 두 쪽 다 돌려야 합니다.
What is Vmin/Fmax binning?같은 웨이퍼에서도 칩마다 속도가 다릅니다. 측정한 fmax(또는 target F에서의 Vmin)로 칩을 등급(bin)으로 나눠 빠른 칩은 높은 클럭 SKU로, 느린 칩은 낮은 클럭 SKU나 높은 전압(AVS 테이블)으로 출하합니다. 칩별 Vmin을 eFuse에 기록해 런타임 AVS(adaptive voltage scaling)에 쓰기도 합니다.
The full grid takes too long. How do you cut test time?① 줄마다 wall을 이분 탐색(nf=9면 9회 → 4회), ② 이전 전압의 fmax 근처부터 탐색(edge tracking), ③ repeats는 wall 근처 점만 늘림, ④ 양산은 pass/fail 한두 점(target F @ ship Vmin, guardband 점)만. 대가는 hole을 못 본다는 것 — char 단계에서만 full grid.
How do you pick the guardband?측정 최악 코너 Vmin 위에 노화(aging, NBTI/HCI로 수년간 Vth 상승 → 수십 mV), 전원 레귤레이터 오차·리플, 측정 장비 오차, 테스트 패턴이 실제 워크로드보다 덜 가혹할 가능성을 더합니다. 너무 크면 전력 낭비, 너무 작으면 필드 불량.
SLT vs ATE?ATE(automatic test equipment)는 스캔/BIST 패턴으로 구조적 결함을 빠르게 봅니다(stuck-at, at-speed transition). SLT(system level test)는 칩을 실제 보드에 올려 OS·드라이버·실제 워크로드(NPU 추론, DDR 트래픽)를 돌립니다. ATE가 놓치는 전원 노이즈·워크로드 의존 결함을 잡지만 느립니다.
What about aging?시간이 지나면 Vth가 올라가 fmax가 떨어집니다. HTOL(고온 가속 수명 시험) 전후로 shmoo를 다시 찍어 wall 이동량을 측정하고 guardband에 반영합니다. 차량용은 15년 수명 요구라 특히 중요합니다.
How would you automate this as a SW engineer?Python 호스트 스크립트가 랩 장비를 제어: 전원 공급기(SCPI over LAN/USB, 예: VOLT 0.85), thermal forcer(ThermoStream 온도 설정 후 soak 대기), DUT는 UART/JTAG로 테스트 펌웨어 실행. 칩 안에서는 bare-metal C가 PMIC 레지스터(I2C/PMBus)와 PLL/클럭 디바이더 레지스터로 V/F를 바꿉니다. 결과는 CSV/DB에 (칩 ID, 코너, 온도, V, F, pass 수) 형태로 쌓아 자동 리포트.
Can the wall ever go the wrong way (higher V fails)?정상은 아니지만 실제로 나옵니다: 높은 V에서 hold-time 위반(데이터가 너무 빨리 도착), 발열로 인한 thermal throttling, 전원 레일 간 순서 문제. 그래서 column 방향 hole도 검사합니다.

7. 자주 하는 실수

  • fmax를 "그 줄에서 가장 높은 PASS"로 계산 → hole을 뛰어넘어 950 mV 줄이 900 MHz로 나옴 (테스트 2번)
  • MARGINAL을 PASS로 취급 → 800 mV fmax가 600이 됨 (테스트 3번). 반대로 MARGINAL을 hole로 보고함
  • 첫 실패에서 repeat를 멈춤 → 호출 횟수 189가 틀어지고 "몇 번 중 몇 번" 정보 손실
  • map[fi * nv + vi] 처럼 인덱스 순서를 섞음 → 단일 줄 격자(테스트 5번)나 render에서 바로 드러남
  • render를 아래 줄(낮은 V)부터 출력 → shmoo 관례(위로 갈수록 높은 V)와 반대
  • margin_pct10을 (m / target) * 1000으로 계산 → 정수 나눗셈이 먼저 0이 됨
  • nominal 전압이 격자에 없는데 가장 가까운 줄을 조용히 고름 → 잘못된 margin 보고. -EINVAL로 알리는 것이 맞음
  • 버퍼 크기 검사를 sweep 뒤에 함 → DUT를 다 돌린 뒤 실패, 또는 오버런
