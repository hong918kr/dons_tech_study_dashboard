평가 요약  
현재 100문항은 “언어 레벨(C), 비트·버퍼·직렬화·무결성·경량 자료구조”에 강하게 치우쳐 있고, 실제 임베디드/FW 인터뷰에서 자주 묻는 아래 축은 부분적이거나 거의 미포함:

- RTOS 커널 객체 (task/thread, priority, scheduling policy, tick vs tickless, priority inversion)
- 동기화/경합 (mutex, binary/semaphore, counting semaphore, event group, barrier, condition‑style wait)
- 실시간 특성 (WCET 추정, 응답 지터 분석, deadline miss 처리)
- Interrupt/DMA 연계 (ISR ↔ DPC/Deferred work, DMA 링, 캐시 일관성)
- Device Driver 패턴 (init/probe, open/close, power states, 에러 복구, re‑enumeration)
- Power & Low‑Power (sleep states, clock gating, wake source, retention)
- Memory/Linker (세그먼트 배치, linker script, MPU/MMU region planning)
- 부트/업데이트 (secure boot chain, watchdog + fallback, A/B image)
- 안전/품질 (MISRA, defensive checks, fault containment, watchdog servicing)
- 테스트/검증 (fault injection, hardware abstraction mock, deterministic replay)
- 통신 스택 상위 계층 (retransmission windows, sliding window ACK, congestion/flow control)
- 진단/트레이싱 (lightweight trace buffers, timestamp correlation)

아래는 “추가로 연습하면 커버리지가 크게 넓어지는” 추천 문제군입니다. (각 15–30m 수준 구현/설계/시그니처 초안 목표)

A. RTOS & 스케줄링  
1. 고정 우선순위 프리엠프 스케줄러 미니 모형  
   - 요구사항: ready bitmap, highest-priority pick O(1), time slice, priority inheritance(옵션)  
2. Priority Inversion 시나리오 & 해결 (mutex PI vs 융통성 없는 설계 비교)  
3. Tickless idle 계산기  
   - 다음 이벤트까지 sleep 기간 산출, 오버슬립 보정  
4. Deadline 모니터  
   - 태스크별 (release, deadline, completion) 기록, miss 통계  

B. 동기화 & 동시성  
5. Counting semaphore (ISR give / task take, timeouts)  
6. Event group (비트 셋 & wait any/all)  
7. Lock-free MPSC 큐 (cache line padding + ABA 방지 간단 전략)  
8. 재귀 mutex vs 비재귀 mutex 구현 차이 & 데드락 예시/검출 훅  
9. Readers–writers lock (writer 우선 정책)  

C. Interrupt / DMA / Deferred Work  
10. DMA descriptor 링 관리  
    - 요구사항: OWN 플래그, wrap, partial completion 콜백  
11. ISR → DPC(Deferred Procedure) 큐 (우선순위 기반)  
12. 캐시 일관성 API 설계 (invalidate / clean / region alignment 검사)  
13. GPIO edge interrupt debounce (하드웨어 + 소프트 조합)  
14. 타이머 캡처/펄스 폭 측정 모듈 (overflow stitching)  

D. Device Driver & HAL 확장  
15. SPI DMA 기반 블록 전송 드라이버 (sync/async + callback)  
16. I2C 오류 복구 (bus hang, clock pulse recovery)  
17. Power state machine (RUN/IDLE/SLEEP/DEEP) + 진입/이탈 훅  
18. Driver probe()/remove() 프레임 (리소스 할당 실패 롤백)  
19. Watchdog pet scheduling + window violation 검출  

E. 메모리 / 부트 / 이미지 관리  
20. Linker script 설계 연습: .text/.data/.bss/.noinit/.fast (SRAM bank 배치 가정)  
21. MPU region planner (겹침 검증, 접근 플래그)  
22. A/B firmware slot + rollback flag 관리  
23. Secure boot hash + manifest 검증(요구사항: SHA256 stub, version anti-rollback)  
24. Heap fragmentation inspection 유틸 (연속 free 블록 통계)  

F. 실시간 & 성능 계측  
25. WCET 추정 보조 도구 (루프 상한, 분기 메타정보 입력 받아 conservative 계산)  
26. 주기 태스크 jitter logger (min/max/avg & 히스토그램)  
27. 경량 Trace Ring: (timestamp + event id) 드롭 카운터 포함  
28. 주기적 드리프트 누적 테스트 하네스 (실제 tick vs ideal 비교)  

G. 통신 상위 계층  
29. Sliding window ARQ (send base, next seq, ack handling, retransmission timer)  
30. Congestion window 축소/증가(간단 AIMD) 시뮬레이터  
31. Fragmented reassembly + reorder window + selective ACK bitmap  
32. 초경량 Pub/Sub (topic hash, retain last payload, QoS 0/1 단순화)  

H. 신뢰성 / 안전  
33. Watchdog mis-pet scenario 재현 & 보호(임계 섹션 중 pet 방지)  
34. Fault injection harness (메모리 오류/timeout 주입 인터페이스)  
35. Safe update transaction (double-write + CRC + commit marker)  
36. Brown-out detection 핸들러 시퀀스 (임시 버퍼 flush 전략)  

I. 품질/규칙/테스트  
37. MISRA-like rule checker 미니 (금지 함수/패턴 스캔)  
38. Deterministic pseudo-rand test harness (seed + reproducible sequence)  
39. Interface contract tests (assert pre/post 조건 매크로 + disable 옵션)  
40. Fuzz harness for binary frame parser (mutation budget, timeout abort)  

J. Callback / FSM / 구성  
41. Hierarchical FSM (상위 상태 공통 처리 + 전이 guard)  
42. Callback registry with priority & reentrancy block (중첩 호출 방지 토큰)  
43. Configuration hot-reload diff 적용기 (변경 필드만 반영 + rollback)  
44. State persistence delta encoding (변경 필드 bitmap + 압축)  

K. 저전력 & 에너지  
45. Sleep budgeting (다음 deadline/latency constraints 고려한 최장 sleep 계산)  
46. Peripheral clock gating 관리자 (refcount + 자동 ungate timeout)  
47. Sensor duty-cycling 스케줄러 (활성/휴면 패턴, 누적 on-time 통계)  

L. 수치/제어 확장  
48. Fixed-point biquad IIR (계수 스케일링 + saturation)  
49. PID autotune (Ziegler-Nichols 간이 루틴, 안전 클램프)  
50. Sensor calibration storage (다항 근사 계수 + CRC + aging counter)

활용 전략  
- 기존 100문항: 언어/버퍼/직렬화/경량 자료구조 → “기초 구현력 + 메모리 안전 사고방식” 평가에 적합.  
- 추가 리스트: “운영(실행 환경)/동시성/RTOS/실시간/드라이버/신뢰성” 영역 보강.  
- 면접 대비 로드맵 (순차 추천)  
  1) 기존 100 중 비트·직렬화·동시성 관련 20~30개 선택 구현  
  2) 위 A~C 블록(스케줄러, semaphore, ISR/DMA) 집중 → RTOS 개념 설명 준비  
  3) 부트/이미지/안전(Wear-leveling, rollback, secure boot stub)  
  4) Sliding window ARQ + Fragment Reassembly → 프로토콜 설계 사고  
  5) Trace/Jitter/WCET → 실시간성 설명 자료화  
  6) Power & Watchdog & Fault Injection → 시스템 안정성 시나리오 정리  

답변 요약  
- 현재 세트는 “언어/저수준 데이터 처리” 편향.  
- RTOS, 동기화 고급, DMA, 드라이버 수명주기, 파워/부트, 실시간 분석 영역이 미흡.  
- 위 50개 추가 유형으로 전체 포트폴리오를 실무 면접 범위로 확장 가능.  

필요 시 위 리스트 중 원하는 블록을 지정하면 해당 세트에 맞는 헤더/시그니처 템플릿을 더 제공 가능.
