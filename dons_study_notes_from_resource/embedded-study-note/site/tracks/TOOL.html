Stage 1 · TOOL · Toolchain, Build & Debugging

툴체인 · 빌드 · 디버깅

아이템 39Basic 14Mid 14Advanced 11학습가능 0

펌웨어 엔지니어의 생산성은 툴체인을 얼마나 깊이 아느냐로 갈린다: 링크 에러 해석, 링커 스크립트와 맵 파일, 코드 크기 다이어트, 디버거·sanitizer·코어 덤프로 버그를 좁히는 능력. 이 트랙은 컴파일 단계부터 JTAG/SWD까지 각 도구를 실제 문제 상황에 적용해 본다.

트랙 목표

  • 전처리·컴파일·어셈블·링크 각 단계의 산출물을 직접 만들고 해석한다
  • 링커 스크립트·맵 파일·섹션 배치를 이해해 메모리 예산을 관리한다
  • Make/CMake로 호스트 테스트와 크로스 빌드를 같은 트리에서 운용한다
  • lldb/gdb·ASan/UBSan/TSan·코어 덤프로 버그를 체계적으로 좁힌다
  • 코드 크기·스택 사용량·빌드 재현성을 측정하고 최적화한다
  • JTAG/SWD·OpenOCD·GDB 원격 디버깅의 동작 원리를 모델과 QEMU로 익힌다
