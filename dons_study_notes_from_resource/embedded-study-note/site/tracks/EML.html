디바이스 ML 추론

아이템 30Basic 10Mid 12Advanced 8학습가능 0

디바이스 ML 추론은 학습된 모델을 MCU·SoC·NPU 위에서 제한된 메모리와 전력으로 정확하고 빠르게 돌리는 기술이다. 텐서 레이아웃, conv/GEMM 커널, int8 양자화, 메모리 플래닝, 연산자 퓨전을 직접 구현해 봐야 TFLite Micro·ONNX Runtime·llama.cpp 같은 런타임과 NPU 컴파일러가 왜 그렇게 설계됐는지 설명할 수 있다. AI 가속기·엣지 AI 펌웨어 면접에서는 'int8 conv를 C로 구현하고 레퍼런스와 bit-exact로 맞춰라' 같은 문제가 실제로 나온다.

트랙 목표

  • 텐서 shape/stride/레이아웃(NCHW/NHWC)을 다루고 conv·GEMM·pooling·activation 연산자를 C로 구현할 수 있다
  • int8 affine 양자화(per-tensor/per-channel), 정수 전용 requantization, 캘리브레이션을 구현하고 레퍼런스와 bit-exact로 맞출 수 있다
  • 그래프 인터프리터, 텐서 수명 기반 메모리 아레나 플래닝, 연산자 퓨전을 직접 만들 수 있다
  • TFLite Micro, ONNX Runtime, llama.cpp의 구조와 모델 변환 파이프라인을 이해하고 활용할 수 있다
  • 키워드 스포팅·소형 CNN·소형 트랜스포머를 end-to-end로 C에서 구동하고 정확도·지연·메모리를 벤치마크할 수 있다
