AI 가속기 (NPU)

아이템 33Basic 9Mid 12Advanced 12학습가능 0

NPU(AI 가속기)는 MAC 어레이·on-chip SRAM·DMA·명령 프로세서·펌웨어·컴파일러가 하나로 설계된 칩이며, 성능의 대부분은 '데이터를 얼마나 적게, 제때 옮기느냐'에서 결정된다. 이 트랙은 systolic array 사이클 시뮬레이터를 C로 직접 만들고, 그 위에 dataflow·타일링·DMA 더블 버퍼링·toy ISA·커맨드 큐 펌웨어·호스트 드라이버·그래프 컴파일러·golden model 검증까지 쌓아 올려 하나의 '나만의 NPU' 스택을 완성한다. Don의 SSD 펌웨어(큐·DMA·커맨드 처리)와 실리콘 검증 경험을 AI 가속기 펌웨어/아키텍처/검증 직무로 연결하는 핵심 트랙이다.

트랙 목표

  • MAC 어레이와 systolic array(weight/output/row stationary dataflow)의 동작을 사이클 단위로 시뮬레이션하고 설명할 수 있다
  • on-chip SRAM 타일링, DMA 디스크립터, 더블 버퍼링으로 DRAM 트래픽과 stall을 최소화하는 스케줄을 설계할 수 있다
  • toy NPU ISA·커맨드 큐·펌웨어·호스트 드라이버 인터페이스를 설계·구현할 수 있다
  • 그래프 lowering, 타일링, 스케줄링, 메모리 할당을 수행하는 미니 NPU 컴파일러를 만들 수 있다
  • int8/fp8/bf16/MX 데이터패스와 희소성의 수치·성능 특성을 구현 수준에서 다룰 수 있다
  • golden model 대비 bit-exact 검증, 성능 카운터, 검증 계획 등 NPU bring-up/validation 업무를 수행할 수 있다

NPU-A08AdvancedNPU 검증 계획: 다층 Golden 비교와 커버리지
연산자·레이어·네트워크·시스템(펌웨어, 드라이버, 전력 전환) 수준 검증 계획을 작성하고, 제약 무작위 연산자 파라미터 생성기 + golden 비교 + 기능 커버리지(shape 경계, 포화, 0 스케일 등 빈) 수집기를 구현해 시뮬레이터에서 커버리지 100%까지 회귀를 돌리고 발견된 버그를 기록한다.		준비중mac
NPU-A09AdvancedSystolic Array RTL과 Verilator 공동 시뮬레이션
4×4 int8 weight-stationary systolic array를 Verilog/SystemVerilog로 작성하고 Verilator C++ 테스트벤치에서 B03 C 모델과 같은 무작위 GEMM을 구동해 출력·사이클 수를 비교하며, 파형(VCD)으로 스큐·유효 신호 타이밍을 확인한다.		외부환경필요fpga
NPU-A10Advanced실제 NPU 툴체인: Arm Ethos-U Vela 컴파일러
int8 TFLite 모델(MobileNetV2, KWS)을 Vela로 Ethos-U55/U65 구성별로 컴파일해 NPU/CPU 연산자 분할, SRAM/Flash 사용량, 예상 사이클 리포트를 수집하고, 자체 M08/M09 컴파일러와 A03 해석 모델의 예측을 비교해 차이 원인을 분석한다.		준비중mac
NPU-A11AdvancedApple Neural Engine 실측: Core ML Compute Units
coremltools로 CNN과 소형 트랜스포머를 Core ML로 변환해 computeUnits를 CPU_ONLY/CPU_AND_GPU/CPU_AND_NE/ALL로 바꿔 지연·전력(powermetrics ANE)을 측정하고, Xcode Core ML 성능 리포트로 ANE에서 fallback된 연산자를 찾아 모델 수정(레이아웃, 연산자 대체)으로 ANE 실행 비율을 높인다.		준비중mac
NPU-A12Advanced종합: 나만의 NPU 스택 End-to-End
EML-M09의 int8 CNN을 M08/M09 컴파일러로 toy ISA로 컴파일하고, M06 드라이버 → M05 펌웨어 → B03/M03 사이클 시뮬레이터에서 실행해 golden과 bit-exact 일치, 총 사이클·DRAM 바이트·추정 에너지·PMU 타임라인을 출력하는 데모와 아키텍처 문서(면접 포트폴리오용)를 완성한다.		준비중mac
