Stage 8 · AUTON · Autonomous Systems

자율 시스템

아이템 27Basic 9Mid 10Advanced 8학습가능 0

자율 시스템은 인지(perception) → 위치추정(localization) → 계획(planning) → 제어로 이어지는 스택과, 그 위를 감시하는 안전 모니터·시뮬레이션 검증으로 이루어진다. 저수준 제어(RCTL)와 미들웨어(ROS)는 다른 트랙에서 다루고, 여기서는 Scout AI·Anduril·Shield AI·Zoox 면접에서 자주 나오는 로컬라이제이션, 맵핑, 경로 계획, 행동 결정, 충돌 예측, 안전 아키텍처를 직접 구현한다.

트랙 목표

  • 자율 스택의 모듈 경계, 주기, 지연 예산을 설계하고 좌표 변환을 정확히 다룰 수 있다
  • 오도메트리·EKF·파티클 필터·ICP로 위치를 추정하고 occupancy grid와 SLAM 개념을 구현할 수 있다
  • A*/Hybrid A*/RRT*/DWA/Frenet 계획기를 구현하고 비교할 수 있다
  • Behavior Tree·HSM으로 미션 로직을 짜고, 다중 객체 추적과 센서 퓨전·시간 동기를 처리할 수 있다
  • 안전 모니터, 런타임 검증, 성능 저하 모드, 시뮬레이션 기반 시나리오 테스트를 설계할 수 있다

B05 occupancy grid 위에 정적 지도·로봇 반경 인플레이션(지수 감쇠 비용)·실시간 장애물 레이어를 합성하는 코스트맵을 구현하고, ALGO-A01 A*가 레이어 변경에 따라 경로를 바꾸는지 테스트한다(A* 자체는 see:ALGO-A01).		준비중mac

AUTON-B08Basic계층적 상태 머신(HSM) 미션 관리
Idle/Mission(Navigate, Inspect)/Recovery/Emergency를 가진 HSM(진입/퇴장 액션, 상위 상태 이벤트 위임)을 구현해 B07 BT와 같은 미션을 재작성하고, 기능 추가 시 변경량·가독성 트레이드오프를 정리한다.		준비중mac

AUTON-M01MidEKF 로컬라이제이션: 오도메트리 + 랜드마크
차동 구동 운동 모델과 알려진 랜드마크 range-bearing 측정 모델로 EKF를 구현하고, 야코비안 수치 검증, 각도 정규화 처리, NEES 일관성 검사로 필터가 과신하지 않는지 확인한다.		준비중mac
AUTON-M02Mid파티클 필터 로컬라이제이션 (MCL)
occupancy grid 위에서 likelihood field 측정 모델과 low-variance 리샘플링을 쓰는 MCL을 구현하고, 전역 위치추정(kidnapped robot 포함)에서 파티클 수에 따른 수렴 성공률과 계산 시간을 측정한다.		준비중mac
AUTON-M03Mid스캔 매칭: 2D ICP
KD-tree 최근접 대응, 이상치 거부, SVD 기반 rigid 정합을 반복하는 point-to-point ICP를 구현하고, 초기 자세 오차 크기별 수렴 영역과 point-to-line 변형의 수렴 속도 차이를 실험한다.		준비중mac
AUTON-M04Mid다중 객체 추적: 데이터 연관 + 트랙 관리
B04 클러스터 중심을 입력으로 등속 칼만 트랙, Mahalanobis 게이팅, 헝가리안 알고리즘 연관, M-of-N 트랙 확정/삭제를 구현하고, 교차 이동 시나리오에서 ID switch 수와 MOTA를 측정한다.		준비중mac
AUTON-M05Mid라이다-카메라 융합: 투영과 연관
핀홀 + 왜곡 모델로 라이다 점을 카메라 영상에 투영하는 함수를 구현하고, 2D 바운딩 박스 안에 들어온 3D 점으로 객체 거리를 추정하는 late fusion을 작성해 외부 파라미터 오차가 연관 정확도에 주는 영향을 측정한다.		준비중mac
AUTON-M06MidHybrid A*: 차량 운동학 제약 계획
(x, y, θ) 이산 셀에 연속 상태를 저장하는 Hybrid A*와 최소 회전반경 기반 전·후진 동작, 목표 근처 Dubins 해석 확장을 구현하고, 주차 시나리오에서 그리드 A* 대비 실행 가능 경로를 보여준다.		준비중mac
AUTON-M07MidRRT / RRT* 샘플링 기반 계획
2D 다각형 장애물 환경에서 RRT와 RRT*(near 반경, rewire)를 구현하고, 반복 수에 따른 경로 비용 수렴과 실행 시간을 비교하며 goal bias·충돌 체크 해상도 영향을 실험한다.		준비중mac
AUTON-M08Mid로컬 플래너: Dynamic Window Approach
(v, ω) 동적 윈도우 샘플링, 궤적 전방 시뮬레이션, 목표 방향·장애물 거리·속도 비용 가중합으로 명령을 고르는 DWA를 구현하고, 전역 A* 경로를 따라가며 갑자기 나타난 장애물을 회피하는 시나리오로 검증한다.		준비중mac
AUTON-M09Mid동적 장애물 예측과 충돌 시간(TTC)
등속·등각속도(원운동) 예측 모델을 구현하고, 두 원형 물체의 상대 운동에서 최초 충돌 시각을 해석적(2차 방정식)·수치적(근 찾기)으로 구하는 함수를 작성해 엣지 케이스(평행, 접선, 이미 겹침) 테스트를 통과시킨다.		준비중mac
AUTON-M10Mid안전 모니터: Doer/Checker 아키텍처
계획기 출력을 받아 속도/가속 한계, 지오펜스, 최소 장애물 거리(TTC 기반), 입력 하트비트·데이터 신선도를 검사해 통과/제한/비상정지 명령으로 바꾸는 safety monitor를 구현하고, 버그 있는 플래너를 주입해 차단되는지 검증한다.		준비중mac

AUTON-A01Advanced포즈 그래프 SLAM: Gauss-Newton 최적화
2D 포즈 그래프(노드=자세, 엣지=상대 자세 + 정보 행렬) 최적화기를 Gauss-Newton + 희소 선형 풀이(Eigen)로 구현하고, 루프 클로저 추가 전후 궤적 오차와 잘못된 루프 클로저에 대한 robust kernel(Huber) 효과를 보인다.		준비중mac
AUTON-A02AdvancedOOSM 처리: 지연 측정 버퍼-리플레이 융합
상태·공분산 히스토리 버퍼를 둔 EKF에서 지연된 측정이 오면 해당 시점으로 되돌아가 갱신 후 재전파하는 buffer-and-replay를 구현하고, 단순 무시/즉시 적용 방식과 추정 오차·계산량을 비교한다.		준비중mac
AUTON-A03AdvancedFrenet 좌표계 궤적 계획
기준선의 Frenet 변환을 구현하고 횡방향 5차·종방향 4차 다항식 궤적 집합을 생성해 저크·편차·속도 비용과 곡률·가속 제약, M09 충돌 검사로 최적 궤적을 고르는 계획기를 작성한다.		준비중mac
AUTON-A04Advanced런타임 검증: 시간 논리 모니터
bounded-response, always/eventually-within 연산자를 지원하는 스트리밍 모니터를 작성해 시뮬레이션 로그 위에서 위반 시점과 robustness 값을 출력하고, M10 safety monitor 규칙과 런타임 검증 규칙의 역할 차이를 정리한다.		준비중mac
AUTON-A05Advanced시뮬레이션 시나리오 테스트 하네스
헤드리스 2D 시뮬레이터(로봇 + 동적 장애물)에 플래너·안전 모니터를 연결하고, 시나리오 파라미터(속도, 진입 각, 센서 노이즈)를 스윕/무작위 생성해 충돌·최소거리·목표 도달 지표를 집계하고 실패 시나리오를 재현 가능한 시드로 저장하는 하네스를 작성한다.		준비중mac
AUTON-A06Advanced성능 저하 모드와 최소 위험 상태(MRC)
센서별 health(신선도·일관성)와 ODD 조건을 입력으로 능력 레벨(Full/Reduced speed/Stop-in-lane/Pull-over)을 결정하는 degradation manager를 구현하고, 고장 조합 테이블 기반 테스트로 항상 안전한 방향으로만 전이하는지 검증한다.		준비중mac
AUTON-A07Advanced엣지 퍼셉션 파이프라인 실시간성 설계
카메라 프레임 → 전처리 → (가짜) 추론 → 추적 파이프라인을 bounded 큐 + drop-oldest 정책으로 구현하고, 추론 시간이 변동할 때 지연 백분위(p50/p99)와 처리량을 측정해 큐 깊이·드롭 정책·스레드 우선순위 선택 근거를 정리한다.		준비중mac
AUTON-A08Advanced다중 로봇 협조: 작업 할당과 충돌 회피
N대 로봇과 M개 목표에 대해 sequential single-item auction 작업 할당을 구현하고, 시공간 예약 테이블을 쓰는 우선순위 기반 다중 경로 계획(cooperative A*)으로 충돌 없이 실행됨을 시뮬레이션으로 검증하며, 통신 두절 시 처리 방식을 논의한다.		준비중mac
