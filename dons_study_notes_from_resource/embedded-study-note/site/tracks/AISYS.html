NVIDIA·Meta·Google·Tenstorrent 같은 AI 인프라 조직의 시스템/펌웨어 엔지니어는 '70B 모델 학습에 GPU 메모리가 얼마나 필요한가?', '이 서빙 SLO에 GPU가 몇 대 필요한가?'에 봉투 뒷면 계산으로 답할 수 있어야 한다. 이 트랙은 학습 메모리·컴퓨트 수학, 데이터/텐서/파이프라인/시퀀스/전문가 병렬화와 ZeRO/FSDP, 혼합 정밀도, 체크포인트·고장 대응, 그리고 PagedAttention·prefix 캐시·speculative decoding·disaggregated 서빙까지를 맥에서 도는 Python/C 시뮬레이터와 미니 구현으로 직접 만들어 본다. 가속기 하드웨어(NPU/GPGPU)와 지표(AIPERF), 네트워크 collective(DCN) 위에 올라가는 '시스템 소프트웨어 층'이다.

트랙 목표

  • 학습 FLOP(6ND)·메모리(파라미터/그래디언트/옵티마이저/활성화)를 계산하고 실측으로 검증할 수 있다
  • DP/TP/PP/SP/CP/EP와 ZeRO/FSDP의 메모리·통신량·버블을 정량화하고 3D 병렬 구성을 고를 수 있다
  • 혼합 정밀도(fp16 loss scaling, bf16, fp8 스케일링)와 activation checkpointing의 트레이드오프를 구현으로 설명할 수 있다
  • PagedAttention 블록 테이블, prefix 캐시, iteration-level 스케줄러, speculative decoding을 미니 서빙 엔진으로 구현할 수 있다
  • TTFT/TPOT SLO·goodput 기반으로 서빙 용량과 disaggregation, 스케줄링 정책을 설계할 수 있다
  • 대규모 학습의 고장률·체크포인트 간격·straggler/SDC 탐지를 모델링하고 학습 런 계획을 세울 수 있다

prefill 풀과 decode 풀, 그 사이 KV 전송(토큰당 KV 바이트 × 입력 길이 ÷ 링크 대역폭, see:GPUSYS-A01·see:DCN)을 모델링하는 시뮬레이터를 작성해 colocated+chunked prefill 대비 SLO 하 GPU당 goodput을 비교하고, 입력/출력 길이 분포별 최적 P:D GPU 비율과 KV 전송이 병목이 되는 링크 대역폭 임계값을 구한다.		준비중mac
AISYS-A04AdvancedExpert Parallel: 부하 불균형과 Expert 배치·복제
M13에서 측정한(또는 Zipf로 생성한) expert 부하 분포로 EP 랭크별 토큰 수·all-to-all 바이트·GEMM 시간을 계산해 가장 느린 랭크가 step time을 결정함을 보이고, 핫 expert 복제와 그리디 재배치(EPLB 방식) 알고리즘을 구현해 최대/평균 부하비와 step time 개선을 측정한다.		준비중mac
AISYS-A05AdvancedContext Parallel: Ring Attention 시뮬레이션
numpy로 N개 가상 디바이스가 Q 조각을 고정하고 K/V 조각을 링으로 전달하며 online softmax(logsumexp 병합)로 부분 결과를 합치는 ring attention을 구현해 전체 attention과 일치를 검증하고, causal mask에서의 부하 불균형(zig-zag 분할로 해결)과 블록 연산 시간 ≥ KV 전송 시간이 되는 최소 시퀀스 길이를 계산한다.		준비중mac
AISYS-A06Advanced3D 병렬 구성 탐색기: DP×TP×PP×CP 스텝 시간 모델
B03·B04·M02·M05·M07·M01 모델을 결합해 (dp, tp, pp, cp, 마이크로배치, ZeRO 단계, 재계산 여부) 조합마다 디바이스당 메모리, 계산 시간(MFU 가정), TP는 노드 내/DP·PP는 노드 간 링크 α-β 통신 시간, 파이프라인 버블을 합산하는 탐색기를 작성하고, 70B 모델·1024 GPU에서 최적 구성을 Megatron/Llama 3 공개 구성과 비교한다.		준비중mac
AISYS-A07Advanced학습 클러스터 신뢰성: 실패율과 최적 체크포인트 간격
GPU당 고장률과 GPU 수로 클러스터 MTBF를 계산해(신뢰성 기초는 see:TEST-B10) Llama 3 보고(16K GPU, 54일 419회 중단)와 대조하고, 체크포인트 저장 시간 δ·재시작 시간 R로 Young/Daly 최적 간격 √(2δ·MTBF)를 구한 뒤 몬테카를로 시뮬레이터로 간격별 유효 학습 시간 비율(goodput)을 측정해 공식과 비교한다.		준비중mac
AISYS-A08Advanced분산 체크포인트: 비동기 저장과 Resharding 복원
M03 미니 FSDP에 랭크별 샤드 + 메타데이터(전역 shape, 오프셋) 저장, GPU→CPU 스냅샷 후 백그라운드 스레드로 디스크에 쓰는 비동기 저장, N랭크 체크포인트를 M랭크로 resharding하는 로더를 구현하고, 임의 시점 kill 후 재시작이 RNG 상태·데이터로더 위치까지 포함해 무중단 학습과 비트 단위로 같은 loss 곡선을 내는지 검증한다.		준비중mac
AISYS-A09AdvancedStraggler와 Silent Data Corruption 탐지
랭크별 스텝 구간 시간(계산/통신 대기) 텔레메트리를 생성하는 시뮬레이터에 느린 노드·열 스로틀·링크 열화와 비트플립 SDC를 주입하고, collective 대기 시간 분포로 straggler 랭크를 특정하는 탐지기와 loss spike·grad norm 이상·DP 복제 간 파라미터 체크섬 불일치로 SDC를 잡는 탐지기를 구현해 탐지율·오탐률을 측정한다.		준비중mac
AISYS-A10Advanced설계 면접: LLM 서빙 시스템 (용량·비용·SLO)
'일 1천만 요청, 평균 입력 2K/출력 300 토큰, p99 TTFT 1s·TPOT 50ms' 요구사항으로 모델 정밀도·TP 크기·배치·KV 예산·prefix 캐시·disaggregation 여부·라우팅/오토스케일링을 결정하는 설계 문서를 작성하고, B10·M11·A02·A03 도구로 GPU 수와 1M 토큰당 비용을 계산해 근거로 제시한다.		준비중mac
AISYS-A11Advanced설계 면접: 대규모 학습 런 계획 (70B, 15T 토큰)
70B 모델을 15T 토큰으로 학습하는 계획서를 작성해 B02로 GPU 수·기간, A06으로 병렬 구성, A07로 체크포인트 간격·예상 중단 횟수, A08·A09로 복구·탐지 전략, 혼합 정밀도(bf16/fp8) 선택을 정하고, 각 결정의 수치 근거와 '예상보다 MFU가 10%p 낮으면?' 같은 민감도 분석을 포함한다.		준비중mac
