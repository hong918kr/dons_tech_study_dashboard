Stage 1 · ALGO · Algorithms

알고리즘

아이템 42Basic 15Mid 15Advanced 12학습가능 1

임베디드 회사 코딩 면접도 결국 알고리즘 문제를 풀게 하지만, 비트 조작·CRC·스트림 파싱·제한된 메모리·실시간 제약 같은 '펌웨어 맛'이 섞여 나온다. 이 트랙은 정렬·탐색·그래프·DP 같은 정석 패턴을 C로 직접 구현하고, 각 문제를 센서·통신·로봇 상황으로 바꿔 풀어 본다.

트랙 목표

  • 복잡도를 이론과 실측으로 모두 설명하고 메모리 제약을 고려한 풀이를 고른다
  • 이진 탐색·투 포인터·슬라이딩 윈도우·재귀/백트래킹 패턴을 경계 실수 없이 구현한다
  • BFS/DFS·위상 정렬·최단 경로·SCC를 로봇·의존성·데드락 문제에 적용한다
  • DP·그리디·힙 활용 문제를 펌웨어 시나리오로 모델링해 푼다
  • 비트 트릭·CRC·체크섬·COBS·스트리밍 파서를 표준 테스트 벡터로 검증한다
  • 45분 면접 형식으로 문제 분석 → 구현 → 테스트 → 복잡도 설명을 연습한다
