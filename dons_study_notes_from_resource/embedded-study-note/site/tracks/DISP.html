Stage 6 · DISP · Display

디스플레이

아이템 25Basic 9Mid 9Advanced 7학습가능 0

디스플레이는 픽셀 클럭과 블랭킹 타이밍, 프레임버퍼 메모리, 색공간 변환, 합성(compositing), 패널 인터페이스(MIPI DSI/eDP/HDMI)가 실시간 제약 아래 맞물려 돌아가는 시스템이다. 차량 클러스터·HMI, 웨어러블, 스마트폰(Apple, Tesla, Rivian, Qualcomm 디스플레이 팀)에서는 패널 bring-up, 티어링, 대역폭/언더런 분석이 자주 출제된다. 이 트랙은 타이밍 생성기부터 DRM/KMS까지 직접 구현·측정하며 디스플레이 파이프라인을 끝까지 따라간다.

트랙 목표

  • 디스플레이 타이밍(hsync/vsync/porch/pixel clock)을 계산·생성하고 EDID로부터 모드를 도출할 수 있다
  • 프레임버퍼 포맷, 색공간 변환(YUV↔RGB), 감마·디더링·알파 블렌딩을 고정소수점으로 정확히 구현할 수 있다
  • 더블/트리플 버퍼링, vsync, 티어링, 지연의 관계를 모델로 설명하고 페이지 플립을 설계할 수 있다
  • MIPI DSI/HDMI(TMDS)/DP의 패킷·인코딩 기초와 패널 초기화 시퀀스를 다룰 수 있다
  • 리눅스 DRM/KMS로 실제 모드셋·페이지 플립을 수행하고 대역폭/저전력 기능을 설계 관점에서 분석할 수 있다

DISP-B01Basic디스플레이 타이밍: Porch·Sync·Blanking과 Pixel Clock
h/v active, front porch, sync width, back porch, refresh rate를 받아 htotal/vtotal과 pixel clock을 계산하는 함수를 작성하고, 1920x1080@60(148.5MHz), 1280x720@60 등 CTA-861 표준 모드 값과 일치하는지 테스트하며 xrandr modeline 문자열을 생성·파싱한다.		준비중mac
DISP-B02Basic타이밍 생성기 사이클 시뮬레이션과 VCD 출력
픽셀 클럭 단위로 h/v 카운터를 증가시켜 HSYNC, VSYNC, DE, 극성을 생성하는 C 모델을 작성하고 VCD 파일로 덤프해 GTKWave로 확인하며, DE 펄스 수와 sync 폭이 설정값과 일치하는지 assert로 검증한다.		준비중mac
DISP-B03Basic프레임버퍼 기초: 픽셀 포맷·Stride·Blit
포맷별 put_pixel, fill_rect, blit(포맷 변환 포함), 클리핑을 갖춘 소프트웨어 프레임버퍼 라이브러리를 작성해 PPM으로 출력하고, stride ≠ width*bpp 인 버퍼와 화면 밖 좌표에서 메모리 침범이 없음을 ASan으로 확인한다.		준비중mac
DISP-B04Basic비트맵 폰트 렌더링과 임베디드 UI 기초
8x16 비트맵 폰트 테이블로 문자열을 프레임버퍼에 그리는 함수와, 변경된 영역만 추적해 부분 전송하는 dirty-rectangle 관리자를 작성하고, SPI LCD 전송 바이트 수를 전체 갱신 대비 비교한다.		준비중mac
DISP-B05BasicRGB↔YUV 변환: BT.601/709, Full/Limited Range
BT.601/BT.709 × full/limited 4가지 조합의 RGB→YUV, YUV→RGB 변환을 Q8 정수 연산으로 구현하고, float 레퍼런스 대비 최대 오차와 모든 24비트 RGB 값에 대한 왕복 오차 분포를 측정한다.		준비중mac
DISP-B06Basic크로마 서브샘플링: 4:2:0 업샘플과 NV12→RGB
NV12(4:2:0) 버퍼를 nearest와 bilinear(co-sited/center siting 구분) 크로마 업샘플로 RGB 변환하는 함수를 작성하고, 빨간 글자 테스트 패턴에서 색 번짐(color bleeding) 차이를 비교한다.		준비중mac
DISP-B07Basic감마와 디더링: Ordered vs Floyd-Steinberg
8비트 그라디언트를 6비트/5-6-5로 줄일 때 단순 절단, 4x4 Bayer ordered dithering, Floyd-Steinberg 오차 확산을 구현하고, 결과 이미지와 저역 필터 후 평균 오차·밴딩 단계 수를 비교한다.		준비중mac
DISP-B08Basic알파 블렌딩과 Porter-Duff: Premultiplied Alpha
Porter-Duff SRC_OVER/SRC_IN/DST_OUT을 straight와 premultiplied 두 방식으로 구현하고, x*a/255를 (t=x*a+128; (t+(t>>8))>>8)로 근사하는 정수 트릭이 65536 조합 전체에서 정확히 반올림됨을 전수 검증한다.		준비중mac
DISP-B09Basic백라이트 PWM과 인지 밝기 곡선
CIE 1931 lightness 공식으로 0–100% 밝기 단계를 12비트 PWM 듀티 LUT로 변환하는 함수와 일정 시간에 걸친 부드러운 fade 램프 생성기를 구현하고, 선형 매핑 대비 저휘도 구간 단계 크기와 PWM 주파수(예: >1kHz) 선택 근거를 정리한다.		준비중mac
Mid · 9개
DISP-M01Mid더블/트리플 버퍼링과 페이지 플립 상태 머신
렌더 스레드와 vblank마다 스캔아웃 주소를 래치하는 가상 디스플레이 컨트롤러를 C로 만들고, 단일 버퍼(티어링 발생 탐지), 더블 버퍼(플립 대기), 트리플 버퍼 상태 머신을 구현해 프레임 ID 체크로 티어링·중복 프레임을 검출한다.		준비중mac
DISP-M02Mid티어링·Vsync·지연 분석: FIFO vs Mailbox
렌더 시간 분포가 다른 워크로드에서 vsync off, FIFO(vsync), mailbox(트리플) 프레젠테이션을 이벤트 시뮬레이션하고, 입력-표시 지연 분포, 티어링 발생 비율, 프레임 페이싱 지터를 표로 비교한다.		준비중mac
DISP-M03Mid하드웨어 오버레이 Plane과 스캔라인 합성기
plane마다 포맷·위치·크기·z-order·전역/픽셀 알파를 갖는 합성기를 스캔라인 단위로 구현하고, 하드웨어 plane 수 제약 아래 레이어들을 plane에 배정하거나 GPU 합성으로 폴백하는 할당 알고리즘을 작성해 테스트 장면으로 검증한다.		준비중mac
DISP-M04Mid디스플레이 스케일러: Polyphase 필터
8-phase × 4-tap 계수 테이블(Lanczos 기반, 계수 합 정규화)을 생성하고 고정소수점 polyphase 수평/수직 스케일러를 구현해, bilinear 대비 해상도 차트에서 aliasing과 ringing을 비교한다.		준비중mac
DISP-M05Mid패널 초기화 시퀀스: Reset 타이밍과 DCS 명령
전원 레일/reset/지연 단계를 포함한 테이블 기반 패널 init 엔진과 mock DSI 호스트를 작성해 sleep out(0x11) → 120ms → display on(0x29) 등 시퀀스를 실행하고, 순서 위반·지연 부족을 검출하는 검사기를 단위 테스트로 검증한다.		준비중mac
DISP-M06MidMIPI DSI 패킷과 Video/Command 모드
DSI short/long packet(DI, WC, ECC, checksum) 인코더를 작성하고, 해상도·fps·bpp·레인 수로 필요한 레인 비트레이트를 계산하는 함수와 command 모드에서 TE 신호 이후 쓰기 시작 시각에 따른 티어링 조건을 모델링한다.		준비중mac
DISP-M07MidEDID 파싱과 모드 선택
128바이트 base EDID와 CTA-861 확장 블록을 파싱해 제조사 ID, 체크섬, Detailed Timing Descriptor, 표준 타이밍, SVD 목록을 출력하는 C 파서를 작성하고, 실제 모니터 EDID 덤프 샘플과 손상된 체크섬 입력으로 테스트한다.		준비중mac
DISP-M08MidHDMI TMDS 인코딩과 DP 링크 대역폭
TMDS 인코더(XOR/XNOR 선택 + running disparity 기반 반전)와 디코더를 구현해 무작위 데이터 왕복과 disparity 유계를 검증하고, DP HBR2/HBR3 레인 수별 유효 대역폭으로 4K@60 10bpc 지원 여부를 계산한다.		준비중mac
DISP-M09Mid디스플레이 컨트롤러 드라이버 (Mock 레지스터)
mock LCD 컨트롤러 레지스터 맵(타이밍, FB 주소, 제어, IRQ 상태)을 정의하고 set_mode, flip(다음 vblank 래치), vblank 콜백, FIFO underrun IRQ 복구를 구현한 드라이버를 작성해, vblank 경계 근처 flip 요청이 정확히 한 프레임 뒤에 반영되는지 테스트한다.		준비중mac

DISP-A01AdvancedDRM/KMS Dumb Buffer 모드셋과 페이지 플립
vkms 가상 드라이버에서 libdrm으로 connector와 모드를 열거하고 dumb buffer 두 개를 만들어 drmModeSetCrtc 후 drmModePageFlip + 이벤트 루프로 애니메이션을 출력하며, flip 이벤트 타임스탬프 간격을 기록해 refresh 주기와 비교한다.		외부환경필요linux
DISP-A02AdvancedAtomic Modesetting과 Plane 속성
vkms에서 primary + overlay/cursor plane 속성(FB_ID, CRTC_X/Y/W/H, SRC_*)을 atomic request로 묶어 커밋하고, DRM_MODE_ATOMIC_TEST_ONLY로 지원되지 않는 구성을 사전 거절하는 흐름과 legacy API 대비 장점을 정리한다.		외부환경필요linux
DISP-A03Advanced디스플레이 메모리 대역폭과 FIFO 언더런 분석
plane 구성(해상도, bpp, 스케일)별 스캔아웃 대역폭을 계산하고, 메모리 지연이 확률 분포로 변하는 DRAM 모델 위에서 FIFO 깊이별 언더런 확률을 시뮬레이션해 목표(예: 1e-9 미만)를 만족하는 최소 FIFO와 QoS 우선순위 필요성을 정리한다.		준비중mac
DISP-A04AdvancedHDR 디스플레이: PQ/HLG 전달 함수와 톤 매핑
PQ EOTF/inverse EOTF와 HLG OETF를 구현해 표준 기준값(예: 10000nit ↔ 1.0, 100nit ↔ 약 0.508)과 비교 검증하고, 1000nit 패널용 BT.2390 스타일 roll-off 톤 매핑 LUT(10비트)를 생성한다.		준비중mac
DISP-A05Advanced가변 주사율(VRR)과 프레임 페이싱
패널 VRR 범위(예: 48–120Hz)를 가진 디스플레이 모델에서 가변 렌더 시간 워크로드를 고정 60Hz vsync, VRR, VRR+Low Framerate Compensation으로 시뮬레이션해 표시 지연과 프레임 간격 지터를 비교한다.		준비중mac
DISP-A06AdvancedPanel Self Refresh와 저전력 디스플레이 설계
정지 화면 감지 → PSR 진입 → 부분 갱신(PSR2 selective update) → 탈출의 상태 머신을 구현하고, 사용 시나리오(타이핑, 영상, 정지)별 링크 활성 시간과 추정 전력을 계산해 진입 지연 파라미터의 트레이드오프를 정리한다.		준비중mac
DISP-A07Advanced타일 기반 프레임버퍼 압축 모델
16x16 타일 단위로 단색 타일 플래그, 기준값 + 델타 비트폭 인코딩을 하는 무손실 압축기/해제기를 구현해 왕복 일치를 검증하고, UI·게임·사진 이미지에서 압축률과 스캔아웃 대역폭 절감량, 타일 헤더 메타데이터 오버헤드를 측정한다.		준비중mac
