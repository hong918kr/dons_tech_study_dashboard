SoC 인터커넥트 · 칩렛

아이템 35Basic 12Mid 13Advanced 10학습가능 2

현대 SoC와 AI 가속기의 성능·전력·정확성은 코어보다 그 사이를 잇는 인터커넥트(AXI/CHI, 크로스바, NoC), SoC 수준 일관성·SMMU·인터럽트 패브릭, 그리고 칩렛 간 D2D 링크에서 결정되는 경우가 많다. NVIDIA·AMD·Tenstorrent·Apple·Rivian 같은 회사의 실리콘/펌웨어 면접은 'outstanding이 몇 개 필요한가', '이 라우팅은 데드락이 없나', 'nested walk 비용은?' 같은 질문을 수치로 답하길 요구하므로, 이 트랙은 모든 개념을 Mac에서 돌아가는 C/Python 모델로 직접 계산·검증한다.

트랙 목표

  • AXI4/ACE/CHI를 버스트·ID·순서·응답·속성 수준에서 설명하고 변환기·체커를 구현한다
  • 크로스바와 NoC(토폴로지, 라우팅, wormhole/VC, 크레딧, 데드락)를 사이클 시뮬레이터로 분석한다
  • SoC 스케일 일관성(snoop filter, CHI 흐름)과 SMMUv3·GICv3 ITS 같은 시스템 IP를 모델로 검증한다
  • 칩렛 수율·UCIe D2D·CXL 패브릭·HBM 인터리빙을 비용·대역폭·지연 수치로 판단한다
  • QoS·전력·행 디버그를 포함한 SoC 성능 모델로 설계 결정을 근거 있게 내린다

SOCX-B05BasicOutstanding 트랜잭션과 Little's Law 대역폭

SOCX-M07Mid프로토콜 데드락과 메시지 클래스 분리

SOCX-M08MidNIU: AXI 트랜잭션 → NoC 패킷화
AXI AR/AW+W를 헤더 플릿(목적지, 트랜잭션 태그, 속성)+데이터 플릿으로 패킷화하고 응답 패킷을 AXI ID 순서 규칙에 맞게 재정렬하는 NIU 모델을 C로 작성해, 버스트 길이·플릿 폭별 헤더 오버헤드와 실효 대역폭을 계산하고 무작위 트래픽에서 순서 규칙 체커(see:ARCH-M14)를 통과시킨다.		준비중mac
SOCX-M09MidACE·ACE-Lite: 하드웨어 IO 일관성
CPU 캐시 2개(MESI, see:ARCH-A04) + CCI 스타일 인터커넥트 + ACE-Lite DMA 마스터 모델을 만들어 DMA ReadOnce/WriteUnique가 CPU 캐시를 스누프하는 흐름을 구현하고, 비일관 DMA + clean/invalidate(see:ARCH-M12) 방식과 버퍼 크기별 지연·스누프 트래픽을 비교한다.		준비중mac
SOCX-M10MidSoC 스케일 Snoop Filter: 크기와 Back-invalidation
코어별 private 캐시 크기 합 대비 snoop filter 엔트리 수(0.5×–2×)와 연관도를 바꾸며 SF 축출 시 back-invalidation을 수행하는 모델을 트레이스 구동으로 작성해, 브로드캐스트 스누프 대비 스누프 메시지 감소와 back-invalidation으로 인한 추가 캐시 미스를 측정한다(디렉터리 기본은 see:MEM-M05).		준비중mac
SOCX-M11MidAMBA CHI 트랜잭션 흐름: RN-F·HN-F·SN-F
RN-F 3개·HN-F(SF 포함)·SN-F로 구성된 CHI 메시지 시퀀스 모델을 Python으로 작성해 주요 트랜잭션의 메시지 순서와 최종 캐시 상태(UC/UD/SC/SD/I)를 검증하고, DCT/DMT 사용 여부에 따른 홉 수·지연과 HN 버퍼 부족 시 RetryAck→PCrdGrant 재시도 흐름을 재현한다.		준비중mac
SOCX-M12MidSMMUv3: StreamID → STE → CD와 2단계 변환
Stream Table(2-level)·Context Descriptor·stage1/stage2 4-level 페이지 테이블을 가진 SMMUv3 C 모델을 작성해 nested walk 메모리 접근 수가 최악 (4+1)×(4+1)−1=24임을 카운트로 확인하고, TLB/walk cache 유무별 평균 변환 지연과 fault 시 Event Queue 레코드 생성을 검증한다(IOMMU 기초는 see:PCIE-M15, 패스스루는 see:VIRT).		준비중mac
SOCX-M13MidGICv3 ITS: MSI → LPI 변환
GITS_CBASER 명령 큐(MAPD/MAPC/MAPTI/INV/SYNC/MOVI)와 Device Table→ITT→Collection→Redistributor 변환, LPI pending/config 테이블을 가진 ITS C 모델을 작성해 GITS_TRANSLATER에 (DeviceID, EventID) 쓰기 시 올바른 CPU에 LPI가 뜨는지, MOVI 후 인터럽트 이동과 INV 누락 버그를 테스트한다(PCIe MSI-X는 see:PCIE-M10).		준비중mac

SOCX-A01AdvancedUCIe Die-to-Die 링크 계산: 대역폭 밀도·에너지·지연
UCIe 모듈(x16/x64 레인, 4–32 GT/s, 범프 피치) 파라미터로 GB/s/mm shoreline·GB/s/mm² 밀도, 링크 전력(pJ/bit × BW), FDI/RDI 계층 지연 합을 계산하는 Python 모델을 작성해 '다이 가장자리 10mm로 2TB/s 양방향이 가능한가?' 같은 설계 질문에 답하고, PCIe/CXL PHY 기반 연결과 비교한다(see:PCIE-B02).		준비중mac
SOCX-A02AdvancedD2D 링크 계층: Flit CRC와 Replay 시뮬레이션

SOCX-A03Advanced멀티 다이 SoC 파티셔닝과 NUMA형 지연 모델
컴퓨트 다이 4개 + IO 다이(메모리 컨트롤러) 구성의 다이 내 NoC·D2D 링크·DDR/HBM 경로 모델을 C로 만들어 주소 인터리빙(다이 로컬 vs 전역 interleave) 정책별 평균/꼬리 지연과 D2D 링크 포화 지점을 측정하고, 같은 워크로드의 모놀리식 대비 성능 손실을 보고한다(OS 측 NUMA는 see:MEM-M09).		준비중mac
SOCX-A04Advanced다이 간 일관성: 홈 노드 배치와 원격 스누프 비용
M11 CHI 모델을 두 다이로 확장(CHI C2C 개념)해 주소 해시 기반 홈 노드 분산, 다이별 로컬 홈 + 원격 SF 캐싱 두 방식에서 공유 데이터 생산자-소비자 트레이스의 원격 메시지 수·평균 미스 지연을 측정하고, 프로그래머에게 보이는 '다이 친화 배치' 지침을 도출한다.		준비중mac
SOCX-A05AdvancedHBM 채널·Pseudo-channel 인터리빙과 AI 텐서 접근
HBM3 스택 N개 × 16채널 × 2 pseudo-channel 주소 매핑(선형/XOR 해시)을 가진 컨트롤러 측 모델에 GEMM 타일·KV 캐시 접근 트레이스를 넣어 채널별 요청 분포·뱅크 충돌·달성 대역폭을 측정하고, 해시 매핑으로 불균형을 해소함을 보인다(대역폭 계산은 see:MEM-A03, 매핑 기초는 see:MEM-M02).		준비중mac
SOCX-A06AdvancedCXL 패브릭: 스위치·메모리 풀링과 티어링
호스트 4개·CXL 스위치·Type 3 MLD 메모리 장치의 용량 할당(논리 장치 바인딩) 모델과, 로컬 DDR(~100ns) vs CXL(~250ns) 2티어 메모리에서 접근 빈도 기반 hot-page promotion/demotion 정책을 Python으로 시뮬레이션해 티어링 정책별 평균 메모리 지연과 마이그레이션 트래픽을 비교한다(CXL 기초·HDM은 see:PCIE-A10).		준비중mac
SOCX-A07AdvancedSoC 유스케이스 대역폭 예산 모델
4K60 녹화+프리뷰+NPU 검출 같은 동시 유스케이스의 마스터별 대역폭·지연 요구를 스프레드시트형 Python 예산 모델로 산출하고, 같은 트래픽을 M03 QoS DES에 넣어 평균 대역폭은 맞지만 버스트 겹침으로 실시간 마스터가 실패하는 경우를 찾아 버퍼 크기·QoS 설정을 권고한다(see:SIM-A06, see:CAM).		준비중mac
SOCX-A08Advanced인터커넥트 전력: 비트당 에너지와 NoC DVFS
링크·라우터·SRAM 버퍼의 pJ/bit/hop 파라미터와 NoC 전압-주파수 테이블을 가진 전력 모델을 B09 시뮬레이터에 붙여, 트래픽 부하에 따른 NoC DVFS·유휴 링크 클럭 게이팅(B11 Q-channel) 정책별 에너지와 지연 증가를 비교하고, 데이터 이동 에너지가 연산 에너지를 넘는 지점을 계산한다(see:NPU-A07).		준비중mac
SOCX-A09Advanced인터커넥트 행(hang) 디버그와 성능 모니터
타임아웃 감지기·트랜잭션 트래커·지연 히스토그램/대역폭 PMU를 가진 인터커넥트 모델에 결함(슬레이브 무응답, 파워 게이팅된 도메인 접근, 크레딧 누수)을 주입하고, 행 시점의 outstanding 테이블 덤프만 보고 원인 블록을 지목하는 분석 스크립트를 작성한다(트리아지 일반론은 see:SIV-M10).		준비중mac
SOCX-A10Advanced종합 설계: AI 가속기 칩렛 SoC 인터커넥트 아키텍처
컴퓨트 칩렛 4개 + IO 다이 + HBM3 스택 4개 구성의 AI SoC에 대해 NoC 토폴로지, 일관성 도메인 경계, UCIe 링크 수, SMMU/ITS 위치, QoS 클래스를 결정하는 설계 문서를 작성하고, 앞선 B08·A01·A03·A05·A07 모델로 각 결정의 대역폭·지연 근거를 표로 제시한다(엣지 SoC 버전은 see:ARCH-A12).		준비중mac
