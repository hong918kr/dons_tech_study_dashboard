임베디드 보안

아이템 30Basic 10Mid 12Advanced 8학습가능 0

연결된 임베디드 디바이스(차량, 드론, 로봇, 방산 장비)는 물리적 접근이 가능한 공격자를 전제로 설계해야 하므로, 보안 부팅·키 관리·안전한 업데이트·사이드채널/글리치 방어가 펌웨어 엔지니어의 기본기가 되었다. 이 트랙은 C 메모리 안전 버그와 기본 암호 구현에서 출발해 chain of trust, TEE/MPU 하드닝, 공격 시뮬레이션까지 직접 만들어 보며 익힌다.

트랙 목표

  • 위협 모델링으로 보호 대상과 공격 표면을 정의한다
  • C 메모리 안전 버그를 재현·탐지·수정하고 컴파일러/MPU 하드닝을 적용한다
  • 해시·HMAC·AES 모드·AEAD·서명·난수를 올바르게 사용하고 오용 결과를 체험한다
  • secure boot, 키 계층, anti-rollback, secure update, 디버그 잠금을 구현 수준으로 설계한다
  • 타이밍·전력 사이드채널과 결함 주입 공격을 시뮬레이션하고 방어 코딩을 적용한다

SEC-B01Basic위협 모델링: 자산, 공격 표면, STRIDE
Wi-Fi 연결 센서 디바이스(부트로더, 앱, OTA, 디버그 포트, 클라우드 API)의 DFD와 신뢰 경계를 그리고 STRIDE 위협 표(위협, 영향, 가능성, 완화책)를 작성해 상위 5개 위협과 대응 트랙 항목을 매핑한다.		준비중mac
SEC-B02BasicC 메모리 안전 버그 1: 스택 버퍼 오버플로
고정 크기 버퍼에 길이 검사 없이 복사하는 명령 핸들러를 작성해 -fno-stack-protector 빌드에서 lldb로 인접 변수·저장된 레지스터가 덮이는 모습을 관찰하고, ASan 탐지 → bounded copy와 길이 검증으로 수정한 뒤 회귀 테스트를 추가한다.		준비중mac
SEC-B03BasicC 메모리 안전 버그 2: 정수 오버플로, 부호 혼동, off-by-one
패킷 길이 필드 처리에서 흔한 취약 패턴 5종(len+hdr 오버플로, signed/unsigned 비교, size_t 언더플로, off-by-one, 곱셈 오버플로)을 재현하고 __builtin_add_overflow 등 checked arithmetic으로 수정해 경계 테스트로 검증한다.		준비중mac
SEC-B04BasicC 메모리 안전 버그 3: UAF, double free, format string
use-after-free, double free, 사용자 입력을 포맷 문자열로 쓰는 로그 함수를 재현해 ASan/-Wformat-security로 탐지하고, 소유권 규칙·free 후 NULL·고정 포맷 사용으로 수정하며 펌웨어에서 정적 할당을 선호하는 이유를 정리한다.		준비중mac
SEC-B05Basic해시 함수 구현: SHA-256
SHA-256을 직접 구현(init/update/final 스트리밍 API, 빅엔디언 처리, 패딩)하고 NIST 테스트 벡터(빈 문자열, 'abc', 백만 'a')와 청크 분할 입력 일치를 검증한다.		준비중mac
SEC-B06Basic메시지 인증: HMAC-SHA256과 길이 확장 공격
자신의 SHA-256으로 HMAC을 구현해 RFC 4231 벡터로 검증하고, H(secret||msg) 방식에 대한 length extension 공격을 실제로 구현해 위조 메시지가 검증을 통과함을 보인 뒤 HMAC에서는 실패함을 확인한다.		준비중mac
SEC-B07Basic타이밍 안전 비교: constant-time memcmp
memcmp 기반 MAC 비교의 일치 바이트 수에 따른 실행시간 차이를 통계(수만 샘플, 중앙값)로 측정하고 XOR-OR 누적 constant-time 비교를 구현, -O2 디스어셈블리에서 분기가 없는지 확인한다.		준비중mac
SEC-B08BasicAES와 블록 암호 모드: ECB, CBC, CTR
Mbed TLS AES로 비트맵 이미지를 ECB/CBC/CTR 암호화해 ECB 패턴 노출을 확인하고, CTR nonce 재사용 시 두 평문 XOR이 드러나는 공격과 CBC 비트 플립 공격을 재현한 뒤 올바른 IV/nonce 관리 규칙을 정리한다.		준비중mac
SEC-B09BasicAEAD: AES-GCM / ChaCha20-Poly1305로 패킷 보호
디바이스↔게이트웨이 패킷 포맷(헤더=AAD, 카운터 기반 nonce, 태그)을 설계하고 Mbed TLS/libsodium으로 구현, 태그 변조·리플레이·nonce 중복을 거부하는지 테스트한다.		준비중mac
SEC-B10Basic난수와 엔트로피: TRNG, DRBG, health test
시간 시드 rand()로 생성한 키를 시드 범위 탐색으로 복원하는 데모를 만들고, CTR_DRBG(Mbed TLS) 기반 난수 API와 TRNG 원시 출력용 Repetition Count·Adaptive Proportion health test(SP 800-90B)를 구현한다.		준비중mac
Mid · 12개
SEC-M01Mid디지털 서명: ECDSA P-256과 Ed25519
Mbed TLS(ECDSA P-256)와 libsodium(Ed25519)으로 펌웨어 이미지 서명/검증 도구를 만들고 DER vs raw(r||s) 서명 포맷 변환, 공개키 해시 고정, ECDSA nonce 재사용 시 개인키가 복원되는 원리를 수식과 코드로 확인한다.		준비중mac
SEC-M02MidSecure boot 검증 경로 구현
이미지 헤더(magic, 버전, 크기, 해시, 서명, 헤더 자체 범위)를 정의하고 부트로더 검증 함수(헤더 경계 검사→해시→서명→점프)를 구현, 변조 이미지·잘린 이미지·헤더 크기 조작·TOCTOU 시나리오 테스트 세트로 검증한다.		준비중mac
SEC-M03MidChain of trust와 키 계층: ROTPK, 인증서, 폐기
OTP에 ROTPK 해시를 두고 root→content-signing 키 인증서 체인을 검증하는 코드를 구현, 키 폐기 비트(OTP fuse 모델)로 유출된 서명 키를 무효화하는 시나리오를 테스트한다.		준비중mac
SEC-M04MidAnti-rollback: 보안 버전과 단조 카운터
eFuse/OTP 단조 카운터 모델과 이미지의 security version을 비교하는 검사를 구현하고, A/B 업데이트에서 카운터를 '언제' 올려야 하는지(새 이미지 mark-good 이후) 잘못된 순서가 벽돌/우회를 만드는 시나리오로 검증한다.		준비중mac
SEC-M05MidSecure firmware update: 서명된 매니페스트와 암호화 페이로드
서명된 매니페스트(버전, 대상 하드웨어, 페이로드 해시, 암호화 키 래핑 정보)와 AES-GCM 암호화 페이로드로 업데이트 패키지를 만들고 디바이스 검증/설치 로직을 구현, TUF/SUIT 개념과 비교한다.		준비중mac
SEC-M06Mid키 저장과 키 래핑: KEK, AES-KW, 보안 엘리먼트
디바이스 고유 키(하드웨어 유도 KEK 모델)로 데이터 키를 AES-KW(RFC 3394)로 wrap/unwrap하는 코드를 구현해 RFC 벡터로 검증하고, OTP·보안 엘리먼트·TEE 키 저장 옵션별 위협 대응을 비교한다.		준비중mac
SEC-M07MidTrustZone-A와 TEE: OP-TEE Trusted Application
OP-TEE QEMUv8 환경에서 hello_world TA와 클라이언트 앱을 빌드·실행하고(또는 가이드 따라 구조 분석), '키를 TA 밖으로 내보내지 않는 서명 서비스' TA 인터페이스(UUID, 명령 ID, 파라미터 타입)를 설계한다.		외부환경필요qemu
SEC-M08MidMPU 권한 분리: 비특권 태스크 샌드박스와 SVC 게이트
QEMU Cortex-M에서 비특권 thread 모드 태스크에 자기 스택·데이터 영역만 허용하는 MPU 영역을 컨텍스트 전환마다 바꿔 끼우고, 특권 서비스는 SVC 게이트로만 호출하게 만든 뒤 다른 태스크 메모리·주변장치 접근이 MemManage fault로 차단되는지 검증한다(기본 MPU 설정은 see:BM-A08).		외부환경필요qemu
SEC-M09Mid컴파일러 하드닝: stack protector, FORTIFY, CFI, PIE
-fstack-protector-strong, _FORTIFY_SOURCE=2, -fsanitize=cfi, PIE/RELRO 각각의 효과를 디스어셈블리·readelf로 비교하고, bare-metal용 __stack_chk_guard(부팅 시 난수 초기화)와 __stack_chk_fail을 직접 구현한다.		준비중mac
SEC-M10Mid보안 통신: 임베디드 TLS 1.3과 mTLS
Mbed TLS로 디바이스 인증서 기반 mTLS 클라이언트/서버를 구성하고 인증서 핀닝·호스트명 검증을 구현, 핸드셰이크 시간·피크 RAM·코드 크기를 측정해 PSK 모드와 비교한다.		준비중mac
SEC-M11Mid디버그 포트 잠금: JTAG/SWD와 readout protection
RDP 레벨(0/1/2) 상태머신 모델(레벨 하향 시 전체 erase)과 challenge-response 인증 디버그 언락(디바이스 nonce + 서명된 응답, 디바이스 ID 바인딩)을 구현하고 리플레이·다른 디바이스 토큰 재사용을 거부하는지 테스트한다.		준비중mac
SEC-M12Mid펌웨어 바이너리 분석: 비밀 노출 찾기
API 키·비밀번호·개인키가 박힌 펌웨어 바이너리(직접 빌드)에서 strings, binwalk, 엔트로피 그래프, Ghidra 함수 참조로 비밀을 찾아내고, 빌드 파이프라인에서 비밀 스캔과 디바이스별 provisioning으로 대체하는 방안을 정리한다.		준비중mac
Advanced · 8개
SEC-A01Advanced타이밍 사이드채널 공격 실습과 방어
로컬 소켓 서버의 비-constant-time 토큰 검증에 대해 바이트별 후보 응답시간을 수천 샘플 수집·통계 검정해 토큰을 복원하는 공격 스크립트를 작성하고, constant-time 비교·rate limit 적용 후 공격이 실패함을 확인한다.		준비중mac
SEC-A02Advanced전력 분석 시뮬레이션: CPA로 AES 키 복원
AES 첫 라운드 S-box 출력의 Hamming weight + 가우시안 노이즈로 합성 전력 트레이스를 만들고, 키 바이트 후보별 상관계수로 키를 복원하는 CPA를 구현해 노이즈 대비 필요 트레이스 수를 측정, 마스킹 적용 시 효과를 비교한다.		준비중mac
SEC-A03Advanced결함 주입(글리칭) 방어 코딩
명령 스킵·분기 반전·레지스터 비트플립을 흉내 내는 결함 시뮬레이터(검증 함수 실행 단계에 주입)를 만들고, 이중 검사·상보 상수 플래그(0x3CA5/0xC35A)·무작위 지연·루프 완료 카운터 검증으로 secure boot 분기를 하드닝해 우회율을 비교한다.		준비중mac
SEC-A04Advanced제어 흐름 탈취와 완화: NX, ASLR, PAC/BTI
격리된 실습 프로그램에서 스택 오버플로로 리턴 주소를 다른 함수로 바꾸는 제어 흐름 탈취를 재현(보호 해제 빌드)하고, M2(arm64e)에서 -mbranch-protection=standard 빌드 시 PACIASP/AUTIASP 삽입과 탈취 실패를 디스어셈블리·실행으로 확인한다.		준비중mac
SEC-A05Advanced원격 증명(Remote Attestation)
측정값(부트 스테이지 해시)과 서버 nonce를 포함한 증명 토큰(CBOR/EAT 유사)을 디바이스 키로 서명하고, 서버 검증기가 서명·nonce 신선도·허용 측정값 목록을 확인하도록 구현해 리플레이와 변조 펌웨어를 거부하는지 테스트한다.		준비중mac
SEC-A06Advanced상태 기반 프로토콜 퍼징
인증→세션→명령 단계를 가진 디바이스 명령 프로토콜에 libFuzzer custom mutator(구조 인식, 메시지 시퀀스 생성)를 적용해 상태 커버리지를 높이고, 일반 퍼징 대비 도달 상태 수·발견 버그를 비교한다.		준비중mac
SEC-A07Advanced메모리 안전 언어 비교: Rust no_std 파서
앞서 취약했던 TLV 패킷 파서를 Rust no_std(슬라이스·Result 기반)로 재작성하고 C 버전과 같은 퍼징 하네스(cargo-fuzz)를 돌려 버그 수·코드 크기·성능을 비교, C와 FFI로 공존시키는 경계 설계를 정리한다.		준비중mac
SEC-A08Advanced종합: 디바이스 보안 아키텍처 리뷰
B01 위협 모델을 갱신해 보안 부팅·키 계층·anti-rollback·secure update·디버그 잠금·증명·로깅을 엮은 보안 아키텍처 문서를 작성하고, 자체 레드팀 체크리스트(각 위협에 대한 테스트 증거 링크)로 평가해 잔여 위험을 정리한다.		준비중mac
