저지연 시스템

아이템 24Basic 8Mid 9Advanced 7학습가능 0

저지연 시스템은 '평균'이 아니라 p99·p99.9 꼬리 지연을 다루는 엔지니어링으로, HFT·로봇 제어·네트워크 장비·펌웨어 모두 같은 원리(캐시, 메모리 오더링, lock-free, 할당 제거, 코어 격리)를 쓴다. 이 트랙은 측정법부터 lock-free 큐, 오더북, 커널 바이패스까지 C++로 구현·계측해 quant SWE와 실시간 펌웨어 면접을 동시에 대비한다.

트랙 목표

  • 타이머 소스와 히스토그램/백분위수로 지연 분포를 올바르게 측정한다
  • 캐시 레이아웃·false sharing·분기 예측이 지연에 미치는 영향을 실측한다
  • SPSC/MPMC/Disruptor 등 lock-free 큐를 구현하고 메모리 오더를 정당화한다
  • 할당 없는 hot path와 오더북을 구현하고 메시지당 지연을 최적화한다
  • CPU 격리·커널 바이패스·io_uring·타임스탬핑으로 시스템 수준 꼬리 지연을 줄인다

LLAT-B08Basic할당 없는 hot path

LLAT-M02MidSeqlock: 단일 writer 스냅샷 공유
시장 데이터 스냅샷용 seqlock을 C++ 메모리 모델에 맞게(atomic 시퀀스, fence, 데이터 복사 방식) 구현하고 torn read 검출 스트레스 테스트와 rwlock 대비 reader 지연을 측정한다.		준비중mac
LLAT-M03Midlock-free 메모리 회수: Hazard Pointer
hazard pointer 기반 회수를 구현해 lock-free 연결 리스트(또는 Michael-Scott 큐)에 적용하고 ASan으로 use-after-free가 없음을 확인, OS 트랙의 epoch 기반 회수와 읽기 경로 지연·메모리 상한을 비교한다(MPMC 큐 구현 자체는 DS 트랙).		준비중mac
LLAT-M04MidLMAX Disruptor 패턴 구현
링 버퍼 + sequencer + 다단계 consumer(journal→replicate→business logic) 의존 barrier를 구현하고 배치 소비가 처리량·지연에 미치는 효과를 측정한다.		준비중mac
LLAT-M05Mid스레드 간 핸드오프 지연 (ping-pong)
두 스레드가 캐시 라인 하나로 ping-pong하는 벤치마크로 왕복 지연을 측정하고, macOS QoS 클래스(P/E 코어 유도)별 차이를 기록, Linux에서의 pthread_setaffinity_np 실험 계획과 비교한다.		준비중mac
LLAT-M06MidBusy polling vs blocking 대기
busy spin(yield/wfe 포함), condition_variable, atomic::wait, 하이브리드(spin-then-park) 대기를 구현해 이벤트→처리 시작 지연 히스토그램과 CPU 사용률을 비교하고 인터럽트 vs 폴링 펌웨어 설계와 연결한다.		준비중mac
LLAT-M07MidCPU 격리 & 피닝: isolcpus·nohz_full·IRQ affinity
Linux VM에서 isolcpus/nohz_full/rcu_nocbs 부팅 옵션과 IRQ affinity를 설정하고, 격리 전후 busy loop의 인터럽션 지연(hiccup) 히스토그램을 측정한다.		외부환경필요linux
LLAT-M08Mid오더북 1: 가격 레벨 & FIFO 매칭
add/cancel/modify/execute를 지원하는 가격-시간 우선 오더북을 구현(가격 레벨 맵 + intrusive 리스트 + 주문 id 해시로 O(1) 취소)하고, 랜덤 주문 시퀀스로 참조 구현과 체결 결과를 대조한다.		준비중mac
LLAT-M09Mid오더북 2: 캐시 친화 최적화 & ITCH 리플레이
