Stage 11 · NET · Linux Networking Stack

리눅스 네트워크 스택

아이템 36Basic 12Mid 13Advanced 11학습가능 0

리눅스 네트워크 스택은 데이터센터·AI 패브릭·SmartNIC·로봇 텔레메트리 어디서나 바닥에 깔린 공통 기반이다. 이 트랙은 맥에서 ARP·IP·ICMP·UDP·TCP를 유저스페이스(가상 와이어/utun)로 직접 구현해 원리를 몸으로 확인한 뒤, Lima VM에서 sk_buff·NAPI·오프로드·netfilter·tc·XDP/eBPF 같은 커널 경로를 계측한다. Meta/Google 프로덕션 엔지니어링, NVIDIA/Arista/Broadcom 네트워킹, 임베디드 리눅스 면접의 'TCP 동작 설명'과 '패킷 드롭 디버깅' 질문을 대비하며 DCN·NETHW 트랙의 선수 과정이다.

트랙 목표

  • ARP·IPv4·ICMP·단편화·UDP를 직접 구현해 L2~L4 헤더와 규칙을 비트 수준으로 설명한다
  • TCP 상태 머신·재전송·흐름 제어·혼잡 제어(Reno/CUBIC/BBR)를 구현·시뮬레이션해 트레이드오프를 정량화한다
  • 소켓 API 시맨틱(TIME_WAIT, half-close, Nagle/delayed ACK, 버퍼 튜닝)과 이벤트 루프 서버를 올바르게 작성한다
  • sk_buff·NAPI·GRO/GSO·RSS/RPS 등 리눅스 수신/송신 경로를 추적하고 성능 영향을 측정한다
  • netns/veth/bridge, nftables/conntrack, tc qdisc, XDP/tc-BPF로 토폴로지·정책·고속 패킷 처리를 구성한다
  • 계층별 카운터와 드롭 사유로 '패킷이 사라진다' 문제를 체계적으로 진단한다

NET-M04Mid흐름 제어: 수신 윈도, Window Scaling, Zero-Window Probe
광고 윈도·window scale 옵션, 수신 앱이 멈췄을 때 zero window → persist 타이머 프로브 → window update 재개, 송수신 양측 SWS 회피(Clark/Nagle 기준)를 미니 TCP에 넣고, 느린 소비자 시나리오에서 데드락 없이 재개됨과 프로브 간격 백오프를 검증한다.		준비중mac
NET-M05MidNagle × Delayed ACK 상호작용과 TCP_NODELAY
write-write-read 요청 패턴의 RPC 클라이언트/서버로 Nagle과 delayed ACK가 겹쳐 생기는 지연(Linux 40ms / macOS delayed_ack 설정)을 재현해 요청당 지연 히스토그램을 그리고, TCP_NODELAY·writev 합치기·TCP_NOPUSH(맥)/TCP_CORK(리눅스)로 각각 해결한 결과를 비교한다.		준비중mac
NET-M06Mid혼잡 제어 1: Reno/NewReno (Slow Start, AIMD, Fast Recovery)
미니 TCP에 cwnd/ssthresh, slow start, congestion avoidance, fast recovery(Reno vs NewReno partial ACK 처리)와 RTO 시 cwnd=1을 구현하고, 병목 대역폭·버퍼 크기를 가진 B01 링크에서 cwnd-시간 그래프와 처리량을 기록해 다중 손실 시 Reno의 성능 붕괴를 보인다(RFC 5681/6582).		준비중mac
NET-M07MidSACK 스코어보드와 손실 복구 (RFC 6675, RACK 개념)
SACK 블록 생성(수신측)과 스코어보드·pipe 추정·NextSeg 선택(송신측)을 구현해 버스트 손실(한 윈도 3~10개)에서 NewReno 대비 복구 시간과 처리량을 비교하고, 시간 기반 손실 감지 RACK-TLP가 tail loss를 어떻게 줄이는지 시뮬레이션으로 확인한다.		준비중mac
NET-M08Mid혼잡 제어 2: CUBIC vs BBR 이산사건 시뮬레이션
병목 링크(대역폭, 전파 RTT, 버퍼 0.25~4 BDP) 이산사건 시뮬레이터에 Reno·CUBIC(W(t)=C(t-K)^3+Wmax)·BBRv1(BtlBw/RTprop 추정, pacing, ProbeBW 게인 주기) 모델을 구현해 처리량, 큐 지연(bufferbloat), RTT가 다른 흐름 간 Jain 공정성, 랜덤 손실 내성을 표와 그래프로 비교한다(데이터센터 CC DCQCN/HPCC는 see:DCN).		준비중mac
NET-M09Mid이벤트 루프 서버 심화: 타이머 휠, 백프레셔, C10K
OS-M12/M13 에코 서버(see:OS)를 확장해 kqueue/epoll 추상 리액터에 계층형 타이머 휠(유휴 연결 타임아웃), 연결별 쓰기 버퍼 high/low watermark 백프레셔(EVFILT_WRITE/EPOLLOUT 토글), HTTP/1.1 keep-alive 파서를 넣고 wrk로 1만 동시 연결 처리량·p99 지연·RSS를 측정한다.		준비중mac
NET-M10Midnetns·veth·bridge·VLAN 토폴로지 구성
ip netns로 호스트 4개 + 라우터 1개를 만들고 veth 쌍, Linux bridge(vlan_filtering=1, 802.1Q VLAN 10/20 분리), 라우터 네임스페이스의 ip_forward와 VLAN 서브인터페이스로 inter-VLAN 라우팅을 구성하는 재실행 가능한 셸 스크립트를 작성해 ping 매트릭스와 bridge fdb/tcpdump로 검증한다(컨테이너 namespace 전반은 see:VIRT).		외부환경필요linux
NET-M11Midnetfilter/nftables: 훅, conntrack, NAT
M10 토폴로지에서 nftables로 stateful 방화벽(ct state established,related 허용), SNAT masquerade, DNAT 포트 포워딩을 구성하고 nft monitor trace로 prerouting→forward→postrouting 경로를 확인하며, conntrack -L 상태와 C로 만든 5-튜플 미니 conntrack(타임아웃, NAT 역변환, B02 증분 체크섬) 결과를 대조한다.		외부환경필요linux
NET-M12Midtc qdisc: netem·tbf·fq_codel과 bufferbloat
veth에 tbf로 10Mbit 병목, netem으로 지연/손실/재정렬을 걸고 부하 중 ping RTT를 pfifo vs fq_codel로 비교해 bufferbloat를 수치로 보이며, 토큰 버킷과 CoDel(target 5ms, interval 100ms, sqrt 제어 법칙)을 C로 구현해 같은 트레이스에서 tc 결과와 경향을 대조한다.		외부환경필요linux
NET-M13Mid소켓 버퍼 튜닝: BDP, autotuning, keepalive, user timeout
netem으로 RTT 10/50/200ms 경로를 만들고 SO_SNDBUF/SO_RCVBUF 고정값 vs tcp_rmem autotuning에서 처리량을 측정해 BDP 공식과 대조하며, ss -tin의 cwnd/rtt/rcv_space를 해석하고 TCP_KEEPIDLE/INTVL/CNT·TCP_USER_TIMEOUT으로 죽은 피어 감지 시간을 설계값대로 맞춘다.		외부환경필요linux

NET-A01Advancedsk_buff 모델: headroom, push/pull, clone vs copy
head/data/tail/end 포인터와 skb_reserve/put/push/pull, 참조 카운트 데이터 공유 clone vs 깊은 copy, frags 배열(scatter-gather)을 가진 sk_buff 유사 구조를 C로 구현해 미니 스택의 계층 간 헤더 추가/제거를 무복사로 바꾸고, Lima VM에서 pahole로 실제 struct sk_buff 레이아웃·크기를 대조한다.		준비중mac

veth/virtio에서 ethtool -K로 tso/gso/gro를 켜고 끄며 iperf3 처리량·CPU 사용률·softirq 비율을 측정하고, tcpdump에 보이는 64KB 슈퍼패킷과 실제 와이어 세그먼트의 차이를 설명하며 GSO를 소프트웨어로 분할하는 C 함수(헤더 복제, seq/IP ID/체크섬 갱신)를 작성해 검증한다(NIC 하드웨어 오프로드는 see:NETHW).		외부환경필요linux
NET-A04AdvancedRSS Toeplitz 해시와 RPS/RFS/XPS
40바이트 키 Toeplitz 해시를 C로 구현해 Microsoft RSS 검증 벡터와 일치시키고, 인디렉션 테이블 큐 분산 균일도, 대칭(symmetric) 키로 양방향 흐름이 같은 큐에 가는지 검증한 뒤, Lima VM에서 rps_cpus/rps_flow_cnt/xps_cpus 설정 전후 softirq CPU 분포를 비교한다.		준비중mac
NET-A05AdvancedXDP 패킷 필터와 BPF 맵 (eBPF)
libbpf + clang -target bpf로 veth에 붙는 XDP 프로그램(특정 UDP 포트 XDP_DROP, 소스 IP별 per-CPU 카운터 맵, ICMP echo XDP_TX 반사)을 작성해 bpftool로 맵을 읽고, 같은 드롭을 nftables로 했을 때와 pps·CPU를 비교하며 검증기가 거부하는 경계 검사 누락 코드를 재현한다(cBPF는 B12, 검증기 개념은 see:VM-A07).		외부환경필요linux
NET-A06Advancedtc-BPF L4 로드밸런서 (Katran 스타일)
VIP:port → 백엔드 맵과 5-튜플 해시(일관 해시 Maglev 테이블)로 백엔드를 고르고 목적지 주소를 재작성(bpf_l3_csum_replace/l4_csum_replace)하는 tc ingress 프로그램과 역방향 SNAT 경로를 M10 netns 토폴로지에 붙이고, 백엔드 하나 제거 시 기존 흐름이 유지되는 비율을 측정한다.		외부환경필요linux
NET-A07Advancedaccept 확장성: SO_REUSEPORT, EPOLLEXCLUSIVE, thundering herd
N워커가 하나의 리슨 소켓을 공유하는 epoll 서버에서 thundering herd(불필요한 wakeup 수)를 측정하고, EPOLLEXCLUSIVE와 SO_REUSEPORT(커널 해시 분산, 워커 재시작 시 연결 유실)를 비교하며, SO_ATTACH_REUSEPORT_CBPF로 CPU 지역성 스티어링을 적용해 워커별 연결 분포와 p99를 기록한다.		외부환경필요linux
NET-A08Advanced제로카피 송수신: sendfile, splice, MSG_ZEROCOPY
1GB 파일 전송 서버를 read/write, sendfile, splice(pipe 경유), MSG_ZEROCOPY(SO_EE_ORIGIN_ZEROCOPY 완료 통지 처리)로 구현해 처리량·CPU·syscall 수를 비교하고, 작은 메시지에서 zerocopy가 오히려 느린 이유와 버퍼 재사용 시점 규칙을 정리한다(io_uring은 see:LLAT-A03, 커널 바이패스는 see:LLAT-A02).		외부환경필요linux
NET-A09Advanced가상 netdev 드라이버: ndo_start_xmit과 NAPI
veth처럼 쌍으로 연결된 가상 netdevice 커널 모듈을 작성해 ndo_open/stop/start_xmit, 링 버퍼 + NAPI poll 수신, netif_stop_queue/wake_queue 흐름 제어, rtnl_link_stats64·ethtool get_drvinfo를 구현하고 netns 두 개에 넣어 ping/iperf3과 ip -s link 카운터로 검증한다(모듈 기초는 see:ELX, HW NIC 디스크립터는 see:NETHW).		외부환경필요linux
NET-A10Advanced패킷 드롭 디버깅 방법론 (프로덕션 면접형)
netns 토폴로지에 rp_filter 비대칭 경로, MTU 불일치 PMTU 블랙홀, conntrack 테이블 포화, rmem 초과 UDP 드롭, nft 규칙 드롭, ARP 실패를 숨겨 넣는 장애 주입 스크립트를 만들고, ip -s link·nstat·ss -m·/proc/net/snmp·kfree_skb 드롭 사유(bpftrace/dropwatch)만으로 각 원인을 찾아내는 런북을 작성한다.		외부환경필요linux
NET-A11Advanced종합: 유저스페이스 TCP/IP 스택 상호운용
B08 utun 위에 ARP를 제외한 IP/ICMP/UDP/TCP(M01~M07, A01 skb 모델) 미니 스택을 통합해 맥의 curl이 미니 스택 HTTP 서버에서 100MB를 내려받고 iperf 유사 전송이 손실 주입 하에서도 완료되게 하며, packetdrill 스타일 회귀 테스트 스위트와 tcptrace식 시퀀스 그래프로 동작을 문서화한다.		준비중mac
