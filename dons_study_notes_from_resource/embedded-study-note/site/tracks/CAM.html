카메라 · 이미지 신호처리

아이템 29Basic 10Mid 12Advanced 7학습가능 0

카메라 파이프라인은 이미지 센서 → MIPI CSI-2 수신 → ISP → 3A 제어 → 버퍼/DMA → 드라이버(V4L2)로 이어지는, 펌웨어·하드웨어·신호처리가 한데 얽힌 대표 시스템이다. 자율주행·드론·로봇(Anduril, Tesla, Rivian, Apple 카메라 팀)에서는 센서 bring-up, 프레임 타이밍, ISP 파라미터 검증이 단골 면접 주제다. 이 트랙은 RAW 버퍼 위에서 ISP 단계를 직접 구현하며 각 단계의 의미와 하드웨어 구현 제약을 체득한다.

트랙 목표

  • 이미지 센서 동작(노출, 셔터 방식, Bayer CFA, 노이즈)을 수치 모델로 설명하고 시뮬레이션할 수 있다
  • MIPI CSI-2 패킷 구조(DI/WC/ECC/CRC)와 RAW 패킹 포맷을 파싱·검증할 수 있다
  • Black level → Demosaic → AWB → CCM → Gamma → NR → Sharpen ISP 파이프라인을 RAW 버퍼 위에서 구현하고 화질 지표로 평가할 수 있다
  • AE/AWB/AF 3A 제어 루프를 센서 지연을 고려해 설계·튜닝할 수 있다
  • 프레임 버퍼 큐, DMA, 타임스탬프, 레지스터 래칭 등 카메라 드라이버의 시스템 측면을 설명하고 V4L2로 실제 캡처할 수 있다
