차량용 임베디드

아이템 27Basic 9Mid 10Advanced 8학습가능 0

차량용 임베디드는 수십~수백 개 ECU가 CAN/CAN-FD/LIN/FlexRay/Automotive Ethernet으로 묶이고, AUTOSAR 계층·UDS 진단·ISO 26262 기능안전이 사실상 표준인 도메인이다. Tesla·Rivian·GM·현대 등 면접에서는 DBC 신호 패킹, ISO-TP/UDS, 부트로더 플래싱, E2E 보호, ASIL 분해를 실제 코드와 설계로 설명할 수 있는지를 본다.

트랙 목표

  • AUTOSAR Classic/Adaptive 계층과 ECU 전원 모드를 설명하고 최소 구현을 만들 수 있다
  • CAN/CAN-FD/LIN/FlexRay 프레임·타이밍·버스 부하를 계산하고 DBC 신호를 패킹/언패킹할 수 있다
  • ISO-TP와 UDS(ISO 14229) 서버, DTC 관리, CAN 부트로더를 구현할 수 있다
  • E2E 보호, SecOC, 워치독/프로그램 흐름 감시 같은 안전·보안 메커니즘을 구현할 수 있다
  • ISO 26262 HARA·ASIL 분해, 차량 OTA, ADAS 센서 퓨전의 설계 트레이드오프를 설명할 수 있다

SOME/IP 16바이트 헤더(Message ID=Service/Method, Length, Request ID, Protocol/Interface Version, Message Type, Return Code) 직렬화와 UDP 위 request/response, 간단한 SD OfferService/FindService를 C++로 구현해 맥 로컬 소켓으로 두 프로세스 간 통신을 검증한다.		준비중mac
AUTO-M09MidAutomotive Ethernet TSN: gPTP와 Time-Aware Shaper
gPTP의 Sync/Follow_Up/Pdelay 타임스탬프로 link delay와 offset을 계산하는 시뮬레이터, 그리고 트래픽 클래스별 게이트 제어 목록(GCL)을 받아 프레임 최악 지연을 계산하는 TAS 시뮬레이터를 작성한다.		준비중mac
AUTO-M10MidFlexRay 정적/동적 세그먼트 스케줄 설계
주기·크기가 다른 메시지 집합을 FlexRay 정적 슬롯(base cycle + repetition)에 배치하는 스케줄러를 작성하고, 슬롯 사용률과 메시지별 최대 지연을 계산해 정적/동적 세그먼트 배분 트레이드오프를 정리한다.		준비중mac

AUTO-A03AdvancedCause-Effect Chain 지연 분석과 LET
센서(10 ms) → 퓨전(20 ms) → 제어(5 ms) → 액추에이터 runnable 체인을 시뮬레이션해 최악 data age/reaction time을 측정하고, 같은 체인을 Logical Execution Time 방식으로 바꿨을 때 지연·지터 결정성을 비교한다.		준비중mac

M08 SOME/IP 위에 ara::com을 흉내 낸 C++ proxy/skeleton(FindService, 이벤트 구독, 메서드 future 반환)을 구현하고, 서비스 재시작·버전 불일치 시 동작을 테스트하며 Classic과의 설계 차이를 정리한다.		준비중mac
AUTO-A05Advanced차량 OTA: A/B 업데이트와 Uptane 메타데이터 검증
Uptane 단순화 모델(root/targets/snapshot/timestamp 서명 메타데이터, 버전 롤백 방지)을 검증하는 Python 클라이언트와 ECU A/B 슬롯 스위치(시험 부팅 → 확정/자동 롤백) 상태 머신을 구현하고, 변조·재생·freeze 공격 시나리오를 테스트한다.		준비중mac
AUTO-A06AdvancedCAN 보안: SecOC (MAC + Freshness Value)
AES-CMAC 기반 truncated MAC과 freshness counter(전송 시 하위 비트만 송신, 수신 측 재구성)를 붙인 SecOC 송수신 모듈을 구현하고, 재생·위조·카운터 동기 상실 시나리오와 CAN-FD 페이로드 오버헤드를 평가한다.		준비중mac
AUTO-A07AdvancedADAS 센서 퓨전: 레이더+카메라 객체 레벨 융합
합성 레이더(거리·속도 정확) + 카메라(횡위치·분류 정확) 객체 리스트를 받아 게이팅·연관·칼만 갱신·트랙 생성/삭제를 수행하는 융합기를 작성하고, 단일 센서 대비 위치 RMSE와 false track 비율을 비교한다.		준비중mac
AUTO-A08AdvancedCAN 최악 응답 시간 분석과 게이트웨이 설계
메시지 집합의 우선순위·주기·지터로 CAN WCRT를 반복 계산하는 도구를 구현하고 B08 시뮬레이터 최악 관측값과 비교한 뒤, 두 버스 사이 게이트웨이(필터·라우팅 테이블·큐) 추가 시 end-to-end 마감 충족 여부를 분석한다.		준비중mac
