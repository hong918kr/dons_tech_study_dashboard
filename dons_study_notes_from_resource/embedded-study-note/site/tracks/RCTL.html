로봇 제어 알고리즘

아이템 32Basic 11Mid 12Advanced 9학습가능 0

로봇·모터 펌웨어의 핵심인 제어 알고리즘(PID, 상태공간, LQR, Kalman, FOC, 기구학, 경로계획)을 시뮬레이션 플랜트 위에서 직접 구현하는 트랙이다. Nimble Robotics 리크루터 단계 탈락의 교훈처럼 로보틱스 펌웨어 면접은 FOC·CAN 기반 모터 제어와 PID 실무 디테일(anti-windup, 이산화, 미분 필터)을 깊게 묻는다.

트랙 목표

  • 이산 PID를 anti-windup·미분 필터·피드포워드·cascade까지 실무 수준으로 구현·튜닝할 수 있다
  • 상태공간 모델, 극배치, LQR, Kalman/EKF를 구현하고 시뮬레이션으로 검증할 수 있다
  • Clarke/Park, SVPWM, 전류·속도 루프를 갖춘 FOC 파이프라인을 PMSM 모델 위에서 완성할 수 있다
  • 2-link 팔의 FK/IK·자코비안과 사다리꼴/S-curve 궤적을 생성할 수 있다
  • A*/RRT 경로계획과 MPC 입문, CAN 기반 모터 제어 인터페이스를 설계할 수 있다

Basic · 11개
RCTL-B01Basic플랜트 모델과 개루프 응답
1차 모터 속도 모델 τ·dω/dt + ω = K·u를 이산 시뮬레이션(C)으로 만들고 스텝 응답 로그에서 K와 τ를 63.2% 규칙과 최소제곱으로 식별해 참값과 비교한다(모델링 심화는 see:SIM).		준비중mac
RCTL-B02Basic이산 PID 구현과 기본 튜닝
1kHz 고정 주기 위치형 PID를 C로 구현해 B01 플랜트를 폐루프로 시뮬레이션하고, Kp/Ki/Kd 변화에 따른 상승시간·오버슈트·정상상태 오차 표를 만든 뒤 Ziegler-Nichols 계단 응답법으로 초기 이득을 정한다.		준비중mac
RCTL-B03BasicAnti-windup: Clamping vs Back-calculation
출력 포화가 있는 플랜트에서 큰 스텝 명령 시 windup 현상을 재현하고, 조건부 적분(clamping)과 back-calculation(Kt 이득) anti-windup을 구현해 오버슈트·정착시간을 비교한다.		준비중mac
RCTL-B04Basic미분항: 필터와 Derivative-on-Measurement
측정 잡음이 있는 시뮬레이션에서 순수 미분, 1차 LPF 미분(N 계수), derivative-on-measurement를 비교해 출력 잡음 RMS와 setpoint kick 크기를 측정한다.		준비중mac
RCTL-B05Basic이산화 방법과 증분형 PID
연속 PI/PID를 forward Euler, backward Euler, Tustin으로 이산화한 계수를 유도·구현해 샘플 주기를 늘려가며 응답 차이를 보이고, 증분형 PID로 bumpless 수동→자동 전환을 구현한다.		준비중mac
RCTL-B06BasicCascade 제어: 위치 → 속도 → 전류
2차 모터 모델(전류·속도·위치)에 내부 전류 PI(10kHz)·속도 PI(1kHz)·위치 P(100Hz) cascade를 구현하고, 내부 루프 대역폭이 충분히 높지 않을 때 외부 루프가 불안정해지는 것을 보인다.		준비중mac
RCTL-B07Basic사다리꼴 속도 프로파일
최대 속도·가속도 제한으로 사다리꼴 프로파일(최고속도 도달 못 하는 삼각 프로파일 포함)을 생성하는 함수를 작성해 고정 주기 샘플링 시 최종 위치 오차·속도 연속성을 검증한다.		준비중mac
RCTL-B08BasicS-curve(저크 제한) 프로파일
최대 저크·가속도·속도 제한의 7구간 S-curve를 생성(제한에 따라 구간이 사라지는 경우 포함)하고, B07 사다리꼴과 동일 이동에서 소요 시간·가속도 연속성을 비교한다.		준비중mac
RCTL-B09Basic피드포워드: 속도·가속도 FF
B06 서보에 속도·가속도(관성) 피드포워드를 추가하고 B07/B08 궤적 추종 시 추종 오차 RMS·최대값을 FF 유무별로 비교, 모델 오차(관성 ±20%)에 대한 민감도를 측정한다.		준비중mac
RCTL-B10Basic2-link 팔 정기구학(FK)과 작업공간
평면 2-link(l1,l2) FK 함수를 구현하고 관절 제한을 고려한 작업공간 경계를 샘플링으로 그리며, 동차 변환 행렬로 일반화한 FK와 결과가 일치하는지 테스트한다.		준비중mac
RCTL-B11Basic2-link 역기구학(IK): 해석해와 특이점
코사인 법칙 기반 해석적 IK(atan2 사용)를 구현하고 FK∘IK 왕복 오차, 도달 불가 입력, 완전히 펴진 특이 자세 근처 수치 거동을 테스트한다.		준비중mac
Mid · 12개
RCTL-M01Mid상태공간 모델과 이산화
DC 모터(전류·속도·위치) 상태공간 A,B,C를 세우고 행렬 지수(Padé 또는 급수)로 ZOH 이산화를 구현해 Euler 이산화와 비교; 가제어성·가관측성 행렬 랭크를 확인하는 작은 행렬 라이브러리를 C로 작성한다.		준비중mac
RCTL-M02Mid극배치 상태 피드백과 Luenberger 관측기
M01 모델에 Ackermann 공식으로 극배치 이득 K를 계산하고, 속도만 측정할 때 Luenberger 관측기로 전체 상태를 추정해 관측기 극 위치별 추정 수렴과 폐루프 응답을 비교한다.		준비중mac
RCTL-M03MidLQR: 이산 Riccati와 도립진자
선형화된 카트-폴 도립진자 모델에 이산 대수 Riccati 방정식을 반복으로 풀어 LQR 이득을 계산하고, Q/R 가중치 변화에 따른 응답·입력 크기를 비교; 비선형 모델 시뮬레이션에서 수렴 영역을 확인한다.		준비중mac
RCTL-M04Mid1D Kalman 필터: 위치·속도 추정
등속 모델 + 잡음 위치 측정 시뮬레이션에서 2상태 Kalman 필터를 C로 구현하고, Q/R 변화에 따른 추정 지연·잡음을 비교하며 NIS/NEES 일관성 검사로 튜닝이 맞는지 판정한다.		준비중mac
RCTL-M05MidEKF: 비선형 2D 로봇 위치 추정
unicycle 모션 모델 + 랜드마크 range-bearing 측정으로 EKF를 구현(자코비안 해석적 유도, 각도 wrap 처리)하고 오도메트리만 쓴 추정 대비 오차와 공분산 타원 일관성을 비교한다.		준비중mac
RCTL-M06Mid자코비안과 속도 IK (Damped Least Squares)
평면 3-link 팔의 자코비안을 구하고 의사역행렬 vs damped least squares 반복 IK로 목표 위치를 추종시켜 특이점 근처 관절 속도 폭주와 감쇠 계수 효과를 비교한다.		준비중mac
RCTL-M07MidClarke/Park 변환 (float·고정소수점)
Clarke(abc→αβ), Park(αβ→dq)와 역변환을 float와 Q15(DSP-B11 LUT sin/cos 재사용)로 구현하고, 평형 3상 입력에서 dq가 상수가 되는지·왕복 오차·전력 불변/진폭 불변 스케일 차이를 테스트한다.		준비중mac
RCTL-M08MidSVPWM 구현
αβ 전압 명령에서 섹터 판정·인접 벡터 작용 시간·3상 듀티를 계산하는 SVPWM과 min-max 주입 방식 등가 구현을 작성해 둘이 일치함을 확인하고, 사인 PWM 대비 DC 버스 이용률 15.5% 향상을 보인다.		준비중mac
RCTL-M09MidFOC 전류 루프: PMSM 모델 위에서
dq 좌표 PMSM 모델(Rs, Ld, Lq, λ, 극쌍)을 시뮬레이션하고 Clarke/Park→d/q PI(id=0 제어)→역Park→SVPWM 파이프라인을 20kHz로 구현해 토크 스텝 응답, 교차결합 디커플링 효과, 전압 포화를 확인한다.		준비중mac
RCTL-M10MidFOC 속도 루프와 엔코더 각도 정렬
엔코더 기계각→전기각 변환과 초기 정렬 절차(d축 전류 주입)를 구현하고, 정렬 오차가 있을 때 토크 상수 저하를 측정한 뒤 M09 위에 속도 PI cascade를 붙여 부하 외란 응답을 평가한다.		준비중mac
RCTL-M11Mid모터 파라미터 식별: R·L·Kt·관성 최소제곱 추정
시뮬레이션한 DC/PMSM 모터에 전압 스텝·정현 입력을 주고 전류·속도 로그로 R, L, Kt, J, 마찰을 최소제곱으로 추정해 참값 대비 오차와 노이즈 민감도를 평가한다(경로 계획은 see:AUTON).		준비중mac
RCTL-M12Mid다축 보간: 선형·원호 보간과 G-code 실행
G0/G1/G2/G3 파서와 B07 사다리꼴 프로파일을 결합한 다축 선형·원호 보간기를 구현하고, 경로 오차와 코너 속도 제한(junction deviation)을 측정한다.		준비중mac
Advanced · 9개
RCTL-A01AdvancedMPC 입문: 제약 있는 이중적분기
이중적분기에 입력·상태 제약이 있는 선형 MPC(예측 구간 N)를 QP로 구성하고 projected gradient 또는 간단한 active-set으로 풀어 LQR(제약 무시+포화) 대비 제약 준수·성능을 비교하며 계산 시간을 측정한다.		준비중mac
RCTL-A02Advanced센서리스 FOC: 관측기와 PLL
M09 PMSM 모델에서 back-EMF 관측기(또는 sliding-mode observer) + PLL로 각도·속도를 추정해 FOC에 사용하고, 저속 영역 추정 실패와 오픈루프 기동→폐루프 전환 로직을 구현한다.		준비중mac
RCTL-A03Advanced주파수 응답 식별과 안정 여유
플랜트에 chirp/sine-sweep을 넣어 입출력으로 주파수 응답을 추정하고 개루프 Bode 선도에서 이득·위상 여유를 계산; 릴레이 피드백 auto-tune으로 임계 이득·주기를 구해 PID를 자동 설정한다.		준비중mac
RCTL-A04Advanced제어 루프 실시간 구현: 지연·지터의 영향
B06 서보 시뮬레이션에 계산 지연(0~1 샘플)과 랜덤 지터를 넣어 위상 여유 손실(ω·Td)을 이론·시뮬레이션으로 비교하고, 지연 보상(상태 예측)과 '측정 즉시 출력' 스케줄링 패턴을 구현한다(see:RTOS).		준비중mac
RCTL-A05Advanced2-link 동역학과 Computed Torque 제어
라그랑지안으로 2-link 팔의 M(q), C(q,q̇), G(q)를 유도·구현해 시뮬레이션하고 독립 관절 PD와 computed torque 제어의 궤적 추종 오차를 비교, 질량 파라미터 오차에 대한 강건성을 평가한다.		준비중mac
RCTL-A06Advanced이동 로봇 궤적 추종: Pure Pursuit·Stanley
unicycle/bicycle 모델에서 pure pursuit(lookahead 거리)와 Stanley 제어기를 구현해 곡선 경로 추종 시 횡오차·조향 입력을 속도별로 비교한다.		준비중mac
RCTL-A07AdvancedCAN 기반 모터 드라이브 인터페이스 (CiA 402)
CiA 402 드라이브 상태기계(Switch On Disabled→Ready→Switched On→Operation Enabled, Fault)와 controlword/statusword, RPDO/TPDO 매핑, SYNC 기반 주기 위치 명령을 C로 구현하고 가상 CAN 버스(host 소켓 mock)로 다축 동기 이동·하트비트 손실 시 안전 정지를 테스트한다.		준비중mac
RCTL-A08Advanced임피던스 제어 1-DOF
스프링-댐퍼 벽 접촉 모델을 가진 1-DOF 액추에이터 시뮬레이션에서 순수 위치 제어와 임피던스 제어(가상 M, B, K)를 비교해 접촉력 피크·안정성을 측정한다.		준비중mac
RCTL-A09Advanced모터 제어 안전·진단과 CI 테스트
과전류·과전압·엔코더 단선·추종 오차 초과·통신 타임아웃 결함 검출과 반응(토크 차단, 제어 정지, 브레이크)을 구현하고, 플랜트 시뮬레이션 기반 폐루프 테스트를 CI에서 돌리는 하네스(시나리오 + 합격 기준)를 만든다.		준비중mac
