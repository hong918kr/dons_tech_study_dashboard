그래픽스 · 3D 자료구조

아이템 26Basic 9Mid 10Advanced 7학습가능 0

그래픽스 기초 수학(벡터·행렬·쿼터니언·투영)과 래스터화, 그리고 BVH·k-d tree·octree·half-edge 같은 3D 자료구조는 렌더링뿐 아니라 로봇 인지, LiDAR 포인트 클라우드, 충돌 검사, 시뮬레이션의 공통 기반이다. GPU/게임/로보틱스 면접(NVIDIA, Apple, Tesla, Anduril)에서는 삼각형 래스터화, ray-triangle 교차, BVH 구축, k-NN 질의를 직접 짜게 하는 문제가 자주 나온다. 본격 렌더링 기법은 REND 트랙에 맡기고, 여기서는 기초 수학과 자료구조를 손으로 구현하고 검증한다.

트랙 목표

  • 벡터·행렬·쿼터니언과 모델/뷰/투영 변환을 직접 구현하고 수치적으로 검증할 수 있다
  • 직선·삼각형 래스터화, 클리핑, 무게중심 보간, z-buffer를 소프트웨어로 구현할 수 있다
  • 메시 표현(indexed mesh, half-edge)과 메시 포맷을 다루고 위상 질의를 수행할 수 있다
  • BVH, octree, k-d tree, spatial hash를 구축·질의하고 성능을 브루트포스와 비교할 수 있다
  • 부동소수점 견고성, 고정소수점 래스터화, 타일 기반 구조 등 하드웨어/임베디드 관점의 제약을 설명할 수 있다

GFX-B01Basic벡터 연산: Dot·Cross·Normalize와 기하 의미
vec2/vec3 라이브러리(dot, cross, length, normalize, project, reflect)를 C로 작성하고, 점이 직선 왼쪽/오른쪽인지 판정, 삼각형 면적·법선 계산, 0벡터 normalize 처리 등을 epsilon 비교 단위 테스트로 검증한다.		준비중mac
GFX-B02Basic4x4 행렬 변환: Row/Column-Major와 합성 순서
mat4 곱, translate/rotate(x,y,z)/scale 생성 함수를 column-major 저장으로 구현하고, T*R*S와 S*R*T가 점에 다른 결과를 주는 테스트와 row-major로 해석했을 때 전치 관계가 됨을 보이는 테스트를 작성한다.		준비중mac
GFX-B03Basic역행렬과 법선 변환(Inverse-Transpose)
cofactor 방식 일반 4x4 역행렬과 R|t 구조를 이용한 affine 빠른 역행렬을 구현해 M*M^-1 ≈ I를 검증하고, 비균등 스케일에서 법선을 M으로 변환하면 수직성이 깨지고 (M^-1)^T로는 유지됨을 테스트로 보인다.		준비중mac
GFX-B04Basic쿼터니언 회전과 Slerp
axis-angle → quat, quat 곱, 벡터 회전(q v q*), quat ↔ mat3 변환, slerp(가까운 경로 선택, 작은 각도 fallback)를 구현하고, 무작위 회전 1만 개에 대해 행렬 결과와의 일치와 정규화 드리프트를 측정한다.		준비중mac
GFX-B05Basic카메라와 투영: LookAt·Perspective·NDC·Viewport
lookAt 뷰 행렬, perspective(fovy, aspect, near, far)와 orthographic 투영, perspective divide, viewport 변환을 구현하고, 알려진 3D 점들이 기대 픽셀 좌표와 깊이 값으로 매핑되는지 테스트하며 OpenGL(-1..1)과 Metal/D3D(0..1) 깊이 범위 차이를 반영한다.		준비중mac
GFX-B06Basic클리핑: Cohen-Sutherland와 Sutherland-Hodgman
2D 사각형에 대한 Cohen-Sutherland 선분 클리핑과, 동차 좌표에서 near 평면 포함 6개 평면에 대한 Sutherland-Hodgman 다각형 클리핑을 구현하고, 카메라 뒤로 걸친 삼각형이 올바르게 잘리는지 테스트한다.		준비중mac
GFX-B07BasicBresenham 직선·원 래스터화 (정수 전용)
8개 옥탄트를 모두 처리하는 Bresenham 직선과 midpoint 원 알고리즘을 정수 연산만으로 구현해 PPM으로 출력하고, float DDA 결과와 픽셀 단위로 비교하며 시작/끝점 대칭성(A→B와 B→A 동일 픽셀)을 검증한다.		준비중mac
GFX-B08Basic삼각형 래스터화: Edge Function과 Top-Left Rule
바운딩 박스 + edge function 방식 삼각형 래스터라이저를 작성하고 top-left fill rule을 적용해, 사각형을 두 삼각형으로 나눠 그렸을 때 모든 픽셀이 정확히 한 번만 칠해지는지(overdraw 카운트 버퍼) 검증한다.		준비중mac
GFX-B09Basic무게중심 보간과 Perspective-Correct 보간
래스터라이저에 barycentric 기반 색/UV 보간을 추가하고, 체커보드 텍스처를 입힌 기울어진 평면을 affine 보간과 1/w 기반 perspective-correct 보간으로 각각 렌더링해 왜곡 차이를 이미지로 비교한다.		준비중mac

GFX-M01MidZ-Buffer와 깊이 정밀도: Reversed-Z
z-buffer를 래스터라이저에 넣어 교차하는 삼각형을 올바르게 그리고, near/far 비율을 바꿔 가며 24비트 정수 깊이, float32 표준 깊이, float32 reversed-Z에서 구분 가능한 최소 거리 차이를 측정·그래프로 비교한다.		준비중mac
GFX-M02Mid컬링: Backface·Frustum (AABB/Sphere vs Plane)
뷰-투영 행렬에서 6개 frustum 평면을 추출하는 함수, sphere/AABB vs frustum 판정(p-vertex/n-vertex 최적화), 화면 공간 winding 기반 backface 컬링을 구현하고, 무작위 객체 1만 개 장면에서 컬링 비율과 오판정(false negative 0) 여부를 검증한다.		준비중mac
GFX-M03Mid메시 포맷: OBJ/PLY 로더와 Indexed Mesh
OBJ(v/vt/vn, 다각형 fan 삼각분할)와 binary PLY 로더를 작성하고, 해시로 정점을 중복 제거해 indexed triangle mesh를 만든 뒤 면적 가중 정점 법선을 계산하며, 정점/인덱스 수와 메모리 크기를 원본과 비교한다.		준비중mac
GFX-M04MidHalf-Edge 메시 자료구조
indexed mesh에서 twin 매칭으로 half-edge 구조를 구축하고 정점 one-ring 순회, 면 인접 면, 경계 에지 검출, 비다양체 에지 거부를 구현해, 닫힌 메시에서 오일러 특성 V−E+F=2를 검증한다.		준비중mac
GFX-M05MidRay-Triangle(Möller-Trumbore)과 Ray-AABB(Slab) 교차
Möller-Trumbore ray-triangle 교차(t, u, v 반환)와 slab 방식 ray-AABB 교차(1/dir 사전계산, NaN/무한대 처리)를 구현하고, 무작위 레이와 해석적 정답 비교 테스트 및 평행 레이 같은 경계 케이스를 검증한다.		준비중mac
GFX-M06MidBVH 구축과 순회: Median Split vs SAH
삼각형 메시에 대해 median split과 binned SAH 두 방식으로 BVH를 구축해 평탄화된 배열 노드(32바이트 정렬)로 저장하고, 스택 기반 순회(가까운 자식 우선)로 레이 100만 개를 쏴서 브루트포스 대비 정답 일치와 노드 방문 수·속도를 비교한다.		준비중mac
GFX-M07MidOctree: 포인트 클라우드 삽입·반경 질의·LOD
버킷 크기와 최대 깊이를 갖는 포인트 octree를 구현해 삽입, 반경 질의, 레벨별 대표점(voxel 중심) LOD 생성을 지원하고, 100만 점 데이터에서 브루트포스 대비 질의 결과 일치와 속도, 메모리 사용량을 측정한다.		준비중mac
GFX-M08Midk-d Tree: 구축과 k-최근접 이웃(k-NN) 질의
median 분할(nth_element)로 3D k-d tree를 구축하고 최대 힙을 쓰는 k-NN 질의(분할 평면 거리로 가지치기)를 구현해, 무작위 점·질의에 대해 브루트포스와 결과가 완전히 일치하는지와 k, 점 개수에 따른 속도를 측정한다.		준비중mac
GFX-M09MidSpatial Hashing과 Uniform Grid: Broad-Phase 충돌
셀 크기 기반 정수 좌표 해시(큰 소수 XOR) 공간 해시를 구현해 움직이는 구 1만 개의 충돌 후보 쌍을 매 프레임 계산하고, O(n²) 결과와 쌍 집합 일치 및 셀 크기에 따른 성능 변화를 측정한다.		준비중mac
GFX-M10Mid정점 캐시 최적화와 인덱스 버퍼 재정렬
FIFO/LRU 정점 캐시 시뮬레이터로 ACMR(삼각형당 캐시 미스)을 측정하는 도구와 Forsyth 선형 속도 정점 캐시 최적화 알고리즘을 구현하고, 무작위 순서·원본·최적화 후 ACMR과 정점 버퍼 재정렬 후 fetch 지역성을 비교한다.		준비중mac

GFX-A02Advanced타일 기반 렌더링(TBR) 비닝 모델
화면을 32x32 타일로 나눠 삼각형을 타일 리스트에 비닝하는 단계와 타일별 on-chip 색/깊이 버퍼로 래스터화하는 단계를 구현하고, 즉시 모드 렌더링 대비 프레임버퍼 DRAM 읽기/쓰기 바이트와 비닝 메모리 오버헤드를 장면별로 비교한다.		준비중mac
GFX-A03AdvancedHierarchical Z 버퍼와 Occlusion Culling
z-buffer에서 max-reduction mip 피라미드(HZB)를 생성하고, 객체 AABB의 화면 사각형 크기에 맞는 mip 레벨 하나로 가려짐을 판정하는 컬링을 구현해, 도시 장면에서 컬링 비율과 보수성(가시 객체를 절대 버리지 않음)을 검증한다.		준비중mac
GFX-A04AdvancedLBVH: Morton 코드 기반 병렬 BVH 구축과 Refit
프리미티브 중심을 30비트 Morton 코드로 변환·radix 정렬하고 Karras 방식으로 내부 노드를 구성하는 LBVH를 구현해 SAH BVH 대비 구축 시간과 순회 비용을 비교하며, 정점이 움직일 때 상향식 AABB refit과 품질 저하를 측정한다.		준비중mac
GFX-A05Advanced메시 단순화: Quadric Error Metrics
정점별 quadric 누적, 최적 붕괴 위치 계산, 우선순위 큐 기반 edge collapse(면 뒤집힘·위상 검사 포함)를 half-edge 메시에 구현하고, 삼각형 수 50%/10%/1%에서 Hausdorff 거리 근사 오차를 측정한다.		준비중mac
GFX-A06Advanced기하 견고성: Robust Predicate와 Watertight 교차
naive orient2d가 거의 공선인 점에서 일관성 없는 결과를 내는 입력을 찾아 재현하고, 오차 한계 필터 + 확장 정밀도(또는 정수 좌표) 기반 robust orient2d와 watertight ray-triangle 교차를 구현해 공유 에지를 지나는 레이가 새지 않음을 검증한다.		준비중mac
GFX-A07Advanced메시 압축: 정점 양자화와 Octahedral 법선 인코딩
AABB 기준 16비트 위치 양자화, octahedral 매핑 기반 2x8비트/2x16비트 법선 인코딩, half-float UV를 구현하고 원본 대비 위치 오차(최대·RMS), 법선 각도 오차, 메모리 절감률을 측정한다.		준비중mac
