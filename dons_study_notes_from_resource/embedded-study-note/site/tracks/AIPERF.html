Stage 7 · AIPERF · AI Workloads & Perf Metrics

AI 워크로드 · 성능 지표

아이템 30Basic 9Mid 12Advanced 9학습가능 0

AI 가속기 회사의 엔지니어는 'TOPS가 높으면 빠른가?'라는 질문에 숫자로 답할 수 있어야 한다. 이 트랙은 TOPS·TOPS/W·지연·처리량·TTFT·tokens/s 같은 지표의 정확한 정의부터 roofline·산술 강도·KV cache 크기·트랜스포머 FLOP 계산, MLPerf 방법론, 전력 측정까지를 직접 계산하고 맥에서 실측하며 익힌다. NPU 아키텍처·성능 엔지니어 면접에서는 '이 레이어는 이 칩에서 memory-bound인가?', '7B 모델 decode tokens/s 상한은?' 같은 봉투 뒷면 계산이 거의 항상 나온다.

트랙 목표

  • TOPS, TOPS/W, 지연 백분위, 처리량, TTFT/TPOT, MFU/MBU 등 AI 성능 지표를 정확히 정의하고 계산할 수 있다
  • 연산자·모델의 FLOP과 바이트를 세고 roofline으로 memory-bound/compute-bound를 판정할 수 있다
  • 배치 크기, KV cache, 양자화, 시퀀스 길이가 LLM·CNN 성능에 미치는 영향을 정량 모델로 예측하고 실측과 대조할 수 있다
  • MLPerf Inference/Tiny 방법론과 통계적으로 신뢰할 수 있는 벤치마크·전력 측정 방법을 적용할 수 있다
  • 가속기 스펙 시트를 비판적으로 읽고 실제 워크로드 성능을 추정·비교하는 보고서를 작성할 수 있다

AIPERF-A01Advanced가속기 스펙 시트 비판적 분석
공개 엣지 AI 칩 2–3종의 스펙(피크 TOPS, DRAM 대역폭, on-chip SRAM, 지원 정밀도)으로 ResNet-50 batch 1 지연과 7B LLM decode tokens/s를 roofline 기반으로 추정하고, 공개 벤치마크 결과와 비교해 utilization 차이와 원인을 1페이지 분석 보고서로 작성한다.		준비중mac
AIPERF-A02AdvancedAttention IO 복잡도: Naive vs FlashAttention
naive attention(Θ(Nd + N²) HBM 접근)과 tiled FlashAttention(Θ(N²d²/M) 접근)의 HBM 바이트를 시퀀스 길이 N, head_dim d, SRAM 크기 M에 대해 계산하는 모델을 만들고, GPGPU-A03 커널 실측 시간과 비교해 모델 정확도를 평가한다.		준비중mac
AIPERF-A03AdvancedLLM 서빙 스케줄링: Continuous Batching 시뮬레이션
요청 도착(포아송), 입력/출력 길이 분포, prefill·decode 단계 시간 모델(M03/M06 기반)을 가진 서빙 시뮬레이터를 작성해 static batching, continuous batching, chunked prefill을 비교하고 TTFT p99·TPOT·goodput 곡선을 그린다.		준비중mac
AIPERF-A04Advanced양자화의 성능-정확도 트레이드오프 실측

AIPERF-A05Advanced분산 추론 통신 비용: Tensor/Pipeline Parallel
tensor parallel(층당 all-reduce 2회)과 pipeline parallel(스테이지 간 활성화 전송, 버블)을 링크 대역폭·지연 파라미터로 모델링해 7B/70B 모델의 decode 토큰 지연과 처리량을 칩 수 1~8에서 계산하고, 칩 간 링크가 느린 엣지 환경에서의 최적 분할을 제시한다.		준비중mac
AIPERF-A06Advanced성능 회귀 감지: 노이즈와 통계 검정
같은 바이너리 반복 측정으로 노이즈 분포(열, 백그라운드, 코어 배치)를 수집하고, 부트스트랩 신뢰구간과 Mann-Whitney U 검정으로 두 빌드 간 회귀를 판정하는 스크립트를 작성해 인위적 2%/5% 지연 주입을 검출력과 오탐률로 평가한다.		준비중mac
AIPERF-A07Advanced열 스로틀링과 지속 성능
GPU/ANE 추론을 20분 이상 연속 실행하며 처리량·전력·(가능하면) 온도를 시계열로 기록해 스로틀링 시작 시점과 지속 성능 비율을 구하고, 벤치마크 보고 시 워밍업·쿨다운·환경 온도 조건을 명시하는 규칙을 정리한다.		준비중mac
