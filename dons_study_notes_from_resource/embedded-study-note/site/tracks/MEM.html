Stage 3 · MEM · Memory Systems

메모리 시스템

아이템 36Basic 12Mid 14Advanced 10학습가능 2

메모리 시스템은 SoC·AI 가속기·SSD 성능과 신뢰성을 좌우하는 병목이다. DRAM 타이밍·컨트롤러 스케줄링·ECC·캐시 일관성·NAND/FTL을 직접 시뮬레이터와 측정 코드로 구현하면서, 실리콘 bring-up/검증과 스토리지 펌웨어 면접에서 나오는 '왜 느린가/왜 깨지는가' 질문에 숫자로 답할 수 있게 한다.

트랙 목표

  • DRAM 조직·명령·타이밍과 주소 매핑을 시뮬레이터로 구현한다
  • 메모리 컨트롤러 스케줄링·리프레시·뱅크 병렬성이 성능에 주는 영향을 정량화한다
  • Hamming/SECDED/RS ECC와 memtest(March) 패턴을 구현하고 RAS 정책을 설계한다
  • MESI/MOESI·디렉터리 일관성과 메모리 순서 모델을 시뮬레이션·실측으로 검증한다
  • 포인터 체이싱·STREAM·roofline으로 지연/대역폭을 측정하고 해석한다
  • NAND/FTL(매핑, GC, WL, bad block, 전원 차단 복구)을 SSD 펌웨어 수준으로 구현한다

MEM-B02BasicDRAM 명령과 타이밍: ACT/RD/PRE, tRCD·tRP·tRAS
단일 뱅크 상태머신(IDLE/ACTIVE)과 타이밍 체커를 구현해 사이클 단위 명령 트레이스를 입력하면 tRCD/CL/tRP/tRAS/tRC/tWR 위반을 검출·보고하고, DDR4-3200 데이터시트 값으로 ns↔cycle 변환을 검증한다.		준비중mac
MEM-B03BasicRow hit/miss/conflict와 페이지 정책
접근 트레이스(순차, stride, 랜덤)에 대해 row hit/empty/conflict를 분류하고 open-page vs close-page 정책별 평균 지연을 계산하는 시뮬레이터를 작성해 어느 워크로드에 어느 정책이 유리한지 정리한다.		준비중mac
MEM-B04BasicDDR4 vs DDR5 vs LPDDR4/5 구조 비교와 대역폭 계산
DDR4/DDR5(2×32b 서브채널, BL16)/LPDDR5(x16 채널, WCK) 비교표를 만들고 데이터율×버스폭×채널 수로 피크 대역폭을, 캐시라인 64B 전송에 필요한 burst 수를 계산하는 도구를 작성한다.		준비중mac
MEM-B05Basic리프레시: tREFI, tRFC와 성능 손실
밀도별 tRFC와 tREFI(정상/고온 2x)를 넣어 리프레시로 잃는 시간 비율을 계산하고, all-bank vs per-bank(same-bank) refresh 스케줄을 시뮬레이터에 넣어 요청 지연 분포 변화를 측정한다.		준비중mac
MEM-B06Basic패리티와 Hamming(7,4): 단일 비트 정정
짝수 패리티와 Hamming(7,4) 인코더/디코더를 비트 연산으로 구현하고, 모든 데이터×모든 단일 비트 오류 위치를 주입해 100% 정정되는지, 2비트 오류에서는 오정정되는지 전수 테스트한다.		준비중mac
MEM-B07BasicSECDED Hamming(72,64) 구현
64비트 데이터에 8비트 체크(7 Hamming + 전체 패리티)를 붙이는 SECDED 인코더/디코더와 신드롬→비트 위치 테이블을 구현하고 단일 비트 전수 정정, 2비트 무작위 100만 회 검출(오정정 0)을 테스트한다.		준비중mac
MEM-B08Basic메모리 테스트 패턴: walking 1/0, address-in-address
결함 주입 가능한 메모리 모델(stuck-at-0/1, 데이터 라인 단락, 주소 라인 alias)을 만들고 data bus/address bus/device 테스트(Barr 스타일)를 구현해 결함 종류별 탐지 여부 매트릭스를 출력한다.		준비중mac
MEM-B09BasicMarch 테스트: MATS+, March C-
March 표기(⇑(w0); ⇑(r0,w1); ⇓(r1,w0)...)를 해석하는 작은 인터프리터를 작성해 MATS+, March C-, March B를 실행하고 SAF/TF/CFin/AF 결함 모델별 탐지율 표를 만든다.		준비중mac
MEM-B10Basic포인터 체이싱으로 메모리 지연 측정
랜덤 순열 linked list(캐시라인 단위)로 의존 load 체인을 만들어 4KB–1GB working set별 ns/load를 측정하고, M2의 L1/L2/SLC/DRAM 경계와 TLB 영향(페이지 단위 stride)을 그래프로 식별한다.		준비중mac
MEM-B11Basic메모리 대역폭 측정: STREAM Copy/Scale/Add/Triad
STREAM 4커널을 직접 구현(배열 크기 ≥ 4×LLC, 컴파일러 최적화 확인)해 스레드 수 1–8별 GB/s를 측정하고, M2 LPDDR5 이론 대역폭 대비 효율과 쓰기 할당(write-allocate) 영향을 분석한다.		준비중mac
MEM-B12BasicNAND 플래시 기초: 페이지/블록, program/erase 제약
NAND 칩 모델(planes/blocks/pages, 페이지 OOB, 블록 내 순차 program 강제, erase 단위, P/E 카운트, SLC/TLC 파라미터)을 C로 작성하고 제약 위반 시 에러를 반환하는지 테스트한다.		준비중mac
Mid · 14개 · 학습가능 2
MEM-M01Mid메모리 컨트롤러 스케줄링: FCFS vs FR-FCFS
다중 뱅크 요청 큐 기반 MC 시뮬레이터를 작성해 FCFS, FR-FCFS, FR-FCFS+age cap 정책을 구현하고 혼합 트레이스에서 처리량·평균/최대 지연을 비교, 읽기/쓰기 큐 분리와 write drain 워터마크도 추가한다.		준비중mac
MEM-M02Mid주소 매핑 정책과 뱅크 병렬성
RoBaRaCoCh, RoRaBaChCo, XOR 해싱 매핑을 MC 시뮬레이터에 연결해 stride(64B–64KB) 접근별 bank conflict율·처리량을 측정하고 power-of-two stride 병목을 XOR 해싱이 해소함을 보인다.		준비중mac
MEM-M03Mid다단계 캐시 시뮬레이터: inclusive vs exclusive
set-associative L1/L2 시뮬레이터(LRU/PLRU, write-back/write-through, write-allocate 여부, inclusive/exclusive)를 작성해 트레이스별 3C miss 분류와 DRAM 트래픽(bytes)을 비교한다.		준비중mac
MEM-M04Mid일관성 트래픽 실측: 공유 캐시라인 경합과 코어 수
공유 카운터 atomic 증가, 코어별 카운터, 읽기 전용 공유 3가지 패턴을 1~8스레드(P/E 코어)로 실측해 확장성 곡선을 그리고, ARCH-A04 MESI 시뮬레이터의 상태 전이 횟수 예측과 비교한다.		학습가능mac
MEM-M05MidMOESI/MESIF와 디렉터리 기반 일관성
MESI 시뮬레이터를 MOESI로 확장해 dirty 공유 시 쓰기 되돌림 감소를 측정하고, full-bit-vector 디렉터리 프로토콜(홈 노드, invalidation, ack 수집)을 구현해 코어 수 증가에 따른 메시지 수를 스누핑과 비교한다.		준비중mac
MEM-M06Mid쓰기 대역폭과 RFO: write-allocate 비용 측정
순차 쓰기·memset·스트라이드 쓰기·읽기-수정-쓰기의 대역폭을 working set별로 M2에서 측정해 RFO로 생기는 실제 DRAM 트래픽(읽기+쓰기)을 추정하고, DC ZVA/STNP 사용 시 차이를 비교한다(false sharing은 see:ARCH-M08).		준비중mac
MEM-M07Mid메모리 일관성 모델 시뮬레이터: SC·TSO·ARM 허용 결과 열거
작은 litmus 프로그램(MP, SB, LB, IRIW)을 입력받아 SC, TSO(store buffer), ARMv8(완화) 모델별 허용 결과 집합을 전수 열거하는 시뮬레이터를 작성하고, ARCH-A05의 M2 실측 결과와 대조한다.		학습가능mac
MEM-M08MidDRAM 저전력 상태: power-down·self-refresh 정책
M01 컨트롤러 시뮬레이터에 idle 타이머 기반 power-down/self-refresh 진입·탈출(tXP, tXS) 모델을 추가해 버스트성 트레이스에서 타이머 값별 평균 지연 증가와 에너지 절감을 계산한다(TLB·page walk는 see:ARCH-A01~A03).		준비중mac
MEM-M09MidNUMA: 지역성, first-touch, 원격 접근 비용
2/4-노드 NUMA 지연·대역폭 모델 시뮬레이터에 first-touch/interleave/bind 정책을 구현해 병렬 워크로드 성능을 비교하고, 리눅스 numactl --hardware/--membind 실측 절차를 정리한다.		준비중mac
MEM-M10MidFTL 매핑 테이블: page-level L2P
앞서 만든 NAND 모델 위에 page-mapping FTL(L2P 테이블, P2L(OOB 기록), valid bitmap, 활성 블록 할당)을 구현하고 랜덤 읽기/쓰기 수십만 회 후 참조 모델(배열 디스크)과 데이터 일치를 검증한다.		준비중mac
MEM-M11MidGarbage Collection: victim 선택과 WAF
FTL에 GC(greedy, cost-benefit, FIFO victim 선택)를 추가하고 uniform/hot-cold(80/20) 워크로드와 OP 7%/28%에 대해 WAF·GC 지연 스파이크를 측정, hot/cold 분리 스트림의 효과를 비교한다.		준비중mac
MEM-M12MidWear leveling: dynamic vs static
FTL에 dynamic WL(낮은 P/E 프리 블록 선택)과 static WL(cold 데이터 블록 이동 임계값)을 구현해 장기 워크로드에서 P/E 분포 표준편차·첫 블록 수명 도달 시점·추가 쓰기량을 비교한다.		준비중mac
MEM-M13MidBad block 관리와 NAND 오류 처리
NAND 모델에 factory bad block 마킹, P/E 증가에 따른 RBER 증가, program/erase 실패를 주입하고 FTL에 bad block 테이블·실패 시 데이터 재배치·read retry 단계를 구현, RBER→UBER(ECC 정정 능력 t) 계산도 포함한다.		준비중mac
MEM-M14MidFTL 전원 차단 복구: 체크포인트와 OOB 스캔
주기적 L2P 체크포인트 + 이후 쓰기의 OOB(LPA, seq) 스캔으로 매핑을 재구성하는 복구 루틴을 구현하고, 임의 시점 power-loss를 수천 회 주입해 ACK된 쓰기가 모두 보존되는지 검증한다.		준비중mac
Advanced · 10개
MEM-A01AdvancedCycle-accurate DRAM 모델: bank group·tFAW
MC 시뮬레이터를 cycle 단위로 확장해 bank group별 tCCD_S/L, tRRD_S/L, tFAW, tWTR, 읽기↔쓰기 turnaround를 반영하고, 같은 BG 연속 접근 vs BG 교차 접근의 대역폭 차이를 트레이스로 재현해 Ramulator 결과와 비교한다.		준비중mac
MEM-A02AdvancedRow Hammer와 완화: TRR, PARA, ECC의 한계
행 활성화 횟수 기반 이웃 행 비트플립 확률 모델을 메모리 시뮬레이터에 넣고 double-sided hammer 패턴을 재현한 뒤 TRR(카운터), PARA(확률적 이웃 refresh), ECC 적용 시 남는 오류율을 비교한다.		준비중mac
MEM-A03AdvancedHBM 구조와 대역폭: stack, pseudo-channel, AI 가속기
HBM2e/HBM3/HBM3E 스택당 대역폭(채널 수×폭×데이터율) 계산기를 만들고 가상 NPU(연산 TOPS, HBM 스택 수)의 roofline에 GEMM/attention 연산 강도를 찍어 compute-bound vs memory-bound를 판정한다.		준비중mac
MEM-A04Advanced메모리 트레이닝: write leveling과 DQ eye 센터링
노이즈·지터가 있는 DQ/DQS 타이밍 모델에서 지연 탭을 스윕해 pass/fail 윈도우를 찾고 eye 중앙 선택, 비트별 deskew, read gate 훈련을 구현한 뒤, 온도 드리프트 시 periodic retraining 필요성을 시뮬레이션한다.		준비중mac
MEM-A05AdvancedChipkill·Reed-Solomon 심볼 ECC 기초
GF(2^8) 산술(log/antilog 테이블)과 RS 인코더·신드롬 계산·단일 심볼 오류 정정을 구현하고, x4 DRAM 칩 하나가 통째로 고장 난 상황을 SECDED와 비교해 chipkill의 필요성을 보인다.		준비중mac
MEM-A06AdvancedECC RAS 펌웨어: patrol scrub, CE/UE, page retire
SECDED 메모리 모델 위에 patrol scrub 스케줄러(대역폭 예산), CE 누적 카운트·누설 버킷 임계치 기반 page offlining, UE 시 처리 경로(poison, 리셋)를 구현하고 EDAC 스타일 로그를 출력한다.		준비중mac
MEM-A07Advanced하드웨어 prefetcher 모델: stride·stream
캐시 시뮬레이터에 PC 기반 stride prefetcher와 stream prefetcher(degree/distance 파라미터)를 추가해 순차/stride/포인터 체이싱 트레이스에서 accuracy·coverage·지연 이득과 대역폭 오염을 비교한다.		준비중mac
MEM-A08AdvancedRoofline으로 메모리 병목 분석: 타일링 전후
naive/블록 타일링/전치 버전 행렬곱을 M2에서 측정해 GFLOP/s와 추정 DRAM 트래픽(캐시 시뮬레이터 또는 이론식)으로 연산 강도를 계산하고, STREAM 대역폭·피크 FLOPS로 만든 roofline 위에 표시해 개선 원인을 설명한다.		준비중mac
MEM-A09Advanced고급 FTL: DFTL(매핑 캐시)과 SLC 캐시
DFTL(CMT LRU 캐시, translation page, GTD)을 구현해 매핑 캐시 크기 대비 추가 NAND 읽기/쓰기를 측정하고, SLC 캐시(동적 영역, 버스트 쓰기 흡수·폴딩) 정책을 추가해 버스트 쓰기 지연 변화를 분석한다.		준비중mac
MEM-A10Advanced종합: SoC 메모리 서브시스템 bring-up 계획
가상 SoC의 DDR bring-up 문서(PHY init→training→MC 타이밍 설정→memtest 단계(데이터/주소 버스→March)→ECC/scrub 정책→대역폭/지연 검증)를 작성하고 앞선 항목 코드로 각 단계 핵심 코드 경로를 연결, 실패 시 디버그 트리를 정리한다.		준비중mac
