운영체제 & Core OS

아이템 39Basic 14Mid 14Advanced 11학습가능 0

범용 OS의 핵심 개념(프로세스, 가상 메모리, 동시성, 파일 시스템, I/O)은 임베디드 리눅스·플랫폼·드라이버 면접의 공통 언어다. OSTEP으로 개념을 익혔다면 이 트랙에서는 셸·malloc·락·페이지 테이블·파일 시스템·스케줄러를 직접 구현하고, Apple Silicon의 약한 메모리 모델 위에서 메모리 오더링을 실험하며, xv6 커널을 수정해 개념을 손에 붙인다.

트랙 목표

  • fork/exec/pipe/signal/mmap 등 POSIX 시스템 콜로 프로세스·IPC 도구를 직접 만든다
  • 페이지 테이블·TLB·페이지 교체를 시뮬레이터와 실측 벤치로 설명한다
  • malloc(free list, segregated, buddy/slab)을 구현하고 단편화·성능을 측정한다
  • mutex/condvar/rwlock/spinlock/atomics를 구현하고 메모리 오더링과 교착을 실험으로 이해한다
  • blocking/non-blocking/kqueue/epoll I/O 모델과 파일 시스템·크래시 일관성을 구현 수준에서 다룬다
  • xv6 커널에 시스템 콜·COW fork를 추가해 커널 내부 흐름을 경험한다

xv6-riscv에 trace(mask) 시스템 콜(호출 추적 출력, fork 상속)과 sysinfo(빈 메모리·프로세스 수)를 추가하고 user/ 테스트 프로그램과 make grade 스타일 테스트로 검증한다.		외부환경필요qemu
OS-A10Advancedxv6 커널 해킹 2: COW fork 구현
xv6의 uvmcopy를 COW로 바꾸고 RSW 비트로 COW 페이지를 표시, 저장 페이지 폴트(scause 15) 핸들러에서 복사, 물리 페이지 참조 카운트를 구현해 cowtest와 usertests를 통과시킨다.		외부환경필요qemu
OS-A11Advanced종합: 멀티스레드 서비스 데몬
