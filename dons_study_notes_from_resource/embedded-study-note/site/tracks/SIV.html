실리콘 검증

아이템 39Basic 14Mid 14Advanced 11학습가능 28

실리콘이 처음 돌아온 날(first silicon)부터 양산까지, 칩이 스펙대로 동작하는지 C 펌웨어와 스크립트로 증명하는 기술이다. Rivian Silicon & Sensing, NVIDIA/Apple/Qualcomm의 post-silicon validation 직무는 레지스터 테스트 프레임워크, 링크 검증 플로우, shmoo/PVT, triage 능력을 직접 묻는다.

트랙 목표

  • 레지스터 기술(register description)에서 리셋값·접근속성·aliasing 테스트를 자동 생성하고 C로 실행할 수 있다
  • IP 블록 bring-up, 인터럽트·DMA 검증 시퀀스를 타임아웃·에러코드까지 갖춘 형태로 작성할 수 있다
  • PCIe/DDR/SerDes 링크 검증 흐름(LTSSM, training, PRBS/BER)을 설명하고 host 모델로 구현할 수 있다
  • PVT 코너·shmoo·스트레스 테스트를 설계하고 실패를 triage/bisect하는 자동화를 만들 수 있다
  • 테스트 플랜·커버리지·ATE/SLT/시스템 검증의 역할 분담을 면접에서 구조적으로 설명할 수 있다

SIV-A04Advanced열 특성화와 Throttling 검증
SoC 열 RC 모델(see:SIM)에 워크로드를 넣어 온도 상승을 시뮬레이션하고 thermal trip/throttle 임계·hysteresis·DVFS 단계 전환을 검증하는 테스트를 작성; 센서 오프셋 오류가 있을 때 throttle 지연이 얼마나 위험한지 정량화한다.		준비중mac
SIV-A05AdvancedErrata 관리와 칩 리비전별 워크어라운드
chip ID/revision 레지스터를 읽어 errata 테이블(ID, 영향 리비전, 워크어라운드 함수, 검증 테스트)을 적용하는 프레임워크를 C로 구현하고, A0/B0 mock에서 각각 올바른 워크어라운드만 적용되는지·ECO 후 제거 가능한지 테스트한다.		준비중mac
SIV-A06Advanced보드 레벨 검증: 전원 시퀀싱과 클럭
레일별 ADC 샘플 로그(타임스탬프 포함)를 입력받아 전원 시퀀싱 순서·ramp time·허용오차(±5%)·glitch를 검사하는 checker와, 주파수 카운터 측정값으로 PLL/클럭 트리 출력 ppm 오차를 판정하는 테스트를 작성한다.		준비중mac
SIV-A07Advanced버스 인터페이스 실패 디버그 (LA 캡처 분석)
로직 애널라이저 CSV(SCL/SDA 샘플)를 디코딩하는 I2C 프로토콜 파서를 작성해 NACK·clock stretching 타임아웃·setup/hold 위반·arbitration lost를 자동 표시하고, 합성 캡처 3종(풀업 약함, 타이밍 위반, 슬레이브 hang)의 원인을 리포트한다.		준비중mac
SIV-A08Advanced생산 연계: 수율·Binning 분석
웨이퍼별 다이 테스트 결과(합성: Vmin, Fmax, 누설, pass/fail 코드)로 수율·bin 분포·wafer map을 계산하고, 테스트 항목 순서를 'fail 확률/테스트 시간' 기준으로 재정렬해 평균 테스트 시간을 줄이는 최적화를 구현한다.		준비중mac
SIV-A09Advanced검증 캠페인 설계: 신규 센싱 SoC (면접형)
카메라(MIPI CSI-2)·레이더(SerDes)·PCIe·DDR를 가진 가상 센싱 SoC에 대해 검증 단계(pre-si 준비, Day-0 bring-up, feature, PVT, stress, 양산 이관), 인프라(시퀀서, 랩 자동화, 대시보드), triage 플로우, 일정·인력·지표를 담은 설계 문서를 쓰고 Day-0 bring-up 스크립트 골격을 구현한다.		준비중mac
SIV-A10AdvancedLFSR BIST와 MISR 시그니처
n비트 LFSR(원시 다항식)로 의사 랜덤 패턴을 만들어 작은 조합 회로 모델에 인가하고 MISR로 응답을 시그니처로 압축하는 C 모델을 작성; golden 시그니처와 비교해 stuck-at 결함 주입 후 검출률과 aliasing 확률(≈2^-n)을 실험으로 측정하고, 펌웨어에서 BIST 시작→완료 poll→시그니처 비교하는 시퀀스를 mock 레지스터로 구현한다.		준비중mac
SIV-A11Advanced클럭·전원 도메인 검증
mock SoC에서 도메인별 clock gate/power switch 시퀀스를 모델링해, 게이트된 도메인 접근 시 에러 응답, 전원 복귀 후 reset 값 vs retention 레지스터 보존, isolation 해제 순서, 클럭 enable 직후 첫 접근 안전성을 검사하는 테스트를 작성하고 순서 위반(retention 누락, isolation 조기 해제) 결함을 주입해 검출한다.		준비중mac
