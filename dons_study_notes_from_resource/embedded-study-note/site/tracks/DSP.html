Stage 5 · DSP · DSP & Fixed-Point

신호처리 · 고정소수점

아이템 33Basic 12Mid 12Advanced 9학습가능 0

FPU가 없거나 전력이 아까운 MCU에서 필터·FFT·제어를 정수 연산으로 정확하게 돌리는 기술이다. 오디오·모터 제어·센서·RF 펌웨어 면접에서 Q15 곱셈의 포화, biquad 구현, FFT 직접 구현, 고정소수점 오버플로 분석은 단골 문제다.

트랙 목표

  • Q-format 변환·곱셈·반올림·포화를 비트 정확하게 구현하고 오차를 분석할 수 있다
  • FIR/IIR(biquad)/CIC/다상(polyphase) 필터를 부동·고정소수점으로 구현하고 주파수 응답으로 검증할 수 있다
  • radix-2 FFT를 직접 구현하고 윈도잉·스펙트럼 분석(SNR/THD/ENOB)을 할 수 있다
  • CORDIC·다항식 근사·LUT로 삼각함수·sqrt·atan2를 정확도/속도 trade-off에 맞게 구현할 수 있다
  • 오버플로·동적범위 분석과 SIMD(NEON/CMSIS-DSP) 최적화로 실시간 DSP 파이프라인을 설계할 수 있다

float↔Q15/Q31/Q7.8 변환 함수(round-to-nearest, truncate, 포화 포함)를 C로 구현하고 범위 끝값(-1.0, 1−2^-15, +1.0 입력)과 랜덤 값에 대해 최대 오차가 0.5 LSB 이내인지 테스트한다.		준비중mac
DSP-B02BasicQ15 곱셈: 반올림·포화·-1×-1 코너
q15_mul(a,b)를 32비트 곱 → 반올림 상수 0x4000 더하기 → >>15 → 포화 순서로 구현하고, 2^32개 전수 조합(또는 대표 샘플) 테스트로 float 기준 대비 오차와 -32768×-32768 오버플로 처리를 검증한다; ARM SMULBB/QDMULH 의미와 비교한다.		준비중mac
DSP-B03Basic포화 덧셈/뺄셈과 오버플로 검출
분기 없는 포화 add/sub(int16/int32)를 구현하고 __builtin_add_overflow 버전과 결과를 전수/랜덤 비교; wrap되는 FIR 누산과 포화 누산의 출력 차이를 사인파 입력으로 보인다.		준비중mac
DSP-B04Basic서로 다른 Q 형식의 혼합 연산
Q1.15×Q3.13 → Q4.28 → Q1.15 변환 체인, N개 Q15 곱 누산에 필요한 guard bit(ceil(log2 N)) 계산기를 작성하고, 누산기 폭이 부족할 때 오버플로가 나는 입력을 만들어 확인한다.		준비중mac
DSP-B05Basic샘플링·Aliasing·양자화 잡음(SQNR)
사인파를 다양한 fs로 샘플링해 aliasing 주파수를 예측·확인하고, N비트(8~16) 양자화 후 SQNR을 측정해 6.02N+1.76dB와 비교; 입력 레벨이 낮을 때 SQNR이 떨어지는 것과 dither 효과를 보인다.		준비중mac
DSP-B06Basic이동평균 필터: O(1) 구현과 주파수 응답
running sum + 원형 버퍼 이동평균을 정수로 구현(N=2^k일 때 shift 나눗셈)하고, 장시간 실행에서도 누산 오차가 없음을 확인; 계단·사인 sweep 입력으로 sinc 형태 주파수 응답과 null 위치를 측정한다.		준비중mac
DSP-B07Basic1차 IIR(EMA) 저역통과 필터
y += (x − y) >> k 형태의 EMA를 구현하고 k별 시정수·-3dB 주파수를 계산·측정; 작은 입력 변화가 반영되지 않는 정체 현상을 재현하고 소수부 누산(상위 비트 확장)으로 해결한다.		준비중mac
DSP-B08BasicFIR 필터 직접 구현 (Q15 + 64비트 누산)
임의 탭 수 FIR을 float와 Q15(int64 누산, 최종 반올림·포화)로 구현하고 numpy.convolve 결과와 비교해 오차를 측정; 원형 버퍼 인덱싱 vs 지연선 복제(double-size buffer) 방식의 속도를 비교한다.		준비중mac
DSP-B09BasicDFT 직접 구현과 bin 해석
O(N²) DFT를 C로 구현해 numpy.fft와 비교하고, bin 주파수 k·fs/N, 실수 신호의 켤레 대칭, 진폭 스케일(2/N), DC/Nyquist bin 특성을 테스트 신호로 확인한다.		준비중mac
DSP-B10Basic윈도잉과 스펙트럼 누설
Rectangular/Hann/Hamming/Blackman/Flat-top 윈도를 구현하고 bin 사이 주파수 사인파로 누설(sidelobe), scalloping loss, ENBW를 측정해 표로 비교; 가까운 두 톤 분리 실험을 한다.		준비중mac
DSP-B11BasicLUT 사인/코사인과 위상 누산기(NCO)
256/1024 엔트리 사인 LUT(1/4 파 대칭 활용)를 Q15로 만들고 nearest vs 선형보간 오차를 측정; 32비트 위상 누산기 NCO로 주파수 해상도 fs/2^32를 확인하고 SFDR을 FFT로 측정한다.		준비중mac
DSP-B12Basic정수 sqrt와 Newton-Raphson 역수
비트 단위 정수 sqrt(uint32→uint16)와 Q-format Newton-Raphson 역수/역제곱근(초기값 LUT + 2회 반복)을 구현해 전수 또는 대량 랜덤 테스트로 최대 오차를 측정하고 반복 횟수별 정확도를 비교한다.		준비중mac

DSP-M01MidRadix-2 DIT FFT 구현 (float)
in-place iterative radix-2 DIT FFT(비트 반전 재배열 + twiddle 테이블)를 C로 구현해 numpy.fft와 상대오차 1e-6 이내로 맞추고, N=64~65536에서 DFT 대비 실행시간이 N log N으로 증가함을 측정한다.		준비중mac
DSP-M02Mid고정소수점 FFT와 Block Floating Point
M01을 Q15로 포팅해 (1) 매 단계 >>1 고정 스케일 (2) 오버플로 감지 시에만 스케일하는 block floating point를 구현하고, 입력 레벨별 출력 SNR을 float FFT 대비 측정해 비교한다.		준비중mac
DSP-M03MidReal FFT 트릭과 Goertzel
N점 실수 FFT를 N/2점 복소 FFT + 후처리로 계산하는 split 알고리즘을 구현해 속도를 비교하고, Goertzel 알고리즘으로 DTMF 8개 톤을 검출하는 디코더를 만들어 합성 DTMF 신호(잡음 포함)로 검증한다.		준비중mac
DSP-M04MidBiquad IIR: DF1 vs DF2T와 SOS 캐스케이드
RBJ cookbook 공식으로 LPF/HPF/peaking 계수를 계산해 Direct Form I, Transposed Direct Form II biquad를 float로 구현하고 scipy.signal.sosfreqz 응답과 비교; 고차 필터를 SOS 캐스케이드로 쪼갤 때 순서·이득 분배가 중요한 이유를 실험한다.		준비중mac
DSP-M05Mid고정소수점 Biquad: 계수 양자화·Limit Cycle
Q2.30 계수·Q31 상태 DF1 biquad를 구현해 저주파 LPF(fc=fs/1000)에서 계수 양자화로 극점이 이동하는 것을 계산하고, 무입력 limit cycle 재현과 error feedback(noise shaping)으로 개선을 측정한다.		준비중mac
DSP-M06MidFIR 필터 설계와 계수 양자화
windowed-sinc(Kaiser) 설계를 Python으로 직접 구현해 통과대역 리플·저지대역 감쇠 스펙을 만족하는 최소 탭 수를 찾고, Q15 양자화 후 응답 열화를 측정; 대칭 계수를 이용해 곱셈을 절반으로 줄인 C 구현을 작성한다.		준비중mac
DSP-M07MidDecimation/Interpolation과 Polyphase
M배 decimator와 L배 interpolator를 (1) 필터 후 다운샘플 (2) polyphase 구조로 각각 구현해 출력이 동일하고 연산량이 1/M임을 보이고, 안티에일리어싱 필터 유무에 따른 aliasing 성분을 FFT로 측정한다.		준비중mac
DSP-M08MidCIC 필터와 비트 성장
N단 CIC decimator(R, M 파라미터)를 정수로 구현해 필요한 레지스터 폭 Bin + N·log2(RM)을 검증(모듈러 산술로 wrap되어도 결과가 맞음을 확인)하고, PDM 마이크 비트스트림 모델 → CIC → 보상 FIR로 PCM을 복원해 SNR을 측정한다.		준비중mac
DSP-M09MidCORDIC: sin/cos/atan2/크기
rotation 모드(sin/cos)와 vectoring 모드(atan2, magnitude)를 Q 형식 정수로 구현하고 게인 K 보정, 사분면 처리, 반복 횟수별 오차(비트당 약 1비트)를 측정해 libm과 비교한다.		준비중mac
DSP-M10Mid다항식 근사: atan2·exp·log 빠른 계산
atan(x) on [0,1]을 Taylor vs minimax(Remez 또는 Chebyshev) 다항식으로 근사해 최대 오차를 비교하고, 사분면 확장으로 fast_atan2를 구현; exp2/log2는 지수부 분리 + 다항식으로 구현해 libm 대비 오차·속도를 측정한다.		준비중mac
DSP-M11Mid오버플로·동적범위 분석
FIR의 L1 노름(Σ|h|) 기반 최악 이득과 IIR의 임펄스 응답 L1/L2 노름을 계산하는 도구를 만들고, 그 경계를 실제로 달성하는 적대적 입력(부호 정렬 입력)을 생성해 오버플로를 재현한 뒤 스케일링으로 해결한다.		준비중mac
DSP-M12Mid고정소수점 PID (가볍게)
Q16.16 또는 Q15 기반 이산 PID(적분 포화 제한, 출력 포화)를 구현하고 float 버전과 1차 플랜트 시뮬레이션 결과를 비교해 적분 누산 정밀도 부족으로 생기는 정상상태 오차를 보이고 개선한다(제어 이론은 see:RCTL).		준비중mac

DSP-A04Advanced분수비 샘플률 변환 (44.1k→48k)

DSP-A05Advanced적응 필터 LMS/NLMS

DSP-A06Advanced디지털 PLL: 위상·주파수 추적

DSP-A07AdvancedADC 스펙트럼 분석: SNR/SINAD/THD/ENOB
비선형성·잡음·지터를 넣은 ADC 모델 캡처(코히어런트 샘플링 조건 포함)에 대해 FFT 기반 SNR, THD(고조파 5개), SINAD, SFDR, ENOB=(SINAD−1.76)/6.02를 계산하는 도구를 만들고 Welch PSD로 잡음 바닥을 추정한다(see:SENS).		준비중mac
DSP-A08AdvancedBit-exact 검증 프레임워크
