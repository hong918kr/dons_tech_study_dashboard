Stage 11 · NETHW · SmartNIC, DPU & Switch ASIC

SmartNIC · DPU · 스위치 ASIC

아이템 36Basic 12Mid 12Advanced 12학습가능 0

SmartNIC·DPU·스위치 ASIC은 데이터센터와 AI 패브릭의 패킷을 라인레이트로 처리하는 하드웨어다. NVIDIA(Mellanox/BlueField), Broadcom, Arista, Intel, AMD(Pensando), Marvell 면접에서는 pps 예산 계산, 디스크립터/큐/doorbell 같은 NIC 데이터패스, TCAM·LPM·match-action 파이프라인, 버퍼·스케줄러, 오프로드와 FEC를 '직접 모델링해 봤는지'를 묻는다. 펌웨어·SSD 경험을 NIC/DPU 펌웨어로 확장하는 트랙이다.

트랙 목표

  • 링크 속도에서 pps·패킷당 사이클·버스 폭 예산을 즉시 계산한다
  • 멀티큐 링·doorbell·CQ·인터럽트 모더레이션·체크섬/TSO/RSS 오프로드를 mock NIC로 구현한다
  • 파서·TCAM·LPM·exact-match·match-action 파이프라인과 P4를 구현·실행해 스위치 ASIC 구조를 설명한다
  • 공유 버퍼·WRED/ECN·스케줄러를 시뮬레이션해 혼잡 시 동작을 정량화한다
  • virtio-net/vhost/vDPA, OVS 오프로드, SR-IOV eswitch, 인라인 암호, RDMA 엔진, DPU 스토리지 오프로드를 설계한다
  • 64b/66b PCS, PAM4, RS-FEC를 수학과 코드로 검증하고 NIC 펌웨어 bring-up·복구를 설계한다

TLS 1.3 레코드 프레이밍(record seq→nonce)을 TCP 스트림 위에 올리고, NIC가 순서대로 들어오는 세그먼트만 인라인 암호화하는 모델에서 재전송·순서 밖 세그먼트가 오면 드라이버가 레코드 시작 위치를 찾아 resync 컨텍스트를 내려주는 경로를 구현해 모든 경우 출력 암호문이 소프트웨어 kTLS와 일치함을 검증한다.		준비중mac
NETHW-A07AdvancedRS(544,514) KP4 FEC 디코더 구현
MEM-A05의 GF(2^8) RS를 GF(2^10)·t=15로 확장해 인코더, 신드롬, Berlekamp-Massey, Chien search, Forney를 C로 구현하고, 무작위·버스트 심볼 오류 주입으로 15개까지 정정·16개 이상 검출(uncorrectable 플래그)을 확인한 뒤 400GbE 코드워드 시간과 디코더 지연 예산을 계산한다 (GF 기초는 see:MEM-A05).		준비중mac
NETHW-A08Advanced패킷 프로세서 마이크로아키텍처 예산: 버스 폭·클럭·65B 문제
12.8T/25.6T/51.2T 스위치와 400G NIC에 대해 클럭·버스 폭(64B/128B/256B)·파이프라인 수 조합별 처리 가능 pps를 계산하는 도구를 작성하고, 65B 패킷이 버스 2비트를 쓰는 worst-case 효율 저하와 패킷 패킹/세그먼트 버스 해법, 테이블 조회 메모리 대역폭 요구를 정리해 설계안을 정당화한다.		준비중mac
NETHW-A09Advanced스위치 SDK 테이블 프로그래밍: make-before-break와 warm boot
SAI 스타일 객체(route, next-hop, ECMP group) 위에 shadow 테이블과 HW 테이블 모델을 두고, ECMP 멤버 교체·경로 변경을 make-before-break 순서(참조 카운트·사용 중 객체 삭제 금지)로 적용하는 드라이버와, 프로세스 재시작 후 HW 테이블을 읽어 원하는 상태와 diff·재조정하는 warm boot 로직을 구현해 업데이트 중 블랙홀 패킷 0을 검증한다.		준비중mac
NETHW-A10AdvancedNIC 펌웨어 인터페이스: Admin Queue, health, 리셋 복구
mock NIC에 펌웨어 admin queue(명령 디스크립터·opcode·완료 상태·버전 협상)와 heartbeat 레지스터를 두고, 명령 타임아웃·펌웨어 크래시 주입 시 드라이버가 health 이상 감지→큐 정지→덤프 수집→FLR/펌웨어 리셋→재초기화→큐 재개를 수행하는 복구 상태기계(devlink health 스타일)를 구현해 진행 중 TX/RX 버퍼 누수가 없음을 검증한다.		준비중mac
NETHW-A11AdvancedDPU 스토리지 오프로드: NVMe 에뮬레이션 → NVMe-oF
PCIE-M01 SQ/CQ 모델을 'DPU가 노출하는 에뮬레이티드 NVMe 컨트롤러'로 재사용해, 호스트 SQ 엔트리를 DPU 측 서비스가 꺼내 PCIE-A09의 NVMe/TCP mini target으로 전달하고 완료를 호스트 CQ에 돌려주는 브리지를 구현하며, 큐 매핑·PRP DMA·타임아웃 전파와 추가 지연을 측정한다 (기초는 see:PCIE-A09).		준비중mac
NETHW-A12AdvancedDPU/IPU 아키텍처 설계 면접: 무엇을 어디에 둘 것인가
'베어메탈 클라우드 호스트를 위한 200G DPU'를 주제로 OVS/eswitch 오프로드, 보안(호스트 격리·secure boot), 스토리지(NVMe 에뮬레이션), 암호화·압축 가속기를 fast path(HW)/exception path(Arm 코어)에 배치하는 설계 문서를 작성하고, exception path 비율별 Arm 코어 수·PCIe 대역폭을 계산하는 예산 스크립트로 trade-off를 정당화한다.		준비중mac
