임베디드 C 핵심

아이템 41Basic 15Mid 15Advanced 11학습가능 41

임베디드 펌웨어 면접의 절반은 C 언어의 '정확한' 이해를 확인한다: 비트 연산, volatile/const, 정수 승격, 구조체 레이아웃, 메모리 맵 레지스터 접근, UB. 이 트랙은 이미 아는 것을 직접 구현·검증하며 다시 다지고, 드라이버·ISR 코드에서 실제로 터지는 함정을 손으로 재현한다.

트랙 목표

  • 비트 연산·정수 승격·shift 규칙을 출력 예측 수준으로 정확히 설명하고 테스트로 증명한다
  • volatile/const/static/linkage의 의미와 한계를 어셈블리·심볼 테이블로 확인한다
  • 구조체 패딩·packed·엔디안·비트필드를 다루는 이식 가능한 직렬화/레지스터 코드를 작성한다
  • memcpy/memmove/strtol/itoa/미니 printf를 libc와 대조 테스트하며 직접 구현한다
  • UB·strict aliasing·인터럽트 공유 데이터 문제를 sanitizer와 최적화 레벨 비교로 재현하고 고친다
  • 호스트에서 mock 가능한 레지스터 접근 계층을 설계해 드라이버를 단위 테스트한다
