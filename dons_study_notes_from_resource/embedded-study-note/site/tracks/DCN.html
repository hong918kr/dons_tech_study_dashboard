데이터센터 네트워크 · AI 패브릭

아이템 35Basic 11Mid 13Advanced 11학습가능 0

AI 학습 클러스터에서는 GPU 간 통신이 스텝 시간의 큰 몫을 차지해, 토폴로지·로드밸런싱·무손실 이더넷·혼잡 제어·collective 알고리즘을 이해하는 엔지니어 수요가 NVIDIA·Broadcom·Arista·Meta·Google 인프라 전반에서 크다. 이 트랙은 Clos/fat-tree 수학과 ECMP부터 RDMA verbs(Soft-RoCE), PFC/DCQCN/HPCC, all-reduce α-β 모델, NCCL·SHARP·UEC까지 시뮬레이터와 실제 코드로 구현해 수치로 설명할 수 있게 만든다.

트랙 목표

  • Clos/fat-tree/dragonfly 토폴로지의 규모·bisection·oversubscription을 계산하고 생성기로 검증한다
  • ECMP 해시·극성화·flowlet/스프레이 부하 분산과 DC BGP 수렴을 시뮬레이션으로 비교한다
  • Soft-RoCE에서 RDMA verbs(QP 상태 전이, SEND/WRITE/READ)를 직접 프로그래밍하고 성능 패턴을 익힌다
  • PFC·ECN·DCQCN·TIMELY/Swift·HPCC의 동작과 PFC 데드락을 시뮬레이터로 재현한다
  • ring/tree/halving-doubling/계층적 all-reduce와 MoE all-to-all을 α-β 모델로 분석하고 NCCL 동작을 해석한다
  • 스케일업 vs 스케일아웃, IB vs RoCE vs UEC, SHARP·광 링크를 근거로 대규모 AI 패브릭을 설계한다

DCN-M09MidHPCC: INT 기반 정밀 혼잡 제어
홉마다 (qlen, txBytes, timestamp, B)를 패킷에 추가하는 스위치 모델과 ACK로 받은 INT로 링크 이용률 U = qlen/(B·T) + txRate/B를 계산해 목표 η=0.95로 윈도우를 조정하는 HPCC 송신자를 구현하고, DCQCN 대비 큐 길이와 수렴 속도를 같은 시나리오에서 비교한다.		준비중mac
DCN-M10MidECMP 너머의 부하 분산: Flowlet·Packet Spraying

NVL72급 NVSwitch 도메인, UALink 스케일업, 400/800G RoCE·InfiniBand 스케일아웃을 GPU당 대역폭·도메인 크기·홉 지연·스위치 수·전력 파라미터로 표현한 모델을 만들고, tensor parallel 그룹이 스케일업 도메인 안/밖에 있을 때 층당 all-reduce 시간 차를 계산해 도메인 크기 선택 근거를 제시한다 (링크 대역폭 계산은 see:GPUSYS-A01).		준비중mac
DCN-A06AdvancedInfiniBand: 크레딧 흐름 제어와 Subnet Manager 라우팅
VL별 크레딧 기반 링크 흐름 제어를 시뮬레이션해 PFC(pause 기반)와 버퍼 요구량을 비교하고, fat-tree 그래프에서 SM처럼 LID를 할당하고 min-hop과 fat-tree(목적지 기반 분산) 라우팅으로 스위치별 LFT를 계산하는 mini SM을 구현해 모든 쌍 경로의 도달성·데드락 자유(채널 의존 그래프 무사이클)·링크 부하 균형을 검증한다.		준비중mac
DCN-A07Advanced손실 복구: Go-Back-N(RoCE) vs Selective Repeat(UEC)
손실률·RTT·BDP를 파라미터로 go-back-N, selective repeat+SACK, 패킷 트리밍(헤더만 전달해 빠른 NACK) 송수신 상태기계를 시뮬레이터로 구현해 손실률 10⁻⁶~10⁻²에서 goodput을 비교하고, 무손실(PFC) 의존을 버리는 UEC 설계 동기(out-of-order 배치, 일시적 연결)를 정리한다.		준비중mac
DCN-A08AdvancedSHARP: 스위치 내 리덕션(In-network Aggregation)
fat-tree 위 집계 트리(leaf→spine 스위치에서 부분합)를 시뮬레이션하는 all-reduce를 구현해 호스트당 송신량이 2(n−1)/n·S에서 S로 줄어드는 것을 확인하고, ring/tree 대비 시간·스위치 메모리 한계로 인한 청크 분할·부동소수 합산 순서(결정성)를 분석한다.		준비중mac
DCN-A09Advanced패브릭 텔레메트리: INT·카운터로 혼잡/PFC Storm 진단
시뮬레이터가 내보내는 홉별 INT 메타데이터(스위치 ID, 큐 길이, 지연)와 포트 카운터(ECN 마킹, pause 송수신, drop)를 수집해 핫스팟 링크·혼잡 근원(root) 포트·PFC storm(고장 NIC의 지속 pause)을 자동 판정하는 분석기를 구현하고, 의도적으로 주입한 3가지 장애를 정확히 지목하는지 검증한다.		준비중mac
DCN-A10Advanced광 링크 기초: 모듈·도달거리·전력 예산
송신 출력·수신 감도·광섬유 손실(dB/km)·커넥터 손실·마진으로 링크 전력 예산 계산기를 만들어 400G-DR4/800G-DR8/FR4 사례를 검증하고, 32K GPU 클러스터의 트랜시버 수·모듈 전력(DSP vs LPO vs CPO)·DAC/AEC 대체 가능 구간을 산정한다 (PAM4/RS-FEC BER는 see:NETHW, see:SIV).		준비중mac
DCN-A11Advanced설계 면접: 수만 GPU 학습 클러스터 패브릭
16K~32K GPU 학습 클러스터에 대해 스케일업 도메인, rail-optimized 3단 Clos(또는 2단+멀티플레인) 스위치·광모듈 수, RoCE(DCQCN/PFC) vs IB vs UEC 선택, 장애 도메인과 링크 장애율로 인한 job 중단 빈도를 수치로 산출한 설계 문서와 계산 스크립트를 작성하고, 한 스텝의 통신 시간(DP all-reduce + TP + EP all-to-all) 예산을 A01·A02 모델로 검증한다.		준비중mac
