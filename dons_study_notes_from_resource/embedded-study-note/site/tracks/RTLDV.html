Stage 10 · RTLDV · RTL Design & Verification

RTL 설계 · 검증

아이템 35Basic 11Mid 13Advanced 11학습가능 0

RTL 설계·검증은 AI 가속기·SoC·실리콘 검증 팀에서 펌웨어/검증 엔지니어에게도 요구되는 공통 언어다. NVIDIA·Tenstorrent·Rivian 같은 회사의 면접은 FIFO·CDC·skid buffer·아비터를 화이트보드로 그리게 하고, assertion·formal·UVM·커버리지로 '어떻게 검증했는지'를 묻는다. 이 트랙은 맥에서 오픈소스 툴(iverilog·Verilator·yosys·SymbiYosys·cocotb)만으로 그 전 과정을 직접 해본다.

트랙 목표

  • 합성 가능한 SystemVerilog로 조합·순차·FSM·FIFO·파이프라인·아비터를 정확히 작성하고 합성 결과로 확인한다
  • CDC(2-FF·펄스·핸드셰이크·비동기 FIFO)와 리셋 전략을 설계하고 정적/동적으로 검증한다
  • cocotb 기반 driver/monitor/scoreboard, constrained random, 기능·코드 커버리지로 검증 환경을 구성한다
  • SVA assertion과 SymbiYosys formal(BMC·induction·cover)로 프로토콜 속성을 증명한다
  • UVM 아키텍처·RAL·회귀/triage 흐름을 설명하고 Python(pyuvm)으로 구현해 본다
  • lint·gate-level sim·타이밍 클로저·저전력 기법 등 사인오프 관점의 개념을 실습으로 연결한다

M13에서 생성한 APB CSR 블록에 대해 pyuvm RAL(또는 직접 만든 미니 uvm_reg 계층)로 레지스터 모델·APB adapter·explicit predictor를 구성하고, hw_reset/bit_bash에 해당하는 내장 시퀀스와 mirror(check) 비교를 실행해 W1C 필드 access 정의를 틀리게 만든 모델 버그와 RTL 버그를 각각 구분해 잡는다(실리콘 측 리셋값·walking 테스트는 see:SIV-B03).		외부환경필요fpga
RTLDV-A03Advanced회귀 인프라: 시드·테스트 리스트·커버리지 병합·Triage
테스트×시드 매트릭스를 병렬 실행하는 Python 러너(결과 JSON, 타임아웃, 재실행 시 파형 덤프 on)를 작성하고 verilator_coverage로 회차별 커버리지를 병합, 실패 로그를 assertion명·메시지 정규화 시그니처로 묶어 'first failing seed + 재현 커맨드' 리포트를 생성하며, 일부러 넣은 저확률 버그가 몇 시드에서 처음 잡히는지 측정한다(실리콘 로그 triage는 see:SIV-M10, CI 파이프라인은 see:INFRA).		외부환경필요fpga
RTLDV-A04AdvancedAXI4 버스트 슬레이브 RTL과 프로토콜 체커
AXI4 메모리 슬레이브(outstanding 2, WRAP 주소 계산, WSTRB, SLVERR 응답)를 SystemVerilog로 작성하고, AW/W/B/AR/R 각 채널 규칙(VALID 유지, WLAST 위치, 4KB 비횡단, 같은 ID 순서)을 SVA 프로토콜 체커로 bind해 cocotb 랜덤 마스터로 검증한다(채널 C 모델은 see:ARCH-M14, AXI-lite Verilator TB는 see:EMU-M01, 인터커넥트 수준 ordering은 see:SOCX).		외부환경필요fpga
RTLDV-A05AdvancedFormal 심화: AXI4-Lite 슬레이브 인터페이스 증명
EMU-M01과 같은 AXI4-Lite 레지스터 슬레이브에 ZipCPU faxil_slave 스타일의 마스터 assume/슬레이브 assert 속성(outstanding 카운터, 응답 대기 상한)을 작성해 sby prove를 시도하고, 의도적으로 넣은 '동시 AW·W 도착 시 BVALID 누락' 버그의 반례를 확인·수정한 뒤 induction 실패를 내부 카운터 불변식으로 강화해 증명을 완료한다(see:EMU-M01).		외부환경필요fpga
RTLDV-A06AdvancedGate-level 시뮬레이션과 X-전파 문제
리셋되지 않은 데이터패스 플롭과 if(x)/case(x)의 X-optimism을 가진 RTL을 yosys로 합성해 write_verilog 넷리스트를 iverilog로 gate-level 시뮬레이션하고, RTL 시뮬레이션과 출력이 갈리는 지점을 파형으로 추적하며, Verilator --x-assign/--x-initial unique 랜덤 초기화로 같은 문제를 RTL 단계에서 잡는 방법을 비교한다.		외부환경필요fpga
RTLDV-A07Advanced타이밍 클로저: 파이프라이닝·리타이밍과 등가성 검사
32비트 MAC과 우선순위 인코더 체인을 yosys+nextpnr-ice40으로 P&R해 타이밍 리포트에서 크리티컬 패스·Fmax를 읽고, 파이프라인 단 추가·리타이밍·one-hot 재인코딩으로 Fmax를 개선한 뒤 원본 대비 등가성(조합 변경은 yosys equiv_*, 지연 추가는 latency 보정 miter + sby)을 증명하며, multicycle/false path·SDC 제약 개념을 결과와 연결해 정리한다(setup/hold 산수는 see:ARCH-B13).		외부환경필요fpga
RTLDV-A08Advanced저전력 RTL: Clock Gating·Operand Isolation·Toggle 측정
M04 MAC 데이터패스에 ICG 셀 모델(래치+AND) 기반 clock gating과 입력 operand isolation을 넣고 동일 워크로드 VCD의 toggle 수를 비교해 동적 전력 감소를 추정하며, 전원 차단 도메인 출력에 isolation clamp·retention 레지스터 모델을 넣고 'shutdown 중 출력은 clamp 값', 'restore 후 상태 복원'을 SVA로 검증한다(toggle→전력 추정은 see:EMU-A06, NPU 전력 관리는 see:NPU-A07).		외부환경필요fpga
RTLDV-A09Advanced저지연 스트리밍 패킷 파서 RTL (64-bit AXI-Stream)
64비트 AXI-Stream(tkeep 포함)으로 들어오는 Ethernet/IPv4/UDP 프레임에서 dst MAC·IP·UDP 포트·페이로드 첫 8B를 추출하는 파서를 작성해 VLAN 유무로 바뀌는 오프셋을 처리하고, cocotb에서 scapy로 만든 패킷과 비교하며 첫 바이트 입력→필드 valid까지의 사이클 지연과 1 beat/cycle 유지를 측정한다(HFT FPGA 맥락은 see:QFIN, see:LLAT).		외부환경필요fpga
RTLDV-A10Advanced버그 헌팅: 파형·Assertion·Formal Cover로 RTL 결함 국소화
앞서 만든 async FIFO·skid buffer·arbiter에 각각 은닉 버그(Gray 변환 비트 오류, skid 2번째 엔트리 덮어쓰기, RR 마스크 갱신 누락)를 넣은 버전을 서로 섞어 놓고, 실패 시드 → 파형 → assertion 추가 → sby cover/bmc로 최소 반례 트레이스 생성까지의 과정을 각 버그별 RCA 리포트(증상·근본원인·수정·재발 방지 assertion)로 작성한다(면접 '이 파형에서 버그를 찾아라' 대비).		외부환경필요fpga
RTLDV-A11Advanced캡스톤: CSR·스트림·인터럽트를 갖춘 가속기 블록 설계·검증
APB CSR(M13 생성)·AXI-Stream 입출력·완료 인터럽트를 가진 CRC32/dot-product 가속기를 스펙 문서(레지스터 맵, 타이밍, 에러 처리)부터 작성해 RTL로 구현하고, pyuvm TB(A01/A02 재사용)·인터페이스 SVA·sby 인터페이스 증명·기능 커버리지 클로저·yosys 면적/Fmax 리포트를 갖춘 검증 사인오프 체크리스트로 마무리한다(systolic array RTL은 see:NPU-A09, DPI-C 참조모델은 see:EMU-M03).		외부환경필요fpga
