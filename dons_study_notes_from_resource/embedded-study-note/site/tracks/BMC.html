Stage 8 · BMC · Server Management Controller (BMC)

서버 관리 컨트롤러

아이템 27Basic 9Mid 10Advanced 8학습가능 0

BMC(Baseboard Management Controller)는 ASPEED AST2600 같은 SoC 위에서 OpenBMC(Linux + D-Bus 데몬)를 돌리며 서버의 전원·센서·팬·로그·펌웨어 업데이트·원격 콘솔을 호스트 CPU와 독립적으로 관리한다. Google·Meta·Microsoft·NVIDIA·AMD의 플랫폼/데이터센터 하드웨어 팀 면접에서는 IPMI/Redfish/PLDM/MCTP 메시지, 팬 PID, 전원 시퀀싱, 서명 이미지·RoT를 코드와 설계로 설명할 수 있는지를 보며, Don의 SSD·PCIe 경험과도 직접 연결된다.

트랙 목표

  • BMC 하드웨어(AST2600)와 OpenBMC 소프트웨어 스택(D-Bus, systemd, bmcweb)을 설명하고 QEMU에서 다룰 수 있다
  • PMBus/SMBus 센서, IPMI 메시지·SDR·SEL, 임계값 이벤트를 구현할 수 있다
  • KCS 호스트 인터페이스, 전원 시퀀싱, PID 팬 제어, 워치독·호스트 복구를 구현할 수 있다
  • Redfish, MCTP, PLDM(모니터링·펌웨어 업데이트) 메시지와 상태 머신을 구현할 수 있다
  • 서명 이미지·Root of Trust·SPDM과 플릿 단위 BMC 관리 시스템을 설계할 수 있다
