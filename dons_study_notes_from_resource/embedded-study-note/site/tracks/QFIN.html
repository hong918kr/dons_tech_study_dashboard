시장 미시구조 · 트레이딩 시스템

아이템 33Basic 11Mid 13Advanced 9학습가능 0

시장 미시구조·트레이딩 시스템 트랙은 HRT·Jane Street·Citadel Securities·Optiver·IMC·Jump 같은 회사의 quant developer / trading-systems SWE 면접에서 요구하는 도메인 지식을 직접 구현하며 익힌다. 주문 유형과 매칭 규칙, 시장 데이터 피드 복구, FIX 세션, 사전 리스크와 OMS, 백테스터, 옵션 가격결정, 마켓메이킹·실행 알고리즘까지 C++(실행 경로)와 Python(분석)으로 만든다. 오더북 자료구조·ITCH·SBE·tick-to-trade 지연 최적화는 LLAT 트랙을 토대로 쌓는다.

트랙 목표

  • 주문 유형·TIF·경매·pro-rata 등 실제 거래소 규칙을 매칭 엔진에 구현하고 테스트로 증명한다
  • A/B 피드 아비트리지·갭 복구·MBO→MBP 변환으로 손실 없는 시장 데이터 경로를 만든다
  • FIX 파서·세션 계층, 사전 리스크 게이트, OMS로 주문 경로의 정확성과 장애 대응을 다룬다
  • 편향 없는 이벤트 기반 백테스터와 PnL 회계로 전략을 정직하게 평가한다
  • 옵션 가격결정(이항·BS·MC·IV·변동성 표면)과 Greeks 리스크를 구현한다
  • 마켓메이킹·통계적 차익·실행 알고리즘을 시뮬레이션하고 거래소/연결성 설계를 설명한다

체결·가격 틱마다 기초자산별 delta/gamma/vega/theta를 증분 갱신하는 C++ 리스크 엔진과, 기초가격×변동성 충격 시나리오 그리드 PnL, historical VaR을 계산해 전체 재계산 결과와 일치·갱신 지연을 측정하고 델타 헤지 트리거 규칙을 설계한다.		준비중mac
QFIN-A05AdvancedAlmgren-Chriss 최적 실행
영구·일시 선형 충격 하 Almgren-Chriss 해(sinh 궤적)를 구현해 위험 회피 λ별 기대 비용-분산 효율적 경계를 그리고, M13 TWAP/VWAP과 Monte Carlo로 비교해 이론 경계 위에 놓이는지 확인한다.		준비중mac
QFIN-A06Advanced스마트 오더 라우터(SOR)
거래소별 호가·수수료/리베이트·지연·숨은 유동성 체결 확률을 가진 다중 거래소 시뮬레이터에서 가격 우선(Reg NMS trade-through 금지) 스윕, 수수료 반영 순가격 라우팅, 지연 차를 고려한 동시 도착(sweep timing) 라우터를 구현해 체결률·평균 비용을 비교한다.		준비중mac
QFIN-A07Advanced거래소 설계: 시퀀서·저널·결정적 리플레이
TCP 주문 게이트웨이(M05 FIX 세션) → 단일 시퀀서 → 매칭 엔진 → 저널 → 멀티캐스트 시장 데이터 발행(M03 형식)으로 이어지는 미니 거래소를 구현하고, 저널 리플레이로 매칭 상태가 비트 단위로 재현됨과 primary 장애 시 backup이 저널로 이어받는 failover를 시연한다(파이프라인 지연 분해는 see:LLAT-A07, 복제 모델은 see:DIST-M05).		준비중mac
QFIN-A08AdvancedFPGA 트레이딩 가속: 사이클 모델 피드 파서
64비트/클럭 데이터 경로로 ITCH 메시지를 cut-through 파싱하고 top-of-book을 갱신해 트리거 주문을 내는 파이프라인을 C++ 사이클 모델로 구현해 첫 바이트 도착→주문 첫 바이트 송신 사이클 수를 계산하고, 소프트웨어 경로(LLAT-A07)와의 지연 예산을 비교한다(HDL 구현·검증은 see:RTLDV, 선택적으로 Verilator).		준비중mac
QFIN-A09Advanced거래소 연결성: 코로케이션·전송 매체·시간 동기
광섬유(n≈1.47) vs 마이크로웨이브 vs 직선 거리로 시카고–뉴저지 편도 지연을 계산하고, 코로 내부 크로스커넥트·스위치 홉 지연 예산, MiFID II RTS 25 시계 정확도(UTC 대비 100µs) 준수를 위한 PTP 오프셋 모니터링 스크립트를 Python으로 작성해 설계 문서로 정리한다(PTP는 see:DIST-M01, 타임스탬핑은 see:LLAT-A04).		준비중mac
