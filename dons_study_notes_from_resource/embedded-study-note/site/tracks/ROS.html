Stage 9 · ROS · Robot Software Stack

로봇 소프트웨어 스택

아이템 23Basic 8Mid 9Advanced 6학습가능 0

ROS 2는 로봇·드론·자율주행 스타트업의 사실상 표준 미들웨어이며, 펌웨어 엔지니어는 micro-ROS·하드웨어 인터페이스·실시간 성능 경계에서 자주 만난다. 이 트랙은 ROS 2를 '사용'하는 것과 동시에, 직렬화·QoS·executor·tf를 갖춘 미니 pub/sub 미들웨어를 C++로 직접 구현해 내부 동작을 이해한다.

트랙 목표

  • ROS 2의 노드·토픽·서비스·액션·파라미터·launch 구조를 실습으로 익힌다
  • DDS QoS와 executor/callback group 동작을 실험으로 설명할 수 있다
  • CDR 직렬화·discovery·QoS·executor·shared-memory 전송을 갖춘 미니 미들웨어를 구현한다
  • tf2 변환 트리와 rosbag(MCAP) 기록/재생을 직접 구현한다
  • 실시간 ROS 2와 micro-ROS로 MCU-호스트 경계를 설계한다
