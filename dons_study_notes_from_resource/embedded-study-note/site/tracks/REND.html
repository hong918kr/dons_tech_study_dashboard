Stage 9 · REND · Rendering

렌더링

아이템 22Basic 7Mid 8Advanced 7학습가능 0

GFX 트랙의 기하·래스터화 부품을 바탕으로 레이 트레이서와 프로그래머블 소프트웨어 렌더러를 만들어 GPU 파이프라인이 내부에서 무엇을 하는지(셰이딩, 블렌딩, 텍스처 필터링, 그림자, AA, 타일 기반 처리)를 이해한다. Apple·NVIDIA·Qualcomm GPU/디스플레이 펌웨어·드라이버 직무에서 요구하는 GPU API(Metal/Vulkan) 개념과 렌더 그래프·동기화까지 연결한다.

트랙 목표

  • 레이-기하 교차·재질·경로 추적으로 물리 기반 레이 트레이서를 구현한다
  • GFX 트랙의 래스터화 부품을 프로그래머블 소프트웨어 GPU 파이프라인으로 조립한다
  • Phong·PBR 셰이딩, 텍스처 mipmap, 그림자, 안티에일리어싱을 구현하고 비교한다
  • forward/deferred/tiled 구조와 타일 기반 GPU(TBDR) 개념을 이해한다
  • Metal로 실제 GPU 파이프라인·동기화를 다루고 렌더 그래프를 설계한다
