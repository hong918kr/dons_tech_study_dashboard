Stage 9 · GAME · Game Engine Architecture

게임 엔진 구조

아이템 24Basic 8Mid 9Advanced 7학습가능 0

게임 엔진은 고정 프레임 예산 안에서 수만 개 객체를 처리하는 '소프트 실시간 시스템'으로, 메모리 아레나·잡 시스템·데이터 지향 설계·결정적 네트워킹 같은 기법이 임베디드·로봇 소프트웨어와 그대로 겹친다. 이 트랙은 게임 루프부터 ECS, 잡 시스템, 에셋 파이프라인, 롤백 넷코드까지 C++로 구현해 미니 엔진을 완성한다.

트랙 목표

  • 게임 루프·이벤트·씬 그래프 등 엔진 골격을 구현한다
  • 아레나/풀 할당자와 generational handle로 메모리를 예측 가능하게 관리한다
  • sparse-set/아키타입 ECS와 데이터 지향 설계로 캐시 효율을 측정·개선한다
  • work-stealing·fiber 잡 시스템으로 멀티코어 프레임 처리를 구현한다
  • 결정적 락스텝과 롤백 넷코드로 네트워크 동기화를 구현한다
