Stage 9 · COMP · Compilers

컴파일러

아이템 28Basic 9Mid 10Advanced 9학습가능 0

작은 C 계열 언어(TinyC)를 대상으로 렉서→파서→타입 검사→SSA IR→최적화→레지스터 할당→AArch64 코드 생성까지 직접 구현해 M2에서 실행한다. 컴파일러를 알면 펌웨어 성능 튜닝·디스어셈블리 읽기가 쉬워지고, NPU/AI 가속기 회사의 ML 컴파일러(TVM·MLIR) 팀과 대화할 수 있는 기반이 된다.

트랙 목표

  • TinyC 언어의 렉서·재귀 하강 파서·AST·인터프리터를 구현한다
  • SSA 기반 IR을 만들고 상수 전파·DCE·GVN·LICM 최적화를 구현한다
  • linear scan 레지스터 할당과 명령어 선택으로 실행 가능한 AArch64 어셈블리를 생성한다
  • LLVM 패스·MLIR lowering을 직접 다뤄 산업용 컴파일러 구조를 읽는다
  • ML 그래프 컴파일러(퓨전·타일링)를 NPU 타깃 개념과 연결한다
