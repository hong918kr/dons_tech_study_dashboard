플랫폼 소프트웨어

아이템 32Basic 11Mid 12Advanced 9학습가능 0

플랫폼 소프트웨어는 SoC가 켜지는 순간부터 OS가 안정적으로 돌기까지의 '바닥층'(부트 체인, TF-A/PSCI, UEFI/ACPI, 전원·클럭, 코어 간 IPC, 업데이트·텔레메트리)을 책임진다. 실리콘·AI 가속기·로봇 SoC 회사의 플랫폼/펌웨어 팀 면접에서 자주 묻는 설계 감각을 직접 구현하며 익힌다.

트랙 목표

  • BootROM부터 OS까지 부트 체인과 EL/보안 상태 전환을 설명·모델링한다
  • PSCI·SCMI·UEFI 같은 펌웨어 표준 인터페이스를 구현 수준으로 이해한다
  • 클럭·리셋·핀먹스·PMIC와 DVFS/suspend/thermal 전원 관리를 설계한다
  • 메일박스·vring 기반 코어 간 통신과 remoteproc 구조를 구현한다
  • A/B 업데이트, 크래시 덤프, 텔레메트리, 프로비저닝 같은 제품 수명주기 기능을 만든다

PLAT-B01BasicSoC 부트 체인 지도: BootROM→BL1/BL2→BL31→BL33
가상 SoC 부트 체인 시뮬레이터(C)를 작성: 각 스테이지가 다음 이미지 헤더(magic, load_addr, size, entry, CRC32)를 검사해 '로드 후 점프'하고 hand-off 구조체(메모리 맵, 부트 소스)를 전달하며, 손상 이미지 주입 시 백업 슬롯으로 fallback하는지 테스트한다.		준비중mac

bootloader+kernel+dtb를 정렬된 오프셋으로 패킹하고 목차 헤더(TOC: 이름, 오프셋, 크기, 해시)를 생성하는 Python 이미지 패커와 C 언패커를 작성해 왕복(round-trip) 검증 및 오정렬/겹침 검출 테스트를 한다.		준비중mac
PLAT-B03BasicARMv8 Exception Level·보안 상태와 SMC/ERET
EL/보안 상태 전이를 C 상태머신으로 모델링하고 SMC 호출 시 EL3 디스패처가 NS 컨텍스트(x0–x7, ELR, SPSR)를 저장→서비스→복원하는 흐름을 구현, 잘못된 전이(EL0에서 SMC 등)가 거부되는지 테스트한다.		준비중mac
PLAT-B04BasicPSCI 인터페이스: CPU_ON/OFF, SYSTEM_RESET
SMCCC function ID 인코딩(fast/yielding, 32/64, owner)을 디코드하고 PSCI 디스패처를 구현: 코어별 상태(ON/OFF/ON_PENDING), CPU_ON 중복 호출 시 ALREADY_ON, 잘못된 MPIDR 시 INVALID_PARAMS 반환을 단위 테스트로 검증한다.		준비중mac
PLAT-B05Basic클럭 트리 모델링: PLL, divider, mux, gate
clk 노드(PLL/divider/mux/gate)로 클럭 트리를 C로 구성하고 recalc_rate 전파, set_rate 시 최적 divider/parent 선택, enable/disable 참조 카운트(부모 자동 enable)를 구현해 clk_summary 형식으로 출력·검증한다.		준비중mac
PLAT-B06Basic리셋·핀먹스 컨트롤러 추상화
pin→function 테이블 기반 pinmux 요청/해제 API(충돌 검사, 소유자 기록)와 reset line assert/deassert API(지연, 의존 순서)를 mock 레지스터 위에 구현하고, UART+SPI 공유 핀 충돌 시나리오로 테스트한다.		준비중mac
PLAT-B07BasicHAL 설계: ops 구조체와 벤더 포팅 레이어
UART HAL(init/tx/rx/irq 콜백) 인터페이스를 정의하고 레지스터 맵이 다른 가상 벤더 A/B 백엔드 두 개를 구현, 동일한 테스트 스위트가 두 백엔드 모두 통과하도록 하고 추상화 비용(간접 호출)을 논의한다.		준비중mac
PLAT-B08Basic펌웨어 버전·빌드 메타데이터 임베드
빌드 시 semver+git hash+dirty 플래그+build ID를 전용 섹션(.fw_info)에 넣는 스크립트/링커 설정을 만들고, 바이너리에서 이를 추출하는 호스트 툴과 버전 비교 함수(pre-release 포함) 단위 테스트를 작성한다.		준비중mac
PLAT-B09Basic보드 bring-up 체크리스트: 전원→클럭→메모리→콘솔
가상 보드용 bring-up 계획서(전원 레일·리셋·클럭·DDR·UART first-light·JTAG 접속 체크)와 각 단계별 smoke-test 펌웨어 코드 경로(mock HW)를 작성하고, 단계 실패 시 다음 디버깅 액션을 표로 정리한다.		준비중mac
PLAT-B10Basic바이너리 로깅: 포맷 ID와 지연 포매팅
로그 호출을 (포맷 문자열 ID + 인자) 바이너리 레코드로 링버퍼에 기록하는 인코더와, ELF의 문자열 테이블로 사람이 읽을 로그를 복원하는 호스트 디코더를 작성해 printf 대비 코드 크기·실행 시간을 측정한다.		준비중mac
PLAT-B11BasicACPI vs Device Tree: 하드웨어 기술 방식 비교
샘플 DSDT를 iasl로 디컴파일해 _HID/_CRS/_STA 의미를 정리하고 같은 장치(UART, I2C 센서)를 DTS로 다시 기술, 열거·전원 제어 방식 차이를 비교표로 작성한다.		준비중mac

PLAT-M01Mid전원 상태 머신: Run/Idle/Sleep/Deep-sleep
상태별 전력·진입/복귀 지연·wakeup source를 가진 전력 관리 시뮬레이터를 작성하고 idle 구간 트레이스에 대해 break-even time 기반 상태 선택 정책을 구현해 에너지·지연을 비교한다.		준비중mac
PLAT-M02MidDVFS 거버너: OPP 테이블과 전압/주파수 전환 순서
OPP 테이블과 부하 트레이스를 입력으로 ondemand/schedutil 유사 거버너를 구현하고 전환 순서 위반을 검출하는 regulator/clk mock을 둬서, 정책별 에너지(∝CV²f)와 마감 미스를 비교한다.		준비중mac
PLAT-M03MidSuspend/Resume 경로: 디바이스 순서와 롤백
부모-자식 디바이스 트리에 대해 suspend(자식→부모)/resume(부모→자식) 프레임워크를 구현하고, 중간 디바이스 suspend 실패 시 이미 내려간 디바이스를 역순 resume하는 롤백과 wakeup 소스 처리를 테스트한다.		준비중mac
PLAT-M04MidThermal 관리: 센서→trip point→cooling device
간단한 열 모델(RC) 위에서 trip point(passive/critical), step-wise와 PID 쓰로틀링 거버너를 구현하고 히스테리시스 유무에 따른 진동, 최대 온도, 성능 손실을 비교한다.		준비중mac
PLAT-M05Mid멀티코어 메일박스 IPC: 공유 메모리 + doorbell
두 스레드를 두 코어로 보고 공유 메모리 슬롯 + doorbell(인터럽트 대용 조건변수) 메일박스를 구현, 헤더(type, seq, len), ACK/타임아웃/재전송, 메모리 배리어 위치를 포함한 프로토콜을 스트레스 테스트한다.		준비중mac
PLAT-M06Midremoteproc/rpmsg 개념과 virtio vring 구현
virtio split vring(desc/avail/used, 인덱스 wrap)을 C로 구현해 두 프로세스(공유 메모리) 간 rpmsg 유사 엔드포인트 메시징을 만들고, remoteproc 리소스 테이블(carveout, vdev, trace) 파서도 작성한다.		준비중mac
PLAT-M07Mid펌웨어 업데이트: A/B 슬롯과 부트 카운터
A/B 슬롯 메타데이터(active, trial, bootcount, good)와 부트로더 선택 로직, 앱의 mark-good을 구현하고, 각 단계 임의 지점 전원 차단 주입 테스트로 항상 부팅 가능한 슬롯이 남는지 검증한다.		준비중mac
PLAT-M08Mid설정 저장소 운영: 스키마 버전·마이그레이션·공장 초기화
버전 태그가 붙은 설정 레코드에 대해 구버전→신버전 마이그레이션 체인, 기본값 채우기, 공장 초기화·손상 시 폴백을 구현하고, 다운그레이드·마이그레이션 중 전원 차단 시나리오를 테스트한다(플래시 KV 저장 엔진은 see:DS-A10).		준비중mac
PLAT-M09Mid디바이스 텔레메트리: 카운터, 히스토그램, heartbeat
펌웨어 메트릭 레지스트리(카운터/게이지/로그 스케일 히스토그램)와 주기적 heartbeat 스냅샷을 TLV로 직렬화하는 코드, 이를 파싱해 CSV로 내보내는 호스트 수집기를 작성한다.		준비중mac
PLAT-M10Mid멀티코어 SoC 크래시 수집: 코어별 덤프와 업로드 큐
앱 코어·실시간 코어·DSP 각각의 크래시 레코드를 공유 예약 메모리에 기록하는 프로토콜(시퀀스 번호·CRC·소유 플래그)과 재부팅 후 수집·영구 저장·업로드 큐를 구현해 동시 크래시·연쇄 리셋 시나리오를 테스트한다(단일 MCU 캡처는 see:BM-A09, 디코더는 see:TOOL-A05).		준비중mac
PLAT-M11MidUEFI 기초: Boot/Runtime Services와 Hello UEFI 앱
gnu-efi(또는 EDK2 최소 앱)로 Hello UEFI 앱을 빌드해 QEMU+OVMF/AAVMF에서 실행하고 GetMemoryMap 결과와 UEFI 변수(BootOrder)를 출력, ExitBootServices 이후 사용 가능한 서비스 차이를 정리한다.		외부환경필요qemu
PLAT-M12MidTF-A on QEMU: BL31 런타임 서비스와 커스텀 SiP SMC
TF-A를 qemu 플랫폼으로 빌드해 BL1/BL2/BL31 로그를 확인하고, BL31에 커스텀 SiP 서비스(SMC ID 하나)를 추가한 뒤 Linux 모듈에서 arm_smccc_smc로 호출해 반환값을 검증한다.		외부환경필요qemu
Advanced · 9개
PLAT-A01Advanced측정 부트(Measured Boot)와 이벤트 로그 재생
SHA-256 기반 PCR extend(PCR = H(PCR || digest))와 TCG 스타일 이벤트 로그를 각 부트 스테이지 모델에 넣고, 이벤트 로그를 재생해 최종 PCR 값과 일치하는지/변조 시 불일치하는지 검증하는 verifier를 작성한다.		준비중mac
PLAT-A02AdvancedSCMI: AP↔SCP 전원·클럭 제어 프로토콜
SCMI 헤더(protocol_id, message_id, token, type)와 shared memory 채널을 구현해 agent(AP)와 platform(SCP) 스레드 간 BASE/CLOCK/PERF 프로토콜 일부(rate get/set, 지원 목록)를 주고받게 하고 비동기 지연 응답도 처리한다.		준비중mac
PLAT-A03Advanced멀티코어 부팅: spin-table vs PSCI, holding pen
pthread로 코어를 흉내 내 holding pen(spin-table: release_addr 폴링) 방식과 PSCI CPU_ON 방식을 구현하고, release 값 쓰기 전후 배리어(DSB/SEV 대응) 누락 시 발생할 수 있는 문제를 주석과 테스트로 설명한다.		준비중mac
PLAT-A04Advanced제조·프로비저닝 흐름: 시리얼, 캘리브레이션, 키 주입
호스트 프로비저닝 툴(Python) ↔ 디바이스 mock(pty UART) 프로토콜을 만들어 시리얼·MAC·캘리브레이션 값·디바이스 키를 OTP 모델(1회 기록, 비트 0→1만 가능)에 쓰고, 검증 후 공장 모드 잠금까지 수행하며 중복/재시도 시나리오를 테스트한다.		준비중mac
PLAT-A05Advanced업데이트 전송 프로토콜: 청크, 재개, 무결성
Python 업데이터 ↔ C 디바이스 mock(소켓/pty) 간 청크 전송 프로토콜(청크 CRC, 오프셋 기반 재개, 윈도우 ACK, 최종 SHA-256)을 구현하고 패킷 손실·중복·연결 끊김 주입 테스트 후 A/B 슬롯 스왑까지 연결한다.		준비중mac
PLAT-A06Advanced리셋 원인 분석과 부트 루프 복구(safe mode)
reset reason 레지스터(POR, WDT, SW, brownout, lockup) 디코더와 부트 이력 링버퍼를 구현하고, N분 내 M회 비정상 리셋 시 safe mode(최소 기능+업데이트 경로만) 진입·해제 정책을 시나리오 테스트한다.		준비중mac
PLAT-A07AdvancedPMIC와 전원 시퀀싱 드라이버
I2C regmap mock 위에 가상 PMIC 드라이버를 작성해 데이터시트식 시퀀스 테이블(레일, 전압, 지연, 의존)로 power-up/down을 수행하고 PGOOD 타임아웃·과전류 폴트 주입 시 안전한 역순 shutdown을 검증한다.		준비중mac
PLAT-A08AdvancedLinux 클럭 provider 드라이버(CCF)
fixed-rate + divider + gate로 구성된 가짜 클럭 컨트롤러 platform driver를 작성(clk_hw_register_*, of_clk_add_hw_provider)하고 소비자 드라이버가 clk_get/set_rate하는 모습을 /sys/kernel/debug/clk/clk_summary로 검증한다.		외부환경필요qemu
PLAT-A09Advanced종합: 가상 SoC 플랫폼 펌웨어 아키텍처 리뷰
가상 AI 가속기 SoC(AP+관리 MCU+NPU)의 플랫폼 펌웨어 설계 문서를 작성(부트 체인, PM 상태, 메일박스 프로토콜, A/B 업데이트, 크래시/텔레메트리 경로)하고 핵심 코드 경로 3개를 앞선 항목 코드로 연결, trade-off를 면접식으로 방어한다.		준비중mac
