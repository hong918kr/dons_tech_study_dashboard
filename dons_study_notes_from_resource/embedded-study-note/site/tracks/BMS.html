Stage 8 · BMS · Battery Management Systems

배터리 관리 시스템

아이템 27Basic 9Mid 10Advanced 8학습가능 0

BMS 펌웨어는 수백 개 셀의 전압·전류·온도를 정밀하게 측정하고, SoC/SoH/SoP를 추정하며, 보호·밸런싱·컨택터·충전 제어를 기능안전 수준으로 수행한다. Tesla·Rivian·Lucid·Joby·에너지 저장 회사 면접에서는 셀 모니터 IC 통신(isoSPI/PEC), 쿨롱 카운팅과 EKF의 한계, 프리차지 시퀀스, 보호 디바운스를 구체적인 코드와 숫자로 설명할 수 있어야 하므로, 셀 모델 시뮬레이터 위에서 전부 직접 만들어 본다.

트랙 목표

  • Li-ion 셀 OCV 곡선과 등가회로 모델을 이해하고 시뮬레이터를 만들 수 있다
  • 전압·전류·온도 측정 체인과 셀 모니터 IC 데이지체인(isoSPI, PEC) 드라이버를 구현할 수 있다
  • 쿨롱 카운팅·OCV·EKF로 SoC를, 용량/저항 변화로 SoH를, 한계 전력(SoP)을 추정할 수 있다
  • OV/UV/OC/OT 보호, 셀 밸런싱, 프리차지/컨택터, CC/CV 충전, 열 관리를 구현할 수 있다
  • ISO 26262 관점의 BMS 안전 목표와 열폭주 감지, 전체 팩 아키텍처를 설계할 수 있다

BMS-B01Basic셀 기초: OCV-SoC 곡선과 화학별 차이
NMC·LFP OCV-SoC 테이블을 선형 보간하는 OCV(SoC)·SoC(OCV) 함수를 C로 구현하고(단조성 검사, 경계 클램프), LFP 평탄 구간에서 10 mV 전압 오차가 몇 % SoC 오차가 되는지 계산해 비교한다.		준비중mac
BMS-B02Basic등가회로 셀 모델 (Rint / 1-RC Thevenin)
OCV(SoC) + R0 + R1‖C1 1-RC 모델을 이산화한 셀 시뮬레이터를 작성하고, 펄스 방전(HPPC 유사) 프로파일에서 순간 강하와 완화(relaxation) 곡선을 출력해 R0/R1/τ가 파형의 어디에 나타나는지 확인한다. 이후 모든 항목의 테스트 플랜트로 재사용한다.		준비중mac
BMS-B03Basic셀 전압 측정 체인과 보정
16비트 ADC 코드 → 셀 전압 변환, 2점 게인/오프셋 보정, 이동평균/IIR 필터를 구현하고, 오차 예산(ADC LSB, 기준전압 온도계수, 필터 지연)을 계산해 ±2 mV 목표를 만족하는지 시뮬레이션으로 검증한다.		준비중mac
BMS-B04Basic전류 측정: 션트·홀 센서와 오프셋 보정
션트 저항 + 증폭기 체인의 코드→암페어 변환, 컨택터 개방(전류 0) 시점의 자동 영점 보정, 두 레인지(저전류 정밀/고전류) 센서 선택 로직을 구현하고 10 mA 오프셋이 24시간 동안 만드는 Ah 오차를 계산한다.		준비중mac
BMS-B05Basic온도 측정: NTC 변환과 센서 고장 검출
분압 회로 ADC 값을 NTC 저항 → 온도로 바꾸는 Beta 식과 Steinhart-Hart 식(룩업 테이블 버전 포함)을 구현하고, 범위를 벗어나는 개방/단락 판정과 이웃 센서와의 타당성 검사를 추가해 테스트한다.		준비중mac
BMS-B06Basic보호 기능: OV/UV/OC/OT 임계값·히스테리시스·디바운스
셀 OV/UV, 팩 충·방전 OC(I²t 또는 다단 시간-전류 곡선), OT/UT를 경고·제한·차단 3단계로 판정하는 보호 모듈을 구현하고(히스테리시스·디바운스 포함), 노이즈 스파이크와 실제 고장 프로파일로 응답 시간을 검증한다.		준비중mac
BMS-B07Basic쿨롱 카운팅 SoC 추정
쿨롱 효율·공칭 용량·샘플 주기를 반영한 쿨롱 카운팅 SoC를 구현하고, B02 셀 모델 주행 사이클에 전류 센서 오프셋·게인 오차를 넣어 SoC 드리프트를 측정한 뒤, 충분한 휴지 후 OCV로 재보정하는 로직을 추가한다.		준비중mac
BMS-B08Basic셀 모니터 IC 드라이버: 명령·PEC15
PEC15 CRC(다항식 0x4599, 초기값 16)를 구현하고, mock SPI 위의 셀 모니터 IC 모델(ADCV 변환 시작, RDCVA..D 그룹 읽기, 설정 레지스터 쓰기·읽어 검증)과 드라이버를 작성해 PEC 오류·변환 미완료 상황을 테스트한다.		준비중mac
BMS-B09Basic수동 셀 밸런싱 알고리즘
최저 셀 대비 ΔV 임계값·최소 전압 조건으로 방전 셀을 선택하고, 측정 시점에는 밸런싱을 멈추는 듀티 스케줄과 IC 온도 기반 동시 밸런싱 수 제한을 구현해, 불균형 팩 시뮬레이션에서 수렴 시간을 측정한다.		준비중mac
Mid · 10개
BMS-M01MidisoSPI 데이지체인 통신
N개 IC 체인 모델(각 IC가 데이터를 shift, 마지막 IC 데이터가 먼저 도착)을 만들고 드라이버에서 IC별 데이터 재정렬, PEC 실패 시 재시도/카운터, 체인 중간 단선 시 위치 진단, 양방향(ring) 체인 폴백을 구현한다.		준비중mac
BMS-M02Mid프리차지·컨택터 제어 상태 머신
DC 링크 커패시터 RC 모델과 함께 Open→Precharge→Close Main→Open Precharge→Closed 상태 머신(전압 95% 도달 조건, 타임아웃, 재시도 제한)을 구현하고, 컨택터 용착(welding)·프리차지 저항 과열·부하 단락 시나리오를 검증한다.		준비중mac
BMS-M03Mid절연 저항 모니터링 (IMD)
HV+/HV− 각각에 기준 저항을 번갈아 연결해 측정한 전압 두 쌍으로 절연 저항을 계산하는 식을 유도·구현하고, 노이즈·Y-커패시턴스 정착 시간을 고려한 측정 타이밍과 500 Ω/V 기준 경고 판정을 테스트한다.		준비중mac
BMS-M04MidEKF 기반 SoC 추정 (1-RC 모델)
상태 [SoC, V_RC] EKF(OCV 기울기 dOCV/dSoC 야코비안)를 구현하고, 초기 SoC 30% 오차·전류 오프셋 조건에서 쿨롱 카운팅 대비 수렴과 RMSE를 비교하며 LFP 평탄 구간에서 관측성이 떨어지는 현상을 보인다.		준비중mac
BMS-M05MidSoH 추정: 용량 페이드와 저항 증가
두 휴지 OCV 사이 적산 Ah / ΔSoC로 용량을 추정하고, 전류 스텝의 ΔV/ΔI로 R0를 추정하는 알고리즘을 구현해 합성 노화 데이터(용량 −20%, R0 +50%)에서 추정 정확도와 신뢰 조건(ΔSoC 최소폭 등)을 평가한다.		준비중mac
BMS-M06MidSoP: 순간 가용 전력과 디레이팅
셀 전압 한계(Vmin/Vmax), R0·RC 상태를 이용해 10초·30초 최대 방전/충전 전류를 예측하는 SoP 함수와 온도·SoC 디레이팅 테이블을 구현하고, 셀 모델 시뮬레이션에서 해당 전류를 실제 인가했을 때 한계를 넘지 않는지 검증한다.		준비중mac
BMS-M07MidCC/CV 충전 알고리즘과 JEITA 온도 제어
셀 모델을 플랜트로 CC/CV 충전 제어 루프(CV 단계 전압 PI 제어, C/20 종료, 타임아웃)와 JEITA 스타일 온도 구간별 전류/전압 제한, 가장 높은 셀 기준 제어를 구현해 불균형 팩 충전 시 개별 셀 과전압이 없는지 확인한다.		준비중mac
BMS-M08MidBMS CAN 보고: 멀티플렉스 신호 설계
팩 상태·한계 전력·고장 비트·셀 전압/온도(멀티플렉스 인덱스)를 담는 DBC를 설계하고 pack/unpack 코드와 송신 스케줄을 구현해 버스 부하를 계산하며, 충전기/VCU 쪽 수신 측 타임아웃 처리도 구현한다.		준비중mac
BMS-M09Mid팩 열 관리: 집중 열 모델과 냉각 제어
셀 그룹별 집중 열용량 모델(발열, 냉각판 전도, 이웃 셀 전달)을 시뮬레이션하고 냉각수 펌프/칠러 PI 제어, 저온 충전 전 히터 예열 로직을 구현해 고부하 주행·급속충전 시 최대 온도와 셀 간 온도 편차를 측정한다.		준비중mac
BMS-M10Mid능동 셀 밸런싱 시뮬레이션
셀 간 전달 효율·전류 한계를 가진 능동 밸런싱 모델에 '최고 셀→최저 셀' 그리디와 SoC 기반 목표 밸런싱 알고리즘을 구현하고, B09 수동 밸런싱 대비 수렴 시간·손실 에너지·가용 용량 증가를 비교한다.		준비중mac
Advanced · 8개
BMS-A01AdvancedBMS 기능안전: 안전 목표와 독립 2차 보호
과충전 위해에 대한 안전 목표·FTTI를 정의하고, 주 MCU 보호와 독립된 2차 OV 경로(별도 비교기/AFE 하드와이어 출력 모델)와 교차 감시를 구현한 뒤, 한 채널 고장 주입 시 FTTI 안에 안전 상태(컨택터 개방)로 가는지 검증한다.		준비중mac
BMS-A02Advanced열폭주 조기 감지: 다중 지표 융합
셀 전압 급락(dV/dt), 온도 상승률(dT/dt), 가스·압력 센서 신호를 persistence 조건과 투표 규칙으로 결합하는 감지기를 구현하고, 정상 급속충전·센서 고장·실제 전조 합성 프로파일에서 검출 시간과 오탐률을 측정한다.		준비중mac
BMS-A03Advanced내부 단락·자기방전 이상 셀 검출
휴지 구간 셀별 OCV 감소율과 누적 밸런싱 방전량을 추적해 팩 통계 대비 이상치(z-score, 이동 윈도우)를 찾는 알고리즘을 구현하고, 미세 누설 셀을 주입한 장기 시뮬레이션에서 검출까지 걸린 시간을 측정한다.		준비중mac
BMS-A04Advanced분산 BMS 아키텍처와 V/I 동기 샘플링
셀 모니터 IC 변환 시점과 전류 샘플 시점이 수 ms 어긋난 경우를 시뮬레이션해 R0/SoC/SoP 추정 오차를 정량화하고, 동기 트리거·타임스탬프 보간으로 보정하는 방식을 구현하며 중앙/분산/무선 BMS 구조 트레이드오프를 정리한다.		준비중mac
BMS-A05AdvancedDual EKF: SoC와 모델 파라미터 동시 추정

BMS-A06AdvancedNVM 데이터 관리: SoC/이력 저장과 전원 차단 내성
mock 플래시/EEPROM 위에 이중 복사 + 시퀀스 번호 + CRC 레코드 저장, 셧다운 시 SoC 저장 경로, 섹터 순환 마모 분산을 구현하고 쓰기 중 무작위 전원 차단을 수천 번 주입해 항상 최신 유효 레코드를 복구하는지 검증한다.		준비중mac
BMS-A07AdvancedBMS HIL 스타일 테스트: 셀 에뮬레이터 + 결함 주입
앞에서 만든 셀/열/AFE/전류 센서 모델을 묶은 팩 에뮬레이터와 BMS 펌웨어를 HAL 경계로 연결하고, 주행·급속충전·센서 단선·AFE 통신 끊김·컨택터 용착 시나리오를 YAML로 정의해 자동 실행·판정하는 하네스를 작성한다.		준비중mac
BMS-A08Advanced시스템 설계: 800 V EV 팩 BMS
800 V·200셀 직렬 팩을 가정해 AFE 배치·통신 토폴로지·MCU 이중화·컨택터/프리차지/퓨즈·IMD·열관리·CAN 인터페이스·OTA·안전 목표를 포함한 설계 문서를 작성하고, 측정 주기·보호 응답 시간·SoC 정확도 예산을 숫자로 정리한다.		준비중mac
