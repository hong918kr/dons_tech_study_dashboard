GPU 연산

아이템 26Basic 9Mid 10Advanced 7학습가능 0

GPU 연산은 AI 가속기 시대의 공용어다. SIMT 실행 모델, 워프/occupancy, 메모리 계층(global/shared/register), coalescing과 bank conflict를 이해해야 GEMM·reduction·softmax 같은 핵심 커널의 성능을 설명할 수 있고, NVIDIA·Apple·AI 칩 회사 면접에서 이 커널들을 직접 최적화하는 문제가 단골로 나온다. 이 트랙은 M2 맥의 Metal compute와 CPU 기반 SIMT 시뮬레이터로 대부분을 실습하고, CUDA 전용 내용은 gpu 환경 항목으로 분리한다.

트랙 목표

  • SIMT 실행 모델(그리드/블록/워프, divergence, 지연 은닉)을 시뮬레이터로 재현하고 설명할 수 있다
  • 메모리 계층과 coalescing, shared memory bank conflict, occupancy를 정량적으로 분석할 수 있다
  • reduction, scan, histogram, tiled GEMM, convolution, softmax 커널을 Metal로 구현·최적화할 수 있다
  • 커널을 프로파일링해 memory-bound/compute-bound를 판정하고 피크 대비 효율을 보고할 수 있다
  • CUDA로 포팅해 Nsight 지표로 검증하고, 수치 결정성·혼합 정밀도 이슈를 다룰 수 있다

GPGPU-B09BasicAtomic과 Barrier: 레이스와 동기화

GPGPU-M01Mid병렬 Reduction: 단계별 최적화
Metal로 sum reduction을 interleaved addressing → sequential addressing → 로드 시 첫 덧셈 → simd_sum(워프 셔플) → 다중 패스 순으로 최적화하며 각 버전의 GB/s를 측정하고, 피크 대역폭 대비 효율과 float 합산 오차를 기록한다.		준비중mac
GPGPU-M02MidPrefix Sum(Scan): Hillis-Steele vs Blelloch
threadgroup 내 Hillis-Steele과 Blelloch(up-sweep/down-sweep) exclusive scan을 구현하고, 블록 합 스캔 후 더하는 3단계 방식으로 1억 원소 배열 스캔을 완성해 CPU 결과와 일치·처리량을 측정하며 decoupled look-back 단일 패스 방식의 원리를 설명한다.		준비중mac
GPGPU-M03MidHistogram: Privatization과 Atomic 경합
256-bin 히스토그램을 전역 atomic 버전과 threadgroup 지역 히스토그램 + 최종 병합 버전으로 구현하고, 균일 분포와 한 bin에 몰린 편향 분포 입력에서 처리량을 비교한다.		준비중mac
GPGPU-M04MidShared Memory Bank Conflict와 Padding 전치
시뮬레이터에 32-bank shared memory 모델을 넣어 접근 패턴별 conflict degree를 계산하고, Metal로 타일 전치 커널을 naive / threadgroup 타일 / 타일+1 padding 세 버전으로 구현해 conflict 예측과 실측 대역폭을 비교한다.		준비중mac
GPGPU-M05MidTiled GEMM: Shared Memory 타일링과 Register Blocking
Metal로 SGEMM을 naive → threadgroup 타일링 → 스레드당 4x4 register blocking → float4 벡터 로드 순으로 구현해 단계별 GFLOPS와 산술 강도를 기록하고, Accelerate(cblas_sgemm)와 MPS 행렬곱 성능 대비 비율을 보고한다.		준비중mac
GPGPU-M06Mid2D Convolution: Halo 타일과 Separable 필터
KxK 2D 컨볼루션을 naive 전역 메모리 버전과 halo 포함 threadgroup 타일 버전으로 구현하고, 가우시안처럼 분리 가능한 필터는 행/열 두 패스로 나눠 K=3,7,15에서 성능과 결과 일치(허용 오차)를 비교한다.		준비중mac
GPGPU-M07MidSoftmax: 수치 안정성과 Online Softmax
행 단위 softmax를 3-pass(max, sum, normalize)와 online 2-pass(실행 중 max 갱신 시 합 재스케일) 방식으로 Metal에 구현하고, 큰 로짓(1e4) 입력에서 naive 버전의 overflow를 재현하며 행 길이별 메모리 트래픽과 성능을 비교한다.		준비중mac
GPGPU-M08MidStream Compaction과 Radix Sort
M02의 scan으로 predicate 기반 stream compaction을 구현하고, 4비트 digit 단위 LSD radix sort(블록 히스토그램 → 전역 scan → scatter)를 완성해 1천만 개 uint32 정렬 결과를 std::sort와 비교하고 안정성(stable)을 검증한다.		준비중mac
GPGPU-M09Mid비동기 실행과 파이프라이닝: Command Buffer와 Stream
Metal에서 단일 command buffer 직렬 실행과 3개 in-flight command buffer + 세마포어로 CPU 준비·GPU 실행을 겹치는 버전을 구현해 처리량을 비교하고, M2 unified memory에서 shared vs private storage 차이와 CUDA stream·cudaMemcpyAsync 겹치기의 대응 관계를 정리한다.		준비중mac
GPGPU-M10Mid커널 프로파일링과 병목 분류
지금까지 만든 커널들에 대해 FLOP 수와 바이트 수를 계산하고 실측 시간으로 달성 GFLOPS·GB/s를 구해 M2 GPU roofline 위에 표시하며, Xcode Metal GPU capture의 카운터로 한 커널의 병목을 확인해 보고서를 작성한다.		준비중mac

GPGPU-A03AdvancedFused Attention 커널 (FlashAttention 스타일)

GPGPU-A05Advanced불규칙 워크로드: SpMV(CSR)와 부하 분산

GPGPU-A06Advanced커널 퓨전과 런치 오버헤드
