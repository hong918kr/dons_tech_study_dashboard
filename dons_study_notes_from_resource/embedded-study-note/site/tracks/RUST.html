임베디드 Rust

아이템 30Basic 10Mid 13Advanced 7학습가능 1

임베디드 Rust는 C 펌웨어에서 코드 리뷰·정적 분석으로 막던 버그(aliasing, UAF, ISR 데이터 레이스, DMA 버퍼 수명)를 타입 시스템과 소유권으로 컴파일 타임에 막는다. 이 트랙은 일반 Rust 튜토리얼이 아니라 'C/C++로 이미 아는 펌웨어 패턴(링 버퍼, 레지스터 접근, ISR 공유 상태, DMA 버퍼, 에러 처리) → Rust 방식'으로 1:1 번역하며 no_std, embedded-hal, PAC, typestate, RTIC/Embassy, C FFI까지 다룬다. 방산·로보틱스·자동차(Anduril, Rivian, Oxide 등) 펌웨어 팀의 Rust 채택이 늘어 면접에서 'C 대비 무엇이 안전해지고 무엇이 unsafe로 남는가'를 설명할 수 있어야 한다.

트랙 목표

  • 소유권·빌림·라이프타임을 C 포인터 버그 클래스와 대응시켜 설명하고 컴파일 에러로 재현한다
  • #![no_std] 크레이트를 호스트(cargo test)와 thumbv7em-none-eabihf 양쪽에서 빌드·검증한다
  • MMIO 레지스터·PAC(svd2rust)·typestate·싱글톤으로 하드웨어 오용을 타입으로 막는다
  • embedded-hal 트레이트 기반 플랫폼 독립 드라이버를 작성하고 mock으로 호스트 테스트한다
  • ISR 공유 상태·SPSC 큐·DMA 버퍼를 critical-section/atomic/소유권 이전으로 안전하게 설계한다
  • RTIC·Embassy async 동시성 모델과 C↔Rust FFI 경계를 설계하고 trade-off를 설명한다

C로 된 인터럽트 구동 UART + 링 버퍼 + 명령 파서(BM-M04 계열)에서 파서→링 버퍼→드라이버 순으로 Rust로 교체하며 각 단계마다 FFI shim과 기존 C 테스트를 유지하고, 크기·성능·발견된 버그를 비교한 뒤 'unsafe가 남는 곳, 인증(Ferrocene/ISO 26262) 이슈, 팀 도입 비용'을 면접용 1페이지로 정리한다 (see:BM-M04).		준비중mac
