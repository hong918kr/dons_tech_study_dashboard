리눅스 무선 연결성

아이템 30Basic 11Mid 11Advanced 8학습가능 0

카메라·IoT·로봇 기기의 연결성 엔지니어는 리눅스 위에서 Wi-Fi·Bluetooth·셀룰러를 붙이고, 수십만 대 fleet에서 '연결이 끊긴다'는 문제를 로그만으로 풀어야 한다. 이 트랙은 cfg80211/mac80211/nl80211, wpa_supplicant·hostapd, WPA2/WPA3 핸드셰이크, BlueZ/HCI/GATT, 펌웨어 로딩·크래시 복구, 연결 관리 데몬과 프로비저닝을 직접 구현·재현하며 익힌다. PHY·링크 레이어 펌웨어와 BLE 패킷 포맷은 RF 트랙을 기반으로 한다.

트랙 목표

  • 리눅스 무선 스택(nl80211→cfg80211→mac80211→드라이버)과 netlink 메시지를 직접 파싱·호출한다
  • WPA2 4-way handshake, WPA3-SAE, PMF, 802.1X를 테스트 벡터와 시뮬레이터로 구현·검증한다
  • mac80211_hwsim·BlueZ 가상 컨트롤러로 하드웨어 없이 재현 가능한 무선 테스트 랩을 만든다
  • 스캔·로밍·절전·다중 링크 failover 정책을 정량적으로 설계한다
  • 펌웨어 로딩·크래시 복구, BLE 프로비저닝, fleet 연결성 분석으로 실서비스 신뢰성 문제를 다룬다

WCONN-B08BasicPTK 유도와 EAPOL-Key MIC 검증

WCONN-M02MidWPA3-SAE(Dragonfly) 개념 구현
P-256 위에서 password element 유도(hunting-and-pecking과 hash-to-element 두 방식), commit(scalar, element)·confirm 교환, PMK/PMKID 유도를 Python으로 구현해 양측이 같은 PMK를 얻는지 검증하고, hostapd 테스트의 SAE 벡터와 비교한다. hunting-and-pecking 반복 횟수가 비밀번호에 따라 달라지는 타이밍 누설(Dragonblood)과 H2E가 이를 막는 이유를 측정·정리한다.		준비중mac

WCONN-M09MidDHCP 클라이언트 상태기계와 연결 시간 측정
RFC 2131의 INIT→SELECTING→REQUESTING→BOUND→RENEWING→REBINDING 상태기계(지수 백오프 재전송, xid 검사, T1=0.5·T2=0.875 lease)와 옵션 TLV 인코더/파서를 구현하고 mock 서버로 offer 유실·NAK·lease 만료를 테스트한다. 연결 이벤트 타임라인(assoc→4-way→DHCP→첫 패킷)에서 각 구간 지연을 측정하는 계측을 넣는다(UDP/IP 구현 자체는 see:NET).		준비중mac
WCONN-M10Mid연결 관리 데몬: 다중 링크 정책과 failover
링크별 상태(carrier, IP, 연결성 검사 HTTP 204 결과, 손실률)를 이벤트로 받아 route metric과 기본 경로를 바꾸는 정책 엔진을 구현하고, 히스테리시스·쿨다운으로 flapping을 막으며 LTE 데이터 비용을 고려한 '필요할 때만 LTE' 정책을 넣는다. netns + veth로 세 링크를 흉내 내고 링크 장애 주입 시 전환 시간과 끊김을 측정한다(라우팅/netns 상세는 see:NET).		외부환경필요linux
WCONN-M11Mid리눅스 셀룰러: QMI/MBIM 메시지와 ModemManager 모델
QMUX 헤더(I/F type, length, service, client id) + QMI SDU(transaction id, message id) + TLV, 그리고 MBIM 메시지 헤더·Command(service UUID, CID) 인코더/파서를 구현해 libqmi/libmbim 문서의 예제 바이트를 디코드하고, ModemManager 상태(disabled→enabling→registered→connecting→connected)를 따라가는 mock 모뎀으로 신호 소실·재등록 시 bearer 재연결을 테스트한다(AT/URC 파서 기초는 see:RF-M08).		준비중mac

가상 '무선 칩' 커널 모듈에 펌웨어 heartbeat 타임아웃·명령 응답 타임아웃을 감지하는 watchdog을 넣고 dev_coredumpv()로 덤프를 /sys/class/devcoredump에 노출한 뒤, 사용자공간 수집기가 덤프를 저장하고 칩 리셋 → 펌웨어 재로드(B11) → cfg80211 재등록 → 재연결을 수행하게 만든다. 복구 루프 폭주를 막는 재시도 예산과 iwlwifi/ath11k의 실제 recovery 흐름을 비교한다.		외부환경필요linux
WCONN-A05Advanced디바이스 프로비저닝 종합: BLE 온보딩 → Wi-Fi 연결
M08 GATT 서비스 위에 ECDH(X25519) + proof-of-possession(기기 라벨 PIN) 기반 세션 키 수립과 AES-GCM 자격증명 암호화를 얹고, 수신한 SSID/PSK를 M04 ctrl_iface로 적용해 연결 결과(잘못된 PSK, AP 없음, DHCP 실패)를 notify로 보고하는 온보딩 흐름을 구현한다. SoftAP·Wi-Fi Easy Connect(DPP)·QR 방식과 보안/UX를 비교하고 이후 클라우드 인증서 등록과의 연결을 설명한다(인증서 수명 관리는 see:SYSD-M08).		외부환경필요linux
WCONN-A06AdvancedMatter·Thread 개요: SPAKE2+ 커미셔닝
RFC 9383 SPAKE2+(P-256) 프로토콜을 Python으로 구현해 RFC 테스트 벡터로 검증하고, 이를 이용한 Matter PASE 세션 수립 → 운영 인증서(NOC) 설치 → CASE 세션 흐름을 메시지 시퀀스 다이어그램과 시뮬레이터로 재현한다. Thread 파티션·border router가 IPv6로 Wi-Fi/Ethernet과 연결되는 방식을 정리한다.		준비중mac
WCONN-A07AdvancedFleet 연결성 신뢰성 분석
합성 fleet 이벤트 로그(disconnect reason/status code, 4-way 타임아웃, DHCP 지연, RSSI, AP OUI·대역, 펌웨어 버전)를 생성하고, reason code 분류표·연결 성공률·time-to-reconnect SLO 대시보드 데이터를 계산하는 분석기를 작성한다. 특정 AP 벤더×펌웨어 버전 조합의 이상을 찾아내고(버전 회귀 통계 검정은 see:INFRA-A06), 조치(펌웨어 롤백 vs 설정 회피)를 제안하는 리포트를 만든다.		준비중mac
WCONN-A08AdvancedWi-Fi 연결 장애 트리아지 케이스 스터디
hwsim 랩에서 잘못된 PSK(메시지 2 MIC 실패), AP 접속 수 초과(status 17), 비콘 손실, PMF 불일치, 규제 도메인 불일치로 인한 채널 미검출, DHCP 서버 무응답 6가지 장애를 재현해 로그·캡처를 수집하고, 이를 입력받아 원인과 근거 라인을 출력하는 규칙 기반 트리아지 도구를 작성해 면접식 '연결이 안 돼요' 질문에 답하는 디버그 순서도를 정리한다.		외부환경필요linux
