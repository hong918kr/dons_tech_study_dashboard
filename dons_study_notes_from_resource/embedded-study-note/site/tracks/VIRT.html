Stage 11 · VIRT · Virtualization & Containers

가상화 · 컨테이너

아이템 34Basic 11Mid 13Advanced 10학습가능 0

가상화는 클라우드 서버, 차량·로봇 SoC의 혼합 임계 통합, Android pKVM, 컨피덴셜 컴퓨팅까지 현대 시스템 소프트웨어의 기반이다. 이 트랙은 trap-and-emulate 원리와 ARM EL2·stage-2 변환에서 출발해 M2 맥의 Hypervisor.framework로 실제 AArch64 게스트를 돌리는 미니 VMM을 키워 virtio 디바이스·인터럽트 가상화·Linux 부팅·마이그레이션까지 구현하고, KVM API와 namespaces/cgroups/seccomp 기반 컨테이너도 직접 만든다. NVIDIA·AWS(Nitro/Firecracker)·Google·Apple·Rivian 등의 하이퍼바이저/플랫폼 면접에서 묻는 'exit가 왜 비싼가, stage-2 fault를 어떻게 처리하나'에 코드로 답하는 것이 목표다.

트랙 목표

  • Popek–Goldberg 조건, 반가상화, HW 가상화(ARM EL2/VHE, x86 VT-x/EPT)의 차이를 트랩 비용 모델로 설명한다
  • Hypervisor.framework와 KVM API로 AArch64 게스트를 실행하는 미니 VMM을 작성하고 MMIO·HVC·타이머·PSCI exit를 처리한다
  • stage-2 변환, dirty page tracking, 라이브 마이그레이션을 구현하고 수렴·다운타임을 정량화한다
  • virtio-mmio/pci 디바이스와 vGIC·irqfd 등 인터럽트 가상화, VFIO 패스스루의 격리 구조를 구현·설명한다
  • namespaces·cgroup v2·overlayfs·seccomp로 미니 컨테이너 런타임을 만들고 microVM과 비교한다
  • pKVM·Xen·정적 파티셔닝·Arm CCA 등 혼합 임계·컨피덴셜 가상화 아키텍처를 설계 수준에서 비교한다

KVM 게스트에서 네트워크·디스크·유휴 워크로드를 돌리며 kvm:kvm_exit/kvm_entry tracepoint(perf kvm stat 또는 trace-cmd)로 exit reason별 횟수·지연을 집계하고, halt_poll_ns 값과 vCPU 핀닝을 바꿔 웨이크업 지연·호스트 CPU 사용률 트레이드오프를 표로 정리한다.		외부환경필요linux
VIRT-A04Advancedioeventfd·irqfd: VMM을 거치지 않는 알림 경로
M09 KVM VMM에 KVM_IOEVENTFD(QueueNotify 주소)와 KVM_IRQFD(GSI)를 등록해 백엔드 워커 스레드가 eventfd로 알림을 받고 인터럽트를 주입하게 바꾸고, KVM_EXIT_MMIO 기반 동기 처리 대비 요청당 지연·VMM 스레드 CPU 사용량을 측정해 vhost/vDPA로 이어지는 동기를 정리한다(vhost-net/vDPA 데이터패스는 see:NETHW).		외부환경필요linux
VIRT-A05AdvancedFirecracker 스타일 microVM과 Jailer
Firecracker 구조(virtio-net/blk/vsock + serial만, 레거시 BIOS 없음, vCPU 스레드별 seccomp, jailer의 chroot+netns+cgroup+uid 드롭)를 분석해 M09 KVM VMM을 M12/M13 minirun 안에서 띄우는 jailer를 작성하고, 디바이스 수·커널 config 축소에 따른 부팅 시간(VMM 시작→init 실행)과 메모리 오버헤드를 측정해 '왜 컨테이너가 아니라 microVM인가'를 설계 문서로 정리한다.		외부환경필요linux
VIRT-A06AdvancedpKVM: 호스트를 믿지 않는 하이퍼바이저
페이지별 소유권 상태(host-owned, guest-owned, shared-owned/borrowed, hyp-owned)와 host_share_hyp/donate/reclaim hypercall 전이 규칙을 가진 C 모델에 호스트·게스트 stage-2 테이블을 연동해, 호스트가 보호 VM 페이지 접근 시 fault, 공유 해제 후 재접근 거부, VM 종료 시 페이지 scrub 후 반환을 테스트로 검증한다.		준비중mac
VIRT-A07AdvancedXen 분할 드라이버: Grant Table과 Event Channel
grant table(domid, frame, readonly 플래그, map/unmap 참조 카운트)과 event channel(bind, notify, pending/mask 비트맵)을 C로 모델링하고 그 위에 blkfront/blkback 공유 링(req/rsp producer·consumer 인덱스)을 구현해 블록 요청을 주고받으며, grant 해제 중 사용(use-after-revoke) 버그 주입과 dom0/driver domain 구조의 장단점을 정리한다.		준비중mac
VIRT-A08Advanced혼합 임계 파티셔닝: 정적 파티션 하이퍼바이저와 캐시 컬러링
Jailhouse/Bao/Xen dom0less 방식의 정적 파티션 설정(코어 핀닝, 메모리 영역, 디바이스·IRQ 할당) 검증기를 작성하고, LLC set 인덱스 비트 기반 캐시 컬러링 페이지 할당기와 공유 캐시 시뮬레이터로 Linux 파티션의 메모리 폭주가 RTOS 파티션 WCET에 주는 간섭을 컬러링·MemGuard식 대역폭 제한 유무별로 비교한다(ARINC 653 시간 분할은 see:AERO-M01, 안전 분석은 see:AUTO).		준비중mac
VIRT-A09AdvancedConfidential Computing: Arm CCA Realm과 GPT
Granule Protection Table(물리 granule별 Non-secure/Secure/Realm/Root PAS)과 RMI GRANULE_DELEGATE/UNDELEGATE·DATA_CREATE 흐름, Realm 초기 측정(RIM) 해시 확장을 C로 모델링해 NS 하이퍼바이저의 Realm 페이지 접근이 GPF로 막히는지 테스트하고, AMD SEV-SNP(RMP)·Intel TDX와 비교표를 만든다(원격 증명 토큰은 see:SEC-A05, TrustZone은 see:SEC-M07).		준비중mac
VIRT-A10Advanced종합: 엣지 AI·차량 SoC 가상화 플랫폼 설계 리뷰
8코어 Arm SoC + NPU + GPU에서 ASIL 제어 RTOS, Linux 인지 스택, 인포테인먼트 Android를 돌리는 플랫폼에 대해 하이퍼바이저 선택(pKVM/Xen/정적 파티션), 디바이스 할당(패스스루 vs virtio vs SR-IOV, GPU 분할은 see:GPUSYS-A05), 인터럽트 지연 예산, 메모리·캐시 격리, 보안 부팅·증명을 담은 설계서를 쓰고 핵심 경로(vIRQ 주입 지연 예산 계산기)를 코드로 검증한다.		준비중mac
