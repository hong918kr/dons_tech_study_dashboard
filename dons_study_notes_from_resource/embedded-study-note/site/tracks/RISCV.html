RISC-V ISA · 특권 구조

아이템 36Basic 12Mid 13Advanced 11학습가능 1

RISC-V는 Tenstorrent·SiFive 기반 NPU·Rivos 등 AI 가속기의 제어/관리 코어와 마이크로컨트롤러에 빠르게 퍼지고 있는 개방형 ISA다. 이 트랙은 ARM 트랙과 겹치는 일반 ISA 기초 대신 RISC-V 고유의 인코딩·확장 구조, M/S/U 특권 모드·CSR·트랩·PLIC/AIA·PMP·Sv39·SBI, RVV 벡터와 커스텀 명령어를 '직접 ISS를 만들고 QEMU virt에서 돌려보며' 익힌다. 칩 회사 면접에서 자주 나오는 '트랩 때 하드웨어가 정확히 무엇을 하나', 'PMP와 MMU의 관계', 'LR/SC 규칙' 같은 질문에 비트 수준으로 답하는 것이 목표다.

트랙 목표

  • RV32I/RV64I/RVC 인코딩을 디코드하고, riscv-tests를 통과하는 C ISS를 직접 구현한다
  • psABI·M/A/F/Zb* 확장의 의미와 엣지 케이스를 ARM과 대비해 설명한다
  • M/S/U 특권 모드, CSR, 트랩·위임, CLINT/PLIC/AIA 인터럽트 흐름을 QEMU virt에서 구현·검증한다
  • PMP와 Sv39/Sv48 MMU, SBI/OpenSBI 부팅, 원격 펜스를 이해하고 S-mode 커널로 시연한다
  • RVWMO 메모리 모델과 LR/SC·AMO·FENCE 사용법을 리트머스와 매핑 표로 근거 있게 설명한다
  • RVV 벡터 커널과 커스텀 명령어/CFU로 AI 가속기 관점의 ISA 확장을 설계·측정한다

RISCV-M10Mid특권 모드 전환과 위임: M→S→U, medeleg/mideleg

RISCV-A05AdvancedRVV 1.0 기초: vsetvli, SEW/LMUL, strip-mining
vsetvli strip-mining 루프로 saxpy·memcpy·int8 합을 RVV intrinsic과 어셈블리로 작성해 QEMU -cpu rv64,v=true,vlen=128/256/512에서 같은 바이너리가 모두 정답을 내는지 검증하고, 고정 폭 NEON 버전(see:ARM-M06)과 꼬리 처리 코드를 비교한다.		외부환경필요qemu
RISCV-A06AdvancedRVV int8 내적·GEMM 커널: vwmacc, 리덕션, segment load
int8×int8→int32 내적과 4×VL 타일 GEMM 마이크로커널을 RVV로 작성해 스칼라 기준과 비트 단위 대조하고, QEMU insn 카운트 플러그인으로 LMUL=1/2/4별 동적 명령 수를 비교하며 ARM SDOT/SMMLA 커널(see:ARM-A05)과 설계 차이를 정리한다 (NPU 관점은 see:NPU).		외부환경필요qemu
RISCV-A07Advanced커스텀 명령어: custom-0/1 opcode와 .insn, ISS 구현
custom-0 공간에 int8 dot4(rs1·rs2의 4바이트 곱 합 + rd 누산) R형 명령을 정의해 ISS에 구현하고, .insn r 매크로를 쓰는 C 인라인 함수로 int8 내적 커널을 재작성해 동적 명령 수·코드 크기 감소를 측정한다.		준비중mac
RISCV-A08Advanced가속기 연결 설계: CFU vs RoCC vs MMIO 코프로세서
RISCV-A07 dot4를 (1) 1사이클 CFU, (2) valid/ready 다중 사이클 CFU, (3) MMIO 레지스터+폴링 가속기로 각각 트랜잭션 C 모델과 펌웨어 드라이버를 작성해 벡터 길이별 사이클 비용 곡선을 그리고 어느 크기에서 MMIO+DMA가 이기는지 설계 문서로 정리한다 (RTL 구현은 see:RTLDV, NPU 명령 프로세서는 see:NPU-M05).		준비중mac
RISCV-A09Advanced디버그 스펙: debug mode, dcsr/dpc, 트리거와 GDB 스텁
ISS에 debug mode(dcsr.ebreakm, step, dpc)와 mcontrol 실행/로드 주소 트리거를 구현하고 GDB remote serial protocol 최소 스텁(g/G/m/M/Z0/Z1/s/c)을 붙여 Python RSP 클라이언트 스크립트로 브레이크포인트·단일 스텝·하드웨어 워치포인트를 검증한다 (JTAG TAP·OpenOCD 흐름은 see:TOOL-A01/A03).		준비중mac
RISCV-A10AdvancedLockstep 공동 시뮬레이션: ISS 커밋 로그 vs Spike 비교
자작 ISS에 Spike --log-commits 형식(pc, 명령, rd 쓰기값, 메모리 쓰기) 로그 출력을 추가하고 같은 ELF를 Spike와 실행해 첫 불일치를 찾는 diff 도구를 작성한 뒤, 일부러 심은 버그 3개(SRA 부호, JALR LSB 클리어 누락, CSR 부작용)를 자동으로 찾아내는지 검증한다 (회귀 일관성 검사는 see:EMU-M10).		외부환경필요qemu
RISCV-A11Advanced종합: 자작 ISS로 xv6-riscv 부팅
RV64IMA+Zicsr ISS에 특권 모드·Sv39·CLINT·PLIC·NS16550·virtio-blk(mmio)를 더해 xv6-riscv 커널과 fs.img로 셸 프롬프트까지 부팅하고 usertests 일부를 통과시키며, 부팅 중 막힌 지점마다 원인·수정을 디버그 로그로 남긴다 (xv6 자체 해킹은 see:OS-A09/A10).		외부환경필요qemu
