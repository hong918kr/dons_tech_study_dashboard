스코프 대역폭·프로브 부하·그라운드 리드 링잉

Basic⏱ 70분env: mac#probe#bandwidth#ground-lead#ringing#oscilloscopeupdated 2026-11-08
목표 측정 체인(스코프·프로브·그라운드 리드)이 파형을 어떻게 왜곡하는지 정량화한다.
과제 tr_meas≈√(tr_sig²+tr_scope²+tr_probe²)와 BW≈0.35/tr로 1ns 에지를 3% 오차 이내로 보기 위한 대역폭을 계산하고, 10x 프로브(10MΩ‖~12pF) + 15cm 그라운드 리드(~150nH) RLC 모델을 시뮬레이션해 링잉 주파수 1/(2π√LC)와 overshoot가 스프링 팁(~10nH)에서 얼마나 줄어드는지 B04 도구로 측정한다.
내 상태

학습 목표#

  • rise-time 예산 tr_meas ≈ √(tr_sig² + tr_scope² + tr_probe²) 와 BW ≈ 0.35/tr 로 "1ns 에지를 3% 오차로 보려면 몇 GHz가 필요한가"를 계산하고, 그 근사가 정확히 맞는 조건(가우시안 응답)과 틀어지는 조건(단일 극점, 평탄 응답 스코프) 을 시뮬레이션으로 확인한다.
  • 10x 패시브 프로브(10MΩ‖12pF) + 그라운드 리드를 직렬 RLC로 모델링해 RK4로 적분하고, 링잉 주파수 1/(2π√LC), 감쇠비 ζ, overshoot를 캡처에서 직접 측정해 이론값과 맞춘다.
  • 15cm 악어 클립(~150nH)과 그라운드 스프링(~10nH)의 차이를 숫자로 말하고, 프로브 tip 용량이 DUT 에지를 늦추는 부하 효과(loading) 를 분리한다.
  • "이 overshoot는 진짜인가, 내 프로브가 만든 것인가"를 캡처 두 장(리드/스프링)으로 판정하는 리포트를 만든다 — 링잉 주파수에서 루프 인덕턴스를 역산하는 것이 핵심 단서다.

1. 문제#

첫 보드 브링업에서 "SPI 클럭 overshoot 60%, 수신기 abs max 위반" 이라는 버그 리포트의 절반은 측정 체인이 만든 가짜다 — Rivian/NVIDIA/Apple 보드·실리콘 검증 면접에서 "스코프로 무엇을 어떻게 봤고, 그 수치를 왜 믿는가"를 물을 때 가장 먼저 확인하는 것이 이 레슨의 내용이다.

스코프 화면의 파형은 DUT 신호 그 자체가 아니라 DUT → 프로브 tip → 그라운드 리드 → 프로브/케이블 → 스코프 프론트엔드 를 통과한 결과다. 각 단계가 대역폭을 깎고(rise time을 늘리고), 프로브 입력 용량은 DUT 노드에 짐을 얹고(loading), 그라운드 리드의 인덕턴스는 그 용량과 직렬 공진기를 만들어 원래 없던 링잉을 그린다.

이 레슨의 측정 도구(히스토그램 mode 상태 레벨, 10–90% 선형 보간 교차, overshoot %)는 HWLAB-B04 가 정식으로 다루는 IEEE 181 방식의 축약판이다. B04와 병렬로 쓰였기 때문에 B04 파일을 import 하지 않고 starter.py 맨 위 "B04-lite" 블록에 완성된 형태로 넣어 두었다 (수정할 필요 없음, 원리는 HWLAB-B04 참고).

Part A — rise-time 예산과 그 근사의 가정#

  • rss, rise_error(tr_sig, [bw...]), required_system_bw(tr_sig, err), required_scope_bw(tr_sig, err, probe_bw) 를 구현한다. 1ns 에지 @3% → 1.418GHz, 2.5GHz 액티브 프로브와 쓸 때 스코프 1.722GHz, 500MHz 패시브 프로브로는 불가능(None) 이 나와야 한다.
  • single_pole_filter (1차 RC의 정확한 이산화)를 구현하고, 같은 1.418GHz라도 스코프 응답이 가우시안이면 측정 오차가 정확히 3.00%, 단일 극점이면 3.87% 가 되는 것을 B04-lite로 측정한다. 이분법으로 "단일 극점이면 몇 GHz가 필요한가"를 찾는다.

Part B — 프로브 부하와 그라운드 리드 RLC#

  • series_rlc(R, L, C) → f0, Z0, ζ, 감쇠 주파수 fd, 이상적 계단 overshoot.
  • simulate_probe(src, Rs, L, C, Rp, scope_bw) — 상태 (i_L, v_C, y_scope) 를 RK4로 적분.
  • ring_analysis(t, v, top, i_start, hyst) — 히스테리시스 극값 탐색 → 0 교차 간격으로 링잉 주파수, 로그 감쇠율로 ζ.
  • 확인할 것: 150nH 리드 overshoot ≈ 59.6% vs 스프링 ≈ 5.1%, 측정 f_ring 이 fd 와 1% 이내, 역산한 L ≈ 150nH, tip C 1/12/100pF 에 따른 rise time 증가, 그리고 리드가 DUT 노드 자체도 흔든다는 것.

Part C — BRD-A rev0: 아티팩트인가 실제인가#

captures/ 에 가상 보드 BRD-A rev0의 세 넷을 15cm 리드와 스프링으로 각각 잰 CSV 6개가 있다 (gen_captures.py 가 결정적으로 생성). 수신기 데이터시트 abs max를 VDDIO+0.3V = 3.6V 로 가정한다 (HWLAB-B02 참고). diagnose(net) 는 두 캡처를 비교해 ARTIFACT / REAL / PASS 와 엔지니어가 그대로 티켓에 붙일 수 있는 한 줄 리포트를 낸다. 심어 둔 결함: QSPI_CLK 는 직렬 종단 저항이 DNP라 보드 자체가 250MHz로 링잉한다 — 스프링으로 재도 overshoot가 남아야 하고, 리포트가 그것을 "보드 SI 문제"로 분류해야 한다.

2. Problem (English)#

Is it the signal or the probe?

Using only the Python 3 standard library:

  1. Rise-time budget. rise_error(tr_sig, bws, k=0.35) -> float returns the relative rise-time error when a signal with 10–90% rise time tr_sig is viewed through cascaded stages of bandwidth bws (tr_i = k/bw_i, root-sum-square). required_system_bw(tr_sig, err) and required_scope_bw(tr_sig, err, probe_bw) (return None if the probe alone exceeds the budget). Example: required_system_bw(1e-9, 0.03) ≈ 1.418e9. Then verify by simulation that the RSS rule is exact for Gaussian responses and not for a single-pole scope.
  2. Probe + ground lead. Model a Thevenin source (Rs) driving a series ground-lead inductance L into the probe input C ‖ Rp, followed by a single-pole scope. Implement series_rlc(R, L, C) (f0, Z0, ζ, fd, ideal-step overshoot), simulate_probe(...) (RK4) and ring_analysis(t, v, top, i_start, hyst) returning the ringing frequency (from zero-crossings) and ζ (from logarithmic decrement). For Rs=33Ω, C=12pF, a 1 ns edge shows ~60% overshoot with a 150 nH lead and ~5% with a 10 nH spring; the measured ringing must match fd = f0·√(1−ζ²) within 1%.
  3. Triage. For each net, two captures (CSV t_ns,volt) exist: 15 cm lead and ground spring. Implement diagnose(net, vmax=3.6, c_probe=12e-12) -> (verdict, report_line, info) where verdict is REAL if the spring capture still exceeds vmax, ARTIFACT if only the lead capture does, else PASS. Back-compute the loop inductance from the lead capture's ringing frequency and the probe capacitance and print it in the report.

4. 힌트#

힌트 1 — 예산을 거꾸로 풀기

(1+err)² = 1 + (tr_sys/tr_sig)² → tr_sys = tr_sig·√((1+err)²−1). err=3% 이면 √0.0609 = 0.2468, 즉 시스템 rise time은 신호의 약 1/4 이어야 한다. 프로브가 있으면 tr_scope = √(tr_sys² − tr_probe²), 근호 안이 음수면 어떤 스코프도 못 맞춘다.

힌트 2 — 단일 극점의 정확한 이산화

τ dy/dt = x − y 를 한 샘플 동안 x가 상수라고 보고 풀면 y[n] = y[n−1] + (1 − e^(−dt/τ))(x[n] − y[n−1]), τ = 1/(2π·BW). 오일러(dt/τ)보다 dt가 클 때도 안정하다.

힌트 3 — RLC 상태방정식

KVL: L di/dt = src(t) − Rs·i − v, 커패시터: C dv/dt = i − v/Rp, 스코프: τ dy/dt = v − y. 상태 3개를 튜플로 들고 RK4 네 번 평가. dt=5ps면 459MHz(주기 2.18ns)도 주기당 435스텝이라 충분하다. every 스텝마다 저장하면 20GS/s 캡처처럼 보인다.

힌트 4 — 잡음 속에서 링잉 주파수 재기

극값의 시각 은 기울기가 0인 곳이라 잡음에 약하다 (6mV 잡음이 꼭대기 위치를 수십 ps 흔든다). 극값은 "어디서 반주기가 바뀌는가"를 찾는 데만 쓰고, 주파수는 극값 사이의 0 교차(기울기 최대 → 시간 오차 = σ_v / slope)를 선형 보간해 잰다. 극값 확정은 히스테리시스: 최대 탐색 중 d < max − hyst 가 되면 확정.

힌트 5 — ζ 와 L 역산

연속한 반대 부호 극값의 비 = exp(−πζ/√(1−ζ²)) (반주기당). 로그를 취해 평균한 dl 로 ζ = dl/√(π²+dl²). 측정 주파수는 감쇠 주파수 fd이므로 f0 = fd/√(1−ζ²) 로 고친 뒤 L = 1/((2πf0)²·C). 첫 극값(overshoot)은 에지 모양·스코프 필터의 영향을 받으니 ζ 계산에서 뺀다.

5. 풀이#

Part A — rise-time 예산: 계산 한 줄, 가정 세 개#

왜 0.35인가. 1차 RC의 계단 응답 10%→90% 시간은 τ·ln 9 = 2.197τ, −3dB 대역폭은 1/(2πτ) 이므로 tr·BW = 2.197/(2π) = 0.350. 가우시안 응답(H(f) = exp(−2π²σ²f²))이면 −3dB 가 f = 0.1325/σ, 10–90% 폭이 2.563σ 이라 tr·BW = 0.3396. 1GHz 이상 고급 스코프는 대역 끝까지 평탄하고 급격히 떨어지는(maximally-flat, brick-wall에 가까운) 응답이라 tr·BW ≈ 0.4–0.45 를 쓴다 (벤더 앱노트 표기 범위, 기종마다 데이터시트 rise time을 직접 확인).

왜 RSS인가. 시스템의 계단 응답을 "임펄스 응답의 누적분포"로 보면, 직렬 연결은 임펄스 응답의 합성곱 이고 합성곱은 분산을 더한다: σ_tot² = σ_1² + σ_2² + …. 10–90% 폭이 σ에 비례하는 모양(가우시안)끼리는 RSS가 정확하다. 모양이 다르면 근사다.

질문계산결과 (실행값)
1ns @ 3% 시스템 BWtr_sys = 1ns·√(1.03²−1) = 246.8ps → 0.35/tr_sys1.4183 GHz
1GHz 시스템으로 보면√(1+0.35²) − 15.95%
500MHz로 보면√(1+0.7²) − 122.07%
2.5GHz 액티브 프로브 + ?√(246.8² − 140²) = 203ps → 0.35/203ps1.722 GHz
500MHz 패시브 프로브 + ?프로브 tr 700ps > 예산 247psNone (불가능)

경험칙 "스코프 BW는 신호 BW(0.35/tr)의 3~5배"는 이 식의 다른 표현이다: 3배 → 5.41%, 4배 → 3.08%, 5배 → 1.98% (연습 1). 3% 요구는 정확히 "약 4배"다.

가정 확인 — 시뮬레이션. 같은 1.418GHz에서:

  • 가우시안 스코프(tr·BW = 0.3396) → 측정 오차 3.00%. RSS와 일치.
  • 단일 극점 스코프 → 측정 오차 3.87%, 3%를 맞추려면 이분법으로 1.622GHz.

왜 단일 극점이 더 나쁜가: 분산이 더해진다는 원리로 보면, 단일 극점의 표준편차는 τ인데 10–90% 폭은 2.197τ 뿐이다(가우시안은 2.563σ). 즉 단일 극점은 "10–90% 숫자로 보이는 것보다 분산을 많이 보탠다". 등가 가우시안 tr로 환산하면 2.563τ = 1.167·tr_scope, √(1 + (1.167·0.2468)²) − 1 ≈ 4.1% — 측정한 3.87%와 같은 쪽으로 같은 크기만큼 틀린다(합성 결과가 완전한 가우시안이 아니라 정확히 같지는 않다). 면접 답: "RSS는 각 단이 가우시안에 가까울 때 정확하고, 단일 극점이면 오차를 과소평가, 평탄 응답 스코프면 k=0.45로 바꿔 계산한다." 실무에서는 스코프 데이터시트의 rise time 스펙(10–90%)을 직접 RSS에 넣는 게 k를 추측하는 것보다 낫다.

Part B — 프로브는 회로의 일부다#

1) 부하(loading) — DC와 AC. 10x 패시브 프로브의 입력은 tip 기준 10MΩ‖(모델에 따라 약 4–15pF; 이 레슨은 과제대로 12pF). DC에서 10MΩ은 33Ω 드라이버에 3ppm이라 무의미하지만, 1MΩ 같은 고임피던스 노드(RC 타이밍, 분압 sense, 크리스털 발진기)에서는 −9.1%(1x 프로브의 1MΩ이면 −50%) — 연습 4. ns 영역에서는 C가 지배한다: RC 근사로 2.2·Rs·C = 2.2·33Ω·12pF = 0.87ns 가 에지에 RSS로 더해진다.

시뮬레이션 실측(스프링 10nH, 1GHz 스코프):

tip C예ζ (Rs=33Ω, 10nH)RC 근사 2.2RsC측정 tr (진짜 1.000ns)
1pF액티브(FET) 프로브0.1650.07ns1.01ns
12pF10x 패시브0.5720.87ns1.12ns

RC 근사가 12pF에서 약 1.37ns(=√(1² + 0.87² + 0.35²))를 예측하는데 실제 1.12ns인 이유는 10nH가 있어 순수 RC가 아니라 약하게 덜 감쇠된 RLC(ζ=0.57) 이기 때문이다 — 응답이 빨라지는 대신 5% overshoot가 생긴다. 1pF에서는 1.59GHz 공진(ζ=0.165)이 1GHz 스코프의 고역 롤오프를 일부 메워서, 스코프만일 때(1.074ns)보다 오히려 빠른 1.01ns가 나온다; 스코프 필터를 빼면 0.93ns로 진짜보다 빠르게 측정된다. "측정 tr < 실제 tr"은 불가능하지 않다 — 공진(peaking)이 있으면 가능하다. demo_peaking.py 실행 결과:

1pF 경우 overshoot가 0인 이유: 가우시안 1ns 에지는 1.59GHz 근처에 에너지가 거의 없어 공진을 "울리지" 못하고, 공진 아래 대역의 이득 상승(peaking)만 받아 에지가 날카로워진다 (원시 시뮬레이션의 max − final도 0.0035%였다).

2) 그라운드 리드 = 인덕터. 리드 루프 인덕턴스는 대략 1nH/mm(루프 모양에 따라 다름) → 15cm ≈ 150nH. 프로브 C와 직렬 공진:

8. 면접 Q&A#

Q1. 1ns 에지를 보려면 몇 MHz 스코프가 필요한가요? 그 근사의 가정은?

신호 자체의 등가 BW는 0.35/1ns = 350MHz지만, 측정 tr 오차를 3%로 묶으려면 시스템(스코프+프로브) tr이 신호의 1/4 (246.8ps)이어야 하므로 약 1.42GHz. 가정: ① RSS — 각 단이 가우시안 응답일 때 정확 (분산이 더해지므로) ② k=0.35 — 단일 극점/가우시안 근사. 단일 극점 시스템이면 시뮬레이션상 1.62GHz가 필요하고, 평탄 응답 스코프(k≈0.45)면 1.82GHz. 프로브 BW도 예산에 들어간다. 꼬리질문: "5배 규칙의 근거는?" → √(1+1/5²) − 1 ≈ 2%. 3배면 5.4%. "그럼 2GHz 스코프면 무조건 OK?" → 500MHz 패시브 프로브를 꽂으면 그 프로브가 22%를 만든다.

Q2. 15cm 그라운드 클립으로 SPI 클럭을 쟀더니 overshoot 60%입니다. 진짜인가요?

먼저 링잉 주파수를 읽는다. 10x 패시브 프로브 ~12pF와 15cm 리드 ~150nH면 1/(2π√LC) ≈ 119MHz. 측정 주파수가 이 근처이고, 다른 넷에서도 같은 주파수로 링잉하면 프로브 공진을 의심한다. 그 다음 그라운드 스프링이나 가까운 GND 비아로 다시 잰다 — 이 레슨 시뮬레이션에서는 59.6% → 5.1%. 판정은 짧은 그라운드 측정 기준. 꼬리질문: "스프링으로도 40% 남으면?" → 실제 SI 문제. 링잉 주파수를 트레이스 왕복 지연과 비교하고(반사, HWLAB-M01), 소스 직렬 종단·드라이브 세기·슬루율 설정을 확인한다. "링잉 주파수가 리드와 일치하면 안심해도 되나?" → 아니다. 리드 공진이 실제 문제를 덮을 수 있다 (Part C의 QSPI_CLK: 리드 캡처만 보면 SPI0_SCLK과 똑같다).

Q3. 1x와 10x 프로브는 언제 무엇을 쓰나요?

10x: 입력 10MΩ‖수~십수 pF, BW 수백 MHz급 — 일반 디지털·클럭 측정의 기본. 1x: 감쇠가 없어 mV급 신호(잡음, 작은 리플)에 유리하지만 입력 용량이 수십~100pF 이상(케이블 포함)이고 BW가 수 MHz~수십 MHz 수준이라 빠른 에지에는 못 쓴다. 1x로 33Ω 노드를 보면 RC만 2.2·33·100pF ≈ 7ns. 꼬리질문: "10x 프로브 보상(compensation)이 안 맞으면 어떤 모양인가?" → 스코프의 1kHz 교정 사각파에서 모서리가 뾰족하게 튀거나(과보상) 둥글게 처진다(부족보상). 이것은 수백 µs 시간 스케일의 저주파 문제이고, 그라운드 리드 링잉(ns 스케일, 100MHz대)과는 완전히 다른 현상이다 — 섞어 말하면 감점.

Q4. 프로브가 회로 동작 자체를 바꾸는 예를 들어 보세요. 어떻게 피하나요?

① 크리스털 발진기 핀(특히 출력 쪽)에 10x 프로브를 대면 부하 용량이 늘어 주파수가 당겨지거나 발진이 멈춘다 ② 고임피던스 노드(1MΩ 분압, RC 리셋 타이머)는 10MΩ에도 −9% ③ 33Ω 노드의 1ns 에지는 12pF로 눈에 띄게 느려진다 ④ 긴 그라운드 리드는 DUT 노드 자체를 흔든다 (이 레슨 모델에서 노드 overshoot 14.3%). 대책: 액티브 FET 프로브(<1pF), 버퍼 출력/테스트 포인트 사용, 짧은 그라운드, 측정 전후로 기능이 바뀌는지 확인. 꼬리질문: "액티브 프로브의 단점은?" → 입력 전압 범위·동적 범위가 좁고(모델별 데이터시트 확인), ESD/과전압에 약하며 비싸고 전원·오프셋 설정이 필요하다.

Q5. 하이사이드 스위치 노드나 차동 신호를 보려고 그라운드 클립을 다른 노드에 물리면?

일반 벤치 스코프의 프로브 그라운드는 스코프 섀시를 통해 접지(earth)에 연결돼 있다. 그라운드 클립을 GND가 아닌 노드에 물리면 그 노드를 접지에 단락시킨다 — 보드나 프로브가 탈 수 있다. 두 채널을 빼서(A−B) 보는 방법은 공통 모드 제거비가 나쁘다. 차동 프로브(고전압용/고속용)를 쓰는 게 정석이고, 스코프 접지를 끊는 것("float")은 안전 문제로 금지. 꼬리질문: "두 프로브의 그라운드를 서로 다른 GND 지점에 물리면?" → 그라운드 루프가 생겨 GND 사이의 전압 강하·자기 결합이 측정에 섞인다. 같은 기준점을 쓰고 루프 면적을 줄인다.

Q6. 측정한 rise time이 실제보다 빠를 수도 있나요?

있다. 공진(peaking)이 있는 체인은 고역 이득이 1보다 커져 에지를 날카롭게 만든다. 이 레슨의 1pF+10nH(ζ=0.165, 1.59GHz 공진) 경우 스코프 필터를 빼면 1ns 에지가 0.93ns로 측정됐다. 일부 스코프의 DSP 응답 보정(equalization)도 비슷한 효과를 낸다. 그래서 overshoot와 tr을 함께 보고, tr이 BW 한계보다 비정상적으로 짧으면 체인을 의심한다. 꼬리질문: "그럼 tr은 언제 믿나?" → 체인 tr이 신호 tr의 1/4 이하이고, 체인 응답이 단조(링잉 없음)이며, 프로브를 바꿔도 값이 안정적일 때.

Q7. 캡처에서 링잉 주파수와 감쇠비를 어떻게 숫자로 뽑나요? 그걸로 무엇을 알 수 있나요?

top 상태 레벨 기준 편차의 교대 극값을 히스테리시스로 찾고, 극값 사이 0 교차 간격(반주기)으로 주파수를, 연속 극값의 진폭비(반주기당 exp(−πζ/√(1−ζ²)))로 ζ를 구한다. 프로브 C를 알면 L = 1/((2πf0)²C) 로 루프 인덕턴스, R = 2ζ√(L/C) 로 직렬 저항(드라이버 + 직렬 R)까지 추정된다 — 이 레슨 캡처에서 L ≈ 149nH, R ≈ 32Ω (생성기 값 150nH, 33Ω, 연습 2). 꼬리질문: "스프링 캡처에서는 왜 ring=none?" → ζ=0.57이라 반주기마다 진폭이 약 11%로 줄어 두 번째 극값이 히스테리시스(66mV) 아래로 떨어진다. 주파수를 재려면 최소 2개의 0 교차가 필요하다.

연습 1 — 스코프 응답 모양과 3·4·5배 규칙#

required_bw(tr, err, k) 로 k=0.35와 0.45를 비교하고, "스코프 BW = m × (0.35/tr_sig)"일 때 RSS 오차를 m=3,4,5에 대해 구하라.

답 보기

1ns @3%: k=0.35 → 1.418GHz, k=0.45 → 1.823GHz. 규칙 오차는 √(1+1/m²) − 1 : 3배 5.41%, 4배 3.08%, 5배 1.98%. "3% 이내"는 사실상 4배 규칙이다. 평탄 응답 스코프라면 같은 m에서도 오차가 더 크니(k가 더 큼) 데이터시트 rise time을 쓴다.

연습 2 — 링잉 캡처에서 직렬 저항 역산#

SPI0_SCLK_lead15cm 캡처에서 f_ring, ζ를 재고 프로브 C=12pF로 L과 직렬 R을 역산하라. 생성기 값은 33Ω.

답 보기

f0 = fd/√(1−ζ²), L = 1/((2πf0)²C), R = 2ζ√(L/C). 실행값: f_ring 118.0MHz, ζ 0.143, L 149nH → R 31.8Ω (3.6% 낮음 — 잡음과 1GHz 필터의 영향). 실무 의미: ζ가 너무 작으면 "드라이버가 생각보다 세다 / 직렬 저항이 빠졌다"는 단서가 된다.

연습 3 — overshoot ≤ 10%를 위한 최대 그라운드 리드#

Rs=33Ω, C=12pF, 1ns 에지에서 시뮬레이션 overshoot가 10% 이하인 최대 L을 이분법으로 찾고, 10nH/cm로 길이를 환산하라. 이상적 계단 기준(ζ에서 역산)과 비교하라.

답 보기

이상적 계단: OS=10% → ζ ≥ 0.591 → Z0 ≤ 33/(2·0.591) = 27.9Ω → L ≤ 9.3nH. 1ns 에지 시뮬레이션: L_max 13.8nH ≈ 1.4cm. 에지가 공진을 덜 쳐서 조금 더 허용되지만, 1ns 에지에서는 사실상 스프링만 허용된다. 15cm 클립은 10배 이상 길다.

연습 4 — 프로브 부하 허용치 (AC와 DC)#

① 1ns 에지, Rs=33Ω 노드에서 tr 증가를 10% 이내로 하려면 tip C는 최대 몇 pF인가 (RC 근사 + RSS)? ② 1MΩ Thevenin 노드를 10x(10MΩ)와 1x(1MΩ)로 읽을 때 DC 오차는?

답 보기

① 2.2·Rs·C ≤ 1ns·√(1.1²−1) = 458ps → C ≤ 6.31pF. 12pF 패시브 프로브는 불합격, ~1pF 액티브 프로브는 여유. (Part B에서 보듯 실제 L이 있으면 RC 근사보다 덜 느려지지만 overshoot를 대가로 낸다.) ② 10x: −9.1%, 1x: −50%. 고임피던스 노드는 DMM(보통 10MΩ)도 같은 문제를 갖는다.

연습 5 — 그라운드 리드에 감쇠 저항을 넣으면?#

15cm 리드(150nH)를 꼭 써야 한다면 루프에 직렬 저항을 넣어 ζ=0.7로 만들 수 있다. 추가 저항과 그때의 overshoot, rise time을 시뮬레이션하라.

답 보기

R_total = 2·0.7·√(150n/12p) = 156.5Ω → 추가 123.5Ω. 실행값: OS 4.4%, 그러나 tr 3.01ns (진짜 1ns). 링잉을 감쇠시켜도 L과 C가 만든 대역폭 한계는 그대로라 에지가 3배 느려진다 — 루프 인덕턴스는 감쇠로 해결되지 않고 줄여야 한다. (일부 프로브 액세서리의 저항성 tip이 같은 원리지만, 고속 에지 측정의 정답은 짧은 그라운드다.)

10. 핵심 정리#

  • tr·BW = 0.35(단일 극점) / 0.34(가우시안) / 0.4–0.45(평탄 응답 스코프). 신호 BW와 측정 시스템 BW는 다른 숫자다.
  • tr_meas = √(tr_sig² + tr_scope² + tr_probe²) 는 가우시안끼리 정확, 단일 극점이면 오차를 과소평가 (1.418GHz에서 3.00% 예측 vs 3.87% 측정).
  • 1ns 에지 @3% → 시스템 1.42GHz (≈4배 규칙). 500MHz 패시브 프로브 하나로 이미 22%.
  • 그라운드 리드 ≈ 1nH/mm. 프로브 C와 직렬 공진 f0 = 1/(2π√LC): 150nH+12pF → 118.6MHz, 10nH → 459MHz. ζ = Rs/(2√(L/C)).
  • 같은 1ns 에지: 15cm 리드 OS 59.6% vs 스프링 5.1%. 에지가 공진 주기보다 느리면 리드도 무해(20ns 에지 0.6%).
  • 링잉 주파수(0 교차) + 감쇠(로그 감쇠율) → L, R 역산. 측정되는 건 fd, f0로 보정.
  • 판정은 짧은 그라운드 기준: 리드 지문(같은 ~118MHz)이 실제 SI 문제를 덮을 수 있다.
  • tip C는 에지를 늦추고 노드를 바꾼다 — 숫자를 보고할 때 측정 체인을 같이 적는다.
