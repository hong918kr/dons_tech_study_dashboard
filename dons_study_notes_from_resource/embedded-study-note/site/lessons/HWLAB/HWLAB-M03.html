PDN 타겟 임피던스와 디커플링 커패시터 선정

Mid⏱ 80분env: mac#power-integrity#pdn#decoupling#target-impedance#anti-resonanceupdated 2026-11-08
목표 PDN 임피던스를 주파수 영역에서 계산해 디커플링 구성을 정량적으로 고른다.
과제 Ztarget=V·(허용 리플%)/ΔI를 계산하고, 커패시터(C, ESR, ESL) 병렬 네트워크의 |Z(f)|를 10kHz–1GHz에서 계산해 반공진 피크를 찾는 Python 도구를 작성한 뒤, 1/10/100µF 조합과 개수를 탐색해 목표 대역에서 Ztarget 이하가 되는 최소 BOM을 제시한다.
내 상태

학습 목표#

  • 레일 스펙(전압, 허용 리플 %, 부하 전류 스텝 ΔI)에서 타겟 임피던스 Ztarget = V·ripple%/ΔI 를 계산하고, 그 숫자가 무엇을 가정하는지(평탄 타겟, 선형 중첩, ΔI의 주파수 성분) 설명할 수 있다.
  • 커패시터를 직렬 RLC (Z = ESR + j(ωL − 1/ωC)) 로 모델링하고, VRM(R + jωL)과 여러 커패시터의 병렬망 |Z(f)| 를 10 kHz–1 GHz에서 직접 계산한다. SRF, 실장 인덕턴스(mounting inductance), 병렬 개수의 효과를 수치로 확인한다.
  • 반공진(anti-resonance) 피크의 주파수 f = 1/(2π√((L1+L2)·C1C2/(C1+C2))) 와 높이 ≈ X²/(R1+R2) 를 유도하고, ESR이 낮을수록 피크가 높아지는 이유를 설명할 수 있다.
  • "decade 점·SRF 지점만 확인" 이나 거친 주파수 그리드가 피크를 놓쳐 PASS라고 거짓말하는 것을 보이고, 국소 최대 + 황금분할 정밀화로 고친다.
  • 1/10/100 µF 개수를 전수 탐색해 목표 대역에서 Ztarget 이하가 되는 최소 BOM 을 고르고, 조립된 보드의 VNA 2-port shunt-thru 측정(.s2p) 에서 Z를 복원해 "10 µF 3개 미실장" 을 찾아내는 리포트를 만든다.

1. 문제#

SoC 코어 레일이 부하 스텝 때 몇 mV 출렁이는지는 결국 PDN 임피던스 |Z(f)| 로 정해진다 — NVIDIA/Apple/Rivian 보드·전원 무결성(PI) 면접의 단골 질문 "타겟 임피던스는 어떻게 정하고, 디커플링 커패시터 몇 개를 어떻게 골랐으며, 그걸 보드에서 어떻게 확인했나?" 에 숫자로 답하려면 직접 계산해 봐야 한다.

전류가 ΔI 만큼 갑자기 변하면 레일 전압은 대략 ΔV ≈ ΔI·|Z(f)| 만큼 움직인다(선형 근사). 허용 리플이 V·ripple% 라면, 관심 대역 전체에서 |Z(f)| ≤ V·ripple%/ΔI 이면 어떤 주파수 성분의 전류 변화에도 리플이 허용치 안에 든다 — 이게 타겟 임피던스(target impedance) 방법이다. 저주파는 VRM(레귤레이터)의 제어 루프가, 그 위는 보드 커패시터가, 수십 MHz 위는 패키지·온다이 커패시턴스가 책임진다.

데이터는 합성(synthetic) 이다. 부품 값·VRM 모델·가격은 pdn_spec.json 의 대표값(데이터시트/제조사 모델 확인 필요)이고, 테스트는 이 JSON과 자기 일관적이다. 측정 파일(.s2p)은 gen_vna.py(고정 seed)가 만든다.

Part A — Ztarget·커패시터 Z·병렬망·피크 찾기#

  • z_target(v_nom, ripple_pct, delta_i) — VDD_CORE_0V9: 0.9 V × 3 % / 2 A = 13.5 mΩ.
  • cap_z(f, c, esr, esl), srf(c, esl) — 직렬 RLC 모델과 자기 공진 주파수. 테스트: |Z(SRF)| = ESR, SRF/100 에선 1/ωC, 100·SRF 에선 ωL (0.1 % 이내).
  • pdn_z(f, bom, parts, vrm) — VRM ∥ (부품 k × nₖ) 병렬망. 같은 부품 n 개는 정확히 Z/n.
  • find_peaks(zmag) — 로그 그리드(10 kHz–1 GHz, 40점/decade = 201점) 위의 국소 최대 = 반공진 후보. rev C 망에서 3개.

Part B — 반공진: 해석식, ESR의 역설, 피크를 놓치는 검사#

  • anti_resonance(c1, l1, c2, l2) — 두 직렬 LC 가지의 무손실 병렬 공진. 100 µF/1.4 nH ∥ 1 µF/0.8 nH = 3.411 MHz.
  • refine_peak(zfun, fa, fb) — log f 축 황금분할 탐색으로 피크를 정밀화. max_z_in_band(zfun, f1, f2, ppd, refine) — 그리드 + 국소 최대 정밀화 + 대역 끝.
  • ESR을 1/4로 줄이면 피크가 3.7배 높아지는 것, 10점/decade 그리드는 피크를 65 %로 읽는 것, "SRF와 decade 점에서만 확인" 하는 검사가 28.8 mΩ 피크를 놓치고 PASS를 주는 것을 테스트로 보인다.

Part C — VALBRD-A rev C, VDD_CORE_0V9: 최소 BOM과 두 보드의 VNA 측정#

  • min_bom(spec, objective) — 100 µF(0–6) × 10 µF(0–12) × 1 µF(0–12) 1183 조합을 전수 탐색. 10점/decade 그리드로 거르고, 목적함수(비용 또는 개수) 순으로 정밀화 재검증 → 첫 통과가 최소 BOM.
  • 조립된 두 보드를 VNA 2-port shunt-thru로 쟀다(SN0106_…s2p, SN0107_…s2p). s21_to_z 로 Z를 복원하고 fit_population 으로 실제로 실장된 개수를 추정한다. SN0107에는 결함이 심어져 있다 — 리포트만 보고 찾아야 한다.

2. Problem (English)#

Build a PDN impedance tool and pick the minimum decoupling BOM.

Using only the Python 3 standard library:

  1. z_target(v, ripple_pct, delta_i) → V·(ripple%/100)/ΔI. Capacitor model Z = ESR + j(ωL − 1/(ωC)), srf = 1/(2π√(LC)). VRM model Z = R + jωL. pdn_z(f, bom, parts, vrm) returns the impedance of the VRM in parallel with n_k copies of each part k (sum admittances).
  2. Evaluate |Z(f)| on a log grid 10 kHz–1 GHz, find local maxima (anti-resonance peaks), and refine each peak with a golden-section search on log f. Show that a coarse grid (10 pts/decade) under-reads a sharp anti-resonance and that checking only at self-resonant frequencies and decade points can pass a design whose true peak is 2× the target.
  3. For a rail with V = 0.9 V, 3 % ripple, ΔI = 2 A and a band of 10 kHz–20 MHz, exhaustively search the number of 100 µF / 10 µF / 1 µF capacitors (part library in pdn_spec.json) and return the cheapest BOM whose refined in-band maximum |Z| ≤ Ztarget.
  4. Read two 2-port shunt-through VNA measurements (Touchstone .s2p, # Hz S DB R 50), convert Z = 25·S21/(1 − S21), estimate how many of each capacitor are actually populated (least squares on log|Z|), and print a PASS/FAIL report.

Example: Ztarget = 13.5 mΩ; a single 100 µF part with 1.4 nH mounted ESL resonates at 425.4 kHz where |Z| = ESR; 100 µF ∥ 1 µF (1.4 nH / 0.8 nH) anti-resonates at 3.41 MHz.

4. 힌트#

힌트 1 — 병렬은 어드미턴스로 더한다

Z1 ∥ Z2 = 1/(1/Z1 + 1/Z2). 부품 k가 nₖ 개면 y += n / cap_z(...). 파이썬 complex 는 그대로 나눗셈이 된다. abs(z) 가 |Z|. 같은 부품 n 개 = C·n, ESR/n, ESL/n 인 부품 하나와 정확히 같다 — SRF는 그대로다.

힌트 2 — 반공진 = 두 가지의 리액턴스가 상쇄

병렬 Z = Z1·Z2/(Z1 + Z2). 무손실이면 Z1 + Z2 = 0 일 때 무한대. jω(L1+L2) + (1/jω)(1/C1 + 1/C2) = 0 → ω² = (1/C1 + 1/C2)/(L1 + L2). 이 주파수에서 큰 커패시터는 이미 인덕터처럼(SRF 위), 작은 커패시터는 아직 커패시터처럼(SRF 아래) 동작한다 — LC 탱크.

힌트 3 — 황금분할 탐색 (log f 축)

국소 최대 i 는 (fs[i−1], fs[i+1]) 안에 진짜 피크를 하나 품는다(그 구간에서 단봉 가정). x = log10 f 로 놓고 c = b − 0.618(b−a), d = a + 0.618(b−a). g(c) > g(d) 이면 피크는 [a, d] 에, 아니면 [c, b] 에 있다. 한 번에 구간이 0.618배 — 50번이면 0.05 decade 구간이 약 2e−12 decade로 줄어든다. 줄이면서 c 또는 d 하나는 재사용한다.

힌트 4 — 전수 탐색을 빠르게

조합이 1183개, 그리드가 34점이면 4만 번의 복소 연산이다. 부품별 어드미턴스 1/cap_z 를 그리드에서 한 번만 계산해 두고, 조합마다 Y = Y_vrm + Σ n·Y_k 만 더한다. |Z| 가 Ztarget을 넘는 순간 그 조합은 break. 그리드 통과 후보만 정렬해 앞에서부터 정밀화 — 정밀화는 비싸니 후보 몇 개에만 쓴다.

힌트 5 — shunt-thru 공식

두 50 Ω 포트 사이에 DUT Z 가 접지로 걸려 있다. 포트 2 쪽은 Z ∥ 50 Ω 이고, S21 = 2Z/(2Z + Z0), S11 = −Z0/(2Z + Z0) = S21 − 1. Z 에 대해 풀면 Z = (Z0/2)·S21/(1 − S21). 10 mΩ 이면 S21 ≈ 4e−4 (−68 dB).

힌트 6 — 실장 개수 추정

모델 |Z| 와 측정 |Z| 를 log 축에서 비교한다(1 mΩ 와 100 mΩ 를 같은 비율 오차로). 모든 개수 조합에 대해 RMS(log10 |Zmeas| − log10 |Zmodel|)를 구하고 최소를 고른다. 2등과의 차이가 추정의 확신도다. 부품 공차(C ±10 %)가 있으니 RMS는 0이 되지 않는다.

5. 풀이#

Part A — Ztarget에서 |Z(f)| 곡선까지#

① Ztarget. VDD_CORE_0V9: V = 0.9 V, 허용 동적 리플 3 % = 27 mV, 부하 스텝 ΔI = 2 A → Ztarget = 27 mV / 2 A = 13.5 mΩ. 가정을 같이 말해야 한다:

가정의미깨지면
선형·시불변ΔV(f) = I(f)·Z(f)큰 스텝에서 VRM이 포화/모드 전환(PFM↔PWM)
평탄(flat) 타겟모든 주파수에서 같은 한도ΔI 스펙트럼이 좁으면 과설계, 피크가 높은 Q면 시간 영역 링잉(아래)
ΔI = 스텝 크기보통 최대 전류의 일부(예: 50 %)실제 di/dt·반복 주파수가 피크와 겹치면 더 나쁨 (rogue wave)
리플 % = 동적 몫DC 정확도(VRM 설정, 부하 레귤레이션)와 나눔전체 ±3 %를 다 쓰면 DC 오차 몫이 없음 (HWLAB-B08 참고)

② 커패시터 한 개. Z = ESR + j(ωL − 1/ωC). 저주파에선 −1/ωC (−20 dB/dec), SRF = 1/(2π√(LC)) 에서 리액턴스가 상쇄되어 |Z| = ESR, 그 위에선 +ωL (+20 dB/dec) — 로그-로그 그래프의 V자. 100 µF / 1.4 nH → SRF 425.4 kHz, 10 µF / 1.0 nH → 1.59 MHz, 1 µF / 0.8 nH → 5.63 MHz.

L은 부품 자체 ESL(0402 ≈ 0.35 nH 수준) + 실장 인덕턴스(패드 → 비아 → 평면까지의 루프, 0.3–0.6 nH 수준)다. 이 레슨의 라이브러리는 둘을 나눠 적었다(esl_part_h, l_mount_h). 실장 L이 부품 ESL보다 크거나 비슷하다는 게 핵심이다 — SRF 위에서 커패시터는 "값"이 아니라 "실장 루프 인덕턴스" 이고, 값을 바꿔도 고주파 성능은 거의 안 변한다.

③ 병렬망. 같은 부품 n 개는 (nC, ESR/n, ESL/n) — V자가 SRF는 그대로 둔 채 아래로 1/n 내려간다. 서로 다른 부품과 VRM은 어드미턴스로 더한다. python3 -I solution.py --profile 실제 출력(일부, mΩ):

④ 피크 찾기. 그리드 |Z| 의 국소 최대(왼쪽보다 크고 오른쪽보다 크거나 같음)가 반공진 후보다. 40점/decade 그리드에서 rev C의 실제 출력: 1.06e+05 Hz 13.41 mOhm, 8.41e+05 Hz 3.88 mOhm, 4.47e+06 Hz 4.96 mOhm — 세 피크의 그리드 값은 정밀화 값(13.49 / 3.89 / 5.00 mΩ)보다 조금씩 낮다. 이 "조금" 이 Part B의 주제다.

Part B — 반공진은 어디에, 얼마나 높이#

주파수. 두 직렬 RLC 가지의 병렬 Z = Z1Z2/(Z1+Z2). 손실을 무시하면 분모 Z1+Z2 = j[ω(L1+L2) − (1/ω)(1/C1+1/C2)] 가 0이 되는 ω 에서 Z → ∞:

ω_ar² = (1/C1 + 1/C2)/(L1 + L2) = 1/((L1+L2)·Cs), Cs = C1C2/(C1+C2)

C1 ≫ C2 면 Cs ≈ C2 → f_ar ≈ 1/(2π√((L1+L2)C2)): 큰 커패시터의 ESL과 작은 커패시터의 C가 만드는 탱크다. rev C 피크 ②는 (200 µF, 0.7 nH) ∥ (50 µF, 0.2 nH) → 838.8 kHz (정밀화 835.6 kHz), 피크 ③은 (50 µF, 0.2 nH) ∥ (3 µF, 0.267 nH) → 4.379 MHz (정밀화 4.357 MHz). 다른 가지들이 조금 끌어당겨 해석식과 1 % 이내로 다르다. 피크 ①은 VRM(8 nH) ∥ 전체 C 253 µF → 1/(2π√(8 nH·253 µF)) = 111.9 kHz (정밀화 108.3 kHz).

높이. 반공진에서 Z1 ≈ R1 + jX, Z2 ≈ R2 − jX 이므로 Z = Z1Z2/(R1+R2) ≈ X²/(R1+R2) (X ≫ R 일 때). X 는 그 주파수에서 한 가지의 리액턴스 ≈ 특성 임피던스 √((L1+L2)/Cs). 결론이 반직관적이다:

  • ESR이 작을수록 피크가 높다. 손실이 없는 LC 탱크는 Q가 무한대다. 실제 출력 (100 µF ∥ 1 µF 한 개씩, VRM 없음):

Q = X/(R1+R2) ≈ 29.5/14.5 ≈ 2 로 낮아서 근사가 9 % 틀리고 피크 위치도 1.9 % 어긋난다. ESR을 1/4로 줄이면(Q ≈ 8) 근사가 4 × 60.14 = 240.6 mΩ, 실제 242.1 mΩ — Q가 클수록 근사가 맞는다. 테스트 허용치(주파수 3 %, 높이 10 %)는 이 Q≈2 경우의 근사 오차를 덮도록 잡은 것이다.

  • 그래서 "초저 ESR MLCC만 쓰면 좋다" 는 틀렸다. 대책: (a) 값 간격을 좁히거나 같은 값 여러 개로 반공진 자체를 줄이기, (b) 병렬 개수를 늘려 탱크의 특성 임피던스 √(L/C)를 낮추기, (c) 의도적으로 ESR이 있는 부품(폴리머/탄탈 벌크, controlled-ESR MLCC)으로 감쇠 — 연습 3에서 최적 ESR ≈ √(L/C) 를 확인한다.

8. 면접 Q&A#

Q1. 타겟 임피던스는 어떻게 정하고, 어떤 가정이 깔려 있나요?

Ztarget = V·(허용 동적 리플)/ΔI. 0.9 V, 3 %, 2 A 스텝이면 13.5 mΩ. 가정: PDN이 선형이라 ΔV(f) = I(f)·Z(f), 그리고 |Z| 가 대역 전체에서 평탄하게 한도 아래면 어떤 스펙트럼의 전류에도 리플이 한도 안이다. ΔI는 최대 전류 전체가 아니라 실제 스텝 크기(워크로드 특성, 흔히 최대의 절반 수준을 가정)이고, 리플 %는 DC 정확도 몫을 뺀 동적 몫이다. 꼬리질문: "평탄 타겟이 너무 보수적이거나 부족한 경우는?" → ΔI 스펙트럼이 좁으면 과설계(비싼 BOM). 반대로 피크가 Ztarget 아래라도 Q가 높으면 부하 전류가 그 주파수로 반복될 때(예: 루프 주기적 워크로드) 응답이 공진으로 쌓이고, 스텝 응답에도 링잉이 남는다 — 그래서 "평탄하고 감쇠된(flat & damped)" 임피던스를 목표로 하는 설계 철학이 있다. 시간 영역 최악 패턴은 부하 스텝 측정으로 확인한다(HWLAB-M02).

Q2. 반공진(anti-resonance)이 뭔가요? 주파수와 높이를 어떻게 추정하나요?

두 커패시터(또는 VRM과 벌크)가 병렬일 때, 큰 쪽은 SRF를 지나 인덕터가 되고 작은 쪽은 아직 커패시터인 주파수에서 둘이 LC 탱크를 이뤄 병렬 Z가 솟는다. 무손실이면 Z1+Z2 = 0 → ω² = (1/C1+1/C2)/(L1+L2). 높이는 X²/(R1+R2) (X ≫ R), X ≈ √((L1+L2)/Cs). 이 레슨의 100 µF∥1 µF는 3.41 MHz, 65.7 mΩ. 꼬리질문: "어떻게 줄이나?" → ① 값 간격을 좁힌다(100 µF→1 µF 두 decade 점프 대신 10 µF를 끼움 — Part B에서 28.8 mΩ 피크가 사라짐), ② 개수를 늘려 탱크의 특성 임피던스를 낮춘다, ③ ESR로 감쇠한다(폴리머 벌크, controlled-ESR MLCC — 최적 ESR ≈ √(L/C)), ④ 같은 값·같은 패키지를 여러 개 쓰면 그 커패시터들 사이에는 반공진이 없다(SRF가 같으니) — VRM·패키지와의 반공진은 남는다.

Q3. "핀마다 0.1 µF 하나" 규칙은 왜 이제 잘 안 맞나요?

그 규칙은 수 MHz 클럭, 수백 mΩ 타겟 시절의 것이다. SRF 위에서 커패시터는 실장 루프 인덕턴스로 동작하고, 같은 0402 패키지면 0.1 µF든 1 µF든 고주파 Z는 거의 같다 — 그러면 더 큰 값이 저주파까지 덮어 주니 손해가 없다. mΩ 타겟에서는 값보다 병렬 개수(Σn/ESL)와 비아 설계가 고주파를 정하고, 필요한 개수는 n ≥ 2π·f_hi·L_mount/Ztarget 로 바로 나온다(연습 4). 그리고 서로 다른 값을 마구 섞으면 반공진이 늘어난다. 꼬리질문: "실장 인덕턴스는 어떻게 줄이나?" → 비아를 패드 바로 옆(via-in-pad 또는 짧은 트레이스)에, 패드당 비아 2개 이상, 전원/접지 평면을 표면 가까운 층에(루프 면적 ↓), 역방향 기하(reverse-geometry, 예: 0204) 또는 다단자(IDC/X2Y 계열) 커패시터.

Q4. 보드 디커플링은 몇 MHz까지 책임지나요? 그 위는요?

다이에서 보면 보드 커패시터 앞에 패키지·BGA 볼·비아·평면 확산(spreading) 인덕턴스가 직렬로 있다. 그 인덕턴스와 온다이 커패시턴스가 또 하나의 반공진(흔히 수십~수백 MHz, "패키지–다이 공진")을 만들고, 그 위는 온다이 C만 유효하다. 보드 캡은 대략 수~수십 MHz까지 의미가 있고, 정확한 상한은 패키지 모델(칩 벤더의 PDN 가이드/모델)과 함께 정한다. 이 레슨은 20 MHz로 가정했다. 꼬리질문: "그럼 1 GHz까지 계산하는 의미는?" → 반공진이 대역 경계 바로 위에 있는지, 보드 캡 군의 L_eff가 패키지 공진 주파수를 어디로 옮기는지 보려고. 대역 밖이라도 높은 피크는 다른 레일과의 결합·EMI 문제로 이어질 수 있다.

Q5. 밀리옴 임피던스를 실제로 어떻게 재나요? 1-port로 안 되는 이유는?

1-port는 Z = Z0(1+S11)/(1−S11). Z = 10 mΩ면 S11 = −0.9996 — 반사계수가 거의 −1이라 작은 크기 오차가 1+S11 에서 증폭된다. 0.01 dB 오차로 Z가 −18.8 mΩ(288 % 오차)이 된다(연습 2). 2-port shunt-thru는 Z = 25·S21/(1−S21), S21 ≈ 4e−4 를 직접 재므로 0.01 dB가 0.115 % 오차다. 두 포트가 각각 레일에 닿으니 접촉 저항이 측정 경로에서 빠진다(켈빈 측정). 꼬리질문: "저주파에서 측정값이 이상하게 평탄하게 높게 나온다?" → 두 케이블의 실드 저항이 만드는 그라운드 루프가 DUT와 병렬/직렬로 끼어든다(대략 100 kHz 이하에서 두드러짐). 공통모드 트랜스포머나 아이솔레이터로 루프를 끊는다. VRM을 켠 채 재려면 DC 블록, 측정 하한(잡음 바닥)은 IFBW를 낮추고 평균으로 내린다.

Q6. VNA로 잰 피크가 시뮬레이션보다 높고 주파수가 다릅니다. 무엇부터 의심하나요?

주파수가 올라갔으면 C가 줄었다: DC bias derating(작은 패키지·낮은 정격 전압일수록 심함), X5R/X7R 온도 특성, 미실장. 주파수가 내려갔으면 L이 늘었다: 실장 L이 모델보다 큼(비아 위치, 평면 거리), 측정 픽스처 인덕턴스. 피크가 높아졌으면 감쇠가 줄었다: ESR이 모델보다 낮거나(초저 ESR 부품으로 대체), 손실 성분이 빠짐. 이 레슨처럼 저주파 반공진과 고주파 L_eff를 같이 보면 "C도 줄고 병렬 경로도 줄었다" = 미실장이 가장 그럴듯하고, 개수 조합 적합으로 확인한다(SN0107: 10 µF 2/5). 꼬리질문: "대체 부품(alternate part)으로 바뀐 것과 미실장을 어떻게 구분하나?" → 미실장은 C와 1/L이 같은 비율로 줄고, 다른 값으로의 대체는 SRF 자체가 이동한다. 적합 잔차(rms)가 공차 수준으로 떨어지는지가 판단 기준이다. 결국 AOI/X-ray와 BOM·feeder 기록으로 닫는다.

Q7. VRM과 벌크 커패시터 사이 반공진은 VRM 루프 설계와 어떤 관계인가요?

VRM 폐루프 출력 임피던스는 루프 대역폭 아래에선 낮고, 그 위로는 출력 인덕터/루프 이득 감소로 인덕터처럼 상승한다 — 이 레슨의 R + jωL 은 그 1차 근사다. 그 등가 L이 벌크 C와 탱크를 이뤄 108 kHz 피크(13.49 mΩ)를 만든다. 실제 VRM 출력 Z는 위상 마진이 낮으면 크로스오버 근처에 자체 피크가 생기고(감쇠비 ζ ↓ → 피크 ↑), 이 피크가 벌크 반공진과 겹치면 더 나빠진다. 부하 스텝 링잉에서 ζ·위상 마진을 추정하는 법은 HWLAB-M02 참고. 꼬리질문: "출력 캡을 늘리면 VRM이 불안정해질 수 있나?" → 그렇다. 많은 벅 컨트롤러는 출력 LC 공진과 ESR 영점을 보상기 설계에 쓴다. 벌크를 크게 바꾸면 LC 극점이 내려가 크로스오버 근처 위상이 바뀐다 — 디커플링 변경 후 VRM 루프(보드 phase/gain 측정 또는 부하 스텝)를 다시 확인한다. 특히 ESR 영점에 기대는 보상(타입 II)은 초저 ESR MLCC로 바꾸면 위상 마진을 잃는다.

9. 추가 연습#

연습 1 — 공차·온도·DC bias 코너#

derate_parts(parts) 로 C에 공차 하한(0.90) × X5R 온도 하한(0.85) × DC bias 계수(0.9 V에서 100 µF 0.80, 10 µF 0.85, 1 µF 0.92 — 대표값)를 곱한 코너 라이브러리를 만들고, rev C가 아직 Ztarget을 지키는지 보라. 못 지키면 코너 라이브러리로 min_bom 을 다시 돌려라.

답 보기

실제 출력: rev C nominal 13.49 mOhm @ 0.108 MHz | corner 21.50 mOhm @ 0.138 MHz → FAIL. 벌크 C가 61 %로 줄면 VRM–벌크 공진이 위로(138 kHz) 가고 √(L/C)가 커져 피크가 오른다. 코너에서 다시 탐색: 100u×5 10u×1 1u×4 $1.07 10 parts, max 13.07 mOhm @ 0.098 MHz — 비용이 거의 두 배. 이 BOM은 공칭 C에서도 통과한다(테스트로 확인 — 코너에서 통과했다고 공칭 통과가 자동으로 보장되는 건 아니니 꼭 같이 돌린다). 교훈: 최적화는 코너 라이브러리로 돌리고 공칭은 확인용으로. 그리고 VRM–벌크 피크가 비용을 지배하면, 벌크 개수를 늘리는 것보다 감쇠(연습 3)나 VRM 보상 조정이 싼 해법일 수 있다. DC bias 계수는 반드시 제조사 곡선(SimSurfing/K-SIM 등)으로 바꿔 넣을 것.

연습 2 — 1-port S11 vs 2-port shunt-thru 감도#

10 mΩ DUT에서 S11과 S21을 계산하고, 둘 다 크기에 +0.01 dB 오차가 있을 때 z_from_s11 과 s21_to_z 가 돌려주는 Z를 비교하라.

답 보기

실제 출력: S11=-0.999600 (-0.00347 dB) S21=3.998e-04 (-67.96 dB), +0.01 dB magnitude error -> 1-port Z = -18.78 mOhm, 2-port Z = 10.0115 mOhm. 1-port는 |S11|이 1을 넘어 저항이 음수가 된다(288 % 오차). Z = Z0(1+S11)/(1−S11) 에서 1+S11 ≈ 4e−4 라는 작은 차이를 큰 두 수의 뺄셈으로 얻기 때문이다(감도 dZ/dS11 = 2Z0/(1−S11)² ≈ 25 Ω). 2-port는 S21 자체가 작은 수라 상대 오차가 그대로 0.115 %. 1-port 반사 측정이 잘 되는 범위는 Z가 Z0(50 Ω) 근처일 때다.

연습 3 — 벌크 ESR로 VRM–벌크 반공진 감쇠#

rev C에서 100 µF 자리 부품의 ESR만 1–100 mΩ로 스윕하며 10 kHz–1 MHz 최악 |Z|를 구하라. 최적 ESR을 √(L_vrm/C_total)과 비교하라.

답 보기

실제 출력:

ESR이 너무 작으면 탱크 Q가 높아 피크가 크고(16.8 mΩ), 너무 크면 벌크가 "저항" 이 되어 VRM L을 못 받쳐 준다(27.7 mΩ, 피크가 위로 이동). 최적은 병렬 ESR ≈ 특성 임피던스 √(L/C) = 5.62 mΩ 근처(실제 6.29 mΩ, 비율 1.12) — RLC를 임계 감쇠 근처로 만드는 값이다. 피크가 13.5 → 7.9 mΩ로 내려가므로, 같은 Ztarget이면 더 적은 부품으로 갈 수 있다. 실무에선 폴리머 커패시터(ESR 수~수십 mΩ)나 controlled-ESR MLCC를 이 자리에 쓴다. 단, VRM 보상이 출력 캡 ESR에 의존하면 루프도 같이 바뀐다(Q7).

연습 4 — 봉투 뒷면 하한: 필요조건 vs 충분조건#

저주파: VRM이 Ztarget을 넘는 주파수 f_x = Ztarget/(2πL_vrm)에서 커패시터가 받으려면 C ≥ 1/(2πf_x·Ztarget) = L_vrm/Ztarget². 고주파: f_hi에서 병렬 ESL이 Ztarget 아래 → Σn/ESL ≥ 2πf_hi/Ztarget. 두 하한을 계산하고 rev C가 만족하는지, 그리고 두 하한을 모두 만족하는데도 실패하는 BOM을 하나 보여라.

답 보기

실제 출력: C_bulk >= L_vrm/Zt^2 = 43.9 uF (rev C has 253 uF); sum(n/ESL) >= 2*pi*f_hi/Zt = 9.31 /nH (rev C 10.18 /nH). rev C는 둘 다 만족. 함정 BOM 100u×1 10u×0 1u×9: C = 109 µF, Σn/ESL = 11.96 /nH — 두 하한 모두 통과인데 실제 최악 36.58 mΩ @ 1.528 MHz. 두 하한은 "각 끝단만" 본 것이고, 그 사이의 반공진은 개수·값 간격·ESR로만 정해진다. 면접에서 하한식은 "몇 개쯤?" 에 30초 안에 답하는 도구, 검증은 반드시 전 대역 계산(또는 측정)으로. 저주파 하한이 L/Zt² 인 것은 우연이 아니다: √(L/C) ≤ Zt, 즉 VRM–벌크 탱크의 특성 임피던스가 타겟 이하라는 조건과 같다. 그리고 Q가 1보다 크면 피크는 그보다 높으니 실제론 C가 더 필요하다(rev C는 하한의 5.8배).

10. 핵심 정리#

  • Ztarget = V·ripple%/ΔI (0.9 V·3 %/2 A = 13.5 mΩ). 가정: 선형, 평탄 타겟, ΔI = 실제 스텝, 리플은 동적 몫.
  • 커패시터 = ESR + j(ωL − 1/ωC), L = 부품 ESL + 실장 인덕턴스. SRF 위에선 값이 아니라 루프 인덕턴스. 같은 부품 n개 = (nC, ESR/n, ESL/n).
  • 병렬은 어드미턴스 합. 반공진 f = 1/(2π√((L1+L2)·C1C2/(C1+C2))), 높이 ≈ X²/(R1+R2) → ESR이 낮을수록 피크가 높다.
  • 위험한 곳은 SRF가 아니라 SRF 사이. 그리드는 피크를 놓치고(10점/decade → 65 %), 밀도와 오차가 단조가 아니다 → 국소 최대 + 황금분할 정밀화.
  • 이 레일의 최악점은 VRM L ∥ 벌크 C (108 kHz). 벌크 개수는 VRM 반공진이, 고주파 끝은 Σn/ESL ≥ 2πf_hi/Ztarget 가 정한다.
  • 최소 BOM = 목적함수(비용/개수) + 전수 탐색 + 정밀화 재검증. 최적해는 경계에 붙으니 공차·온도·DC bias 코너로 설계한다(코너에서 rev C 21.5 mΩ).
  • mΩ 측정은 2-port shunt-thru: Z = 25·S21/(1−S21). 1-port는 0.01 dB가 288 % 오차.
  • 미실장의 지문: 저주파 반공진 ↑ + 고주파 L_eff ↑ 동시에. log|Z| 적합으로 개수(SN0107: 10 µF 2/5)를 찾고, 위치는 AOI/X-ray로.
