IPC 학습 가이드 (2026-11-08)

IPC(Inter-Process Communication, 프로세스 간 통신)는 "서로 메모리를 공유하지 않는 실행 단위끼리 데이터와 신호를 주고받는 방법"이다. 리눅스 프로세스 사이뿐 아니라 RTOS 태스크 사이, 멀티코어 SoC의 코어 사이(메일박스·rpmsg), 호스트와 GPU 펌웨어 사이까지 같은 질문이 반복된다: 복사를 몇 번 하나, 누가 기다리나, 상대가 죽으면 어떻게 아나.

중심 아이템은 OS-B14 IPC 비교다. 이번에 빠져 있던 주제 7개(POSIX 메시지 큐, fd 전달, 프로세스 공유 락, 알림용 fd, 견고한 공유 메모리 프로토콜, 미니 RPC, macOS Mach/XPC)를 OS 트랙에 🆕로 추가하고, 다른 트랙에 흩어진 IPC 아이템과 함께 8개 층으로 묶었다.

쓰는 법

  • 층을 위에서부터 내려간다. 층마다 면접 체크를 말로 설명할 수 있으면 다음 층으로 간다.
  • ⭐ 표시 15개가 핵심 경로다. 시간이 없으면 ⭐만 순서대로 푼다.
  • 🆕 표시는 이 가이드를 만들며 새로 추가한 아이템이다 (7개).
  • 아이템 ID를 누르면 트랙 표의 그 줄로 간다. 레슨이 써졌는지(학습가능/준비중)는 그 표에서 실시간으로 보인다.
  • env가 linux면 Lima VM elinux, qemu면 QEMU, gpu면 NVIDIA GPU가 필요하다. 나머지는 Mac에서 바로 된다.

OS-B07Basic · mac시그널: 핸들러, async-signal-safe, self-pipe시그널 핸들러에서 할 수 있는 일의 제약과 안전한 처리 패턴을 익힌다
OS-B09 ⭐Basic · macmmap: 파일 매핑, 익명 매핑, MAP_SHARED vs PRIVATE메모리 매핑 I/O와 COW private 매핑의 의미를 실험으로 확인한다
OS-B14 ⭐Basic · macIPC 비교: 파이프·FIFO·Unix 소켓·공유 메모리IPC 수단별 지연·처리량·사용 패턴의 차이를 측정한다

  • ☐ IPC 왕복 지연에 문맥 교환 비용이 얼마나 들어가나

3. 공유 메모리와 동기화#

가장 빠른 IPC지만 가장 위험하다. 동기화와 "상대가 죽었을 때"를 직접 설계해야 한다.

아이템레벨 · env제목확인할 것 (아이템 목표)

DS-A01 ⭐Adv · macLock-free SPSC 큐: C11 atomics단일 생산자/소비자 큐를 acquire/release만으로 정확하고 빠르게 만든다
OS-A12 ⭐ 🆕Adv · mac견고한 공유 메모리 IPC: 버전·백프레셔·상대 프로세스 장애 감지빠른 공유 메모리 채널을 실서비스에서 쓸 수 있게 만드는 프로토콜 설계 요소를 익힌다.
ROS-A05Adv · mac미니 미들웨어 4: shared-memory 전송프로세스 간 zero-copy 전송(iceoryx 방식)을 구현하고 비교한다.
ROS-M06Mid · linuxIntra-process & zero-copy 통신같은 프로세스 내 복사 없는 메시지 전달과 그 조건을 이해한다.
DIST-B07Basic · macZero-copy 직렬화 (FlatBuffers 개념)파싱 없이 버퍼에서 바로 읽는 포맷의 구조와 trade-off를 이해한다

면접 체크 — 말로 설명할 수 있으면 통과

  • ☐ 공유 메모리에 일반 뮤텍스를 두면 안 되는 이유 (PROCESS_SHARED)
  • ☐ 락을 쥔 프로세스가 죽으면? robust mutex의 EOWNERDEAD
  • ☐ 프로세스 간 SPSC 링에서 head/tail의 memory order
  • ☐ 공유 메모리 채널에 버전 · 하트비트 · 시퀀스 번호가 필요한 이유
  • ☐ 제로카피가 "공짜"가 아닌 경우 (소유권 관리, 캐시 일관성)

4. 알림 · 이벤트#

OS-M12Mid · macI/O 모델 비교: blocking·non-blocking·select·kqueue 에코 서버스레드-per-연결과 이벤트 루프 모델의 차이를 구현과 부하 테스트로 체감한다
OS-M13Mid · linuxepoll 에코 서버: level vs edge triggered리눅스 epoll의 LT/ET 의미와 ET에서 EAGAIN까지 읽어야 하는 이유를 확인한다

면접 체크 — 말로 설명할 수 있으면 통과
