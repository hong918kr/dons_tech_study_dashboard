/*
다음은 위 문제와 유사하게 C 숙련도를 측정/향상시킬 수 있는 합리적인 10개 연습 과제입니다.
각 과제는 저수준 데이터 처리, 비트 조작, 메모리/버퍼 안전성, API 설계를 다룹니다.
테스트 코드는 생략합니다.

1. ZigZag + Base-128 Varint (signed 64-bit)
- 설명: int64_t를 ZigZag 인코딩한 뒤 Base-128 varint로 직렬화/역직렬화.
- 요구사항:
  - 음수/양수 모두 최소 바이트 수로 인코딩
  - 오버플로, 잘못된 입력(너무 긴 바이트열) 검출 및 에러 코드 반환
  - 스트리밍 디코딩 지원

2. 헤더 비트-패킹/언패킹
- 설명: 여러 필드를 하나의 64비트 워드에 패킹/언패킹.
- 필드:
  - version(3b), type(5b), flags(10b), payload_len(20b), session_id(26b)
- 요구사항:
  - 마스크/시프트 정확성, 범위 체크
  - 엔디안 독립적 메모리 레이아웃 문서화

3. 엔디안-안전 직렬화 유틸리티
- 설명: 버퍼에 정수형(16/32/64), 부동소수(float/double)을 Little/Big Endian으로 쓰고 읽는 API.
- 요구사항:
  - 미스얼라인드 접근 금지, 버퍼 경계 검사
  - const-correctness
  - 호스트 엔디안 자동 감지 또는 명시적 변환

4. 고정 크기 메모리 풀(프리 리스트)
- 설명: 일정 크기 블록 N개를 관리하는 경량 할당기 구현.
- 요구사항:
  - init/alloc/free 제공, O(1) 연산
  - 이중 해제/이상 포인터 방지
  - 선택: thread-unsafe/lock-free 변형

5. 순환(ring) 버퍼 바이트 큐
- 설명: 단일 생산자/소비자 시나리오용 원형 버퍼.
- 요구사항:
  - write/read/peek/size 제공
  - 오버런/언더런 처리, 래핑 처리
  - 8/16/32비트 벌크 쓰기 옵션, 메모리 제로화 정책

6. CRC16-CCITT(0x1021) 인크리멘탈 해시
- 설명: 스트림 데이터에 대해 누적 갱신형 CRC 계산.
- 요구사항:
  - 초기값/리플렉션/최종 XOR 옵션 지원
  - 속도와 코드 크기 트레이드오프(테이블 기반 vs 비테이블)
  - 공개 테스트 벡터 일치

7. TLV(Type-Length-Value) 인코더/디코더
- 설명: T=1바이트, L=2바이트(빅엔디안), V=가변의 프레임을 encode/decode.
- 요구사항:
  - 다중 TLV 파싱, 길이 초과/겹침 방지
  - 알 수 없는 T 스킵, 최대 길이 제한
  - 안전한 버퍼 탐색

8. COBS(Consistent Overhead Byte Stuffing) 프레이밍
- 설명: 0x00 구분자를 쓰는 프레임을 위해 COBS 인코드/디코드.
- 요구사항:
  - 입력에 0x00 포함 가능, 최대 프레임 길이 제한
  - 디코드 시 불량 프레임 검출
  - in-place 불가 시 안전 복사

9. 고정소수점(Q16.16) 산술 라이브러리
- 설명: add/sub/mul/div, saturating 연산, double <-> Q16.16 변환.
- 요구사항:
  - 오버플로/언더플로 처리
  - 반올림 모드 선택(내림/최근접)
  - 성능 고려한 곱셈/나눗셈 구현

10. 스트리밍 가변길이 프레임 파서 상태기계
- 설명: 시작 바이트 0x7E, 이스케이프 0x7D, 바이트-스터핑 규칙을 가진 프로토콜 파서.
- 요구사항:
  - 바이트 단위 feed API, 부분 입력/경계 분할 처리
  - 최대 길이/타임아웃 훅, 상태 리셋 로직
  - 오류 복구 전략

각 과제는 다음 포인트를 평가합니다:
- 정확한 비트 연산과 경계 체크
- 포인터, const, restrict, alignment, 메모리 안전성
- 오버플로/언더플로/에러 처리와 API 설계
- 엔디안/플랫폼 의존성 최소화
- 스트리밍과 점진적 처리 모델

원하시면 각 과제별 템플릿 헤더/함수 시그니처도 제공하겠습니다.
