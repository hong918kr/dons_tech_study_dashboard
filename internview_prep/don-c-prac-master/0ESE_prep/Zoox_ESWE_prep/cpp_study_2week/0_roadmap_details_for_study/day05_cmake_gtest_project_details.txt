[5일차: CMake & Google Test 프로젝트 실습 Step by Step]

CMake는 C/C++ 프로젝트의 빌드 자동화 도구입니다.
아래는 CMake와 Google Test를 활용한 실전 프로젝트 구조와 실습 예제입니다.

---------------------------
Step 1. 프로젝트 구조 설계
---------------------------
예시 디렉토리 구조:
project_root/
 ├── CMakeLists.txt
 ├── src/
 │    ├── Calculator.cpp
 │    └── Calculator.h
 ├── main/
 │    └── main.cpp
 └── test/
      └── test_calculator.cpp

---------------------------
Step 2. Calculator 클래스 분리
---------------------------
// src/Calculator.h
#pragma once
class Calculator {
public:
    int add(int a, int b) const;
    int sub(int a, int b) const;
    int mul(int a, int b) const;
    int div(int a, int b) const;
};

// src/Calculator.cpp
#include "Calculator.h"
#include <stdexcept>
int Calculator::add(int a, int b) const { return a + b; }
int Calculator::sub(int a, int b) const { return a - b; }
int Calculator::mul(int a, int b) const { return a * b; }
int Calculator::div(int a, int b) const {
    if (b == 0) throw std::invalid_argument("divide by zero");
    return a / b;
}

---------------------------
Step 3. main 실행 파일 작성
---------------------------
// main/main.cpp
#include <iostream>
#include "Calculator.h"
int main() {
    Calculator calc;
    std::cout << "2 + 3 = " << calc.add(2, 3) << std::endl;
    return 0;
}

---------------------------
Step 4. Google Test 테스트 작성
---------------------------
// test/test_calculator.cpp
#include <gtest/gtest.h>
#include "Calculator.h"
TEST(CalculatorTest, Add) {
    Calculator calc;
    EXPECT_EQ(calc.add(2, 3), 5);
}
TEST(CalculatorTest, DivideByZero) {
    Calculator calc;
    EXPECT_THROW(calc.div(1, 0), std::invalid_argument);
}

---------------------------
Step 5. CMakeLists.txt 예시
---------------------------
# project_root/CMakeLists.txt
cmake_minimum_required(VERSION 3.10)
project(CalculatorProject)

# Calculator 라이브러리
add_library(calculator src/Calculator.cpp)

# main 실행 파일
add_executable(main_exec main/main.cpp)
target_link_libraries(main_exec calculator)

# GoogleTest 연동
find_package(GTest REQUIRED)
enable_testing()

# 테스트 실행 파일
add_executable(calculator_test test/test_calculator.cpp)
target_link_libraries(calculator_test calculator GTest::gtest GTest::gtest_main)

# 테스트 자동화
add_test(NAME CalculatorUnitTest COMMAND calculator_test)

---------------------------
Step 6. 빌드 및 테스트 실행
---------------------------
mkdir build
cd build
cmake ..
make
./main_exec           # 메인 프로그램 실행
ctest                 # 또는 ./calculator_test

---------------------------
[추가 설명]
---------------------------
- add_library: 라이브러리 타겟 생성
- add_executable: 실행 파일 타겟 생성
- target_link_libraries: 타겟에 라이브러리 연결
- find_package(GTest REQUIRED): 시스템/패키지 매니저에서 gtest 찾기
- add_test: ctest로 자동 테스트 등록
- enable_testing(): 테스트 기능 활성화

이 예제를 따라하면 CMake와 gTest의 기본적인 프로젝트 구성을 익힐 수 있습니다!
