## 📌 한 줄 요약
이번 강의는 신경망의 기본 학습 구조를 복습한 뒤, 여러 사례 연구(case study)를 통해 AI 프로젝트에서 **어떻게 의사결정을 내리는지**를 다룬다. 주야간 분류, 트리거 워드 탐지(trigger word detection), 얼굴 검증(face verification)을 통해 지도학습(supervised learning)을 살펴보고, 이어서 **자기지도학습(self-supervised learning)**, 대조학습(contrastive learning), 약지도학습(weakly supervised learning), 그리고 멀티모달 임베딩(multimodal embedding)까지 연결한다. 핵심 관통 개념은 **임베딩(embedding)**이 현대 AI 시스템을 잇는 "연결 조직(connective tissue)"이라는 점이다.

## 🎯 핵심 메시지
> "딥러닝은 공학(engineering) 분야다. 좋은 데이터 수집·라벨링 전략을 세우고, 사람을 프록시(proxy)로 한 실험으로 빠르게 가설을 검증하며, 전문가의 조언을 활용해 의사결정을 내리는 것이 모델 자체만큼 중요하다."

**보조 메시지**
- 모델 = **아키텍처(architecture, 청사진)** + **파라미터(parameters)** 두 가지로 이해하라. 클라우드 상의 "두 개의 파일"이 곧 모델이다.
- 입력·출력·아키텍처·**손실 함수(loss function)**는 모두 바꿀 수 있는 설계 변수이며, 특히 손실 함수 설계는 "예술(art)"이다.
- 데이터의 양과 다양성이 필요한 모델의 **용량(capacity)**을 결정한다. 데이터보다 용량이 너무 크면 **과적합(overfitting)**으로 외워버린다.
- 라벨링 비용을 줄이는 방향으로 학습 패러다임이 진화했다: 지도학습 → 자기지도학습 → 약지도학습.

## 🔁 복습: 신경망 학습의 기본 구조

전통적 지도학습 설정은 입력 → 모델 → 출력으로 흐른다. 예: 고양이 이미지 입력 → 0~1 사이 확률 출력(1=고양이, 0=고양이 아님).

**학습 과정(경사하강법, gradient descent)**
1. 이미지를 (아직 학습되지 않은) 모델에 통과시켜 예측을 얻는다.
2. **손실 함수(loss function)**로 정답(ground truth)과 예측의 차이를 측정 → 멀면 페널티.
3. 이 피드백으로 파라미터를 "조금 오른쪽/왼쪽으로" 갱신한다.
4. 수백만 장의 배치(batch) 데이터로 이를 반복해 파라미터를 보정한다.

**바꿀 수 있는 설계 변수**

| 요소 | 예시 / 변형 |
|------|-------------|
| 입력(input) | 이미지, 텍스트, 오디오, 비디오, 정형 데이터(스프레드시트) |
| 출력(output) | 분류(0/1), 회귀(예: 고양이 나이 추정), 생성(저해상도→고해상도, 출력이 입력보다 큰 경우) |
| 아키텍처 | MLP/완전연결망, RNN, CNN, Transformer (모두 기본 신경망을 다르게 쌓은 것) |
| 손실 함수 | 과제에 맞게 창의적으로 설계 (예: YOLO의 복잡한 손실 함수) |
| 기타 | 활성화 함수, 옵티마이저, 하이퍼파라미터 |

### 뉴런(neuron) = 로지스틱 회귀
이미지는 RGB 3채널의 숫자를 벡터로 펼쳐 뉴런에 입력한다. 뉴런은 두 부분으로 구성된다.

```
선형부:  z = Wᵀx + b      (W=가중치, b=편향)
활성화:  a = sigmoid(z)    (임의의 수를 0~1로 → 확률처럼 해석)
```
예: 출력 0.73 > 0.5 → 모델은 고양이가 있다고 판단.

### 다중 동물 분류로 확장하기 (인터랙티브 토론)
고양이 탐지를 cat/dog/giraffe 다중 탐지로 바꾸려면:
- **출력 레이어**를 동물 수만큼 뉴런으로 늘린다 (동물당 1뉴런, 각각 독립).
- 강아지·기린·자연 등 **데이터**를 추가한다.
- ⚠️ 가장 흔한 실수: 데이터만 추가하고 **라벨을 바꾸지 않는 것**.
  - **원-핫 벡터(one-hot)**: 고양이만 있으면 `[0,1,0]`
  - **멀티-핫 벡터(multi-hot)**: 고양이+강아지면 `[1,1,0]`

### 표기법(notation)과 용량(capacity)
- `a` 위첨자 대괄호 `[layer]` = 레이어 번호, 아래첨자 `index` = 뉴런 번호, `a`는 활성화(activation).
- 망이 깊을수록 **용량(capacity)**이 커진다 = 더 유연. 단, 데이터 대비 용량이 과하면 **외워버려(overfit)** 진짜 "고양이"를 학습하지 못한다.

### 신경망 내부에서 일어나는 일: 인코딩(encoding)
얼굴 데이터로 잘 학습된 망의 각 뉴런을 들여다보면:
- **앞쪽 레이어**: 픽셀을 직접 보므로 저수준 특징(대각선/수직/수평 엣지) 인코딩.
- **중간 레이어**: 앞 레이어 출력을 보므로 더 높은 수준(눈, 코, 귀 — 엣지로 원을 검출).
- **깊은 레이어**: 과제에 가까운 큰 얼굴 특징을 검출.

> **피처 엔지니어링(feature engineering) vs 피처 러닝(feature learning)**: 과거엔 눈 검출기·입 검출기를 사람이 수동으로 만들어 조합했다. 지금은 **end-to-end 학습**으로 데이터가 스스로 말하게 하여 특징을 자동으로 배운다(feature learning).

> **인코딩 vs 임베딩**: 인코딩은 임의의 벡터 표현. **임베딩(embedding)**은 그 인코딩 간 거리가 **의미(meaning)**를 가질 때를 가리킨다 — 가까우면 유사, 멀면 상이. 검색·연관 같은 작업의 핵심.

## ☀️🌙 사례 1: 주야간 분류 (Day/Night Classification)

문제: 이미지를 주간(1) / 야간(0)으로 분류. (파운데이션 모델이 없다고 가정하고 "후드 밑"을 들여다보는 연습)

**핵심 토론 포인트**
- **과제 정의가 먼저다.** 한 장소만 보는지, 전 세계 어디서나 보는지에 따라 난이도와 필요 데이터량이 완전히 달라진다.
- **어려운 경우들(엣지 케이스)**: 실내 사진(시계로 추정?), AM/PM 모호함, 흐림/맑음, 노르웨이/스웨덴 북부(백야), 여명/황혼(dawn/dusk → "낮/밤의 정의" 문제).
- 데이터 수집: 같은 장소에서 폰으로 주간·야간 스트림 촬영 등.

**해상도(resolution) 결정 — 사람을 프록시로 사용**
- 너무 낮으면 정보 손실(예: 시계가 안 보임), 너무 높으면 연산량 증가 → 학습이 무겁고 느려져 **반복 주기(iteration cycle)**가 길어진다.
- 여러 해상도로 출력해 사람에게 "낮/밤 구분 가능?"을 물어 임계 해상도를 찾는다.
- 결론: **64×64×3** 근처. 색(3채널)은 파란 하늘 정보 때문에 이 과제에선 유의미 (강화학습에선 색 제거가 학습을 단순화하기도 함).

**설계 요약**

| 요소 | 선택 |
|------|------|
| 출력 | 0/1 |
| 마지막 활성화 | **sigmoid** (0~1 출력) |
| 아키텍처 | 얕은 망(shallow) + convolution (이미지/시퀀스에 강함) |
| 손실 함수 | **logistic loss = binary cross-entropy** |

> 교훈: 여러 **프록시 프로젝트**를 쌓아두면("그때 사람 실험은 이랬지", "그 과제엔 이미지가 이만큼 필요했지") 나중에 빠른 의사결정이 가능하다.

## 🎙️ 사례 2: 트리거 워드 탐지 (Trigger Word Detection)

배경: Alexa/Siri 같은 음성 비서는 단일 모델이 아니라 에너지·효율을 위한 **모델 캐스케이드(cascade)**다.

```
1) 활동 감지 (경량): 소리(볼륨)가 있는가? → 항상 켜져 있어도 에너지 적음
2) 트리거 워드 (중간): "Alexa / Hey Siri / OK Google" 키워드만 청취
3) 본 모델 (무겁고 느림): 실제 요청 이해
```
이 사례는 **2번(트리거 워드)** 모델. 문제: 10초 오디오에서 단어 "activate" 탐지.

**데이터 수집 토론**
- 오디오는 주파수(frequency) 신호. **푸리에 변환(Fourier transform) + 전처리** 후 입력. 단어 길이(시퀀스 길이)도 중요.
- 캠퍼스에서 마이크(폰)로 "activate"와 다른 단어/문장 녹음. **부정 단어(negative)**로 "deactivate"처럼 비슷한 단어를 넣어야 모델이 구분을 배운다.
- ⚠️ 단어 선택 자체가 중요: 일상에서 잘 안 쓰는 단어여야 한다(실제로 "activate"는 나쁜 선택).

**데이터 분포(distribution)가 중요한 이유** — 캠퍼스 데이터만으로는 한계
- **억양(accents)**: 초기 모델은 강사의 독일인 친구들에게서 작동하지 않아 추가 수집 필요.
- **연령대**: 캠퍼스는 평균 연령이 낮아 주파수 분포가 편향.
- **말 속도(cadence)**: 사람은 잘 구분하지만 주파수 수치상으론 매우 다르게 보여 모델이 고전.
- **성비(male/female)**, **배경 소음(background noise)**: 조용한 캠퍼스 데이터는 뉴욕 지하철 환경에서 실패.

**라벨링 스킴(labeling scheme) — 사람 실험**
- 스킴 1: 클립 전체에 단일 라벨 `0` 또는 `1` (단어 유무만). 라벨링은 쉬우나 학습이 매우 어려움 → 약 1000배 데이터 필요(cold start 문제).
- 스킴 2: 단어가 재생되는 위치에 **시퀀스로 1을 찍음**. 라벨링이 1000배 어렵지 않으면서 학습은 훨씬 빠름.
- 사람도 단어 위치를 알려주면 훨씬 쉽게 찾았다(이탈리아어 샘플 실험) → "사람에게 쉬우면 모델에게도 쉽다".
- 추가 트릭: 라벨이 0으로 **편향(skew)**되면 전부 0을 찍어도 99.9% 정확. 그래서 양/음 라벨을 **균형(balance)** 있게 만드는 순수 공학적 핵.

**설계 요약**

| 요소 | 선택 |
|------|------|
| 마지막 활성화 | 시퀀스의 매 타임스텝마다 **sigmoid** |
| 아키텍처 | **RNN** (이후 강의에서 학습) |
| 손실 함수 | **binary cross-entropy를 매 타임스텝 시퀀스로** 적용 |

**합성 데이터 생성 (3시간에 수백만 데이터)**
1. 세 개의 DB 구축: ① 긍정 단어("activate") ② 부정 단어(deactivate, kitchen, lion …) ③ 배경 소음 (온라인에 사실상 **무료**·무한).
2. 캠퍼스에서 단어만 정확히 잘라 녹음(licensing 지식 중요: CC BY, CC BY-NC, MIT, Apache 등).
3. **파이썬 스크립트**로 배경 소음 10초에 부정/긍정 단어를 무작위·비중첩 삽입 → 스크립트가 삽입 위치를 알므로 **자동 라벨링**.
4. **데이터 증강(data augmentation)**: 주파수 증감, 가속/감속 등.
- ⚠️ 이건 **학습셋**용. **테스트셋(test set)**은 실제와 최대한 가깝게 **수동 라벨링**(소량).

> 교훈: 데이터 수집·라벨링 전략, 사람 실험, **전문가 조언(TA/시니어)**이 결정적. 아키텍처 탐색(architecture search)도 전문가는 무엇이 실패할지 안다.

## 🧑‍🦱 사례 3: 얼굴 검증 (Face Verification)

문제: 학교가 학생증 검증에 얼굴 인식 사용. 카메라가 찍은 얼굴과 DB의 사진이 같은 사람인지 확인.

- 데이터: 입학 시 업로드한 사진(최소 1장) DB에 이미 존재. 같은 사람을 여러 각도·시간대로 수집하면 좋음.
- 해상도: 주야간 과제보다 **높아야** 함(눈동자 색 등 미세 차이 필요). 사용 예 **412×412×3** (공항 보안은 홍채 수준으로 훨씬 더 높음).
- 출력: 0/1 (이 사람 맞나/아니다).

**왜 픽셀 비교(pixel comparison)가 안 되는가**
두 사진의 픽셀을 직접 비교해 가까우면 동일인이라 판단하는 방식의 문제들:
- **조명(lighting)** 차이: 같은 위치 픽셀이 밝음 vs 어두움(차이 ≈255)인데 정작 의미는 없음.
- **이동 불변성(translation invariance)** 위배: 사람이 3픽셀 이동하면 비교 완전히 달라짐.
- 배경, **거리(scale)**, **회전(rotation)** 불변성, 안경/모자, 헤어스타일/수염, 나이 변화(학생증은 더 어릴 때).

**해법: 인코딩(encoding) 기반 비교**
얼굴을 이해하도록 학습된 망의 중간/깊은 층 벡터(예: **128차원**)는 픽셀보다 의미 있는 비교 기준이 된다.

```
학생증 사진 → [딥 신경망] → 벡터 v1
카메라 사진 → [같은 신경망] → 벡터 v2
거리 = dist(v1, v2)      예: 0.4
거리 < 임계값(threshold)? → 동일인 판정
```
- 임계값이 **참/거짓 양성·음성(TP/FP/FN)** 비율을 결정. 공항은 낮은(엄격한) 임계값, 식당은 느슨한 임계값.
- 출력(0/1 단일 차원)이 아닌 **벡터**를 비교하는 이유: 1차원은 의미 있는 정보를 담을 수 없고, 충분히 큰 벡터라야 검증에 필요한 정보를 유연하게 담는다.

**손실 함수 설계: 트리플렛 손실 (Triplet Loss)**
원하는 것: *같은 사람 사진 → 비슷한 벡터, 다른 사람 사진 → 다른 벡터*.

- **트리플렛(triplet)** = (Anchor 기준, Positive 동일인, Negative 다른 사람).
- Anchor–Positive 인코딩 거리는 **최소화**, Anchor–Negative 거리는 **최대화**.

```
L = max( ||Enc(A) - Enc(P)||²  -  ||Enc(A) - Enc(N)||²  +  α ,  0 )
   (A=anchor, P=positive, N=negative, α=마진/margin)
```
- 세 사진을 같은 망에 병렬(배치)로 통과 → 세 벡터 → 손실 계산 → 파라미터 갱신을 반복.
- **α(alpha) 마진**이 없으면 0이 정답이 되어 모델이 불안정해질 수 있어 안정성을 위해 필요.
- 출처: **FaceNet** (Schroff et al., 2015). 슬라이드에는 항상 논문 참조를 표기.

> 인터랙티브 투표: "A–P 거리를 최소화"가 핵심 키워드. *minimize*이므로 정답은 A.

## 🔍 검증 → 식별 → 클러스터링 (인코딩 망의 재활용)

같은 인코딩 망 위에 간단한 알고리즘만 얹으면 다른 과제로 확장된다.

| 과제 | 정의 | 방법 |
|------|------|------|
| 얼굴 **검증**(verification) | 카드 스와이프 후 "같은 사람?" 1:1 비교 | 트리플렛 손실로 학습된 망 + 임계값 (유럽 공항식) |
| 얼굴 **식별**(identification) | DB에서 "누구인가?" 즉시 인식 | **K-최근접이웃(KNN)**: 사진→이미지 대신 **벡터**를 DB에 저장, 카메라 벡터의 최근접 벡터 탐색 (Global Entry식) |
| 얼굴 **클러스터링**(clustering) | 라벨 없이 같은 사람끼리 묶기(폰 갤러리) | **K-means**(비지도): 벡터들을 군집화, 같은 사람 벡터는 한 곳에 모임 |

- 학습 시에만 negative로 트리플렛을 만들고, **테스트 시에는 negative 없이** 카메라 벡터와 DB를 비교.
- KNN으로 K=3, 10 등을 쓰면 "최근접 K개가 모두 동일인"인지 확인해 보안을 강화.
- DB에 없는 사람: 최근접 벡터도 임계값을 초과 → 입장 거부. (그래서 사전 가입/등록이 필요)
- K-means의 군집 수 결정 알고리즘은 CS230이 아닌 **CS229**에서 다룸.

## 🌱 자기지도학습 (Self-Supervised Learning)

지금까지(주야간, 트리거 워드, 트리플렛)는 모두 **지도학습**(라벨 존재). 그러나 **라벨링은 비싸다.** 라벨 없이 학습하려면?

**핵심 아이디어: 데이터 증강으로 스스로 라벨 만들기**
- 강아지 사진을 90° 회전해도 같은 강아지 → 두 이미지의 벡터가 **가까워지도록** 손실을 설계 (회전 불변성 + 의미 학습).
- 얼굴 한쪽 절반에 패치(patch)를 가리고 두 변형이 같은 벡터를 갖도록 강제.
- 즉 노이즈·회전·크롭·이동 등 **증강 쌍(pairs)**을 만들어 "이 둘은 같다"고 학습 → 라벨 불필요.

> 이것이 **자기지도학습**: 사람이 수동으로 라벨링하지 않고, 데이터의 패턴 자체로부터 학습하는 환경을 만든다.

- 예시 논문: **SimCLR**. 2015 FaceNet의 **지도 트리플렛** → **자기지도 쌍(pairs)**으로의 전환이, 현대 모델이 **수십억 장의 라벨 없는 이미지**로 학습되는 이유.
- 이 방법을 **대조학습(contrastive learning)**이라 부른다: *같이 속하는 것은 끌어당기고, 아닌 것은 밀어낸다.*

### 텍스트의 자기지도: 다음 토큰 예측 (Next Token Prediction)
GPT의 핵심. 문장을 보고 다음 단어(토큰)를 예측 → 사람이 라벨링하지 않으므로 자기지도.

**창발 행동(emergent behavior)** — 단순 목표에서 의도치 않게 생기는 능력:

| 예시 문장 | 창발하는 이해 |
|-----------|---------------|
| "I poured myself a cup of ___" (tea/coffee/water) | 컵에 들어가는 것·액체라는 물리 이해, **공기 공존(co-occurrence) 패턴** |
| "The capital of France is ___" (Paris) | **실세계 사실(facts)** 인코딩 |
| "She unlocked her phone using her ___" (face/password/fingerprint) | 의미적 이해(잠금 해제 수단들이 유사) |
| "The cat chased the ___" (dog/mouse/ball) | **확률적 추론** |
| "If it's raining I should bring an ___" (umbrella) | **추론·인과(조건 연결)** |

> **창발 행동(emergent behavior)**: 명시적으로 가르치거나 라벨링하지 않았는데, 단순한 학습 목표를 대규모(scale)로 수행할 때 나타나는 예상 밖 능력. (이후 강화학습 강의에서 로봇·게임의 창발, 예: AlphaGo도 다룸)

### 다른 모달리티의 자기지도
| 모달리티 | 자기지도 과제 |
|----------|---------------|
| 오디오 | 일부 타임스텝(예: 20개) **마스킹** 후 복원 |
| 비디오 | 일부 프레임 제거 후 예측 |
| 생물학(단백질/DNA) | 구조의 일부를 마스킹 후 완성 → 패턴 학습 |
- 한계는 본질적으로 **연산량(compute)과 규모**뿐.

## 🔗 약지도학습과 멀티모달 임베딩 (Weakly Supervised & Multimodal)

세계는 멀티모달이다(단어·이미지·소리·행동을 함께 경험). 이들을 어떻게 연결하나?

**약지도학습(weakly supervised learning)**
- 텍스트–이미지를 잇으려면 이미지 캡션 같은 라벨 데이터가 필요. 그러나 인스타그램 캡션처럼 세상에 **자연 발생적으로 짝지어진(naturally occurring pairings)** 데이터를 활용.
- 사람이 직접 라벨링하지 않고 자연 발생 쌍을 이용하므로 순수 지도학습이 아닌 **약지도학습**이라 부른다.

**자연 발생 멀티모달 쌍의 예** (모달리티 연결에 사용)
- 오디오 ↔ 비디오 (유튜브: 짖는 소리 + 짖는 영상)
- 영상/이미지 ↔ 자막(텍스트) ↔ 오디오 (영화 자막)
- 음악 ↔ 곡 제목, 유전형 ↔ 표현형, 의료 영상 ↔ 초음파, 게임 영상 ↔ 키보드 입력, 표정 등

**공유 공간(shared space)과 ImageBind**
- 목적: 서로 다른 모달리티의 벡터를 공간상에서 **서로 가깝게** 표현.
- 대부분의 모달리티는 **텍스트**로 연결되므로 텍스트를 공유 공간의 중심 축(pivot)으로 삼는 경우가 많다.
- **ImageBind** (Meta): 대부분이 단일 모달리티를 거쳐 연결됨. 예: 열화상 → 이미지 → 텍스트. 그래서 텍스트는 이미지를 통해 열화상과도 연결.
- 데모: 텍스트 "drums" → 드럼 오디오 + 벡터 공간상 가장 가까운 이미지. "개 짖는 소리 + 사진" → "해변의 개" 같은 멀티모달 임베딩.
- 핵심 통찰: **공유 임베딩 공간**이 모달리티를 잇는 "연결 조직"이며, 최근 몇 년의 가장 큰 혁신 중 하나.

## 🔑 핵심 용어

| 용어 | 의미 |
|------|------|
| 아키텍처 / 파라미터(architecture / parameters) | 모델의 청사진(구조)과 학습되는 가중치. 클라우드 상 "두 파일" |
| 용량(capacity) | 망의 표현력. 깊을수록 큼. 데이터 대비 과하면 과적합 |
| 피처 러닝(feature learning) | 사람이 특징을 설계(엔지니어링)하지 않고 end-to-end로 자동 학습 |
| 인코딩 / 임베딩(encoding / embedding) | 임의 벡터 표현 / 거리에 의미가 있는 벡터 표현 |
| 원-핫 / 멀티-핫(one-hot / multi-hot) | 단일 라벨 벡터 / 다중 라벨 벡터 |
| 손실 함수(loss function) | 예측-정답 차이로 피드백을 주는 함수. 설계가 "예술" |
| binary cross-entropy / logistic loss | 이진 분류용 손실 함수 |
| 푸리에 변환(Fourier transform) | 오디오를 주파수로 변환하는 전처리 |
| cold start / 라벨 편향(skew) | 초기 학습 난항 / 라벨이 한쪽으로 쏠려 신호 찾기 어려움 |
| 트리플렛 손실(triplet loss) | (anchor, positive, negative)로 동일/상이를 학습하는 손실 |
| 마진 α(alpha/margin) | 트리플렛 손실의 안정화 항 |
| KNN / K-means | 식별용 최근접이웃 / 클러스터링용 비지도 알고리즘 |
| 자기지도학습(self-supervised learning) | 라벨 없이 데이터 패턴으로 학습 (증강 쌍, 다음 토큰 예측) |
| 대조학습(contrastive learning) | 유사 쌍은 끌고 비유사 쌍은 미는 학습 (예: SimCLR) |
| 다음 토큰 예측(next token prediction) | GPT의 자기지도 목표 |
| 창발 행동(emergent behavior) | 단순 목표를 대규모로 학습할 때 생기는 예상 밖 능력 |
| 약지도학습(weakly supervised learning) | 자연 발생 쌍(캡션 등)을 활용한 학습 |
| 공유 공간 / ImageBind | 모달리티를 잇는 공통 임베딩 공간 (텍스트 중심 축) |

## ✍️ 학습 메모
- **모델 = 아키텍처 + 파라미터** 프레임으로 모든 시스템(ChatGPT 포함)을 단순화해 이해하라.
- 프로젝트 의사결정 시 **사람을 프록시로 한 빠른 실험**(해상도, 라벨링 스킴 비교)을 적극 활용하라.
- **데이터/라벨링 전략이 모델 성능을 좌우**한다. 합성 데이터 + 자동 라벨링 + 데이터 증강으로 학습셋을 대량 생성하되, 테스트셋은 실제에 가깝게 수동 라벨링하라.
- 손실 함수는 "원하는 결과(유사→가깝게, 상이→멀게)를 평이한 영어로 먼저 표현"한 뒤 수식으로 옮겨 설계하라.
- 다음에 학습할 것: **RNN/CNN/Transformer**(아키텍처), **오토인코더·확산 모델(diffusion)·GAN**(2주 뒤, 생성 모델링), 신경망 해석·시각화 강의, **적대적 공격·방어**(2주 뒤), 심층 강화학습.
- 보충: convolution의 정확한 동작, triplet loss의 α 역할, KNN의 K 선택, K-means 군집 수 결정(CS229)은 직접 구현하며 직관을 쌓을 것.
