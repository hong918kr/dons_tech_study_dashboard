## ⭐⭐⭐ 최우선

### 1. Silicon System Integration / Architecture Engineer, TPU (Cloud)
- **하는 일**: TPU SoC 시스템 통합/아키텍처 — 블록 통합, 시스템레벨 정의, 데이터센터 가속기
- **내 매칭**: 실리콘-시스템 integration 경험 직결 ✅ / 갭: TPU/DC 가속기 아키텍처, 버스/NoC
- 참고: [Silicon System Integration/Architecture, TPU](https://www.google.com/about/careers/applications/jobs/results/94149051930288838-silicon-system-integrationarchitecture-engineer/)

### 2. Hardware Design and Integration Engineer

## ⭐⭐ 확장 방향

### 3. Silicon Engineer, Platform & Devices (Tensor / On-device)
- **하는 일**: 소비자 디바이스용 SoC — imaging, **ML(on-device)**, video, security. Pixel/Tensor 칩
- **내 매칭**: on-device LLM 방향 부합 / 갭: 소비자 SoC, ML 블록
- 참고: [Silicon Engineer, Platform and Devices, 2026](https://www.google.com/about/careers/applications/jobs/results/73379279982731974-silicon-engineer-platform-and-devices-university-graduate-2026)

### 4. TPU SoC Design Engineer / ASIC Design (RTL)
- **하는 일**: SoC-level RTL(SystemVerilog), top-level 통신버스, ASIC 통합
- **내 매칭**: 통합 관점 / 갭: **RTL 설계**(SV) — 진입 시 필요
- 참고: [TPU SoC Design Engineer](https://careers.google.com/jobs/results/120353972954243782-tpu-soc-design-engineer/), [Senior ASIC Design](https://www.google.com/about/careers/applications/jobs/results/128568901167391430-senior-asic-design-engineer-google-cloud)

### 5. Post-Silicon Validation / ASIC Formal Verification (TPU Compute)
- **내 매칭**: 검증/브링업 감각 / 갭: formal, TPU DV 플로우
- 참고: [ASIC Formal Verification, TPU Compute](https://www.google.com/about/careers/applications/jobs/results/93401021752976070-asic-formal-verification-engineer/)

### 6. Edge / LiteRT NPU Enablement (On-device LLM)
- **하는 일**: LiteRT로 mobile~IoT~AI PC에 모델 배포, Qualcomm/내부 NPU에서 on-device LLM(Gemma 등) 최적화
- **내 매칭**: on-device 방향 / 갭: ML, 양자화, 컴파일러/런타임, Python
