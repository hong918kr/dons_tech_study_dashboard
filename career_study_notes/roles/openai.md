# OpenAI — Target Roles

> 커스텀 AI 실리콘(코드명 *Jalapeño*) + **로보틱스 재가동**(데이터센터/전력망/공장 buildout용 로봇).
> HW/SW co-design과 로보틱스 **펌웨어**가 내 프로필과 강하게 공명. 스타트업 결 → role 폭이 넓음.
> _리서치 2026-07-12 · 지원 전 [OpenAI Careers](https://openai.com/careers/search/)에서 원문 확인_

## ⭐⭐⭐ 최우선 (내 프로필과 강한 공명)

### 1. Firmware Engineer, Robotics
- **하는 일**: 로보틱스 하드웨어 통합·제어용 펌웨어 (physical AI, 인프라 buildout 로봇)
- **내 매칭**: 임베디드 FW + SSD FW + physical AI 방향 ✅ / 갭: 실시간 제어, 모터/센서, 안전
- 참고: [Firmware Engineer, Robotics](https://openai.com/careers/firmware-engineer-robotics-san-francisco/)

### 2. Hardware / Software CoDesign Engineer
- **하는 일**: AI 워크로드용 HW-SW 공동 설계·최적화 (AI-native 실리콘 + 시스템)
- **내 매칭**: FW↔실리콘 브리지 역할 ✅ / 갭: ML inference 내부, 성능 모델링
- 참고: [Hardware/Software CoDesign](https://openai.com/careers/hardware-software-codesign-engineer-san-francisco/), [Research-Hardware Codesign](https://openai.com/careers/research-hardware-codesign-engineer-san-francisco/)

## ⭐⭐ 확장 방향

### 3. Design Verification (DV) Engineer
- **하는 일**: ML 가속기의 IP~subsystem~full SoC 기능검증
- **내 매칭**: 검증 감각 / 갭: SV/UVM DV 방법론
- 참고: [Design Verification Engineer](https://openai.com/careers/design-verification-engineer-san-francisco/)

### 4. Reliability / DFX Engineer
- **하는 일**: 가속기 신뢰성·DFX
- **내 매칭**: 데이터센터급 신뢰성 감각(SSD) ✅ / 갭: DFX 방법론
- 참고: [Reliability/DFX Engineer](https://openai.com/careers/reliabilitydfx-engineer-san-francisco/)

### 5. Software Engineer, Hardware
- **하는 일**: 하드웨어를 구동/검증하는 시스템 SW
- **내 매칭**: FW/시스템 / 갭: 대규모 SW 엔지니어링
- 참고: [Software Engineer, Hardware](https://openai.com/careers/software-engineer-hardware-san-francisco/)

### 6. Robotics Software Engineer
- **하는 일**: 로봇 제어/자율 SW
- **내 매칭**: 방향 부합(stretch) / 갭: ROS, 제어이론, 인지
- 참고: [Robotics Software Engineer](https://openai.com/careers/robotics-software-engineer-san-francisco/)

## 배경 (context)
- OpenAI는 프론티어 모델용 **AI-native 커스텀 실리콘**을 개발 중(Jalapeño 기반 차세대).
- **로보틱스는 2021년 해체 후 재가동** — 초점은 가정용/창고용이 아니라 **데이터센터·전력망·공장을 짓는 인프라 buildout 로봇**. → 내 임베디드/시스템 배경과 결이 맞음.
- 참고: [OpenAI robotics push (TFN)](https://techfundingnews.com/sam-altmans-openai-just-made-robotics-its-next-frontier-and-its-hiring-to-prove-it/)

## 준비 포인트 (OpenAI)
- (robotics FW) 실시간 제어·모터드라이브·센서 I/O·안전
- (co-design) transformer inference 워크로드, 메모리/대역폭 병목, roofline
- 스타트업 → 넓은 오너십 어필 (브링업+FW+통합 풀스택)
