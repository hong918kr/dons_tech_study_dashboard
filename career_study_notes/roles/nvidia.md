# NVIDIA — Target Roles

> 내 fit **가장 높은 회사**. 실리콘/HW 조직이 크고, 인터페이스·브링업·펌웨어 강점이 직결.
> _리서치 2026-07-12 · 지원 전 [NVIDIA Careers](https://www.nvidia.com/en-us/about-nvidia/careers/)에서 원문 확인_

## ⭐⭐⭐ 최우선 (내 현업과 거의 동일)

### 1. PCIe / HSIO Post-Silicon Validation Engineer
- **하는 일**: GPU의 PCIe/NVLink/C2C 등 HSIO 인터페이스 functional·electrical 브링업, 시스템레벨 검증, corner qualification, 랩 디버그
- **요구**: PCIe 프로토콜 심화, 신호무결성(SI), 랩장비(DSO/BERT/protocol·logic analyzer), BS/MS EE·CE + 5년+
- **내 매칭**: PCIe/인터페이스 브링업이 현업 그대로 ✅ / 갭: NVLink·SI 심화, GPU 랩 플로우
- 참고: [Senior PCIe Post-Silicon Validation](https://jobs.nvidia.com/careers/job/893392453421), [Senior HSIO Validation](https://jobs.anitab.org/companies/nvidia/jobs/51327545-senior-hsio-validation-engineer)

### 2. Firmware Engineer — Silicon Bring-up / SerDes Verification
- **하는 일**: 차세대 GPU/네트워크 플랫폼을 pre-silicon 시뮬 → early power-on까지 브링업, NVLink FW unit/integration 검증, feature enablement
- **요구**: 임베디드 FW, C, 실리콘 브링업, verification infra
- **내 매칭**: SSD FW + 임베디드 직결 ✅ / 갭: NVLink/네트워크 도메인
- 참고: [Firmware SerDes Verification](https://jobs.nvidia.com/careers/job/893393729230), [Firmware Engineer](https://jobs.nvidia.com/careers/job/893394876010)

## ⭐⭐ 확장 방향

### 3. Silicon Solutions / Silicon Hardware Engineer
- NVIDIA 칩을 consumer/server/mobile/**automotive** 솔루션으로 productize. Verilog/SV/VHDL, board-level, PCB
- **내 매칭**: 시스템 통합·보드 경험 / 갭: RTL 리터러시

### 4. Robotics — Isaac / Jetson (Physical AI)
- 자율 머신용 SW/HW, Isaac Sim, Jetson 플랫폼(제조/물류/헬스케어)
- **내 매칭**: 임베디드 + physical AI 방향 / 갭: 로보틱스 스택, CUDA

### 5. Jetson / Edge AI Platform Engineer (On-device)
- edge 가속기(NPU/GPU) 플랫폼, on-device inference
- **내 매칭**: on-device 방향 / 갭: CUDA, inference 런타임
