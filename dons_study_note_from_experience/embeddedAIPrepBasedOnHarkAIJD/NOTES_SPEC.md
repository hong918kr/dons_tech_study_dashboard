- 코드 실행 환경: `.venv/bin/python` (numpy 2.0, pandas, matplotlib, torch 2.8 설치됨, Python 3.9)

## 마크다운 규칙 (빌더가 지원하는 것만)
1. `#`~`###` 제목, 문단, `-`/`1.` 목록(**중첩 금지**), 표(한 행 한 줄, 셀 안 줄바꿈은 `<br>`), `> ` 인용, 코드펜스, `---`, `- [ ]` 체크박스, 인라인 `` `코드` `` `**굵게**` `[링크](url)`.
2. **raw HTML 금지** (단 표 셀 안 `<br>`, 그리고 아래 `svg` 펜스는 허용).
3. 본문에 별표 `*`를 그대로 쓰지 말 것(이탤릭으로 해석됨). 곱셈은 `×` 또는 `·`, 포인터·코드 표기는 인라인 코드로.
4. **수식**: LaTeX 렌더러가 없다. 유니코드로 쓴다 (`ŷ = σ(W·x + b)`, `∑`, `∂L/∂w`, `√`, `x²`, `≈`, `∈`, `ℝ`). 긴 수식이나 여러 줄 유도는 언어 없는 코드펜스 안에 정렬해서 쓴다.
5. 코드 블록 언어: ```` ```python ````, ```` ```c ````, ```` ```sh ````, ```` ```text ````(출력). 다이어그램은 언어 없는 ```` ``` ````.

## 그림 · 차트 (적극 사용 — 노트당 SVG 3개 이상 + ASCII 다이어그램)
- **SVG 펜스**: ```` ```svg ```` 안에 `<svg …>…</svg>`를 그대로 쓰면 페이지에 그림으로 삽입된다.
  - `viewBox`를 쓰고 `width`/`height` 속성은 생략 (반응형). 가로 480~680 정도.
  - 다크 모드 대응: 텍스트는 fill을 지정하지 않는다(자동으로 글자색). 선·축은 `stroke="currentColor"`. 데이터 색은 중간 채도 색만: 파랑 `#4a7bd0`, 주황 `#e08a3c`, 초록 `#3f9a6b`, 빨강 `#d0564a`, 회색 `#888`. 배경 사각형 금지.
  - `<text>` 크기 12~14, `font-family` 지정 금지. `<script>`, 외부 이미지, `<foreignObject>` 금지.
  - SVG 바로 다음 줄에 캡션 문단을 쓴다: `*그림 N.*`는 별표라 금지 → `그림 1 — 설명` 형태의 문단.
  - 좌표는 직접 계산해서 **정확하게** 그린다 (예: sigmoid 곡선은 점 15개 이상을 실제 계산한 polyline). 필요하면 `.venv/bin/python`으로 좌표를 계산해서 붙여 넣는다.
- 좋은 그림 예: 벡터 화살표, 행렬곱 격자, 손실 곡면·경사하강 경로, 학습/검증 loss 곡선(overfitting), 정규분포, softmax 막대, confusion matrix 히트맵, 데이터 흐름 블록도, 텐서 shape 도식.
- ASCII 다이어그램(언어 없는 펜스)도 함께 써도 된다 (메모리 레이아웃, 계산 그래프 등).

## 코드 예제 (핵심 — 반드시 실행해서 검증)
- 노트당 **실행 가능한 예제 6개 이상**. 주력은 Python(numpy / PyTorch), 필요하면 **C로 같은 계산**을 보여 줘서 펌웨어와 연결 (예: numpy 행렬곱 ↔ C 삼중 루프).
- 모든 Python 예제는 **`.venv/bin/python`으로 실제 실행**하고, 출력은 ```` ```text ```` 블록에 **실제 출력 그대로** 붙인다. 지어낸 출력 금지. 난수는 seed 고정.
- C 예제는 `cc -std=c11 -Wall -Wextra -O2`로 컴파일·실행해 경고 0개, 출력 확인. 파일은 스크래치(`/private/tmp/...` 또는 노트 폴더 밖 임시 위치)에서만 만들고 노트 폴더에 남기지 않는다.
- 각 예제 위에 "무엇을 확인하는 코드인지" 한 문장, 아래에 "출력에서 볼 것" 한두 문장.
- 한 예제는 30줄 이내가 좋다. API는 실제 존재하는 것만 (numpy 2.x, PyTorch 2.x).
